# 第4章 增益的直觉:先建立手感再谈公式

## 4.1 弹簧比喻

把伺服轴想象成:目标位置钉了一根**弹簧**,把电机往回拉。

- 增益大 = **粗硬的弹簧**:偏 1mm 就被大力拉回,又快又硬,但弹簧本身会弹来弹去(振荡);
- 增益小 = **软趴趴的橡皮筋**:拉得回,但慢慢悠悠,压上东西就偏。

真实的伺服里还有"阻尼"(消耗振荡的能量),对应速度环积分等机制。**调增益的本质 = 给这台机器配一根"最硬又不弹跳"的弹簧。**

## 4.2 阶跃响应:增益手感的"试金石"

让轴从一个位置瞬间跳到另一个位置(阶跃指令),看它怎么到位:

```
位置
 │      ←①欠阻尼(增益偏高/积分偏强):冲过头,来回晃几下才停
 │     ╭─╮
 │    ╭╯ ╰╮   ←②临界(手感最好):快,几乎不冲
 │   ╭╯   ╰╮
 │  ╭╯     ╰──╮ ←③过阻尼(增益偏低):慢吞吞爬到位
 └─┴───────────┴──→ 时间
```

| 波形长相 | 术语 | 通常是 |
|---|---|---|
| ①冲过头再回来晃 | 超调/欠阻尼 | Kp 或前馈偏大,Ti 偏小(积分偏强) |
| ②快速到位不冲或轻微冲一点点 | 良好 | 目标状态 |
| ③慢慢爬到位 | 过阻尼 | Kp 偏低 |

## 4.3 临界增益与"回退 20~30%"

从低往高调某个增益,调到**刚刚开始出现啸叫/振荡/超调的那一点**,叫**临界点**。

> ⚠ **铁律:调到临界后,回退 20~30% 再继续调下一个参数。**
> 原因:①温度变化会让机械特性漂移;②负载、行程位置会变;③留出增益裕度(第14章)。贴着临界跑的机器,冬天好好的、夏天报警,今天好好的、明天震。

## 4.4 增益的三个" NOT "

1. **增益不是越大越好**——天花板在机械(共振、齿隙),不在驱动器;
2. **增益不能凭空互相补偿**——Kv 软了用 Kp 硬撑,会破坏带宽阶梯(第6章);
3. **一次只动一个参数**——同时动两个,好了不知道谁救的,坏了不知道谁害的。

## 4.5 本章要点

1. 增益=弹簧硬度,调参=给机器配一根"最硬又不弹跳"的弹簧;
2. 阶跃响应是手感试金石:点头→偏高,爬行→偏低;
3. 调到临界点,回退 20~30%——给温度、老化、负载变化留裕度;
4. 一次只动一个参数;增益之间不能互相硬撑。

# 第5章 惯量比:最重要的"体检指标"(重点章)

## 5.1 什么是惯量

**惯量 J(kg·m²)= 转动物体的"懒惰程度"**。

推空购物车,轻轻一推就走;装满货,得使劲。转动的世界同理:转盘、联轴节、丝杠、工件……每个旋转件、每个直线移动件,都对电机表现为一份"懒得动"。

- 电机自己的惯量叫**转子惯量 Jm**——手册里有,查得到;
- 负载对电机轴表现的惯量叫**负载折算惯量 JL**——要算(下一节)。

## 5.2 折算:不同机械的惯量怎么算

**规则一:旋转件直接相加**(注意单位统一成 kg·m²)。

**规则二:直线运动件按丝杠导程折算**:

```
J = m × (Pb / 2π)²
```

m=直线负载质量(kg),Pb=丝杠导程(m)。直觉:导程越小,电机要转很多圈才前进一点,负载"拖累"电机越重?不对——导程越小,同样质量折算惯量越**小**(除以 2π 后平方)。记公式就行,直觉交给例题。

**规则三:经过减速机构,惯量除以减速比的平方**:

```
电机转 n 圈,负载转 1 圈 → 折算惯量 = 负载惯量 / n²
```

**例题 1**(直线负载):工作台+工件 10 kg,丝杠导程 10 mm = 0.01 m:

```
J = 10 × (0.01 / 6.283)² = 10 × (0.00159)² = 10 × 2.53×10⁻⁶ ≈ 2.5×10⁻⁵ kg·m²
```

**例题 2**(别忘丝杠自己!):Φ20 mm、长 1 m 的钢丝杠:
质量 = π×0.01²×1×7850 ≈ 2.5 kg → J = ½×2.5×0.01² ≈ **1.2×10⁻⁴ kg·m²**

> ⚠ 注意:丝杠自身惯量(1.2×10⁻⁴)**比工作台折算值(2.5×10⁻⁵)大 5 倍**!新手十有八九漏算丝杠。

合计:JL ≈ 1.5×10⁻⁴ kg·m²。

**例题 3**(减速的威力):同样的丝杠+负载,经 2:1 皮带减速(电机转 2 圈,丝杠转 1 圈):

```
折算 = 1.5×10⁻⁴ / 2² = 3.7×10⁻⁵ kg·m²  → 只有直接连接的 1/4!
```

> **结论:重负载想好调,加减速比。** 平方级效果,一条 3:1 的皮带抵得上换大两号电机。

**例题 4**(转盘):均质圆盘 J = ½·m·r²。直径 300 mm、重 5 kg 的铝盘:
J = ½ × 5 × 0.15² ≈ 0.056 kg·m²——一个不起眼的转盘,比例题1+2 整套丝杠系统的合计惯量(1.5×10⁻⁴)还大三百多倍。**转盘类机械是惯量大户。**

## 5.3 惯量比的定义

```
惯量比 R = 负载折算惯量 JL ÷ 电机转子惯量 Jm
```

例题 1+2 的系统,配 Jm = 1.0×10⁻⁴ kg·m² 的电机(中惯量系列约 750W 级):

```
R = 1.5×10⁻⁴ / 1.0×10⁻⁴ = 1.5   → 非常好调
```

## 5.4 为什么惯量比决定"好不好调"

两个原因,一个比一个深:

**原因一(入门级):负载越重,系统越"迟钝"。**
同样转矩,加速度 = T/(Jm+JL)。JL 越大加速越慢。想保持原来响应就得**加大增益**;而增益大了容易撞共振墙(第11章)。

**原因二(进阶级):负载越重,共振频率越低、越贴近工作频段。**
第11章会推导:负载越重,机械共振频率越往低频走、离速度环的工作频段越近,增益天花板越低。**惯量比大 = 天花板又低、你又更想跳——双重难。**

## 5.5 ★ 不同惯量区间的现象(拿现场现象对号入座)

> 使用方法:你接到一台机器,先做惯量辨识(或查模组样本),得到 R,然后对号入座——**你将要看到什么现象、要动用什么手段,这一张表说尽**。

| 惯量比区间 | 通俗评价 | 你会看到/听到的现象 | 典型调试手段 | 大概难度 |
|---|---|---|---|---|
| **R < 3**(近直接驱动) | 极好调 | 自动调谐一把过;阶跃又快又干净;全程安静;几乎听不到啸叫;用手压轴感觉很"顶"(硬) | 默认参数+自调谐即可;**警惕**:增益能推很高,若指令有毛刺会出现静止微抖(反馈噪声被放大) | ★ |
| **R = 3~10**(甜点区) | 好 | 各增益都能到手册中上水平;阶跃干净;共振频率较高(传动刚度好时 >1kHz)且远离工作频段,平时碰不到 | 自调谐+小幅微调 Kp/Ti;一般用不上陷波器 | ★★ |
| **R = 10~30**(普通工业常态) | 中等,可调好 | 加减速末端偶有过冲或轻响;某些速度段/行程段出现啸叫;速度波形有细毛刺;共振频率降到几百 Hz,开始"够得着"速度环 | 惯量辨识**必须准**;自调谐打底;手动微调;预备 1 个陷波器;考虑 S 曲线 | ★★★ |
| **R = 30~50**(困难区) | 难 | **自调谐给的参数一跑就震**;啸叫点多个;速度/转矩波形毛刺明显;定位要么过冲要么发肉;对机械质量极其敏感(换个联轴节判若两机) | 手动全面接管:降 Kv、加大 Ti、1~2 个陷波器、前馈小心加;**认真评估机械**(联轴节刚性、皮带张紧、悬伸) | ★★★★ |
| **R > 50**(专家区) | 极难,建议改机械 | 增益压很低仍然震;反谐振/谐振进入工作频段,表现为**"又肉又震"**——响应迟钝+特定速度段啸叫+定位点头并存;怎么调都达不到满意 | 电气手段全上(2自由度、DOB、深滤波)也未必救得动;**正确答案常常是改机械**:加减速比、换大惯量电机、换刚性联轴节、加支撑 | ★★★★★ |

> 💭 **想一想 1**:一台 R≈15 的机器,空载调得好好的,装上工件(R≈35)后一加速就啸叫、匀速又正常。为什么?
> 提示:加速时激励能量和惯量比各发生了什么变化?
>
> **答案**:两层原因。①装上工件 R 变大,共振频率下移,原来安全的增益现在顶到了共振;②加减速阶段指令能量大、频谱宽,最容易把共振激励起来;匀速时能量小,就"听不见"了。**处置:带满真实负载重做辨识→重调;加陷波;指令上 S 曲线。**

> 💭 **想一想 2**:同样 R=40,为什么有的机器好调、有的根本调不动?
>
> **答案**:R 只是分母分子,还有"弹簧"没算——传动**刚度 K** 和机械质量。K 大(刚性联轴节、短粗丝杠、张紧皮带)的 R=40 好调;K 小(弹性联轴节、长细丝杠、松皮带)的 R=40 是灾难。**惯量比和传动刚度要一起看**(第11章公式把两者绑在一起:共振频率 = √(K×(1/Jm+1/JL)))。

> 💭 **想一想 3**:给你一台"一加速就叫、匀速正常"的机器,你能列出三种可能原因吗?
>
> **答案**(至少):①共振(最常见的啸叫,加减速激励);②加减速过快导致转矩饱和后失控振荡(看转矩波形是否顶到上限);③速度环积分在加减速段的"滞后追赶"引起超调震荡(适当加大 Ti)。用示波看转矩/速度波形分辨:毛刺高频→共振;波形顶格→饱和;低频摆动→积分/惯量问题。

## 5.6 ★ 惯量比"填错"了会怎样(高频事故!)

驱动器里那个"惯量比"参数不是摆设——**自动调谐按它算增益,实时调谐持续参考它,转矩前馈用它算 T=J·α,不少厂商的抗扰/观测模型也拿它当参数**。设错的症状是镜像对称的:

| 惯量比设置 | 驱动器以为 | 实际结果 | 现象 |
|---|---|---|---|
| **填得比实际小**(如实际 30 填 10) | "负载轻,增益可以猛" | 实际负载重,系统迟钝,跟不上猛增益 | **震荡、啸叫、超调**——像用推空车的猛劲推满载车,车没动,人先摔 |
| **填得比实际大**(如实际 10 填 30) | "负载重,增益要保守" | 实际负载轻,被压着不敢用增益 | **系统发软:响应慢、跟随误差大、定位肉、抗扰差**——安全但性能废了 |
| 前馈连带错误 | 转矩前馈 T=J·α 用错 J | 加速段补偿过度或不足 | 过冲(填大时)或加速段滞后(填小时) |

> 💭 **想一想 4**:一台机器空载辨识后调好了,装上工件忘记重新辨识,驱动器里还是空载的惯量比。带载运行会出什么现象?
>
> **答案**:实际 R 比填的大 → 驱动器以为负载轻、给的增益偏猛 → 加速阶段啸叫/震荡/超调(和想一想 1 同源)。**口诀:机械一动,辨识重做。**换工件、换减速比、拆装联轴节,都算"一动"。

## 5.7 惯量辨识:原理与操作

驱动器让电机做特定的加减速动作,测"出多少转矩、产生多少加速度",用 T=J·a 反算总惯量,减去已知的 Jm,得到 JL,自动算出惯量比。

- **离线辨识**:调试时专门执行,负载必须真实在位、机械连接正常;
- **在线/实时辨识**:运行中持续更新,适合负载变化的场合(机械手抓不同工件);负载突变剧烈时估计值会抖,反而引入噪声,要酌情关闭;
- **何时重做**:⚠ 见上面口诀。

## 5.8 选电机的视角(顺带一提)

新手选电机问"扭矩够不够",高手第一句问"**惯量比多少**"。扭矩不够可以换大机号,但**换大机号往往同时抬高 Jm、降低 R,响应也更好**——所以"调不硬"的机器,换大一号电机经常比换驱动器更对症。

## 5.9 本章要点

1. R = JL/Jm,折算公式:丝杠 m(Pb/2π)²、减速除以 n²、圆盘 ½mr²,**别忘丝杠自身**;
2. R 大 = 天花板低 + 你更想跳 = 难;
3. 五个区间的现象表(5.5)——现场对号入座;
4. 惯量比填错:填小→震,填大→肉;
5. 机械一动,辨识重做;重负载好调靠减速比。

# 第6章 参数详解:每个旋钮"设小了/设大了"会怎样(重点章)

> 本章体例统一:每个参数 = 是什么 → 💭 想一想 → **症状对照表(设太小 / 设太大)** → 怎么调。
> 症状表是本章的灵魂。**先遮住表格,自己推,再对照**——推错了的格子,回第4、5章找直觉。

## 6.1 位置环增益 Kp(单位:s⁻¹)

**是什么**:位置环的"弹簧硬度",决定"用多高的比例把位置误差换算成速度指令"。

**两个必背公式**:

```
匀速跟随误差  Δp = v / Kp        (v=指令速度)
定位整定时间  ts ≈ 3~4 / Kp
位置闭环带宽  ≈ Kp / 2π  [Hz]     (Kp=50 s⁻¹ → 约 8 Hz)
```

**例题**:Kp=50 s⁻¹,匀速 3000 rpm(=50 r/s):

```
Δp = 50 r/s ÷ 50 s⁻¹ = 1 整圈!
```

匀速时实际位置**永远落后指令一整圈**。这不是故障,是纯 P 位置环的数学宿命——缩小它的两条路:加大 Kp(天花板在共振),或速度前馈(第10章,不用加大 Kp 就能吃掉)。

> 💭 **想一想**:Kp 设太小会怎样?先想"纠错力度小"的后果,列出 3 条;再想 Kp 设太大撞到什么墙?
>
> **答案**:太小→跟随误差大、定位最后一段爬行、轨迹跟踪松(圆弧变椭圆);太大→定位过冲/异响,更糟的是顶到速度环带宽限制,整轴震荡。

**Kp 症状对照表**:

| | 现象 | 为什么 |
|---|---|---|
| **Kp 太小** | ①匀速跟随误差大(v/Kp 大)②定位最后一段"爬行"到位慢 ③插补轨迹发松(两轴都小时圆变椭圆)④抗外扰偏移大 | 纠错比例低,误差"攒着不还" |
| **Kp 太大** | ①定位过冲、"哐当"到位 ②到位后来回晃 ③**整轴高频震荡/啸叫**(顶穿速度环带宽时)④激励机械共振 | 纠错动作过猛;位置环指挥了一个跟不上拍的速度环(违反 3~5 倍带宽阶梯);高频能量喂进共振点 |
| **判断方法** | 看定位波形:爬行型→偏小;过冲/震荡型→偏大 | |

**怎么调**:在匹配规则(6.4 节)允许的范围内,从自调谐值起步,每次 +10~20%,看到过冲或异响回退。

## 6.2 速度环增益 Kv(单位:Hz 或 s⁻¹,厂商而异)

**是什么**:速度环的"弹簧硬度",决定速度环带宽(单位 Hz 的厂商,增益≈带宽;单位 s⁻¹ 的,带宽≈Kv/2π,以手册为准)。**整台机器的"刚性"主要由它撑起来**——它硬,位置环才能配高 Kp,抗扰才强。

> 💭 **想一想**:Kv 太小,手压轴会怎样?Kv 太大,耳朵会听到什么、手会摸到什么?
>
> **答案**:太小→轴软,一压就偏,松手慢慢回来;太大→高频啸叫,电机"发麻",电流波形毛刺,严重时随机过流报警。

**Kv 症状对照表**:

| | 现象 | 为什么 |
|---|---|---|
| **Kv 太小** | ①轴"软":外力一压就偏 ②负载突变时转速跌落、恢复慢 ③速度阶跃上升缓慢 ④连带 Kp 上不去(带宽阶梯限制),整机性能平庸 | 速度环反应慢,抗扰弱 |
| **Kv 太大** | ①**高频啸叫**(最典型)②速度/转矩波形毛刺、电流抖动 ③电机异常发热 ④激发机械高频共振 ⑤随机过流/过速报警 | 反应过猛把反馈噪声和机械微小弹性振荡放大 |
| **判断方法** | 听:高频尖啸;看:速度波形毛刺;摸:电机发麻 | |

**怎么调**:每次 +20~30% 往上推,出现啸叫/毛刺回退 20~30%。这是手动调试中**最先动、也最出效果**的旋钮。

## 6.3 速度积分时间常数 Ti(单位:ms)

**是什么**:积分作用的强弱开关。**⚠ 方向反直觉:Ti 数值越小 = 积分越强 = 补偿动作越急。**它决定"对持续存在的速度偏差,多快把它补掉"。

> 💭 **想一想**:积分(=慢慢积累修正)太强,对"阶跃指令"会干什么?提示:回到淋浴比喻——"越等不到越猛补"的人会怎样?
>
> **答案**:超调和低频振荡。积累的修正量在到达目标时已经攒过头,冲过去再往回补,如此往复。

**Ti 症状对照表**:

| | 现象 | 为什么 |
|---|---|---|
| **Ti 太大(积分太弱)** | ①带持续负载时转速"掉":重力轴缓降、切削力下进给变慢 ②静态刚性差,外力下位置偏移恢复慢 ③稳态速度差消不掉 | 持续偏差没人"记账补偿" |
| **Ti 太小(积分太强)** | ①**低频"嗡—嗡"振荡**(几~几十 Hz,和共振啸叫音色完全不同!)②速度阶跃超调大、加减速"点头" ③定位末端来回晃 ④对惯量比设置错误极其敏感 | 积分攒的账在到达时过量,反复追补 |
| **判断方法** | 听音色:低沉"嗡嗡"=积分问题;尖锐"嘶叫"=比例/共振问题 | |

**怎么调**:从大(积分弱)往小推,出现低频振荡或超调回退。典型范围几 ms~上百 ms,厂商手册给推荐范围。

> 💭 **想一想**:低频"嗡嗡"震荡,你第一反应不该是什么?
>
> **答案**:不该是设陷波器!陷波器治高频共振,不治积分振荡(它不发生在一个固定频率点上,而且病根在积分强度)。第一反应:加大 Ti(减弱积分)、检查惯量比是否填对、必要时降 Kp。**先分清音色,再动手**——这是新手老手的第一道分水岭。

## 6.4 参数匹配规则:三环带宽阶梯的具体化

第3章说"内环快于外环 3~10 倍",落到参数上:

```
Kp ≤ 速度环带宽 ÷ (3~5)
```

**例题**:Kv 对应速度环带宽 100 Hz:

```
Kp ≤ 100/3~5 ≈ 20~33 s⁻¹   →  取 30 s⁻¹ 就到顶了,想更高 Kp,先提 Kv
```

> **推论(很重要)**:用户说"跟随误差大",你直接猛加 Kp,加到 40 就震——**正确路径是先提 Kv(如果机械允许),Kv 提上去后 Kp 的天花板自动抬高**。位置环和速度环是联动的,永远一起考虑。

各厂商手册会给出更精细的匹配公式(含惯量比、Ti 的修正项),以手册为准;但"外环显著慢于内环"永远成立。

## 6.5 刚性档位(增益套餐)

厂商把 Kv/Ti/Kp/滤波打包成档位:安川"刚性 1~31"、台达"PT1~PT7/ST1~ST7"等。数字越大越硬(增益越高)。

- 本质:**预设组合**,自调谐=帮你选档;
- 症状:档位低→整机软(同"增益小"症状);档位高→震(同"增益大"症状);
- 手动精调通常要退出档位模式,逐参数改。**注意**:有些机器"改了参数没反应",就是被实时自动调谐/档位模式覆盖了(故障表第12条)。

## 6.6 自动调谐:原理与局限

**原理**:辨识惯量(第5章)→按厂商的"标准机械模型"推算一组增益→写入。

**它能信到什么程度**:

| 机械状况 | 自动调谐效果 |
|---|---|
| 刚性连接、无齿隙、R<30 | 一步到位或微调即可 |
| 弹性连接(皮带/长丝杠/弹性联轴节) | 给出的参数**一跑就震**——模型假设"刚性",失配 |
| 齿隙大 | 同上,且定位末端来回晃 |
| 负载会变 | 开实时自调谐,但突变剧烈时估计值抖动,酌情关 |

> ⚠ **自动调谐是起点,不是终点。**它的输出是"不炸的及格线",不是"最优解"。弹性机械上,正确姿势是:自动调谐打底→手动降 Kv→设陷波→再逐步抬增益(第三、四部分完整演练)。

## 6.7 本章参数速查总表(打印贴墙版)

| 参数 | 设太小的症状 | 设太大的症状 | 记忆钩子 |
|---|---|---|---|
| Kp | 跟随误差大、定位爬行、轨迹松 | 过冲、异响、整轴震、激共振 | **位置误差的还债速度** |
| Kv | 轴软、抗扰差、掉速 | 高频啸叫、毛刺、发热、随机过流 | **整机的刚性支柱** |
| Ti(值越小积分越强!) | (积分弱)带载掉速、刚性差 | (积分强)低频嗡嗡、超调、点头 | **音色:嗡嗡=积分,嘶叫=比例** |
| 速度前馈 | 跟随误差大、定位慢 | 过冲、末端冲击、齿隙机械"打牙" | **抄近路,不占增益预算** |
| 转矩前馈 | 加速段滞后 | 转矩冲击、对指令毛刺敏感 | **依赖惯量准** |
| 低通滤波 τ | (τ小)毛刺噪声多 | (τ大)响应肉、滞后大、增益上不去 | **平滑是有代价的** |
| 陷波 f0/Q/深度 | (设错/太浅)共振照旧 | (太宽太深)响应肉、新共振 | **手术刀,不是锤子** |
| 惯量比 | (填小)震、啸叫、超调 | (填大)软、肉、跟随误差大 | **填小震,填大肉** |
