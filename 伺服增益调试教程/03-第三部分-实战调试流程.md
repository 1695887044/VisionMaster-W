> 本部分目标:把第二部分的"知识"变成"手上功夫"——从通电前的准备,到八步流程,到看波形诊断,到前馈调节。

# 第7章 调试前的准备:省下的都是返工

## 7.1 安全清单(一条都不能省)

- [ ] 急停按钮**亲手按一次**确认有效;
- [ ] 行程软限位、硬限位有效;
- [ ] 首次上电用**手动点动、最低速度**试方向——方向反了什么都白调;
- [ ] 调试期间手不离开急停;
- [ ] ⚠ 垂直轴(带负载会掉落的)确认抱闸逻辑正常再脱开抱闸,严防坠落。

## 7.2 参数备份( ⚠ 血泪教训第一名)

用调试软件把**出厂参数**存档。之后每调好一个阶段再存一版。
调崩了能一键回去;设备复制到第二台时能直接套用。**不备份就乱改的人,迟早有一天把整条产线调趴下。**

## 7.3 机械检查清单(调试=一半修机械)

- [ ] 联轴节顶丝紧固、无旷量(手掰电机轴与丝杠之间无相对转动);
- [ ] 皮带张紧度合适(太松→共振+齿隙;太紧→轴承发热);
- [ ] 导轨、丝杠润滑正常,拖动均匀无异响;
- [ ] 齿隙在合理范围(千分表测反向间隙);
- [ ] 底座、电机座螺丝紧固;
- [ ] **带满真实负载**(空载调好≠带载能用,第5章想一想 4)。

## 7.4 软件工具

| 厂商 | 调试软件 | 你主要用它的 |
|---|---|---|
| 松下 | PANATERM | 示波器、惯量辨识、自动调谐 |
| 安川 | SigmaWin+ | 同上 + FFT 分析 |
| 台达 | ASDA-Soft | 同上 |

# 第8章 八步调试流程(照着做)

```
①准备安全 → ②惯量辨识 → ③自动调谐打底 → ④调速度环 → ⑤调位置环 → ⑥调前馈 → ⑦治共振 → ⑧验收
```

## 第①步 准备(7章清单过一遍)

## 第②步 惯量辨识

- 带满真实负载,执行离线辨识;
- 记下 R 值,对照第二部分 5.5 的区间表,预判难度:
  - R<10 → 大概率顺利;
  - R=10~30 → 预留 1~2 小时,预备陷波器;
  - R=30~50 → 预留半天,认真检查机械;
  - R>50 → 先停,评估机械方案(减速比/换电机),别硬调。

## 第③步 自动调谐打底

执行自动调谐,得到第一组参数。**心理预期管理:它给你的是"不炸的及格线",后面三步才是拿分数。**

## 第④步 调速度环(先内环!)

| 动作 | 观察 | 过头信号 → 处置 |
|---|---|---|
| Kv 每次 +20~30% | 速度阶跃波形:上升是否又快又稳 | 啸叫/毛刺 → 回退 20~30%,记下当前值 |
| Ti 每次 -20%(积分加强) | 带载是否掉速;抗扰恢复是否变快 | 低频嗡嗡/超调 → 回退,记下 |

完成后做一个"扰动测试":匀速运行中用手(安全前提下)或负载变化观察轴被压偏多少、恢复多快——这就是你的刚性现状。

## 第⑤步 调位置环

- Kp 从当前值每次 +10~20% 上调;
- 上限两条线:**匹配规则 Kp ≤ 速度环带宽/3~5**(硬线)和**出现过冲/异响**(软线);
- 每次改动后跑一次定位动作,看定位波形(第9章)。

## 第⑥步 调前馈(第10章详解)

## 第⑦步 治共振(第四部分详解,有啸叫才做)

## 第⑧步 验收

| 项目 | 判据 |
|---|---|
| 定位超调 | 点位机 <5% 或无;精密机不允许可见过冲 |
| 整定时间 | 达到工艺要求(如"到位后 50ms 内可开始下一动作") |
| 跟随误差 | 匀速段 ≤ 工艺要求;两插补轴相互匹配 |
| 噪声 | 耳听无啸叫异响;连续运行无累计温升 |
| 报警 | 全速全行程往复 30 分钟无报警 |
| **变条件复测** | 不同速度、不同行程、正反向、空载/带载全部复测一遍 |

> ⚠ 最后一条是新手最常跳过的。增益调在"这台设备的这些工况"上,工况一变(速度变了、行程变了、温度变了)裕度可能吃光。**验收=最恶劣工况组合下仍稳定。**

# 第9章 看波形:示波器是调试者的眼睛

## 9.1 三个必看波形

| 波形 | 通道建议 | 看什么 |
|---|---|---|
| 定位波形 | 位置指令、位置反馈、位置误差 | 超调、整定时间、到位后误差是否贴零 |
| 速度波形 | 速度指令、速度反馈 | 阶跃上升沿、纹波、毛刺、有无持续振荡 |
| 转矩波形 | 转矩指令/实际 | 是否饱和(顶格)、毛刺(共振/齿隙)、低频摆动(积分问题) |

## 9.2 五种病态波形(诊断对照表)

> 💭 先自己诊断:每张"图"先猜病根,再看右侧答案。

**A 型:过冲点头型**
```
    ___________
   / \          ← 冲过目标线,回落,可能再晃一下
  /   \___/\__
```
诊断:超调。病根候选(按概率):Kp 偏大 → Ti 偏小(积分强)→ 速度前馈偏大。
药方:按此顺序逐项回调,**一次只动一个**。

**B 型:爬行到位型**
```
        __________
    ___/
   /              ← 前段快,最后一段慢慢"蹭"到位
```
诊断:欠阻尼/低增益。病根:Kp 偏小,或前馈没开。
药方:提 Kp(在匹配线内)、开速度前馈。

**C 型:毛刺振颤型**
```
    ~~~≈≈≈~~~≈≈   ← 波形上骑着一层"毛"
```
诊断:高频噪声/共振。病根:Kv 偏大顶到共振、编码器机械缺陷、齿隙打牙。
药方:FFT 找频率(第四部分)→陷波;或先降 Kv 确认方向。

**D 型:低频摆动型**
```
      ∿∿∿∿       ← 3~20 Hz 的正弦状摆动
   ______∿∿∿
```
诊断:积分太强 / 惯量比填错 / Kp-Kv 失配。
药方:加大 Ti;核对惯量比;必要时降 Kp。**不是陷波器!**(音色判断见第二部分 6.3)

**E 型:到位静止微抖型**
```
 目标线 ————————
 实际:    ∙∙∙∙∙  ← 到位后误差在极小范围内高频抖
```
诊断:静止增益过高放大反馈噪声;编码器量化;齿隙内反复修正。
药方:轻微抖可接受;明显抖→检查齿隙、略降 Kp 或开启厂商"静止增益切换"类功能。

## 9.3 波形判读口诀

> **先看频率(高频毛刺=共振/比例;低频摆动=积分),再看时刻(加减速段出事=前馈/饱和/共振;匀速段出事=跟随误差;到位出事=Kp/积分),最后看幅值(顶格=饱和)。**

# 第10章 前馈:让误差还没发生就被补偿

## 10.1 纯反馈的宿命

反馈控制是"先错后改":看到误差才动手,所以**运动中的误差永远先于纠正存在**。第二部分算过:Kp=50、3000rpm 时,匀速跟随误差 = 1 整圈。

缩小它只有两条路:
1. 加大 Kp → 代价是顶带宽天花板、激励共振;
2. **前馈** → 把已知的信息提前喂给内环,不占增益预算。

## 10.2 速度前馈

**原理**:位置环要"等误差出现"才换算出速度指令;但指令规划器**早就知道**这一时刻该多快——把这个速度直接抄近路送给速度环:

```
跟随误差  Δp = (1 − β) × v / Kp      (β=前馈系数 0~100%)
```

β=100% 时理论上跟随误差→0。例题:还是 Kp=50、3000rpm,开 100% 速度前馈后,匀速跟随误差从 1 整圈 → ≈0。

**附带好处**:定位整定时间缩短——到位瞬间误差已经很小,不需要"最后一段爬行"(B 型波形消失)。

## 10.3 转矩前馈

**原理**:加速需要转矩 T=J·α。用辨识好的惯量乘以指令加速度,**预先把转矩算好注入转矩指令**,不等速度环"发现跟不上"再补。

- **前提**:惯量辨识必须准(填错了,前馈就往错误方向补——第二部分 5.6 的表格);
- **搭配**:指令要平滑(S 曲线),否则指令上的毛刺被原样放大成转矩冲击。

## 10.4 前馈的"设小了/设大了"症状表

> 💭 先自己想:前馈开太大,指令里有毛刺时会发生什么?

| | 现象 | 为什么 |
|---|---|---|
| **前馈太小** | 跟随误差大(A/B 型波形:B 爬行型);定位慢 | 近路没修,误差还得靠 Kp 慢慢还 |
| **速度前馈太大** | ①定位**过冲**(A 型)②末端冲击 ③指令毛刺被放大,轨迹发毛 | 补偿过头,到位时"刹车不及" |
| **转矩前馈太大** | ①加减速瞬间"闷响"/顿挫 ②转矩波形尖峰 ③过流风险 | T=J·α 里 α 被指令毛刺抬高,转矩猛打 |
| **两者都大+指令生硬** | 全程"哐哐"响,像机械坏了 | 前馈忠实放大了一切指令缺陷——它分不清"你要的"和"你的指令的毛病" |

**调节步骤**(一次一个):
1. 指令先上 S 曲线/平滑;
2. 速度前馈从 80% 起试:看定位波形,过冲→降到 60~70%;不过冲且误差明显小→试 100%;
3. 需要更快加减速响应时,转矩前馈从 20~30% 小步加,看转矩波形不出现尖峰为限;
4. 每次改动复测不同速度/行程。

## 10.5 前馈的边界(高手认识,先记住结论)

> **前馈只改善"跟踪",不改善"抗扰"。**
> 外界扰动(切削力、碰撞、负载变化)前馈根本不知道——抗扰刚性仍然由 Kv+Ti+Kp 决定。
> 所以"高 Kp+小前馈"和"低 Kp+大前馈"跟踪指标可能一样,抗扰完全不同。

**不该开大前馈的场合**:
- 短行程点到点:加减速占全程,前馈全程都在"踢",过冲风险大于收益;
- 齿隙大的机械:前馈推着齿来回"打牙",异响+磨损;
- 指令生硬无平滑的上位机:先修指令。

## 10.6 本章要点

1. 前馈 = 拿"已知信息"抄近路,不占共振预算,这是它和"加 Kp"的本质区别;
2. 速度前馈治匀速跟随误差和 B 型爬行;转矩前馈治加速滞后;
3. 前馈过大 → A 型过冲、末端冲击;指令质量差时前馈是"放大器";
4. 前馈不改善抗扰;惯量错则前馈错。
