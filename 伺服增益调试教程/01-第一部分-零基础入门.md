# 第1章 伺服系统到底是什么

## 1.1 三种电机,三种"性格"

先别管参数,认识一下你以后天天打交道的家伙。

| 类型 | 怎么工作 | 知不知道自己转到哪了 | 比喻 |
|---|---|---|---|
| 普通电机(异步电机) | 通电就转,快慢靠电压/频率大概控制 | **不知道** | 家里的风扇:按几档就是几档,转多快没人管 |
| 步进电机 | 每发一个脉冲走一步,"数步子"定位 | 半知道(它假设步子没丢) | 数着步子闭眼走路的机器人:走了几步它记得,但**被绊了一下它不知道**,从此全错 |
| **伺服电机** | 随时看"眼睛",差多少补多少 | **完全知道**(编码器实时上报) | 睁着眼睛走路的机器人:被绊一下立刻发现,立刻修正 |

**伺服 = Servo,来自拉丁语 servus,"仆人"**——主人(指令)说去哪,仆人(电机)看着路(反馈)走过去,走岔了马上改。

## 1.2 伺服系统的三大件

| 部件 | 角色 | 比喻 | 一句话职责 |
|---|---|---|---|
| **伺服电机** | 手 | 干活的 | 把电能变成转动,带机械运动 |
| **编码器** | 眼睛 | 看路的 | 装在电机尾部,实时测量"转到了哪个角度、转多快",分辨率可达一圈的 839 万分之一(23 位编码器 = 8388608 个位置/圈) |
| **伺服驱动器** | 大脑 | 想事的 | 一边接收上级(PLC/控制器)的指令,一边收编码器的报告,**比较两者的差距(=误差),决定输出多大电流** |

再加一个你熟悉的角色:

| **上位机**(PLC/运动控制器/数控系统) | 上级 | 发命令的 | "转 5 圈""以 3000rpm 转""走到坐标 100mm" |

信号流就是这样一圈:

```
上位机 ──指令──► 驱动器 ──大电流──► 电机 ──机械转动──► 设备干活
                  ▲                                    │
                  └──────── 编码器反馈(转到哪了) ◄──────┘(编码器装在电机尾部)
```

## 1.3 编码器:伺服的底气

普通电机调不准的根本原因是"不知道自己转到哪"。伺服一切能力都建立在编码器上:

- **分辨率**:比如 23 位编码器,一圈分成 2²³ ≈ 839 万份,每份约 0.00004°;
- 它同时报**位置**和**速度**(速度由位置差分或特殊处理得到);
- 后面你会看到:增益能不能往高调,和编码器分辨率、采样周期有直接关系(反馈本身就是有噪声的,增益太高会把噪声放大成抖动)。

> 💭 **想一想**:为什么"知道自己在哪"这么重要?假设你是步进电机,指令让你走 10000 步,走到第 3000 步时机械卡了一下、你实际只走了 2500 步但丢了 500 步——你最后停在哪?上位机以为你在哪?
>
> **答案**:你实际停在相当于 9500 步的位置,少走了 500 步;但上位机以为你已经走满 10000 步。误差 500 步,**永远没人知道、永远没人修正**——这就是开环的宿命。伺服靠编码器发现"我实际在 9500 步的位置",于是把差的 500 步补上。

## 1.4 "伺服增益调试"在整套系统里的位置

一台设备动不好,可能的原因分布在四层:

```
上位机(指令生硬?插补不好?)      ← 不属于本教程
   │
驱动器参数(增益、前馈、滤波…)     ← ★ 本教程的主战场
   │
电机+编码器(选型对不对?)          ← 选型问题,本教程只涉及惯量匹配
   │
机械(联轴节、丝杠、皮带、齿隙…)   ← 共振的根源,第11章会教你判断
```

**经验法则:机械问题占一半,参数问题占三成,选型和上位机占剩下的。**调参数之前永远先看一眼机械——螺丝紧没紧、联轴节有没有旷量、皮带张得怎么样。机械烂,神仙参数也救不了;机械好,默认参数就能跑得不错。

# 第2章 误差:整个伺服系统拼命消灭的东西

## 2.1 定义

```
误差 e = 指令要求的位置 − 编码器测到的实际位置
```

驱动器里每时每刻都在算这个数。它一辈子只干一件事:**让误差变成 0**。

## 2.2 先做一个思想实验:淋浴调水温

你住酒店,淋浴是那种"拧一下要等两秒才变温"的老式花洒:

1. 你觉得冷,往热水方向拧一点;
2. 等 2 秒,还是冷,再拧一点;
3. 又等 2 秒——突然烫了!你赶紧往回拧;
4. 又过 2 秒——突然凉了……

这就是一个**失控的闭环系统**,而且它把伺服调试里最常见的几种病全演了一遍:

| 淋浴现象 | 伺服里的对应物 | 病根 |
|---|---|---|
| 拧了没反应,要等 | 响应慢 | 增益低(纠错力度小) |
| 突然烫过头 | 超调 | 纠错力度相对滞后太大 |
| 来回冷热振荡 | 低频振荡 | 纠错太猛 + 环路里有延迟 |
| 水温总差一点点到位 | 稳态误差 | 缺少"持续积累修正"的机制(积分) |
| 你越着急拧得越狠,振荡越凶 | 增益越高震荡越剧烈 | 增益与延迟的矛盾 |

记住这个例子。以后你调任何参数遇到怪现象,都可以回来问自己:"这在淋浴上对应什么?"

## 2.3 增益:反应的激烈程度

看到误差,出多大力气去纠正?这个"力度比例"就是增益。

- **增益大**:误差 1° 出 10 份力 → 跟得紧、定位快、抗干扰强,我们说系统很"**硬/刚**";
- **增益小**:误差 1° 出 1 份力 → 温和、安静,但跟得松、定位肉,我们说系统很"**软**"。

**核心矛盾(全文最重要的一句话)**:

> 增益大 → 快而刚,但纠错动作本身会激励机械,太大会震荡啸叫;
> 增益小 → 稳而静,但软、慢、误差大。
> **调试的全部艺术 = 在这台机器的机械允许范围内,把增益推到最高,且不震荡。**

而"机械允许到什么程度"由什么决定?——由**共振**(第11章)和**惯量比**(第5章)决定。这条线会贯穿整个教程。

## 2.4 一台轴"没调好"的三种典型长相

| 长相 | 你看到/听到的 | 通俗诊断 |
|---|---|---|
| **软**(过阻尼) | 定位慢吞吞,最后一点距离"爬"半天;用手能压动轴一丢丢 | 增益太小 |
| **炸**(不稳定) | 啸叫、来回振荡、越跑越凶甚至报警 | 增益相对机械极限太大 |
| **点头**(欠阻尼) | 到位冲过头,再回来,晃一下才停 | 增益中等偏大或积分太强 |

> 💭 **想一想**:两台一模一样的机器,A 轴增益设得很小,B 轴增益设到临界(再大就震)。加工时台面上突然压下来一个 10 N 的恒定外力,哪台轴被压偏得多?哪台恢复快?
>
> **答案**:A 偏得多、恢复慢(软);B 偏得少、恢复快(硬)。这就是"刚性"的直观含义:**抗外力保持位置的能力,基本正比于增益**。所以追求精度的人永远想把增益往高推——天花板就是共振。

# 第3章 三环:伺服的内部结构

## 3.1 为什么要套三层?一个环不行吗?

假设让驱动器直接拿"位置误差"算输出电流,一个环搞定,行不行?

问题在于三层控制的**对象、速度尺度完全不同**:

| 要管的事 | 发生的时间尺度 | 需要的反应速度 |
|---|---|---|
| 电流跟不跟得上转矩指令(力气管不管用) | 万分之一秒级 | 极快 |
| 转速跟不跟得上(快慢) | 千分之一秒级 | 快 |
| 位置到没到(到位) | 百分之一秒级 | 可以慢一点 |

**用同一个旋钮同时伺候三个速度尺度,顾此失彼。**所以分成三层,每层只管自己的事,每层的输出作为下一层的"指令"——这就是**级联(串级)控制**,俗称**三环**。

## 3.2 结构图(全书最重要的一张图,建议默画)

```
位置指令 θ*──►(−)──►【位置环 P:Kp】──ω*──►(+)──►【速度环 PI:Kv,Ti】──T*──►【电流环 PI】──► 功率PWM ──► 电机 ──► 机械负载
             ▲                 ▲ (+速度前馈ω*FF,可选)        ▲(+转矩前馈T*FF,可选)                │
             │                 └────────────┐                  └──┐                                 │
             └──── 位置反馈 ◄───────────────┴── 速度反馈 ◄─────────┴── 电流反馈 ◄─────────────────────┘
                                          (位置/速度反馈来自编码器)
```

**读图方法**(新手必练):从左往右是"命令逐级下发",底下那条长反馈线是"战果逐级上报"。前馈是两条从上直接插到内环的"捷径"(第10章才讲,现在不用管)。

| 环 | 它比较什么 | 它输出什么 |
|---|---|---|
| 位置环 | 指令位置 vs 实际位置 | **速度指令 ω\***(该转多快) |
| 速度环 | 速度指令 vs 实际速度 | **转矩指令 T\***(该出多大力) |
| 电流环 | 转矩指令(=电流) vs 实际电流 | PWM 电压(直接驱动功率管) |

## 3.3 电流环:最里层,"肌肉的神经反射"

- **管什么**:让流进电机的电流精确、快速地跟上指令。因为电机转矩 ∝ 电流,控制住电流=控制住"出多大力"。
- **多快**:带宽最高,几百 Hz 到几 kHz,反应速度是三环里最快的一层。
- **比喻**:你伸手拿杯子,手指肌肉自动微调握力——不需要大脑(你)刻意指挥每一根肌纤维。
- **⚠ 你要不要动它**:基本不要。出厂按电机参数整定好了。整定依据是电机的电阻、电感等模型,换负载不影响它多少。手册里通常有"电流环增益""电流环积分"等参数,标着"出厂设定,勿动"或干脆藏在隐藏参数里。

## 3.4 速度环:中间层,"汽车的定速巡航"

- **管什么**:让实际转速跟上速度指令 ω*。
- **两个旋钮**:
  - **速度环增益 Kv(比例)**:速度差多少,立刻出多少比例的转矩。Kv 大→转速被拉得紧、抗扰强;
  - **速度积分时间常数 Ti**:把"持续存在的速度差"随时间累积补偿掉。**注意方向:Ti 的数值越小,积分作用越强**(它是一个时间常数,时间短=补偿动作急)。
- **比喻**:定速巡航 100km/h。上坡速度掉到 95(比例项立刻加油门),坡一直陡,油门就一直多踩着(积分项记住了这个持续偏差)。
- **它是谁**:三环里你调得最多的一层。**系统的"刚性""抗扰能力"主要由它决定。**

> 💭 **想一想**:为什么只有速度环需要积分,位置环却通常不需要?
> 提示:想想"持续偏差"在外环和内环各是什么样子。
>
> **答案**:恒速运动时,速度环面对的是"指令 3000rpm、实际 2980rpm"这种**持续偏差**——需要积分记住并补掉(比如摩擦、重力需要持续转矩)。而速度环的积分保证了内环不留稳态偏差,外环剩下的匀速跟踪误差(v/Kp)靠提高 Kp 或加前馈解决即可;若外环再加积分,响应慢、容易超调和低频振荡,得不偿失。所以位置环以纯 P 为主(匀速跟踪误差 Δp=v/Kp 的来龙去脉见第二、三部分)。(个别厂商提供位置积分或"微小误差补偿",是特定场景的补丁,不是主力。)

## 3.5 位置环:最外层,"导航"

- **管什么**:让实际位置跟上指令位置。
- **一个旋钮**:位置环增益 **Kp**,单位 s⁻¹(1/秒)。含义:**每秒要把多大比例的剩余误差消化掉**。Kp=50 s⁻¹ 粗略地说"每秒消除约 50 个'比例单位'的误差"——精确含义第6章用公式讲。
- **比喻**:导航说"前方 2 km 右转",它不直接控制你的脚踩油门多重,而是告诉"巡航系统"该跑多快。位置环不直接出力,它只对速度环喊"该快些/该慢些"。

## 3.6 走一遍完整信号流(新手必须能复述)

场景:电机静止,上位机突然发指令"以 3000 rpm 正转"。

1. **位置环**:指令位置开始匀速前进,实际位置还在原地 → 误差立刻出现 → Kp 输出一个速度指令"请以 3000 rpm 转起来"(实际是让实际位置追指令);
2. **速度环**:收到速度指令,当前转速 0 → 速度误差 3000rpm → 输出大转矩指令 T*;
3. **电流环**:收到转矩指令,立刻把电流拉上去(这一步毫秒级完成);
4. **电机**:转矩使转子加速,转速上升;
5. **反馈**:编码器把新转速、新位置报回来,三环各自比较,指令逐渐收敛;
6. **稳态**:转速到达 3000rpm,速度误差→0(积分兜底);位置误差稳定在一个固定值 v/Kp(第6章算给你看,3000rpm、Kp=50 时**整整落后一圈**——这就是后面前馈要解决的问题)。

## 3.7 带宽阶梯:内环必须远快于外环

**带宽『系统反应速度的上限,单位 Hz』**。三层环的带宽必须像台阶一样排:

```
电流环 500Hz~几kHz  ≫  速度环 30~300Hz  ≫  位置环 5~50Hz
      神经反射            定速巡航              导航
```

**为什么必须这样**:外环在给内环下命令。如果内环反应比外环还慢,等于"指挥官每秒下 10 道命令,部队 1 秒才执行 1 道"——命令堆积、冲突,最后乱成一团(震荡)。

经验法则:**相邻两环带宽差 3~10 倍**。这条规则在第6章会变成具体的增益匹配公式:Kp ≤ 速度环带宽 ÷ 3~5。

## 3.8 挨了一拳之后:扰动响应的全链路(理解"刚性")

场景:设备运行中,机械手在丝杠末端压了一下(扰动)。

1. 位置被压偏 → 编码器如实上报 → **位置环**:误差!输出更高的速度指令;
2. **速度环**:速度指令升高,但实际转速被外力压着 → 输出更大的转矩指令;
3. **电流环**:立刻加大电流 → 电机输出更大转矩对抗外力;
4. 电机"顶"回去,误差消失,各环指令回落。

整条链路越快越有力(增益越高),轴被压偏得越少、恢复越快——这就是**刚性**的物理来源。同时你也看到:**任何一层慢了、软了,整条链的刚性都上不去**。

## 3.9 本章要点(背下来)

1. 三环级联:位置→速度→电流,**外环的输出=内环的给定**;
2. 电流环出厂调好,**不碰**;你的战场是速度环(Kv、Ti)和位置环(Kp);
3. 位置环通常纯 P,积分放速度环;
4. 内环必须显著快于外环(3~10 倍);
5. 刚性=抗扰保持位置的能力,由整条增益链决定,天花板是机械。
