# 附录A 公式速查(打印贴墙)

```
【惯量折算】
  丝杠直线负载    JL = m × (Pb/2π)²            m:质量kg,Pb:导程m
  减速比 n:1      JL = J负载 / n²              电机转n圈负载转1圈
  均质圆盘        J = ½·m·r²
  钢材密度        7850 kg/m³(算丝杠/滚筒自重用)
  惯量比          R = JL / Jm

【跟随与定位】
  匀速跟随误差    Δp = v / Kp
  部分速度前馈    Δp = (1−β) × v / Kp          β:前馈系数
  定位整定时间    ts ≈ 3~4 / Kp
  位置闭环带宽    f_p ≈ Kp / 2π  [Hz]

【带宽阶梯】
  位置带宽 ≤ 速度带宽 ÷ (3~5) ≤ 电流带宽 ÷ (3~5)

【共振】
  反谐振频率      ω_a = √(K / JL)
  谐振频率        ω_r = √(K·(1/Jm + 1/JL)) = ω_a·√(1+R)
  (rad/s 换 Hz:÷2π)

【滤波与延迟】
  一阶低通        fc = 1/(2πτ)
  低通相位滞后    φ = arctan(f/fc)             fc 处恰为 45°
  延迟相位        φ ≈ 360° × f × t_delay
  陷波带宽        BW = f0 / Q

【稳定性判据】
  相位裕度 PM ≥ 45°;增益裕度 GM ≥ 6dB

【前馈】
  转矩前馈        T_ff = (Jm+JL) × α
```

# 附录G 计算题答案要点

**第二部分自测题 1**:20 kg、导程 5 mm、Φ25×1.5m 丝杠、Jm=1.3×10⁻⁴
- 负载:J₁ = 20×(0.005/2π)² = 20×6.33×10⁻⁷ ≈ 1.27×10⁻⁵
- 丝杠:质量 = π×0.0125²×1.5×7850 ≈ 5.79 kg → J₂ = ½×5.79×0.0125² ≈ 4.5×10⁻⁴
- 合计 JL ≈ 4.6×10⁻⁴ → **R ≈ 3.6**(甜点区,好调;注意丝杠又是大头)

**第二部分自测题 5**:80/3~5 ≈ **16~27 s⁻¹**

**第四部分自测题 1**:JL = R×Jm = 8×10⁻⁴;ω_a = √(800/8×10⁻⁴) = 1000 rad/s ≈ **159 Hz**;ω_r = 159×√9 = **477 Hz**

**第五部分自测题 2**:360×150×0.0005 = **27°**
