# 第四部分 振动治理:共振、滤波、陷波(第11~13章)

> 本部分目标:搞懂增益的天花板——**共振**从哪来;**滤波器**为什么是双刃剑;**陷波器**这个"手术刀"怎么用、用错了会怎样。
> 前提:你已知道"高频啸叫=共振、低频嗡嗡=积分"的音色分界(第二部分 6.3)。

# 第11章 共振:增益的天花板从哪来

## 11.1 机械不是刚体

教科书里的联轴节是刚体;现实中的联轴节、皮带、丝杠,都是**弹簧**——只是硬得不一样。

于是真实系统是这样的:

```
电机 Jm ——(扭转刚度 K + 少量阻尼)—— 负载 JL
        ↑中间不是刚性连接,是一个"弹簧"
```

这叫**二质量系统**:两个惯量被一根弹簧连着。你猛推电机,负载不会立刻跟上——弹簧先扭一下,再弹回来,来回传能量。**到某个特定频率,弹簧"来不及传"、能量在机械里来回弹,这就是共振。**

## 11.2 两个关键频率(公式+例题)

```
反谐振频率  ω_a = √(K / JL)
谐振频率    ω_r = √(K × (1/Jm + 1/JL)) = ω_a × √(1 + R)
```

K=联轴节/传动链的扭转刚度(N·m/rad),R=惯量比。

**例题**:Jm=1.0×10⁻⁴,JL=5.0×10⁻⁴(R=5),弹性联轴节 K=1000 N·m/rad:

```
ω_a = √(1000 / 5×10⁻⁴) = √(2×10⁶) ≈ 1414 rad/s ≈ 225 Hz
ω_r = 225 × √6 ≈ 551 Hz
```

→ 这台机器在 **551 Hz 附近有一个共振点,225 Hz 附近有一个反谐振点**(反谐振=负载"失联"的凹点)。

**把公式和第5章连起来(惯量比与共振的关系)**:
- JL 越大(R 越大)→ ω_a 越低(√(K/JL)),ω_r 也往低频走、越来越贴近反谐振点;
- **所以"惯量比大"不只是"迟钝",还把共振点搬进了你的工作频段**——双重难,第二部分 5.5 区间表的现象全部由此而来。

> 💭 **想一想 1**:为什么"换刚性联轴节"(K 变大)能让增益调得更高?从公式出发说。
>
> **答案**:ω_r = √(K×(1/Jm+1/JL)),K 越大共振频率越高,离速度环工作频段(几十~几百 Hz)越远,增益天花板越高。这就是 5.5 表里"同样 R=40,机械好就调得动"的数学根源。

> 💭 **想一想 2**:两台机器其他都一样,一台用 10mm 短粗丝杠,一台用 1m 长细丝杠,哪台共振频率低?哪台难调?
>
> **答案**:长细丝杠刚度低(丝杠刚度∝直径⁴/长度),共振频率低,难调。而且长丝杠共振频率还**随螺母位置变化**(螺母在中点时最软)——这就是"某段行程啸叫、其他段正常"故障的来源。

## 11.3 共振源速查表(典型量级)

| 共振源 | 典型频率 | 现场特征 |
|---|---|---|
| 弹性联轴节扭转 | 100~1000 Hz | 最常见;换刚性联轴节立竿见影 |
| 同步带/皮带横向振动 | 50~300 Hz | 张紧度影响大;敲皮带听音可判断 |
| 丝杠轴向/扭转 | 几百~几 kHz | 长丝杠低且随螺母位置漂移 |
| 底座/立柱/悬臂结构 | 几十~几百 Hz | 换行程位置音调变化;结构加固解决 |
| 编码器/联轴安装缺陷 | 1~几 kHz | 小电机高频刺叫;重新安装解决 |
| 齿隙冲击 | 宽带"咔哒" | 不是纯共振,见 11.5 |

## 11.4 共振的症状清单(对号入座)

1. **啸叫**:可闻尖音,常在某段速度/某段行程出现;
2. **波形毛刺**:速度/转矩波形上骑着一层高频"毛"(第三部分 C 型);
3. **莫名报警**:过流、过速、过载——共振把电流打饱和了;
4. **手感/手感异常**:电机发"麻";工件表面出现振纹;
5. **时有时无**:特定速度段、特定行程段才出现(共振点被特定频率激励)。

> ⚠ 诊断第一问:**这个振动是"高频尖啸"还是"低沉嗡嗡"?** 尖啸→本章继续;嗡嗡→回第三部分 D 型(积分/惯量问题),别在本章浪费时间。

## 11.5 容易混淆的三种"振动"(别治错!)

| | 高频共振 | 低频积分振荡 | 齿隙极限环 |
|---|---|---|---|
| 频段 | 数百 Hz~kHz | 几~几十 Hz | 极低频,有规律来回爬 |
| 听感 | 尖啸"嘶——" | 低沉"嗡—嗡—" | 咔哒、咔哒 |
| 病根 | 机械弹性 + 增益过高 | 积分过强/惯量比错 | 齿隙+静摩擦+高增益 |
| 药方 | 陷波/滤波/降 Kv/改机械 | 加大 Ti、改惯量比、降 Kp | 齿隙补偿、降 Kp、修机械 |
| 陷波器有用吗 | **有用** | **没用,别设** | 没用 |

## 11.6 为什么增益高了会"炸"(预告第14章的直觉版)

增益放大一切,包括机械的微小弹性振荡;共振点附近,反馈的**相位**恰好让"修正"变成"火上浇油"(负反馈变正反馈)——能量越滚越大。所以**共振频率附近的环路增益必须压下去**。用什么压?——陷波器(第13章)。为什么不能用低通随便压?——见第12章。

## 11.7 本章要点

1. 传动链是弹簧,真实系统是"电机—弹簧—负载"的二质量体;
2. ω_a=√(K/JL),ω_r=ω_a·√(1+R)——**R 越大,共振频率越低、越贴近工作频段**;
3. 治振先分音色:尖啸→本章;低沉嗡嗡→积分/惯量问题,**别设陷波**;
4. 处置优先级:改机械 > 陷波 > 低通 > 降增益。

# 第12章 滤波器:双刃剑

## 12.1 滤波器藏在哪

| 位置 | 滤什么 | 什么时候动它 |
|---|---|---|
| 速度反馈滤波 | 编码器测速的高频噪声 | 测速毛刺多、小电机高频抖 |
| 转矩指令滤波 | 转矩指令的高频成分 | 压制对机械的高频激励 |
| 位置指令滤波(含前馈路径) | 上位机生硬指令 | 指令毛刺、圆弧棱角 |

## 12.2 一阶低通:最常用的滤波器

一个旋钮:**时间常数 τ(ms)**。与截止频率的关系:

```
fc = 1 / (2πτ)
τ=0.5ms → fc≈318Hz    τ=1ms → fc≈159Hz    τ=5ms → fc≈32Hz
```

低于 fc 的频率基本放行,高于 fc 的频率逐步压低。

**代价:相位滞后**(双刃剑的那一面):

```
相位滞后 φ = arctan(f / fc)
在 f = fc 处,φ = 45°
在 f = 2fc 处,φ ≈ 63°
```

**例题**:你为了压 800 Hz 的毛刺设了 τ=1ms(fc=159Hz)的低通。但你的速度环带宽是 100 Hz——在这个频率上,滤波器吃掉约 32° 相位滞后(φ=arctan(100/159))。相位裕度(第14章)通常总共才 45~60° 的家底,**这一个滤波器就先拿走过半** → 结果:毛刺是没了,系统开始低频振荡,你被迫把 Kv 降回来。

> **这题的教训(本章核心)**:滤波器的截止频率离系统带宽越近,杀伤力越大。**滤波能压振动,但压振动的代价往往是"能用的增益变低、系统变软"。**滤波不是免费的。

## 12.3 "设小了/设大了"症状表

> 💭 先自己想:把滤波时间常数 τ 设得很大,系统会变成什么样?提示:平滑=延迟,延迟=相位扣款(12.2 刚算过账)。

| | 现象 | 为什么 |
|---|---|---|
| **τ 太小/没滤波** | 波形毛刺多、静止微抖、高频激励传给机械 | 噪声和激励没拦住 |
| **τ 太大(滤波过重)** | ①响应变"肉":速度跟不上指令、定位慢 ②相位滞后吃光裕度→**低频振荡**(和积分过强易混淆!)③可配的 Kv/Kp 被迫降低,整机变软 ④前馈路径被滤慢→前馈失效 | 平滑的代价是延迟 |
| **判断方法** | 加了滤波之后**新出现**低频振荡/发肉 → 滤波过重 | |

**怎么调**:从厂商默认值起步;为了压高频毛刺,fc 至少设在**系统带宽的 5 倍以上**;每加一个滤波器,复测定位波形并重新确认增益没有被迫下调。

## 12.4 什么时候用低通,什么时候用陷波

- **毛刺是宽带噪声、没有明显单频** → 低通合适;
- **毛刺有明显单频(啸叫/FFT 有峰)** → 用陷波,别用低通(低通为压一个点,把整个高频段都拖慢了);
- 共振点太多、陷波器不够用 → 组合:陷波处理最凶的两三个,低通兜底,并接受增益损失。

## 12.5 本章要点

1. 滤波器藏在三处:速度反馈、转矩指令、位置指令(含前馈路径);
2. fc=1/(2πτ),**在 fc 处相位恰好滞后 45°**;
3. 滤波不是免费的:平滑=相位扣款=可用增益下降;
4. fc 至少设在系统带宽 5 倍以外;**单频共振用陷波,宽带噪声才用低通**。

# 第13章 陷波器(Notch):只切一个点的手术刀

## 13.1 原理图解

陷波器 = 对**某一个频率**深度衰减、对其余频率几乎无损的滤波器。三个旋钮:

```
增益(dB)
   │←———— 通带:几乎无损
 0 ┼────────────────────────────
   │            ╲
   │             ╲
-20 ┄┄┄┄┄┄┄┄┄┄┄┄╲┄┄┄┄┄┄  ← 衰减深度(如 -30 dB):切多深
   │              ╲
   │               ╲
   └──────┬──┴──┬──────→ 频率
          f0(中心频率):切哪个点
          |←带宽→|  带宽 = f0 / Q(Q 决定切多宽)
```

| 旋钮 | 含义 | 典型值 |
|---|---|---|
| 中心频率 f0 | 要切除的共振频率 | 实测得到(13.3) |
| 衰减深度 | 切多深 | 10~40 dB,从 -20dB 起步 |
| Q 值 | 切多窄,**带宽=f0/Q** | 2~10;Q=2 宽口,Q=10 窄口 |

**例题**:共振在 551 Hz(11.2 例题),设 f0=551、Q=4 → 带宽≈138 Hz(约 482~620 Hz 被切);Q=10 → 带宽≈55 Hz(约 523~578 Hz)。

**Q 的取舍(手术刀 vs 锤子的区别)**:
- **Q 高(窄)**:对相邻频率无伤、相位损失小 → 增益天花板抬得回最高;但**共振频率一漂移就切空**(失效);
- **Q 低(宽)**:频率漂移也切得住;但伤及无辜频段、相位损失大 → 抬回的增益少。

选择依据:**共振频率稳不稳**。频率钉死(刚性联轴节、负载恒定)→ 高 Q;频率漂移(长丝杠随螺母位置变、皮带、负载变化)→ 低 Q 或多级陷波。

## 13.2 ★ 陷波器"设置不合适"的症状表( ⚠ 高频事故区)

> 💭 先自己想:陷波器 f0 设错了会怎样?Q 太窄呢?深度不够呢?再对表。

| 设置错误 | 现象 | 为什么 |
|---|---|---|
| **f0 设错**(没对准真实共振频率) | 啸叫**照旧**,一点没改善——"设了等于没设" | 切错了地方,真共振点还在 |
| **Q 太窄 + 频率漂移** | **时好时坏**:某行程/某温度安静,换一段又叫 | 漂移后共振点滑出了窄刀口 |
| **深度不够** | 啸叫**变小但还在**,增益仍抬不上去 | 峰被压低但没压平,裕度还是不够 |
| **f0 误设在通带内**(如把工作基频/指令频段切了) | 系统发肉、响应怪异:特定速度段"吸一下" | 把有用频段当共振切了——手术刀切到了血管 |
| **深度太深+Q 太低(大开刀)** | 表面安静了,但响应明显变肉、甚至**诱发新的低频问题** | 切除太宽,相位损失过大,裕度在别处掉光 |
| **只在转矩指令路径生效、前馈路径没覆盖** | 加减速段仍叫 | 前馈绕过了陷波器,把共振激励又喂了进去(看厂商"2自由度/前馈滤波"设置) |

**通用纠错法**:任何陷波设置后,必做两件事——①复跑啸叫工况确认消失;②**把之前因共振压低的增益试着加回去**。第②件不做,等于白设(见 13.4)。

## 13.3 怎么找到共振频率(三招)

1. **驱动器自带 FFT/振动监视**(首选):跑一段能激发振动的运动(通常是最响的那段),看频谱最高峰——那就是 f0。SigmaWin+、MR Configurator2 等都有;
2. **手机测频 APP**:对着啸叫录几秒,主频大致就是 f0——粗糙,但够用来初次设定;
3. **经验猜**:按 11.3 的表,结合机械结构猜一个量级,用"设了有没有效"反推验证。

**实操技巧**:降 Kv 到振动消失→FFT 里看残余峰→那就是罪魁→设陷波→把 Kv 逐步加回去验证。

## 13.4 设定七步法

1. 找到 f0(13.3);
2. 设 f0、深度 -20dB、Q=3(先保证切得到);
3. 复跑啸叫工况:消失→第 5 步(若频谱里还有别的明显峰,先做第 4 步);没消失→回 13.2 表纠错(f0 错?加深?加宽?);
4. 有多个峰 → 用第二个、第三个陷波器逐个处理;
5. **把之前因共振压低的增益(Kv→Kp)逐步加回去**——每加一档复测;
6. 出现新啸叫(换了频率)→ 新峰新陷波,或把 Q 调低;
7. 验收:变条件复测(不同速度/行程/温度),确认频率漂移时仍然安静。

> **本章最重要的一句话(重复第三遍)**:治共振的最终目的不是"不叫",而是**把增益天花板抬回去**。只切峰不加增益,机器安静了但性能没回来,等于没治。

## 13.5 陷波 vs 低通 vs 降增益(决策表)

| 手段 | 压振动机制 | 代价 | 适用 |
|---|---|---|---|
| **陷波器** | 只在 f0 切除 | 相位损失局限窄带,基本不伤带宽 | 明确单频共振(**首选**) |
| 低通滤波 | 高频整体压制 | 全频段滞后,带宽被迫降 | 宽带噪声;共振点太多时兜底 |
| 降增益 | 减少能量注入 | 系统变软、误差变大 | 以上用尽后的保底 |

优先级:改机械(11.6 提过)> 陷波 > 低通 > 降增益。

## 13.6 本章要点

1. 陷波器三旋钮:f0(切哪)、深度(切多深)、Q(切多宽,带宽=f0/Q);
2. Q 的取舍:**频率稳用高 Q,频率漂移用低 Q**;
3. 设错的六种症状(f0 错/Q 窄/深度浅/切到通带/大开刀/前馈路径漏了)各有识别特征;
4. **治共振的目的是把增益抬回去,不是"不叫"**——设完陷波必须试着加增益。
