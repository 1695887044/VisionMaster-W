# 伺服增益调试系列教程(从零基础到调试高手)

> 这是一套**从"伺服是什么都不知道"讲起**的系统教程。
> 你不需要任何自动化基础,只需要愿意动手。
> 每个概念都先用生活比喻讲直觉,再给严谨定义;每个公式都配手算例题;每章末尾有小白问答和自测题。

## 二、全教程只有一条主线

所有章节都围绕这一句话展开,读到哪里忘了就回来看:

> **误差是伺服唯一要消灭的东西。三环是"分级消灭误差"的架构;增益决定纠错的力度;力度太大就会撞上"机械共振"这堵墙;滤波和陷波负责把这堵墙拓宽;前馈负责绕过这堵墙。**

## 三、四周学习计划(建议)

| 周 | 学习内容 | 动手任务 |
|---|---|---|
| 第1周 | 第一部分(第1~3章) | 默画三环框图;给同事讲一遍"淋浴调水温" |

| 第3周 | 第三部分(第7~10章) | 有条件就在一台真机(或厂商仿真软件)上走完八步流程 |
| 第4周 | 第四、五部分、补充篇(07)+附录 | 用故障速查表模拟诊断;做附录自检清单;按补充9 的速查表找到自己那本手册该看的页 |

## 四、阅读约定

- **白话**:术语第一次出现时,用"『』"标注白话解释,如:带宽『反应速度的上限』;
- **比喻**:每个抽象概念配一个生活比喻,比喻只帮理解、不严格等于定义;
- **💭 想一想**:思考题——先自己想 30 秒再看答案。本教程"从现场症状反推出参数病根"的功夫,全靠这些题练出来;
- **例题**:所有例题都给出完整计算过程,请拿计算器跟着算一遍;
- **⚠ 警告**:标 ⚠ 的地方是新手最容易犯错的地方;
- **厂商差异**:本教程讲通用原理,具体参数号(Pn001 之类)请对照你的驱动器手册,附录C 给了主流厂商的关键词对照。

## 五、学完你能达到什么水平

- **入门达标**:独立完成一台普通设备的自动调谐+手动微调,让轴稳定、安静、精度够用;
- **进阶达标**:遇到啸叫/振动,能用 FFT 定位频率、设好陷波器,把增益天花板抬回去;
- **高手达标**:能用相位裕度的语言解释一切调参现象,处理弹性机械、齿隙、摩擦等疑难杂症。
