# 第14章 稳定性与相位裕度:为什么"调大就炸"

## 14.1 换一个视角:看"整个环"

前面我们一直逐个环地看。高手会退一步,把"从误差出发→经过三环→电机→机械→编码器→回到误差"看成**一整圈**,问两个问题:

1. 这一圈的**总增益**在每个频率上有多大?
2. 这一圈的**总相位滞后**在每个频率上有多大?

画成图就是**伯德图**(增益-频率曲线、相位-频率曲线)。你的驱动器调试软件里就有(有的叫"机器分析""伺服分析")。

## 14.2 穿越频率与两个裕度

```
增益(dB)
   │
 0 ┼───────╲___
   │        ╲  ╲←—— 穿越频率 fc:总增益降到 0dB 的地方
   │         ╲   ╲     系统的"实际响应速度"就由它代表
   └──────────┴──────→ 频率(对数)
              fc
```

- **穿越频率 fc**:越高=系统响应越快=你调得越"猛"。加增益本质就是把 fc 往高频推;
- **相位裕度 PM**:在 fc 处,相位滞后离 -180°(自激的临界点)还差多少度。**PM ≥ 45° 安全,PM→0° 必震荡**;
- **增益裕度 GM**:在相位滞后 -180° 的频率上,增益还能再加多少 dB。**GM ≥ 6 dB 安全**。

> **"调大就炸"的完整解释(背下来)**:
> 加增益 → 穿越频率 fc 往高频移动 → 高频区相位滞后本来就大(滤波、延迟、共振都在高频) → fc 移进了"相位账户透支"的区域 → PM 耗尽 → 震荡。
> 增益没错,错的是**相位账户余额不够你这么跳**。

## 14.3 相位账单:每个环节都在扣款

| 环节 | 相位扣款 | 备注 |
|---|---|---|
| 积分器(I) | 固定 −90° | 速度环积分,一直挂着 |
| 每个低通滤波器 | 在其 fc 处 −45° | τ 越大,在系统带宽处的扣款越多 |
| 控制周期/采样延迟 | φ ≈ 360° × f × t_delay | 例:0.5ms 延迟,在 200Hz 处 −36°! |
| 机械共振点 | 共振前后相位剧烈摆动 ±90° | 最凶的扣款项 |

**例题**:控制周期 1ms(等效延迟约 0.5ms)。你想把速度环带宽做到 300 Hz:

```
延迟扣款 φ ≈ 360 × 300 × 0.0005 = 54°  →  一半裕度没了
```

→ 这就是"为什么同一台驱动器,带宽有物理极限"、厂商宣传"高速电流环"时在吹什么(缩短延迟,少扣相位)。

## 14.4 用这套语言重讲所有旧规则(高手自检)

| 旧规则(前面各章) | 相位裕度语言 |
|---|---|
| 内环必须快于外环 3~10 倍 | 给内环的滞后留外环的 PM |
| Kp ≤ 速度环带宽/3~5 | 同上 |
| 惯量比大要降增益 | 共振下移,提前吃光 PM |
| 滤波要节制,fc 离带宽远点 | 每个滤波器都在扣 PM |
| 临界增益回退 20~30% | 给 GM 留 3~6dB |
| Ti 太小会低频震荡 | 积分 −90° 挂得太"低"(低频),把低频 PM 吃光 |
| 换刚性联轴节能提增益 | K↑→共振频率↑→远离 fc,PM 不再被共振吃 |

**能达到这一步:你已经能自己推理出 90% 的调参规则,不需要背了。**

## 14.5 现象反推频段(疑难杂症定位法)

| 频段 | 嫌疑名单 | 第一动作 |
|---|---|---|
| 几~几十 Hz 低频振荡 | 积分过强、惯量比错、Kp/Kv 失配 | 加大 Ti、核对惯量比 |
| 百 Hz 级啸叫/振荡 | 速度环带宽顶到机械共振 | 降 Kv 或 FFT→陷波 |
| kHz 级啸叫 | 电流环边缘、编码器/联轴缺陷、高频共振 | 陷波、检查机械安装 |
| 特定行程才叫 | 长丝杠/结构共振随位置漂移 | 低 Q 陷波、改善支撑 |
| 只有加减速叫 | 共振被宽频激励 / 转矩饱和 / 前馈过大 | FFT、看转矩是否顶格、回调前馈 |

# 第15章 高手武器库(知道有这些,用前读手册)

| 武器 | 解决什么 | 原理一句话 | 代价/风险 |
|---|---|---|---|
| **2自由度控制** | 跟踪与稳定"既要又要" | 指令通道(前馈+滤波)与反馈通道(高增益)分开设计——滤波只放指令/前馈路径,反馈路径保持高增益 | 需要厂商支持;设置项多 |
| **干扰观测器 DOB** | 提高抗扰刚性而不顶共振 | 用模型实时估计扰动转矩并反向补偿,等效于"看不见地加增益" | 模型误差和噪声敏感;设猛了照样震 |
| **摩擦补偿** | 匀速爬行、圆弧象限突起 | 按速度方向注入等值反向转矩抵消摩擦 | 摩擦模型不准就补错 |
| **齿隙补偿** | 反向顿挫、定位来回找 | 机械上补角度 | 只补固定间隙,磨损后要重标 |
| **S 曲线/加减速平滑** | 从源头减少激励 | 把阶跃指令磨圆 | 响应时间略加长 |
| **前馈通道独立滤波** | 前馈有效且不喂共振 | 前馈路径单独滤波,不拖累反馈 | 配置复杂 |
| **静止/运动增益切换** | 静止微抖 | 静止时自动降增益 | 切换瞬间可能有轻微动作 |

> 使用心法:**每件武器都是"给增益让路"或"从源头减激励"**——没有一件是凭空变出性能的。机械差的机器,武器库全开也只是"能用",不是"好用"。
> 各厂商对同一件武器的叫法(模型跟随/伪微分前馈/自适应滤波器/机械谐振抑制…)见 [补充篇 补充8](07-厂家手册精华-补充篇.md)。

# 第16章 综合案例:三台病机器(问答式)

> 每个案例按"现象→你的推理→答案"推进。**先自己写推理再往下看**——这一章是全教程的毕业考。

## 案例 1:加速就叫的皮带轴

**背景**:同步皮带模组,R≈28(辨识值)。自调谐后,每次加减速"嘶——"啸叫,匀速正常,速度波形加减速段有毛刺。

**💭 推理 1**:音色高频、只在加减速、匀速没事——嫌疑名单?
**答案**:共振被宽频激励(第一);转矩饱和(第二,看波形排除);前馈过大(刚自调谐,前馈默认小,基本排除)。

**💭 推理 2**:你手上有什么工具能确认?
**答案**:跑加减速段,FFT 找峰——比如 320 Hz 处一根独峰(皮带典型频段,对照第11章表)。

**💭 推理 3**:设定方案?
**答案**:陷波 f0=320、深度-20dB、Q=2~3(**皮带+负载变化→频率会漂→低 Q 宽口**)。

**💭 推理 4**:设完就完了?
**答案**:不。①复跑确认安静;②把自调谐因啸叫压低的增益逐步加回去,复测;③变条件验收(不同行程/负载,确认漂移不切空);④如果加增益后又出现新频率的啸叫→新陷波或再降 Q。

**结局**:Kv 比初始值抬高约 40%,加减速安静,匀速跟随误差随之下降——**这就是"治共振=抬天花板"的完整闭环。**

## 案例 2:换了大工件就"发肉"的转盘轴

**背景**:转盘轴,原来装铝治具(R≈12)调得很好。客户换铁治具(R≈40)后,没重新调试,现象:定位慢吞吞、跟得松、但不震不叫。

**💭 推理 1**:不震不叫但肉——增益方向还是惯量比方向?
**答案**:不震说明增益没超限;"肉"且发生在负载变大之后——第一嫌疑:**惯量比参数还是旧值**(驱动器以为 R≈12)。

**💭 推理 2**:惯量比填得比实际小,症状应该是什么?(回第二部分 5.6)
**答案**:填小→驱动器以为负载轻→增益相对偏猛→**应该震**。但现在不震反而肉?→ 说明驱动器增益模型按旧惯量算出的绝对增益,对新负载"显得不足"——两种现象都可能出现,取决于厂商模型;**无论哪种,根源都是惯量比失真**。

**💭 推理 3**:动作?
**答案**:带新治具重做惯量辨识→按新 R(≈40)对照 5.5 区间表→自调谐打底→手动微调→验收。全程 1~2 小时,不需要动机械。

**教训**:**机械一动,辨识重做**(第二部分口诀第三次出现)。

## 案例 3:圆弧加工出"棱"的两轴系统

**背景**:XY 两轴走圆,圆上出现四个 45° 方向的凸起(象限突起),且圆整体略呈椭圆。

**💭 推理 1**:象限突起的经典原因?
**答案**:摩擦换向(X 轴过顶点时摩擦力方向翻转,跟随误差符号突变)——**这不是增益问题,加增益治不了**(第15章摩擦补偿的领地)。

**💭 推理 2**:椭圆是哪个原因?
**答案**:两轴跟随误差不同→**两轴 Kp(或前馈)不一致**。插补轴的铁律:**两轴位置环增益必须一致**(误差才同比例),否则圆变椭圆——这是"跟随误差公式 Δp=v/Kp"最实用的推论。

**💭 推理 3**:处置顺序?
**答案**:①查两轴 Kp 是否相等,不等→对齐(以较低轴为准,或提低轴);②象限突起→摩擦补偿/机械改善(导轨润滑、预压);③两轴都微调前馈,让两轴跟随误差都趋近 0 且相等。

| # | 症状 | 嫌疑(按概率排序) | 处置 |
