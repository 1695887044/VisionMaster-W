# 界面与常用功能

## 主菜单

| 菜单 | 内容 |
| --- | --- |
| 文件(F) | 方案的新建 / 打开 / 保存 / 另存等 |
| 视图(V) | 各面板的显示与隐藏、画布切换 |
| 画布(C) | 流程画布与组态画布之间的切换 |
| 工具(T) | 截屏、保存布局、加载布局、恢复默认布局、报表查询 |
| 系统(S) | 用户登录、全局变量、相机设置、运动板卡、通讯设置、硬件设置、运行窗口设置、系统参数设置、变量事件 |
| 帮助(H) | 帮助文档（就是本手册）、关于等 |

## 面板

- **算子工具箱**：按分类列出所有可用算子（插件）。分类名和本手册目录里的分类一致；
- **流程栏 / 流程画布**：搭建与查看流程；右键步骤可改名、写注释、打开「模块参数」、禁用、删除；
- **图像画布（图集）**：把流程运行中发布出来的图按流程收成一集，逐张查看、可导出；
- **监视**：每个步骤的状态（空闲/运行中/成功/失败）与耗时；
- **日志**：运行与配置的流水，出问题时先看这里。

## 变量

- **全局变量**（系统 → 全局变量）：方案级的变量表，流程与组态共用；
- 变量可以连接通信（PLC / 上位机写入）与步骤端口，实现"配方名、结果、状态"的对外交换；
- **变量事件**（系统 → 变量事件）：按变量值变化触发规则（更改数值 / 值为真 / 值为假 / 上限 / 下限）。

## 设备

- **相机设置**（系统 → 相机设置）：相机增删、连接、采流、参数与预览，配置挂在当前方案上；
- **运动板卡**（系统 → 运动板卡）：卡设置 / 手动调试 / 轴点位表 三个页签；
- **通讯设置**（系统 → 通讯设置）：串口 / 网口 / PLC 等连接与地址表；
- **硬件设置**（系统 → 硬件设置）：本机硬件相关的其它配置。

## 权限与留档

- **用户登录**（系统 → 用户登录）：登录 / 注销 / 修改密码 / 用户管理；
- 权限分档（操作员 / 工程师 / 管理员），部分操作需要更高权限；
- **空闲自动登出**：多久没人操作就退回操作员权限，时长在「系统 → 系统参数设置」里改（填 0 = 不自动登出）；
- 留档目录在程序目录下：日志 `Logs`、操作审计 `Audit`、报警历史 `Alarms`、未保存草稿 `Autosave`。
  它们各占一个目录，清日志不会连审计一起删掉。

## 系统参数设置里能改什么

「系统 → 系统参数设置」集中了几项软件级参数（存程序目录 `AppConfig.json`，点确定立即生效，不必重启）：

| 分组 | 参数 |
| --- | --- |
| 安全与会话 | 空闲自动登出时长（分钟） |
| 历史留档 | 操作审计保留天数、报警历史保留天数 |
| 画布（图像列表） | 启用画布采集、每轮开始是否清空、是否保留同一位置的历史帧、是否收录插件注入的图、是否兜底采集所有输出端口、报警时留存当前图集、总张数上限、单流程张数上限 |

## 界面布局

- 面板位置可以随意拖拽；「工具(T) → 保存布局 / 加载布局」把当前布局存下来或换回来；
- 布局乱了用「工具(T) → 恢复默认布局」。

## 运行窗口形态

- 「系统 → 运行窗口设置」决定组态运行窗口是**依附主窗口（全屏）**还是**独立窗口（并排）**，
  这是软件级偏好，存 `AppConfig.json`，改完下次打开运行窗口即生效。
