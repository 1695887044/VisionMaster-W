# 常见问题

## 启动时提示「视觉引擎（HALCON）不可用」

只影响**图像算法**（采集之外的处理、匹配、检测都跑不了），不影响看方案、配流程、调通讯。
把 HALCON 运行环境装好（或把本机 halcondotnet 相关 DLL 放回程序目录）后重启软件即可。

## 启动时提示某个插件加载失败，或工具箱里少算子

- 插件是程序目录下 `Modules` 里的 `Plugin*.dll`。先确认这个文件在；
- **改了插件源码，必须重新构建插件工程**——只重建主程序不会带出新的插件 DLL，
  跑的还是上一次编译出来的旧插件（表现为"改了没反应"，很容易误判成代码没生效）；
- 仍然失败时看日志里的「加载插件失败 xxx.dll：…」，里面是具体原因。

## 启动后提示「上次是异常退出 / 有未保存草稿」

- 未保存的方案草稿被自动转存在程序目录 `Autosave\recovered`，可以用「打开方案」载入继续编辑；
- 异常退出的现场留在程序目录 `crash_reports`，需要排查时把这个目录给维护人员。

## 改了参数但运行时没变化

- 参数改动要**重新编译并重新运行**流程才会生效（编译这一步才会把参数交给运行内核）；
- 以「模块参数」界面里显示的值与说明为准，本手册只解释参数含义，不替代界面。

## 相机连不上 / 采不到图

1. 「系统 → 相机设置」确认相机类型、连接参数（IP / 序列号）与"采流"状态；
2. 看状态文字：多数相机在界面上会直接写"未连接 / 等待客户端接入"这类原因；
3. 还不行就看日志——相机的连接与取流失败都会落一行原因。

## 图像画布（图集）里的图不更新、或太多

「系统 → 系统参数设置 → 画布（图像列表）」里控制：

- 每轮开始**清空整张画布** 还是 **只覆盖本流程上一轮的图**；
- 是否**保留同一位置的历史帧**（不勾选时每个「步骤.端口」只留最新一张）；
- **总张数上限 / 单流程张数上限**（图片占内存，别配太大）。

## 界面布局乱了 / 面板不见了

「工具(T) → 恢复默认布局」。想保留现在的布局就用「保存布局」。

## 操作一会儿就被退出登录

这是空闲自动登出的安全策略。时长在「系统 → 系统参数设置 → 空闲自动登出」里改，
填 `0` 表示不自动登出（无人值守的机台这样配）。

## 找不到某个算子的用法

左侧目录按**算子分类**找（分类名与算子工具箱一致）。目录里带「自动生成」角标的插件还没写手册，
那一页只列出了插件的描述与输入输出端口——参数细节请在流程里双击该步骤打开「模块参数」查看。
