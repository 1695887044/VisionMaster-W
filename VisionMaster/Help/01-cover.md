# 封面

**VisionMaster 视觉检测系统 · 软件使用手册**

本手册是软件自带的使用说明，与「插件自带手册」在启动时合并成一本目录：
软件手册在最上面，下面按算子分类列出每个插件的说明。

## 本手册怎么用

- 左侧目录分两类节点：**软件手册**（本部分）与**算子分类**（与算子工具箱的分类名完全一致）；
- 分类下的插件节点展开就是它自己的手册页；目录里带「自动生成」角标的插件，
  表示该插件尚未附带手册，那一页由软件按插件注册信息（描述 + 输入输出端口）自动生成；
- 顶部工具栏：**隐藏目录 / 上一步 / 打印 / 选项（正文字号）**；
- **上一步**回到上一页正文（左侧目录的选中态会跟着回退）。

## 图例约定

| 写法 | 含义 |
| --- | --- |
| 「文件(F) → 新建方案」 | 依次点击菜单里的项 |
| `SrcImage` | 插件端口名（连线时显示的名字） |
| 双击步骤 / 右键「模块参数」 | 打开该步骤的参数配置界面 |

> 手册内容随软件版本一起发布，没有独立版本号；以软件里的实际界面为准。
