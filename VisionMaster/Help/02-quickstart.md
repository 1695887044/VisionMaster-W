# 快速入门（三步走）

第一次使用，按下面三步就能跑起来一套检测流程。

## 一、新建或打开方案

- 在「文件(F)」菜单里新建方案，或打开已有的方案文件（方案文件扩展名 `.vms`）；
- 方案是"一个工位的全部内容"：它包含流程、变量、相机与运动卡配置、组态页面等；
- 方案没有打开时，流程、变量、组态这些面板都是空的——先有方案，才有后面的一切。

## 二、搭一条流程

1. 在左侧**算子工具箱**里找到要用的算子（按分类浏览，或用「帮助(H) → 帮助文档」查每个插件的说明）；
2. 把算子**拖到流程栏**，它会成为流程里的一个步骤；
3. 连接步骤之间的端口：上游步骤的输出端口 → 下游步骤的输入端口（大多数情况只需要连图像）；
4. 双击步骤（或右键「模块参数」）打开参数配置界面，改完点确认。

> 提示：写流程时先别急着配齐所有参数。先用「采集图像 → 一个处理算子 → 结果显示」跑通链路，
> 再逐个补参数——一次配完再运行，出了问题很难判断是哪一步。

## 三、编译并运行

- 流程改动后先**编译**（编译会把参数与连线固化到运行内核，并报告连不上的端口、未知的配方名等问题）；
- 然后运行：单次运行适合调试；循环运行适合产线连续跑；
- 运行中可以在**监视**页看每一步的状态与耗时，在**图像画布**看每个步骤发布出来的结果图；
- 出问题时先看**运行日志**：端口为空、参数非法、算子返回失败都会在那里留一行原因。
