# VM.Charts 图表控件 使用说明

> ScottPlot 5 的 MVVM 封装控件库。
> 一句话设计原则:**ViewModel 里零 ScottPlot 类型** —— VM 只提供数据与状态,控件负责把变化翻译成绘图调用;升级/换绘图库时只重写 `ChartView.cs` 一个文件。

- 依赖:ScottPlot 5.1.59(`ScottPlot.WPF` NuGet 包,net462+ 资产)
- 环境:.NET Framework 4.7.2+ / .NET 6+ 的 WPF
- 特性:无主题字典依赖,`UserControl` 组合实现,任何宿主直接可用

---

## 1. 文件清单

| 文件 | 内容 |
|---|---|
| `ChartView.cs` | 控件主体:适配器、渲染循环、交互(光标/吸附/卡尺/拖拽)、右键菜单、主题 |
| `ISeriesVm.cs` | 实时信号契约 + `SignalSeriesVm`(定采样率、滑动缓冲、线程安全) |
| `IScatterSeriesVm.cs` | XY 数组契约 + `ScatterSeriesVm`(按索引填充、`MaxIndex` 推进、`SetData` 整组替换) |
| `IChartAnnotation.cs` | 阈值线 `ThresholdLineVm`(可拖拽)/ 事件标记 `EventMarkerVm` |
| `ExtraSeries.cs` | 柱状 `BarSeriesVm` / 环形 `PieSeriesVm` / 直方图 `HistogramSeriesVm` / 函数 `FunctionSeriesVm` / 区域填充 `FillYSeriesVm` / 热力图 `HeatmapSeriesVm` |
| `GaugeVm.cs` | 仪表盘单项 |
| `MenuItems.cs` | 业务菜单项 `ChartMenuItemVm` + CSV 导入数据 `CsvImportData` |
| `ChartTheme.cs` | 颜色主题(优先 Fluent 令牌,无则内置同款色) |
| `ChartRenderScheduler.cs` | 全局渲染调度器(所有图共用一个 30ms 计时器) |

## 2. 快速开始

```csharp
// ── ViewModel(零 ScottPlot 类型)──
public class MonitorVm
{
    public SignalSeriesVm Ch1 { get; } = new SignalSeriesVm(
        key: "ch1", label: "CH1 传感器", color: Colors.DodgerBlue,
        sampleRate: 200, capacitySeconds: 8);
    public ThresholdLineVm UpperLimit { get; } = new ThresholdLineVm
        { Key = "upper", Y = 2.8, Label = "上限", IsDraggable = true };
    public ObservableCollection<ISeriesVm> Series => new() { Ch1 };
    public ObservableCollection<IChartAnnotation> Annotations => new() { UpperLimit };
}

// ── 采集线程(任意线程,不知道 UI 的存在)──
vm.Ch1.Append(measuredValue);          // 单点
vm.Ch1.AppendRange(buffer);            // 批量(整批只计一次版本递增)

// ── View(代码或 XAML 绑定)──
var chart = new ChartView { AutoScroll = true, AutoScrollSeconds = 4, SnapToNearest = true };
chart.SetBinding(ChartView.SeriesSourceProperty,      new Binding("Series"));
chart.SetBinding(ChartView.AnnotationsSourceProperty, new Binding("Annotations"));
```

数据流:

```
采集线程 ──写──▶ VM 缓冲区(线程安全)
                    ▲
控件 30ms 轮询 Version ◆── 有变化才渲染(拉模型,渲染频率与数据频率解耦)
```

## 3. 核心概念

### 3.1 五个数据源(都接受集合或单个对象)

| 依赖属性 | 内容类型 | 用途 |
|---|---|---|
| `SeriesSource` | `ISeriesVm`(实时信号)/ `IScatterSeriesVm`(XY 数组) | 曲线本体 |
| `AnnotationsSource` | `IChartAnnotation` | 阈值线、事件标记 |
| `ExtrasSource` | `IExtraSeriesVm` | 柱状/饼图/直方图/函数/填充/热力图 |
| `GaugesSource` | `GaugeVm` | 仪表盘 |
| `MenuItemsSource` | `ChartMenuItemVm` | 右键业务菜单项 |

> 注意:这些 DP 以 `object` 类型注册,**单个 VM 和集合都能直接绑定**(WPF 绑定把单个对象绑到 `IEnumerable` 型 DP 时会静默丢弃,库内已规避)。

### 3.2 线程模型

- 采集线程只做一件事:写系列缓冲区(`Append`/`AppendRange`,内部加锁);
- VM 的 `PropertyChanged` **可以在任意线程触发**(如 `GaugeVm.Value`、`HeatmapSeriesVm.Update()`),控件内部统一 `Dispatcher` 封送,宿主不必自己调度;
- `CursorMoved` 命令在 UI 线程执行。

### 3.3 滑窗与时间轴

`SignalSeriesVm` 写满容量后自动滑窗丢最旧,同时:

- `HeadSeconds` = 已写入总时长(单调增长,时间轴持续前进);
- `XOffsetSeconds` = 缓冲区内第一样本的全局时刻 —— 控件每帧同步给 Signal 的 `Data.XOffset`,保证曲线贴住真实时间轴。

设置 `StartTime` 后 X 刻度显示真实时钟(`HH:mm:ss`),悬浮读数与光标回传都会带绝对时间。

## 4. 系列类型参考

### 4.1 `SignalSeriesVm` — 实时信号(定采样率)

```csharp
new SignalSeriesVm(string key, string label, Color color,
                   int sampleRate, int capacitySeconds = 10, int yAxisIndex = 0)
```

| 成员 | 说明 |
|---|---|
| `Append(double)` / `AppendRange(IEnumerable<double>)` | 采集线程写入(线程安全) |
| `Clear()` | 清空(开始新一轮采集) |
| `IsVisible` / `Label` / `Color` / `LineWidth` / `LineType` | 支持 INPC 热更新(颜色/线宽/线型/可见性即时生效) |
| `StartTime`(DateTime?) | 采集起点:绝对时间轴 + 读数带时刻 |
| `YAxisIndex` | 0 = 左轴,1 = 右轴(配合 `Y2Label`) |

### 4.2 `ScatterSeriesVm` — XY 数组(如 100 万点按需增长)

```csharp
new ScatterSeriesVm(string key, string label, Color color,
                    double[] xs, double[] ys, int yAxisIndex = 0)
```

- `MaxIndex`(int):渲染上界,随数据增长推进(超界自动钳制);
- `SetData(xs, ys)`:整组替换数据源(控件自动重建曲线);
- `MarkerSize`:0 = 无标记点,>0 显示数据点;
- 适配"外部按索引填数 + 逐步显示"的历史代码(如旧 `CurveBaseView` 模式)。

### 4.3 注释元素

| 类型 | 属性 | 说明 |
|---|---|---|
| `ThresholdLineVm` | `Y` / `Label` / `Color` / `LineWidth` / `LineType` / `IsVisible` / **`IsDraggable`** | 水平阈值线;可拖拽,拖完 `Y` 自动更新(INPC 双向) |
| `EventMarkerVm` | `X` / `Label` / `Color` / `LineType` | 某时刻的竖直事件标记 |

### 4.4 扩展图形(`ExtrasSource`)

| 类型 | 构造 | 关键属性 |
|---|---|---|
| `BarSeriesVm` | `(key, label, color, double[] values)` | `Positions`(可选,默认 0..n-1) |
| `PieSeriesVm` | `(key, IList<PieSliceVm> slices)` | `DonutFraction`(0=饼图,0.5=环形);`PieSliceVm(label, value, color) |
| `HistogramSeriesVm` | `(key, label, color, double[] values, int binCount)` | 自动等宽分箱并定位箱中心 |
| `FunctionSeriesVm` | `(key, label, color, Func<double,double> f)` | 直接画 y=f(x),`LineType` 默认虚线 |
| `FillYSeriesVm` | `(key, label, fillColor, xs, ysTop, ysBottom)` | 两界之间区域填充(公差带) |
| `HeatmapSeriesVm` | `(key, double[,] intensities, string colormap="Viridis")` | `Update()` 通知重绘;`Smooth`;配色 Viridis/Plasma/Inferno/Turbo/Magma |

### 4.5 `GaugeVm` — 仪表盘单项

```csharp
new GaugeVm("rate", "采集速率", value: 100)   // Value 任意线程可写,实时摆动
```

> 仪表盘半径以"1 个数据单位的像素数"为基准,纯仪表图会自动 AutoScale 到其数据范围,无需手动设轴。

## 6. 公共方法与事件

| 成员 | 说明 |
|---|---|
| `SavePng(path, width = 800, height = 600)` | 导出 PNG(VM 可直接调用,无需窗口) |
| `SetAxisLimits(xMin, xMax, yMin, yMax, y2Min?, y2Max?)` | 显式设置轴范围(含右轴),供"X 随数据拉伸"等策略 |
| `SetAxisColors(x?, y?, y2?)` | 设置轴刻度/标签颜色(null = 不改) |
| `RefreshTheme()` | 换肤后重刷图表配色(通常无需手动调用) |
| `PlaceCursor(x, y)` | 程序化放置光标(自动化测试/标注) |
| `ConfigureMenu(Action<IPlotMenu>)` | 完全接管右键菜单(Clear/Add),调用后自动重建被跳过 |
| `PlotControl` | 底层 `WpfPlot` 只读转义舱口(约定只许 View 层使用) |
| `CsvImportRequested` 事件 | 右键"导入数据..."解析完 CSV 后触发,参数 `CsvImportData { FilePath, ColumnNames, double[][] Columns }`,由宿主决定数据送往哪个系列 |
| `ChartView.DiagnosticsLog`(静态) | 诊断输出钩子(慢帧/渲染异常/菜单自检),默认 Trace,**建议接入宿主日志** |

## 7. 右键菜单(默认中文,按图类型自适应)

```
复制图像
另存为 PNG...
复位视图
────
显示测量卡尺(✔)        ← 仅 Measurable = true 的折线/曲线图显示
✔ 光标同步
轴范围同步
导入数据...
导出数据 CSV...
────
(业务项:MenuItemsSource)
```

- **显示测量卡尺**:两条可拖拽静态线(深橙 2.5px),两线间常驻 `ΔX / 频率 / 各曲线 ΔY`;拖拽为本控件自研(命中 ±8px,拖线时不会触发图面平移);位置经 `MeasureCursorAX/BX` 双向读写;
- **导入/导出 CSV**:导出按公共时间轴写全部可见信号系列;导入解析后触发事件,数据去向由宿主决定;
- 业务项点执行其 `ICommand`;`ConfigureMenu` 可完全替换整套菜单。

## 8. 渲染与性能

- **全局调度器**:所有 ChartView 共用一个 30ms 计时器(弱引用注册表),N 张图只有一个唤醒源;不可见/未加载的图自动跳过;
- **脏标记合并**:VM 属性变化(颜色/可见性/阈值线移动/热力图更新)只打脏标记,**合并进 30ms 渲染帧**——高频改属性不会触发多次全图重绘;
- **鼠标节流**:非吸附路径十字位置逐事件跟手、提示文本约 30Hz 重算;吸附模式整体按 30Hz 执行(散点的 `GetNearest` 在大数组下逐事件查询开销明显);
- **大缓冲**:AutoScroll 的 Y 范围扫描步进采样(封顶 2000 点);渲染循环复用可见系列缓冲,稳定运行时零逐帧列表分配;
- **慢帧诊断**:单帧渲染 >50ms 记一条 `DiagnosticsLog`(1 秒最多一条);
- **异常兜底**:渲染连续 5 次异常后停止该图渲染并出示错误标题,不崩窗口;
- **纯饼图自动隐藏坐标轴网格**(条件解除自动恢复);纯仪表图同理。

> 100 万点散点 + `SnapToNearest` 的建议:吸附已按 30Hz 节流;若仍觉卡顿,可只保留可视窗口内的数据点(降低 `MaxIndex` 推进长度)或对吸附关闭该系列(`IsVisible` 不变、单独用更少点的代理系列)。

## 9. 接入现有工程

1. 拷贝 `Charts` 文件夹(10 个源文件 + 本说明)到目标工程;
2. 添加 NuGet 引用:`<PackageReference Include="ScottPlot.WPF" Version="5.1.59" />`
   - 旧式(non-SDK)工程:在 csproj 加 `<RestoreProjectStyle>PackageReference</RestoreProjectStyle>`,并从 `packages.config` 移除旧的 ScottPlot 条目;
   - 依赖树(SkiaSharp 3.119 / OpenTK 3.3)由 NuGet 自动还原;
3. 建议在启动处接日志:`ChartView.DiagnosticsLog = msg => Logger.Warn(msg);`
4. 主题:若工程合并了 Fluent 令牌字典,图表自动跟随换肤;没有则使用内置同款色,无需配置。

**面向旧 `CurveBaseView` 的迁移映射**:

| 旧用法 | 新写法 |
|---|---|
| `WpfPlot1.Plot.AddScatter(xs, ys)` + 手动 `MaxRenderIndex` | `new ScatterSeriesVm(key, label, color, xs, ys)` + 推进 `MaxIndex` |
| `AddPoint` 回调逐点填充 | 采集端按索引写 `Ys` 数组后推进 `MaxIndex`(或直接 `Append` 到 `SignalSeriesVm`) |
| `lines[i].Color / IsVisible` | VM 属性(INPC 即时生效) |
| `Plot.YAxis2.Label(...)` | `Y2Label` 属性 + 系列 `YAxisIndex = 1` |
| `SetAxisLimits(X…)` 增长拉伸 | `SetAxisLimits(...)` 方法或 `ViewLimits` 绑定 |
| `DeployCustomMenu` 右键事件 | `MenuItemsSource`(命令)或 `ConfigureMenu`(完全自定义) |
| `ClearData` + 手工重置 | `SignalSeriesVm.Clear()` / `ScatterSeriesVm.MaxIndex = 0` |

## 10. 常见问题(FAQ)

- **中文显示成方块?** 已内置 `Microsoft YaHei UI` 字体(带 SimSun 兜底),无需处理;
- **仪表盘缩成小圆环?** 纯仪表图已自动 AutoScale;请勿对仪表图手动 `SetLimits` 到 ±10 之类的大范围;
- **曲线超过容量后错位/时间轴停滞?** 已在 `XOffsetSeconds` 机制中修复;自定义系列若自行实现 `ISeriesVm`,务必正确返回 `XOffsetSeconds`;
- **拖拽卡尺没反应?** 卡尺需在"折线/曲线图"上(`Measurable = true`),且从右键菜单开启;命中范围是线两侧 ±8px;
- **把单个 VM 绑到 Source 属性不生效?** 请绑定本库的 `object` 型 Source 属性(库内已归一化);不要自行把单对象转成 `IEnumerable` 以外类型;
- **Signal 报 "Data must not contain NaN"?** ScottPlot 5 的 Signal 禁止 NaN;本库用 `MaxRenderIndex` 截断未写入区间,自定义系列不要向缓冲区填 NaN。
