## 目标重述（与原实现的差别）

你要的是**全局可复用的基座/母版**（定义一次、所有页面实时引用、改一次全部生效），而现实现是**单页内的容器控件**（`Hmi.Panel`，只服务当前页）。两者是不同东西：本批做的是"基座"这一层，而"底板"（`Hmi.Panel`）保留——它仍是"单页内的区域框"，基座则管"整页共享的公共层"。

## 核心设计：`ScadaBasePage` + 引用字段 + 合成渲染

**不做"继承"（基类页面）**——那要把 `ScadaPage` 的类型体系变成树，序列化与撤销栈都要跟着改。改成**组合 + 实时引用**：基座本身就是一份普通的 `ScadaPage`（可编辑、可进画面列表、可进属性面板），页面多一个 `BasePageId` 引用它。

### 模型层（`Scada\Models`）

| 改动 | 内容 |
|---|---|
| `ScadaPage.BasePageId` | `Guid`（默认 `Guid.Empty` = 不引用）。落盘、参与撤销。 |
| `ScadaDocument` 新增 `BasePages` 集合 | 存"可作为基座的页面"。**刻意不**与 `Pages` 合并：基座要单独管理（不许被导航、不许被删除时连带删引用它的页面）。序列化与 `Pages` 同一个范式。 |
| `ScadaPage.ResolveBase()` | 按 `BasePageId` 在 `Document.BasePages` 里反查；找不到（基座被删）返回 null，按"无基座"降级——不丢画面内容。 |
| 环检测 | `SetBasePage` 不许基座引用自己（`page.BasePageId == page.PageId`），也不许成环（A 引用 B 且 B 引用 A）。 |

### 画布渲染（`Scada.Controls\Canvas\ScadaCanvas.cs`）

画布加 `BasePage` 依赖属性，与 `Page` 并列。渲染时**合成两棵树**：基座页面在下（按 `BasePage.Background` 铺底 + 基座图元按自己的 Z 序），本页内容在上。叠放关系由"渲染先后"天然保证（基座先画）。

关键设计：**基座里的图元在运行态照常绑定**（共享画面里的曲线、报警条、公共指示灯都能活）。做法是数据泵把"本页 + 基座"两张页面的绑定合并成一份表——`ScadaRuntimeBinder` 建表时遍历 `EnumerateControls()` 的结果已经是"全量渲染的图元"，只要画布的 `EnumerateControls` 把基座图元也枚举进去，绑定就自动接上，**不动数据泵一行代码**。

### 编辑态

| 改动 | 内容 |
|---|---|
| 编辑器顶栏 | 在「新建」旁边加「基座」下拉框（候选 = `Document.BasePages` 里的页面，加一项"（无基座）"）；选了哪个，当前页就引用哪个基座。 |
| 属性面板 | 画面模式多出一行"基座"（Choice 候选 = 基座页面名）；改了它 = 写 `BasePageId`。 |
| 新建页面入口 | `AddPage(name, basePageId)` 重载；编辑态顶栏「新建」默认带当前基座（新建页默认沿用当前基座是常态）。 |
| 基座编辑 | 基座本身也进画面列表，能像普通页面一样被选中编辑；它自己的 `BasePageId` 恒为 `Guid.Empty`（基座不许再套基座）。 |

### 运行态

| 改动 | 内容 |
|---|---|
| `ScadaRuntimeHost` | `CurrentPage` 的合成视图（本页 + 基座）照常渲染；`PageLoaded`/`Unloaded` 事件只对**本页**触发，基座的事件钩子不触发（基座是"公共层"，不是"被打开的画面"）。 |
| 基座导航 | 基座页面**不参与**画面跳转下拉框（它不是终点，是公共层）。 |

### 序列化与兼容

- `BasePageId` 落盘，旧 .vms 没有它时反序列化取 `Guid.Empty`（无基座）——**不需要迁移代码**（与 `ParentId` 同一口径）。
- `ScadaDocument.CurrentSchemaVersion` **不升**：新增字段由"反序列化默认值 + `EnsureIdentity`"消化。

### 断言（进 `ScadaChecks`）

- 基座引用往返：设基座 → 保存 → 读回 → 渲染出的画面含基座图元
- 改基座一次 → 两个引用它的页面都跟着变（实时引用的核心承诺）
- 环检测：A 引用 B 且 B 引用 A 被拒
- 基座删除后引用它的页面按"无基座"降级（不崩、不丢内容）
- 基座不参与导航下拉框
- 属性面板"基座"行出现在画面模式

### 明确不做的（本轮）

- 基座**不能再套基座**（一层，与底板同口径）
- 基座上的图元在基座自己的编辑器里可以编辑；**在引用它的页面上是只读的**（在引用页上编辑基座图元会让"改一次"的语义变成"改两份"，与实时引用冲突）
- 不做"页面覆盖基座的某项"（局部替换）——那是引用 + 差量补丁，复杂度跳一个量级，先把"整页引用"做稳
- 既有 `Hmi.Panel`（底板）保留：它是"单页内的区域框"，基座是"跨页的公共层"，两者互补不冲突

### 验证方式

`dotnet build VisionMaster.sln` 0 错误；`ScadaChecks` 全绿（新增基座段断言）；渲染探针出一张"基座 + 本页"的合成 PNG 供人眼复核。
