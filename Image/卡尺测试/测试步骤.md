# 卡尺测量插件 · 手工测试流程

5 张合成测试图（本目录）几何真值精确到像素，用于在界面上验证卡尺测量的 5 种测量类型。
每张图配一对步骤：`图像采集（指定图像）→ 卡尺测量`，预期读数见下表。

| # | 测试图 | 卡尺类型 | 真值（像素当量=1.0） | 判定填法（标准值 / 上公差 / 下公差） |

## 操作步骤

1. 编译并启动主程序，新建流程（如"卡尺功能测试"）。
2. 从工具箱拖 5 个「图像采集」+ 5 个「卡尺测量」到流程里，按上表配对。
3. 每个图像采集步骤：模式选「指定图像」，选择对应的测试图。
4. 每个卡尺步骤：打开配置窗口 →
   - 「图像输入」卡片点 🔗，链接对应的图像采集输出（图像采集_0.OutputImage）；
   - 「测量类型」按下表选择；
   - 搜索区数值框按下表逐项输入（也可先拖个大概再用数值框精调）；
   - 「判定与标定」：像素当量 1.0，标准值/公差按上表；
   - 点「执行」试运行 → 右侧预览出现标注图（卡尺+边缘十字+连线），信息栏显示测量值与判定。
5. 全部配好后整体运行一次流程，在步骤输出里核对 5 个 `MeasureValue` 与 `IsOk`。

## 搜索区参数表（[中心行R, 中心列C, 角度Phi, 半长L1, 半宽L2]）

⚠ **角度 Phi 的单位是弧度**（与 HALCON 一致）：`0` = 水平扫描，`1.5708` = 竖直扫描（90°=π/2）。
半长 L1 = 扫描方向扫多远（必须横跨被测边）；半宽 L2 = 卡尺阵列排开的方向与宽度。

### 1. 宽度（白带 x∈[280,320]，宽 40px）

- 搜索区 1：`R=240, C=300, Phi=0, L1=80, L2=100`，卡尺数 5

### 2. 两点距（两竖条，左条左缘 x=97，右条左缘 x=337）

- 区 1：`R=240, C=100, Phi=0, L1=60, L2=80`
- 区 2：`R=240, C=340, Phi=0, L1=60, L2=80`
- 卡尺数 5。两点距取"每个搜索区各边缘点的平均位置"再算距离 → 240.0

### 3. 点到线距（线=竖条 x=97；点=短竖条 x=297）

- 区 1（出"点"）：`R=250, C=300, Phi=0, L1=60, L2=60`
- 区 2（拟合"线"）：`R=250, C=100, Phi=0, L1=60, L2=80`
- 卡尺数 5。点到竖直线的水平垂距 → 200.0

### 4. 圆直径（圆心 R=240, C=320，半径 100）

- 圆搜索区：`圆心行=240, 圆心列=320, 半径=100`，环宽 30，卡尺数 16
- 16 把卡尺沿圆周径向扫描 → 拟合圆 → 直径 = 2×半径 → 200.0

### 5. 角度（水平条 + 竖直条，正交）

- 区 1（竖直扫描 → 拟合出水平线）：`R=120, C=240, Phi=1.5708, L1=60, L2=80`
- 区 2（水平扫描 → 拟合出竖直线）：`R=240, C=440, Phi=0, L1=60, L2=80`
- 卡尺数 5。两线夹角归一化到 0~180° → 90.0（单位：度）

## 负向用例（顺手验证报错质量）

| 操作 | 预期 |
| --- | --- |
| 把搜索区拖到空白区（无特征） | 中文报错"第 X 把卡尺未检出边缘…请降低边缘阈值…"，不崩 |
| 边缘阈值调到 255 | 同上（检不出任何边） |
| 宽度搜索区 Phi 改成 1.5708（转 90°，扫错方向） | 报错或测不出（扫描方向不再横跨边缘） |
| 圆搜索区半径拖大、圆心挪到图像边缘 | 中文报错"圆周卡尺中心超出图像范围" |

## 备注

- 像素当量改 0.1 → 读数变为真值 ×0.1（如宽度 4.0），可验证当量换算。
- 测试图由脚本生成（黑底白形、硬边、无抗锯齿），几何真值精确到像素：
  宽度带 [280,320)、两点距条缘 97/337、点线条 97/297、圆心 (240,320) 半径 100、
  横条 y∈[117,123)、竖条 x∈[437,443)。
