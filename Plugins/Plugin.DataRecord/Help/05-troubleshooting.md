# CSV记录 · 排错

> 分类：数据处理 ｜ 来源：插件 Plugin.DataRecord

下表的文案都是插件里**原文照抄**的日志与界面文本，在宿主日志或配置面板里能逐字搜到。
`{…}` 表示运行时填进去的具体值。

## 一、步骤失败（本步骤 `Success=false`，`ErrorMessage` 就是这些）

| 日志/错误原文 | 含义 | 处置 |
| --- | --- | --- |
| `CSV记录：未配置任何启用的列` | 列全被取消勾选，或所有列名是空白 | 至少留一列勾着且列名非空 |
| `CSV记录：写入队列已满，记录被拒（检查磁盘/文件占用）` | 200 000 行的队列满了，且勾了「写入失败阻断流程」 | ① 记录目录是否在慢盘/网络盘；② 当天文件是否被 Excel 长期独占；③ 磁盘是否快满（看下面的水位日志） |
| `CSV记录：记录中枢正在关停，不再接收` | 进程正在退出，队列已关闭 | 属正常收尾（3 秒冲刷预算之后的行为）；若非退出时机出现，说明后台写线程已经异常退出，看下一节的 ERROR |

## 二、中枢后台日志（`[数据记录]` 前缀）

| 级别 | 日志原文 | 处置 |
| --- | --- | --- |
| WARN | `[数据记录] 写入队列已满（200000 行），来自『{实例名}』的一条记录被拒——请检查磁盘是否过慢/目标文件长期被占用` | 与上面的失败文案成对出现（没勾阻断时只有这条 WARN，行就丢了，必须人工补记） |
| WARN | `[数据记录] 图片队列已满，放弃存图：{不含扩展名的图片路径}` | 图多盘慢。降低节拍、改"仅NG存图"、或换更快的盘 |
| WARN | `[数据记录] 目标被占用，{N} 行已改写入旁路 {旁路路径}（原因: {异常消息}）——请关闭 Excel 中打开的 {文件名}` | 有人用 Excel **独占**打开了主账本。关掉它，再把旁路文件（除表头）粘回主账本。旁路是"宁旁路不丢账"的兜底，不是错误，但要看一眼里面是哪几行 |
| ERROR | `[数据记录] 旁路文件也写入失败，丢失 {N} 行: {异常消息}` | 真丢账。立即查目录权限、磁盘是否满、路径是否被别的进程锁死 |
| ERROR | `[数据记录] 磁盘 {盘符} 剩余 {N}MB，低于 500MB 水位——请立即清理或更换记录目录！` | 清盘或把「记录目录」换到大盘；每个盘符每 60 秒最多报一次 |
| ERROR | `[数据记录] 批量写入异常: {异常消息}` | 一批数据整体异常（权限、路径过长等）。本批可能未落盘，需要核对账本尾部 |
| ERROR | `[数据记录] 写线程异常退出: {异常消息}` | CSV 写线程死了，队列不再消费 → 很快表现为"队列已满"。重启流程最省事，之后必须查根因 |
| ERROR | `[数据记录] 图片写线程异常退出: {异常消息}` | 图片不再落盘，账本里的图片路径全部指向不存在的文件（人工补账口径见 04 第七节） |
| WARN | `[数据记录] 存图失败（账本路径已写出，需人工留意）: {图片路径}` 后面跟着异常消息（两者用竖线分隔） | 磁盘、路径过长或格式名不对。账本行是对的，图缺 |
| WARN | `[数据记录] 序列号边车 {边车路径} 无法写入（{异常消息}）——重启后序号将从 0 重来，图片可能撞名，请检查程序目录写权限` | 程序目录没有写权限（装在 `C:\Program Files` 下常见）。授权或把程序放免权限目录。**整个进程只警告一次** |
| WARN | `[数据记录] 清理过期文件失败（跳过，不影响记录）: {异常消息}` | 文件被占用或权限问题。记账不受影响，但旧账没清掉 |
| INFO | `[数据记录] 保留期清理（{N} 天）：已删除 {N} 个过期文件` | 正常。确认 `KeepDays` 没被误填（`0` 才是永不清理） |

> 这些日志由静态中枢暂存，**在下一次执行「CSV记录」步骤时**才转交宿主日志。
> 也就是说：如果流程不再跑，最后几条可能一直待在暂存队列里看不到——排查时先跑一轮再翻日志。

## 三、面板「测试写一行」的结果文本

| 界面原文 | 含义 |
| --- | --- |
| `✘ 没有启用的列，请先添加` | 列全停用或列名空白 |
| `✔ 已写入一行：{文件路径}` | 成功。注意它落在 `未赋值` 目录下（面板实例还没被引擎命名），并且**占了一个序号**，图片路径列是样例文本 |
| `✘ 写入失败：{异常消息}` | 目录建不出来 / 权限不足 / 文件被独占。异常消息原文照抄，据此定位 |

## 四、现象 → 先查这一项

| 现象 | 先查 |
| --- | --- |
| 账本某列一直是空的 | ① 来源=端口 但没连线（或上游本轮失败）；② 来源=变量 但**变量名打错**（按名精确匹配，取不到写空串，**不报"找不到"**）；③ 来源=内置 选了「图片路径」但记录方式是"不存图" |
| 选了"仅NG存图"一张都不存 | `结果列` 要**逐字等于**列名（区分大小写）；`NG值` 要等于那列**格式化之后**的文本。最常见坑：判定列接布尔端口，账本里写 `True`/`False`，而 NG值填 `NG`，永远不相等。改法：把 NG值改成 `False`，或改接输出 `OK`/`NG` 文本的端口 |
| Excel 双击打开乱码 | 本算子写的是 UTF-8 带 BOM，正常不乱码。先确认这文件是本算子写的（没被别的工具另存洗掉 BOM），再看是否用"数据导入向导"打开——那条路径不认 BOM，要手动选 UTF-8 |
| 日期列变成 `2026/9/16`（想要 `2026-09-16`） | 在该列「格式」填 `yyyy-MM-dd`（留空时时间戳列默认带时分秒毫秒） |
| Excel 里数值列变成日期或文本 | Excel 自己的类型猜测，不是账本问题。导入时指定"常规"，或在列名后加单位（如 `宽度mm`）避开自动推断 |
| 序号跳号 | 序号是**全局**的：别的「CSV记录」步骤和"测试写一行"都会占号。不是丢行 |
| 图片文件名撞车 | 序号回绕（边车写不了）或命名模板里没放 `{序号}`。模板改成 `{序号}_{结果}` |
| 跨月/跨年没建新目录 | 「记录目录」里有没有 `{yyyy-MM}`；写死月份的路径自然不会自动建新目录 |
| 同一个 CSV 里行列长短不齐 | 中途改过列定义（加/删/停用/调序），老文件结构不会被改。归档旧文件，等第二天新文件 |
| 账本里出现 `_conflict1.csv` | 见上面的"目标被占用"。粘回主账本后删掉旁路 |
| 图片路径列有值但文件不存在 | 存图失败或被跳过（队列满 / 格式名不对 / 路径过长），看 `[数据记录] 存图失败…` 或 `图片队列已满…` |
| 流程跑完账本一行都没有 | ① 步骤是否失败（看 `ErrorMessage`）；② 队列是否积压（磁盘慢）；③ 记录目录是否被改到别处；④ 该列来源是否全是端口且全没连线（会写出一行空串而不是没行） |
| 画布上找不到「图片」连接器 | 记录方式不是"不存图"后，直接在面板卡片③的「图片源」里连线即可 |

## 五、上线前自检清单

1. 「测试写一行」跑过：目录能建、表头齐、列宽合适（结果落在 `未赋值` 目录属正常）；
2. 跑一轮真流程，用资源管理器确认账本落在 `D:\Records\流程名.步骤名\年-月\日期.csv`；
3. 判定列的**实际文本**和 `NG值` 对得上（布尔列的 `True`/`False` 不等于 `NG`）；
4. 要留证就加一列内置「图片路径」，**列名填 `图片路径`**（这样「Excel报表」开箱就能点）；
5. 决定 `KeepDays`：产线一般 90/180；需长期追溯填 `0` 并配磁盘水位监控；
6. 与班长确认 `BlockOnFailure` 口径：宁停线不丢账（默认）还是绝不停线（关）；
7. 程序目录有写权限（序号边车），记录盘剩余空间有人管；
8. 变量列的变量名与上游写入的键**逐字一致**（大小写也算）——填错只会静默写空；
9. 翻一次宿主日志，确认没有 `[数据记录]` 的 WARN/ERROR 残留。
