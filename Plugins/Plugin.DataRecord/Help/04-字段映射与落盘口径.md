# CSV记录 · 字段映射与落盘口径

> 分类：数据处理 ｜ 来源：插件 Plugin.DataRecord

这页管三件事：**每一格的值从哪来、怎么变成文本**、**文本怎么落到盘上（编码/追加/轮转/清理）**，
以及**会不会丢数、丢在哪**。所有数值与判据都取自插件源码，与界面行为一致。

## 一、三路取值（字段来源）

| 来源 | 值从哪来 | 口径要点 |
| --- | --- | --- |
| `端口` | 与该列**同名的输入端口**的当前值（上游连线值，或端口里的常量手填值） | 列名 = 端口名，改列名等于改端口、要重连 |
| `变量` | 本轮运行期变量池 `context.LocalVariables` 里按 `VariableName` **精确匹配**取 | 作用域只有**本轮流程执行**（每轮新建上下文），跨轮不保留；这是「变量定义 / 变量赋值 / C#脚本」写的那个池，**不是「变量管理」里的全局变量** |
| `内置` | 由本算子自己算，见下表 | 不需要连线 |

## 二、内置字段口径

| 内置项 | 值是什么 | 细节 |
| --- | --- | --- |
| `时间戳` | 本行被记录的时刻（本地时间） | 默认文本 `yyyy-MM-dd HH:mm:ss.fff`，可用该列「格式」改 |
| `序列号` | 全局单调自增号 | 跨步骤实例、跨重启连续（靠边车）；账本里没有序号列**且**图片名不含 `{序号}` 时**不取号**，所以空耗不会发生 |
| `步骤名` | 该步骤实例名 | 等于 **流程名.步骤名**；配置面板单独跑时是"未赋值" |
| `本轮耗时ms` | `本行时刻 − 本轮流程开始时刻`，保留 1 位小数 | 是**到本步骤为止的整轮耗时**，不是本步骤自身耗时；放在流程末端才有意义，面板实例上没有上下文时取 `0.0` |
| `图片路径` | 本件图片的绝对路径 | 只有"真存了图"或"上游给的是路径字符串"时才非空；不存图时是**空串** |

## 三、单元格格式化（值 → 文本）

| 原始值 | 落笔结果 |
| --- | --- |
| `null`（没连线、上游失败、变量名打错） | 空串——**行照记，不报错** |
| `string` | 原样写入（含逗号/引号/换行时由转义规则包裹） |
| `DateTime` | 有「格式」按格式，没有则 `yyyy-MM-dd HH:mm:ss.fff` |
| 其它实现了格式化接口的值（数值、`double`、`decimal`…） | 有「格式」按格式（如 `F3`），没有则按**不变区域性**原样 |
| 其它对象（如误接进来的图像对象） | 退化成类型名文本——好过整行炸掉 |

- **一律不变区域性（InvariantCulture）**：不让区域设置把小数点写成逗号而毁掉整列对齐。
- **本算子不换算、不改数**：上游给像素就是像素、给毫米就是毫米；「格式」只做位数。量纲换算请在产出它的算子里做（标定变换或像素当量）。角度单位跟随上游（本仓约定：度）。
- **列数 = 当前启用的列数**：中途加列/删列/停用/调序**不会改动已存在文件的结构**，同一个文件里会出现长短不齐的行、列序与表头对不上。规范做法是改完列定义把旧文件改名归档（或等第二天新文件），别指望软件补表头。

## 四、时间戳与时区

账本里所有时间都是**执行机本地时间**，没有 UTC 开关（这与「结果上报」不同，那边有"时间戳用 UTC"）。
跨天/跨月滚动用的也是这个本地时刻：行入队时记下时刻，后台线程按**各行自己的时刻**展开日期占位符，
所以一批跨天的数据也能各归各文件。

## 五、编码、分隔与转义（固定，不可配）

| 项目 | 口径 |
| --- | --- |
| 编码 | **UTF-8 带 BOM**（保证 Excel 双击不乱码） |
| 分隔符 | 半角逗号，**没有**分隔符配置项 |
| 转义 | 按 RFC 4180：值里含逗号、双引号、换行时用双引号包裹，内部双引号翻倍 |
| 换行 | 每行一行一换行（Windows 环境默认） |
| 覆盖 | **没有**覆盖开关——永远 `FileMode.Append` 追加，目录不存在自动创建 |
| 表头 | 只在**文件不存在或文件长度为 0** 时写一次；追加批次绝不重复写 |
| 行数上限 | **没有**——滚动靠"目录按月 + 文件按天" |

要按小时分文件，把文件名模板写成 `{yyyy-MM-dd HH-mm-ss}.csv`；长占位符**优先替换**，
`{yyyy-MM-dd}` 不会被 `{yyyy}` 截胡，展开顺序固定为
`{StepName}` → `{yyyy-MM-dd HH-mm-ss}` → `{yyyy-MM-dd}` → `{yyyy-MM}` → `{yyyy}` → `{MM}` → `{dd}`。

## 六、轮转、清理与旁路

| 机制 | 判据 |
| --- | --- |
| 轮转 | 目录模板 + 文件名模板决定，默认每月一目录、每天一文件 |
| 保留期清理 | `KeepDays > 0` 时，每个记录目标**每天至多扫一次**：只删文件名里带 `\d{4}-\d{2}-\d{2}` 日期且早于截止日的 csv；图片目录按文件最后写入时间判旧，顺带收掉空子目录。清理失败只 WARN，绝不影响记账 |
| 名字里没有日期的文件 | **一律不动**（保守不出错） |
| 目标被占用 | 重试 3 次（递增退避 120 / 240 / 360 毫秒），仍失败 → 改写同目录旁路 `xxx_conflict1.csv`（顺延到 `_conflict99`，都占则用不带数字的 `_conflict.csv`） |

## 七、图片存不存的判定

- `每件存图`：恒存。
- `仅NG存图`：取**「结果列」这一列格式化之后的文本**，与「NG值」比较（不区分大小写）。
  注意两处大小写口径不同：`结果列` 与列名的匹配是**区分大小写**的精确匹配，`NG值` 的比较**不区分大小写**。
- 「记录方式」不是"不存图"时才有 `图片` 端口；端口给 `HImage` → 深拷贝一份独立副本交后台落盘（与上游生命周期解耦）；
  给 `string` → 只把这条现成路径抄进账本，本算子不写图。
- **图片失败不回改账本**：账本里的路径已写出，落盘失败只留 WARN 供人工补账——避免"账上少一行"这种更糟的后果。

## 八、容量、时序与"丢不丢数"

| 项目 | 数值 | 触发后果 |
| --- | --- | --- |
| 数据队列容量 | 200 000 行 | 满 → 该行被拒（非阻塞入队，不拖节拍）；勾了阻断则本步骤失败 |
| 图片队列容量 | 2 000 张 | 满 → **放弃存图**并 WARN，账本里的路径已写出，需人工补账 |
| 攒批窗口 | 500 毫秒，单批最多 5 000 行 | 磁盘慢时批与批排队，最终表现为队列满 |
| 被占用重试 | 3 次，退避 120 / 240 / 360 毫秒 | 仍失败 → 旁路文件 + WARN |
| 磁盘水位 | 每个盘符每 60 秒抽查一次，剩余低于 500 MB | 打 ERROR（不阻断写入，只预警） |
| 序号落盘 | 每前进 50 号写一次边车；退出与关停强刷 | 边车写不了 → WARN 一次 → 重启后序号从 0 重来、图片可能撞名 |
| 退出冲刷 | 预算 3 秒，之后放弃不死等 | 磁盘卡死等极端情况可能留下未写出的行——要"一行都不许丢"就勾 `每行立即落盘` |
| 中枢日志 | 即时 sink + 暂存队列（最多 2 000 条） | 步骤执行时把 sink 指向宿主日志，后台错误**当场**进日志；sink 为空（还没跑过该步骤）时暂存，等下一次执行补投 |
| 写盘失败 | `LastWriteError` + 失败计数 | 每次写盘失败记时间/目标文件/原因并自增计数；步骤用"开始快照 vs flush 后"比较，只认本次期间的新失败 |

**"宁停线不丢账"**：`BlockOnFailure` 默认开启，理由是追溯数据丢失比停一次线更贵。
它覆盖**入队被拒**与**异步写盘失败**：入队后有界等待队列落盘（最长 2 秒），本次步骤期间出现写盘错误即失败。
它不管"某一格是空值"——空值一律照记。
阻断时若本件图片尚未入队，那份副本会被就地释放，不留悬挂内存。

## 九、落点速查

| 东西 | 落在哪 |
| --- | --- |
| 账本 CSV | `记录目录` + `文件名`，默认 `D:\Records\流程1.CSV记录_0\2026-09\2026-09-16.csv` |
| 图片 | 记录目录下的 `ImageDirName`（默认 `img`）子目录，绝对路径由 `Path.GetFullPath` 拼出 |
| 旁路文件 | 主账本同目录 `2026-09-16_conflict1.csv` |
| 序号边车 | **程序目录**（宿主 exe 所在目录，不是插件 DLL 所在的 `Modules\`）下的 `DataRecord_seq.json` |

## 十、与「结果上报」的分工

| 维度 | CSV记录 | 结果上报 |
| --- | --- | --- |
| 产物 | 本地追加式 CSV 账本 | 发给对端的 HTTP 报文 |
| 失败语义 | 宁停线不丢账（默认阻断） | 重试 + 落盘暂存等补传（默认不阻断） |
| 时间口径 | 本地时间，无 UTC 开关 | 可选 UTC、格式可配 |
| 留证图 | 支持（只记路径） | 不涉及二进制，可上报图片路径文本 |

同一件产品可以既记账又上报：`CSV记录` 管"人看的账"，`结果上报` 管"MES 看的 JSON"。
