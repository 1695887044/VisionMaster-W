# CSV记录 · 端口与参数

> 分类：数据处理 ｜ 来源：插件 Plugin.DataRecord

本页逐项列「有什么端口、每个参数存盘键叫什么、默认值多少、能填什么范围、填错或接不上会怎样」。
界面标签按配置面板上的原文写，方便对着看。

## 输入端口

| 端口 | 必填 | 什么时候有 | 接不上会怎样 |
| --- | --- | --- | --- |
| `<列名>`（如 `结果`、`宽度`、`偏差`） | 否 | 「列定义」里 来源=端口 且勾了「用」的每一列，自动长出一个**同名**端口；类型 `object`，任意上游输出都接得进来 | 未连线不算「参数缺失」，那一格写**空串**，行照记、不报错。上游本轮失败时它的输出通常也是空的 |
| `图片` | 否 | 只有「记录方式」不是 `不存图` 时才存在（面板卡片③的「图片源」就是这个端口的连线入口） | 不连线就没有图：接 `HImage` 才落盘，接 `string` 只把路径抄进账本 |

> **列名就是端口名**：改名等于改端口，连线会断，需要重连；重名的列只建一个端口（但表头会重名）。
> 列名**不会自动去首尾空格**，请自己别打空格，也别用半角逗号和非法文件名字符。
> 画布上看到的连接器只有在改了配置并重新打开面板后才齐全，「图片」端口优先在面板内点连线。

## 输出端口

| 端口 | 说明 |
| --- | --- |
| `Success` | 本步骤是否成功（基类契约，供下游判定/分支用） |
| `ErrorMessage` | 失败原因文本（基类契约） |

本算子只做记录、不产出计算值，**没有**动态输出端口。

## 配置项（`[StepConfig]`，共 13 项）

| 界面标签 | 存盘键 | 类型 | 默认值 | 范围与回落 | 接不上/填错会怎样 |
| --- | --- | --- | --- | --- | --- |
| 记录目录 | `DirectoryTemplate` | 文本 | `D:\Records\{StepName}\{yyyy-MM}\` | 认 `{StepName}` `{yyyy}` `{yyyy-MM}` `{yyyy-MM-dd}` `{MM}` `{dd}` `{yyyy-MM-dd HH-mm-ss}`；整体填 `null` 回落 `D:\Records\` | 路径非法（非法字符、盘符不存在）时后台写线程报错进日志；勾着阻断则本步骤失败，未勾则账本没有新行、只留日志 |
| 文件名 | `FileNamePattern` | 文本 | `{yyyy-MM-dd}.csv` | 空白回落 `{yyyy-MM-dd}.csv`；必须自己带 `.csv` | 不带 `.csv` 也照写（扩展名不是判据），但清理逻辑只认扩展名为 csv 的文件 |
| 保留天数 | `KeepDays` | 整数 | `0` | 负数归 `0`；`0` = **永不清理** | 填了正数就会每天删一次过期文件；只认文件名里带 `yyyy-MM-dd` 日期的 csv |
| 新文件写表头 | `WriteHeader` | 布尔 | `true` | 无 | 关掉后老文件追加不受影响，新文件只有数据行没有表头 |
| 每行立即落盘 | `FlushEveryRow` | 布尔 | `false` | 无 | 打开 = 一行一次"开→写→关"，断电保真但牺牲吞吐，磁盘慢时更容易堆队列 |
| 写入失败阻断流程 | `BlockOnFailure` | 布尔 | `true` | 无 | 勾着 = 入队被拒**或异步写盘失败**时本步骤失败（有界等待队列落盘，宁停线不丢账）；取消 = 错误只写日志、该行进不了账、步骤仍成功 |
| 列定义 | `Columns` | 列集合（可序列化） | 三列：`时间`（内置:时间戳）、`序号`（内置:序列号）、`结果`（端口） | 顺序即 CSV 列顺序；见下页小节 | 全部取消勾选（或列名全空白）→ 本步骤失败并报 `CSV记录：未配置任何启用的列` |
| 记录方式 | `ImageSaveMode` | 枚举 | `不存图`（`Off`） | `不存图` / `仅NG存图` / `每件存图` | 非"不存图"才长出 `图片` 端口；`仅NG存图` 对不上判定值时一张都不存（见 05） |
| 结果列 | `ResultColumn` | 文本 | `结果` | `null` 归空串 | 要和那一列的**列名逐字一致**（区分大小写）；对不上时"仅NG存图"永不触发 |
| NG值 | `NgValue` | 文本 | `NG` | `null` 回落 `NG` | 比的是那列**格式化之后**的文本，比较不区分大小写 |
| 命名模板 | `ImageNameTemplate` | 文本 | `{序号}_{结果}` | 空白回落 `{序号}`；认 `{序号}`、`{Sequence}` 和任意列名占位符 | 占位符里写的列名不存在则**原样留在文件名**里；非法字符自动换 `_`；不含 `{序号}` 时容易撞名 |
| 格式 | `ImageFormat` | 文本 | `png` | 下拉可填 `png` / `jpg` / `bmp`；自动去空格转小写，空白回落 `png` | 写成 HALCON 不认的格式 → 存图失败进 WARN，账本路径仍已写出 |
| 图片子目录 | `ImageDirName` | 文本 | `img` | 空白回落 `img` | 它被拼在记录目录**之下**；写成绝对路径会把整条记录目录顶掉（拼接语义如此），所以只能用相对名 |

## 列定义里每一行的六个格子

| 界面列 | 存盘键 | 默认 | 说明 |
| --- | --- | --- | --- |
| 用 | `Enabled` | 勾选 | 临时停用某列不必删；取消勾选就既不建端口也不写这一格 |
| 列名 | `Name` | `列`（自动编号） | CSV 表头；来源=端口时同时是端口名 |
| 来源 | `Source` | `端口` | `端口` / `变量` / `内置` 三选一（存盘为 `Port` / `Variable` / `BuiltIn`） |
| 取值 | `VariableName` 或 `BuiltIn` | 空 / `时间戳` | 同一列表头「取值（连线 / 变量名 / 内置项）」随来源切换：端口给连线入口、变量给**可编辑下拉**（候选=全局/通讯/系统变量与上游「变量定义」，**仍可手填**脚本 `SetVar` 的名字）、内置给下拉 |
| 格式 | `Format` | 空 | .NET 格式串：数值 `F2`/`F3`/`P2`，时间 `HH:mm`。留空 = 时间走 `yyyy-MM-dd HH:mm:ss.fff`、数值按不变区域性原样 |
| （按钮） | — | — | 行末 `✕` 删除该列 |

内置项下拉五选一：`时间戳` / `序列号` / `步骤名` / `本轮耗时ms` / `图片路径`（存盘名 `Timestamp` / `Sequence` / `StepName` / `ElapsedMs` / `ImagePath`）。

| 元素 | 位置 | 行为 |
| --- | --- | --- |
| `+ 添加列` | 卡片② | 追加一列，自动起不重名的列名（`列`、`列2`、`列3`…），默认 来源=端口 |

| 说明行 | 各卡片 | 面板里的灰字提示与本页口径一致，以源码为准 |
