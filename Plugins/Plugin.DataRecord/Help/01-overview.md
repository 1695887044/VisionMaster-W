# CSV记录

> 分类：数据处理 ｜ 来源：插件 Plugin.DataRecord

流程每跑一次，就往账本里**追加一行**：时间、序号、判定、各个检测数值……
产出是一份 **UTF-8 带 BOM 的 CSV**（Excel 双击打开不乱码），还可以按判定结果同步留下 NG 图片。
检测类算子负责"判"，本算子负责"记"——它是追溯链（SPC、质量分析、客户审计）的数据源头。

## 为什么需要它 / 原理

产线的账本有两个硬要求：**不能拖节拍**、**不能丢行**。本算子的做法是"生产者-消费者"：

```
流程线程（微秒级，不碰磁盘）
  ├─ 第一遍：逐列取原始值并格式化成字符串（图片路径列先占位）
  ├─ 第二遍：处置图片（存副本 / 只记路径），得到图片路径列的值
  └─ 第三遍：整行入队 —— 入队成功就算记上了
              ↓  有界队列（数据 20 万行 / 图片 2000 张）
后台写线程（插件内的静态中枢 RecordingHub）
  ├─ CSV 写线程：500ms 攒一批 → 建目录 → 开→写→关
  └─ 图片写线程：逐张 HALCON 落盘
```

- **500ms 攒批**：节拍快时把多行合并成一次写、空闲时不空转。要"断电也不丢最后一行"就勾 `FlushEveryRow`（代价是牺牲节拍）。
- **句柄只持有几毫秒**：每批"开→写→关"，最大限度给 Excel 让路（人常常开着账本看数）。
- **多个「CSV记录」步骤共享同一个中枢**：各归各账、互不干扰；但**序号是全局单调的**（跨步骤、跨重启连续）。
- **列定义 = 动态端口**（本算子最重要的概念）：一列有三种来源——
  `端口`（连线取上游值，列名同时就是端口名）、`变量`（取本轮运行期变量）、`内置`（时间戳/序号/步骤名/耗时/图片路径，无需连线）。

## 输入端口

| 端口 | 必填 | 说明 |
| --- | --- | --- |
| `<列名>`（如 `结果`、`宽度`、`偏差`） | 否 | 「列定义」里 来源=端口 且勾了「用」的每一列，自动长出一个**同名**输入端口；类型是 `object`，任何上游输出都接得进来。未连线不算「参数缺失」，那一格写空串 |
| `图片` | 否 | 只有「图片记录方式」不是"不存图"时才存在。接 `HImage` → 深拷贝一份落盘；接 `string`（上游已存好的路径）→ 只把路径抄进账本，本算子不写图 |

> 端口名就是列名，所以列名请**用汉字或字母开头，别含空格和半角逗号**；重名的列只建一个端口。
> 「图片」端口的**连线入口在配置面板里**（卡片③）——改了记录方式后画布上不会立刻长出连接器，直接在面板内点连线即可。

## 输出端口

| 端口 | 说明 |
| --- | --- |
| `Success` | 本步骤是否成功（基类契约，供下游判定/分支用） |
| `ErrorMessage` | 失败原因（基类契约） |

本算子只做记录、不产出计算值，因此没有动态输出端口。

## 关键参数

> 完整参数与取值范围以流程中该步骤的「模块参数」界面为准，这里只解释含义。

**账本文件**

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 记录目录模板 `DirectoryTemplate` | `D:\Records\{StepName}\{yyyy-MM}\` | 占位符：`{StepName}` `{yyyy}` `{yyyy-MM}` `{yyyy-MM-dd}` `{MM}` `{dd}`。默认"每月一个目录"，跨月自动建新目录 |
| 文件名模板 `FileNamePattern` | `{yyyy-MM-dd}.csv` | 默认"每天一个文件"（按天滚动）。填空回落到它 |
| 写表头 `WriteHeader` | `true` | **只在新建文件（或空文件）时**写一行表头，追加批次不会重复写 |
| 保留天数 `KeepDays` | `0` | `0` = **永不清理**（追溯数据的删除必须显式决定）。清理只认"文件名里带 `yyyy-MM-dd` 日期"的 csv，名字没日期的文件一律不碰；图片目录按最后写入时间判旧 |
| 写入失败阻断流程 `BlockOnFailure` | `true` | 队列满/关停中被拒时让本步骤**失败**（宁停线不丢账）。取消则只写 WARN 继续跑 |
| 每行立即落盘 `FlushEveryRow` | `false` | 一行一开一关，断电保真、牺牲节拍 |

**列定义（`Columns`，顺序就是 CSV 的列顺序）**

出厂三列：`时间`（内置:时间戳）、`序号`（内置:序列号）、`结果`（端口，需自己连线）。
每一行六个字段：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| 用 `Enabled` | `勾选` | 临时停用某列不必删除；取消勾选就不建端口、也不写这一格 |
| 列名 `Name` | `""` | CSV 表头；来源=端口时同时是端口名 |
| 来源 `Source` | `端口` | `端口` / `变量` / `内置` 三选一 |
| 变量名 `VariableName` | `""` | 来源=变量时**手打**的键名（见下方"名字类行"） |
| 内置项 `BuiltIn` | `时间戳` | 来源=内置时选哪种：时间戳 / 序列号 / 步骤名 / 本轮耗时ms / 图片路径 |
| 格式 `Format` | `""` | .NET 格式串：数值填 `F2`/`F3`，时间填 `HH:mm`。留空 = 时间 `yyyy-MM-dd HH:mm:ss.fff`、数值按不变文化原样 |

**图片记录**

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 图片记录方式 `ImageSaveMode` | `不存图` | `不存图` / `仅NG存图`（推荐，省磁盘省节拍）/ `每件存图` |
| 结果列名 `ResultColumn` | `结果` | "仅NG存图"看**这一列**的值决定存不存 |
| NG 判定值 `NgValue` | `NG` | 结果列的值等于它即视为 NG（比较不区分大小写） |
| 图片子目录 `ImageDirName` | `img` | 位于记录目录之下，如 `D:\Records\流程1.CSV记录\2026-09\img` |
| 图片命名模板 `ImageNameTemplate` | `{序号}_{结果}` | 可用 `{序号}` 与**任意列名**做占位符；非法文件名字符自动换成 `_` |
| 图片格式 `ImageFormat` | `png` | `png` / `bmp` / `jpg`（HALCON 落盘，自动补扩展名） |

## 口径与失败策略

- **编码与分隔符固定、不可配**：UTF-8 **带 BOM**、逗号分隔、按 RFC 4180 转义（含逗号/引号/换行的值加双引号、内部引号翻倍）。
  这是刻意的——保证 Excel 双击不乱码、列不错位。**没有**编码项、**没有**分隔符项、**没有**覆盖选项、**没有**行数上限（滚动靠"目录按月 + 文件按天"）。
- **只追加、绝不覆盖**：`FileMode.Append`，目录不存在自动创建。
- **数值一律不变区域性（InvariantCulture）**：不让区域设置把小数点变成逗号而毁掉整列对齐。
- **没连线的列 = 空串**：上游本轮失败时它的输出端口通常是空的，账本里那一格就是空——**行照记，不报错**。
- **图片存失败不回改账本**：账本里的图片路径已经写出，落盘失败只留一条 WARN 供人工补账（避免"账上少一行"这种更糟的后果）。
- **目标被占用不丢账**：写不进去重试 3 次（递增退避），仍失败就改写**旁路文件** `xxx_conflict1.csv` 并 WARN 提示关闭 Excel。
- **磁盘水位**：每个记录盘符每 60 秒抽查一次，剩余低于 **500MB** 打 ERROR。
- **序号跨重启续号**：程序目录下的边车 `DataRecord_seq.json` 每 50 号落一次盘。边车写不了（程序目录无写权限）会 WARN 一次，**重启后序号从 0 重来、图片可能撞名**。
- **进程退出**：3 秒预算内尽力把队列冲刷干净（残留行落盘、序号落盘）。
- **名字类行只能手填**（本仓纪律 R33）：`变量名`、`结果列名`、`图片命名模板`里的 `{列名}` 要的是**名字**不是值，所以界面给的是文本框而不是连线入口。填错的后果是**静默写空**（不报"找不到"），排查方法见第二页。

## 典型用法 / 接线

```
① 缺陷检测存档（最小账本）
Blob.IsOk ─────────────▶ CSV记录.结果
Blob.DefectCount ──────▶ CSV记录.缺陷数        （新增一列：缺陷数，来源=端口）
Blob.DefectImage ──────▶ CSV记录.图片          （记录方式=仅NG存图）
                          └─▶ D:\Records\流程1.CSV记录\2026-09\2026-09-16.csv
                          └─▶ D:\Records\流程1.CSV记录\2026-09\img\12_NG.png

② 尺寸 SPC
卡尺.MeasureValue ─▶ CSV记录.宽度   （格式 F3）
卡尺.Deviation ───▶ CSV记录.偏差   （格式 F3）
卡尺.IsOk ────────▶ CSV记录.判定
                   内置列「本轮耗时ms」── 节拍统计

③ 事后出报表 / 同时上报 MES
CSV记录 的账本 ──▶ Excel报表（人看的报表）
             └─▶ 结果上报（MES 看的 JSON）
```

**位置原则**：放在**流程末端**（判定之后）。它是"记"，不是"判"。

## 常见问题

**Q：账本到底落在哪个路径？**
默认目录模板 `D:\Records\{StepName}\{yyyy-MM}\` + 文件名 `{yyyy-MM-dd}.csv`。
其中 `{StepName}` 展开成**流程名.步骤名**（编译时由引擎赋，如 `流程1.CSV记录_0`），
所以典型路径是 `D:\Records\流程1.CSV记录_0\2026-09\2026-09-16.csv`，图片在同目录的 `img\` 子文件夹里。

**Q：在面板点「测试写一行」，怎么跑到 `D:\Records\未赋值\` 去了？**
正常现象。「测试写一行」用的是**配置面板里新建的那份配置实例**，此时引擎还没给它命名（`{StepName}` 还没值，回退成"未赋值"）。
它的作用只是让你当场验证**目录能不能建、表头对不对、列宽好不好**；正式跑流程时才会落到 `流程名.步骤名` 目录下。
另：测试行会**占一个序号**，且图片路径列里写的是样例路径（`测试路径\img_N.png`），不是真图。

**Q：Excel 双击打开是乱码？**
本算子写的是 **UTF-8 带 BOM**，正常双击不乱码。如果确实乱码，先确认这个文件是本算子写的（不是别的工具另存过、把 BOM 洗掉了），再看是不是用"数据导入向导"打开——那条路径不认 BOM，要手动选 UTF-8。

**Q：某几列一直是空的？**
按这三条查：① 该列来源=端口 但**没连线**（或上游算子本轮失败，输出端口是空的）；
② 来源=变量 但**变量名打错了**（运行期变量池按名精确匹配，取不到就写空串，**不会报"找不到"**）；
③ 来源=内置 选了「图片路径」但记录方式是"不存图"（没存图时那一格本来就是空串）。

**Q：选了"仅NG存图"，结果一张图都没存？**
两处要对上：`结果列名` 要**逐字等于**那一列的列名（区分大小写）；`NG 判定值` 要等于那列**格式化之后**的文本。
最常见的坑：判定列接的是布尔端口（`IsOk`），写进账本是 `True`/`False`，而 NG 判定值填的是 `NG` —— 永远不相等，一张都不存。
两种改法：把判定列的格式改成文本（上游输出 `OK`/`NG` 的端口），或把 NG 判定值改成 `False`。

**Q：日志提示"目标被占用，N 行已改写入旁路"？**
有人用 Excel **独占打开**着当天的账本。关掉它，然后把 `2026-09-16_conflict1.csv` 的内容（除表头）粘回主账本即可。
旁路是"宁旁路不丢账"的兜底，不是错误——但要看一眼里面到底是哪几行。

**Q：序号从 1 重来了 / 图片撞名了？**
看日志有没有"序列号边车 … 无法写入"。边车 `DataRecord_seq.json` 落在**程序目录**，没有写权限就落不了盘，重启后序号从头开始。
处理：给程序目录写权限，或把记录目录换到大盘（序号本身仍在内存里连续，只是重启后回绕）。

**Q：会影响产线节拍吗？**
默认几乎不会——流程线程只做"取值 + 格式化 + 入队"（微秒级）。如果磁盘很慢或被长期占用，队列（20 万行）会满，
此时按「写入失败阻断流程」的勾选决定：勾着（默认）= 本步骤失败并报"写入队列已满"，不勾 = 丢该行只留 WARN。

**Q：想要旧的账本自动删掉？**
填「保留天数」。填 `0` 表示**永不清理**（这是刻意默认，追溯数据不能由软件悄悄删）。
注意清理只认"文件名里带日期"的 csv，手写名字没日期的文件不会被删。
