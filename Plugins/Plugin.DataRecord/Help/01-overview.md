# CSV记录 · 定位与快速上手

> 分类：数据处理 ｜ 来源：插件 Plugin.DataRecord

流程每跑一次，就往账本 CSV 里**追加一行**；需要留证时，顺手把当件图片按判定结果存到本地。
工具箱里的实名是 **「CSV记录」**（不是"数据记录"），分组成员是 **数据处理**，图标是数据库形状。
产出是一份 **UTF-8 带 BOM 的 CSV**（Excel 双击打开不乱码）。检测类算子负责"判"，本算子负责"记"——
它是追溯链（SPC、质量分析、客户审计）的数据源头。

## 用它还是用别的

| 需求 | 该用谁 |
| --- | --- |
| 每件的判定和各路数值要留底，事后用 Excel 看 | 本算子「CSV记录」 |
| 每件结果要按 JSON 发给 MES 或群机器人 | 「结果上报」 |
| 要生成多工作表、带样式的正式报表 | 「Excel报表」 |
| 只想在画布上看图，不需要留底 | 「结果显示」 |

## 五步上手

1. **放到流程末端**（判定之后）。它是"记"，不是"判"。
2. **确认账本落点**：卡片①「记录目录」默认 `D:\Records\{StepName}\{yyyy-MM}\`，「文件名」默认 `{yyyy-MM-dd}.csv`，
   即每月一个目录、每天一个文件；`{StepName}` 展开成 **流程名.步骤名**（如 `流程1.CSV记录_0`）。
3. **搭列**：卡片②出厂三列 `时间`（内置）、`序号`（内置）、`结果`（端口，要自己连线）。
   点「+ 添加列」加数值列，来源选 `端口` 后**列名就是输入端口名**，回画布把上游输出连上；
   数值列想要两位三位小数，就在「格式」里填 `F2` / `F3`。
4. **（可选）留证图**：卡片③「记录方式」选 `仅NG存图`，把上游图连到**面板内的**「图片源」连接器；
   再加一列 来源=内置、内置项=`图片路径`，列名填 `图片路径`，「Excel报表」开箱就能点图。
5. **当场验一次**：卡片④点「测试写一行」，看目录建不建得出、表头齐不齐、列宽好不好；
   然后跑一轮真流程，用资源管理器确认账本落在 `流程名.步骤名` 目录下。

## 六条口径先记住

- **只追加、绝不覆盖**：目录不存在自动创建；没有"覆盖旧账"这个开关。
- **写盘不占节拍（不勾阻断时）**：流程线程只做"取值 + 格式化 + 入队"（微秒级），磁盘 IO 全交给后台写线程（500ms 攒一批）。勾着「写入失败阻断流程」（默认）时会额外**有界等待本拍落盘**（队列空闲时约 20 毫秒，上限 2 秒）——这是"宁停线不丢账"的代价。
- **宁停线不丢账**：入队被拒或**异步写盘失败**时，「写入失败阻断流程」默认**勾选**，本步骤直接失败；不想要就取消勾选（错误只进日志）。
- **名字类行只能手填**：`变量名`、`结果列`、命名模板里的 `{列名}` 要的是**名字**不是值，界面给的是文本框；填错**静默写空**，不报"找不到"。
- **图片不进 CSV**：账本里只有路径文本；存图失败也不回改已写出的账本行。
- **序号是全局的**：跨步骤实例、跨重启连续，所以看到跳号别以为丢行。

## 三个高频疑问

**Q：配置面板里的下拉是中文，为什么方案文件（`.vms`）里存的是英文？**
`.vms` 存的就是枚举成员本名（`Port` / `BuiltIn` / `Timestamp` / `OnlyNG` 这一类），这是全仓统一的存盘口径，
面板显示中文靠的是插件内的显示字典。目前 `ColumnSource`、`BuiltInField`、`ImageSaveMode` 三个枚举**还没补
`[Display(Name)]` 特性**，所以只有在本插件面板里是中文；哪天某个界面不走这个插件直接渲染枚举，就会回落成英文。
**不要据此以为已经补好了**——这一笔欠账在 AGENTS.md 的枚举显示名清单里挂着。

**Q：点「测试写一行」，文件跑到 `D:\Records\未赋值\` 去了？**
正常。测试用的是配置面板里那份配置实例，引擎还没给它命名，`{StepName}` 回退成"未赋值"。
测试行会**占一个序号**，且图片路径列写的是样例路径，不是真图。

**Q：会拖产线节拍吗？**
不勾「写入失败阻断流程」时几乎不会（流程线程只入队）。勾着（默认）时每拍会等本拍真正落盘：
队列空闲时约 20 毫秒，磁盘慢或文件被占用时最长等到 2 秒后判失败——这是"宁停线不丢账"的代价。
真正会出问题的场景是磁盘过慢或当天文件被 Excel 长期独占，见 04 的容量表。
