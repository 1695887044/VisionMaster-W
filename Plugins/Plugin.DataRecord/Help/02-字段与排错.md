# CSV记录 · 字段与排错

本页专管三件事：**数据落在哪里**、**字段口径对不对**、**会不会丢数**。
所有数值与判据都取自插件源码与开发文档，与界面行为一致。

## 一、落盘位置速查

| 东西 | 落在哪 | 备注 |
| --- | --- | --- |
| 账本 CSV | `记录目录模板` + `文件名模板`，默认 `D:\Records\{StepName}\{yyyy-MM}\{yyyy-MM-dd}.csv` | 目录不存在自动创建；跨月自动建新目录 |
| `{StepName}` 展开成什么 | **`流程名.步骤名`**（如 `流程1.CSV记录_0`） | 由流程编译器在编译时注入；配置面板里"测试写一行"时还没注入，会写成 `未赋值` |
| NG/每件图片 | `记录目录\{ImageDirName}\{图片命名模板}.{ImageFormat}`，默认 `…\img\12_NG.png` | 图片路径是**绝对路径**（`Path.GetFullPath` 拼出来的） |
| 旁路文件 | 主账本同目录，`2026-09-16_conflict1.csv`（占不到就顺延 `_conflict2` … 最多 99） | 只在目标被独占、重试 3 次仍失败时出现 |
| 序号边车 | **程序目录**（宿主 exe 所在目录，不是插件 DLL 所在的 `Modules\`）下的 `DataRecord_seq.json` | 不在记录目录里；换盘、挪目录都不影响它 |
| 日期占位符 | `{yyyy}` `{yyyy-MM}` `{yyyy-MM-dd}` `{MM}` `{dd}`（还有 `{yyyy-MM-dd HH-mm-ss}`） | 长 token **优先替换**，`{yyyy-MM-dd}` 不会被 `{yyyy}` 截胡；日期一律不变区域性 |

**轮转口径**：滚动靠"目录按月 + 文件按天"，**没有**行数上限、**没有**单文件大小上限、**没有**覆盖开关（永远追加）。
要按小时分文件，把文件名模板写成 `{yyyy-MM-dd HH-mm-ss}.csv`——注意这个模板带时间戳，
同一批里的行取的是**各行自己的时刻**，可能出现一批跨多个文件（后台写线程按"目标→日期→行"两级分组，跨天批次也能各归各账）。

## 二、字段口径（列名 ↔ 算子输出）

| 列的来源 | 值从哪来 | 口径要点 |
| --- | --- | --- |
| `端口` | 列名同名端口的当前值（上游连线或端口里的常量） | **列名 = 端口名**，改名等于改端口；连线锚在端口上，改列名要重连 |
| `变量` | 本轮运行期变量池 `context.LocalVariables` 里按名取 | 作用域是**本轮流程执行**（每轮新建上下文），跨轮不保留；这是「变量定义 / 变量赋值 / 脚本 SetVar」写的那个池，**不是「变量管理」里的全局变量** |
| `内置:时间戳` | 本行被记录的时刻 | 默认 `yyyy-MM-dd HH:mm:ss.fff`；该列的「格式」可改 |
| `内置:序列号` | 全局单调自增号 | 跨步骤实例、跨重启连续（靠边车）；账本没序号列且图片名不含 `{序号}` 时**不取号** |
| `内置:步骤名` | 该步骤实例名 | 同上 = `流程名.步骤名` |
| `内置:本轮耗时ms` | `本行时刻 − 本轮流程开始时刻`，保留 1 位小数 | 是**到本步骤为止**的整轮耗时，不是本步骤自身耗时；放在流程末端才有意义 |
| `内置:图片路径` | 本件图片的绝对路径 | 只有"真存了图"或"上游给的是路径字符串"时才有值；不存图时是**空串** |

**数值与单位**：本算子**不换算、不改数**——上游给像素就是像素、给毫米就是毫米，「格式」只做截位（`F3`），
量纲换算请在产出它的算子里做（接标定变换或设像素当量）。角度单位跟随上游（本仓约定：度）。

**文本值解析**：账本只写文本，不做反向解析。若你把变量/端口的值当名字用（列名、变量名），
名字类行是**手填文本**，填错静默写空——这是本仓"名字与值必须分家"纪律的体现，不要试图给这些行挂连线。

**图片存不存**：CSV 里**永远只有路径文本**，不含图片二进制。要看图就用「Excel报表」把那列变成可点击的超链接
（默认认的列名是 `图片路径`——**列名要和它逐字一致**，或者去 Excel 报表里改「图片走这里」）。

**表头与列序**：
- 表头只在**文件不存在或文件长度为 0** 时写一次，追加批次绝不重复写；
- 每行的字段数 = 当前启用的列数。**中途改列定义（加列/删列/停用/调序）不会改已存在文件的结构**，
  同一个文件里会出现长短不齐的行、列序也可能和表头对不上。
  规范做法：改列定义后把旧文件改名归档（或等第二天新文件），不要指望软件帮你补表头。

## 三、容量、时序与"丢不丢数"

| 项目 | 数值 | 触发后果 |
| --- | --- | --- |
| 数据队列容量 | **200 000 行** | 满 → 该行被拒（非阻塞，不拖节拍）；勾了阻断则本步骤失败 |
| 图片队列容量 | **2 000 张** | 满 → **放弃存图**（WARN），账本里的路径已经写出，需要人工补账 |
| 攒批窗口 | 500 ms，单批最多 5 000 行 | 磁盘慢时批与批之间排队，最终表现为队列满 |
| 被占用重试 | 3 次，退避 120 / 240 / 360 ms | 仍失败 → 写旁路 `_conflictN.csv` + WARN |
| 磁盘水位 | 每 60 秒抽查一次盘符，剩余 < **500 MB** | 打 ERROR（不阻断写入，只是预警） |
| 序号落盘 | 每前进 50 号写一次边车；退出/关停强刷 | 边车写不了 → WARN 一次 → 重启后序号从 0 重来 |
| 进程退出冲刷 | 预算 **3 秒**，之后放弃不死等 | 极端情况（磁盘卡死）可能留下未写出的行——要"一行都不许丢"就勾 `FlushEveryRow` |
| 中枢日志暂存 | 最多 2 000 条，超出丢最旧 | 日志在下一次执行该步骤时转交宿主日志（静态中枢拿不到上下文，只能这样投递） |

**"宁停线不丢账"**：`BlockOnFailure` 默认**开启**。理由是追溯数据丢失比停一次线更贵。
不想要这个行为就取消勾选（取消后写入被拒只写 WARN，本步骤仍然算成功）。
注意：这条只管"入队被拒"，不管"某一格是空值"——空值一律照记。

**并发**：本插件标注为并行安全（`[ParallelSafe]`）——多个流程/分支同时在记时，
入队是线程安全的、后台只有一条 CSV 写线程串行落盘，所以**行与行不会交织成半行**。

## 四、现场排障：现象 → 查哪一项

| 现象 / 日志原文 | 先查这里 |
| --- | --- |
| `CSV记录：未配置任何启用的列` | 列全被取消勾选了（或列名为空白）。至少留一列 |
| `CSV记录：写入队列已满，记录被拒（检查磁盘/文件占用）` | 队列 20 万行满。① 记录目录是否在慢盘/网络盘上；② 当天文件是否被 Excel 长期独占；③ 磁盘是否快满 |
| `CSV记录：记录中枢正在关停，不再接收` | 进程正在退出，属正常收尾（3 秒冲刷预算之后的行为） |
| `[数据记录] 目标被占用，N 行已改写入旁路 …` | 有人用 Excel 打开了主账本。关掉，再把 `_conflict1.csv` 粘回来 |
| `[数据记录] 磁盘 X:\ 剩余 … MB，低于 500MB 水位——请立即清理或更换记录目录！` | 清盘或把 `记录目录模板` 换到大盘 |
| `[数据记录] 序列号边车 … 无法写入 …重启后序号将从 0 重来，图片可能撞名` | 程序目录没有写权限（装在 `C:\Program Files` 下常见）。用管理员授权，或把程序放免权限目录 |
| `[数据记录] 存图失败（账本路径已写出，需人工留意）` | 图片落盘失败但账本已有路径。查磁盘、查命名模板展开后是否含非法字符（非法字符会被换成 `_`，但整条路径过长也会失败） |
| `[数据记录] 保留期清理（N 天）：已删除 X 个过期文件` | 正常。确认 `KeepDays` 是不是被误填（`0` 才是永不清理） |
| 账本某列一直是空 | 见「常见问题」三条：没连线 / 变量名打错 / 上游本轮失败 |
| 账本日期列变成 `2026/9/16`（想要 `2026-09-16`） | 在该列「格式」填 `yyyy-MM-dd`（留空时时间戳列用默认的 `yyyy-MM-dd HH:mm:ss.fff`） |
| Excel 里数值列变成日期/文本 | Excel 自己的猜测，不是账本问题。导入时把该列指定为"常规"，或在列名后加单位（如 `宽度mm`）避开自动类型推断 |
| 序号跳号 | 序号是**全局**的：别的「CSV记录」步骤、以及"测试写一行"都会占号。不是丢行 |
| 图片文件名撞车 | 序号回绕（见上面的边车）或命名模板里没放 `{序号}`。模板改成 `{序号}_{结果}` |
| 跨月/跨年没建新目录 | 检查 `记录目录模板` 里有没有 `{yyyy-MM}`；写死月份的路径自然不会自动建 |

## 五、上线前自检清单

1. 「测试写一行」跑过，目录能建、表头齐、列宽合适（注意它落在 `未赋值` 目录下）；
2. 跑一轮真流程，用资源管理器确认账本落在 `D:\Records\流程名.步骤名\年-月\日期.csv`；
3. 判定列的值和 `NG 判定值` 对得上（布尔列 `True/False` ≠ `NG`）；
4. 需要留证就加一列 `内置:图片路径`，**列名填 `图片路径`**（这样「Excel报表」开箱就能点）；
5. 决定 `KeepDays`（产线一般填 90/180，需要长期追溯就填 `0` 并配磁盘水位监控）；
6. `BlockOnFailure` 与班长确认口径：宁停线不丢账（默认开）还是绝不停线（关）；
7. 程序目录有写权限（序号边车），记录盘剩余空间有监控或定期清理。
