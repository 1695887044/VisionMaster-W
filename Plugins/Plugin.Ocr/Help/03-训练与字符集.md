# OCR 文本识别 · 训练与字符集

> 分类：图像处理 ｜ 来源：插件 Plugin.Ocr

先记住那条主干认知：**切字（分割）占成败的九成，认字只是一行调用**——所以排错也先从分割查起，别一上来就怀疑模型。

## 一、模型从哪来

OCR 认哪些字符，**完全由模型文件（`.omc`）决定**，界面上没有"字符集""只允许数字"这类约束项。

- **内置模型**：`Industrial_0-9A-Z_Rej`（约 208 KB，随插件一起投递），字符集只有**数字 0-9 与大写字母 A-Z**，并带"拒识"能力——认不出的区域它不乱填，而是留一个"什么都没有"的占位，插件把它显示成 `?`。
- **HALCON 自带的其它预训练模型**：仓库里有若干现成 `.omc`（如不同字符集/语言包），把 `ModelPath` 指过去即可换字符集，无需自己训练。
- **自己训练的模型**：当现场要认中文、小写、带冒号/斜杠/空格、或特殊字体时，内置模型覆盖不了，就得**在 HALCON 侧离线训练**一个匹配的 `.omc`（`create_ocr_class_mlp`），再用 `ModelPath` 指过来。

> **本插件自身不训练、只读取模型**（`read_ocr_class_mlp`）。训练是插件之外的独立工序：在 HDevelop 里用切好的字符样本生成 `.omc`，产出后放回现场、填进 `ModelPath`。

模型的查找顺序（留空 `ModelPath` 时）：**程序目录 `\Assets\ocr` → `%HALCONROOT%\ocr` → 交 HALCON 按短名兜底**。
一旦 `ModelPath` 显式填了却指向不存在的文件，插件**直接报错**、不静默退回内置——否则会伪装成"这 OCR 连中文都认不出"，把真因（路径写错）藏起来。

## 二、字符集与语言

- **内置只认 0-9 与 A-Z**：`:` `/` 空格、中文、小写字母都会被判为拒识（`Detail` 里显示 `?`）。
- **大小写**：内置模型只输出大写；要区分大小写就得换/训练对应字符集的模型。
- **中文**：必须用含中文类的模型（自带或自训练），并保证**训练样本的字体与现场一致**。
- 界面把开关显示成中文勾选框（暗字亮底 / 固定阈值 / 竖排），而流程 `.vms` 里存的是对应布尔成员名——手册里讲的参数名就是成员名，不用手打进界面。

## 三、训练样本怎么采集与预处理

自训练最容易栽在"**训练时字的样子**和**现场跑时字的样子**不一致"（域漂移）。三条铁律：

1. **训练与现场用同一套分割口径**——阈值、字符尺寸范围、形态学半径都要一致。切样本用什么参数，上线就用什么参数，否则喂给分类器的字形分布对不上，识别率自然崩。
2. **尺寸要归一**——分类器对字符区域大小敏感；同类字符应落到相近的归一化尺寸。若相机视野/工件距离会变，先在上游做定位+缩放（接模板匹配的 `AlignedImage`），让字符在图里大小稳定，再训练、再上线。
3. **点阵 / 喷印字先焊合再切样本**——由散点拼成的字，直接连通会碎成一地小点；**先用闭运算（`ClosingRadius` 从 1.5~2 起）把点连成笔画**，再切、再标注。训练样本和现场都要经过同一道焊合，字形宽度才对得上。

采集建议：从**现场真实图**切字，逐字符标注类别；每种字体、每个易混字符（0/O、1/I、8/B）都要有足够的样本量。

## 五、置信度与"宁缺勿错"的分流

- **两条 Warn 是硬机制**：出现拒识字、或平均置信度 < 0.9 时，日志主动告警。这不是判 NG，只是提醒"本次结果别直接拿去放行"。
- **分流做法**：在下游把结果分三路——
  - `Text` 比对通过 **且** `Confidence` 高于自定阈值 → 正常放行；
  - `Detail` 里有 `?`（有拒识）**或** `Confidence` 偏低 → 转人工复判 / 重新拍照，别盲信；
  - 本步失败（没图 / 切不出字符）→ 按流程失败处理。
- **0/O、1/I 这类形近混淆**：插件不做受约束重打分，靠下游"期望值比对"来兜——已知料号格式时，拿 `Text` 和期望串比，不符即转人工。

## 六、结果怎么读（没有字符框时）

本插件不输出标注图，排错全靠这三个输出：
- `Detail`：`1:1(0.99) 2:?(0.72) …` —— 逐位告诉你第几个字认成什么、把握多大，`?` 就是这一位没认出来；定位到"哪一位崩了"，再回第四节查对应的分割参数。
- `Count`：切出的字符总数（含拒识）。跟期望字数一比，多了就是切进了假区域（收紧尺寸/面积档或焊合过度），少了就是字被切断或没框全。
- `Confidence`：整串平均把握。配 0.9 告警线看趋势——突然走低通常是光照、极性、字体或识别区变了。
