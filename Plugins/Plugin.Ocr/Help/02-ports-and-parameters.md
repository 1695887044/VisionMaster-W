# OCR 文本识别 · 端口与参数

> 分类：图像处理 ｜ 来源：插件 Plugin.Ocr

## 输入端口

| 端口 | 必填 | 说明 |
| --- | --- | --- |
| `Image` | 否（端口层标记非必填） | 待识别的图像（`HImage`）。运行期由上游连入；**没有图会直接失败**，报"上游没有图像"。彩色图也允许直接连进来，内部会自动转灰度 |

## 输出端口

| 端口 | 类型 | 说明 |
| --- | --- | --- |
| `Text` | `string` | 逐字符拼出的识别文本。**拒识位在串里是 U+001A（SUB 控制符），界面上看不见**——不是空格、也不是 `?`。要"可显示文本"请用 `Detail`，或在下游按 U+001A 自行替换 |
| `Count` | `int` | 字符数（**含**被拒识的字符），= `Classes.Length` |
| `Confidence` | `double` | 平均置信度（0~1），各位字符置信度的算术平均。低置信 = 本次结果不可信 |
| `Detail` | `string` | 逐字符明细，格式 `序号:字符(置信度)`，用空格分隔；**被拒识的字符显示为 `?`** |
| `Classes` | `string[]` | 逐字符**原始类别名**，与 `Confidences` / `CharBoxes` **逐项对齐**，顺序 = 阅读顺序（横排时列坐标递增）。拒识字符**保留原始 U+001A**，不替换成 `?`——下游要判"这一位没认出来"，看它是不是 U+001A 即可 |
| `Confidences` | `HTuple`（double） | 逐字符置信度 0~1，长度 = `Count`，下标与 `Classes` 一一对应 |
| `RejectedCount` | `int` | 拒识字符数，= `Classes` 里 U+001A 的个数。**不含**判定语义（它只说明"有几个字没认出来"，不是 NG 原因） |
| `CharBoxes` | `HTuple`（double） | 逐字符外接框，**扁平 stride 4**：`[row1,col1,width,height, row2,col2,...]`。轴对齐最小外接矩形（`smallest_rectangle1`），坐标是**图像绝对坐标**；宽高按像素**含端点**（`col2-col1+1`），所以单像素宽的字也是 1 而不是 0。长度 = `Count × 4`，第 i 组对应 `Classes[i]` |

> **逐字符三件套的契约**：`Classes[i]` / `Confidences[i]` / `CharBoxes[i*4 .. i*4+3]` 讲的是同一个字符，顺序都是阅读顺序（由 `ColumnFirst` 决定按行还是按列）。下游可以按位拼判定条件（第 3 位必须是 `B`、字间距超限即报警），不必再解析 `Detail` 的字符串。
>
> **0 字符时**：`Classes` 是空数组、`Confidences` / `CharBoxes` 是空元组（长度 0），`RejectedCount` = 0，识别层不会因此报错。注意当前分割层"一个区域都没切出来"是**整体失败**（报三档筛选原因，端口保持清零后的空值）——所以运行期看到 `Count` = 0 通常伴随本步失败，而不是"成功但没字"。
>
> **失败轮不留残值**：每轮开头八个输出端口全部清零（`Text` 空串 / `Count` 0 / `Confidence` 0 / `Detail` 空串 / `Classes` 空数组 / `Confidences`、`CharBoxes` 空元组 / `RejectedCount` 0），下游不会读到上一轮的旧数据。
>
> 本插件**不输出标注图 / 字符框图像**（未做位置投射）：框只以数据形式给在 `CharBoxes` 里。要在图上看见切分效果，用上游「创建 ROI / 裁剪」把整行裁出来，再在配置界面点「试算」。

## 关键参数

> 完整参数与取值范围以流程中该步骤的「模块参数」界面为准，这里只解释含义。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `RoiParams` | 空 | 识别区形状，按 HALCON 矩形约定 `[中心行, 中心列, 角度(弧度), 半长, 半宽]`。在配置界面的图上右键 → 新建矩形即可回写，不建议手填。角度非 0 就是给歪着的字行用的 |
| `TextIsDark` | `true` | 极性：`true` = 暗字亮底（工业最常见的打码方式），`false` = 亮字暗底。**选反了一个字都切不出来** |
| `MinCharHeight` | `8` | 字符最小高度（像素）。按实际字符尺寸收紧，能挡掉背景纹理与脏点 |
| `MaxCharHeight` | `300` | 字符最大高度（像素） |
| `MinCharWidth` | `4` | 字符最小宽度（像素） |
| `MaxCharWidth` | `300` | 字符最大宽度（像素） |
| `UseFixedThreshold` | `false` | `false` = 自动阈值（按直方图双峰找分界），`true` = 用下面的固定阈值。光照均匀时自动即可，光照不匀时再切固定 |
| `FixedThreshold` | `128` | 固定阈值：暗字时取灰度 ≤ 本值，亮字时取 ≥ 本值。仅在 `UseFixedThreshold = true` 时生效 |
| `MinArea` | `20` | 字符最小面积（像素²），三档筛选的最后一道 |
| `MaxArea` | `5000` | 字符最大面积（像素²） |
| `ClosingRadius` | `0` | 闭运算半径（像素）——**点阵 / 喷印字焊合散点的首选**。先扩后缩，点连上了、字形尺寸基本还原。实心印刷字留 0；点阵喷印从 1.5 起试 |
| `ErosionRadius` | `0` | 腐蚀半径（像素）：印刷字粘连时先腐蚀断开 |
| `DilationRadius` | `0` | 膨胀半径（像素）：笔画过细时加粗。**注意它会外扩字形**，点阵字要的是"连接"不是"加粗"，请优先用 `ClosingRadius` |
| `ModelPath` | 空 | 外部模型文件（`.omc`）路径。**留空 = 用内置模型（0-9 / A-Z，带拒识）**；填了就改用指定模型（如中文 / 自训练模型） |
| `ColumnFirst` | `false` | `true` = 按列优先排序（竖排文本），`false` = 按行优先（横排，默认） |

> 界面上的开关（暗字亮底 / 固定阈值 / 竖排）是勾选框，`.vms` 流程里存的是对应布尔成员名；这里给的是参数含义，不是要手打的文本。

## 口径与失败策略

- **不判 OK/NG**：本插件只报"认到了什么"，合格与否由下游比较节点 / 脚本决定（与颜色检查同一规矩）。
- **拿不到输入图 → 失败**：上游没连图或图为空，本步报失败"上游没有图像"。
- **切不出字符 → 失败并指明该放宽哪一档**：报错里会把三档筛选逐级写出来（连通域 N 个 → 过高/过宽/过面积各剩几个），据此就知道该调极性以及调尺寸范围。
- **没框识别区 → 失败**，提示去配置界面右键新建矩形。
- **认不准 ≠ 流程失败**：只要跑出了结果，本步仍算成功；但插件有两条 **Warn 诚实机制**：出现拒识字、或平均置信度低于 0.9 时主动写告警。因为 OCR 最危险的失败不是"认错"，而是"给出一串看着正常的错字符却毫无提示"——那会被下游当成功直接放行。
- **0.9 是常量、不是配置项**：它只决定"要不要提醒"，不参与判定。
- **字符集只由模型文件决定**：内置模型只含 0-9 与 A-Z，冒号 `:`、斜杠 `/`、空格一律会被判为拒识；界面没有"只允许数字"这类正则约束（格式校验归下游）。
