# 深度学习异常检测 · 快速上手

> 分类：图像处理 ｜ 来源：插件 Plugin.DlAnomaly

把一张图送进 **ONNX 异常检测模型**，输出"**这张图有多异常（分数）**"以及（模型支持时）"**异常在哪个位置（热力图）**"。

工业上最大的用途是**新机种刚上线、不良品一张都没有**的那些天：良品照片有成千上万，划痕、缺胶、异物、装配不到位却还没攒出样本。分类要求每一类都有样本，这类场景做不到；传统算子又说不清规则——异常检测只学良品，把"不像良品"的判成异常。

## 为什么需要它

| 想解决的问题 | 该用哪个 |
| --- | --- |
| 有明确灰度/面积/形状规则 | Blob 缺陷检测 |
| 要把目标框出来、还要位置 | YOLO 目标检测 |
| **每一类都有标注样本，只要整体结论** | 深度学习分类（Plugin.DlClassify） |
| **只有良品样本，或不良品少得可怜** | **深度学习异常检测（本节点）** |
| **要输出逐像素的类别图** | 深度学习分割（Plugin.DlSegment） |

### 推理链路

```
① 取原图尺寸
② 算缩放几何（Letterbox 等比 + 居中补 114 灰　或　Stretch 直接拉成方形）
③ 构造输入画布（非 byte 图先转 byte；单通道自动补成 3 通道）
④ 转 NCHW float 张量（直接取底层缓冲整块拷贝，像素 /255 归一到 0~1）
⑤ ONNX Runtime 推理（CPU、单线程）
⑥ 按秩识别输出契约：秩 2 的 [1,1] = 图像级分数；秩 4 的 [1,1,H,W] 或秩 3 的 [1,H,W] = 热力图
⑦ 热力图求最大/均值/峰值位置，并按上限归一化成 0~255 的图
```

### 一轮检测产出什么

```
Score              double   图像级异常分数（越大越异常；模型不给分数时为 NaN）
HasScore           bool     分数是否由模型直接给出（false = 从热力图归约而来）
HeatmapMaxValue    double   热力图最大值（无热力图时为 NaN）
HeatmapMaxRow      double   最大值所在行（无热力图时为 -1）
HeatmapMaxCol      double   最大值所在列（无热力图时为 -1）
HeatmapImage       HImage   热力图渲染图（单通道 0~255；无热力图为空）
Summary            string   一句话摘要（可直接喂给「结果显示」或日志）
```

### 三个"做错了不报错、只是结果静默变差"的点

| 环节 | 口径 | 做错的表现 |
| --- | --- | --- |
| **缩放模式要与训练一致** | 默认 `Letterbox`（等比补边，不破坏长宽比）；部分自训练/老导出用 `Stretch`（拉成方形） | 选错 = **分数静默偏移**：不报错、不崩溃，只是分数系统性偏高/偏低，阈值不再适用 |
| **补边灰度 = 114** | 训练时的默认填充值 | 填黑边会引入模型没见过的强边缘，异常分数整体抬高 |
| **归一化 /255** | 训练时像素归一到 0~1 | 少除/多除模型照样跑，只是精度静默劣化 |

### 输出契约不猜：形状不认识就明确拒绝

异常检测的 ONNX 输出**没有统一标准**：有只给一个图像级分数的，有分数 + 热力图两份输出的，还有只给热力图要调用方自己归约的。硬编码一种格式 = 对用户的真实模型无效却不报错。所以本节点**按秩识别**：

| 输出张量形状 | 判为 | 说明 |
| --- | --- | --- |
| 秩 2 且 `dims[1] == 1`，如 `[1,1]` | 图像级分数 | 取值 `[0]` 作为分数 |
| 秩 4 且 `dims[0]==1 && dims[1]==1`，如 `[1,1,64,64]` | 热力图 | H/W 取 `dims[2]`、`dims[3]` |
| 秩 3 且 `dims[0]==1`，如 `[1,64,64]` | 热力图 | H/W 取 `dims[1]`、`dims[2]` |
| 其它（如 `[1,1,1,64,64]`、`[1,84,8400]`） | **拒绝** | 模型卡上显示读到的真实形状，错误信息写明"不会替你猜" |

## 五步跑通

1. **画布上放一个「深度学习异常检测」节点**（工具箱 → 图像处理）。
2. **接图**：把上游「图像采集」或「读图」的输出连到本节点的 `Image` 端口。本节点检测**整幅图**，不吃 ROI；要只看某个区域，请上游先用「创建ROI」裁好。
3. **选模型**：点「浏览」选一个 `.onnx` 异常检测模型。选完立刻解析，卡片上会显示输入尺寸、输出契约（有没有分数、热力图多大）——**看到"拒绝"字样就是模型形状不符合上表**，换模型或先检查导出。
4. **看试算**：点「试算一下」用上游图跑一遍（与运行期共用同一段代码，不会"界面看着对、跑起来不对"），结果卡里出现分数与热力图摘要即为通。
5. **设阈值**（在**下游**做）：本节点不给 OK/NG。把 `Score` 接到「结果比较」或「判断」节点，按你现场的良品分布定阈值——见「差分口径与调参」一页的定阈法。

## 不做的事（边界）

- **不判定**：只出分数与热力图，OK/NG 归下游。与分类/YOLO/颜色检测同一规矩。
- **不内置模型**：模型是客户资产，路径找不到就明确报错，绝不静默退回任何默认模型。
- **不训练**：本节点只做推理，训练在外部完成（Anomalib / PatchCore / DRAEM / 自研都可以，只要导出 ONNX）。
- **不做逐像素类别图**：那是分割。

## 常见误用

| 误用 | 后果 | 正解 |
| --- | --- | --- |
| 把「分越高越异常」当成本节点保证 | 有的模型输出的是"相似度"，越大越像良品 | 看「模型卡」与训练侧文档确认方向；不确定就先拿良品与不良各跑几张对数 |
| 拿分类模型当异常模型 | 输出形状通常被拒（好）；侥幸接受时分数毫无意义 | 模型卡显示 `task` 不是 anomaly 时换模型 |
| 上游先缩放再送进来 | 双重缩放，精度静默劣化 | 送原始分辨率的图，缩放交给本节点 |
| 热点位置直接当缺陷坐标用 | 热力图分辨率通常远低于原图 | 用 `HeatmapMaxRow/Col` 估区域，再用「创建ROI」+ 卡尺/Blob 精定位 |
