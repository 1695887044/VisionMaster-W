# 几何查找 · 端口与参数

> 分类：几何工具 ｜ 来源：插件 Plugin.GeometryFinder

本页是**逐项口径表**：每个端口是什么类型、必填与否、默认值多少、调大调小各会发生什么。
概念与接线见「快速上手」，出问题见「排错与常见问题」。

## 输入端口

| 端口 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `SrcImage` | `HImage` | 是 | 待查找图像。为空或未初始化直接失败：`几何查找：未接入图像（SrcImage 为空）` |
| `MaskRegion` | `HRegion` | 否 | 查找区域：接「ROI」算子的 `MaskRegion`（合并有效区域）。只在区域内找，**未接 = 整图**；坐标不因它改变 |
| `Kind` | `GeometryFindKind` | 是 | 查找类型：直线 / 圆 / 椭圆（默认**直线**）。界面显示中文，流程文件里存的是它的数值（如 `1` = 圆） |
| `Sigma` | `double` | 否 | 边缘提取的平滑量（默认 1.0）。越大越抗噪，但边会发"糊"、定位变钝 |
| `LowThreshold` | `double` | 否 | 边缘低阈值（默认 20）。低于它的对比度直接不算边 |
| `HighThreshold` | `double` | 否 | 边缘高阈值（默认 40）。强弱分界：只有强于它的才算"确定的边" |
| `MinContourLength` | `double` | 否 | 参与候选的轮廓长度下限，像素（默认 30）。短于它的轮廓一律不参与"取最长" |
| `FitAlgorithm` | `FitAlgorithmKind` | 否 | 拟合鲁棒算法（默认 **Tukey 抗离群（推荐）**）：最小二乘 / Huber 抗离群 / Tukey 抗离群。**只对直线、圆生效** |
| `FailOnNotFound` | `bool` | 否 | 找不到是否判本步骤失败（默认**是**）。设为否 → 步骤算成功，只把 `IsFound` 置 false |
| `DisplayViewIndex` | `int` | 否 | 显示窗口：`0` = 不显示，`1~9` = 主界面第几个图像窗口（默认 1，填大于 9 按 9 处理） |
| `Success` / `ErrorMessage` | `bool` / `string` | — | 基类自带：本步骤是否跑通、失败时的中文原因 |

> 「必填」= 端口自己声明的 `IsRequired`：既没连线、步骤数据里又没有常量值时，编译报 `[参数缺失] '<端口>' 未配置`。
> 打开一次「模块参数」点确定，默认值就存成常量，之后不连线也能跑。

本插件**没有自定义配置界面**，也没有 `[StepConfig]` 常量：所有参数都在上面这张端口表里。
所以"参数"和"连线"是同一张表——数值想让它跟着上游走就点 🔗，想固定就直接在框里填。

## 输出端口

| 端口 | 类型 | 说明 |
| --- | --- | --- |
| `Geometry` | `GeometryParam` | **主输出**：类型化几何基元。类型由 `Kind` 决定，可直接喂给「几何计算」的 `A` / `B` |
| `Contours` | `HXLD` | 参与拟合的**那一条**最长轮廓（XLD）。复核"拟合用的是哪条边"就看它；也能给「结果显示」描边 |
| `IsFound` | `bool` | 本轮是否真的拟合成功（失败轮为 false） |
| `Row` / `Col` | `double` | 基准点：直线 = 拟合线段中点，圆 = 圆心，椭圆 = 中心（像素） |
| `Phi` | `double` | 方向角（**度**，[0,180)）：直线 = 沿线方向，椭圆 = 长轴方向。圆不用这一项，值为 0 |
| `Radius` | `double` | 圆 = 半径，椭圆 = **长半轴**（像素）。直线不用这一项，值为 0 |
| `Annotations` | `List<MeasureAnnotation>` | 本轮投射用的标注列表（拟合出的线/圆/椭圆 + 基准点/文本）。**不烘焙、不开窗**；接「结果显示」的结果项即可烧进最终图，供「图像赋值」写到 SCADA |

**每轮开头清零**：`Geometry` / `IsFound` / `Row` / `Col` / `Phi` / `Radius` / `Annotations` 一律先重置，
`Contours`（非托管）由框架在轮首自动回收。失败轮下游读到的是空值，**不是脏值**。

## 参数怎么调（调大 / 调小各会怎样）

| 参数 | 默认 | 调法与后果 |
| --- | --- | --- |
| `Sigma` | 1.0 | 调大（1.5~3）→ 噪声纹、脏污被抹平，边变粗变"钝"；调小 → 边更锐利，但纹理/毛刺也会各出一条边，"取最长"更容易挑错。**低于 0.4 的值会被按 0.4 兜住** |
| `LowThreshold` | 20 | 调小（10~15）→ 弱对比的边也能出来，同时视野里的纹理也算边；调大 → 只剩明显边，找不到就报"未找到足够长的轮廓"。**低于 1 按 1 处理** |
| `HighThreshold` | 40 | 与低阈值是**滞后对**：高阈值定"确定的边"、低阈值把它们的延伸段捡回来。差距调大 → 边更长更连续（更容易把相邻轮廓串成一条）；差距调小 → 边断成多段、每段都变短。**不足"低阈值 + 1"时会被自动抬到"低 + 1"** |
| `MinContourLength` | 30 | 调大 → 滤掉碎边、杂边（**挑错边时第一根要动的旋钮**）；调小 → 短弧、短段也能进候选，但更容易选中一条噪声。**下限按 1 兜住** |
| `FitAlgorithm` | Tukey | 最小二乘最脆（一个毛刺点就能把线拽歪）；Huber 折中（离群点降权但不清零）；Tukey 最抗离群（离群点近乎不参与拟合）。**先看现场有没有毛刺再决定往哪调**，别一上来就换最小二乘；点数本来就少时鲁棒算法也没有冗余可用 |
| `FailOnNotFound` | true | 计量场景保持 true；探测/遍历场景设 false，配合 `IsFound` 走分支 |
| `DisplayViewIndex` | 1 | `0` 关掉推图（不影响算法与输出端口）；多相机/多窗口时把它对准要看的那一格 |

## 失败口径（三条文案各对应一种处置）

| 文案 | 触发条件 | 处置方向 |
| --- | --- | --- |
| `几何查找：未接入图像（SrcImage 为空）` | `SrcImage` 空 / 未初始化 | 查上游连线；上游本轮失败时它的输出就是空的 |
| `几何查找：未找到足够长的轮廓（长度下限 N px）——请检查 ROI/阈值/Sigma，或放宽长度下限` | 筛完长度后没有候选轮廓 | 先看 `MaskRegion` 有没有罩住目标，再降 `LowThreshold`，最后放宽 `MinContourLength` |
| `几何查找：轮廓存在但拟合 直线/圆/椭圆 失败（点集退化/特征不是该形状）——请检查 ROI 是否套住目标、增大 Sigma 或轮廓长度下限` | 有轮廓但拟合不收敛 | 目标不是这个形状、或弧太短/点太少（圆 ≥ 3、椭圆 ≥ 5 个点） |
| `几何查找：未知查找类型 <Kind>` | `Kind` 落到未定义的成员上 | 正常配置不会出现；出现即说明存盘值被手改坏 |

**找不到时也会推图**（红字"未找到轮廓"，拟合失败推"未拟合到目标"），成功时推**绿色**的拟合线/圆/椭圆 +
结果文字（`φ=` / `r=` / `长×短`）；推的是**源图**，不带区域裁剪。
推图失败只写一条 Warn（`预览发布失败（视图 N），算法结果不受影响`）——**显示层绝不把一次成功的查找判成失败**。
