# 标定 · 端口与参数

> 分类：标定 ｜ 来源：插件 Plugin.Calibration

本页是**照抄界面用的清单**：端口名与类型（连线的名字以此为准）、配置项默认值与取值范围、失败口径。
参数怎么用见「界面与取点编辑」，判读质量见「标定判据与验收」。

## 输入端口（5 个，全部非必填）

| 端口 | 类型 | 界面文案（原样） | 说明 |
| --- | --- | --- | --- |
| `SourceImagePath` | `string` | 标定图路径（配置态取点/预览用；运行期不读盘） | 浏览或链接变量都行。**运行期不读盘**：需要的元信息（图像尺寸）在配置态已记录 |
| `SourceImage` | `HImage` | 实时图（可选）：配置态优先用它做画布底图与取点；运行期不参与计算 | 配置态优先级高于文件路径；图像所有权在上游，本插件不释放 |
| `SourceSerial` | `string` | 上游相机序列号（可选）：接「图像采集」的 SourceSerial；与「相机序列号」不一致则失败 | 两端都非空才校验，比较忽略大小写 |
| `SourcePointRow` | `double?`（可空） | 上游定位点 Row（可选）：接匹配 Row / 圆查找中心行；点行上「预填」填入 | 空 = 未提供（与 0 区分，0 是合法坐标） |
| `SourcePointCol` | `double?`（可空） | 上游定位点 Col（可选）：接匹配 Column / 圆查找中心列；点行上「预填」填入 | 含义同上 |

## 输出端口（4 个 + 基类的 `Success` / `ErrorMessage`）

| 端口 | 类型 | 界面文案（原样） | 说明 |
| --- | --- | --- | --- |
| `Transform` | `CalibrationTransform` | 标定结果（像素 ↔ 毫米/机械坐标的变换） | 下游接「坐标变换」的 `Transform`。失败轮为**空** |
| `MmPerPixel` | `double` | 像素当量（mm/px） | 便利口：直接接给卡尺测量等算子的 `MmPerPixel` 输入 |
| `ResidualRmsPx` | `double` | 标定残差均方根（像素） | 质量主指标，可接「CSV记录」做标定档案 / 漂移报警 |
| `ResidualMaxPx` | `double` | 最大单点残差（像素） | 哪个点没取好，看表格"残差px"列指到哪一行 |

## 配置项（在「模块参数」/配置界面里落盘）

> 完整项与取值范围以流程中该步骤的界面为准，这里是含义与默认值。

| 配置项 | 默认 | 取值范围 / 类型 | 说明 |
| --- | --- | --- | --- |
| `Mode` | `PixelScale`（像素当量） | 四选一：`PixelScale` / `NinePoint` / `Perspective` / `Mesh` | 界面显示中文、流程里存成员名。切换只影响界面与执行分支，**不会清掉另一种模式已填的数据** |
| `GridSize` | 3 | 夹取 2~10（下拉可选 2~10） | 标定表行数 = N²。点数只是采样密度：3×3 覆盖四角+中心是常规规模，4~5 加密抗噪，2（4 点）是最小覆盖 |
| `KnownLengthMm` | 100 | 正数 | 像素当量模式的标定物已知长度（mm）。**填错 = 当量整体缩放错** |
| `ScaleARow` / `ScaleACol` | 空 | 可小数 | A 点坐标。**空 = 未取点，0 是合法坐标**（标定物一端可能正好落在图像边缘） |
| `ScaleBRow` / `ScaleBCol` | 空 | 可小数 | B 点坐标，含义同 A。当量 = 已知长度 ÷ A–B 像素距离 |
| `PointRows` | 空（新步骤自动铺 N×N 行） | 每行 `{机械X, 机械Y, 图像Row, 图像Col, 残差px}` | 九点/透视/网格共用同一张表，JSON 快照随步骤存盘。**整行留空 = 空行**（不参与计算）；**半填 = 报错并指名行名**；旧方案"四值全 0"的行载入时自动还原为空行 |
| `ResidualThresholdPx` | 1.0 | ≥0 | 质量闸门（px）：残差 RMS 超过它判**业务失败**。经验：≤0.2px 很漂亮，0.2~1px 正常 |
| `MmPerPixelMin` / `MmPerPixelMax` | 0.001 / 1.0 | ≥0 | 当量合理性护栏：防"µm 当 mm 填"、防标定物长度量错一个数量级。**填反了对称使用，不报错** |
| `IsCalibrationLocked` | false | 勾选 | 锁定防误改：表格 / 取点 / 粘贴 / 重建 / 清空 / 拖标记都被拒。**只锁输入不锁输出** |
| `CameraSerial` | 空 | 文本 | 这份标定属于哪台相机（与「系统 → 相机设置」的序列号一致）。多相机**必填** |
| `SourceImageWidth` / `SourceImageHeight` | 0 | 自动写入 | **载图时自动记录**并随步骤存盘：下游据此做"换分辨率就失效"的自证 |
| `CalibrationStampUtc` | 空 | 自动维护 | 标定配置的最后改动时间（UTC），按"输入签名"推进——**运行期每轮重算不会把它刷成"刚刚"** |

## 关键口径

- **行名即标记名**：九点/透视/网格的行名是 P1..PN（画布上同名圆标记），像素当量模式的两个标记叫 A / B。
  「残差px」与红色箭头点名的都是行名，回表格找同名行即可。
- **默认铺位**：「把点画到图上」时，空行也会被撒到视野中部 60% 范围内的 N×N 均匀分布点上，
  方便"先把点撒上、再一个个拖到位"。标记半径按图幅比例放大（大图上固定像素半径会看不见）。
- **实时图优先**：画布底图 = 实时图（若有）→ 文件预览。切换底图会**清掉旧标记**（坐标语义已变），
  但图像尺寸记录**只增不清**——它是标定快照的一部分。
- **导出/导入的字段范围**：模式、网格规模、已知长度、A/B 点、标定表、相机序列号、残差阈值与当量护栏、
  标定图尺寸、来源标签、时间戳，能求解时附带质量快照与版本号。**不含**锁定开关、预览图路径、画布状态。
- **格式版本 1**：导入端遇到更高版本直接拒绝（同版本或更低按缺省字段宽容处理，缺省即"未填"）。

## 必填与校验口径

| 情况 | 结果 |
| --- | --- |
| 像素当量：A/B 四个值没取全 | 失败（配置态橙字），提示"请点「取点」在图上各点一下，或直接填表格里的 Row/Col" |
| 九点：有效点 < 3；透视：< 4 | 失败，并报当前组数与表格行数 |
| 网格：表行数 ≠ N²、某行还空着、某行半填 | 失败，指到行名；缺一个节点时报"它周围四格都不可用" |
| 任一行半填（四个值不齐） | 失败，指名行名（0 不会被当成没填） |
| 任一行含 NaN / Inf | 失败，指名行名 |
| 点近似共线 / 全部重合 | 失败，提示把点铺开成 N×N 网格 |
| 残差 RMS > `ResidualThresholdPx` | **失败**（红字，质量数字照常显示），给三查清单 |
| 当量 ≤ 0 或落在护栏外 | 失败，提示先查单位与标定物长度 |
| 上游 `SourceSerial` 与 `CameraSerial` 都非空且不同 | 失败，两个序列号都写进文案（忽略大小写） |
| 任一身份项为空（单相机 / 离线 / 未接线） | **不校验**，零打扰 |
| 网格标定基线残差超阈值 | **不算失败**（网格节点处精确通过，基线只用来判读畸变） |

## 失败策略（一句话版）

**失配必须失败**：上面每一行都是明确失败并写清下一步做什么，绝不"先用着旧矩阵"。
**开轮清零**：`Transform` 置空、三个数值输出置 0（失败轮下游读不到上一轮脏值）。
**无阻塞操作**：没有需要取消的等待，也没有取消分支；同一组输入永远得到同一矩阵（幂等）。
