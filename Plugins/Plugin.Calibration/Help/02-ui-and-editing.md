# 标定 · 界面与取点编辑

> 分类：标定 ｜ 来源：插件 Plugin.Calibration

这一页讲配置窗口**每个控件落在哪、按下去发生什么**。参数含义与默认值见「端口与参数」，
判读残差与验收见「标定判据与验收」。

## 窗口布局

| 区域 | 内容 |
| --- | --- |
| 左栏 ① 标定模式与标定图 | 四个模式单选按钮、「标定图」编辑器（浏览 / 链接变量）、标定图尺寸一行、实时图说明一行、像素当量专用行 |
| 左栏 ② 标定表 | 「网格规模」下拉 + 「重建网格」、表格（行名 / 机械X / 机械Y / 像Row / 像Col / 取点 / 预填 / 残差px）、表格下方「粘贴 N 行」「清空表格」「把点画到图上」 |
| 左栏 ③ 内参标定（去畸变） | 「标定板」下拉、「相机模型」两个单选 + 像元(µm)、「标定图文件夹」+ 浏览、图列表多行框、「开始内参标定」「合成自验证」「清除内参」、内参质量区、标定结果区、自验证误差表、「取点前先去畸变」开关 + 说明行 |
| 左栏 ④ 质量与标定信息 | 质量一行（`QualityText`）+ 畸变提示一行、相机序列号、「锁定标定（防误改）」、「导出标定…」「导入标定…」、残差阈值(px)、当量下限/上限 |
| 右栏 | HALCON 画布（底图 + 标记 + 残差箭头）、画布上方橙色取点横幅、下方信息栏（左：已载入的标定图路径；右：状态消息） |

画布操作：滑轮缩放、右键菜单「适应图片」、点中标记直接拖动（拖完自动回写表格）。
模式为九点/透视/网格时表格才显示（像素当量模式不需要表），网格规模行随之隐藏。

## ① 模式与标定图

- **四个单选**：`像素当量` / `九点标定（N×N）` / `透视标定（投影）` / `网格标定（分段仿射）`。
  切换后表格/网格规模显隐立刻跟着变，取点待命态自动取消（因为取点目标从"某行"变成"A/B"或反之）。
- **「标定图」编辑器**：既能浏览选文件，也能链接变量（流程变量、上游路径输出）。
  它只是**配置态取点/预览**用的图——运行期不读盘，运行用的是标定数据本身。
- **`标定图尺寸：5120×3840（载图时自动记录…）`**：载图成功即写入并随步骤存盘；
  没载过图时显示`（尚未载入——选择标定图后自动记录）`。这个尺寸是下游"换分辨率就失效"的判据。
- **实时图说明行**：接了 `SourceImage` 端口（连线或点试运行时自动桥接）后，画布**优先显示实时图**
  并可直接在其上取点；此时文件预览仍在，断开实时图会回落。
- **像素当量专用**：「已知长度(mm)」数值框、「取A点」「取B点」两个按钮、A.Row / A.Col / B.Row / B.Col
  四个输入框、跨度提示一行（`标定线 …px，占视野对角 …%`）。

## ② 标定表与三种取点方式

三种方式**完全等效**，任一种改完都**即时重算质量区**（不用切模式、不用点重建、不用跑流程）：

| 方式 | 怎么用 | 适合 |
| --- | --- | --- |
| 「取点」（逐行 / A / B） | 点按钮 → 画布出现橙色横幅"取点中：请在图上点击目标位置" → 在图上点一下即回填该行 Row/Col，横幅消失。再点一次按钮或按 Esc 取消 | 单点定位、快速补一格 |
| 「把点画到图上」 | 按当前表把 N² 个标记（像素当量则 A/B 两个）撒到画布，空行也给铺位；点中标记拖动到位即回写表格 | 一次铺满再逐个拖，最顺手 |
| 表格里直接敲 | 在 像Row / 像Col 格子里输入数值，画布上的同名标记会跟着走 | 数值来自脚本/示教器 |

- **「粘贴 N 行」**：从 Excel / 示教器复制若干行文本再点它。每行 4 列（机械X、机械Y、图像Row、图像Col）
  或 5 列（第一列序号会被丢掉）；分隔符支持 Tab、空格、逗号、分号（含中文全角逗号、分号）。
  **Tab 分隔（Excel 原生）时空格子 = 未填**，行首空列也按未填处理，整行留空跳过——
  这样"只填机械、图像后补"不会把后面的列顶到前面。粘贴会覆盖前 N 行并把行名重排为 P1..PN。
- **「重建网格」**：按当前「网格规模」把表重排成 N² 行，**已填值保留**；缩小网格时若被丢掉的行里有非空行，
  插件**一行都不删**并提示该把规模调到多大（建议值按当前行数向上取整，例如 12 行提示 4×4）。
- **「清空表格」**：只清数值，**行结构与行名保留**。
- **行上的「预填」**：把上游定位点端口 `SourcePointRow` / `SourcePointCol`（接「模板匹配」的 Row/Column
  或「几何查找」的 Row/Col）直接填进该行图像坐标，省掉在画布上重复取点；两个端口都没值时拒绝并提示怎么接。
- **「残差px」列**：求解后由插件回写，配置态调点时立即更新（不是"跑一次流程才填"）。

## ③ 内参标定（去畸变）

**这一组是"相机资产"的产出区**，与上面三张卡片的"标定数据"分开：内参描述的是**镜头畸变**（畸变像素 ↔ 理想针孔像素），
不是"像素 ↔ 机械坐标"；两者串联使用（畸变像素 →去畸变→ 理想像素 →矩阵→ 机械坐标）。

- **「标定板」下拉**：候选来自本机 HALCON 的 `calib\` 目录（旧式板 `caltab_*.descr` / 新式板 `calplate_*.cpd`，
  显示文本里直接标了**灰度极性**）。**落盘存的是文件名**，换机器只要 HALCON 里有同名板就能用；
  也允许直接填全路径用现场自己的板。下方一行给出解析状态或"本机没有这块板"的原因。
- **「相机模型」两个单选**：`单系数（division）` / `多系数（polynomial）`。旁边「像元(µm)」是**假设值**
  （默认 5.2µm）——它只决定焦距/kappa 的**报告单位**，填错不影响去畸变正确性（去畸变对整组等比重参数化精确不变），
  要与镜头标称焦距比对时才需填准。
- **「标定图文件夹」+ 浏览…**：放十几张从不同角度拍到完整标定板的照片（bmp/jpg/png/tif）；
  扫描按文件名排序，结果可复现。下方一行给出"找到几张 / 够不够"。
- **图列表（多行框）**：每行一个路径，`#` 开头为注释。**填了就优先于文件夹**（更具体的那一个说了算）。
- **「开始内参标定」**：读图 → 找标定板 → 求解 → 落内参。**逐张记失败原因**（哪几张没找到、为什么、
  对应的 HALCON 码），有效图数少于 6 张直接失败并给下一步。运行在后台线程，期间按钮禁用。
- **「合成自验证」**：用 HALCON 合成已知内参的 12 张标定板图跑**完整标定链**，与真值比对给出误差表
  （焦距相对误差 / 主点偏差 / kappa / 重投影 RMS 各带判据）。**不接相机就能自证本机标定环境可用**——
  出问题时先跑它，能把"环境坏了"与"你的照片/参数不对"分开。
- **「清除内参」**：清除内参，并**同时关掉**「取点前先去畸变」（内参没了那个开关必然失败）。
- **「取点前先去畸变」**：打开后取到的图像点先经内参去畸变再求解，产出的标定 `Kind` 变成对应的
  `*Undistorted` 成员并带上内参（下游据此知道像素是去畸变域的）。**内参缺失 / 内参标定图尺寸与当前标定图不符
  → 运行期明确失败**（绝不静默退回"不去畸变"）。下方说明行按当前状态给"能不能用"的一句话。

## ④ 质量、锁定与标定文件

- **质量一行**：九点显示 `残差 RMS …px ｜ 最大 …px ｜ 各向异性 …%`；透视额外附 `尺度跨度 …×（四角+中心当量）`；
  网格显示 `网格 N×N：节点处精确通过；下列为**全局仿射基线**残差 …`；像素当量只显示 `像素当量 … mm/px`。
- **畸变提示行**（橙字）：残差随半径放大时给"疑似镜头畸变"方向性建议，没有异常就留空。
- **「相机序列号」**：填「系统 → 相机设置」里的序列号。多相机必填——它是下游失配核对用的机器身份。
- **「锁定标定（防误改）」**：勾上后表格编辑、取点、把点画到图上、粘贴、重建、清空全部拒绝，
  拖动已存在的标记会被弹回表格记录的位置；**运行照常重算与输出**，下游不受影响。
- **「导出标定…」/「导入标定…」**：JSON 文件，用于备份、换机台、让第二台相机复用同一份机械系数据。
  导出文件名建议形如 `标定_{序列号}_{日期时间}.json`（未填序列号时用 `calib`）。
  导入是**全量覆盖**标定数据与质量策略；锁定态拒绝；文件版本更高/非法 JSON/表含空行/阈值或护栏非法都会给出中文原因。
- **「残差阈值(px)」「当量下限」「上限」**：质量闸门的三个数字，超过阈值 = 步骤失败，不是警告。

## 信息栏与画布箭头的颜色口径

| 颜色 | 含义 | 典型场景 |
| --- | --- | --- |
| 绿 | 就绪，配置可用 | 求解成功且闸门通过（各向异性 > 1% 时会转橙） |
| 橙 | 还没配完 / 需要注意 | A、B 未取全、有效点不足、半填行、实时图刚断开、锁定提示、短标定线 |
| 红 | 当前配置不可用 | 残差超阈值、当量越界、共线/重合退化、相机身份不符、标定图不存在或读图失败 |

**闸门未过时质量数字照常红字显示**（让你看见"差多少、离阈值多远"），运行期照旧失败不输出。
画布上的箭头：从实际图像点指向变换反推的理想点，长度 = 残差 × 50（残差是亚像素级，不放大看不见），
阈值内绿色短线、超阈值红色并标出行名与像素值。**透视模式不画箭头**（见「标定判据与验收」的说明）。

## 确定 / 取消

- **确定**：把未链接的参数值写回步骤配置（已链接的端口不写，保留连线）；标定数据、阈值、锁定状态、
  尺寸记录都随步骤存进方案文件。
- **取消**：不改写步骤配置；关窗时取点待命自动取消。
- 配置窗口的「执行」按钮走的是与运行期**同一段计算**，所以"界面绿了、一跑就失败"不会发生。
