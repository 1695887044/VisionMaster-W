# 标定 · 上手与现场验收

这一页讲界面按钮怎么配合、标定数据怎么进出、以及交付时怎么验收。参数含义与默认值见上一页。

## 一、像素当量（6 步）

1. **准备标定物**：一段已知准确长度的东西（量块 / 打印标尺 / 圆点靶上两点距）。
   长度尽量**跨越视野对角的 1/3 以上**——基线越短相对误差越大，界面上的"跨度提示行"会在偏短时报橙字；
2. 「标定图」选一张拍到该标定物的图（浏览或链接变量都行）。载图时插件会**自动记录图像尺寸**，
   下游据此判断"换分辨率就失效"；
3. 填**已知长度(mm)**；
4. 三种取点方式**等效**，改完即时重算：
   - 点「取A点」→ 在图上点标定物一端（Row/Col 自动回填），再「取B点」点另一端；
   - 点「把点画到图上」→ 直接拖动画布上的 A / B 标记（拖完自动回写表格）；
   - 直接在 A/B 的 Row/Col 输入框里手填；
5. 看质量区：`像素当量 ≈ 0.02… mm/px`。超出 [0.001, 1] 护栏会直接报越界——先查单位；
6. **需要机械坐标的场景不要停在这里**——像素当量模式只给 mm/px，改用「九点标定」。

## 二、九点标定（9 步）

**先选工作流**：

- **A：单图九靶点**（标定板一次拍全）——一张图里同时看到 9 个特征点，取点全在画布上完成；
- **B：多图走位**（机械带着标定物走 9 个位置，每处采一张图）——图像点用「模板匹配 / Blob 缺陷检测」或人工读，
  机械坐标从示教器读。插件画布主要服务工作流 A 与核对。

**步骤**：

1. 模式切到「九点标定（N×N）」，网格规模默认 3×3（下拉 2~10）。加密到 4×4/5×5 能提高抗噪余量、
   也更容易暴露畸变，代价是填表工作量 N²；
2. 「标定图」载入一张图（工作流 A 就载那张九点图；工作流 B 载任意一张用于核对）；
3. 需要调整表的大小就点「重建网格」（按当前网格规模重排成 N² 行，**已填值保留**；
   若缩小网格会丢掉已填的行，插件会拒绝并提示该把规模调到多大）；
   点「把点画到图上」→ 画布出现 N² 个标记；
4. **逐行点「取点」**在图上定位（点一下特征点中心，Row/Col 自动填进该行）；
   也可以拖动标记，或直接在表格里敲 像Row/像Col——**三种方式改完都即时重算质量区**，
   不用切模式、不用点重建；
5. **填/粘贴机械坐标**：点「粘贴 N 行」，从示教器或 Excel 复制过来。每行 4 列
   （机械X、机械Y、图像Row、图像Col）或 5 列（带序号，第一列丢弃）；
   分隔符支持 Tab / 空格 / 逗号 / 分号（含中文逗号、分号）。
   **Tab 分隔（Excel 原生）时空格子 = 未填**，行首空列也按未填处理，整行留空跳过——
   这样"只填机械、图像后补"不会把后面的列顶到前面；
6. 上游有定位结果时，行上的「预填」按钮可把 `SourcePointRow` / `SourcePointCol`（接「模板匹配」的
   Row/Column，或「几何查找」的 Row/Col）直接填进该行的图像坐标，省掉手抄；
7. 看质量区三件事：残差 RMS / 最大偏差 / 各向异性；出现橙色"疑似镜头畸变"提示时**别急着重取点**，
   先按下面第三节的形态表判断该升哪一档；
8. 残差超阈值 → 红字失败，按提示三查（机械与图像是否一一对应 / 是否取在同一物理位置 / 是否畸变）；
9. 试运行确认 `Success = true`，然后下游接线：`标定.Transform ──▶ 坐标变换.Transform`。
   核验无误可勾「锁定标定（防误改）」。

## 三、残差形态 → 该用哪种标定

| 残差形态 | 含义 | 处置 |
| --- | --- | --- |
| 随机小残差、无方向性 | 就是取点噪声 | 合格。要更好就加密点数、改善打光、把点取在更清晰的边上 |
| 中心小、边缘大（径向带逐带放大） | **镜头畸变**，仿射模型吸不住 | 转「网格标定」（N×N 全取点，逐格仿射），或做镜头内参校正 |
| 单方向偏 / 呈梯形分布 | **相机斜置**（近大远小） | 转「透视标定」（至少 4 点，推荐 3×3/4×4） |
| 某一行特别大 | 那一个点取错了 | 看表格"残差px"列定位行名，重新取该点 |
| 各向异性 > 1% | 标定物没正对镜头 / 像素非方形 | 提示不是失败；介意就摆正标定物重标 |

**判读口径**：径向带分 3 带（归一化半径 ≤0.4 / 0.4~0.7 / >0.7），边缘带 ≥ 2×中心带且超过门限
（`max(0.5px, 残差阈值×0.5)`）才报"疑似镜头畸变"。**空带记 0**——先看各带点数再看均值，
没有点的带不参与形态判读。

**网格模式的质量口径不同**（必读）：网格在节点处精确通过，节点残差恒 0。质量区显示的 RMS/最大/径向带
是**同一批点上"全局仿射基线"**的拟合质量，衡量"畸变有多大、网格值不值得用"，
所以它偏大是正常现象，网格模式也**不做残差闸门**（当量护栏照旧生效）。

## 四、画布上的残差箭头

求解后画布会叠一层箭头：从**实际图像点**指向**变换反推的理想点**，长度 = 残差 × 50
（残差是亚像素级，不放大看不见）。阈值内绿色短线，超阈值红色并标出行名与像素值。
看哪几个点在拖后腿，比只看 RMS 直观得多。

## 五、标定数据导出 / 导入

- 「导出标定」生成 JSON（含：模式、网格规模、已知长度、A/B 点、标定表、相机序列号、
  残差阈值与当量护栏、标定图尺寸、时间戳，以及能求解时附带的质量快照）；
- **不含**锁定开关、预览图路径、画布状态——那些是本机状态，不该跟文件走；
- 求解失败也不阻断导出（文件的价值是数据本身）；
- 「导入标定」按同样格式读回。用途：换机台/备份/让第二台相机复用同一份机械系数据（注意仍要各自核对）。

## 六、多相机怎么配

1. **一台相机一份标定、一个标定步骤**，流程里各自接线；
2. 九点表"一行 = 一个机械位置"：机械走一次，多台相机各自取各自的图像点（各自一个标定步骤）；
3. **统一坐标系**：每台相机各自与机械做九点标定，就天然统一到同一个机械坐标系
   （多相机融合在机械系里做）；
4. 每台都填 `CameraSerial`，并把「图像采集」的 `SourceSerial` 接到本步骤（或下游「坐标变换」）的同名口——
   两端都非空且不一致时**明确失败**（大小写不敏感；任一为空则不校验，单相机/离线不打扰）。

## 七、现场三步验收（交付时执行）

1. **当量核对**：放一个已知尺寸（如 100mm 标定尺），读数与实物一致（±0.5% 以内）；
2. **回算核对**：九点标定后把 9 个点的机械坐标经矩阵反算成图像点，误差 < 1 像素当量
   （界面上的残差箭头与"残差px"列就是这一件事，不用手算）；
3. **示教器比对**：用「坐标变换」把匹配得到的 Row/Col 换成机械坐标，与示教器读数比对
   （±0.5mm 或 ±1 像素当量，取大者）。

三步都过再接产线；任何一步不过，先回到第三节的形态表判断是取点问题还是模型选错。
