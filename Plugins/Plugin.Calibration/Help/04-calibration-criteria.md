# 标定 · 判据与现场验收

> 分类：标定 ｜ 来源：插件 Plugin.Calibration

这一页回答三个问题：**该用哪个模型**、**点按什么顺序取**、**怎么判断这份标定合格、不合格怎么办**。
最后给交付现场的三步验收。界面操作见「界面与取点编辑」。

## 一、模型怎么选（先看残差形态，再换模型）

残差不是"越小越好"就完事，**形态**才告诉你该干什么：

| 残差形态 | 含义 | 处置 |
| --- | --- | --- |
| 随机小残差、无方向性 | 就是取点噪声 | 合格。要更好就加密点数、改善打光、把点取在更清晰的边上 |
| 中心小、边缘大（径向带逐带放大） | **镜头畸变**，仿射模型吸不住 | 转「网格标定」（N×N 全取点，逐格仿射），或做镜头内参校正 |
| 单方向偏 / 呈梯形分布 | **相机斜置**（近大远小） | 转「透视标定」（至少 4 点，推荐 3×3/4×4） |
| 某一行特别大 | 那一个点取错了 | 看表格"残差px"列定位行名，重新取该点 |
| 各向异性 > 1% | 标定物没正对镜头 / 像素本身非方形 | 提示不是失败；介意就摆正标定物重标 |

**判读口径**：径向带分 3 带（归一化半径 ≤0.4 / 0.4~0.7 / >0.7），边缘带 ≥ 2×中心带且超过门限
（`max(0.5px, 残差阈值×0.5)`）才报"疑似镜头畸变"。**空带记 0**——先看各带点数再看均值，
没有点的带不参与形态判读。

**换模型不会丢数据**：四个模式共用同一张标定表（像素当量共用 A/B 两点），切过去即时重算，
所以"先九点、发现畸变再网格"不需要重取点。

**点数是采样密度，不是模型**：仿射 6 个自由度、3 点即唯一解。加密到 4×4/5×5 能提高抗噪余量、
更容易暴露畸变，但**不会把畸变拟合掉**——想吸畸变只能换模型（网格/透视）。

## 二、取点顺序

### 像素当量（6 步）

1. **准备标定物**：一段已知准确长度的东西（量块 / 打印标尺 / 圆点靶上两点距）。
   长度尽量**跨越视野对角的 1/3 以上**——基线越短相对误差越大，界面上的"跨度提示行"会在偏短时报橙字；
2. 「标定图」选一张拍到该标定物的图（浏览或链接变量都行）。载图时插件会**自动记录图像尺寸**；
3. 填**已知长度(mm)**；
4. 取 A、B 两点（三种方式等效，改完即时重算）：
   - 点「取A点」→ 在图上点标定物一端，再「取B点」点另一端；
   - 点「把点画到图上」→ 拖动画布上的 A / B 标记（拖完自动回写）；
   - 直接在 A / B 的 Row/Col 输入框里手填；
5. 看质量区：`像素当量 ≈ 0.02… mm/px`。超出护栏 [0.001, 1] 会直接报越界——先查单位；
6. **需要机械坐标的场景不要停在这里**——像素当量只给 mm/px，改用「九点标定」。

### 九点标定（9 步）

**先选工作流**：

- **A：单图九靶点**（标定板一次拍全）——一张图里同时看到 9 个特征点，取点全在画布上完成；
- **B：多图走位**（机械带着标定物走 9 个位置，每处采一张图）——图像点用「模板匹配 / Blob 缺陷检测」
  或人工读，机械坐标从示教器读。插件画布主要服务工作流 A 与核对。

**步骤**：

1. 模式切到「九点标定（N×N）」，网格规模默认 3×3（下拉 2~10）；
2. 「标定图」载入一张图（工作流 A 载那张九点图；工作流 B 载任意一张用于核对）；
3. 需要调整表的大小就点「重建网格」（按当前规模重排 N² 行，**已填值保留**；
   缩小会丢掉非空行时插件拒绝并提示该调到多大）；点「把点画到图上」→ 画布出现 N² 个标记；
4. **逐行点「取点」**在图上定位（点一下特征点中心，Row/Col 自动填进该行）；
   也可以拖标记，或在表格里直接敲 像Row / 像Col——**三种方式改完都即时重算质量区**；
5. **填 / 粘贴机械坐标**：点「粘贴 N 行」，从示教器或 Excel 复制过来（每行 4 列，或 5 列带序号；
   Tab 分隔时空格子 = 未填，整行留空跳过）；
6. 上游有定位结果时，行上的「预填」把 `SourcePointRow` / `SourcePointCol` 直接填进该行图像坐标，省掉手抄；
7. **顺序纪律**：先把图像点全部取在同一物理特征上，再核对机械坐标与图像点是否**一一对应**（串行是
   现场最常见的"残差某一行特别大"）；机械坐标取自示教器时注意当前机械系与工具/工件号；
8. 看质量区三件事：残差 RMS / 最大偏差 / 各向异性；出现橙色"疑似镜头畸变"时**别急着重取点**，
   先按第一节形态表判断该升哪一档；
9. 试运行确认 `Success` 为真，然后接线 `标定.Transform ──▶ 坐标变换.Transform`；
   核验无误可勾「锁定标定（防误改）」。

### 透视标定

与九点同一张表、同一套取点动作，差别只有：最少 4 组点（推荐 3×3/4×4），且**必须覆盖视野四角**——
近大远小是位置相关的，只取中间一小片等于没标斜置。质量区会额外给
`尺度跨度 …×（四角+中心当量）`：这个数越接近 1 说明越不斜，明显大于 1 就是斜置量。

### 网格标定

**要求 N×N 每行都取点**（缺一个节点，它周围四格都不可用，插件直接失败并指到行名）。
节点必须**按行主序**排（第一行从左到右、再下一行），行名 P1..PN 就是这个顺序；表格行数与网格规模不一致时
先点「重建网格」对齐。取点精度要求比九点更高：网格是插值模型，节点错一个，周围四格整体跟着歪。

## 三、精度怎么评估

| 指标 | 在哪看 | 判读 |
| --- | --- | --- |
| 残差 RMS（px） | 质量区 + 输出 `ResidualRmsPx` | 与 `ResidualThresholdPx` 比较；超阈值即失败。≤0.2px 很漂亮，0.2~1px 正常 |
| 最大单点残差（px） | 质量区 + 输出 `ResidualMaxPx` + 表格"残差px"列 | 某行远大于其余 → 那一点取错，重取该点而不是放宽阈值 |
| 各向异性（%） | 质量区 | >1% 转橙提示（标定物没正对镜头 / 像素非方形）；若测量方向落在当量大的那一向，误差会被放大 |
| 径向三带 | 质量区提示行 | 边缘 ≥ 2×中心 → 疑似镜头畸变（仿射吸不住） |
| 尺度跨度 | 透视模式质量区 | 四角+中心局部当量的 max/min，衡量"视野内均匀程度" |
| 残差箭头 | 画布 | 从实际图像点指向理想点，长度 = 残差 × 50；绿=阈值内，红=超阈值并标行名与像素值 |

- **残差统一像素口径**：机械系偏差（mm）会按当量换算成像素后再统计与比较，表格列同一口径回写。
- **箭头只在九点与网格模式出现**：网格画的是全局仿射基线的偏差（与质量区同口径）；
  透视模式不画（它的 6 元矩阵按设计保持零，见下），像素当量模式没有逐点残差可画。
- **网格模式的质量口径不同**（必读）：网格在节点处**精确通过**，节点残差恒 0、没有信息量。
  质量区显示的 RMS / 最大 / 径向带是"**同一批点上全局仿射基线**"的拟合质量，用来判读畸变有多大
  （它偏大是**正常**的，正是你选网格的理由）。网格模式**不做残差闸门**，当量护栏照常生效。
- **透视与网格故意把 6 元 `Matrix` 留成零**：未升级的消费者拿它会因行列式为 0 明确失败——
  绝不允许把"透视/网格"静默近似成"仿射"（边缘区域会整体错位）。
- **时间戳**：`CalibrationStampUtc` 只在标定数据真的改动时推进（运行期每轮重算不动它），
  用它盯"标定多久没更新"才有意义。

## 四、不合格时的处置（先查点、再查单位、最后才动阈值）

1. **残差超阈值**（红字，数字照常显示）：
   ① 逐行看"残差px"列 → 定位到具体点，重取该点（多半是没取在同一物理位置，或机械坐标与图像点串了行）；
   ② 看径向带提示 → 中心小边缘大转「网格标定」，单向偏/梯形转「透视标定」；
   ③ 都排除了再考虑放宽 `ResidualThresholdPx`（大画幅/弱镜头现场常见），但要明白这是在**容忍误差**；
2. **当量算出 0.00002 这种量级** / 报越界：单位填错一个数量级（µm 当 mm）或标定物长度写少一位，
   先核 `KnownLengthMm` 与标定物实际标注；
3. **报近似共线**：只沿一条输送带走点是最常见成因 → 把点铺开成 N×N 覆盖四角与中心；
4. **报某行半填 / NaN**：整行留空 = 空行、四值齐全 = 有效点，别用 0 占位（0 是合法坐标）；
5. **报相机身份不符**：换相机了 → 用那台相机重新标定；只是序列号填错 → 改「相机序列号」；
6. **报两点像素距离为 0**：A、B 重合 → 把两个标记拖到标定物两端；
7. **下游「坐标变换」报"只有像素当量"**：模式选错，改用九点/透视/网格重标一份。

**重标定的最小动作**：只改坏的那个点（不必整表重来）——改完质量区立即重算，绿了再试运行。

## 五、标定数据导出 / 导入

- 「导出标定」生成 JSON：模式、网格规模、已知长度、A/B 点、标定表、相机序列号、
  残差阈值与当量护栏、标定图尺寸、来源标签、时间戳，能求解时附带质量快照；
- **不含**锁定开关、预览图路径、画布状态——那些是本机状态，不该跟文件走；
- 求解失败也不阻断导出（文件的价值是数据本身）；
- 「导入标定」按同样格式读回，**全量覆盖**标定数据与质量策略，时间戳以文件为准；
  行数与网格规模不一致时以行为准归一规模；文件里没记尺寸时**不会把本机尺寸清成 0**
  （0 会让下游"换分辨率自证"直接放行）；
- 用途：换机台、备份、让第二台相机复用同一份机械系数据（注意仍要各自核对相机序列号与残差）。

## 六、多相机怎么配

1. **一台相机一份标定、一个标定步骤**，流程里各自接线；
2. 九点表"一行 = 一个机械位置"：机械走一次，多台相机各自取各自的图像点（各自一个标定步骤）；
3. **统一坐标系**：每台相机各自与机械做九点标定，就天然统一到同一个机械坐标系（多相机融合在机械系里做）；
4. 每台都填 `CameraSerial`，并把「图像采集」的 `SourceSerial` 接到本步骤（或下游「坐标变换」）的同名口——
   两端都非空且不一致时**明确失败**（大小写不敏感；任一为空则不校验，单相机/离线不打扰）。

## 七、现场三步验收（交付时执行）

1. **当量核对**：放一个已知尺寸（如 100mm 标定尺），读数与实物一致（±0.5% 以内）；
2. **回算核对**：九点标定后把 9 个点的机械坐标经矩阵反算成图像点，误差 < 1 像素当量
   （界面上的残差箭头与"残差px"列就是这一件事，不用手算）；
3. **示教器比对**：用「坐标变换」把匹配得到的 Row/Col 换成机械坐标，与示教器读数比对
   （±0.5mm 或 ±1 像素当量，取大者）。

三步都过再接产线；任何一步不过，先回到第一节形态表判断是取点问题还是模型选错。
验收通过后勾「锁定标定（防误改）」，并把 `ResidualRmsPx` 接进数据记录留档。
