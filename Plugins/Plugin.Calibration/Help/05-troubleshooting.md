# 标定 · 排错

> 分类：标定 ｜ 来源：插件 Plugin.Calibration

引号里的都是**界面/日志里的原文**，看到哪句就跳到哪条。质量判读与重标定流程见「标定判据与验收」。

## 常见问题

**Q：下游「坐标变换」报"当前标定只有像素当量、不含机械坐标"？**
用了 `PixelScale` 模式去做坐标换算。像素当量只给 mm/px、不知道机械系在哪，
要机械坐标就重新用「九点标定」（或透视/网格）标一份。

**Q：残差报"超过阈值 1px"，先改什么？**
口诀：**先查点、再查单位、最后才动阈值**。
① 表格逐行看"残差px"列指到哪一行（多半是那一行的图像点没取在同一物理位置，或机械坐标与图像点串了行）；
② 看径向带提示：中心小、边缘大 → 疑似镜头畸变，仿射吸不住，转「网格标定」（工程近似）
   或做「内参标定（去畸变）」（正解：第 ④ 卡片标一次内参，再勾「取点前先去畸变」重取点）；
   单方向偏/梯形 → 相机斜置，转「透视标定」；
③ 都排除了再考虑放宽 `ResidualThresholdPx`（大画幅/弱镜头现场常见），但要明白这是在容忍误差。
超阈值时质量区**照常红字显示残差数字**，看得到差多少；运行期照旧失败不输出。

**Q：当量算出来是 0.00002 这种量级？**
单位填错一个数量级（把 µm 当 mm）或标定物长度写少一位。护栏 [0.001, 1] 会直接报越界；
先核 `KnownLengthMm` 与标定物实际标注单位。护栏两个数**填反了也对调使用**，不会因此报错。

**Q：报"标定表第「P3」行只填了一部分"？**
标定表四个值（机械X / 机械Y / 图像Row / 图像Col）必须齐全。**没填就整行留空**，别写 0——
0 是合法坐标（机械回零位、工件原点、图像边缘都会取到 0）。整行留空 = 空行不参与计算；半填会被当成漏填而明确报错。

**Q：A/B 点把 Row 填成 0 就"没反应"？**
不会。这四个字段是可空语义：`null` = 未取点，`0` = 合法坐标（旧版本拿 0 当"没填"，已修）。
旧方案里"四个值全是 0"的行在载入时会自动还原成空行，并在信息栏提示还原了几个。

**Q：各向异性 2% 要不要紧？**
通常是标定物没有正对镜头（或像素本身非方形）。它是**提示不是失败**；
但如果测量方向正好落在当量大的那一向，误差会被放大——介意就摆正标定物重标。

**Q：换相机 / 换分辨率后旧标定还在用？**
填好 `CameraSerial` 并接上游 `SourceSerial`（两端都非空才校验，大小写不敏感，单相机/离线不打扰）；
图像尺寸在载图时自动记录，下游「坐标变换」接了 `SrcImage` 就会做尺寸失配校验。
标定时间戳 `CalibrationStampUtc` 只在标定数据真改动时推进，可用来盯"标定多久没更新"。

**Q：怕现场有人误改标定？**
勾「锁定标定（防误改）」。锁定后表格编辑、取点、把点画到图上、粘贴、重建、清空全部被拒，
拖动已有标记会被弹回表格位置；**运行照常重算输出**，下游不受影响。解锁后才能继续改。

**Q：网格标定为什么报"第「P7」行还空着"，我表里都填了？**
网格要求 N×N **每行都取点**（缺一个节点，它周围四格都不可用）。另外它还要求**行数 = N²**：
行数与「网格规模」不一致时先点「重建网格」把两者对齐。粘贴扩容导致"非平方行数"时，
把网格规模调到能装下全部行的值（提示里给的就是这个建议值）。

**Q：网格模式残差看着很大，是不是标坏了？**
不一定。网格在节点处**精确通过**，质量区显示的是"同一批点上全局仿射基线"的残差——
它衡量畸变有多大，偏大正是你选网格的理由。**网格模式不做残差闸门**，当量护栏照常生效。

**Q：透视标定为什么不显示残差箭头？**
箭头的画法依赖 6 元仿射矩阵，而透视/网格模式按设计把 6 元矩阵保持为零
（防止未升级的下游把透视/网格静默当仿射用）。透视的质量数字与"尺度跨度"仍在质量区显示，
逐点偏差看表格"残差px"列（透视用逐点局部当量换算，边缘不会悄悄放行放大误差）。

**Q：改了表格，质量区数字不动？**
不会发生——四个模式的质量数字都走**同一段计算**，改表格任一格、拖标记、取点、粘贴都即时重算。
若确实没反应，先看是不是勾了「锁定标定」（锁定 = 只读，改动被拒）。

**Q：试运行一次比一次慢？**
标定是每轮重算（微秒级），慢不会来自这里。倒是接了大标定图时配置态读图会等一帧预览，
与运行期无关。

## 现象 → 查哪一项

| 原文（节选） | 根因 | 下一步 |
| --- | --- | --- |
| `像素当量：A / B 两点尚未取全` | A/B 有任一值为空 | 「取A点」「取B点」各点一下，或在 A.Row/A.Col/B.Row/B.Col 手填 |
| `两点像素距离为 0：请在画布上把 A/B 两个标记拖到标定物两端` | A、B 取在同一处 | 把两个标记拖开；两点越远当量越可信 |
| `已知长度必须为正数（当前 0）` | `KnownLengthMm` 没填或填 0/负数 | 按标定物实际标注填 |
| `有效标定点不足：至少需要 3 组，当前 N 组（表里共 M 行）` | 表里整行留空的太多 | 补点；或确认半填行没有把有效行吃掉 |
| `透视标定至少需要 4 组点（推荐 9~16 组，覆盖视野四角+中心）` | 透视是 8 自由度模型，3 点不够 | 补到 ≥4 组并覆盖四角 |
| `标定表第「Pn」行只填了一部分：机械X / 机械Y / 图像Row / 图像Col 必须四值齐全` | 漏填一格 | 补齐或整行留空 |
| `标定表第「Pn」行含非法数值（NaN/Inf）` | 该行了写了非数字 | 重填该行（粘贴时最常见） |
| `标定点近似共线（无法定出平面方向）：请把点铺开成 N×N 网格` | 点落在一条线上（沿输送带走点） | 重排点覆盖四角与中心 |
| `标定点在图像上全部重合（尺度为 0）——请把点铺开成 N×N 网格` | 所有图像点同一个位置 | 检查是否预填把同一值写进了每一行 |
| `标定点分布退化（近似共线/重合或覆盖不足），无法稳定求出投影变换` | 透视点构型太差 | 补点并覆盖四角；有重复点先去掉 |
| `投影矩阵求解退化（h33≈0，无法按 h33=1 归一化）` | 数据构型接近仿射退化 | 换点分布重标；确认机械坐标没串列 |
| `标定点跨越投影退化线（映射折返、雅可比符号不一致）` | 点覆盖到了视野外/翻转区域 | 把点收回镜头正常视野内重标 |
| `标定残差 Xpx 超过阈值 Ypx（最大偏差 Zpx）。请检查：① …` | 见上方"残差超阈值" | 先查点，再按形态换模型 |
| `像素当量 X 非法（必须为正）` | 矩阵退化或当量算成 0 | 检查标定数据；必要时重建表 |
| `当量 X mm/px 超出合理范围 [min, max]：① 单位是否把 µm 当 mm 填了？` | 单位或长度量错一个数量级 | 核单位；或按现场光学放宽护栏 |
| `相机身份不符：这份标定属于「A」，但当前图像来自「B」` | 换相机没换标定，或序列号填错 | 用该相机重标，或修正「相机序列号」/接线 |
| `网格标定要求 n×n = K 行标定表，当前表里有 M 行` | 行数与网格规模不一致 | 点「重建网格」或按提示调规模 |
| `网格标定要求 N×N 每行都取点：第「Pn」行还空着` | 缺节点 | 补该点（缺一个，周围四格都不可用） |
| `第 r 行第 c 列的网格退化（像素点共线或重合）` | 该格四个节点构型太差 | 重取该格角点 |
| `标定图不存在: 路径` / `加载标定图失败: …` | 路径失效 / 图损坏 | 重新「标定图」浏览选文件；链接变量时确认变量值 |
| `请先加载标定图（文件路径或实时图），再点「取点」` | 画布现在没有底图 | 先选标定图，或接上 `SourceImage` 实时图 |
| `已取点（Pn）：Row …, Col …` 后表格没变 | 看错了行 | 提示里的名字就是被写入的行名 |
| `标定已锁定：先解锁再导入`（或粘贴/重建/清空/取点同类文案） | 勾了锁定 | 取消勾选后再改 |
| `网格缩小会把已有的第 k 行（Pn）丢掉：请先清空该行，或把网格规模调到 …` | 缩小会丢非空行 | 按建议值调，或先清空该行 |
| `剪贴板第 k 行有 N 列，应为 4 列…或 5 列（带序号）` | 复制的列数不对 | 只复制四列（或带序号五列）；空格子按未填处理 |
| `剪贴板第 k 行「文本」不是数字` | 行内有表头/单位文字 | 别复制表头，或去掉单位 |
| `导入失败：文件版本 V 不支持（当前支持 1~1）` | 文件来自更高版本 | 用同版本软件导出 |
| `导入失败：不是有效的标定文件（…）` / `导入失败：缺少标定表` / `导入失败：标定表含空行` | 文件损坏或被手工改坏 | 重新导出一份 |
| `导入失败：残差阈值非法（NaN）` / `导入失败：当量护栏非法（…）` | 文件里策略值坏 | 重新导出 |
| `未接标定：请把「标定」插件的 Transform 输出接到本步骤`（下游报） | `Transform` 没连线 | 把本步骤 `Transform` 接到下游 |
| `标定与当前图像尺寸不符（标定时 WxH，当前 WxH）——换分辨率/换相机后需重新标定`（下游报） | 改了分辨率 | 用当前分辨率重标一份 |

### 内参标定（去畸变）组

| 报错 | 原因 | 下一步 |
| --- | --- | --- |
| `内参标定：没有可用的标定图` / `尚未指定标定图` | 文件夹空、路径不存在、图列表为空 | 选一个放了 12 张以上标定板照片的文件夹 |
| `内参标定：标定板描述文件不存在——…` | 落盘的是文件名但本机没有这块板 | 在下拉里选本机有的板（说明行会列出可用项） |
| `内参标定：成功找到标定板的图只有 N 张，少于要求的 6 张…` | 板不完整/太小/极性配反 | 逐张诊断里给了每张的原因；先修图再重标 |
| 某张报 `#8397 分割不出标定标记` | 板太小/太远（板宽应占画面 1/3 以上）、对比度不足 | 把板靠近相机重拍，避免反光 |
| 某张报 `#8431 定不出标定板朝向` | **灰度极性配反**（旧式板标记暗、新式板标记亮） | 核对板文件与实际明暗关系；或换成与实际板同极性的文件 |
| 某张报 `#8404 椭圆搜索没找到标定标记` | 板太大/太近，或过曝糊掉 | 把板挪远一点 / 调暗照明 |
| `内参标定：标定图尺寸不一致——…` | 文件夹里混了不同分辨率的图 | 只保留同一台相机同一分辨率的图 |
| `内参标定：像元尺寸假设非法（0）` | 像元(µm) 填了 0 或负数 | 填正数（不知道就留 5.2） |
| `内参求解失败… #8498 No observation data` | 找到板的图不足 2 张 | 按逐张诊断补拍 |
| `「取点前先去畸变」已启用，但相机内参缺失…` | 没标内参就开了开关 | 先做一次内参标定，或关掉开关 |
| `「取点前先去畸变」已启用，但内参的标定图尺寸 … 与当前标定图 … 不一致` | 换分辨率/换相机后沿用旧内参 | 用当前分辨率重标内参 |
| `「取点前先去畸变」已启用，但内参不可用（…）` | 内参损坏或字段不全 | 重新做一次内参标定 |
| `合成自验证未通过` | 本机 HALCON 标定链或环境有问题 | 把误差表内容反馈给开发者（余量本应有一个数量级，红了多半是环境变了） |

## 产物与部署三条红线

1. 手册页放在本工程 `Help\`（单插件类程序集用扁平目录，不许再分子目录）；
2. 改完手册要**重建本工程**才生效（`Modules\` 里的 DLL 带着内嵌资源）；
3. 契约对象 `CalibrationTransform` / `CalibrationMesh` 属 `Core.Interfaces`，
   **绝不能把契约程序集副本拷进 `Modules\`**——否则运行期出现两份 `ImageHub`/两份类型，
   症状是"数据投进去取不出来"、跨插件端口类型对不上（标定侧与坐标变换侧算出两套坐标）。
