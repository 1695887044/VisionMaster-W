# 图像对齐 · 快速上手

> 分类：图像处理 ｜ 来源：插件 Plugin.ImageAlign

把当前图**搬回基准帧**：先由 2~4 对基准点（或上游位姿）求变换，再重采样出一张与基准同尺寸的对齐图，
同时给出正/逆变换矩阵和**有效区**。下游的差分、Blob、颜色、读码、OCR 就可以按固定坐标检测，
不用每个插件自己写一遍对齐。

工具库里的名字是「图像对齐」，分组在**图像处理**。

## 三种模式

| 模式 | 输入 | 变换 | 典型场景 |
| --- | --- | --- | --- |
| **基准点（2~12 点对）** | 参考点 + 当前点，各 2~12 对（>4 走 RANSAC） | 2 点刚性 / 3 点仿射 / 4 点透视 / 5+ 点 RANSAC | PCB 标记点、标签角点、印刷套准 |
| **手动四点（透视）** | 必须正好 4 对点 | 透视 | 调试、离线标定、倾斜拍摄 |
| **上游位姿（刚性）** | 上游 `HomMat2D`（参考→当前）或 `PoseRow/Column/Angle`（弧度） | 刚性 | 前面已有模板匹配/位姿，不想再跑一遍 |

**v1 不自己跑模板匹配**。需要模板位姿时，先接「模板匹配」的 `Row/Column/Angle`（或其它位姿源），
再用本插件的「上游位姿」模式；这样不会和 `Plugin.Matching` 重复，也不会多一次匹配耗时。

## 一轮对齐产出什么

```
输入：当前图（Image，必接）
      基准图（ReferenceImage，可选；只定输出尺寸/有效区，必须同尺寸）
      参考点 / 当前点（端口或文本，2~4 对）
      或 上游 HomMat2D / PoseRow/Column/Angle

      │
      ├─▶ AlignedImage        搬回基准帧的图（同尺寸；画幅外填 0）
      ├─▶ ValidRegion         有效像素区（黑边之外）；下游用它限制检测区
      ├─▶ HomMat2D            当前图 → 基准帧（9 元；warp 用的就是它）
      ├─▶ InverseHomMat2D     基准帧 → 当前图（9 元；结果坐标搬回原图）
      ├─▶ Score / Residual    分数 / 验证点残差
      ├─▶ ValidAreaRatio      有效区面积占画幅比例
      ├─▶ UsedPointCount      参与拟合的点对数（2~12；位姿模式 0）
      ├─▶ InlierCount / OutlierCount  RANSAC 内点 / 外点数
      ├─▶ IsOk / Reason       可选阈值结论；默认 metrics-only
      ├─▶ Details             明细：模式/点数/残差/分数/有效区/矩阵
      └─▶ Success / ErrorMessage  执行成功与否
```

## 五步配出第一次对齐

### 第一步：接当前图

`Image` 接当前这一拍的图。`ReferenceImage` 可选：接了就用它的尺寸和域作为目标；**必须与 Image 同尺寸**，
否则直接失败（v1 不做输出尺寸缩放）。

### 第二步：选模式

- 有 4 对可靠的基准点 → **手动四点（透视）**；
- 只有 2~3 对 → **基准点（2~4 点对）**，自动选刚性/仿射；
- 前面已经有位姿 → **上游位姿（刚性）**。

### 第三步：填点对

点文本格式：`行,列; 行,列; ...`（Row, Column，像素坐标，逗号分隔，分号/换行分隔每组）。

**配置界面左侧画布可以直接点选**：点「取参考点」或「取当前点」，再在图上点一下；
右侧表格会新增/回填一行，坐标也可直接在表格里改。

- `RefPointsText`：基准帧上的点；
- `CurPointsText`：当前图上的对应点；
- 两组数量必须一致，2~12 对；>4 对走 RANSAC（自动剔除外点）。

也可以接 `RefPoints` / `CurPoints` 端口（`HTuple`，交错 `r,c,r,c,...`），端口优先于文本。
端口适合上游脚本/算法自动产点；文本适合手动调试。

### 第四步：加验证点（4 点强烈建议）

**4 点透视刚好定 8 个自由度，残差恒为 0**：第 4 点填错也能拟合出一个“看起来正常”的透视矩阵。
要发现错点，填 `ValidationPointText`：`refRow,refCol,curRow,curCol`（第 5 对点）。
拟合后用前 4 对求变换，再看第 5 对映射回基准的误差；超过 `ResidualLimit`（默认 5px）直接失败。

2/3 点也是精确拟合，残差恒 0；要自检同样靠验证点。
5~12 点则走 RANSAC：自动剔除外点，要求至少 5 个一致点；`OutlierCount` 告诉你剔除了几个。

### 第五步：接下游

- `AlignedImage` → 差分 / Blob / 颜色 / 读码 / OCR；
- `ValidRegion` → 下游的 `MaskRegion` / `SearchRegion` / `RoiRegion`，**黑边必须排除**；
- `InverseHomMat2D` → 下游把结果坐标搬回原图（结果显示、机械手）；
- `IsOk` → 可选，接「逻辑判断」；默认 metrics-only。

## 接线图

```
[采图] ──Image──▶ [图像对齐].Image
[模板匹配] ──Row/Column/Angle──▶ [图像对齐].PoseRow/PoseColumn/PoseAngle（上游位姿模式）
[创建 ROI/脚本] ──HTuple──▶ [图像对齐].RefPoints / CurPoints
[基准图] ──Image──▶ [图像对齐].ReferenceImage（可选，同尺寸）
                        │
                        ├──AlignedImage──▶ [图像差分] / [Blob] / [读码] / [OCR]
                        ├──ValidRegion───▶ 下游 MaskRegion（排除黑边）
                        ├──InverseHomMat2D──▶ [结果显示] / 结果坐标回搬
                        └──IsOk──────────▶ [逻辑判断]（可选）
```

## 这个插件不做什么

- **不自己跑模板匹配**。模板位姿请用「模板匹配」或上游位姿；本插件只消费位姿/矩阵。
- **不做局部可变形**（v2）。v1 只做刚性/仿射/透视；柔性件、拉伸薄膜不在范围内。
- **不做镜头畸变校正**。先由「标定」去畸变，再做对齐；不要把畸变混进透视矩阵。
- **不做判定**。默认 metrics-only；`IsOk` 只是可选阈值结论，不改变 `Success`。
- **不写全局变量**。结果只走端口/运行时变量；要全局由下游「变量赋值」映射。
- **画布点选已提供**：左侧画布点「取参考点/取当前点」后点击取点；拖拽编辑点、多基准点库是后续版本。

## 常见误用

| 写法 | 后果 | 正确做法 |
| --- | --- | --- |
| 把 `HomMat2D` / 点对方向写反 | 对齐图整幅飞出画幅、有效区为空 | 记住：点对/上游矩阵都是**参考→当前**；插件内部求逆做 warp |
| 4 点填错一个，没填验证点 | 透视矩阵仍能精确拟合，图上“看起来对齐”，实际错 | 填 `ValidationPointText`（第 5 对） |
| 下游不吃 `ValidRegion` | 黑边被当缺陷，差分/Blob 整片报差异 | 把 `ValidRegion` 接下游 `MaskRegion`/`SearchRegion` |
| ReferenceImage 与 Image 尺寸不同 | 直接失败（v1 不缩放输出） | 先统一尺寸，或断开 ReferenceImage |
| 拿散焦图做基准点 | 点定位漂，残差大 | 先用「图像质量检查」拦掉散焦图 |
