# 可形变模板匹配 · 界面与编辑

本页说明配置界面的分区、字段与交互。界面设计基线见
`docs/UI设计基线/可形变模板匹配/design.html`（v0.1）。

## 1. 整体布局

- 左栏 368px 配置轨：算法 → 模板 → 查找参数 → 输出 → 怎么用；
- 左栏底部固定「学习模板 / 清除模板」操作栏，滚动参数时始终可见；
- 右栏：参考图只读预览 + 匹配结果表 + 状态栏。

左栏顺序是刻意设计的：**先选算法，再学习**。算法是创建期选择，先学局部再切平面会白跑一次。

## 2. 算法卡片

两张卡片二选一：

| 卡片 | 适合 | 专有输出 |
| --- | --- | --- |
| 局部非刚性 | 柔性/形变物体 | `DeformedContours`、`RectifiedImages` |
| 平面透视 | 倾斜的平面目标 | `HomMat2D` |

切换算法会：

- 隐藏/显示「平滑度」（仅局部）；
- 切换结果区详情（局部显示轮廓段数与校正图张数；平面显示 `HomMat2D`）；
- 把状态改成「参数已改 · 需重新学习」（因为模型类型变了）。

## 3. 模板区

### 3.1 模板来源

模板有三个来源，优先级从高到低：

| 来源 | 选择位置 | 真源 | 适用 |
| --- | --- | --- | --- |
| 方案资产 | 配置窗口顶部资产下拉 | 方案 `Assets\Templates\*.json` | 产线/多人共用，需版本、冻结、归档 |
| 本地模板文件 | 左栏「本地模板文件」 | 磁盘上的 `DeformableTemplateEntry` JSON | 离线调试、外部交接 |
| 内嵌模板 | 左栏「学习模板」 | `.vms` 里的 `TemplateJson` | 单机小方案、向后兼容 |

规则：

- **资产优先于本地文件，本地文件优先于内嵌**；同时配置时只认优先级最高的那个。
- 资产模式下「学习模板」禁用，本地文件输入也禁用；要改模板，先在顶部下拉选「（不使用资产）」。
- 本地文件模式下学习同样禁用；点「清除」清掉文件路径后回到内嵌模式。
- 外部来源模式点「确定」时只把 ROI/算法/参数等元数据写回 `TemplateJson`，模型 base64 留在资产/文件里，避免 `.vms` 重复膨胀。
- 因此从外部来源切回内嵌模式后状态会显示「未学习」：需要重新学习，或重新选择资产/本地文件。
- 资产/文件里的 `LearnedAlgorithm` 必须与上方算法卡片一致；不一致运行期会明确失败，不会静默换算法。

### 3.2 参考图

- 填绝对路径，点「载入」；
- 只用于学习/重学；运行期读模型，不需要参考图；
- 路径不存在时预览区显示空态，状态栏报「参考图不存在」。

### 3.3 ROI 形状

支持三种：

| 形状 | 字段 | 说明 |
| --- | --- | --- |
| 矩形 | 中心行/列、角度、半长、半宽 | 最常用 |
| 圆 | 中心行/列、半径 | 角度与第二半轴自动隐藏 |
| 椭圆 | 中心行/列、角度、长半轴、短半轴 | 适合拉长的目标 |

注意 HALCON 的 `rectangle2` 半长沿 column 轴（phi=0 时），不是 row 轴；填反会得到旋转 90° 的 ROI。

### 3.4 掩膜

- 「涂抹掩膜」用于挖掉反光/会变化的区域；
- 「清除」清空掩膜；
- 掩膜状态显示「未设置 / 已设置」；
- 非对称掩膜会改变模板域重心，原点补偿会按实际重心计算；
- v1 画布只读预览，涂抹编辑器在后续批次提供；掩膜字段与学习逻辑已经就绪。

### 3.5 学习/清除

- 未学习时按钮显示「学习模板」；
- 已学习后显示「重新学习」；
- 资产/本地文件模式下按钮禁用，必须先切回内嵌模式；
- 清除模板只清模型与结果，不清 ROI/参考图；
- 外部来源模式下按钮显示「清除内嵌」，只清 `.vms` 里的内嵌模型，运行期仍从资产/文件读取；
- 学习成功后状态栏显示算法与模型大小。

## 4. 查找参数区

这些参数**运行期立即生效**，改了不需要重学：

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| 角度起点（度） | -30 | 搜索范围起点 |
| 角度范围（度） | 60 | 从起点开始的范围；0 表示只搜起点角度 |
| Row 缩放下限/上限 | 1 / 1 | 行方向缩放范围 |
| Col 缩放下限/上限 | 1 / 1 | 列方向缩放范围 |
| 平滑度 | 11 | 仅局部；HALCON 典型 11，最小 3 |
| 分数下限 | 0.5 | 低于它不算命中 |
| 最大命中数 | 1 | 1~100 |
| 最大重叠 | 0.5 | 去重阈值 |
| 搜索激进度 | 0.9 | 越大越快、越容易漏 |

「使用极性」是创建期参数：改了会提示重新学习。

## 5. 输出区

- 运行显示窗口：0=不发布，1~9=主界面视图；
- 端口摘要：公共端口 + 局部/平面专有端口；
- 平面 `HomMat2D` 为 9×N；局部 `RectifiedImages` 每命中一张；
- `DeformedContours` 是扁平 XLD 数组，每命中多段，`CountObj` 不等于命中数。

## 6. 右栏

### 6.1 参考图预览

- `ImageReadOnly` 常驻，只读；
- 预览图由参考图 + ROI 轮廓合成，ROI 改数值后即时刷新；
- 「适应」= FitToWindow；「1:1」= FitToImage；
- 无参考图时显示空态覆盖层，不折叠画布控件。

### 6.2 匹配结果表

| 列 | 含义 |
| --- | --- |
| # | 序号（按分数降序显示） |
| Score | 分数 0~1 |
| Row | 中心行（亚像素） |
| Column | 中心列（亚像素） |

- 表格按分数降序显示，最高分行浅蓝底；
- 端口数组仍保持 HALCON 返回顺序，不保证分数降序；
- 局部模式详情显示 `DeformedContours` 段数与 `RectifiedImages` 张数；
- 平面模式详情显示 `HomMat2D` 长度与反推说明。

### 6.3 状态栏

- 圆点颜色：绿=Info，橙=Warning，红=Error；
- 左侧是 `StatusMessage`；
- 右侧是模型状态与当前算法。

## 7. 五态

| 状态 | 视觉 |
| --- | --- |
| 默认 | 白底 + 1px 边框 |
| 悬停 | 边框加深 + 浅底 |
| 焦点 | 主色边框 + 3px 焦点环 |
| 禁用 | 灰底 + 45%~55% 不透明 |
| 错误 | 红边 + 红底 + 原因文案 |

过渡统一 150ms。

## 8. 窄档

640 宽时：

- 左栏 300px；
- 结果区单列，详情在表格下方可滚动；
- 工作区提示与状态胶囊隐藏，状态栏保留。

## 9. 设计契约

- `DataContext` 是插件实例；
- 数值用 `NumericBox` + 校验规则；
- 预览用 `ImageReadOnly`，不折叠；
- 结果表用 `ListView+GridView` + `GridListViewStyle` + `GridViewRowPresenter`；
- 颜色只引 `Dialog*` / `PluginPreview*` 令牌，视图零十六进制。
