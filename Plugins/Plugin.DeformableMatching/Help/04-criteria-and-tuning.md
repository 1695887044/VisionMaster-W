# 可形变模板匹配 · 判定与调参

## 1. 先选对算法

| 现象 | 更合适的算法 |
| --- | --- |
| 目标会弯、会皱、会被局部拉伸 | 局部非刚性 |
| 目标整体是平面，但被斜着拍 | 平面透视 |
| 目标只是平移/旋转/等比缩放 | 现有「模板匹配」 |
| 目标被遮挡且形变很大 | 局部非刚性 + 降分数下限 |
| 目标只有很窄的一条边 | 两种都不适合，先用预处理增强 |

## 2. 分数下限

- 起步建议 0.4~0.7；
- 分数太低会把背景/相似纹理当目标；
- 分数太高会在强形变/低对比时漏检；
- 分数是“模型点被找到的比例”，不是概率。

## 3. 角度范围

- 先给一个合理范围（例如 ±15°），不要一上来 -180~180；
- 范围越宽，创建/查找越慢；
- 查找范围必须落在创建期能表达的范围内；本插件创建期不读角度上限，
  查找期直接传实际范围，所以改角度不需要重学；
- 但**换算法**或改 ROI 仍然要重学。

## 4. 缩放范围

- 默认 1/1（不搜缩放）最快；
- 需要搜缩放时，先给 0.9~1.1 这类窄范围；
- `ScaleRMin/ScaleCMin` 是创建期参数，改了下限要重学；
- `ScaleRMax/ScaleCMax` 是查找期参数，改了立即生效。

## 5. 平滑度（仅局部）

HALCON 的 `deformation_smoothness`：

- 最小 3；
- 典型 11；
- 越大越“刚”，越小越能贴合强局部形变；
- 21 适合只有很小全局形变的场景；强弯曲/褶皱建议先试 11，再往 3 方向调。

## 6. 最大命中数与重叠

- `MaxMatches=1` 适合单目标定位；
- 多目标时按实际数量给上限；
- `MaxOverlap` 控制去重：太大会把同一目标报两次，太小会把相邻目标合并掉；
- 单目标场景建议 0.3~0.5。

## 7. 搜索激进度

- 0.9 快，但可能漏；
- 0.7~0.8 更稳；
- 漏检优先降激进度，不要先改分数。

## 8. 局部 vs 平面的输出差异

| 输出 | 局部 | 平面 |
| --- | --- | --- |
| `Score/Row/Column` | 有 | 有（Row/Column 由 HomMat2D 反推） |
| `Angle` | 无 | 无（本插件不声明） |
| `Scales` | 无 | 无（本插件不声明） |
| `DeformedContours` | HALCON 直接返回 | 模型轮廓投影 |
| `RectifiedImages` | 每命中一张 | 空 |
| `HomMat2D` | 空 | 每命中 9 个 double |

## 9. 性能

- 形变匹配比 shape matching 重，尤其是全角度/全缩放；
- 先用小 ROI、窄角度、1/1 缩放把流程跑通；
- 再按现场需求扩范围；
- `NumLevels` 越大越快但可能漏小特征；先 0（auto），再按实测调；
- `MaxMatches` 越大越慢；
- 不要用“假 timeout”掩盖慢查询，先量再调。

## 10. 验收口径

与 HALCON 同进程参考实现逐项比对：

| 项 | 容差 |
| --- | --- |
| `MatchCount` | 相等 |
| `Score` | ≤ 1e-6 |
| `Row/Column` | ≤ 1e-3 px |
| `DeformedContours` 点数/坐标 | ≤ 1e-6 |
| `HomMat2D` | 逐值 ≤ 1e-9（同模型/同参数） |
| 派生 `Row/Column` | ≤ 1e-3 px |

平面 11 张刹车盘图必须 11/11 命中数一致；局部合成形变序列必须全部在容差内。

## 11. 反向断言

只对拍“两边都命中”不够，必须证明“两边都会变”：

- 模板 0°、搜索图旋转 30°；
- 查找角度范围 0/0 → 参考实现与插件都必须 0 命中；
- 查找角度范围 -180/180 → 两边都必须 ≥1 命中。

## 12. 调参记录

每次改参数请记录：

- 算法、ROI、掩膜；
- 角度/缩放范围；
- 平滑度、分数、最大命中数、重叠、激进度；
- 命中数、最高分、耗时；
- 参考实现是否一致。

没有记录的“调好了”无法复现，也无法判断是参数还是代码的问题。
