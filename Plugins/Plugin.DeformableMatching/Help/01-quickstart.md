# 可形变模板匹配 · 快速开始

本插件封装 HALCON 的两类可形变模板匹配：

- **局部非刚性**（`LocalDeformable`）：物体被局部拉伸、弯曲、挤压时仍能定位；
- **平面透视**（`PlanarUncalibDeformable`）：平面目标被倾斜/透视拍摄时，估计单应矩阵。

一个步骤只保存一个模板；模型随方案（`.vms`）落盘，运行期不需要参考图。

## 1. 适用场景

| 场景 | 建议算法 |
| --- | --- |
| 柔性材料、橡胶件、纸张、布料、变形标签 | 局部非刚性 |
| 倾斜安装的平面件、铭牌、PCB 局部、刹车盘端面 | 平面透视 |
| 只有平移/旋转/等比缩放的刚性件 | 用现有「模板匹配」插件更轻 |
| 需要角度/缩放倍率端口 | 用现有「模板匹配」；本插件局部模式不返回角度/缩放 |

## 2. 五分钟走一遍

1. 在算子工具箱拖入「可形变模板匹配」。
2. 打开配置界面，左栏最上方先选算法：
   - 局部非刚性：适合会弯/会皱的目标；
   - 平面透视：适合倾斜的平面目标。
3. 在「模板」区填参考图绝对路径，**或**从下面的「图像资产」下拉选一张（资产优先于路径，换机器不会断），点「载入」。
4. 选 ROI 形状（矩形/圆/椭圆），填：
   - 中心行、中心列；
   - 角度（度）；
   - 半长/半宽（圆时只填半径）。
5. 点底部「学习模板」。状态胶囊从「未学习」变「已学习」。
6. 回到流程，把上游图像接到 `Image` 端口。
7. 运行。结果表显示 `# / Score / Row / Column`，状态栏给出命中数与最高分。

## 3. 状态胶囊

| 状态 | 含义 | 下一步 |
| --- | --- | --- |
| 未学习 | 还没有模型 | 填 ROI 后点「学习模板」 |
| 已学习 | 模型与当前创建期参数一致 | 可以直接运行 |
| 参数已改 · 需重新学习 | ROI/掩膜/算法/层数/极性/ScaleRMin/ScaleCMin 改过 | 点「重新学习」 |
| 参考图不存在 | 路径无效 | 检查路径或重新选择参考图 |

查找参数（角度范围、缩放上限、平滑度、分数下限、最大命中数、最大重叠、搜索激进度）
改了**不需要**重新学习，运行期立即生效。

## 4. 第一次运行前检查

- 上游图像已连到 `Image`，且不是空图。
- 参考图路径存在；模型已学习。
- `Algorithm` 与学习时一致（换算法必须重学）。
- ROI 在参考图范围内，面积大于 0。
- 分数下限不要设得过高（建议 0.4~0.7 起步）。

## 5. 结果怎么看

- `MatchCount`：命中实例数。
- `Score / Row / Column`：最高分实例的分数与中心（亚像素）。
- `Scores / Rows / Columns`：全部命中，顺序保持 HALCON 返回顺序。
- `DeformedContours`：形变后的轮廓（扁平 XLD 数组，每命中多段；`CountObj` 不等于命中数）。
- `HomMat2D`：仅平面模式，每命中 9 个 double。
- `RectifiedImages`：仅局部模式，每命中一张校正图。
- `MeasureImage`：标注图；无命中时输出原图，原因看 `ErrorMessage`。

## 6. 常见失败提示

| 提示 | 原因 | 处理 |
| --- | --- | --- |
| 输入图像为空或未初始化 | 上游没图 | 检查上游步骤 |
| 模板还没学习 | `Model` 为空 | 打开配置界面学习 |
| 模板是用「X」学的，当前算法是「Y」 | 换算法没重学 | 重新学习 |
| 模板加载失败（载荷损坏） | base64 损坏/版本不兼容 | 重新学习 |
| 未找到目标 | 分数不够/角度缩放范围太窄 | 降分数下限或扩大范围 |
| ROI 不在参考图内或面积为 0 | 中心/半长填错 | 检查 ROI 数值 |
