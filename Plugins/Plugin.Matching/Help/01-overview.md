# 模板匹配（Shape-based 定位）

> 分类：定位 ｜ 来源：插件 Plugin.Matching

多模板库 + 配方驱动定位：按产品型号选模板，输出亚像素位姿与**位姿归一化的图像**，
支持旋转 / 缩放搜索与涂抹掩膜编辑。

## 这个算子做什么

- **一个实例 = 一个模板库**：库里可以有多个条目（一条 = 矩形 / 圆 / 椭圆区域 + 涂抹掩膜 + 提取参数 + 模型），
  条目上限 20 条（`.vms` 体积防护）；
- 运行时按 `RecipeName` 端口选条目——该端口可以接上游变量或上位机写入，
  **换产品型号不用改流程**；端口没连或为空时用界面上「设为默认」的那条；
- 名字不在库里时步骤失败，并把库里现有的名字列在日志里（避免"名字打错了却以为是没找到目标"）。

## 两个关键设计（决定了怎么用）

1. **模型原点锚定在你框的中心**：学习时会先在参考图上自匹配一次，把模型原点锚回你画的区域中心。
   所以输出的 `Row` / `Column` 就是"你框的中心"的坐标，矩形 / 圆 / 椭圆三种区域口径一致；
2. **`AlignedImage` 把目标搬回学习时的位姿**（刚性变换到标准位置与 0°）：
   下游所有按固定坐标画框的算子（裁剪、Blob、卡尺、胶路检测……）不用改任何参数就能直接吃这张图。

## 端口

| 方向 | 端口 | 说明 |
| --- | --- | --- |
| 输入 | `Image` | 待定位的图像 |
| 输入 | `RecipeName` | 配方名 / 产品型号；为空用「默认模板」；名字不在库里 → 步骤失败 |
| 输出 | `Score` / `Row` / `Column` / `Angle` | **最高分实例**的分数、中心行/列（亚像素）、角度（度） |
| 输出 | `MatchCount` | 命中实例数（已按 `MaxOverlap` 去重） |
| 输出 | `MatchedTemplate` | 本帧实际使用的模板名（配方追溯用） |
| 输出 | `Rows` / `Columns` / `Angles` / `Scores` / `Scales` | **全部实例**的数组，按分数从高到低逐项对齐 |
| 输出 | `MeasureImage` | 标注图：原图 + 命中实例的模板轮廓 + 位姿 + 判定文字 |
| 输出 | `AlignedImage` | 位姿归一化图像（目标在标准位姿）；`OutputAlignedImage` 关闭时输出空 |

> 标量端口（`Row` 等）= 最高分那个实例，数组端口 = 全部实例。只定位单目标时用标量端口最省事。

## 关键参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `MinScore` | 0.5 | 分数下限，低于它的命中不算找到（shape matching 的工业常用起点） |
| `MaxMatches` | 1 | 最多输出几个实例（1 = 单目标，绝对多数场景） |
| `MaxOverlap` | 0.3 | 两个命中区域允许的最大重叠比例（去重用，0~1）——同一目标别报两次 |
| `Greediness` | 0.8 | 搜索激进程度（0.1~0.9）：越大越快、越容易漏 |
| `DisplayViewIndex` | 1 | 标注图发布到主界面几号视图窗口（1~9），0 = 不发布 |
| `OutputAlignedImage` | true | 是否输出 `AlignedImage` |
| 每条目的极性 | 使用极性 | 「使用极性 / 忽略极性」，作用于当前编辑的库条目 |
| `TemplateLibraryJson` / `DefaultTemplateName` | — | 模板库与默认模板名，由配置界面维护，不建议手改 |

## 失败语义

输入为空、模板未学习、未知配方名、未找到目标 —— 都判**失败**（下游拿不到位姿无法继续）。
标注图仍然输出：未找到目标时是"原图 + 红字原因"，产线上要能当场看到现场。

## 典型用法

1. 采一张**良品图**，在配置界面里画一个框住特征（或整个工件）的区域；
2. 需要忽略干扰时用涂抹掩膜把要忽略的部位涂掉（比如会变的丝印、反光点）；
3. 点学习（会自匹配一次并锚定原点）；
4. 给这条产品型号起个名字加入库，点「设为默认」，或用 `RecipeName` 端口在运行时切换；
5. 产线上把 `Row` / `Column` / `Angle` 交给下游（画框、机器人取料），或直接把 `AlignedImage`
   交给需要固定坐标的算子。
