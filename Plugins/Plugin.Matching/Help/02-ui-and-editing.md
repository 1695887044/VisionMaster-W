# 模板匹配 · 界面与画布编辑

> 分类：定位 ｜ 来源：插件 Plugin.Matching

这一页讲**配置窗口里每一格在哪、画布怎么操作、模板库怎么管**。
参数含义与调法在第四页，端口与参数清单在第三页，报错文案在第五页。

## 一、界面地图（左列卡片，从上到下）

| 卡片 | 控件 | 作用 |
| --- | --- | --- |
| ① 模板 | 模板列表（每行显示条目名）、`新增` / `删除` / `设为默认` | 库就是这一列；选中项就是当前编辑条目，行名旁有状态徽标 |
| ① 模板 | 数值行「配方名」 | 写的是**当前条目的名字**（`RecipeName` 端口按它选模板），改完列表立刻刷新 |
| ① 模板 | 「参考图（可选）」路径框 + `载入` | 单独调模板时才填路径；连了上游点下方「执行」把图带进来更快 |
| ① 模板 | 「当前模板区域」+ `创建模板` / `清除` | 显示区域摘要（形状 + 尺寸），`创建模板` 就是"学习"这个动作 |
| ① 模板 | 「模板预览（绿色 = 模型记住的特征边）」 | **判断模板学得好不好就看这张图**：绿线稀稀拉拉 = 区域选错了 |
| ① 模板 | 折叠区「涂抹编辑」：涂抹模式 / 笔刷半径(px) / `清除涂抹` | 把"会变的部分"从学习里挖掉；提示原文是"涂抹后要重新点「创建模板」才生效；掩膜随方案保存，重开配置界面会以橙色显示。" |
| ② 提取参数 | 最小/最大角度(度)、角度步长(度)、梯度阈值、使用极性、启用缩放匹配 + 最小/最大比例(倍)、金字塔层数 | **创建态**：卡片顶上写着"改任何一项都需要重新点「创建模板」，徽标会转橙提醒" |
| ③ 匹配参数 | 分数下限、匹配数上限、最大重叠、搜索激进度 | **运行态**：卡片顶上写着"改完立即生效，不用重新创建模板" |
| ④ 输出 | 「配方名端口」链接框、「运行显示窗口」下拉、`输出位姿归一化图像（AlignedImage 端口）` | 决定 `RecipeName` 接谁、标注图发到几号窗口、要不要多付一次整图重采样 |
| 怎么用 | 三段说明 | 建模顺序、分数下限的用法、"执行内核已接通"（连线就能跑） |
| 右列 | 「参考图像」画布 + 提示"右键 → 新建矩形/圆形/椭圆，框住模板特征" | 画框、涂抹、看预览都在这块；下方信息栏三色：绿=正常、橙=还能继续、红=失败 |

## 二、把图弄上屏（没图没法画框）

两种方式任选其一：

- **推荐**：流程里把上游图像接到 `Image` 端口，然后**试运行一次**——画布会自动显示上游那张图
  （插件盯的是端口值变化，试运行桥接进来的图也算，信息栏会说"已显示上游图像…"）；
- 流程还没搭：在「参考图（可选）」填一张本地图片的完整路径，点 `载入`。
  路径为空会说"还没有参考图路径：填一个图像路径后再点「载入」"，文件不存在会说"参考图不存在：…"。

> **参考图路径只在配置态用**（画框、重学、预览），运行期一律吃 `Image` 端口的图。
> 它是**本机绝对路径**：换电脑后路径失效不影响已学好的模板定位，只影响"重开界面时画布上有没有图"。
> 模型与掩膜都以 base64 存在方案里，所以拷给同事模板还在。

## 三、框选模板区域：这一步决定 80% 的成功率

在右侧画布**右键 → 新建矩形 / 圆形 / 椭圆**，框住目标上"**稳定、独特、跟着产品一起动**"的特征。

| 要求 | 为什么 | 现场怎么验 |
| --- | --- | --- |
| **有边界、纹理丰富** | 形状匹配比的是边缘：丝印字符、边角组合、安装孔位、螺栓阵列都是好特征 | 看左下角**模板预览的绿线密度** |
| **独特**（别处不长这样） | 相似特征会在图的别处也命中，表现成"位置跳到隔壁工件/背景花纹" | 拉远看整幅图：这个模样还有第二处吗 |
| **稳定**（每批都一样） | 会变的区域（活动件、遮挡物、反光面、换代的丝印版本）把分数拖成随机数 | 连跑 20 帧看 `Score` 的分散度，而不是看一帧 |
| **跟着产品一起动** | 框住背景 = 定位到背景上，产品偏了看不出来 | 手动把工件挪一点，`Row`/`Column` 必须跟着走 |
| **宁可框大一点** | 分数≈"对上了几成特征"：4 条特征边错 1 条掉到 75%，40 条错 1 条还剩 97.5% | 前提是**仍然独特**——大到把别的花纹罩进去反而是坏事 |

界面写的那句画框要领原文：「框住目标上稳定、独特、随产品一起动的特征（丝印、边角组合、安装孔位），
不要框到反光面或会变的区域。」

### 三条容易踩的画布口径

1. **一个条目只认一个区域**：画了第二个框，插件以**最新画的那个**为准（前一个作废）。
   想套两个特征就建两条条目，别在一个条目里画两框；
2. **`清除` 只清画布**：清掉的是画布上的框，条目里已学的模型和区域参数不变、运行照旧。
   真要撤掉这条模板，请在模板列表里选中它点 `删除`；
3. **三种形状的定位口径一致**：矩形看半长/半宽、圆看半径、椭圆看两个半径，
   输出的 `Row`/`Column` 都是**你框的中心**。圆形区域只填 3 个数（第 4、5 个是占位 0），
   看方案 JSON 时别把 0 当成"半径 0"。

拖句柄的既有约定（跟全仓库一套，不用你记）：**未选中的区域一次手势就能拖**（控件在换绑活动对象后补发一次按下），
摘除活动对象的命中容差比 HALCON 手柄宽（屏幕上 14px），而**挑选其它对象的命中测试无容差**——
所以相邻框紧贴时不会误选，但空白处点一下就退出编辑，这是有意的。

## 四、涂抹编辑：把"会变的部分"从学习里挖掉

框里有反光面、会随批次变的丝印、旁边粘的标签时，别重画框——展开「涂抹编辑」：

1. 涂抹模式选**绘制涂抹**，用笔刷（半径 1~50 px，默认 10）把不想学的部分涂成橙色；
2. 涂多了切**擦除涂抹**找回来（红色），彻底重来点 `清除涂抹`；选**正常显示**回到普通编辑态；
3. **涂完必须重新点 `创建模板`** 才生效——掩膜只是"下次学习要挖掉哪里"，改它徽标就会转橙；
4. 重开配置界面时掩膜会以橙色显示（随方案存盘，可继续编辑）。

三条判据：

- **有效排除域 =（绘制 − 擦除）∩ 模板区域**：涂在模板区域**外面**的部分不参与学习（也不报错），
  别指望"涂一大圈把整个工件圈掉"；
- **掩膜坐标是参考图的绝对坐标**：换参考图 / 上游换分辨率之前，插件会把当前涂抹按**旧图**坐标系写回条目，
  换图之后同样的数字含义就变了——**换图后要重新涂**，别看它还显示着就以为对；
- **验证有没有真挖掉**：看重学后信息栏的"载荷 … KB"和预览绿线。挖掉一大块反光面，载荷会明显变小、
  那块绿线会消失；载荷没变说明涂的位置压根没落在模板区域里。

## 五、模板库与配方的管理口径

- **上限 20 条**（方案体积防护：模型和掩膜都是 base64，整库随方案文件走）。
  满了点 `新增` 会提示"模板库已满（上限 20 个）——多产品大批量建议拆流程"，
  **这是建议拆流程，不是让你去改上限**；
- `新增` 自动起名"模板N"并规避重名；名字就是**配方键**（`RecipeName` 按它**逐字符**匹配，大小写与空格都算），
  改名立刻生效但上游给的名字要跟着改；长期方案是让上位机传字符串变量而不是手打；
- **每条模板各学各的**：② 提取参数（角度/缩放/步长/梯度/极性/金字塔）跟着条目走，
  产品 A 要 ±180°、产品 B 只要 ±5° 完全可以共存；③ 匹配参数（分数下限/匹配数/重叠/激进度）
  是**整个步骤共用一套**（运行行为，不分产品）；
- `设为默认` = 给没接 `RecipeName` 时兜底；**删掉当前条目时默认名自动顺延到库里第一条**（库空了就变空）；
  改条目名不影响已连的线（连线锚在端口上，条目名只是被查的键）；
- **徽标三态**：灰「未学习」→ 框区域、点 `创建模板`；绿「已学习」→ 可用；
  橙「参数已改·需重新学习」→ 再点一次 `创建模板`。**橙色时跑流程用的仍是旧模型**（不报错，所以容易被忽略）。

## 六、信息栏文案（配窗口里那一行）

| 文案（颜色） | 该做什么 |
| --- | --- |
| 请先在模板列表里新增一个条目（橙） | 先在 ① 区点 `新增` 再画框 |
| 请先在右侧图上右键 → 新建矩形/圆形/椭圆，框住模板特征，再创建模板（橙） | 还没画区域，画完再点创建 |
| 请先载入参考图像（或试运行把上游图带进来），再创建模板（橙） | 画布上没图，无法学习 |
| 创建模板失败：…（区域里特征太少？换一块纹理更丰富的区域试试）（红） | 先看后半句原文；九成是区域里没边（大平面/纯黑纯白）或梯度阈值填太高 |
| 模板库已满（上限 20 个）——多产品大批量建议拆流程（橙） | 删掉不用的条目，或按产品族拆成多个流程/多个步骤 |
| 没有可删除的模板条目 / 请先选择一个模板条目（橙） | 列表里先选中一条 |
| 还没有参考图路径：填一个图像路径后再点「载入」（橙） | 填路径，或直接试运行带图 |
| 参考图不存在：… / 参考图载入失败：…（红） | 路径打错了 / 文件被移动 / 格式 HALCON 读不了 |
| 已载入参考图 … / 已显示上游图像 …（绿） | 图已就位，接着右键画区域 |
| 模板「X」已学习：金字塔 N 层，角度 a~b°，…，载荷 K KB。左下角为模板预览（绿） | **这里的层数是模型实际生成的层数**；圆区域显示"半径 N px"，矩形/椭圆显示"宽×高 px" |
| 已删除模板「X」/ 默认模板已设为「X」…（绿） | 删掉的若是默认条，默认名自动顺延到库里第一条 |
| 模板已学习，但预览生成失败：…（红） | **模型已经学好了**，只是左下角那张预览图没画出来，可以照常运行 |

> 提示文案里偶尔出现"点「学习模板」"的字样，界面上的按钮实际叫 **`创建模板`**，是同一件事。

## 七、改完怎么落盘

点「确定」才写进方案：涂抹掩膜先写回当前条目，整库序列化进 `TemplateLibraryJson`，
默认名与 ③ 区参数一并落盘。只改画布不点确定 = 白干；
`载入` 参考图、切换条目这些动作不会污染已确认的数据（确认时存的是快照）。
