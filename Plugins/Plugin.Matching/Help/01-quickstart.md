# 模板匹配 · 快速上手

> 分类：定位 ｜ 来源：插件 Plugin.Matching

一句话：**一个步骤 = 一个模板库（上限 20 条），运行时按配方名换产品型号**，输出亚像素位姿
（`Row` / `Column` / `Angle`）与位姿归一化图（`AlignedImage`），支持旋转 / 缩放搜索与涂抹掩膜编辑。
换型号不改流程、不改配置——上游给个配方名就自动切过去。

## 一、这个算子做什么

- **学习**（界面按钮「创建模板」）：在一张良品图上框住"要认的特征"，插件把框内的**边缘特征**
  （哪里有明暗边界、边界朝哪个方向）做成形状模型，序列化成 base64 随方案存盘；
- **查找**（每帧一次）：取上游图转灰度，在图里找这组特征的组合，给出**中心行/列（亚像素）+ 角度（度）+ 分数（0~1）**，
  一次可以报多个实例；
- **两样附带产物**：`MeasureImage` 标注图（命中轮廓 + 判定文字，**失败也有**）、
  `AlignedImage` 位姿归一化图（把目标搬回学习时的位置与 0°，下游固定坐标的算子零改动直接吃）。

## 二、它比的是"形状"，不是"像素"

| 维度 | 形状匹配（本插件唯一的一条路） | 灰度 / 相关匹配 |
| --- | --- | --- |
| 记的东西 | 框内像素的**梯度**（边缘的位置与方向） | 框内每个像素的**灰度值** |
| 光照变化 | 整体变亮变暗、对比度漂移**照样找得到**（边的相对关系没变） | 亮一点分数就掉，必须重学或补光 |
| 旋转 / 缩放 | 学习时按角度（和缩放）区间**预先烤入变体**，查找即取 | 得自己逐级转，代价高 |
| 适合 | 有清晰边界的工件：丝印、孔位、边角组合、螺栓阵列 | 没有边界、只有明暗斑块的纹理（毛毡、雾面印刷） |

**本插件没有"灰度 / 相关匹配"的开关**（不存在 `create_ncc_model` 那条链路，界面与方案里都不会出现这个选项）。
三条推论：

1. 目标几乎没有边时，正确做法是在上游用「图像预处理」把边**造**出来（直方图均衡 → 二值化，
   把一块灰度差变成一条硬边界），再交给本算子学；
2. 要判**颜色**本身请接「区域颜色检查」`Image` / 「颜色序列检查」`Image`，别指望形状匹配区分红蓝；
3. 彩色图照样能定位：1 通道灰度、3 通道彩色、4 通道 RGBA/BGRA 都吃，内部统一转灰度后用，彩色信息不参与比对。

## 三、原理只有两阶段，参数也因此分两半

```
学习阶段（创建态）：缩减域 → 统一转灰度 → 按梯度阈值筛特征边 → 建金字塔
                  → 预先算好各旋转（和缩放）变体 → 原点锚定 → 存 base64 进条目
查找阶段（运行态）：取图转灰度 → 按配方名选条目 → 在条目烤入的角度/缩放区间里搜
                  → 结果天然按分数从高到低 → 按 MaxOverlap 去重 → 端口赋值
                  → 可选归一化图 → 标注图 → 发布视图
```

这条分界决定了怎么用：

- **② 提取参数**（金字塔层数、角度区间、角度步长、梯度阈值、极性、缩放）是**创建态**——
  改任何一项都必须**重新点「创建模板」**，界面上橙色徽标「参数已改·需重新学习」就是在提醒你，不重学不会报错；
- **③ 匹配参数**（分数下限、匹配数上限、最大重叠、搜索激进度）是**运行态**——改完立即生效、不用重学。

两个决定"输出坐标怎么读"的设计：

- **原点锚定在你框的中心**：`Row` / `Column` 就是"你画的那个区域的中心"，矩形 / 圆 / 椭圆三种区域口径一致
  （HALCON 默认原点与区域中心有 1~2px 系统性偏差，学习时已补偿掉）；
- **`AlignedImage` 只按最高分那个实例**做刚性变换把目标搬回学习位姿，画幅不变（同幅面输出）、出界填黑，
  下游按固定坐标画框的算子不用改任何参数。

## 四、建模七步（照着做）

1. 接好 `Image` 端口，**试运行一次**把上游图带进画布（流程没搭就在「参考图」填本地路径点「载入」）；
2. 模板列表点「新增」，把名字改成产品型号（这个名字就是**配方键**）；
3. 右侧画布**右键 → 新建矩形 / 圆形 / 椭圆**，框住"稳定、独特、跟着产品一起动"的特征，先看左下角预览绿线密不密；
4. 有干扰（反光、批次会变的丝印、旁边粘的标签）就展开「涂抹编辑」挖掉，**挖完再点创建**；
5. 按需要定提取参数——默认值通常就够，**唯一强烈建议改的是角度区间**（别偷懒留 ±180°）；
6. 点「创建模板」，读信息栏那行绿字：金字塔实际层数 / 角度区间 / 特征区域尺寸 / 载荷 KB；
7. 想长期用就点「确定」落盘（涂抹与整库序列化都在这一步写进方案文件）。

每步的判据与"没做对会怎样"写在第二页；学完必做的压力测试清单在第五页。

## 五、第一次上手的三条判据

| 检查什么 | 怎么看 |
| --- | --- |
| 学没学上 | 徽标是绿「已学习」，信息栏给出"金字塔 N 层…载荷 K KB"，且**特征区域不是 0×0** |
| 找没找到 | 跑一帧看 `MatchCount` ≥ 1、`Score` 与现场相符；标注图上绿轮廓**贴着目标**而不是贴在别处 |
| 坐标对不对 | 手动把工件挪一点，`Row` / `Column` 必须跟着走；框住背景的话它永远不动 |

## 六、典型用法 / 接线

```
── 引导链路（要原图坐标：抓取、贴装、机械坐标）
图像采集.Image ─────────────▶ 模板匹配.Image
变量/上位机（产品型号）─────▶ 模板匹配.RecipeName
模板匹配.Row / Column / Angle ▶ 坐标变换.PoseRow / PoseCol / PoseAngle  （位姿跟随 ROI）
模板匹配.Row / Column ──────▶ 坐标变换.PixelPointRow / PixelPointCol    （像素→机械）
模板匹配.Angle ─────────────▶ 坐标变换.PixelAngle（要机械角才接）
坐标变换.MechanicalX / MechanicalY ▶ 轴运动 / CSV记录 / 结果上报

── 固定坐标检测链路（要标准位姿图，最省事）
ROI.Domain_定位区 ──────────▶ 模板匹配.Image（只在 ROI 内搜，坐标仍是全局）
模板匹配.AlignedImage ──────▶ 卡尺测量.SrcImage / BlobDetect.SrcImage / Ocr.Image / CodeReader.Image
模板匹配.MeasureImage ──────▶ 结果显示.SrcImage（要再叠别的结果时；它已自带标注）

── 留数据、盯趋势
模板匹配.Score / MatchedTemplate ▶ CSV记录（分数格式 0.000，模板名看每帧实际用哪条）
模板匹配.MatchCount ────────▶ 条件步骤（≥1 才继续）
```

> 选型口诀：**要原图坐标 / 引导 → 接 `Row`/`Column`/`Angle` 给「坐标变换」；
> 内部 ROI 固定的算子（卡尺 / Blob / OCR / 读码）→ 接 `AlignedImage`。**
> 两条别混用——归一化图已经把目标搬走了，再拿 `Row`/`Column` 去对原图坐标就对不上。

`Image` 端口吃**带 domain 的图**：上游接「ROI」插件的 `Domain_ROI名`，HALCON 只在域内搜、域外直接不命中，
而**返回的坐标仍是全局坐标**（下游一个都不用换算）——这是最划算的一次提速。

## 七、失败面一句话

四种情况判失败：输入图像为空 / 未知产品名 / 条目未学习或载荷损坏 / 未找到目标。
其中**只有"未找到目标"记 Warn**，其余记 Error。失败轮标量端口是 0、数组端口为空、`AlignedImage` 为空，
但 **`MeasureImage` 仍然有值**（原图 + 红字原因），可以接记录/存图留证。
全部原文文案见第五页。
