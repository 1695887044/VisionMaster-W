# 图像赋值 · 排错

> 分类：图像处理 ｜ 来源：插件 Plugin.ImageAssign

本页按**看到的现象**索引：错误原文（与源码逐字一致）→ 为什么 → 怎么改。
检索词提示：运行日志里本算子的行都以步骤实例名开头（形如 `主流程.图像赋值_0 …`）。

## 一、错误原文对照表

| `ErrorMessage` 上的那句话 | 为什么 | 怎么改 |
| --- | --- | --- |
| `输入图像为空或未初始化` | 上游没连图，或上游本轮产出的图是空的（上游失败时它的图像输出通常是空句柄） | 先确认上游那一步成功；本算子常常只是"替上游报错"的那个 |
| `目标变量名不能为空` | 变量名那一格没填、填的是空格，或连进来的文本输出本轮为空串 | 手打变量名；若由上游供名，确认那个字符串端口本轮有值且不是纯空格 |
| `当前执行环境不支持写入全局变量` | 执行上下文没有绑定全局变量写入能力（离线断言容器、简化构造的上下文一类）。**这是设计内行为、不是缺陷** | 在正式界面里跑正常流程；正式界面出现这句说明启动链没装配完整，按这句报修 |
| `找不到全局变量「X」，请先在变量管理里新建同名变量` | 变量没建。本算子**不会**自动建变量 | 到「变量管理」新建同名 `HImage` 全局变量，或把这里改成已有的名字 |
| `全局变量「X」的类型是 Y，无法写入 HImage（值 […]）` | 变量存在但声明类型收不下图像（只有 `HImage` 或 `object` 能收） | 把变量声明类型改成 `HImage`；或换目标变量 |
| `全局变量「X」不支持写入（该变量类型未实现可写契约）` | 那个变量类型本身不可写 | 换一个可写的全局变量 |
| `写入全局变量「X」失败` | 写入器返回失败但**没给出原因**时的兜底文案（原文里的 `X` 就是你填的名字，未 `Trim`） | 少见。先看上一行那批更具体的消息；仍只见到这句就把名字与类型一起核一遍 |

## 二、分诊：现象 → 先查哪一项

| 现象 | 先查 |
| --- | --- |
| 步骤红，`ErrorMessage` = `输入图像为空或未初始化` | 上游步骤的 `Success`。上游失败时先修上游，本算子的错误只是回声 |
| 步骤绿，但画面不刷新 | ① 图元绑的变量名与这里填的是不是**同一个**（大小写不敏感，拼写必须对）；② 图元绑的是**运行时变量**还是**全局变量**（两者同名也不是同一个东西）；③ 画面是否真在读这个全局变量 |
| 步骤绿、画面也没问题，但重启后画面空白 | 设计口径：图像变量的**当前值不落盘**，重启后为空，跑一轮流程才有图。不是丢数据 |
| 编译期报 `[参数缺失] … 必填参数 'InputImage' 未配置` | 图像口只能由链接提供：把上游图像输出连进来（不存在"手填一张图"） |
| 编译期报 `[参数缺失] … 必填参数 'VariableName' 未配置` | 参数面板从没点过「确定」：打开、填名字、点确定 |
| 报 `找不到全局变量「1485」` 这种"名字是个数字"的错 | 变量名那一行被挂上了"由上游提供**值**"的通用变量绑定 → 拿值当名字。断开那条连线、改成手打 |
| 写"成功"了，但值落到了别的变量里 | 名字打错且撞上一个 `object` 类型的已存在变量：本算子不校验"目标是不是图像变量"，只保证写入值的类型能塞进声明类型 |
| 画面上的图一直在，但内容跟着上游一起变 | 正常：写进去的是**引用**不是快照。需要冻结某一帧，应由上游产出新实例 |
| 想显示带标注的图，画面上却只有原图 | 上游换成「结果显示」的 `AnnotatedImage`；组态画面上的图元要的是全局变量，视图窗口它看不到 |
| 多路画面只有一路有图 | 一个实例只写一个变量。多路请放多个「图像赋值」，各自填各自的变量名 |

## 三、"画面卡顿 / 颜色不对"不归本算子

本算子**零 HALCON 调用**、不做像素转换：它只是把一个图像引用交给变量。
"Halcon 像素 → WPF 位图"的转换发生在显示端（组态取值出口那一处统一转换）。
所以图像显示的颜色、缩放、卡顿这类问题，请到组态画面/图元那一侧查，不要在这里找原因。

## 四、自查顺序（现场最快的一遍）

1. 本步骤 `Success` 是否为 `true`，`ErrorMessage` 有没有内容；
2. 有内容 → 对照第一节原文表，逐条处置；
3. 无内容（步骤绿）但画面无图 → 核变量名一致性、核作用域（全局 vs 运行时）、核是否刚重启（当前值不落盘）；
4. 画面有图但内容不对 → 核上游连的是哪一路图像输出，以及上游是否原地修改了同一实例；
5. 全都对不上 → 抓运行日志里以该步骤实例名开头的行（`已把图像写入全局变量 X` 或失败原因），连同
   「变量管理」里该变量的名字与类型一起提工单。

## 五、上线前自检（图像链路）

1. 每个目标变量在「变量管理」里**已事先建好**、类型是 `HImage`（或明确想用 `object` 收图）；
2. 每个「图像赋值」只写一个变量，多路画面是多个实例而不是一个实例改名字；
3. `VariableName` 这一行**没有**接"提供值"的通用变量绑定；
4. 需要"存图"与"上画面"两条路时，分别用「CSV记录」的图片端口与本算子，不要混用一个节点；
5. 想上带标注的图：上游是「结果显示」的 `AnnotatedImage`，不是原始采集输出。
