# ROI · 界面与画框

> 分类：常用工具 ｜ 来源：插件 Plugin.CreateRoi

这一页讲**配置界面长什么样、框怎么画、怎么改**：三种编辑入口（画布右键 / 拖拽句柄 / 参数微调数值框）、
画笔涂抹与擦除、掩膜预览与排除模式，以及 ROI 的命名规则。

## 一、界面布局

```
┌──────────────────────────────────────────────────────────────┐
│ 图像输入：图像路径 [🔗 链接上游的 SrcImage]   显示窗口 [不显示/窗口1…9] │
├──────────────┬────────────────────────────────┬───────────────┤
│ ROI 列表      │  画布（ImageEdit）              │ 参数微调       │
│ 名字  [形状]  │  右键 → 区域 → 新建矩形/圆/椭圆   │（选中后可编辑） │
│ 选中即联动    │  拖拽句柄粗调大小与角度           │ 每参数一个数值框 │
│ 删除 / 清空   │  涂抹 / 擦除 + 笔刷 + 清除涂抹    │ 中心行列/角度   │
│              │  原图 ○ 掩膜预览 ○  排除模式 □   │ 半长半宽…      │
└──────────────┴────────────────────────────────┴───────────────┘
```

- **底图从哪来**：「图像输入」那一行（界面上标签写的是"图像路径"）绑的就是 `SrcImage` 端口。
  在流程里**试运行一次**，上游图会自动显示到画布上；不试运行也可以手打/链接一个图像路径。
- **显示窗口**：下拉第 0 项是"不显示"（`DisplayViewIndex = 0`），往后 1~9 就是主界面的视图窗口号，**所见即所在**——选"窗口 1"就投进第 1 格。
- **左列是主区**（ROI 列表，下方接参数微调）。**未选中 ROI 时「参数微调」只剩标题一行**，这是正常的，不是控件坏了。
- 画布支持滚轮缩放、中键/拖动平移；框画在图外也没关系，运行时按实际有效域裁。

## 二、画框与编辑：三个入口，一个数据源

三种改框的动作**全部经由同一份 `RoiList`**（互相不直接对话），所以永远同步、不会出现"画布和列表说的不一样"。

| 入口 | 怎么用 | 适合什么 |
| --- | --- | --- |
| 画布右键 → 区域 → 新建 | 新建矩形 / 圆形 / 椭圆；新建即进列表并自动取唯一名 | 首次画框 |
| 拖拽句柄 | 选中框后拖动角 / 边 / 中心句柄 | **粗调**（实时跳动，参数框跟着变） |
| 参数微调数值框 | 选中 ROI 后逐个数值框精调 | **精调**（亚像素、固定角度、要复现的坐标） |

- **删除选中**：列表里选中后按 `Del`，或点「删除」按钮。
  **焦点在文本框里时 `Del` 不触发**（那是文本编辑键，会优先删字符），此时请用按钮。
- **清空**：点「清空」会弹**二次确认**（"该操作不可撤销"），不会一键抹掉辛苦画的框。
- **列表 ↔ 画布双向选中联动**：列表点一项 → 画布把句柄挂到对应的框上；
  画布点某个框 → 列表滚动定位到那一项；画布点空白 → 列表取消选中（参数微调随之收起）。
- **拖拽改大小的手感**：**未选中的框一次手势就能拖**（按下即换绑并补发"按下"给 HALCON），
  不需要"先点一下选中、再点一下拖"。活动框的摘除容差比手柄宽（14px），瞄偏一点也不会丢选中。
- **数值框的口径**：角度类按 4 位小数（弧度是小量），其余 1 位；小数点永远是 `.`（不受区域设置影响）；
  **非法输入直接按当前值还原显示**——不崩，也不会静默把值改成别的。
- **掩膜预览下改了参数延迟约 200 毫秒重算**（防抖）：拖拽时看到预览"慢半拍"是设计如此，别以为卡住了。

## 三、涂抹与擦除：用画笔修正 ROI

拖句柄只能改"规则形状"，不规则边界靠画笔。工具条三选一：**正常 / 绘制涂抹 / 擦除涂抹**，
外加「笔刷」半径（像素，只接受数字与小数点）与「清除涂抹」按钮。

| 动作 | 效果 | 显示 |
| --- | --- | --- |
| 绘制涂抹 | 涂到的地方**也算有效区**（并入 ROI） | 净涂抹（涂 − 擦）显示为橙色 |
| 擦除涂抹 | 涂掉的地方**从有效区里挖走**，且**不会出现在裁剪图里** | 用**红色细轮廓**标出（不是红填充，免得你以为又涂了一笔红的）；被挖空处露出底图 |
| 清除涂抹 | 一键置空涂抹与擦除两类，画布同步清除 | — |

**合并口径（铁律，配置预览与运行输出同一条）**：

```
合并有效区域 = (ΣROI ∪ 涂抹) − 擦除        （恒为正语义，不随排除模式反转）
```

- 这条区域就是 `MaskRegion` 端口的内容；擦除同样作用于**每一个 ROI 的裁剪域**
  ——擦掉的地方不会出现在 `Crop_名字` / `Domain_名字` 里（早期版本"只影响预览"，现在真的改输出）。
- **涂擦会随方案保存**：区域被编码成游程文本 `行,起列,止列;…`（超过 4KB 自动 GZip + base64，带 `gz:` 前缀）。
  数据损坏时按"无涂擦"降级处理，不会打断编辑、也不会报错。

## 四、掩膜预览与排除模式

- **「原图」/「掩膜预览」单选**：预览模式看到的与运行期产出的**同口径**（合并区域 → 掩膜 → 抠图），
  所以"预览里长这样，跑出来就这样"可以用来直接验收框画得对不对。
- ⚠ **掩膜预览显示的是抠图结果（原图 × 掩膜），不是黑白掩膜图**。想要黑白那张请去看 `MaskImage` 端口。
- **排除模式**（界面上写作"排除模式（ROI 外有效）"，参数名 `MaskInvert`）：勾选后 `MaskImage` 黑白反转——
  ROI 圈反而变黑、圈外保留。适合"这块是坏的/不要的，检测除它以外的所有地方"。
  改了立刻刷新预览（不需要重新试运行）。
- **注意 `MaskRegion` 不会跟着反转**：正语义只有一份，反转只发生在掩膜那一层（"反转"是视图，不是数据）。
- 抠图算法是 `原图 × 掩膜 ÷ 255`（彩色图先把掩膜合成三通道再乘），缩放因子固定 1/255，
  免得截断把有效区刷成一片白。

## 五、命名规则：名字就是下游端口的键

- 列表里显示的是 `名字  [矩形/圆形/椭圆]`（形状用中文名）。
- 名字决定端口名：`Crop_名字` / `Domain_名字` / `OffsetRow_名字` / `OffsetCol_名字`，下游按名引用。
- **重开配置再画不会撞名**：画布控件的命名序号每次打开配置都归零，所以本算子强制唯一名——
  撞名时自动取同词干现有最大序号 +1（`ROI_0`、`ROI_2` 在场 → 新框叫 `ROI_3`；无序号名"缺陷区" → "缺陷区_1"），并回写画布上的标签。
- **当前界面不能手改 ROI 名**（保证唯一性即可），语义命名是后续候选。
- **改名或删框会断开对应的连线**（动态端口按名字重建），改完记得重接；
  下游脚本里如果写死了端口名，也要一起改。

## 六、删掉 / 清空之后会发生什么

- 删除一个框 → 它的 4 个动态端口一起消失（`RoiList` 一变就重建端口表并把"名字+类型"快照写进步骤数据）。
- 若下游正连着这些端口，流程里那根线会断；**已保存的连线不会自动迁到别的端口**。
- `RoiCount` 相应减少（它是"本轮实际成功输出的裁剪图数"）。
- 涂抹/擦除**不随单个框删除**——它们是全局的两块区域，只有「清除涂抹」会置空。
