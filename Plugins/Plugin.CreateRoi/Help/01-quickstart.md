# ROI · 快速上手

> 分类：常用工具 ｜ 来源：插件 Plugin.CreateRoi

在图像上画一个或几个"**框**"（矩形 / 圆 / 椭圆，还可以用画笔涂抹与擦除修正边界），
告诉后续步骤"**只看框里的，框外的别管**"。它是"告诉算法**看哪里**"的算子——
配置期由人画好、固定的框；而模板匹配是"运行期由算法找出**目标在哪**"。两者常搭配：
先用 ROI 圈出工位区域，再在区域内做模板匹配，搜索更快也更稳。

## 一分钟理解它产出什么

画完框后，本算子对外交三类东西：

```
你画的框（矩形 / 圆 / 椭圆）+ 画笔涂抹 − 画笔擦除
        ↓ 合并口径：合并有效区域 = (ΣROI ∪ 涂抹) − 擦除
   ├── 每个 ROI 各自 4 个输出端口
   │     Crop_名字      裁剪图（图变小了，坐标系跟着搬走）
   │     Domain_名字    带 domain 的原图（图没变，坐标也没变）  ← 最常用
   │     OffsetRow_名字 / OffsetCol_名字   裁剪图原点在原图里的位置
   ├── 全局端口
   │     MaskRegion   合并有效区域（HRegion，恒为"哪里有效"的正语义）
   │     MaskImage    二值掩膜图（有效区 255、其余 0；排除模式下反转）
   │     RoiCount     本轮实际成功输出的裁剪图数
   └── 主界面视图窗口：合并掩膜合成图（一帧看清全部 ROI 与涂擦修正）
```

**记住一句话**：下游要"只看框里"，优先连 `Domain_名字`——坐标系一点没动，下游插件一个都不用改。
只有"必须把图裁小"（省算力、给脚本/导出用）才走 `Crop_名字`，而且**必须把两个 Offset 一起连上**。

## 第一次画 ROI（6 步）

1. **连输入**：把上游图像的输出（如 `图像采集.OutputImage`）连到本步骤的 `SrcImage`。
2. **试运行一次**：上游的图会自动显示到配置界面的画布上——没有底图就只能凭记忆画框，很容易画歪。
3. **画框**：在图上**右键 → 区域 → 新建矩形 / 圆形 / 椭圆**，圈出要分析的区域。
   新建的框自动进列表、自动取唯一名（名字就是下游端口的键，如 `ROI_0`）。
4. **调准**：选中框后拖句柄粗调；要精调（亚像素、固定角度）用列表下方的「参数微调」数值框，
   改数字和画布上的框是实时双向同步的。
5. **接下游**：按下游是哪种插件选路线（见坐标系与下游接线）——
   智能插件连 `Domain_名字`；脚本/导出连 `Crop_名字` + 两个 `Offset`；只要区域/掩膜就连 `MaskRegion` / `MaskImage`。
6. **设显示窗口 + 保存**：「显示窗口」下拉选主界面第几格（1~9，选"不显示"= 0 = 不发布），点确定。

## 典型接线

```
图像采集.OutputImage ──▶ ROI.SrcImage

【首选：零坐标换算】
ROI.Domain_焊盘区 ──▶ 模板匹配.Image          （返回的仍是全局坐标）
ROI.Domain_检测区 ──▶ Blob缺陷检测.SrcImage
ROI.Domain_标签区 ──▶ 卡尺测量.SrcImage
ROI.Domain_读数区 ──▶ 码读取 / OCR / 颜色检查.Image

【必须用裁剪图时：三条线一起连】
ROI.Crop_小图      ──▶ C#脚本 / 结果上报（只管手里这张图的下游）
ROI.OffsetRow_小图 ──▶ 下游（global_row = local_row + 本值）
ROI.OffsetCol_小图 ──▶ 下游（global_col = local_col + 本值）

【整图抠掩膜】
ROI.MaskRegion ──▶ Blob缺陷检测.MaskRegion   （限制检测区）
ROI.MaskImage  ──▶ 需要二值掩膜参与运算的下游
ROI.RoiCount   ──▶ 循环 / 计数的上界
```

## 三个最容易踩的点（先知道，细节在后面的页）

1. **只连 `Crop_` 不连 `Offset` 不会报错**，坐标会**静默**整体偏一个框左上角的距离。
   要么三条线一起连，要么改用 `Domain_` 路线。
2. **改名或删框会断开对应的连线**——动态端口是按 ROI 名字建的，改完要重接。
3. **`RoiCount` 是"成功数"不是"配置的框数"**：参数无效或被擦除涂光的框会被跳过（日志里有 Warn）。
   下游按它循环取数才不会越界。

## 什么情况下该用它 / 不该用它

| 场景 | 用什么 |
| --- | --- |
| 工位固定，只想看板上某一块 | **本算子**（画框最直观） |
| 目标会随产品移动、要先找出来 | 模板匹配 / 几何找圆等**搜索类**算子，再在本算子里圈定搜索区 |
| 要任意多边形轮廓 | 本算子只支持矩形 / 圆 / 椭圆三种参数化形状；不规则边界用「绘制涂抹」补、「擦除涂抹」挖 |
| 要"这块是坏的，检测除它以外的一切" | 勾选**排除模式**（只反转 `MaskImage`，`MaskRegion` 恒为正语义） |
| 要按灰度阈值自动生成区域 | 预处理 / Blob 的阈值分割，不是本算子（本算子的框全部由人画） |
