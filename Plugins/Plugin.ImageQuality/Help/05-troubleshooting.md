# 图像质量检查 · 排错

> 分类：图像处理 ｜ 来源：插件 Plugin.ImageQuality

## 报错原文与处理

### `输入图像未连接（Image 端口为空）。请接「采图」或「读图」步骤的输出。`

`Image` 端口没接，或上游这一步没产出图（采图失败/读图路径错）。
先看上游步骤的 `Success` 和 `ErrorMessage`，不要在本步骤反复调参数。

### `图像类型 {type} 不受支持；v1 只支持 byte / uint2（相机原始位深）。请在上游用「预处理」转成 byte 后再检查。`

输入是 `real` / `int4` / 其它位深。v1 不做静默转换（截顶会得到假指标）。
在上游插一个「预处理」，把图转成 `byte` 再接进来。

### `图像通道数为 {n}，v1 只支持 1（灰度）/ 3（RGB）/ 4（RGBA）。`

2 通道（某些相机 YUV 输出）或 5 通道以上。上游先统一成灰度或 RGB。

### `ROI 有效像素 {area} 小于下限 {minRoiPixels}，指标不可信。请扩大 ROI，或断开 Roi 端口按全图检查。`

ROI 太小或与图像不相交。两种处理：

1. 扩大 ROI / 挪到产品上；
2. 断开 `Roi` 端口，按全图检查（同时确认 `MinRoiPixels` 不是被填得过大）。

### `有效像素 {n} 小于下限 {minRoiPixels}，指标不可信。`

没有接 ROI，但图像自带域本身很小（上游裁过图）。同样：放大有效域或调低 `MinRoiPixels`（不建议低于 16）。

### `阈值区间非法（Min > Max）：对焦、曝光… 请修正参数后再运行。`

配置错误，不是图的问题。把对应的 `Min` 调到 `Max` 以下。
本插件**不会**自动交换两端——那会掩盖填错的事实。

### `直方图箱数 {n} 少于预期 {bins}（灰度类型 {type}）。`

极少见，通常意味着 HALCON 版本/类型行为异常。记录 `Details` 与图类型，交开发排查；
不要靠调参数绕过。

## 不报错但结果不对

### 对焦分一直很低，但图看起来清楚

先看 `ContrastScore`：

- 对比度也低 → 可能是低对比（光源衰减、雾状、镜头脏），不是散焦；
- 对比度正常 → 可能是纹理本身弱（大面积同色），Sobel 梯度天然低，`FocusRef` 需要按这个产品重标；
- 两者都正常但下游不稳 → 看 `ExposureRaw` 与 `Details` 的均值/范围。

### 曝光分一直 1.0，但图明显偏暗

`ExposureRaw` 只数**截断**（0 和满量程），不数“整体暗”。
如果画面整体偏暗但没有像素压到 0，曝光分仍会是 1.0。看 `Details` 里的均值/范围；
需要按亮度拦截时，用下游「比较」对均值做区间判断，或把光源调好再标定。

### 灰度图的 `SaturationRaw` 是 NaN / `SaturationScore` 是 0

预期行为。饱和度只对彩色图有意义，灰度图跳过。用 `HasColor` 区分：

- `HasColor=false` → 饱和度无意义，不要参与判定；
- `HasColor=true` 但 `SaturationScore` 很低 → 才需要查光源/白平衡/色彩增益。

### 分数长期顶在 1.0 或长期 0.2

参考值没标定。默认 `FocusRef=200` / `ContrastRef=128` / `SaturationRef=128` 只是起点。
按 04 页的流程，用良品批次的 P5 重标；换镜头/光源/曝光时间/产品都要重标。

### `pcb_focus` 上“单调性”断言失败

这套图是**过焦点扫描**：061 附近最清晰，两端都散焦。
全序列单调下降的判据不成立。以 061 为锚，看 `|i−61|` 的相关性，或分段看趋势。
这不是插件缺陷。

### 同一张图连跑两次，指标略有差异

本插件所有指标都是确定性的（直方图/梯度/均值），同一张图、同一 ROI 应完全一致。
如果出现差异，先确认：

- 上游图是不是每轮都变了（相机自动曝光/自动增益）；
- ROI 是不是被上游每轮重新生成且位置有抖动；
- 是否开了并行分支、上游共享了可变缓冲。

## 性能

v1 没有把 5MP 耗时写死成门禁。参考量级（单张、Debug、全图）：

- 对焦（real 转换 + Sobel）通常是大头；
- 直方图（byte 256 箱）很轻；uint2 65536 箱也不慢；
- 彩色图多一次 decompose3 + trans_from_rgb。

要提速：

1. **接 ROI**，只算产品区；
2. 关掉不需要的指标目前不支持（v1 四项全算）——如果现场只需要对焦，可以先用 ROI 把面积降下来；
3. 需要精确数字时用 Release 构建，并记录机器型号与 HALCON 版本。

## 什么时候该找开发

- `Success=false` 且 `ErrorMessage` 不在本页列表里；
- 同一张图、同一 ROI、同一参数，指标不稳定；
- `Details` 里的 P5/P95/均值明显违背肉眼（例如全黑图对比度却是 255）；
- HALCON 抛 `#` 开头的错误码（记录完整文案与图类型）。
