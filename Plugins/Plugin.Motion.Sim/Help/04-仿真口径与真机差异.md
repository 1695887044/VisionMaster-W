# 仿真口径与真机差异（哪些能验、哪些验不到）

## 一、仿真器认真模拟了什么

| 项 | 口径 | 为什么这样定 |
|---|---|---|
| 时间 | 单一虚拟时钟，1ms 一拍；轴位置按 `速度 × 拍长` 逐拍推进 | 触发时刻与图像必须严格对应，时钟分叉就没有"对应"可言 |
| 运动曲线 | 梯形加减速（加速段/匀速段/减速段），到位无超调 | 与真机差在整定，不差在"走没走到" |
| 到位判定 | 走完才置 `InPosition=true`、`Moving=false` | "下发 ≠ 到位"是这条产线最容易被写错、也最需要被验的语义 |
| 回零 | 八种方式逐种实现，回零期间 `Moving=true`，完成置 `Origin=true` | 「轴回零」步骤的等待/超时/取消路径要能被真跑 |
| 限位 | 按轴位置推导：越过软限位边界点亮 `PositiveLimit`/`NegativeLimit` | 硬限位停机路径要能被真触发 |
| IO | 输入由轴位置与工位状态**真推导**（滑台到位→对应传感器亮） | 随便翻转的假 IO 会把"接线错位"这类问题全掩盖掉 |
| 急停 | 仿真器侧也有急停态；触发后所有运动命令被拒 | 验"急停后必须先复位"的门禁 |
| 工件 | 有位置、有节拍、有计数，随轴动作移动 | 定位引导/触发时序要有对象可跟 |

## 二、仿真器明确不模拟的（不要拿它证明）

| 项 | 后果 |
|---|---|
| 伺服整定 / 跟随误差 | 真机上"到位后还在抖 20ms"的现象测不出来；`InPosition` 一到就是稳的 |
| 编码器噪声与量化 | 位置是干净浮点；0.01mm 级的抖动、丢脉冲测不出来 |
| 机械柔性 / 背隙 / 摩擦 | 反向间隙、过冲、爬行都测不出来 |
| 多轴插补 | 契约层未实现插补，仿真器也没有该通道 |
| 通信实时性抖动 | 上位机与仿真器走本机回环，RTT 稳定在亚毫秒；真机网口的抖动测不出来 |
| 热变形 / 温漂 | 长时间运行引起的坐标漂移测不出来 |
| 真实安全回路 | 急停是"软件态"，不涉及安全继电器与硬接线 |

## 三、"验得到"清单（这些才是本驱动的价值）

1. **命令语义**：未使能/未回零/正在运动时下发运动命令会被拒，且拒绝理由与真机口径一致。
2. **下发与到位的分离**：连发两条 Move，第二条必须在第一条完成后才被接受（基类门禁），
   而"第一条还没到位"这件事能通过 `poll` 看见。
3. **等待与超时**：回零/清报警的等待路径可被取消（急停打断 → `Canceled`，不是 `Failed`），超时 → `TimedOut`。
4. **限位停机**：让轴走到边界，`PositiveLimit` 点亮 → 基类判安全停机。
5. **多工位时序**：视觉触发、轴到位、IO 输出三者在同一条时间轴上对得上。
6. **故障恢复**：仿真器被杀 → 轮询失败 → 看门狗判失联 → 安全停机；重启后可重连，增量编码器要求重新回零。

## 四、与「虚拟运动卡（仿真）」的差异

| | 虚拟运动卡 | 本驱动 |
|---|---|---|
| 位置推进 | 轮询线程按 `PollIntervalMs` 推进（周期一变，速度就变） | 仿真器按固定 1ms tick 推进（周期只影响观测频率，不影响速度） |
| 加速度 | 忽略：速度直接到位 | 梯形加减速真算 |
| 回零耗时 | 固定 `SimulatedHomeDurationMs`（默认 200ms） | 按回零方式与行程真算 |
| IO | 可手工置位（`SetInput`） | 由世界状态推导，不可手工置位 |
| 轴数 | 固定 3/8/8 | 由 `hello` 决定 |
| 故障注入 | 卡内开关（`SimulateAlarm` 等） | 由仿真器侧注入（慢设备、断连、急停），驱动不提供开关 |

两条都要：虚拟卡快、无外部依赖，适合做单元级断言；本驱动慢一点，但能验跨进程闭环。

## 五、验收口径怎么定

一条"仿真通过"的结论必须写清三件事，否则不可采信：

1. **验的是哪一层**：命令语义 / 时序 / 坐标对应 / 异常恢复，四者不互相替代。
2. **期望值从哪来**：不能与生成端共用同一个常量（例如"200mm/s ÷ 5mm = 40 帧"这种自证）。
3. **失败长什么样**：断言必须能被反证——把仿真器改坏一处，对应断言必须红。

## 六、什么时候该上真机

出现下面任一情况，就别再靠仿真器下结论：

- 结论涉及"精度能否达到"（μm 级、重复定位精度）；
- 结论涉及"节拍能否达到"（真实加减速与整定时间占大头）；
- 结论涉及"长期稳定性"（温漂、磨损、丢步）；
- 结论涉及安全（急停链路、安全门、光栅）。
