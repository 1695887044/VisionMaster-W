# 结果显示 · 标注口径

> 分类：常用工具 ｜ 来源：插件 Plugin.ResultDisplay

这一页讲**口径**：接进来的值会画成什么、文字块的九宫格锚点/边距/字号到底怎么算、
NG 判定怎么比、以及"烧图"这件事的失败与降级策略。端口与参数清单见《端口与参数》。

## 值类型 → 怎么画

| 接进来的值 | 图上表现 |
| --- | --- |
| 数值 / 文本 / 枚举 / 布尔 / 时间 | 按「文字位置」选的锚点叠一行 `名字: 值单位`（**白色底框**，好认；默认左上角） |
| `bool` | 显示 `OK` / `NG` |
| 几何基元 `GeometryParam` | 点 = 十字、线 = 贯穿直线、圆 = 圆 + 圆心十字、椭圆 = 椭圆、轮廓 = 折线；一律**青色**，标签跟在图元旁（**不带底框**，免得白框盖住被测特征） |
| `HRegion` / `HXLD` / 其它 HALCON 对象 | 青色描边（`margin` 画法）画出原样 |
| `HTuple` | 按元素逐个格式化，最多 32 个，超出显示 `…(+n)` |
| `HImage` | **不支持**：写告警 + 图上一行提示（图像是底图，请连 `SrcImage`） |

空值只显示 `(空)`，且**不计入 `DisplayedCount`**。
几何项**恒青色**，不参与判定换色（判定换色只作用于文本项）。
色名是插件内部常量、白名单固定：几何 `cyan`、合格 `green`、不合格 `red`、提示 `orange`——
用户字符串**绝不会**被当成 HALCON 色名传下去（非法色名一律回落，见排障页）。

## 九宫格锚点：只管"文字块"，不管逐行

**为什么只给九宫格、不给逐行坐标**：现场的真实抱怨只有一个——文字块压住了要看的工件，
九宫格 3 下点完就能躲开。而逐行配像素坐标在**换相机分辨率 / 改 ROI 之后会静默错位**
（坐标还是老图的坐标），那是比"压住工件"更难发现的故障。真需要各自定位，
就把要单独放的结果项再接一个「结果显示」算子（各自一个角落）。

**水平口径**（三列，靠「对齐」实现，不是估宽度）：
- 左列：`col` = 边距，每行**左对齐**（左边缘贴边距）；
- 中列：`col` = 画布宽的一半，每行**居中对齐**；
- 右列：`col` = 画布宽 − 边距，每行**右对齐**（右边缘贴画布）。

所以选右/中列时是**每一行各自**右对齐/居中，长短不一的几行右边缘是齐的。
每行的像素宽度由 HALCON **实测**（不是按字符数估算）——等宽字体也有小数点、负号、中文的差异，
估算必然歪，歪的结果就是"贴边对不上、极端时整行推出画布"。量不到宽度时**退回左对齐并留一条告警**，
宁可贴边也不许丢字。

**垂直口径**（三带）：
- 上带：首行 `row` = 边距，往下按行距堆；
- 中带：**整块垂直居中**（上留白等于下留白）；
- 下带：保证**最后一行的底边**留一个边距。

垂直分量归"块"，所以**行数与行距由调用侧决定**（块高 = 行数 × 行距），烘焙件只看一行行独立文字。
文字块比画布还高（项特别多 + 字号特别大）时，块从所选带的起点溢出，**首行不会被推到画布外**——
首行通常是判定项，宁可下面的行看不见。真塞不下就调小字号或减少结果项。

**同一水平带的三个锚点首行 `row` 完全相同**：换水平列不影响垂直，换垂直带不影响水平列的 `col`。

**几何标签不受九宫格影响**：点/线/圆/椭圆旁那圈青色小字永远跟着图元走——
把它挪到角落就等于取消"这个数属于这条线"的对应关系。但**字号倍率照用**（放大是为了看清，
只放大角上的字等于没解决"看不清"）。

## 边距与字号

- **边距 `TextMargin`**：文字块到画布边缘的距离（0~4096）。`0` 与"填自动值"出的是**同一份结果**；
  自动值 = 取「画布高 × 2%」与 12 像素里的较大者。填具体数字就是把整块推离边缘（左右上下同一个数）。
- **字号 `TextScale`**：倍率 0.5~3.0，`1.0` = 按图高自适应（14~64 之间）。
  **行距跟着一起缩放**，几何标签一起放大。倍率不会越界：填 9 按 3.0 算、填 0.1 按 0.5 算、
  填非有限值按 1.0 算。它**只改字号、不改几何**——半径/圆心参数一字不动。

## 烧图与不烧图

本算子的产物是一张**新图**：`AnnotatedImage` 与底图**不是同一句柄**，两者都有效
（烧录不会把底图顺手释放）。这意味着——

| | 烧图（本算子） | 不烧图（窗口覆盖层那类） |
| --- | --- | --- |
| 缩略图 / 导出 PNG / 报警抓图 / 存图 | **都带标注** | 图一离开门窗就没标注 |
| 下游算子拿到的图 | 已是标注图（`AnnotatedImage`） | 需要下游自己再叠一遍 |
| 同一批标注 | 只画一次 | 若同时开覆盖层 = **画两遍（重影）** |
| 原底图 | **不被修改**（另出一张新图） | 通常也不改，但产物不是可存档的图 |

`DisplayViewIndex = 0` 是"烧图但不发布"：不抢占任何窗口、`IsDisplayed = false`，
但 `AnnotatedImage` 照算——下游「数据记录」仍能存出带标注的图。

**绘制顺序是固定的：图形（Shapes）→ HALCON 对象（Objects）→ 文字（Texts）**。
文字永远在最上层，不会被几何盖住；要改层序得改攒内容时的入列顺序，而不是改烘焙件。

## NG 判定怎么比

判定项**按 `Label` 匹配，找不到再按 `Id` 找一次**。命中 NG 值 → 判定项与所有文本项转红，否则全绿。

比对三路（与「结果上报」同一口径，另加两条）：
1. 两边都能当数字就**按数字比**（`21` 等于 `21.0`）；
2. 否则**按真假比**——NG 值认 `NG` / `OK` / `true` / `false` / `1` / `0`
   （`false` 与 `NG` 同义，这样"图上写着 NG、颜色却是绿的"这种自相矛盾不会出现）；
3. 再否则**按文本忽略大小写比**。

数字解析用**不变区域性**且**拒绝千分位**（`1,5` 不会被读成 `15`），不会被系统区域设置改掉结果。

## 元素上限与抽稀

- **`MaxDrawElements`（默认 300，夹取 10~2000）**：一轮最多画多少个元素。
  超限时**端口数据永远全量，只是不画完**——只画预算内的元素、`DisplayedCount` 只数真画进去的，
  文字标签仍按行给（截断说明那一行**不占**预算，否则这件事本身说不出来），并在图上写明"仅绘制前 N 个"。
- **轮廓抽稀**：`GeometryParam` 的轮廓点集超过 2000 点按等间隔抽稀（保留首末点），信息栏会写明抽稀后点数。
  `HXLD` / `HRegion` **不抽稀**——重生成会把多段轮廓并成一条折线，那是改形状不是省时间。
- **坐标钳制**：坐标分量钳进图幅（NaN / ±Inf 的项**整个不进绘制计划、不占预算**并留告警）；
  **半径原样保留**——钳半径是篡改数据不是保护。

## 失败与降级策略

- **宁缺显示不停线**：底图为空、读尺寸失败、组装标注失败、某一项画不出来，
  都只写告警并跳过；**本步骤仍算成功**。显示是给人看的，不能把一次成功的测量判成失败。
- **降级梯度**：烧录整体失败 → 降级为发布**原底图**（不带标注，用户至少看得到图）；
  连这都发不出去才静默。
- **单个元素失败只丢那一个**：非法色名回落、坐标非有限值跳过、空对象集静默跳过——坏元素不带走整张图。
- **坐标系**：全部图像像素系 `(Row, Col)`（**行主口径**：先给行再给列，`φ=30` 时 Δrow 与 Δcol 不是对调关系）；
  角度单位是**度**，椭圆进绘制计划时角度取反（`P[2]` 等于 `−Φ`）。
