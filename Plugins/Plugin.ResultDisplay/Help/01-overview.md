# 结果显示

> 分类：常用工具 ｜ 来源：插件 Plugin.ResultDisplay

把**任意算子的输出**汇总到一个算子里，**烧进图像像素**：数值 / 文本 / OK-NG / 几何基元 / 区域 / 轮廓都能标。
产出是一张**全新的标注图**（原底图不被修改），缩略图、导出图、报警抓图、数据记录存图**都自带标注**。

## 为什么需要它

多数算子只把结果写进自己的输出端口和信息栏，图上不留痕；纯计算类算子（几何计算、变量运算…）连图像出口都没有。
本算子补的就是这个口子：**流程末端接一个，整幅图连同所有结果一起存档/显示**。

关键差别：**烧图 vs 不烧图**。
- **烧图**（本算子做的事）：标注成为像素的一部分。缩略图、导出的 PNG、报警抓图、写进 CSV 记录的图，
  拿出去**都带标注**，且不需要查看端支持任何叠加层协议。
- **不烧图**（走显示发布的覆盖层通道）：标注只是窗口上飘一层，图存出去就没了；
  同一批标注"既烧像素又走覆盖层"还会画两遍（重影）。所以本算子**只烧录、不双发**——
  发布时随事件带出去的 annotations 一律为空（断言 `A1【D10 只烧录不双发】` 钉着这件事）。

原底图永远不动：烧录产出的是**一张全新的图**（`AnnotatedImage`），底图句柄在烧录后仍然可用，
上游或别的算子还能继续用它。

## 快速上手：5 步

1. **接底图**：把要画在哪张图上的输出连到 `SrcImage`（这是唯一一个必接的口）。
2. **加结果项**：配置里点「添加结果项」，一行 = 一个动态输入端口 = 图上一段标注。
   默认名字是 `结果1`、`结果2`…（内部端口名是 `r1`、`r2`…，界面上不暴露、也永不改）。
3. **取值**：行内点 🔗 连上游端口；没连线时可以直接手填常量（调试用）。
4. **格式与单位**：数值想截几位填 .NET 格式串（`F2` / `0.000`）；想带后缀填单位（`mm` / `°`）。
   本算子**只贴标签不换算**。
5. **选显示窗口**：`1~9` 发到主界面第几个图像窗口；填 `0` = **只烧录不发布**
   （不抢占窗口，标注图照样给下游/存图用）。

跑通后应该看到：所选窗口里那张图上有青色几何、带白底框的文字行；`DisplayedCount` 是**真的画进图里的项数**；
`IsDisplayed` 表示本轮是否发布了显示。

## 接线

```
图像采集.OutputImage ──▶ 结果显示.SrcImage
几何查找.Geometry ─────▶ 结果显示.r1        （青色画出圆/线/椭圆）
几何计算.Angle ────────▶ 结果显示.r2        （格式 F2，单位 °）
变量运算.Result ───────▶ 结果显示.r3        （判定项，NG 值 = NG）
结果显示.AnnotatedImage ─▶ 数据记录.图片      （存的图自带标注）
```

**要多窗口/多用途就这么接**：一个本算子只能发布到一个窗口；想同时看两个窗口就放两个本算子
（各自接同一批上游输出），其中一个把「显示窗口」设为 `0` 只出标注图给存图用。
