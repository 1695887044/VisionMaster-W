# 结果显示

把**任意算子的输出**汇总到一个算子里，**烧进图像像素**：数值 / 文本 / OK-NG / 几何基元 / 区域 / 轮廓都能标。
产出是一张**全新的标注图**（原底图不被修改），缩略图、导出图、报警抓图、数据记录存图**都自带标注**。

## 为什么需要它

多数算子只把结果写进自己的输出端口和信息栏，图上不留痕；纯计算类算子（几何计算、变量运算…）连图像出口都没有。
本算子补的就是这个口子：**流程末端接一个，整幅图连同所有结果一起存档/显示**。

## 输入

| 端口 | 说明 |
| --- | --- |
| `SrcImage` | 底图：结果画在哪张图上（**必接**，`HImage`） |
| `r1` `r2` … | 结果项动态端口（每加一行多一个）；类型不限，连什么显示什么 |

## 输出

| 端口 | 说明 |
| --- | --- |
| `AnnotatedImage` | 烧录后的标注图（全新图；可接「数据记录」的图片端口存图） |
| `DisplayedCount` | 本轮真的画进图里的结果项数 |
| `IsDisplayed` | 本轮是否发布了显示（显示窗口=0 / 无底图 / 发布失败 → false） |

## 值类型 → 怎么画

| 接进来的值 | 图上表现 |
| --- | --- |
| 数值 / 文本 / 枚举 / 布尔 / 时间 | 按「文字位置」那一节的锚点叠一行 `名字: 值单位`（白色底框，好认；默认左上角） |
| `bool` | 显示 `OK` / `NG` |
| 几何基元 `GeometryParam` | 点=十字、线=贯穿直线、圆=圆+圆心十字、椭圆=椭圆、轮廓=折线；一律**青色**，标签跟在图元旁（**不带底框**，免得白框盖住被测特征） |
| `HRegion` / `HXLD` / 其它 HALCON 对象 | 青色描边（`margin`）画出原样 |
| `HTuple` | 按元素逐个格式化，最多 32 个，超出显示 `…(+n)` |
| `HImage` | **不支持**：写告警 + 图上一行红字提示（图像是底图，请连 `SrcImage`） |

## 配置

| 项 | 说明 |
| --- | --- |
| 结果项 · 用 | 勾选才建端口、才参与显示 |
| 结果项 · 名字 | 图上那行字的冒号左边、信息栏的标签。**改名字不会断连线**（连线锚在内部固定 Id 上） |
| 结果项 · 取值 | 行内点 🔗 连上游端口；没连线时可直接手填常量（调试用） |
| 结果项 · 格式 | .NET 格式串（`F2` / `0.000` / `HH:mm`）；留空 = 数值最多 4 位小数、不留末尾 0 |
| 结果项 · 单位 | 后缀（`mm` / `°` / `ms`）。**只贴标签不换算**——单位换算请在产出该数值的算子里做 |
| 显示窗口 | `1~9` = 发布到主界面第几个图像窗口；`0` = 只烧录不发布（不抢占窗口，标注图照样给下游/存图用） |
| 图上叠字 | 取消勾选 = 图上只画几何/区域/轮廓，文字仍进缩略图信息栏 |
| 判定项 / NG 值 | 按哪一项决定整幅文字颜色：命中 NG 值 → **红**，否则 → **绿**。留空 = 不判定（一律绿） |
| 九宫格（文字位置） | 文字块落在画布哪个角落：左上 / 中上 / 右上 / 左中 / 居中 / 右中 / 左下 / 中下 / 右下。**默认左上** = 老版本位置 |
| 边距 | 文字块到画布边缘的距离（像素，0~4096）。**0 = 自动**（取「画布高×2%」与 12 像素里的较大者） |
| 字号 | 字号倍率 0.5~3.0，`1.0` = 按图高自适应（14~64 之间）。**行距跟着一起放大**，几何标签也一起放大；倍率本身不越界（填 9 按 3.0 算、填 0.1 按 0.5 算） |
| 绘制上限（高级） | 一轮最多画多少个元素（10~2000），防大轮廓点集拖慢烧录；超限只画前面的并在图上写一行提示 |

### 文字位置怎么定

- **九宫格管的是"文字块"整体**：那些数值/文本行按行距堆成一块，整块搬到你选的角落。
  选右/中列时**每一行各自右对齐/居中对齐**（宽度由 HALCON 实测，不是等宽估算），所以长短不一的几行右边缘是齐的。
- **几何标签不受九宫格影响**：点/线/圆/椭圆旁那圈青色小字永远跟着图元走——
  把它挪到角落就等于取消"这个数属于这条线"的对应关系。字号倍率**照用**（放大是为了看清）。
- 垂直方向：上带从边距起往下堆；下带保证**最后一行的底边**留一个边距；中带整块居中。
- 文字块比画布还高（项特别多 + 字号特别大）时，块会从所选带的起点溢出，**首行不会被推到画布外**——
  首行通常是判定项，宁可下面的行看不见。真塞不下就调小字号或减少结果项。

**NG 判定怎么比**（与「结果上报」同一口径，另加两条）：两边都能当数字就按数字比（`21` = `21.0`）；
否则按真假比 —— NG 值认 `NG` / `OK` / `true` / `false` / `1` / `0`（`false` 与 `NG` 同义，
这样"图上写着 NG、颜色却是绿的"这种自相矛盾不会出现）；再否则按文本忽略大小写比。
数字解析用**不变区域性**且**拒绝千分位**（`1,5` 不会被读成 `15`），不会被系统区域设置改掉结果。

## 口径与失败策略

- **宁缺显示不停线**：底图为空、烧录失败、某一项画不出来，都只写告警并跳过；本步骤仍算**成功**。
  显示是给人看的，不能把一次成功的测量判成失败。烧录整体失败时降级为发布**原底图**（不带标注）。
- **单个元素失败只丢那一个**：非法色名回落绿色、坐标非有限值跳过、空对象集静默跳过。
- **轮廓抽稀**：`GeometryParam` 轮廓点集超过 2000 点按等间隔抽稀（保留首末点），信息栏会写明抽稀后点数。
  `HXLD` / `HRegion` **不抽稀**——重生成会把多段轮廓并成一条折线，那是改形状不是省时间。
- **坐标系**：全部图像像素系 (Row, Col)；角度**度**。

## 接线

```
图像采集.OutputImage ──▶ 结果显示.SrcImage
几何查找.Geometry ─────▶ 结果显示.r1        （青色画出圆/线/椭圆）
几何计算.Angle ────────▶ 结果显示.r2        （格式 F2，单位 °）
变量运算.Result ───────▶ 结果显示.r3        （判定项，NG 值 = NG）
结果显示.AnnotatedImage ─▶ 数据记录.图片      （存的图自带标注）
```

## 常见问题

**Q：图上看不到字？**
① 「显示窗口」是不是填了 0（0 = 只烧录不发布）；② 「图上叠字」是不是被取消了；
③ 结果项那一行是不是没连线也没手填值（空值只显示 `(空)`，且不计入 `DisplayedCount`）；
④ 上游算子本轮是不是失败了（失败步骤的输出端口通常是空的）。

**Q：导出/存图里为什么没有标注？**
「显示窗口」填 0 也不影响——标注是烧进 `AnnotatedImage` 像素的。检查存图算子接的是不是
`AnnotatedImage`（而不是原始 `OutputImage`）。导出图目前只支持 **PNG**（无损，字不会被压糊）。

**Q：判定项选了名字，改了一下别的结果项名字，判定项就空了？**
已修（R35）：候选列表重填前会记住当前值、重填后顶回去。若仍遇到，直接把名字重新填进「判定项」框即可
（它是可编辑下拉，允许手填任意名字）。

**Q：数值显示的位数/单位和现场仪表对不上？**
本算子**不改数**，只按「格式」截位、按「单位」贴后缀。数值本身的换算（像素→毫米）必须在产出它的算子里做
（接标定变换或设像素当量）。先用「格式」留空看原始值，确认上游给的就是你要的量纲，再设格式与单位。

**Q：文字压住要看的产品了怎么办？**
把「九宫格」换成右下角（或任何不挡的角落）；边距想再留宽一点就把「边距」从 0 改成具体像素。
只有**数值/文本那块**会动，几何标签本来就贴着图元、不会跟着跑。

**Q：字太小看不清 / 想整块挪远一点？**
「字号」填 1.5~2（行距自动跟着放大），「边距」加大把整块推离边缘。两者都是**整块生效**，不用逐行配。

**Q：想让某一行单独放到别的位置？**
本算子刻意**不给逐行坐标**：像素坐标在换相机分辨率或改 ROI 之后会静默错位（图上看着正常、位置其实全偏），
比"压住工件"更难发现。真需要各自定位，就把要单独放的结果项再接一个「结果显示」算子（各自一个角落）。

**Q：想同时在两个窗口显示？**
一个「结果显示」只能发布到一个窗口。要多窗口就放多个本算子（各自接同一批上游输出），
其中一个把「显示窗口」设为 0 只出标注图给存图用。
