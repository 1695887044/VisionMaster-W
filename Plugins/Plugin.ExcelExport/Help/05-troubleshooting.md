# Excel报表 · 排障

> 分类：数据处理 ｜ 来源：插件 Plugin.ExcelExport

逐条"看到什么现象 → 为什么 → 怎么改"。下表第一列是**界面/日志里的消息原文**（取自插件源码，
改了源码文案必须同步改这张表，否则这张表就是假绿）。

## 一、失败消息原文 → 查哪一项

| 消息原文 | 含义与处置 |
| --- | --- |
| `源账本不存在：{路径}（请检查『源账本路径』模板与『源步骤名』）` | 路径展开后没这个文件。核对「源步骤名」（要等于上游 CSV 记录步骤的名字）、日期层（`{yyyy-MM}`）、上游是否真写过账本 |
| `源账本路径为空` | 账本路径模板被清空了。填回默认 `D:\Records\{源步骤}\{yyyy-MM}\{yyyy-MM-dd}.csv` |
| `输出报表路径为空` | 输出目录/文件名模板整段为空。文件名留空会回落默认，但目录整段空要在面板填回来 |
| `源账本没有数据行（只有表头？）：{路径}` | 账本存在但一行数据都没有。当天流程没跑，或跑的都因上游失败没落行 |
| `『图片路径』列没有任何有效图片路径，没有可导出的行` | 勾着「只导有图的行」，但那一列全是空/相对路径。先把上游存图配好，或临时取消勾选 |
| `写入报表失败：…（报表可能正被 Excel 打开，请先关闭）` | 目标 xlsx 被占用。**关掉 Excel 再导**（本算子不旁路改名产出第二个文件） |
| `没有写入权限：…` | 输出目录不可写（受保护目录、UAC、只读盘、网盘未登录） |
| `导出异常：{类型名} {说明}` | 其它异常（例如账本格式意外）。日志里有类型名，按类型名查 |
| `导出参数为空` | 内部调用未传任务参数，正常界面路径不会出现；出现即为代码问题 |
| `Excel报表：{上面的消息}` | 勾了「导出失败阻断流程」时写进本步骤的 `ErrorMessage`（此时本步骤为失败） |

## 二、成功但"不对劲"的面板提示

| 面板/日志文本 | 结论 |
| --- | --- |
| `✔ 已导出 N 行（未找到列『XX』，导出为纯表格）` | **成功，但没有链接**。列名对不上——去核对「图片走这里」是否逐字等于账本表头里那一列的名字 |
| `✔ 已导出 N 行（『XX』列没有可用的绝对图片路径，未生成链接）` | **成功，列在但值不是绝对路径**。查上游存图与文件名模板（相对路径一律不建链接） |
| `✔ 已导出 N 行，其中 M 行图片路径已变成可点击链接` | 完全正常，M 就是能点开的行数 |
| `✘ …`（红字） | 失败原因就在后面那一句里，对照第一节表 |
| 面板红字「账本不存在（检查『源步骤名』是否与 CSV 记录步骤一致）」 | 配置期实时校验的提示。改「源步骤名」到预览变绿（`✔ 账本已找到`）再点导出 |
| 点了「立即导出」没反应 | 手动导出有重入保护：上一次还在跑（几万行确实要几秒）。等结果文本变绿再点 |
| 结果文本一直停在 `正在导出…` | 导出线程尚未收尾；界面不会被卡住（后台线程），但按钮仍是灰的 |

## 三、三条现场排查链

**链一：报表没有蓝色链接**

```
1 账本表头里有没有一列的名字逐字等于「图片走这里」？（默认 图片路径，区分大小写）
2 「CSV记录」是不是真的存了图？（不存图时那列是空串）
3 那一格是不是绝对路径？（相对路径 img\1.png 会被跳过，压根不建链接）
4 导出的结果文本走的是哪一句？（"未找到列" = 第 1 步；"没有可用的绝对图片路径" = 第 2/3 步）
```

**链二：账本找不到**

```
1 「源步骤名」填错（最常见）→ 去上游步骤看它的步骤名，逐字抄过来
2 那一天还没产生账本 → 看日期层 {yyyy-MM} / {yyyy-MM-dd}，"今天那份账"只按导出那一刻展开
3 上游改过「记录目录模板」→ 比如去掉了 {yyyy-MM} 这一层，本算子的默认模板就对不上，要跟着改
4 面板"实际读取 →"预览行：绿（✔ 账本已找到）才算对上
```

**链三：Excel 打开报表说"需要修复"**

```
1 用的是不是本插件产出的文件（别拿别的工具二次另存过的）
2 是否只重建了宿主没重建插件工程（跑的是旧 DLL）——改了插件源码必须重建插件工程
3 目录里有没有残留 .tmp（说明改包环节被中断过）
```

## 四、常见问题

**Q：报表里真的有图片吗？**
没有。只有指向磁盘原图的超链接，单元格显示短文件名。这是刻意取舍——嵌图会让报表体积暴涨且没法筛选排序。

**Q：点链接打不开？**
① 原图被删除或挪走了（被保留天数清理过、或手工搬过相册）；② 账本里那格是**相对路径**（会被跳过，压根不会生成链接）；
③ 链接是在别的机器上生成的（`file:///` 指向的是当时那台机器的路径）。

**Q：勾了「只导有图的行」却没过滤？**
过滤依赖「图片走这里」那一列**存在**（判定看账本第一条数据行的键名）。列不存在时过滤不生效、导出全量，
并提示未找到列。先把列名对上。

**Q：能导出昨天/上周/指定时间范围吗？**
不能。日期占位符只按**导出那一刻**展开，即"今天那份账"。要历史报表，就把「账本路径」里的
`{yyyy-MM-dd}` 换成具体日期导一次（或者上游按天留着的文件本身就在，直接打开 CSV）。

**Q：「每次执行都导」会怎样？**
每次都**重写整本报表**（读全账本 + 写 + 改包），而且是在流程线程里同步做的。
只适合"一个班次只跑一次"的报表流程；高频循环流程挂在流程里请用「触发端口」。

**Q：报表出错了，产线会停吗？**
默认**不会**（「导出失败阻断流程」不勾，失败只写一条 WARN），要停线自己勾上。
注意勾上之后 `ErrorMessage` 前会带 `Excel报表：` 前缀。

**Q：导出后自动打开报表，结果下一次导不出去？**
就是「导出后打开报表」勾在自动导出档上导致的：Excel 把文件占住了，而本算子**不旁路改名**。
自动导出时把这个勾取消，只在手动导出时勾。

**Q：面板预览的路径和真跑不一样？**
预览时引擎还没注入实例名，步骤名会退回"步骤名本身"，真跑是 `流程名.步骤名`。
所以预览可能少一个"流程名."前缀——以真跑为准，预览只用来发现目录层级/名字填错。

**Q：挂了流程但一条日志都没有，是不是没执行？**
不一定。导出方式=仅手动、或触发端口而未触发时是**静默通过**（连日志都不写，
免得高频流程里刷日志淹没真正的问题）。要看到日志就是本次真的导了（成功 INFO / 失败 WARN）。

**Q：交付机上报表能导但报缺 DLL？**
本算子依赖 `MiniExcel.dll`（插件私有依赖，随插件一起投递到 `Modules\`）。
交付清单里少了它，导出会异常。改了插件源码还要重建**插件工程**（只重建宿主不带出 `Modules\` 里的新 DLL）。

## 五、上线前自检清单

1. 先确认上游有账本：跑一轮流程，默认模板展开的那份 CSV（形如 `D:\Records\<流程名.CSV记录>\<年-月>\<日期>.csv`）真存在、且有数据行；
2. 面板「源步骤名」填好后，看"实际读取 → 路径"这一行变绿（`✔ 账本已找到`）；
3. 「图片走这里」= 上游那列的列名（默认 `图片路径`；上游要有一列 `来源=内置:图片路径` 且列名填 `图片路径`）；
4. 点「立即导出」，读结果文本里的三种提示之一，确认链接数 M 与预期 NG 件数量级一致；
5. 打开报表抽点两个链接，确认能调起系统看图软件（第一台机器要现场验，默认程序与权限都可能不同）；
6. 挂进流程时把「导出方式」改成 `触发端口`，并把「导出后打开报表」取消；
7. 交付机上确认 `Modules\MiniExcel.dll` 与本插件 DLL 都随插件投出来了。
