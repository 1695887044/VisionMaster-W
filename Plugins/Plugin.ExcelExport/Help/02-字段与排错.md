# Excel报表 · 字段与排错

本页管四件事：**报表落在哪里**、**报表的列从哪来**、**图片字段到底点不点得开**、**出问题时查哪一项**。
判据与消息原文都取自插件源码。

## 一、落点与轮转

| 东西 | 落在哪 | 备注 |
| --- | --- | --- |
| 读：源账本 | `源账本路径模板` 展开后的绝对路径，默认 `D:\Records\{源步骤}\{yyyy-MM}\{yyyy-MM-dd}.csv` | 只读，不动它；目录不存在/文件不存在都不创建 |
| 写：报表 | `报表输出目录模板` + `报表文件名模板`，默认 `D:\Records\{StepName}\{yyyy-MM}\报表\{yyyy-MM-dd}_报表.xlsx` | 目录自动创建；文件名没写 `.xlsx` 会自动补 |
| 临时件 | 同目录 `.tmp`，成功即原子替换、失败即删除 | 正常情况**看不到**残留 `.tmp`；看到残留说明改包环节被中断 |
| 历史报表 | 默认按天一个文件名 → 自然形成"每天一份快照" | 同一天重复导 = **覆盖**（`overwriteFile`），不是追加 |

**快照语义**：报表是"导出那一刻的账"。账本后来又长了行，老报表不会自己变——要新的就再导一次（同名会覆盖当天的那份）。

**没有的东西**（现场常问，这里逐条说明）：

| 你会找 | 实际 |
| --- | --- |
| "是否带图"开关 | **没有**。由「图片走这里」那一列在不在隐式决定，找不到列就降级纯表格 |
| 时间范围/按班次筛 | **没有**。只有"当前时刻"的日期占位符 = 今天那份账 |
| 行数上限 / 分页 | **没有**。唯一的减量手段是 `只导出有图行` |
| 报表模板 xlsx（套皮） | **没有**。报表从 CSV 现场生成 |
| 编码设置 | **没有**。本算子不写 CSV；编码在上游「CSV记录」（固定 UTF-8 带 BOM） |
| 嵌图 / 缩略图 | **没有**。只做外链（点文件名打开磁盘原图） |
| 多工作表 | **只处理 sheet1** |

## 二、报表列的来龙去脉（字段名对应关系）

报表**不做列映射、不做改名、不做排序**，列就是账本的列：

```
算子的输出端口名        CSV 的列名（= 表头）        报表的列名
Blob.IsOk        ──▶   「结果」(来源=端口)    ──▶   结果
卡尺.MeasureValue ─▶    「宽度」(格式 F3)     ──▶   宽度
内置:图片路径      ──▶   「图片路径」          ──▶   图片路径（变成可点击的短文件名）
内置:时间戳        ──▶   「时间」              ──▶   时间
```

三条口径：

- **列名要逐字对上**。报表里想要的列叫什么，就去「CSV记录」里把那列的**列名**改成什么；
  「图片走这里」填的也是**列名**（不是列号、不是列标题的别名），默认 `图片路径`。
- **值的长相由上游决定**。账本里是文本，报表就照抄文本；数值列的位数在「CSV记录」的「格式」里定（`F3`），
  本算子不会重新格式化，也不会做单位换算。
- **列序 = 账本表头序**。想调报表的列顺序，去调「CSV记录」里列的上下顺序。

**为什么有的单元格还是长长一串路径**：那格的路径被判为"不能作链接目标"（空、相对路径、含非法字符），
于是保持原文。这类行勾了 `只导出有图行` 会被整行过滤掉。

## 三、读账本的口径（也是最容易出事的地方）

- 按 **CSV** 解析（不是 xlsx），**第一行当表头**；只有表头没有数据行 → 直接报"源账本没有数据行"。
- 认「CSV记录」的整套约定：UTF-8、逗号分隔、**RFC 4180 引号转义**（含逗号/空格/引号的路径能正确读出来，
  链接里会被百分号编码成合法的 `file:///`）。
- **文件被 Excel 独占打开着也能读**（读的是账本，写的是报表）；被独占的是**报表**时写不进去，报"请先关闭"。
- 账本中途改过列定义（加列/删列）会让行与表头对不齐——那是上游的问题，本算子照表头读，
  多余的列丢、缺的列读成空。改列定义后建议归档旧账本，见「CSV记录」第二页。

## 四、失败消息原文 → 查哪一项

| 消息（面板/日志原文） | 含义与处置 |
| --- | --- |
| `源账本不存在：{路径}（请检查『源账本路径』模板与『源步骤名』）` | 路径展开后没这个文件。核对 `源步骤名`（要等于上游 CSV 记录步骤的名字）、日期层（`{yyyy-MM}`）、上游是否真写过账本 |
| `源账本路径为空` / `输出报表路径为空` | 模板被清空了。回落默认：路径模板留空会退回默认文件名模板，但整段为空要先在面板填回来 |
| `源账本没有数据行（只有表头？）：{路径}` | 账本存在但一行数据都没有。当天流程没跑，或跑的都是"启用列为 0"的失败轮 |
| `『图片路径』列没有任何有效图片路径，没有可导出的行` | `只导出有图行` 打开着，但那一列全是空/相对路径。先把上游存图配好，或临时取消勾选 |
| `写入报表失败：…（报表可能正被 Excel 打开，请先关闭）` | 目标 xlsx 被占用。**关掉 Excel 再导**（本算子不旁路改名） |
| `没有写入权限：…` | 输出目录不可写（受保护目录、UAC、只读盘、网盘未登录） |
| `导出异常：{类型名} {说明}` | 其它异常（例如账本格式意外）。日志里有全名，按类型名查 |
| 面板提示 `已导出 N 行（未找到列『XX』，导出为纯表格）` | 正常成功，只是没链接。列名对不上——去核对「图片走这里」 |
| 面板提示 `已导出 N 行（『XX』列没有可用的绝对图片路径，未生成链接）` | 正常成功，列在但值不是绝对路径。查上游存图与 `ImageNameTemplate` |
| 面板提示 `已导出 N 行，其中 M 行图片路径已变成可点击链接` | 完全正常，M 就是能点开的行数 |
| 面板红字显示「账本不存在（检查『源步骤名』是否与 CSV 记录步骤一致）」 | 配置期实时校验的提示，改 `源步骤名` 到预览变绿再点导出 |
| 点了「立即导出」没反应 | 手动导出有重入保护：上一次还在跑（几万行确实要几秒）。等结果文本变绿 |

## 五、性能与节拍

| 场景 | 表现 |
| --- | --- |
| 仅手动导出 | 不占产线节拍（在配置面板里点，后台线程跑） |
| 触发端口 / 每次执行 | **在流程线程里同步完成**读账本 + 写报表 + 改包：几万行的账本会明显拖这一拍的节拍 |
| 高频循环流程 | `每次执行都导` = 每次都重写整本报表，慎用；要挂在流程里请用 `触发端口`（收工信号） |

结论：**要节拍就只在收工时导一次**；要历史快照就按天留文件，不要按件导。

## 六、上线前自检清单

1. 先确认上游有账本：跑一轮流程，`D:\Records\流程名.CSV记录\年-月\日期.csv` 真存在、且有数据行；
2. 面板「源步骤名」填好后，看"实际读取 → 路径"这一行变绿（`账本已找到`）；
3. 「图片走这里」= 上游那列的列名（默认 `图片路径`；上游要加一列 `来源=内置:图片路径` 且列名填 `图片路径`）；
4. 点「立即导出」，读结果文本里的三种提示之一，确认链接数 M 与预期 NG 件数量级一致；
5. 打开报表抽点两个链接，确认能调起系统看图软件（第一台机器要现场验，权限/看图软件默认程序都可能不同）；
6. 挂进流程时把「导出方式」改成 `触发端口`，`OpenAfterExport` 取消（自动导出后打开 Excel 会把文件占住，影响下一次导出）；
7. 交付机上确认 `Modules\MiniExcel.dll` 随插件一起投出来了（本算子的私有依赖靠它；只重建宿主不会带出插件 DLL，改了源码要重建插件工程）。
