# Excel报表

> 分类：数据处理 ｜ 来源：插件 Plugin.ExcelExport

把「CSV记录」写出的**流水账**加工成**给人看的 xlsx 报表**：首行冻结、能筛选排序，
最关键的是——图片那一列不再是一长串路径，而是蓝色下划线的**短文件名**（如 `12_NG.png`），
点一下就用系统看图软件打开磁盘上的高清原图。

工具箱里的实名是「**Excel报表**」，分组「数据处理」（照 `[Display(Name, GroupName)]` 实值，
不叫"Excel 导出"也不叫"报表导出"）。

## 一、为什么是"事后导出"

CSV 账本机器读得懂、人看着累；而产线上**边测边写 xlsx 是错的**：写 Excel 要整份重写、
还得防 Excel 占用，代价高且没意义（机器不看报表）。所以本算子**不接数据流、只读文件**——
人要看的时候再导，报表就是"当时那份账"的快照。

```
CSV 账本（D:\Records\流程1.CSV记录\2026-09\2026-09-16.csv）
   ↓ ① 读账本（按 CSV 解析、表头行当列名）
   ↓ ② 可选过滤：只保留"图片列有有效绝对路径"的行
   ↓ ③ 写数据 xlsx（列序 = CSV 表头序；冻结首行 + 自动筛选；先写 .tmp 再原子替换）
   ↓ ④ 改写 xlsx 内部的 zip 三处，把图片路径列变成可点击超链接
报表（D:\Records\流程1.Excel报表\2026-09\报表\2026-09-16_报表.xlsx）
```

四条要先记住的取舍：

- **报表里没有图片二进制**，只有指向磁盘原图的 `file:///` 链接。好处是文件小、能筛选排序；
  代价是**原图被删/挪走链接就断**。
- **上游是"文件"不是"连线"**：本算子不接上游的结果端口，它读的是「CSV记录」的**产物**。
  所以配错的是"源步骤名"，不是连线。
- **缺列就降级**：找不到「图片走这里」指定的列，不报错，导出成纯表格（报表照样可用）。
- **导出前会等账本落盘**：先调数据记录插件的 flush 桥（最长 3 秒）等 CSV 队列排空，排不空则本次导出失败，
  不会静默读半截账本。流程里没有「CSV记录」时该桥直接放行。

## 二、第一次导出（5 步，照做即可）

1. **先确认上游有账本**：跑一轮流程，让默认模板展开出来的那份 CSV（形如
   `D:\Records\<流程名.CSV记录>\<年-月>\<日期>.csv`）真存在且有数据行；
2. 把「Excel报表」拖进流程（放在「CSV记录」之后即可，**不需要连线**）；
3. 双击本步骤打开配置面板，卡片① 的「**源步骤名**」逐字抄上游 CSV 记录步骤的名字
   （面板上会**实时显示**"实际读取 → 路径"和"✔ 账本已找到 / ✘ 账本不存在"，填错当场就能发现）；
4. 卡片② 的「**图片走这里**」= 上游那一列的**列名**（默认 `图片路径`，区分大小写，默认值就是照上游内置列给的）；
5. 卡片④ 点「**立即导出**」，读结果文本：绿字带 ✔ 就是成功，末行是报表的完整路径；
   打开报表抽点两个链接，确认能调起系统看图软件（第一台机器要现场验，默认程序与权限都可能不同）。

跑通后应该看到：面板结果文本形如 `✔ 已导出 137 行，其中 12 行图片路径已变成可点击链接`，
流程日志里同一句话后面跟着 ` → 报表路径`，本步骤的「报表路径」「导出行数」两个输出端口有值。

## 三、配置界面的四个区

| 卡片 | 管什么 | 关键行 |
| --- | --- | --- |
| ① 报表来源（CSV 账本） | 读哪本账 | 源步骤名 / 账本路径 / "实际读取"预览 + 账本存在性红绿提示 |
| ② 报表输出 | 写到哪、哪列变链接 | 输出目录 / 报表文件名 / 图片走这里 / "实际写出"预览 |
| ③ 报表选项 | 什么时候导、导成什么样 | 导出方式（选了"触发端口"才多出「触发信号」那一行）+ 冻结首行 / 自动筛选 / 只导有图的行 / 导出后打开报表 / 导出失败阻断流程 |
| ④ 立即导出 | 按当前配置马上导一份，不用跑流程 | 「立即导出」按钮 + 结果文本（后台线程跑，几万行不卡界面） |

逐行含义与默认值见《端口与参数》页；报表的列从哪来、链接按什么口径生成见《列映射与写入口径》页；
报错原文对照与现场排查链见《排障》页。

## 四、典型用法

```
① 标准链路（事后导出，推荐）
采集 ──▶ 检测 ──▶ CSV记录（写账本，含「图片路径」列）
                        ↓ 收工时
                    Excel报表（导出方式=仅手动 → 面板点「立即导出」）
                        └─▶ 报表路径 ──▶ 日志/下游可读

② 收工自动出报表
CSV记录 ─▶ Excel报表（导出方式=触发端口，收工信号 ─▶ 导出触发.端口）

③ 只看 NG 图（抽检）
Excel报表：只导有图的行 = 勾选，图片走这里 = 图片路径
        → 账本里图片列为空的行（合格件）不进报表

④ 与结果上报并列
CSV记录 ──▶ Excel报表（人看）
        └─▶ 结果上报（MES 看）
```

**导出方式怎么选**（三档都在卡片③ 的下拉里，显示中文、落盘是枚举成员名）：

| 选项 | 什么时候导 | 用在什么场合 |
| --- | --- | --- |
| 仅手动（点按钮才导） | 流程执行时**一律不导**，只有面板上点按钮才导 | 默认值。人要看时现导，不占产线节拍 |
| 触发端口（收到信号才导） | 「导出触发」端口为 `true` 的那一次执行才导 | 挂在流程末尾，由收工/换班信号触发 |
| 每次执行都导 | 本步骤每跑一次就重写整本报表 | 只适合"一个班次只跑一次"的报表流程，高频循环慎用 |

## 五、边界速览（现场常问的"有没有"）

| 你会找 | 实际 |
| --- | --- |
| 报表里嵌图片 | **没有**，只做外链（点文件名打开磁盘原图） |
| 时间范围 / 按班次筛 | **没有**，日期占位符只按"导出那一刻"展开 = 今天那份账 |
| 列映射 / 改名 / 排序 | **没有**，列就是账本的列、列序就是表头序 |
| 报表模板 xlsx（套皮） | **没有**，报表从 CSV 现场生成 |
| 行数上限 / 分页 | **没有**，唯一的减量手段是「只导有图的行」 |
| 多工作表 | **只处理第一个工作表**（sheet1） |
| 报表样式配置 | **固定**（超链接字体 Calibri、字号 11、蓝色下划线，不可配） |

**失败默认不停线**：报表是给人看的附属产物，`导出失败阻断流程` 默认不勾，导出失败只写一条 WARN；
要"报表出不了就停线"才勾上。详见《排障》页。
