# 手眼标定：两种装法与坐标系约定

同一个 4×4 矩阵，在不同的装法下含义完全不同。本页把"这个矩阵到底是什么"讲清楚，
因为**用错装法的表现是"有数、残差小、抓取偏"**，靠看数值发现不了。

---

## 一、两个坐标系先分清

- **机器人基座坐标系（base）**：机器人本体的原点，固定在设备上；
- **法兰 / 工具坐标系（gripper）**：机器人末端法兰盘上的坐标系，
  随手臂一起动。如果设置了 TCP，通常指的是工具末端。

手眼标定求的 X 是一个**固定不变**的刚体变换：它要么描述"相机相对法兰装在哪"，
要么描述"相机相对基座装在哪"。哪一个，取决于相机装在谁身上。

---

## 二、眼在手上（Eye-in-Hand）

```
        法兰(动) ── X ──> 相机(动)
             \              /
              A            B
               \          /
               基座 ── 靶标(固定)
```

- 相机固定在机器人手臂上，随手臂一起动；
- 靶标（标定板）固定在工装/台面上，**不动**；
- 机器人走到第 i 个位姿时：A_i = 法兰在基座里的位姿（机器人读数），
  B_i = 靶标在相机里的位姿（视觉解算）；
- 因为靶标不动，`A_i · X · B_i` 恒等于一个常数 → 得到 AX = XB；
- **X 的含义**：从相机坐标系到法兰坐标系的变换。输出 4×4 时选「眼在手上」。

**怎么验证你选对了**：把 X 乘上一个相机系里的点，应该得到法兰系里的点。
如果算出来的点整体跑到基座系里去了（数值量级差一个机器人臂长），装法选错了。

---

## 三、眼在手外（Eye-to-Hand）

```
        相机(固定) ── X ──> 基座
             |               |
             B               A
             |               |
        靶标(动) ── 法兰(动)
```

- 相机固定在支架上，**不动**；
- 靶标装在机器人末端，随手臂动；
- 机器人走到第 i 个位姿时：A_i = 法兰在基座里的位姿（机器人读数），
  B_i = 靶标在相机里的位姿（视觉解算）；
- 因为相机不动，`A_i · X · B_i` 同样恒等于常数；
- **X 的含义**：从相机坐标系到**基座**坐标系的变换。输出 4×4 时选「眼在手外」。

注意：两边的 A 与 B 的**物理含义反过来了**，但方程形式一样。
本插件内部对两种装法用同一套求解，区别只在于输出的 4×4 是相对法兰还是相对基座。

---

## 四、装法选错的三个症状

| 症状 | 原因 |
|---|---|
| 残差正常，但抓取点整体差一个臂长量级 | 该选「眼在手上」却选了「眼在手外」（或反之） |
| 残差正常，但抓取点整体镜像 | 欧拉角约定不对（把 XYZ 当成 ZYX 用了） |
| 换一个机器人位姿，误差就变 | 相机或靶标在采集中途动过；或者 A/B 不是同一时刻的数据 |

前两条**不会触发任何报错**，因为矩阵在数学上完全合法。这就是为什么每次换工位
都要按「快速开始」第六节做一次已知点核对。

---

## 五、欧拉角的三个符号

本插件只支持 **ZYX 欧拉角**：R = Rz(RZ) · Ry(RY) · Rx(RX)。

换新品牌机器人时，先做这个核对（5 分钟，能省掉半天）：

1. 机器人摆到 RX=RY=RZ=0 的位姿，记下控制器读数；
2. 只把 RX 转到 90°，RY/RZ 保持 0，记下读数；
3. 拿这两个位姿各写一行数据，跑一次「手眼标定」；
4. 如果提示"旋转激励不足"，说明第 2 步实际转的不是 RX 那一轴——
   换 RY 或 RZ 再试，直到找到控制器里哪个字段对应"绕 X 转"。

**符号错的表现**：矩阵解出来、残差也不大，但抓取点整体镜像或转反。
遇到这种情况不要怀疑数据，先按上面四步核对三个符号。

## 六、和「标定」插件的关系

| | 「标定」插件 | 「手眼标定」插件 |
|---|---|---|
| 解决 | 平面映射 | 三维刚体变换 |
| 输出 | 6 元仿射 / 9 元射影 / 网格 | 4×4 + 残差 |
| 数据 | 机械坐标 ↔ 图像像素 | 机器人位姿 ↔ 相机位姿 |
| 前置 | 无 | 需要先标相机内参（用「标定」的相机内参模式） |

两者是串联关系：**先标内参 → 再标手眼**。内参没标就直接跑手眼，
误差会被当成噪声吸收进矩阵里，残差看起来还行，但精度上不去。
