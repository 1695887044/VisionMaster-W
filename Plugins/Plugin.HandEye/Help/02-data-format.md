# 手眼标定：数据采集与文件格式

本页把「怎么把成对数据录对」讲透。格式错一格，后面的求解全废，
而且**大多数格式错不会报错**——它们只是让残差变大，或者让解悄悄偏掉。

---

## 一、文件格式

一个纯文本 CSV（UTF-8），每行 12 列，逗号分隔：

```
robotX,robotY,robotZ,robotRx,robotRy,robotRz,camX,camY,camZ,camRx,camRy,camRz
```

| 列号 | 含义 | 单位 |
|---|---|---|
| 1~3 | 机器人位姿的 X / Y / Z | 毫米 |
| 4~6 | 机器人位姿的 RX / RY / RZ | 度 |
| 7~9 | 相机位姿的 X / Y / Z | 毫米 |
| 10~12 | 相机位姿的 RX / RY / RZ | 度 |

约定：

- **位置一律毫米，角度一律度**。插件内部会转成弧度再算，不需要你写弧度。
- **姿态按 ZYX 欧拉角**：先绕 Z 转 RZ，再绕 Y 转 RY，最后绕 X 转 RX。
  即 R = Rz(RZ) · Ry(RY) · Rx(RX)。
- 首行可以写表头。判据是"第一列不是数字"——所以表头怎么写都行，
  但**不要在数据行里出现任何非数字**。
- 空行、`#` 开头的行会被跳过，可以拿来做分组注释。
- 数值里不要写千分位逗号（那是分隔符），不要写单位后缀。

---

## 二、行号与列号的报错

格式真的坏掉时（列数不对、某格不是数字），插件会报出**行号 + 列号 + 原始文本**：

```
成对数据第 7 行有 11 列，应为 12 列：512.3,120.8,340.0,178.2,-3.1,45.6,12.44,-88.02,410.6,179.9,0.8
```

```
成对数据第 9 行第 5 列不是数字：「-3.1度」
```

之所以要报到这一级：现场最常见的两个错是"某一行少了一列"和"某一格粘了单位"，
只说"格式错误"会让人从第一行数到最后一行。

## 三、两类数据各自的坑

### 3.1 机器人侧

- **控制器显示的是什么坐标系？** 有的品牌显示基座坐标，有的显示工具坐标，
  有的在 TCP 补偿打开后显示的是"法兰 + 工具偏移"。**必须用同一套**，
  中途换过一次，整批数据作废。
- **回零状态**：机器人没回零时读出的位姿可能是相对值。开机先回零再采。
- **RX/RY/RZ 的欧拉约定**：不同品牌默认的旋转顺序不同（ZYX / XYZ / ZYZ）。
  本插件只认 ZYX。换品牌时**先做一次"只绕单轴转 90°"的核对**：
  只转 RX 90° 时，第 4 列应该从 0 变 90，其它两列保持 0。
  如果控制器给出的顺序不是 ZYX，需要在导出时先换算。
- **精度位数**：至少保留 3 位小数（毫米级）。四舍五入到整数会让平移残差虚高。

### 3.2 相机侧

- 相机位姿不是"图像上的像素坐标"，而是**标定板位姿**：
  由标定板在该位姿下的成像 + 相机内参算出的 6-DOF。
  内参没标过就直接用，误差会被手眼求解当成噪声吸收进矩阵里。
- **靶标必须刚性固定**。眼在手上时靶标固定在工装上，眼在手外时靶标装在机器人末端。
  采集中途靶标被碰动过，整批作废。
- **单位与机器人侧一致**：如果标定板位姿算出来是米，要乘 1000 换成毫米。

## 四、一次采集的完整流程

1. 机器人回零，确认 TCP 与工件坐标系设定正确；
2. 相机内参已标定（用「标定」插件的相机内参模式）；
3. 把靶标固定好，确认整个采集过程中不会动；
4. 让机器人走到第一个位姿，等它**完全停稳**（有余振的机器要等 1 秒以上）再触发拍照；
5. 记录：机器人控制器读数 + 标定板位姿解算结果，写一行；
6. 换位姿，重复 4~5，共 6~9 组。**姿态要散开**，不要只在同一平面上平移；
7. 存成 CSV，跑一次手眼标定，看残差。

---

## 五、怎么判断这批数据能不能用

跑完之后看三个数：

| 指标 | 健康的量级 | 说明 |
|---|---|---|
| 旋转残差 RMS | < 0.1° | 明显大于 0.5° 说明姿态数据有问题 |
| 平移残差 RMS | < 0.3 mm | 明显大于 1 mm 说明点位数据有问题 |
| 参与组数 | ≥ 6 | 少于 6 组时结果不稳 |

如果**旋转残差正常但平移残差很大**：多半是某几组点位抄错，或者机器人没回零。
如果**平移残差正常但旋转残差很大**：多半是姿态的欧拉约定不对，或者角度单位混了。
如果**两个都大**：先怀疑靶标动过，或者机器人侧和相机侧不是同一时刻的数据。

残差正常也不代表解对——验收要按「快速开始」第六节做一次已知点核对。

## 六、常见问题

**Q：能不能直接用机器人示教的点位，不拍照？**
不行。手眼标定需要的是"同一时刻的机器人位姿和相机位姿"这一对关系，
少一边就只剩一个未知数比方程多的方程组。

**Q：组数越多越好吗？**
不是。10 组散开的姿态比 30 组挤在一起的姿态有用得多。
真正决定精度的是**姿态的跨度**，不是点的数量。

**Q：可以分几次采，然后拼起来吗？**
可以，但要保证这几次之间**靶标和相机都没动过**。拼接后按一个文件跑。

**Q：换了相机镜头，要重标吗？**
要。内参变了，相机位姿的数值全变，手眼矩阵必须重算。
