# 卡参数与轴参数（逐项：默认值、下发去向、改了影响什么）

> 分类：运动卡 ｜ 来源：插件 Plugin.Motion.ZMotion

寻址口径先说清：这张卡上**没有任何"地址端口"**。流程步骤只给名字，
轴级操作给**逻辑轴名**（一次解析同时得到哪张卡 + 卡内物理轴号 + 当量 + 软限位），
卡级操作（轴卡 IO、轴停止留空）给**卡名称**。IP 只活在「运动卡设置」里。

本驱动不实现流程算子，所以没有 `[StepConfig]` 与自有端口；
下面三份表分别是**卡配置对象**（`MotionDescriptor`）、**轴映射**（`AxisMapping`）、
**卡级参数**（`MotionParams`）的字段逐个 —— 它们随方案落盘，界面标签与字段名一一对应。

## 卡配置：`MotionDescriptor` 字段逐个

| 字段 | 类型 / 默认 | 作用与后果 |
| --- | --- | --- |
| `Id` | Guid，自动生成 | 内部稳定身份。运行态设备表、轴注册表都按它对齐；**引用一律用 Id 或稳定键，不用显示名** |
| `DriverTypeKey` | AssemblyQualifiedName | 把方案与"哪家驱动"绑定。换驱动等于换卡，要重建实例；驱动不可用时创建阶段就报"驱动…不可用（插件未加载或被删除）" |
| `DisplayName` | 空 | 卡名。卡级步骤**按它逐字、区分大小写**匹配；界面标题回退顺序是它 → `Address` → `(未命名运动卡)` |
| `Address` | 空 | 连接地址，正运动是控制器 IP。留空直接失败：`未填写控制器 IP 地址` |
| `CardModel` | 空 | 机型标识（`ECI3428` / `ECI3828` / `ZMC408SCAN` / `VPLC532R`）。留空则用控制器自报的 SoftType；**配置优先于上报** |
| `AutoConnect` | false | 随方案启动自动连接。只对勾了的卡发起一次，一台失败不阻断启动 |
| `Remarks` | 空 | 备注，只给人看，不参与寻址 |
| `Axes` | 列表 | 轴映射表，见下节 |
| `Points` | 列表 | 点位表（每轴固定 16 行 P0–P15，懒补齐），见"点位模型" |
| `Params` | 对象 | 卡级参数，见后节 |
| `Caption` | 只读计算 | 界面一行的标题 |

已退役的成员：`ResolveAxisIndex`（带 `[Obsolete]`）。它只在单卡范围内按名找轴号，
跨卡重名时命中哪根全看列表顺序 —— 后果是"命令发给 A 卡、动的是 B 卡"。
现在走轴注册表解析出"卡 Id + 轴号"，插件侧用注入的取轴入口一次拿到"设备 + 轴配置"。

## 轴映射：`AxisMapping` 字段逐个

行内表格编辑前 5 个核心字段，其余 7 个收在「轴配置」弹窗里，**全部随方案 JSON 落盘**。

| 字段 | 默认 | 是否下发到卡 | 说明 |
| --- | --- | --- | --- |
| `LogicalName` | 空 | 否（纯寻址键） | 流程的唯一引用名，**全局唯一**（跨卡也不能重名），最长 32 字符，不含凸轮分隔符 |
| `PhysicalIndex` | 0 | 是（作轴号参数） | **0 基**：卡上第 1 根轴填 0。超范围被门禁挡下 `轴号 5 超出范围（本卡 4 轴）` |
| `Enabled` | true | 是（决定遍历面） | 关掉的轴不进候选、不被轮询、不被"停全部轴/清报警/安全停止"遍历 |
| `UnitsPerMm` | 1000 | 是（`SetUnits`，下限取 0.0001） | **每毫米多少个单位**。配错的后果是行程按错误倍率走且**看起来能跑**，现场最难发现 |
| `SoftLimitMinMm` | -1000000 | 否（软件层校验） | 只在绝对运动时校验 |
| `SoftLimitMaxMm` | 1000000 | 否（同上） | 保持默认等于这道防线是空的（`IsSoftLimitDisabled` 据此给界面提示） |
| `AxisRemark` | 空 | 否 | 轴备注 |
| `EncoderType` | 空 | 否 | 无 / 增量 / 绝对值 / 光栅尺，记录用；空时界面按"增量编码器"回退展示 |
| `EncoderPpu` | 0 | 否 | 每毫米脉冲数，位置反馈换算参考值；**本驱动不用它**（用的是 `UnitsPerMm`） |
| `MotorDriver` | 空 | 否 | 驱动器型号，示教与报警码解析的记录位 |
| `MotorRatedCurrentA` | 0 | 否 | 额定电流（A），过载估算记录位；0 时界面按 5 回退展示 |
| `FollowErrorUpperPulse` / `FollowErrorLowerPulse` | 0 | 否 | 跟随误差上/下限；**不下发给驱动器**，真实窗口要在伺服参数里设；界面按 ±5000 回退展示 |

## 卡级参数：`MotionParams` 字段逐个

| 字段 | 默认 | 在正运动卡上的真实作用 |
| --- | --- | --- |
| `DefaultVelocityMmPerS` | 50 | **不影响步骤运动命令**：命令速度 ≤0 时驱动"不覆盖"，沿用控制器内 SPEED。它是点位表与调试面板的默认值来源 |
| `DefaultAccelMmPerS2` | 500 | 同上，点位表默认加减速来源 |
| `PollIntervalMs` | 10 | 轮询周期（实际取用会夹到 1~1000 ms）。决定报警/限位多久被发现；太小占满网口带宽，太大安全响应迟钝 |
| `CommandTimeoutMs` | 30000 | 单条命令默认超时；轴运动 / 轴卡 IO / 轴停止的下发超时就是它；回零没给超时的兜底也是它（下限 1000 ms） |
| `WatchdogTimeoutMs` | 3000 | 连续 3 次轮询失败**或**超过这个时长没有成功轮询 → 判失联、清队、安全停机（实际取用下限 200 ms） |
| `AutoReconnect` | true | **只是配置项**：本层没有自动重连逻辑，掉线后要人工「断开 → 连接」 |
| `MaxQueueDepth` | 256 | 队列上限，超过即 `被拒绝：命令队列已满（上限 256 条）` |

## 机型与能力（决定能操作几根轴、几个点）

机型名**按前缀匹配**（控制器自报的 SoftType 可能带后缀，如 `ECI3428_V2` 也能命中 `ECI3428`）：

| 机型 | 轴数 | 输入 | 输出 | 类型 | IO 点数是否核实 |
| --- | --- | --- | --- | --- | --- |
| `ECI3428` | 4 | 24 | 16 | EtherCAT 总线型 | 已核实 |
| `ECI3828` | 8 | 24 | 20 | EtherCAT 总线型 | 已核实 |
| `ZMC408SCAN` | 4 | 24 | 20 | EtherCAT 总线型 | 已核实 |
| `VPLC532R`（虚拟 PLC，RTSys 仿真器同属此类） | 32 | 24 | 16 | 总线型 | **未核实**（点位取决于组态） |
| 认不出（含留空且自报名不匹配） | **4** | **24** | **16** | 按总线型 | 未核实（兜底值就是猜的，如实标记） |

- 兜底刻意取"常见的最小配置"（4 轴）：报小的后果是"某些轴不能操作"（可见、可改），
  报大的后果是"对着不存在的轴下发命令"（不可见，真机上表现为莫名其妙的失败）。
- `AxisCount` 决定命令门禁里的轴号上界，也决定连接后自动铺多少行轴映射。
- 上报能力：硬限位支持、点动支持、**直线/圆弧插补不支持**；总线型支持全部 8 种回零方式，
  脉冲型只上报 3 种（负限位+Index / 正限位+Index / 原点开关）。

## 命令 → 正运动 API 对照（现场对厂商手册时用这张表）

| 统一命令 | 正运动 API | 完成判定 | 备注 |
| --- | --- | --- | --- |
| 使能 | `ZAux_Direct_SetAxisEnable(轴, 1)` | 返回 0 即完成 | 使能状态由下一次轮询的 `GetAxisEnable` 回报 |
| 失能 | 先 `Single_Cancel(轴, 2)` 再 `SetAxisEnable(轴, 0)` | 返回 0 | 失能即停：撤掉当前运动再断电 |
| 绝对定位 | `SetSpeed`（速度>0 时）→ `SetAccel`/`SetDecel`（加减速>0 时）→ `SetSramp` → `Single_MoveAbs(轴, 目标mm)` | **下发即返回** | 等到位是`等待到位`步骤的事 |
| 相对定位 | 同上 → `Single_Move(轴, 增量mm)` | 下发即返回 | 增量可为负；不查软限位 |
| 点动 | 同上 → `Single_Vmove(轴, ±1)` | 下发即返回 | 速度模式持续走，直到被叫停 |
| 回零 | 总线型 `BusCmd_Datum(轴, 模式码)`；脉冲型 `Single_Datum(轴, 模式码)` | 总线型 `GetHomeStatus==1`；脉冲型 `GetIfIdle≠0` | 超时**先停轴**再报失败；回零速度/偏移沿用控制器内设置 |
| 停止 | `Single_Cancel(轴, 模式)`；轴号 -1 时**逐启用轴**逐个取消 | 返回 0 | 模式 2=减速停、3=立即停（SDK 约定值）；≤0 归为 2 |
| 写输出 | `ZAux_Direct_SetOp(点号, 1/0)` | 返回 0 | 点号 **0 基** |
| 清报警 | `ZAux_BusCmd_DriveClear(轴, 0)`，**逐启用轴** | 全部返回 0 | **不自动重新使能** |
| 读输入 | `GetInMulti(0, 点数-1)`（在轮询里批量） | —— | `轴卡 IO` 读的是这份快照 |

### 回零方式对照（两张数字不要混）

`HomeMode` 是契约枚举，界面上的中文名来自契约层的显示字典；**C# 枚举值 ≠ 正运动模式码**。
下表"正运动模式码"取自驱动 `ZMotionHomeModes.ToSdk` 的 switch（逐字），"C# 值"是枚举成员自身的值。

| 界面中文 | 枚举成员 | C# 值 | 正运动模式码 |
| --- | --- | --- | --- |
| 负限位 + Index | `NegativeLimitIndex` | 0 | 1 |
| 正限位 + Index | `PositiveLimitIndex` | 1 | 2 |
| 原点开关 | `Origin` | 2 | 19 |
| 负限位 + 原点 | `NegativeLimitOrigin` | 3 | 27 |
| 正限位 + 原点 | `PositiveLimitOrigin` | 4 | 23 |
| 负限位（不回原点） | `NegativeLimit` | 6 | 17 |
| 正限位（不回原点） | `PositiveLimit` | 7 | 18 |
| 零位置预设（不找开关） | `PresetZero` | 5 | 37 |

`PresetZero` 被额外标记为"不需要找开关"，界面据此提示。模式码**只能来自手册**：
填错一个数字，回零会按完全不同的寻零路径走（把"负限位+Index"填成"正限位+Index"，轴会朝反方向撞过去）。

## 其它厂商码口径

- **轴号基准 0**：卡上第 1 根轴是 0（`PhysicalIndex`、日志与报错里的"轴号"同一个口径）。
- **IO 点号基准 0**：`IN0` / `OUT0` 就是点号 0，`GetInMulti(0, count-1)` 也是这个区间。
- **停止模式 2/3**：2 = 减速停、3 = 立即停，与正运动 SDK 的取值一致；软件层不做换算。
- **S 平滑时长 200**：`SetSramp` 的单位是毫秒，200 是本驱动自己给 S 曲线定的固定值（不可调），
  梯形恒为 0。这两个数**不是**厂商码，别与手册里的其他参数混读。

## 点位模型

每轴固定 16 行（`Index` 0..15，界面显示 P0–P15），字段：`AxisLogical`（所属轴名）、`Index`、
`Name`、`PositionMm`（绝对 mm）、`SpeedMmPerS`、`AccelMmPerS2`（两者 ≤0 = 用卡级默认）、`Curve`（梯形/S 曲线）。
首次打开某轴点位表时懒 seed：位置 = 序号×10，速度/加减速 = 卡级默认值，名称 = 「点位{序号}」，曲线 = 梯形。
