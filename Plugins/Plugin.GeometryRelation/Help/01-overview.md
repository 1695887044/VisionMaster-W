# 几何计算

对上游**几何基元**（点 / 线 / 圆）做关系运算，输出**数值**或**新基元**。与「几何查找」配套：查找出基元 → 计算算关系。

## 输入

| 端口 | 说明 |
| --- | --- |
| `A` | 几何 A（点/线/圆），必接 |
| `B` | 几何 B（多数模式需要） |
| `C` | 几何 C（三点构圆用） |
| `MmPerPixel` | 像素当量（接「标定」的 `MmPerPixel`）；未接 = 数值输出**像素** |
| `StandardValue` / `UpperTolerance` / `LowerTolerance` | 判定规格（默认 0 = 零容忍，未填即 NG） |
| `AngleTolerance` | 平行/垂直判定的角度容差（度） |
| `SrcImage` | 叠加显示用图像（可选）：接上游图像源，把结果画在它上面 |
| `DisplayViewIndex` | 显示窗口（0=不显示，1~9=窗口号） |

## 输出

| 端口 | 说明 |
| --- | --- |
| `Value` | 数值结果（距离/夹角/圆心距…） |
| `Geometry` | 基元结果（交点 / 构造出的线或圆）——可继续喂给下一个「几何计算」 |
| `IsOk` | 判定结果 |

## 模式（`Op`）

| 模式 | 输入 | 输出 |
| --- | --- | --- |
| 距离 | 点-点 / 点-线 / 平行线 | `Value` |
| 夹角 | 两线 | `Value`（度，[0,90]） |
| 求交 | 线-线 / 线-圆 / 圆-圆 | `Geometry`（交点） |
| 垂足 | 点 + 线 | `Geometry`（垂足点）+ `Value`（垂距） |
| 平行/垂直 | 两线 | `IsOk` |
| 圆关系 | 两圆 | `Value`（圆心距）+ `IsOk`（同心） |
| 构造 | 两点 → 线；三点 → 圆 | `Geometry` |

## 口径

- 坐标系：图像像素系 `(Row, Col)`；角度单位**度**，线方向角归一化 [0,180)。
- **夹角是无向夹角 [0,90]**（两条无向直线的真实夹角）。
- 距离类数值 = 像素 × 像素当量；**未标定时直接输出像素**（不假装是 mm）。
- 找不到/类型不匹配 → **明确失败**并给中文原因，绝不静默返回脏值。
