# 几何计算 · 快速上手

> 分类：几何工具 ｜ 来源：插件 Plugin.GeometryRelation

## 它是什么、不管什么

吃上游的**几何基元**（点 / 线 / 圆），算它们之间的**关系**：距离、夹角、求交、垂足、平行垂直、圆关系、构造（连线构圆）。
输出要么是**数值**（`Value`，可判定 OK/NG），要么是**新基元**（`Geometry`，可以接着喂给下一个「几何计算」，串成表达式树）。

它**不找边**（那是「几何查找」）、**不碰图像像素**（纯数学，图像只是拿来叠一层标注给人看）、
**不做标定换算之外的任何坐标变换**（要物理坐标就接 `MmPerPixel`）。

## 为什么需要它

现场要的是"这条边到那个圆心多少毫米""两条边是不是垂直"，而单个算子只会报自己那一个量。
把基元当数据传下去、用一个算子算关系，好处有三：**不用为每一种组合新增算子**（七种模式覆盖常见关系）、
**中间结果能复用**（求出的交点可以接着量距离）、**换产品只改连线不改流程结构**。

**为什么是纯托管数学而不是调视觉库**：这些关系都有闭式解，写成托管代码能逐条被断言钉死
（合成已知量对解析解，误差控到 1e-9），而调库的结果没法逐值验证。附带两个好处：跑得快、结果与平台版本无关。
代价是**不与「卡尺测量」的角度逐值一致**——卡尺的角度依赖"点分布取向"（射线口径 0~180°），
本算子的基元只带 (行, 列, 方向角) 没有那个取向，所以夹角一律给**无向夹角 [0,90]**。

## 原理（一次运算的骨架）

```
A（必接基元） [+ B / C]
   ↓ 按 Op 选模式 → 校验类型（Kind 不对就明确失败，不硬算）
   ↓ 纯几何公式（方向单位向量 = (sin φ, cos φ)，φ 为线的方向角、度）
   ↓ 长度类结果 × 像素当量（角度类不乘）
   ↓ 有规格的模式做判定：值 ∈ [标准值 − 下公差, 标准值 + 上公差]
Value / Geometry / IsOk（成功时把输入与结果叠到 SrcImage 上推视图窗口）
```

基元是**不可变**的：本算子只做换算、产新对象，绝不就地改上游那个基元
（否则两个下游共享同一对象时，一个改动会把另一个的结果悄悄改掉）。

## 第一次接线（四步）

1. 先有基元：两个「几何查找」（分别找两条边），各出 `Geometry`。
2. `几何查找#1.Geometry → 几何计算.A`、`几何查找#2.Geometry → 几何计算.B`；`Op` 选**距离**。
3. 要毫米就再连 `标定.MmPerPixel → 几何计算.MmPerPixel`（推荐用连线而不是手填：忘重标会当场失败，不会静默出像素数）。
4. 想让图上有标注，就再连一条图像源：`图像采集.OutputImage → 几何计算.SrcImage`，并确认 `DisplayViewIndex` 是你要看的那一格。

试运行后看左上角那行字：`距离 = 12.34`，绿字 = 判定 OK、黄字 = 判定 NG（**注意第三种情况：求交/垂足/构造这类模式根本不做判定，字永远是黄的**，详见「口径与判定」）。

## 常用接法

```
几何计算.Geometry    ──▶ 几何计算#2.A              （表达式树：交点接着量距离）
几何计算.Value       ──▶ CSV记录 / 结果显示         （数值落盘或上屏，格式自己定）
几何计算.IsOk        ──▶ 结果上报.判定字段          （只有判定型模式有意义）
量"两个圆的圆心距"：两个几何查找(圆) → A/B，Op=圆关系 → Value + IsOk
判"两条边是否垂直"：两个几何查找(边) → A/B，Op=平行/垂直、RelationKind=垂直 → IsOk
拿"两条边的交点"：  Op=求交 → Geometry（一个点），再把这个点喂给下一算子量点-点距
```

## 五条口径，先记住再用

- **没接当量就是像素**：`Value` 不带单位，长度类数值在未标定时是像素数，别当毫米用。
- **夹角永远是度**，与当量无关；且是**无向夹角 [0,90]**（0° 与 170° 的两条线报 10°）。
- **NG 不是失败**：超差只把 `IsOk` 置 false，步骤照样成功、流程继续。分流看 `IsOk`，别看步骤红绿。
- **失败就是失败**：类型不匹配、缺输入、几何退化（近平行 / 不相交 / 同心内含 / 三点共线）、上游当量无效，
  一律明确失败并给中文原因，绝不返回"看着合理"的兜底值。
- **基元的线是无限直线**（一点 + 方向角，没有端点）：点到线的垂足落在线段延长线上照样算，
  图上画出的那根线只是示意（长度取图对角线的 1/4），**别拿它估尺寸**。

端口、参数、七种模式的详细口径在「端口与参数」和「口径与判定」两页；出问题时看「排错与常见问题」。
