# Blob 缺陷检测 · 调参与排错

这一页讲**怎么把 Blob 调到能用**：先看直方图定阈值，再沿"二值化 → 候选区域 → 连通域 → 特征筛选 → 判定"这条链路逐段判读标注图，最后按现象查参数。
所有现象与取值都对应界面上的实际字段，照着调即可。

## 一、第一次配检测（六步）

1. **接图**：把前级（采集 / ROI / 预处理）的图像连到 `SrcImage`。
2. **选二值化方式**：图干净、明暗稳定 → `固定阈值`；想省事、产品换型频繁 → `自动阈值`；**打光不匀 / 曲面 / 有渐变** → `动态阈值`。
3. **看直方图定阈值**：右侧切到「数据输出」页签看**灰度直方图**，图上两条标记线就是当前的`下限灰度`/`上限灰度`，**可以直接用鼠标左右拖**。把区间收到"缺陷那一坨"上：拖到背景峰与缺陷峰之间的**谷底**，就是最佳分割点。
4. **设筛选**：`面积下限`滤噪点（默认 30，噪声多就调大）；需要区分气泡/划痕再动`圆度下限`/`长宽比上限`；边缘有假缺陷就设`排除触边`。
5. **设判定规格**：`缺陷个数上限` / `单个缺陷面积上限` / `缺陷总面积上限`按产品规格填。
6. **看标注图核对**：红圈有没有圈对、编号有没有落在缺陷上。清单里点某一行 → 图上给那个缺陷套**黄框**，可以逐个核对。

> 加载第一张图时，若参数**仍是出厂默认值**，插件会自动适配一次（阈值取实际灰度范围里最暗/最亮的 25% 作保守带，面积按画幅比例从 640×480 基准缩放）。这给的只是**可用起点、不是正确值**——一旦你改过任何一个参数就不再自动覆盖，想重来一次点「按当前图像重新适配」。

## 二、沿链路定位问题：四段判读法

出问题时先判断"是哪一段把缺陷弄丢了"，别一上来就改判定阈值。

### 第 1 段｜二值化（可疑像素切出来了吗）

| 现象 | 判读 | 处理 |
| --- | --- | --- |
| 标注图上整片都红 | 阈值太宽，背景被整片切进来 | 收窄灰度区间；动态阈值则调大`标准差权重`/`绝对灰度偏移` |
| 缺陷区域只有薄薄一圈边 | 固定阈值下缺陷灰度不均，只切到了边缘 | 换`动态阈值`；或把区间放宽后靠`面积下限`兜 |
| 打光不匀：左边全红、右边全空 | 全局阈值处理不了局部光照差 | 换`动态阈值`，`局部窗口宽/高`取**缺陷尺寸的 2~3 倍**（窗口比缺陷小，缺陷本身会被当成本地背景而消失） |
| 检出一堆比头发丝还细的毛刺 | 噪声像素连成片 | `开运算半径`从 1 起加；或调大`面积下限` |

### 第 2 段｜形态学（候选区域形状对不对）

| 现象 | 处理 |
| --- | --- |
| 一条划痕被断成三四段、个数虚高 | `合并半径`：从缺陷段间宽度的**一半**往上取（它按"间距 < 2×半径"合并）；先试 1~2 倍噪声间距 |
| 缺陷内部有亮点、面积偏小或被拆成两个 | 勾`填孔`（按外轮廓算面积）；或`闭运算半径`补内孔 |
| 两个相邻的小麻点被合成一个大缺陷、误判面积超标 | `合并半径`调小或归 0，`闭运算半径`调小 |
| 缺陷旁边挂着毛刺导致长宽比失真 | `开运算半径`磨掉毛刺，再看`长宽比上限` |

> 执行顺序固定：**开 → 闭 → 拆连通域 → 合并 → 填孔 → 特征筛选**。合并这一步内部是 `union1` → 闭 → `connection`，所以它是"跨连通域"的合并，而`闭运算半径`只在原候选区上连断口。

### 第 3 段｜连通域与特征筛选（这个算不算缺陷）

| 现象 | 处理 |
| --- | --- |
| 小缺陷被当成噪点丢了 | `面积下限`调小。**注意单位是像素**：换相机/改 ROI 后同一物理缺陷的像素面积会变 |
| 整片背景脏污既不计数也不 NG | `面积上限`被人填小了（筛选会直接把它"看不见"）。0 = 不限，此时上限自动取图像像素总数 |
| 想只报气泡、不报划痕 | `圆度下限`（气泡高、划痕约 0.02~0.1）或`长宽比上限`（划痕比值大，滤长条就填 3） |
| 想只报划痕、不报圆点 | `圆度下限`保持 0，`长宽比上限`填不了"下限"语义——把`圆度下限`填高（如 0.3）滤掉圆斑反而更容易；或在下游取`DefectCircularities`/`DefectAspectRatios`数组分流 |
| 画面边缘（右缘/底缘）稳定误报 | `排除触边`设边界带宽。ROI 只能整体裁形状，没法"往里缩一圈"，所以这条必须在插件里做 |

### 第 4 段｜判定（合不合格）

| 现象 | 处理 |
| --- | --- |
| 良率明明很高却大批 NG | 先确认是**筛选没滤干净**还是**规格太严**：看`DefectCount`与`MaxArea`，再对照 NG 原因文案（个数超标 / 个数不足 / 单缺陷面积 / 总面积） |
| "每个都合格、整片却像发霉"照样 OK | 填`缺陷总面积上限` |
| "这个标记怎么没了"没报警 | 填`缺陷个数下限`（存在性检测专用，0 = 不判定） |
| 想表达"任何缺陷都不允许" | `缺陷个数上限 = 0`（零容忍），不要靠把`单个缺陷面积上限`填 0——0 的语义是"不做这项判定" |

## 三、按现象查参数（速查表）

> 完整参数与取值范围以流程中该步骤的「模块参数」界面为准，这里只解释含义。

| 现象 | 调哪里 |
| --- | --- |
| 漏检（缺陷没检出来） | 阈值区间没覆盖 → 看直方图重设`下限/上限灰度`；或`面积下限`太大；或极性选反 |
| 误检（背景当缺陷） | 阈值收窄；`面积下限`调大；`标准差权重`/`绝对灰度偏移`调大 |
| 打光不匀、一头漏一头死 | 换`动态阈值`，`局部窗口宽/高`取缺陷尺寸的 2~3 倍 |
| 缺陷个数虚高（一条划痕算多个） | `合并半径`；或`闭运算半径`连断口 |
| 边缘总有假缺陷 | `排除触边` |
| 固定位置（螺丝孔/二维码）总误报 | 接`排除区域` |
| 只想看某一块区域 | 接`检测区域`（`MaskRegion`） |
| 缺陷有孔洞导致面积偏小 | 勾`填孔` |
| 大画幅相机（>1000 万像素） | 面积类规格按面积比例放大（像素面积与画幅成正比）；`面积上限`保持 0 |
| 想区分气泡（圆）与划痕（长条） | `圆度下限`/`长宽比上限`筛，或下游读`DefectCircularities`/`DefectAspectRatios` |
| 报表要"最大缺陷排第一" | `输出排序 = 面积从大到小` |
| mm² 输出对不上现场尺寸 | 接`MmPerPixel`或填准`像素当量`；注意判定仍按像素，不会因当量改变 |

## 四、现场排障（现象 → 原因）

| 现象 | 排查 |
| --- | --- |
| 步骤直接失败："输入图像为空或未初始化" | 上游没连、上游那一步本轮失败（失败步骤的输出端口通常是空的） |
| 步骤失败："不支持的图像通道数：N" | 只支持 1（灰度）、3（彩色）、4（RGBA/BGRA，丢 alpha 后转灰度）通道。上游先转成灰度或 RGB |
| 步骤失败：像素当量来自上游连线但无效 | 标定步骤本轮失配/失败，或链接的变量没值。让标定先成功，或断开连线改手填`像素当量` |
| NG 原因写"最大缺陷面积 xxx 超过上限" | 是真的有一条超标；若是整片背景被算成一个缺陷 → 回到第 1 段（阈值太宽） |
| 明明一大片脏污却报 OK | `面积上限`被填小了（筛选把背景"看不见"了）。这是最危险的一类，把它归 0 |
| 预览/参数改了不刷新 | 参数改动有 200ms 防抖；确认不是运行实例（预览只在配置界面跑） |
| 标注图没有编号/文字 | 缺陷数超过 300 时画面只画前 300 个并写明提示（端口与判定仍是全量）；渲染整体失败时`DefectImage`为空但**不影响判定** |
| 判定 NG 但流程当成失败走了异常分支 | 不会。NG 是正常结果，`Success` = true，原因写在`ErrorMessage`。分流请用`IsOk`而不是执行状态 |
| 阈值/面积参数"自己变了" | 只有**配置界面**在参数仍为出厂默认值时才自动适配一次；改过就不再覆盖。若仍出现，确认 `Modules\` 下加载的是本版本插件 DLL（旧副本残留会让人误以为改动没生效） |

## 五、四个常用配方

**案例 1｜固定阈值检暗斑（最常用）**
`二值化方式 = 固定阈值`、`检测目标 = 暗缺陷`；直方图把`上限灰度`拖到背景主峰的左肩（例：背景 180~200，缺陷 90~140 → 区间 0~150）；`面积下限 = 30`；`缺陷个数上限`按规格。

**案例 2｜动态阈值（打光不匀的救命稻草）**
`二值化方式 = 动态阈值`、`检测目标 = 暗缺陷`；缺陷约 5 像素宽 → `局部窗口宽/高 = 15`；`标准差权重 = 0.4` 起步，误报多就加到 0.8~1.2；低对比区域漏检就适当加大`绝对灰度偏移`（反向：太严就减小）。

**案例 3｜合并断裂的划痕**
一条 60 像素长的划痕被打光切成 3 段、段间空隙约 4 像素 → `合并半径 = 3`（空隙 < 2×3），个数从 3 变 1，面积也合并成真实值。

**案例 4｜排除触边**
透明膜卷边缘反光稳定误报，宽度约 12 像素 → `排除触边 = 15`；画面中间的二维码用`排除区域`端口接它的 ROI。

## 六、上线前检查清单

- [ ] 用**良品 + 已知 NG 样**各跑一批，确认`IsOk`与人工判定一致；
- [ ] NG 原因文案能在现场说清楚（个数超标 / 面积超标 / 总面积超标 / 个数不足）；
- [ ] `运行显示窗口`设好（1~9），操作员能立刻看到缺陷在哪；不需要发窗口就填 0，`DefectImage`照样给下游存图；
- [ ] `输出排序`与报表口径一致（默认"不排序"的顺序不可预期）；
- [ ] 像素当量与标定连线口径确认（接了标定就以标定为准）；
- [ ] 面积/个数规格是**像素**口径，换相机分辨率后必须重算。
