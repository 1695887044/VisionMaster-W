# Blob 缺陷检测 · 快速上手

> 分类：缺陷检测 ｜ 来源：插件 Plugin.BlobDetect

把图里"比背景暗（或亮）的可疑像素"切成二值区域 → 拆成一个个连通域 → 按面积/圆度/长宽比/触边筛掉噪声 →
数个数、量面积 → 与规格比对给出 **OK/NG**，同时叠一张红圈 + 逐缺陷编号 + 判定文字的标注图。
它回答的是"**有没有缺陷、有几个、最大多大、合不合格**"——划痕、暗斑、脏污、气泡、麻点、异物这类检测的主力算子。
工具库里的名字是「Blob 缺陷检测」，分组在**缺陷检测**。

## 一轮检测产出什么

```
输入图像（SrcImage，1/3/4 通道都行）
      │
      ├─▶ DefectImage   标注图：原图 + 缺陷红边 + 逐个编号 + 左上角判定横幅
      ├─▶ Defects       缺陷区域集合，可直接给下游再分析
      ├─▶ DefectCount / MaxArea / TotalArea          个数、最大单缺陷面积、总面积（都是像素）
      ├─▶ MaxAreaMm2 / TotalAreaMm2                  同一量的毫米平方口径
      ├─▶ IsOk / ErrorMessage                        判定结果；NG 时原因写在这里
      └─▶ 8 个数组端口：中心行/列、面积、宽、高、圆度、长宽比、方向角
                       └── 与 Defects 逐项对齐，编号 1 = 数组第 0 项
```

## 它内部按这五步走

```
① 转灰度   → 彩色/多通道先归一成单通道（1 通道直接用，3 通道彩色转灰度，4 通道丢 alpha 再转）
② 二值化   → 按阈值把"可疑像素"切出来（固定 / 自动 / 动态三种方式，见 04 页第三节）
③ 形态学   → 开运算去毛刺、闭运算补孔连断口、合并半径把断成几段的划痕接回去
④ 拆连通域 → 一片片区域拆开，每片 = 一个候选缺陷
⑤ 筛选+判定 → 按面积/圆度/长宽比/触边筛掉噪声，再与规格比对给 OK/NG，并叠标注图
```

第 ① 步解释了"为什么彩色图也能检缺陷"：Blob 只看灰度，彩色信息在第一步就被归一掉了（标注图底图仍保持彩色）。
第 ③④ 步的先后顺序固定，`合并半径`必须排在"拆连通域"之后才有意义——详见 04 页第四节。

## 第一次配检测（六步）

1. **接图**：把前级（图像采集 / 创建 ROI / 预处理）的图像连到`输入图像`（端口 `SrcImage`）。
2. **选二值化方式**：图干净、明暗稳定 → `固定阈值`；想省事、产品换型频繁 → `自动阈值`；
   **打光不匀 / 曲面 / 有渐变** → `动态阈值`。
3. **看直方图定阈值**：右侧切到「数据输出」页签看**灰度直方图**，图上两条竖线就是当前的`下限灰度`/`上限灰度`，
   按住可以左右拖。把区间收到"缺陷那一坨"上：拖到背景峰与缺陷峰之间的**谷底**就是最佳分割点。
4. **设筛选**：`面积下限`滤噪点（默认 30，噪声多就调大）；要区分气泡与划痕再动`圆度下限`/`长宽比上限`；
   边缘有假缺陷就设`排除触边(px)`；画面中间的固定干扰（螺丝孔、二维码）接`排除区域`。
5. **设判定规格**：`缺陷个数上限` / `单个缺陷面积上限` / `缺陷总面积上限`按产品规格填；
   做"这个标记在不在"的存在性检测就填`缺陷个数下限`。
6. **看标注图核对**：红圈有没有圈对、编号有没有落在缺陷上。清单里点某一行 → 图上给那个缺陷套**黄框**，逐个核对。

> 第一次加载图像时，若**所有参数都还是出厂默认值**，插件会按这张图自动适配一次：阈值取实际灰度范围里
> 最暗（或最亮）的 25% 作保守带，面积按画幅比例从 640×480 基准缩放。这给的只是**可用起点、不是正确值**——
> 一旦你改过任何一个参数就不再自动覆盖；想重来一次点「按当前图像重新适配」。

## 典型接线

```
① 最常用：固定阈值检暗斑
图像采集.OutputImage ──▶ Blob检测.SrcImage
创建ROI.MaskRegion ────▶ Blob检测.MaskRegion     （可选：只在产品区域内找）
创建ROI.MaskRegion ────▶ Blob检测.ExcludeRegion  （可选：螺丝孔/二维码一律不报）
标定.MmPerPixel ───────▶ Blob检测.MmPerPixel     （可选：让 mm² 输出成真值）
Blob检测.IsOk ─────────▶ 条件分支 / 结果上报       （NG 报警、OK 放行）
Blob检测.DefectImage ──▶ 数据记录.图片            （留证据图）
Blob检测.DefectAreas ──▶ C#脚本                   （分拣：气泡 vs 划痕）

② 打光不匀：换动态阈值
预处理.Image ──▶ Blob检测.SrcImage   （局部窗口宽/高取缺陷尺寸的 2~3 倍）

③ 存在性检测（有没有这个标记）
缺陷个数下限 = 1 → 一个都没检到就 NG

④ 先定位再检测
模板匹配.AlignedImage ──▶ Blob检测.SrcImage   （工件位置飘，先对齐再检缺陷）
```

## 三个必须先建立的口径

- **NG 不是执行失败**。判 NG 是正常结果（步骤仍然成功、流程照走），原因写在 `ErrorMessage`；
  分流请用 `IsOk`，别拿"执行状态"当判定。
- **筛选 ≠ 判定**。`面积下限`/`面积上限`/`圆度下限`/`长宽比上限`/`排除触边` 决定"这东西算不算缺陷"，
  被筛掉的**既不计数也不判 NG**；`缺陷个数上限`等四项才决定"合不合格"。详见 04 页。
- **面积与尺寸默认是像素口径**。`MaxArea` `TotalArea` `DefectAreas` 和所有判定阈值都是像素；
  只有 `MaxAreaMm2` / `TotalAreaMm2` 是物理量，而且像素当量不参与判定。

## 分工与边界：什么时候该用、什么时候不该用

本算子**靠规则判定（灰度、面积、形状），不需要训练样本**——这是它相对深度学习方法的全部优势，
也是它的上限：规则写得出来的缺陷才检得出来。仓库里三个算子各管一件事，别混用：

| 你要回答的问题 | 该用的算子 |
| --- | --- |
| 这片图里有没有异常、有几个、最大多大、合不合格 | 本算子「Blob 缺陷检测」 |
| 目标在不在、在哪、姿态对不对 | 「模板匹配」 |
| 图干不干净（增强、滤波、白平衡），检不检得出先看这步 | 「图像预处理」 |
| 缺陷种类说不清规则、只能"靠经验认" | 「YOLO 目标检测」或深度学习分类 |
