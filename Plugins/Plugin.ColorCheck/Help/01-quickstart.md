# 颜色序列检查 · 快速上手

> 分类：图像处理 ｜ 来源：插件 Plugin.ColorCheck

**这个算子干的事**：在你框出的**采样区**里沿短轴扫出**一维颜色序列**（例如 `黑,白,灰,紫,蓝,绿,黄,红,玫红,棕`），
再和**期望序列**逐位比对，回答两件事——**根数对不对、顺序对不对**。
它不认识"线"这个字，只认"一串颜色"，所以线序、排线、印刷色带、色块标签用的是同一个节点。

配套五页：《颜色序列检查 · 界面与操作》讲画布与每个按钮；《颜色序列检查 · 端口与参数》给端口/参数全表；
《颜色序列检查 · 颜色口径与判定》讲颜色词、判据与**每个旋钮往哪调**；《颜色序列检查 · 排障》按真实报错文案逐条对、
末尾附换灯换型的重调顺序；开发三页（架构与数据流 / 宿主契约 / 不变量与陷阱清单）给改这个插件的人看。

## 跑通第一次：6 步

| 步 | 动作 | 看到什么算对 |
| --- | --- | --- |
| 1 | 从工具箱「图像处理」分组把**颜色序列检查**拖进流程画布 | 流程栏出现一个步骤节点 |
| 2 | 从上游（图像采集一类）的输出**拖一条线**到本节点的 `Image`；或右键本节点 → 变量绑定，选上游的图像输出 | 连线上有箭头，编译不报「连线类型不匹配」 |
| 3 | 双击本节点打开配置窗口，点一次**执行** | 右侧画布出现上游那张图。这一步会报**尚未框选采样区**——那是对的，图这时候才上屏 |
| 4 | 在右侧图上**右键 → 新建矩形**，框住整条线束/整条色带 | 左栏「当前采样区」从"尚未框选采样区"变成 `中心 (行, 列) 角度 … 半长 … 半宽 …` |
| 5 | 点**试算一下** | 结果框出现六行：根数与序列 / 线距 / 三个阈值 / 逐根来源（检、补）/ 期望与配方名 / 判定 |
| 6 | 点**把试算结果存成配方**，然后确认关闭配置 | 配方框末尾多一行 `10 芯 = 黑,白,…`；下次执行不再报"未知产品" |

跑通后：流程执行完，主界面**视图窗口 1** 上是**底图 + 一条采样线 + 逐根颜色标签 + 一行结论**；
合格时采样线与结论是绿的，不合格是红的，不符的那一根单独标红，**规整补出来的那几根是橙字**。

## 框的画法（唯一一件必须先懂的事）

| 轴 | 含义 |
| --- | --- |
| 长边（半长大的那条轴） | 线束**走向**——沿线排开的方向 |
| 短边 | **采样方向**——扫过每一根线的方向 |

- 长轴由算法**自动判**，**竖着画、横着画都能用**，不需要按固定方向画框。
- 框要**贴住线束**：把大片浅色背景或连接器的金属触点圈进来，根数就会错。
- 短边至少要 **8 个像素**（太窄会直接报错）。
- 序列的**索引 0 是坐标较小的那一端**；方向和实物相反就勾「序列反向」，不用重画框。

## 最小配方写法

一行一条，`#` 开头是注释，空行忽略：

```
# 十芯主线束
10芯 = 黑,白,灰,紫,蓝,绿,黄,红,玫红,棕
5芯  = 棕,红,黄,绿,蓝
测试件第3位不检 = 黑,白,*,紫,蓝
```

- 颜色词**只有** `黑 白 灰 棕 红 玫红 橙 黄 绿 蓝 紫` 十一个，写 `深红`、`天蓝`、`magenta` 一律认不出。
  正解是用第 6 步那个按钮一键生成，不手打。
- `*` 表示**这一位不检**。
- 匹配方式是**按实测根数挑配方**（期望序列的长度就是这条配方要求几根）；不带等号的行按"整行就是颜色序列"处理，产品名自动取「N 芯」。
- 想钉死"这一轮比哪条"，把期望序列喂进 `ExpectedSequence` 输入端口——**填了端口就完全绕过配方表**。

## 三个常见的第一反应

**Q：第一次点执行报"上游没有图像…"，是不是没连上？**
不是。这个报错的原文就带着补救办法（把 `Image` 连到上游、或右键变量绑定）。
如果**已经**连上却还报这条，先确认上游那一步自己也跑成功了——上游没出图，这里自然拿不到。

**Q：判定不合格（`Result=false`）算不算这一步失败？**
不算。线序错、根数不符时这一步**照常跑通**，八个输出端口全部齐全，下游用 `Result` / `BadIndex` / `Verdict` 分流即可。
只有**跑不动**才失败（`Success=false` + `ErrorMessage`），例如没框采样区、送进来的是灰度图。

**Q：报"未知产品：N 芯没有对应配方"，产品不良吗？**
不是，这是**工程配置缺失**，算子有意报错把流程停住而**不判 NG**（配错的配方会把良品永远报成不良，现场只会以为这批货有问题）。
补一条长度为 N 的配方，或用 `ExpectedSequence` 端口把期望序列直接给进来。
