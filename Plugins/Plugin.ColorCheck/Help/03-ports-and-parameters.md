# 颜色序列检查 · 端口与参数

> 分类：图像处理 ｜ 来源：插件 Plugin.ColorCheck

本页是**全表**：两个输入端口、九个自有输出端口（外加基类两个）、25 个 `[StepConfig]` 配置项的
名字、类型、默认值与"接不上/填错会怎样"。含义、判据与**每个旋钮往哪调**见《颜色序列检查 · 颜色口径与判定》。

## 输入端口

| 端口 | 类型 | 必填 | 接不上/不接会怎样 |
| --- | --- | --- | --- |
| `Image` | `HImage` | 编译期**不强制**，运行期必需 | 运行期没有图或图未初始化 → 本步骤 `Fail`，报错原文即"上游没有图像：请先在流程里把本节点的 Image 连到上游…"。必须是**三通道彩色图**（`CountChannels` < 3 直接失败）；12/16 位高位深图自动等比压回 8 位再判色 |
| `ExpectedSequence` | `string` | 否 | 留空则按实测根数去配方表里挑。**填了就以端口为准、完全绕过配方表**（工单/数据库下发就是这个用法）。逗号分隔，中英文逗号与顿号都认；某一位写 `*` 表示该位不检 |

- `Image` 的 `IsRequired = false`：**编译期不会因为没接线而拦你**，错误在运行期才出现——这是有意为之，
  好让"先打开配置框一个采样区"这条路径走得通（点一次执行，上游图会自动显示到配置界面右侧）。
- `ExpectedSequence` 声明成 `string` 而**不是枚举**：枚举端口经步骤的 `InputValues` 往返会抛
  `InvalidCastException`（内核里 `RoiShapeNames` 用字符串而不是枚举，同一个坑）。
- **采样区不接上游 ROI**：它是本算子内部在图上框出来的矩形参数 `RoiParams`，上游只进 `Image`。
  想让上游先裁好再送过来，把「ROI」算子的 `Domain_名字` 输出接到 `Image`。

## 输出端口

| 端口 | 类型 | 含义 |
| --- | --- | --- |
| `Result` | `bool` | 判定结论：`true` = 合格 / `false` = 不合格。**不合格时本步骤仍然算跑通** |
| `BadIndex` | `int` | 第一位不符的序号（**从 1 起**）；`0` = 全对，**或者根数本身就不符**（长度对不上时无从谈"第几位"） |
| `Verdict` | `string` | 结论全文，写给人看的那一句。日志、画面标注、界面摘要、下游上报**共用同一句** |
| `Expected` | `string` | 本次比对用的期望序列（回显，用来排查"到底比的哪条配方"）。来源是端口时配方名显示「输入端口」 |
| `Count` | `int` | 根数 |
| `Sequence` | `string` | 颜色序列，逗号分隔 |
| `Detail` | `string` | 逐根明细：`1黑检,2白补,…`。`检` = 命中可靠段（真的看到）；`补` = 按等间距规整补出来的 |
| `Rows` | `string` | 每根线中心的**图像行号**（逗号分隔，由剖面坐标经换算表线性插值译回图像坐标后四舍五入） |
| `Annotations` | `List<MeasureAnnotation>` | 本轮投射用的标注列表（采样线 + 逐根标签 + 结论行）。**不烘焙、不开窗**；接「结果显示」的结果项即可烧进最终图，供「图像赋值」写到 SCADA |
| `Success` | `bool` | 基类自带：本步骤是否跑通 |
| `ErrorMessage` | `string` | 基类自带：失败时的中文原因（`LastError` 读的是它） |

**只有九个口，没有动态端口**：根数不固定，所以不按"第几根"生成 `Color1`、`Color2` 这类口。
要逐根取色就把 `Sequence` / `Detail` 交给下游脚本或 CSV 记录自己切。

## 配置项：采样与判定（10 项）

| 参数 | 类型 | 默认 | 说明 / 填错会怎样 |
| --- | --- | --- | --- |
| `RoiParams` | `double[]` | 空数组（未框选） | 采样区矩形，5 个数：`[中心行, 中心列, 角度(弧度), 半长, 半宽]`（Halcon Rectangle 约定）。**在配置界面的图上右键新建，别手打**。不是 5 个数 → 运行期直接失败"尚未框选采样区"；半长或半宽 ≤ 0 → "采样区的半长/半宽必须大于 0：请重新画一个框" |
| `ReverseSequence` | `bool` | `false` | 序列反向：把名字、来源标记、位置一起首尾对调（位置按 `长度-1-位置` 镜像），**反向发生在判定之前**，所以配方也要按反过来的顺序写 |
| `WireCount` | `int` | `0` | 手动指定线数；`0` 或负数 = 自动反推。填正数且与自动值不同时，**以检出范围的中点为基准**向两边展开，日志留一条说明 |
| `Regularize` | `bool` | `true` | 等间距规整化：开 = 按估出的线距铺满整束（**能补出看不见的白线**）；关 = 只报直接看得见的可靠段（调参对照组，端点外推与手动线数在关闭时都不生效） |
| `DarkSpanRatio` | `double` | `35` | 暗线判据幅度（百分比）。两张样本图上的安全阈值窗口是 **100~160**，默认 35 给出 154 与 114 |
| `BrightPercentile` | `double` | `92` | 白线百分位：亮度高于这条百分位算可靠线像素。白线检不到 → 调低；浅色背景被收成过长段 → 调高 |
| `MinRun` | `int` | `4` | 最小段长：连续这么多行都可靠才算一根线（滤噪点）。线很细时调小 |
| `MaxRunRatio` | `double` | `0.33` | 最大段长比例：长过剖面长度这个比例的可靠段**按背景丢弃**。填 `0` = 关掉这条保护 |
| `RuleWindowRatio` | `double` | `0.30` | 补色窗口半宽（**线距的比例**）：给"补出来"的那几根取中位色的窗口大小。线很密时调小 |
| `ExtendEnds` | `bool` | `true` | 端点外推：两端各多探一根，判据是"那一格里有明暗起伏"（≥ 全局起伏的 20%），不要求认得出颜色 |

## 配置项：颜色判据阈值（13 项）

默认值取自内核 `Core.Halcon.Color.ColorThresholds`，**本算子带一份可覆盖的副本**，随方案落盘，
改它不影响别的工位、别的颜色算子。界面上在 高级参数 → 颜色判据阈值（共用控件 `ColorThresholdEditor`）。

| 参数 | 类型 | 默认 | 界面标签 |
| --- | --- | --- | --- |
| `ColorlessSaturation` | `double` | `0.45` | 无彩饱和度（无彩/有彩分界，黑/白/灰/棕全住在这条线以下） |
| `BlackValue` | `double` | `80` | 黑明度 |
| `WhiteSaturation` | `double` | `0.15` | 白饱和度（白的附加条件） |
| `WhiteValue` | `double` | `195` | 白明度 |
| `BrownWarmth` | `int` | `12` | 棕暖度（R 比 G、B **都**高出这么多才算棕） |
| `BrownValue` | `double` | `175` | 棕明度（比它亮就归灰） |
| `RoseHueFrom` | `double` | `330` | 玫红起点（色相，度） |
| `RedHueFrom` | `double` | `350` | 红起点 |
| `RedHueTo` | `double` | `20` | 红止点（红跨 0 度：`≥350` 或 `<20` 都是红） |
| `OrangeHueTo` | `double` | `45` | 橙止点 |
| `YellowHueTo` | `double` | `70` | 黄止点 |
| `GreenHueTo` | `double` | `160` | 绿止点 |
| `BlueHueTo` | `double` | `230` | 蓝止点（比它高就是紫） |

## 配置项：配方与显示（2 项）

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `RecipeText` | `string` | 空 | 配方表正文，一行一条 `产品名 = 颜色1,颜色2,…`；`#` 开头注释、空行忽略；不带等号按"整行就是颜色序列"处理，产品名自动取「N 芯」。某芯数**多条同长**时取第一条并留告警 |
| `DisplayViewIndex` | `int` | `1` | 结果投射到主界面第几个视图窗口（1~9），**窗口号原样直传**（不做 +1、不做映射）；`0` = 完全不投射 |

## 界面上有、但不是配置项的东西

| 名字 | 是什么 | 会不会落进 `.vms` |
| --- | --- | --- |
| `Hint` | 界面底部的一行提示（载入图、存配方的反馈都走它） | **不标 `[StepConfig]`，不落盘** |
| `ResultSummary` | 试算结果摘要框的正文 | 不落盘 |
| `RoiSummary` | 「当前采样区」那行摘要（由 `RoiParams` 现算，角度换算成度） | 不落盘（派生只读） |
| `CanvasRois` / `CanvasActiveRoi` | 画布集合与当前编辑句柄，控件绑定用 | 不落盘（真源是 `RoiParams`） |
| `DisplayImage` | 配置界面显示的那张图，**上游图的私有副本** | 不落盘 |

**本算子没有任何枚举型配置**，界面上全是数字框、勾选框和多行文本，
因此不存在"下拉显示英文成员名"那类显示欠账（AGENTS.md R40 的欠账清单里没有本插件）。
