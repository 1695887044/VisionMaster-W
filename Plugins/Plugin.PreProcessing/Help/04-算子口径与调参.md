## 0. 先记住两条贯穿全链的口径

**① 全程只有图像，没有区域。**
本插件所有算子都是"图像进、图像出"，包括二值化——它输出的是一张只有 0 和 255 的**单通道图像**，
不是区域对象。灰度形态学做的是**对灰度值取邻域最值**，也不是二值区域运算。
需要区域时，请把二值化后的图接到下游的 Blob 检测 / 区域类算子去生成。

**② 尺寸类算子会连带影响所有像素单位的参数。**
「固定框裁剪」「修改图像尺寸」「按比例缩放」「对角镜像」「图像旋转（90/270 度）」都会改宽高。
下游若拿坐标与原图对齐，必须在改尺寸之前做，或者在下游自己换算。
只想"别让下游看见框外"而保持坐标系不变，用「框外屏蔽」而不是裁剪。

**③ 顶帽 / 黑帽 / 边缘检测输出的是"特征图"，不是"干净图"。**
顶帽输出"原图里比模板小的亮结构"，黑帽输出"比模板小的暗结构"，边缘检测输出"梯度/二阶差分"。
它们把背景压成 0、把要找的东西留下，**不是**给下游继续做亮度/对比度调整的普通灰度图。
正确接法通常是：顶帽/黑帽/边缘图 → 二值化 → Blob/轮廓类下游。
反过来，如果你要的是"把图洗干净"，用开/闭运算或滤波，不要用顶帽/黑帽。

## 1. 色彩与通道

处理链的第一族：**把彩色图变成后续算子能用的单通道图**。除了本族这一个算子，链上其余算子都按灰度图设计，
所以多数方案的第一步就是它。

### 彩色空间转换

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 转换方式 | 转灰度（三通道加权合成） | 转灰度（三通道加权合成）/ RGB 通道分离（取某一个通道）/ HSV 色彩空间 / HSI 色彩空间 / YUV 色彩空间 / CIELAB 色彩空间。选转灰度时通道号无意义 |
| 输出通道 | 第一通道 | 转换后取第几个通道（1 基）。选"RGB 通道分离"时即取 R / G / B 中的第几个 |

**口径**：输入一张彩色图，输出一张**单通道**图。转灰度是三通道加权合成成一个通道；
通道分离是拆开只留一个；HSV / HSI / YUV / CIELAB 是先整体变换再取指定通道。
对彩色图做灰度化或取通道都会**丢掉颜色信息**，所以这一步要放在链上"还想用颜色"的最后一个位置。

**什么时候用哪个**：

- 只是要给下游一张灰度图：用默认的转灰度。加权合成保留亮度信息，对"深浅不同的灰度差"最稳，是工业默认选择。
- 靠颜色区分的目标（红章、彩色标签、油墨色标）：先用 RGB 通道分离试。
  目标在某个通道上"消失"或"变最深"，说明这个通道对比最强。
  例：红色目标在 R 通道偏亮、在 G/B 通道偏暗——想突出深色目标就取 G 或 B。
- HSV 三通道依序是**色调 / 饱和度 / 明度**，打光均匀但颜色深浅变化大的场景常取第三通道（明度）。
  HSI、YUV、CIELAB 同理，是几种不同的加权/坐标方式，哪个能把目标和背景的灰度差拉开就用哪个。
  拿不准就三种各跑一次，用逐步预览对比，比背公式有用。

**选通道的省时走法**：预览停在"算子输出"并选中这一步 → 依次把转换方式设为 RGB 通道分离、通道 1/2/3 各看一次 →
挑反差最大的那张（可用「导出图片」按步存出对比）→ 都不理想再回到 HSV / HSI / YUV / CIELAB 重复一遍 →
调好后留在链首，后面所有算子面对的就是这张对比度最高的灰度图。

**现象 → 先查**：

- 画面全黑或全白：多半取到的通道在目标上没有对比，换「转换方式」再对比，别先去调后面的阈值。
- 对本来就是灰度的图跑了这一步、画面没变：**设计行为**，单通道图没有"色彩空间"可言，算子原样透传。
- 彩色转灰度后目标反而看不清：加权合成把颜色和亮度混在一起了，改用通道分离或换一种色彩空间。

## 2. 几何调整

这一族改的是**像素的位置与画布尺寸**：镜像、旋转、改尺寸、缩放、裁剪、框外屏蔽。
建议放在链的前面——改完尺寸再开始调滤波与阈值。除「固定框裁剪」外，其余都只改摆位或画布，不改内容。

### 图像镜像

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 镜像方式 | 水平镜像（左右翻转） | 水平镜像（左右翻转）/ 垂直镜像（上下翻转）/ 对角镜像（沿主对角线翻转）。**对角镜像会把宽高互换** |

### 图像旋转

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 旋转角度 | 180 度 | 90 度 / 180 度 / 270 度。旋转**不放大画布**：90/270 度时超出原画布的四角会被裁掉 |

非 90 度整数倍的倾斜校正不归本插件管——本族只做整角度。
工件有随机角度时先走模板匹配定位，或用带角度的 ROI 把目标转正后再进这条链。

### 修改图像尺寸

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 目标宽度 | 0 | 0 = 沿用原图宽度。超出部分裁掉，不足部分补 0（黑） |
| 目标高度 | 0 | 0 = 沿用原图高度。同上 |

算的是**画布**不是缩放：1000 宽改成 800 就是砍掉右边 200 列，改成 1200 就是右边补 200 列黑。
两项都等于原尺寸（或都填 0）时透传。用途：统一多相机/多型号的画布尺寸，让下游按固定坐标取数。

### 固定框裁剪

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 中心行 | 0 | 框中心所在行（像素，0 基），也可在画布上直接拖 |
| 中心列 | 0 | 框中心所在列（像素，0 基） |
| 框宽度 | 0 | **整宽**（不是半宽）。填 0 = 还没框，本算子原样透传 |
| 框高度 | 0 | **整高**（不是半高）。同上 |

只做**正框**（不倾斜）。输出图的宽高就是框的宽高，**坐标系从 0 重新起算**——
下游原来按原图坐标填的参数，跨过这一步都要改成"相对裁剪框"的坐标。
框正好盖住整张图时按透传处理（裁剪是恒等变换，省一次全图拷贝）。

### 按比例缩放

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 行方向因子 | 1.0 | 垂直方向（高度）缩放比例，>1 放大、<1 缩小；合法 0.01~20，超出自动夹取 |
| 列方向因子 | 1.0 | 水平方向（宽度）缩放比例，同上 |
| 插值方式 | 双线性 | 最近邻（最快，放大后有明显锯齿）/ 双线性（速度与质量折中）/ 双三次（最平滑，最慢） |

行、列分开填的用意：线扫图像常在行方向过采样，只需压行；看细节时双向一起放大。
**放大后还要测尺寸的，别用最近邻**（锯齿会让边缘位置抖动）。两个因子都是 1 时透传。

### 框外屏蔽

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 中心行 / 中心列 / 框宽度 / 框高度 | 0 | 同「固定框裁剪」：整宽整高；宽或高 ≤ 0 = 未框选，透传 |
| 框外灰度 | 0 | 框外填充的灰度值（0~255）。彩色图会把三个通道都填成这个值，即一种灰色 |

框内保留原像素、框外整片涂掉，**图像尺寸不变、坐标系与原图一致**。
取舍：只要"别让下游看见框外"、又要下游继续用原图坐标 → 屏蔽；想少算一半像素提速 → 裁剪。
两者也可以连用，但先屏蔽再裁剪时，裁剪之后屏蔽已经没有意义。

**现象 → 先查（本族）**：

- 框拖出图外没报错、结果偏小：越界的处置是"自动夹取到图内"，摘要会挂"（越界已夹取）"，日志有一条 Warn。把框画回图内。
- 拖了半天框、输出还是整张图：宽或高还留着 0（未框选 = 透传）；另确认拖框时预览处在「输入图」态。
- 90 度旋转后四角内容不见了：旋转不放大画布，超出部分本来就会被裁掉。先加「修改图像尺寸」把画布开大再旋转。
- 改完宽高下游所有位置参数都错位：尺寸变化的必然结果。要保坐标系就用「框外屏蔽」替代裁剪。
- 缩放后发糊/有锯齿：插值选的是最近邻。放大看细节改双三次，纯提速保持最近邻。
- 裁剪后图比预期小一圈：先查有没有越界夹取，再查填的是整宽还是半宽——界面要的是**整宽整高**。

## 3. 滤波

滤波是为了让**下游只看见真实的灰度变化，看不见噪声**。四个算子各有明确症状，
选错的表现通常是"噪声小了但边缘也糊了，阈值怎么调都切不干净"。

| 图上的症状 | 用哪个 | 为什么 |
| --- | --- | --- |
| 整幅细碎的灰度抖动（传感器噪声、压缩纹） | 均值滤波 | 邻域求平均，最快最省事，代价是糊边缘 |
| 孤立的白点/黑点（椒盐噪声、灰尘、脏点） | 中值滤波 | 取邻域中值，点噪声被邻居"投票"掉，边缘基本不动 |
| 想平滑但尽量保住边缘形状 | 高斯滤波 | 中心权重高的加权平滑，比均值自然 |
| **整幅周期性的条纹**（摩尔纹、纱窗纹、扫描线、布纹） | FFT 频域滤波（陷波/带阻） | 周期性干扰在频谱上是一根孤立谱线，空域滤波按邻域办事去不掉它，只能在频域点掉 |
| 缺陷本身就是细小亮点/暗点 | **别用滤波** | 滤波会把缺陷一起抹掉。改用灰度形态学：它按"结构尺寸"选择性处理 |

### 均值滤波

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 模板宽度 | 5 | 矩形模板宽度（像素），1~999，填 0 或负数收敛到 1 |
| 模板高度 | 5 | 矩形模板高度，同上 |

模板越大越平滑也越糊。经验起点：模板边长取"噪声颗粒尺寸"的 2~3 倍，
不要一步跨到覆盖整个特征——那等于把要检的东西抹平了。

### 中值滤波

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 模板形状 | 方形 | 方形 / 圆形。HALCON 23.05 的 median_image 不接受菱形；圆形取各向同性邻域（不带方形的直角） |
| 模板半径 | 5 | 邻域**半径**，实际边长约 2×半径+1（半径 5 ≈ 11×11）；合法 1~50 |
| 边缘扩充 | 镜像扩充 | 图像边界外的像素怎么补：镜像扩充（用翻转的邻边补，工业默认更稳）/ 循环扩充（把图对侧内容搬过来补，仅当内容本身上下/左右连续时才合理） |

**半径是"半径"不是直径**，这是现场最常填错的一项：想要 5×5 的效果，半径应填 2 而不是 5。
去噪能力上限约为"邻域内一半像素"——比半径大的白点不会被清掉，会被当成真实结构保留。

### 高斯滤波

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 模板尺寸 | 5 | 必须是 3/5/7/9/11（HALCON 限制）；偶数/越界会收敛到最近合法值 |

尺寸是**整核边长**（不是半径），所以数字比中值的半径看着大一倍：效果上"尺寸 5 的均值/高斯"与"半径 2 的中值"量级接近。

### FFT 频域滤波

先把图变换到频域，按**到直流（0 频）的距离**留/去某个频带，再变换回来。
和上面三个空域滤波的本质区别：空域滤波按"邻域"办事，去不掉整幅图上周期性的条纹；
那类干扰在频谱上是一根孤立的亮点，只能在频域里点掉。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 滤波类型 | 低通 | 低通（只留低频，平滑去噪）/ 高通（只留高频，突出边缘）/ 带通（只留环带）/ 带阻（去掉环带）/ 陷波（点掉指定方向的周期干扰） |
| 过渡形状 | 高斯 | 理想（硬截止，边界振铃明显）/ 高斯（平滑过渡，无振铃，截止处增益 0.5）/ 巴特沃斯（二阶，比高斯陡、振铃比理想小） |
| 低频截止 | 0.05 | 归一化频率 **0~0.5**（0.5 = Nyquist）。高通只用它；带通/带阻是环带内边界 |
| 高频截止 | 0.15 | 归一化频率 **0~0.5**（0.5 = Nyquist）。低通只用它；带通/带阻是环带外边界 |
| 陷波中心行 | 0 | 仅陷波，归一化中心 −0.5~0.5，0 = 直流所在行 |
| 陷波中心列 | 0.15 | 仅陷波，归一化中心 −0.5~0.5，0 = 直流所在列 |
| 陷波半径 | 0.03 | 仅陷波，归一化半径 0~0.5。太小去不掉干扰，太大连同有用细节一起挖掉 |
| 保留直流 | 勾选 | 仅陷波：陷波圈碰到直流（0 频）时不挖掉它。默认勾选，避免整幅图被整体挖空 |

**频率怎么填**（这一步最容易填错）：单位是 **cycles/pixel**，0.5 就是 Nyquist，
所以 `频率 = 1 / 周期像素数`。图上一段条纹每 8 个像素重复一次 → 频率 0.125；
每 4 个像素重复一次 → 0.25（已经到极限，再密就会混叠）。

- **竖条纹**（沿列方向明暗变化，行方向不变）：谱线落在"行 = 0"这条线上，
  把「陷波中心列」填成它的频率，「陷波中心行」保持 0。
- **横条纹**：反过来，「陷波中心行」填频率，「陷波中心列」保持 0。
- **斜纹**：行、列各填一个分量（分别是两个方向上的频率）。
- 拿不准频率时：先用「固定框裁剪」取一小块纯纹理区，用逐步预览看它每几个像素重复一次，
  按 `1/周期` 填；半径从 0.02 起试，够盖住那根谱线就行。

**什么时候用哪个类型**：

| 想干的事 | 用哪个 | 怎么填 |
| --- | --- | --- |
| 去掉一条/几条周期条纹，其余原样 | 陷波 | 中心 = 条纹频率，半径小（0.02~0.05） |
| 去掉某一圈频率的干扰（如网格纹、织布纹，频率有散布） | 带阻 | 低频/高频截止夹住那圈，半径按散布宽度给 |
| 只要某个频带的纹理（如表面划痕的增强） | 带通 | 同上，反过来留环带 |
| 整体平滑、不要空域滤波那种"糊边" | 低通 | 高频截止按"要保留的最细结构"填 |
| 只要边缘/细节，把大块明暗压掉 | 高通 | 低频截止按"要压掉的大结构"填 |

**五条必须知道的坑**：

1. **输出会被自动拉满对比度**。算子在反变换之后做 min/max 归一化（和「灰度归一化」同一口径），
   所以输出的 0~255 与原图的灰阶**不再一一对应**：只去掉一点点频率，画面看上去也会"变亮/变通透"。
   判读效果请看**结构有没有变**（条纹还在不在），不要拿灰度值和原图比。
2. **归一化频率与图像尺寸绑定**。同一个物理条纹，相机分辨率翻倍 → 像素周期翻倍 → 频率减半，
   参数要重填。换相机/换倍率之后必须重新标一次频率。
3. **直流（0 频）是图像的平均亮度**。低通/带通/带阻都把直流当普通频率处理：
   高通和带通会去掉平均亮度（结果以 0 为中心，归一化后照样能看，但"背景灰度"已经没了）；
   陷波用「保留直流」防止陷波圈误挖直流。
4. **边界振铃**。FFT 把图像当作**周期延拓**：左右/上下边界不连续时，反变换会在边缘出现一圈亮暗波纹。
   理想形状最明显，高斯最轻。办法是先用「框外屏蔽」把边缘涂平，或裁掉边缘几个像素再看结果。
5. **代价是整幅运算**。FFT 的耗时与内存随像素数增长（内部要一张同尺寸的 float 掩膜 + 两张复数频谱），
   大图（2000 万像素以上）会比空域滤波慢一个量级；先裁剪再滤波是最有效的提速。

**现象 → 先查（本族）**：

- 滤波后二值化切不出东西：目标和背景灰度差被一起抹平了。用逐步预览对比滤波前后两态，边缘已发虚就是模板太大，先减尺寸。
- 噪声还在但已经糊得没法测：均值滤波的天花板到了。换中值（点噪声）或灰度形态学（尺寸型噪声）。
- 图边缘出现亮/暗边框伪影：查中值的「边缘扩充」，换另一种试；也可先用「框外屏蔽」把边缘干扰带涂掉再滤波。
- 偶数尺寸没生效：高斯自动 +1 成奇数，以参数摘要显示的收敛值为准。
- 陷波/带阻跑完条纹还在：频率填错。按 `频率 = 1/周期像素数` 重算一遍，并确认竖条纹填的是「中心列」而不是「中心行」。
- 条纹没了但目标也跟着没了：陷波半径太大，把邻近的有用频率一起挖掉了。半径先减半再试（0.02 起）。
- 结果整体变亮、对比度变了：归一化的必然结果（min/max 拉满），不是参数错。看结构变化，别看灰度值。
- 图边缘出现一圈亮暗波纹：FFT 把图当周期延拓，边界不连续就会振铃。换「高斯」形状，或先用「框外屏蔽」把边缘涂平。
- 节拍不够：滤波代价随模板面积增长。先用「固定框裁剪」或「按比例缩放」把像素量降下来，比换算子有效得多。
  FFT 是整幅运算，这条对它更明显。

**放在链上哪儿**：惯例是裁剪 → 滤波 → 增强 → 二值化。
滤波放在裁剪之后（少算像素）、二值化之前（先把噪声压下去阈值区间才稳）。
**锐化不要放在滤波之前**——先放大噪声再去噪，等于白做一遍。
FFT 频域滤波也在这条线上，但**先保证边缘已经涂平**（框外屏蔽/裁剪），否则边界振铃会被下游当成缺陷。

## 4. 灰度形态学

**对灰度值做"邻域取最值"**：膨胀让亮区扩张、腐蚀让暗区扩张，开闭运算把两者串起来按结构尺寸选择性清理。
它是灰度算子，不是二值区域算子——可以在二值化**之前**用，也可以在二值图上直接改黑白块形状。

| 算子 | 干的事 | 典型用途 | 一句话判据 |
| --- | --- | --- | --- |
| 灰度膨胀 | 邻域内取最大值：亮区扩张 | 填补暗色裂纹、把断开的亮线连起来 | 想让"亮的更长、暗的更细"用它 |
| 灰度腐蚀 | 邻域内取最小值：暗区扩张 | 去掉细小亮点噪声 | 想让"暗的更长、亮的更细"用它 |
| 灰度开运算 | 先腐蚀后膨胀 | 滤掉**比模板小**的亮结构（白点噪声） | 去白点、保大体形状 |
| 灰度闭运算 | 先膨胀后腐蚀 | 填掉**比模板小**的暗结构（黑点、细裂缝） | 补黑点/裂缝、保大体形状 |
| 灰度顶帽 | 原图 − 开运算 | 把**比模板小**的亮结构单独拿出来（亮斑、毛刺、亮点） | 要找"被开运算清掉的亮东西"用它 |
| 灰度黑帽 | 闭运算 − 原图 | 把**比模板小**的暗结构单独拿出来（暗点、裂纹、黑斑） | 要找"被闭运算填掉的暗东西"用它 |

顺序不是随便排的：开 = 腐→膨，闭 = 膨→腐，都是"先动一刀再用相反的一刀把尺寸还回去"，
所以目标和背景的整体面积基本不变，只有比模板小的结构被清掉。这就是它们比单纯膨胀/腐蚀更适合去噪的原因。

**顶帽/黑帽与开/闭的分工**（最容易混的一处）：

- **开/闭**回答"把图洗干净"：输出仍是原图尺寸/量纲的灰度图，亮斑被清掉后背景保持原样。
- **顶帽/黑帽**回答"被清掉的东西长什么样"：输出是**残差图**，背景变 0、只留下被清掉的亮/暗结构。
  顶帽 = 原图 − 开运算（亮残差）；黑帽 = 闭运算 − 原图（暗残差）。
- 所以顶帽/黑帽后面通常直接接**二值化 → Blob/轮廓**，而不是接亮度/对比度调整。
- 极性反了（亮缺陷用了黑帽、暗缺陷用了顶帽）的表现是"整张几乎全黑、什么都找不到"，
  不是参数没调好——先换算子再调模板。

六个算子参数完全相同：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 模板宽度 | 5 | 矩形模板宽度（像素），1~999，填 0 或负数收敛到 1 |
| 模板高度 | 5 | 矩形模板高度，同上 |

模板就是"多大算噪声"的分界线：**比模板小的亮（暗）结构被清掉，比模板大的保留**。
填法只有一条规则——按要去掉的干扰尺寸填，并让它**小于真实特征的最小尺寸**。
例：白噪点直径 3 px、要保留的最小字符笔画宽 5 px，模板取 5×5 就能吃掉噪点而基本不动笔画。
宽高可以不等：竖条纹干扰用窄高模板（小宽度、大高度），横条纹反之。

顶帽/黑帽的模板口径要**反过来想**：它要**大于要检的缺陷**、同时小于背景变化的尺度。
模板小于缺陷 → 缺陷被开/闭保留下来，残差接近 0（"什么都没检到"）；
模板过大 → 背景的缓变梯度也被当成"大结构"清掉，残差会出现大片光晕。
经验起点：模板取缺陷最大尺寸的 2~3 倍，再拿预览看残差里缺陷是否完整、背景是否干净。

**现象 → 先查（本族）**：

- 开运算之后目标整个没了：目标比模板小，被当噪声清掉了。把模板调小到"刚好盖住噪声"。
- 闭运算把两处缺陷之间的沟填平了：沟宽小于模板就会被填。缩小模板，或改成只用膨胀/只用腐蚀分开调。
- 白点没了、笔画也变细了：先腐蚀的必然副作用。开运算的膨胀那一刀只还原"面积"，还原不了锐利边缘；
  要求笔画完整时改用中值滤波去点噪声。
- 图边缘一圈异常亮/暗带：边缘处邻域不完整，形态学在图边上一圈本来就易出伪影。先用「框外屏蔽」涂掉边缘带。
- 黑白二值图上做开运算、黑色区域里冒出白点：先确认二值化的「反转」状态。
  灰度形态学只认"亮/暗"，不认"前景/背景"——二值图上"亮 = 前景"这个约定可能和你预期的相反。
- 顶帽/黑帽结果几乎全黑：先确认极性（亮缺陷用顶帽、暗缺陷用黑帽），再确认模板是不是小于缺陷
  （模板小于缺陷时开/闭会把缺陷保留下来，残差自然接近 0）。
- 顶帽/黑帽背景出现一大片亮/暗光晕：模板过大，把背景的缓变梯度也当成"大结构"清掉了。
  减小模板，或先做「对比度」/背景校正再进顶帽/黑帽。

**与滤波、二值化的搭配**：

- 去点噪声时，中值滤波与灰度开/闭运算常常二选一：滤波按邻域统计、形态学按结构尺寸。
  噪声尺寸整齐时形态学更干净，噪声尺寸杂乱时中值更稳。
- 二值化**之前**用形态学：适合"缺陷本身就是亮点/暗点"——按尺寸滤掉噪声再二值化，
  比"先二值化再在二值图上修"少一次边缘损失。
- 二值化**之后**用形态学：适合把二值图上的毛刺、小孔、断裂修整齐，此时模板尺寸要按"二值块"的尺寸填。

## 5. 图像增强

这一族改的是**灰度分布**：把目标与背景之间的灰度差拉开，让后面的二值化一刀切干净。

| 症状 | 用哪个 |
| --- | --- |
| 边缘发虚、目标轮廓不干脆 | 锐化 |
| 打光不均（一半亮一半暗），同一个阈值两头不能兼顾 | 对比度（局部光照增强） |
| 整体偏暗或偏亮、对比度还行 | 亮度调节 |
| 目标与背景的灰度差被挤在很窄的一段里 | 直方图均衡 |
| 暗背景上的亮目标想转成亮背景（便于后续阈值/下游习惯） | 反色 |

### 锐化

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 模板宽度 | 7 | 邻域尺寸，必须奇数，3~201，偶数自动 +1 |
| 模板高度 | 7 | 同上 |
| 增强因子 | 1.0 | 越大越锐，参考范围 0.3~20（界面允许 0~50，超出夹取）。**因子过大画面会出现白边** |

邻域非锐化掩模：把"当前像素"与"邻域平均"的差按因子放大加回去。
所以它放大的**也包括噪声**——锐化之前应该已经做过滤波。

### 对比度（局部光照增强）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 模板宽度 | 101 | 局部均值的邻域尺寸，要**远大于目标特征**尺寸，必须奇数，3~999 |
| 模板高度 | 101 | 同上 |
| 增强因子 | 0.7 | 界面填 0~1；执行前收敛到 **0.01~0.99**（端点会让底层运算报错） |

用"邻域内的平均亮度"把整幅图拉平：暗处提亮、亮处压暗，改善打光不均。
模板取小了会把**目标本身**当成"局部亮度"抹掉——这是这一族最典型的误用。
目标尺寸接近或超过 101 时，把模板一起放大。
（提醒：默认 101×101 的掩膜在大图上就是秒级运算，这是界面预览需要防抖的主要原因。）

### 亮度调节

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 倍数(Mult) | 1.0 | 灰度线性放大倍数，0~100。>1 提对比、<1 压对比 |
| 偏移(Add) | 0 | 整体加一个灰度值，-255~255。正数变亮、负数变暗 |

`输出 = 输入 × 倍数 + 偏移`。整幅线性变换，**不区分局部**：暗部噪声会跟着倍数一起放大。
结果超出 0~255 会被截断——倍数填大时高光成片死白，细节一去不回。
先想清楚要的是"整体偏暗"（用偏移）还是"灰度差太小"（用倍数，或直接用直方图均衡）。

### 直方图均衡

无可调参数。全局把灰度分布摊开到整个 0~255 动态范围。
彩色图三个通道各自均衡，**可能轻微偏色**（要保色彩时先均衡再转灰度，或反过来）。

- 什么时候用：来料光照忽明忽暗、目标与背景的灰度差被挤在很窄的一段里，阈值怎么调都不干净。
  先均衡把有效灰度差拉满，再二值化就轻松了。
- 什么时候别用：图像对比度本来就够。均衡会把噪声一起放大，
  原本能靠一个窄阈值区分的场合反而变糟。

### 反色

无可调参数，灰度取反（亮暗互换）。
典型用途：暗背景上的亮目标转成亮背景，便于后续阈值处理或统一下游的极性约定。

**现象 → 先查（本族）**：

- 锐化之后噪声比原来大：正常，它放大所有高频。顺序改成"滤波 → 锐化"，或把增强因子往下调。
- 锐化后目标边缘一圈白边/黑边：因子过大。降因子，或改用「对比度」处理打光不均（那是低频操作，不出白边）。
- 用了「对比度」后小目标整体变淡甚至看不见：模板比目标小了，目标被当成局部亮度抹掉。模板放大。
- 调完亮度一片死白/死黑：线性变换必然截断。减小倍数、把偏移往回收，或改用直方图均衡。
- 均衡后能看见目标但阈值仍切不干净：均衡把背景和噪声也一起摊开了。改用「均值二值化」（局部阈值），
  它按每个像素自己的邻域判决，比全局阈值更适合这种图。
- 不知道增强有没有效：预览停在增强这一步看输出态，再「导出图片」按步存 PNG 对比。
  只看最终二值图反推中间步骤，是调参最慢的路径。

## 6. 二值化

这一族把灰度图变成**只有 0 和 255 的单通道图**——它是整条链的出口，
也是下游（Blob 检测、区域类算子、匹配、OCR 切字）能不能一眼分清"目标 / 背景"的关键一步。

| 症状 | 用哪个 |
| --- | --- |
| 光照均匀，目标与背景灰度差稳定（同一台机、同一盏灯） | 二值化（全局阈值） |
| 打光不均 / 工件有弧度 / 图上一半亮一半暗 | 均值二值化（局部阈值） |
| 灰度差被挤在很窄的一段里 | 先插「直方图均衡」，再回到二值化 |
| 灰度图上全是碎点，阈值调大又丢目标 | 先插「灰度开运算」压掉细碎噪声，再二值化 |

### 输出约定（这一族最重要的一条）

- 输出是 **byte 单通道 0/255 图**，尺寸与输入一致；**它仍是图像，不是区域**。
- **不反转时：命中区间的像素是白（255）、背景是黑（0）**；勾选「反转」后命中变黑、背景变白。
  下游找不到目标时先看这一位——目标在图上是黑块还是白块取决于它，不取决于原图。
- 「均值二值化」**没有反转开关**，命中恒为白。要反的极性请在它前面用「反色」，或交给下游按极性配置处理。
- 输入若是彩色图，两个算子都**先自动转灰度**再判决（不必自己在链上补一步「彩色空间转换」，
  但补上可以明确"用哪个通道判决"，光照偏色时值得显式转）。

### 二值化（全局阈值）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 灰度下限 `Low` | 128 | 参与判决的灰度区间起点；按图像位深填（uint2 可到 65535），不按 255 夹取 |
| 灰度上限 `High` | 255 | 区间终点；按图像位深填（uint2 可到 65535），不按 255 夹取 |
| 反转 `Reverse` | 不勾选 | 勾选后命中区间变黑、背景变白 |

- 判决是**闭区间**：灰度落在 `[下限, 上限]` 内的像素算命中。
- 上下限**填反了会自动交换**（旧版不交换，原样丢给底层，结果是整张全黑图且不报错）。
  所以"填反就全黑"这个现象在当前版本已经不会复现；又得到全黑图，那是极性选错了，不是区间写反。
- 调法：预览停在「输入图」态，用取色看目标与背景各自的灰度范围，把区间卡在两者之间，
  再往两边各留 10~20 的余量吸收来料波动。

### 均值二值化（局部阈值）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 模板宽度 `MaskWidth` | 15 | 计算局部均值的邻域宽度，3~999，小于 3 自动抬到 3 |
| 模板高度 `MaskHeight` | 15 | 同上 |
| 标准差倍数 `StdDevScale` | 0.2 | 判决偏移 = 局部标准差 × 本系数，**越大越难被判为前景**，0~10 |
| 绝对阈值 `AbsThreshold` | 2 | 偏移量下限：局部平坦处至少差这么多才算前景；按图像位深填，不按 255 夹取 |
| 比较方式 `Mode` | 比局部均值亮（≥） | 取比局部均值**亮** / **暗** / **约等于** / **不等于**的像素；界面显示中文，存盘存成员数字 |

- 每个像素跟**自己邻域**的均值比，所以图上的明暗梯度会被吸收掉——这正是它适合打光不均场合的原因。
- **模板必须明显大于目标特征尺寸**。模板取到目标同量级时，目标自己就被算进"局部均值"，
  结果是目标整体消失或只剩边缘一圈。目标多大，模板至少取它的 2~3 倍。
- `标准差倍数` 与 `绝对阈值` 是两道闸门：前者随局部对比度浮动，后者是不管局部多平坦都要跨过的固定门槛。
  **噪声多就加大前者，淡色目标被吞就加大后者。**
- 「比较方式」选错的表现非常直接：**目标变背景、背景变目标**，整图反过来。
  暗字亮底选「比局部均值亮（≥）」，亮字暗底选「比局部均值暗（≤）」。

**现象 → 先查（本族）**：

- 输出整张全黑：① 区间太窄或落在目标灰度之外（用输入图取色核对）；② 勾了「反转」而目标本来就在这个区间里；
  ③ 上游某一步已经把图拉平了（例如「亮度调节」倍数填太小把高光压成一片同值）。
- 目标边缘锯齿、比原图粗了一圈：二值化本身不承担平滑。在它**之前**放「高斯滤波」或「中值滤波」，
  不要放在它之后（0/255 图上再滤波只会把边糊软，边缘位置还是歪的）。
- 目标内部有洞：命中不稳。先加大灰度区间余量，或在它前面加一步「灰度闭运算」。
- 图上一片碎点：`标准差倍数` / `绝对阈值` 都调大，或在它前面加「灰度开运算」；
  碎点仍有残留时，把"按面积筛掉"交给下游 Blob 检测，别在这里用形态学硬磨。
- 一半判得准、另一半全丢：典型光照不均，换「均值二值化」并把模板放大到覆盖亮暗渐变尺度。
- 彩色来料判不出目标：自动转灰度走的是 RGB 加权，红字在蓝底上转灰度后可能几乎同值。
  显式插一步「彩色空间转换」挑出反差大的通道（或转 HSV 取 S 通道），再接二值化。

## 7. 边缘检测

这一族输出的是**边缘强度图**，不是"干净的灰度图"：平坦区被压到 0，只有灰度突变的地方亮起来。
它适合回答"边缘在哪、有多强"，不适合直接拿来测尺寸——亚像素定位请接「卡尺测量」或「几何查找」。

| 算子 | 数学口径 | 典型用途 | 一句话判据 |
| --- | --- | --- | --- |
| Sobel 边缘 | 一阶梯度幅值（\|Gx\|+\|Gy\|、√(Gx²+Gy²)、细线/单方向变体） | 轮廓增强、边缘图接二值化/Blob、毛刺检测 | 要"边缘粗细适中、抗噪好一点"用它 |
| Laplace 边缘 | 二阶差分绝对值 | 细线/斑点/纹理边缘、快速看高频 | 要"更细更敏感"用它，但前面必须先滤波 |

### Sobel 边缘

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 模板尺寸 | 3 | 3~11 的奇数，偶数自动 +1；越大越平滑、边缘越粗 |
| 滤波类型 | 绝对值和 | 绝对值和（\|Gx\|+\|Gy\|）/ 平方和开根（√(Gx²+Gy²)）/ thin_sum_abs / thin_max_abs / x / y |

- 模板越大：抗噪越好，但边缘越粗、定位越粗；测尺寸不要用大模板。
- `绝对值和` 是工业默认：两个方向的梯度不会互相抵消；`平方和开根` 更接近真实梯度模；其余是 HALCON 的细线/单方向变体。
- 彩色图会先自动转灰度，输出单通道边缘图。

### Laplace 边缘

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 模板尺寸 | 3 | 3~11 的奇数，偶数自动 +1 |
| 邻域 | 4 邻域 | 4 邻域（n_4，快、简单）/ 8 邻域（n_8，更各向同性、也更敏感） |

- Laplace 对噪声比 Sobel 敏感得多：链上**先放高斯/中值滤波**，否则满屏噪点边缘。
- 8 邻域比 4 邻域更各向同性，但噪声也更大；拿不准先用 4 邻域。
- 输出是绝对值图，看不到正负过零点；要亚像素/零交叉定位请用几何查找或卡尺。

**现象 → 先查（本族）**：

- 边缘图几乎全黑：输入太模糊/对比度太低，先做「锐化」或「对比度」；也可能模板太大把边缘抹平了。
- 满屏噪点边缘：没有先滤波，或 Laplace 用了 8 邻域。先加高斯/中值，或换 Sobel。
- 边缘太粗、两条边粘在一起：模板尺寸太大，降到 3；或者改用卡尺做单边测量。
- 彩色图边缘图变成三通道：当前实现会先转灰度、输出单通道；若看到多通道，检查是不是绕过了本算子。

**放在链上哪儿**：边缘检测是"分支出口"，不是主链的必经步骤。
典型：`转灰度 → 裁剪/屏蔽 → 滤波 → Sobel/Laplace → 二值化 → Blob/轮廓`。
把边缘图再拿去做亮度/对比度调整没有意义——它已经不是原图的灰度分布了。

## 8. 算术运算

处理链的最后一族：**在既有灰度上做"平移 / 拉伸 / 换类型"**，不改变画面内容（不改几何、不改邻域）。
它们只对**当前这一张图**做常数运算——链内算子拿不到第二张图（见下节"为什么没有图像−图像"）。

### 灰度加常数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 常数 | 0 | 逐像素加上的量。正数提亮，负数压暗；范围按图类型：byte 图有效区间 −255~255 |

**口径**：`out = image + value`。整幅图**绝对平移**，暗处与亮处抬升的量一模一样。
byte 图超过 255 的像素被**饱和截断到 255**，不会回绕，也不会报错——高光区一旦推满就再也分不出层次。

**什么时候用**：相机曝光偏保守、整图偏暗但**没有过曝**时，先加常数把直方图整体抬到中间区间，比调曝光重复性好；
固定阈值方案里，把"背景基准灰阶"抬到某个整数方便卡阈值也常用这一步。

**不要用**：想提高对比度（暗的更暗、亮的更亮）时用「灰度乘增益」或「对比度」，
加常数只会把整条直方图平移，对比度一点没变。

### 灰度减常数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 常数 | 0 | 逐像素减去的量。范围按图类型：byte 图有效区间 −255~255 |

**口径**：`out = image − value`。同样是绝对平移。

**【陷阱】byte 图是无符号的，负结果被截成 0。**
减过头不会得到"一片负值"让你事后补救，而是得到**一片纯黑、信息永久丢失**。
如果后续还要靠这些像素判读，请先加「转浮点图」再减（real 图保留负值），最后用「灰度归一化」拉回 0~255 上屏。

**典型用途**：压掉均匀背景光（背景原来是 180，减 180 后背景接近 0，目标就跳出来了）；
配合「灰度归一化」做"去基频 → 拉伸"的两步组合。

### 灰度乘增益

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 常数 | 0 | 增益系数。大于 1 提亮、小于 1 压暗，1 表示不变；常用 0.8~1.3 |

**口径**：`out = image × value`。这是**相对**调整——原来亮的像素变化大，原来暗的变化小，
所以它会**同时放大对比度**（这正是它和"加常数"的本质区别）。

**填法**：想整体提亮 20% 填 `1.2`；想压暗 20% 填 `0.8`。
一次超过 `1.5` 基本会把高光推爆，需要更强反差时连做两步（每步 1.2）比一步 1.5 更可控。

**注意**：增益是**乘法**，值为 0 的像素乘任何数还是 0 —— 已经全黑的地方救不回来。

### 转浮点图

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| （无参数） | — | 把图像类型转成 real |

**口径**：只换类型，**不动灰度值**。byte 的 0~255 变成 real 的 0.0~255.0，数值一一对应。

**为什么要有这一步**：链上所有算子默认按 byte 处理，负值在**算出来的当下**就被截断了。
所以"先减再放大"这类操作必须**先转浮点**：`转浮点图 → 灰度减常数 → 灰度乘增益 → 灰度归一化`。
少了第一步，减出来的负差全变成 0，后面乘多少都还是 0。

**代价**：real 图内存是 byte 的 4 倍，处理时间也明显更长。不需要负值时不要随手加它。

### 灰度归一化

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| （无参数） | — | 按全图真实最小/最大灰度线性拉伸到 0~255 |

**口径**：取全图 min/max（`min_max_gray` 的 Percent=0，**不做百分位裁剪**），
线性映射到 0~255 并转回 byte。`out = (image − min) × 255 / (max − min)`。

**典型用途**：浮点链算完的动态范围常常是 −30000~30000，直接上屏要么全白要么全黑，
归一化后才是人眼能判读的灰度图。它是**浮点链的收尾步骤**。

**两个必须知道的边界**：
- **全图灰度一致时输出全黑图**（1×1 全 0 图）。这是刻意的选择：没有任何对比信息时，
  塞随机噪声反而让人误以为"有东西"。看到全黑先查是不是原图本来就没有起伏。
- **极值驱动**：只要有一个孤立噪点特别亮或特别暗，整条直方图就会被压扁。
  噪声大的图要先滤波再归一化。

### 为什么这里没有"图像 − 图像"

这是**刻意的缺口，不是漏做**。

链内算子（`OperatorStepItem`）只带"算子 key + 参数字典 + 启用开关"，**只有一张输入图**。
硬在链里做"绝对差"只能退化成 `|image − value|`，语义变成"亮度离某个基准值有多远"，
跟用户心里的"两张图差多少"完全不是一回事，摆进算子菜单只会被误用。

**真正的双图差分在 Plugin.ImageDiff 插件**，它有两个真正的图像输入端口，支持
绝对差 / 带符号真实差 / 原始减法三种口径，带阈值出缺陷区域、差异占比统计和差分图上屏。
需要比对基准图与待检图时，用那个插件，不要在这里绕。

## 9. 一条链怎么调

### 先定顺序，再调参数

```
转灰度 → 裁剪/屏蔽 → 滤波 → 增强 → 形态学 → 二值化 → （必要时）算术运算
```

- **转灰度放最前**：绝大多数后续算子面向单通道图，彩色图每多走一步就多一倍像素量。
- **裁剪放很前**：后面每一步只算框内，这是最便宜也最容易被忽略的一次提速。
  只想"别让下游看见框外"但保持坐标系不变，用「框外屏蔽」而不是裁剪。
- **滤波在增强之前**：锐化会连同噪声一起放大，先压噪声再拉反差。
- **形态学按尺寸填**：它决定"多大算噪声"，放在二值化前压碎点，或放在二值化后修毛刺。
- **边缘检测/顶帽/黑帽走分支**：它们输出的是特征残差图，不插在主链末端；
  典型接法是 `滤波 → Sobel/Laplace → 二值化 → Blob/轮廓`，顶帽/黑帽同理。
- **二值化放最后**：它是链的出口。之后一切都是 0/255，再滤波只会把边缘糊软。
- **算术运算看场合**：它不是主链的常客。要保留差值就得 `转浮点图 → 减 → 乘 → 灰度归一化` 连排，
  这组一插进去画面色彩就变了，**只在上屏或做可视化时用**；纯判定场景通常不需要它。

### 调参节奏

1. 先只放「彩色空间转换」，把通道调对，得到一张对比度最高的灰度图。
2. 加几何族，把画布/裁剪定下来——**后面所有像素单位的参数都以这一步之后的图为准**。
3. 加滤波，压到"背景看起来均匀"为止，不要追求绝对干净（糊边缘的代价比留点噪声大）。
4. 加增强，只解决一个问题：要么拉反差（均衡/亮度倍数），要么补打光（对比度），不要两个一起堆。
5. 最后二值化：先定极性，再卡区间，最后留 10~20 余量。
6. 每加一步都选中它看"算子输出"，与上一步比对；发现某一步之后画面变坏，就地调它，不要往下找。
