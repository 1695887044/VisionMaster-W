# 图像预处理 · 几何调整算子

> 分类：图像处理 ｜ 来源：插件 Plugin.PreProcessing

这一族改的是**像素的位置与画布尺寸**：镜像、旋转、改尺寸、缩放、裁剪、框外屏蔽。
它们也是最容易"把下游坐标搞错"的一族——只要宽高变了，所有以像素为单位的参数都要跟着重算，
所以建议放在链的前面，改完尺寸再开始调滤波与阈值。

## 输入 / 输出

输入 `SrcImage` 的当前图，输出一张几何变换后的图。除「固定框裁剪」外，其余算子都不改内容，只改摆位或画布。

## 关键参数

> 完整参数与取值范围以流程中该步骤的「模块参数」界面为准，这里只解释含义。

### 图像镜像

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 镜像方式 | 水平镜像（左右翻转） | 水平镜像（左右翻转）/ 垂直镜像（上下翻转）/ 对角镜像（沿主对角线翻转）。**对角镜像会把宽高互换** |

### 图像旋转

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 旋转角度 | 180 度 | 90 度 / 180 度 / 270 度。旋转不放大画布：**90/270 度时超出原画布的四角会被裁掉** |

非 90 度整数倍的倾斜校正不归本插件管——本族只做整角度。工件有随机角度时先走模板匹配定位，
或用带角度的 ROI 把目标转正后再进这条链。

### 修改图像尺寸

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 目标宽度 | 0 | 0 = 沿用原图宽度。超出部分裁掉，不足部分补 0（黑） |
| 目标高度 | 0 | 0 = 沿用原图高度。同上 |

算的是**画布**不是缩放：把 1000 宽改成 800 宽，就是砍掉右边 200 列；改成 1200，就是右边补 200 列黑。
两项都等于原尺寸（或都填 0）时算子透传，不白造一张图。
用途：统一多相机/多型号的画布尺寸，让下游按固定坐标取数。

### 固定框裁剪

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 中心行 | 0 | 框中心所在的行（像素，0 基）。也可以在画布上直接拖动框 |
| 中心列 | 0 | 框中心所在的列（像素，0 基） |
| 框宽度 | 0 | **整宽**（不是半宽）。填 0 表示还没框，本算子原样透传 |
| 框高度 | 0 | **整高**（不是半高）。同上 |

只做**正框**（不倾斜）。输出图的宽高就是框的宽高，坐标系从 0 重新起算——
下游原来按原图坐标填的参数，跨过这一步都要改成"相对裁剪框"的坐标。
框正好盖住整张图时按透传处理（裁剪是恒等变换，省一次全图拷贝）。

### 按比例缩放

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 行方向因子 | 1.0 | 垂直方向（高度）缩放比例，>1 放大、<1 缩小。合法范围 0.01~20，超出自动夹取 |
| 列方向因子 | 1.0 | 水平方向（宽度）缩放比例，同上 |
| 插值方式 | 双线性（默认，速度与质量折中） | 最近邻（最快，放大后有明显锯齿）/ 双线性 / 双三次（最平滑，最慢） |

行、列分开填的用意：线扫图像常在行方向过采样，只需压行；看细节时双向一起放大。
纯提速用最近邻或双线性；**放大后还要测量尺寸的，别用最近邻**（锯齿会让边缘位置抖动）。
两个因子都是 1 时透传。

### 框外屏蔽

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 中心行 / 中心列 / 框宽度 / 框高度 | 0 | 同「固定框裁剪」：整宽整高，宽或高 ≤ 0 = 未框选，透传 |
| 框外灰度 | 0 | 框外填充的灰度值（0~255）。彩色图会把三个通道都填成这个值，即一种灰色 |

框内保留原像素、框外整片涂掉，**图像尺寸不变、坐标系与原图一致**。
取舍：只要"别让下游看见框外"、又要下游继续用原图坐标 → 用屏蔽；想少算一半像素提速 → 用裁剪。
两者也可以连用（先屏蔽再裁剪也行，只是裁剪之后屏蔽已无意义）。

## 现场现象 → 先查什么

- **框拖出图外了，画面却没报错、结果偏小**：越界的处置是"自动夹取到图内"，
  参数摘要会挂"（越界已夹取）"，日志里有一条 Warn。把框画回图内，别指望它按你填的尺寸出图。
- **拖了半天框，输出还是整张图**：宽或高还留着的 0（未框选 = 透传）。
  另外确认拖框时预览处在「输入图」态——带框算子的框坐标基准就是那一步的输入图。
- **90 度旋转后四角的内容不见了**：旋转不放大画布，超出原画布的部分本来就会被裁掉。
  先加「修改图像尺寸」把画布开大再旋转，或把目标离四角远一点。
- **改完宽高，下游所有位置参数都错位**：这是尺寸变化带来的必然结果。用「框外屏蔽」替代裁剪可以保住原坐标系。
- **缩放后图变糊/有锯齿**：插值方式选的是最近邻。放大看细节改双三次，纯提速保持最近邻。
- **裁剪后图比预期小一圈**：先查是不是同时存在越界夹取，再查框宽高度填的是整宽还是半宽——界面要的是**整宽整高**。
