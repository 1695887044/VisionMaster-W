# 图像预处理 · 界面与链编辑

> 分类：图像处理 ｜ 来源：插件 Plugin.PreProcessing

本页讲配置界面每一块做什么、处理链怎么排、画布上的框怎么拖。
算子本身的口径与参数在 `04-算子口径与调参.md`；端口与参数被改值的原因在 `03-ports-and-parameters.md`。

界面由本节点自带（不是通用的参数表格），主窗口弹出后即可一边看图一边改链。

---

## 1. 各块做什么

| 区块 | 内容 | 要点 |
| --- | --- | --- |
| 图像输入 / 图像路径 | `SrcImage` 的绑定入口：链接按钮选上游端口或变量；未连线时可手动指定一张本地图 | 流程还没跑起来也能让预览先动起来 |
| 显示窗口 | 下拉：`不显示` / `窗口1~9` | 存成 `DisplayViewIndex`（0~9），运行时把结果推到主界面几号视图；填 0 不影响 `Image` 输出 |
| 预览 | 三态单选：`原图` / `输入图` / `算子输出` | 默认"算子输出"；**拖框之前先切到"输入图"** |
| 画布 | 共享图像编辑控件，显示当前预览态的图，可拖框、滚轮缩放、右键保存 | 右键菜单里有「保存原始图像 / 保存缩略图像」，只想存当前这一张比导出整链快 |
| 算子库 | 按六族分组的算子按钮，悬停提示即用途说明 | **点击即追加到处理链末尾**，不需要拖拽 |
| 处理链 | 标题显示"共 N 步"，每行 = 步号 + 算子名 + 参数摘要 + 行首「启用」勾选框 | 支持上移 / 下移 / 删除 / 清空 |
| 链搬运 | 「复制整链」「粘贴到链尾」 | 见 §4 |
| 导出图片 | 按步导出 PNG + 参数清单 + 链快照 | 见 §5 |
| 算子参数 | 选中那一步的参数面板（表格式 ⇄ 卡片式两种布局） | 改完约半秒内自动重算预览 |
| 刷新 | 手动重算一遍预览 | 防抖失效或想立刻看结果时按 |
| 底部提示行 | 命令的操作反馈（复制/粘贴/导出成功或失败的原因都写在这里） | 一次操作只留最新一条 |
| 顶部黄色提示 | 读盘时认不出的算子提示 | 见 `05-troubleshooting.md` |

## 2. 处理链的编辑动作

- **加**：在算子库点一下，追加到链尾，并自动选中新加的那一步。
- **删**：选中后按「删除」；「清空」一次清掉整条链（清空前不需要逐个删）。
- **排序**：「上移」「下移」每次挪一格。顺序 = 执行顺序，改顺序等于改算法。
- **启停**：行首勾选框取消 = 该步透传，图像原样流向下一个算子。
  **不要靠"删掉"来试关闭一个算子**——透传会保留参数，勾回来就复原；删了要重新调。
- **选中项决定预览与参数面板**：切换选中步骤时，预览会跟着显示那一步的输入/输出；
  链空时预览自动退回"原图"态。

## 3. 预览三态各回答一个问题

| 预览态 | 看到的是 | 用它回答 |
| --- | --- | --- |
| 原图 | 链的输入 | "进来的图本来长什么样"——判断是不是上游/光源的问题 |
| 输入图 | **选中这一步**的输入 | "前面几步合起来已经弄成了什么"，也是拖框类算子的坐标基准 |
| 算子输出 | 选中这一步的结果 | "这一步单独做了什么" |

三条实用纪律：

1. **带框的算子（固定框裁剪、框外屏蔽）必须在「输入图」态下拖框**。框的坐标基准就是那张输入图，
   在别的态下拖的框，基准对不上，实际生效的框比你以为的小。
2. **一步一步往后点，不要只看最后一步**。链上任何一步坏了，最终图只会表现成"结果不对"，
   看不出是谁干的。选中第 N 步看输出，与上一层比对，坏的那一步当场现形。
3. **改完参数要点「确认」再运行**。预览是即时重算的，运行用的是确认时落盘的链。

某一步透传或没产出新图时，"算子输出"会退回显示原图而不是给你一张空白——
画面没变不代表预览坏了，先看那一步的参数摘要。

## 4. 画布上的框

- 同一时刻画布上只有**一个**可编辑框，名字叫「编辑框」，属于当前选中的那个框类算子。
  链上有多个框类算子时，**每个算子各存自己的框参数**，切换选中项就是切换画面上那个框的位置与尺寸。
- 拖完框，参数面板里的中心行/中心列/宽度/高度会同步更新；反过来在参数里填数值，框也会跟着移动。
- 参数填的是**整宽 / 整高**（不是半宽半高），中心是 0 基像素坐标。
- 宽或高还是 0 时视为"没框"，该步透传——画面上有框但输出是整张图，通常是这一位没填。
- 想把框去掉：用参数面板/画布的删除入口删掉框，框参数被清空后该步回到透传状态。
- **框拖出图像范围不会报错**：插件先夹尺寸再夹位置，把框夹进图内执行，
  参数摘要挂上"（越界已夹取）"，运行日志里另有一条 Warn。

## 5. 复制、粘贴、导出

| 动作 | 结果 | 注意 |
| --- | --- | --- |
| 复制整链 | 把当前所有步骤（含参数与启用状态）序列化成文本放进剪贴板 | 提示 `已复制 N 步到剪贴板（文本格式，可粘到其它方案的本节点）`；链为空时按钮不可用 |
| 粘贴到链尾 | 把剪贴板里的链**追加**到当前链末尾，原有步骤保留 | 要清空原有步骤就先按「清空」；粘贴完选中第一条新算子，参数面板直接可改 |
| 导出图片 | 每步输出按 `前缀_步号_算子名.png` 写出，同目录再生成参数清单 `.txt` 与链快照 `.json` | 只弹一次保存框（借清单文件定位目录与统一前缀）；链为空时按钮不可用 |

**导出的是"此刻的效果"**：插件会先按当前参数同步重跑整条链再出图，所以没确认的参数也会被导出进去。
禁用与透传的步骤**不产文件**，清单里写明"已禁用，未出图"或"透传，未单独出图"。
只想存当前这一张，用画布右键的「保存原始图像」更快。

粘贴时认不出的算子会被跳过并提示，全部认不出时会明确告诉你有多少步不存在。

## 6. 布局与窗口尺寸

- 参数面板有**表格式 ⇄ 卡片式**两种布局，由配置壳上的开关切换。
  卡片式自带左侧分组页签与卡片留白，固定开销明显大于表格式，所以参数列更宽——
  屏幕窄时切卡片式会挤，**这是正常现象，不是错位**。
- 打开本节点时窗口会自动放大到能容纳内容区（约 1120×620）的尺寸，但受屏幕可用区域限制：
  在小屏上不会无限撑大，此时用滚动条或换表格式布局。

## 7. 界面卡顿与"预览没反应"

- 全图运算很重（对比度算子默认 101×101 掩膜，大图上就是秒级），而参数框是逐字符触发刷新的，
  所以界面有 **200ms 防抖**：连续输入只算最后一次。
- 后台还在跑时你又改了参数，不会叠加计算，跑完自动补一轮——**画面短暂落后于参数是正常的**。
- 链很长、图很大时逐步预览会明显变慢：预览要把**每一步**的图都留住。
  正式运行是跑一步扔一张，不攒内存，**节拍变慢与预览的开销是两回事**。
- 真不动了：按「刷新」；仍不动就先按 §3 确认预览态与选中步骤，再按 `05-troubleshooting.md` 查输入图。
