# 图像预处理 · 图像增强算子

> 分类：图像处理 ｜ 来源：插件 Plugin.PreProcessing

这一族改的是**灰度分布**：把目标和背景之间的灰度差拉开，让后面的二值化一刀就切干净。
五个算子：锐化、对比度、亮度调节、直方图均衡、反色。

## 先按症状选算子

| 症状 | 用哪个 |
| --- | --- |
| 边缘发虚、目标轮廓不干脆 | 锐化 |
| 打光不均（一半亮一半暗），同一个阈值两头不能兼顾 | 对比度（局部光照增强） |
| 整体偏暗或偏亮、对比度还行 | 亮度调节 |
| 目标与背景的灰度差被挤在很窄的一段里，阈值怎么调都不干净 | 直方图均衡 |
| 暗背景上的亮目标，想转成亮背景（便于后续阈值/下游习惯） | 反色 |

## 关键参数

> 完整参数与取值范围以流程中该步骤的「模块参数」界面为准，这里只解释含义。

### 锐化

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 模板宽度 | 7 | 邻域尺寸，必须奇数，3~201，填偶数自动 +1 |
| 模板高度 | 7 | 同上 |
| 增强因子 | 1.0 | 越大越锐，参考范围 0.3~20（界面允许 0~50，超出夹取）。**因子过大画面会出现白边** |

邻域非锐化掩模：把"当前像素"与"邻域平均"的差按因子放大加回去。
所以它放大的**也包括噪声**——锐化之前应该已经做过滤波，不要放在滤波之前。

### 对比度（局部光照增强）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 模板宽度 | 101 | 局部均值的邻域尺寸，要**远大于目标特征**尺寸，必须奇数，3~999 |
| 模板高度 | 101 | 同上 |
| 增强因子 | 0.7 | 界面填 0~1；执行前收敛到 **0.01~0.99**（端点会让底层算子报错） |

用"邻域内的平均亮度"把整幅图拉平：暗处提亮、亮处压暗，改善打光不均。
模板取小了会把**目标本身**当成"局部亮度"抹掉——这是这一族最典型的误用：模板必须明显大于目标。
默认 101；目标尺寸接近或超过模板时，把模板一起放大。

### 亮度调节

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 倍数(Mult) | 1.0 | 灰度线性放大倍数，0~100。>1 提对比、<1 压对比 |
| 偏移(Add) | 0 | 整体加一个灰度值，-255~255。正数变亮、负数变暗 |

`输出 = 输入 × 倍数 + 偏移`。整幅线性拉伸，**不区分局部**：暗部噪声会跟着倍数一起放大。
结果超出 0~255 会被截断——倍数填大时高光会成片死白，细节一去不回。
先想清楚要的是"整体偏暗"（用偏移）还是"灰度差太小"（用倍数，或直接用直方图均衡）。

### 直方图均衡

无可调参数。全局把灰度分布摊开到整个 0~255 动态范围。
彩色图三个通道各自均衡，**可能轻微偏色**（要保色彩时先做这一步再转灰度，或反过来）。

- **什么时候用**：来料光照忽明忽暗、目标与背景的灰度差被挤在很窄的一段里，阈值怎么调都不干净。
  先均衡，把有效灰度差拉满，再二值化就轻松了。
- **什么时候别用**：图像对比度本来就够。均衡会把噪声一起放大，
  原本能靠一个窄阈值区分的场合反而变糟。

### 反色

无可调参数，灰度取反（亮暗互换）。
典型用途：暗背景上的亮目标转成亮背景，便于后续阈值处理或统一下游的极性约定。

## 现场现象 → 先查什么

- **锐化之后噪声比原来还大**：正常。锐化放大所有高频，包括噪声。顺序改成"滤波 → 锐化"，
  或把「增强因子」往下调（算子说明给的参考范围是 0.3~20）。
- **锐化后目标边缘一圈白边/黑边**：因子过大。降因子，或换「对比度」改善打光不均（那是低频操作，不出白边）。
- **用了「对比度」之后小目标整体变淡甚至看不见**：模板比目标小了，目标被当成局部亮度抹掉了。模板放大。
- **调完亮度，图上一片死白/死黑**：线性变换必然截断。减小倍数、把偏移往回收，
  或改用直方图均衡让分布自己摊开。
- **均衡后能看见目标了，但阈值还是切不干净**：均衡把背景和噪声也一起摊开了。
  回到「均值二值化」（局部阈值），它按每个像素自己的邻域判决，比全局阈值更适合这种图。
- **不知道增强有没有效**：把「逐步预览」停在增强这一步，看输出态；
  再点「导出图片」按步存出 PNG 对比。只看最终二值图反推中间步骤，是调参最慢的路径。
