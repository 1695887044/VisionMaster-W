# 图像预处理 · 色彩与通道算子

> 分类：图像处理 ｜ 来源：插件 Plugin.PreProcessing

处理链的第一族：**把彩色图变成后续算子能用的单通道图**。除了「彩色空间转换」，链上其余算子都按灰度图设计，
所以多数方案的第一步就是它。

## 彩色空间转换

算子名：彩色空间转换 ｜ 分组：色彩与通道 ｜ 说明：彩色图转灰度、按通道分离，或转到 HSV / HSI / YUV / CIELAB 后取某一通道。

原理：转灰度是三通道加权合成成一个通道；通道分离是把 R/G/B 拆开只留一个；
转到 HSV / HSI / YUV / CIELAB 后先做整体色彩空间变换，再取指定的那一个通道。

### 输入 / 输出

输入一张彩色图，输出一张**单通道**图。对彩色图做灰度化或取通道都会丢掉颜色信息，
所以这一步要放在链上"还想用颜色"的最后一个位置。

### 关键参数

> 完整参数与取值范围以流程中该步骤的「模块参数」界面为准，这里只解释含义。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 转换方式 | 转灰度（三通道加权合成） | 可选：转灰度（三通道加权合成）/ RGB 通道分离（取某一个通道）/ HSV 色彩空间 / HSI 色彩空间 / YUV 色彩空间 / CIELAB 色彩空间。选转灰度时下面的通道号无意义 |
| 输出通道 | 第一通道 | 转换后取第几个通道（1 基）。选"RGB 通道分离"时即取 R / G / B 中的第几个 |

### 什么时候用哪个

- **只是要给下游一张灰度图**：用默认的转灰度。加权合成保留的是亮度信息，
  对"深浅不同的灰度差"最稳，是工业上的默认选择。
- **靠颜色区分的目标（红章、彩色标签、油墨色标）**：先用 RGB 通道分离试。
  目标在某一个通道上"消失"或"变最深"，就说明这个通道对比最强。
  例：红色目标在 R 通道上偏亮、在 G/B 通道上偏暗——想突出深色目标就取 G 或 B。
- **HSV 的三个通道依序是色调 / 饱和度 / 明度，打光均匀但颜色深浅变化大的场景常取第三通道（明度）**；
  **HSI、YUV、CIELAB** 同理，是几种不同的加权/坐标方式，哪个能把目标和背景的灰度差拉开就用哪个。
  拿不准就三种各跑一次，用逐步预览对比，比背公式有用。

### 现场现象 → 先查什么

- **画面全黑或全白**：多半取到的通道在目标上没有对比。换「转换方式」再对比，不要先去调后面的阈值。
- **对一张本来就是灰度的图跑了这一步，画面没变**：这是设计行为。
  单通道图没有"色彩空间"可言，算子原样透传（不会像旧版那样硬算出一张黑图）。
- **彩色图转灰度后目标反而看不清了**：加权合成会把颜色和亮度混在一起，改用通道分离或换一种色彩空间。

## 怎么选"输出通道"才不浪费时间

1. 在配置界面把预览切到「算子输出」，选中最上面这一步；
2. 依次把「转换方式」设为 RGB 通道分离，通道 1/2/3 各看一次输出；
3. 挑"目标与背景最反差"的那一张，把它的灰度差用直方图看一眼（导出图片可以按步存出来对比）；
4. 都不理想再回到 HSV / HSI / YUV / CIELAB 重复第 2 步。

调好后把它留在链首，后面所有算子面对的就是这张对比度最高的灰度图。
