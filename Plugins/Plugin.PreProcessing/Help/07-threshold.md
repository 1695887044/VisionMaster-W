# 图像预处理 · 二值化算子

> 分类：图像处理 ｜ 来源：插件 Plugin.PreProcessing

这一族把灰度图变成**只有 0 和 255 的单通道图**——它是整条链的出口，也是下游（Blob 检测、区域类算子、
匹配、OCR 切字）能不能一眼分清"目标 / 背景"的关键一步。
两个算子：**二值化**（全局阈值）与**均值二值化**（局部阈值）。

## 先按症状选算子

| 症状 | 用哪个 |
| --- | --- |
| 光照均匀，目标和背景的灰度差稳定（同一台机、同一盏灯） | 二值化（全局阈值） |
| 打光不均 / 工件有弧度 / 图上一半亮一半暗，同一个阈值两头不能兼顾 | 均值二值化（局部阈值） |
| 目标与背景的灰度差被挤在很窄的一段里，阈值怎么调都切不干净 | 先插「直方图均衡」（图像增强族），再回到二值化 |
| 灰度图上全是碎点，阈值调大又丢目标 | 先插「灰度开运算」（灰度形态学族）压掉细碎噪声，再二值化 |

## 输出约定（这一族最重要的一条）

- 输出是 **byte 单通道 0/255 图**，尺寸与输入一致。
- **不反转时：命中区间的像素是白（255），背景是黑（0）**；勾选「反转」后命中变黑、背景变白。
- 「均值二值化」**没有反转开关**，命中恒为白。要反的极性请在它前面用「反色」，或交给下游按极性配置处理。
- 输入若是彩色图，两个算子都**先自动转灰度**再判决（不用自己在链上补一步「彩色空间转换」，
  但补上可以明确"用哪个通道判决"，光照偏色时值得显式转）。

## 关键参数

> 完整参数与取值范围以流程中该步骤的「模块参数」界面为准，这里只解释含义。

### 二值化（全局阈值）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 灰度下限 `Low` | 128 | 参与判决的灰度区间起点，0~255，超出自动夹取 |
| 灰度上限 `High` | 255 | 区间终点，0~255，超出自动夹取 |
| 反转 `Reverse` | 不勾选 | 勾选后命中区间变黑、背景变白 |

- 判决是**闭区间**：灰度落在 `[下限, 上限]` 内的像素算命中。
- 上下限**填反了会自动交换**（旧版不交换，原样丢给 HALCON，结果是**整张全黑图**且不报错）。
  所以"填反就全黑"这个现象在当前版本已经不会复现；如果又得到全黑图，那是极性选错了，不是区间写反。
- 调法：先用「逐步预览」停在输入图态，用取色看目标与背景各自的灰度范围，把区间卡在两者之间，
  再往两边各留 10~20 的余量吸收来料波动。

### 均值二值化（局部阈值）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 模板宽度 `MaskWidth` | 15 | 计算局部均值的邻域宽度，3~999，小于 3 自动抬到 3 |
| 模板高度 `MaskHeight` | 15 | 同上 |
| 标准差倍数 `StdDevScale` | 0.2 | 判决偏移 = 局部标准差 × 本系数，**越大越难被判为前景**，0~10 |
| 绝对阈值 `AbsThreshold` | 2 | 偏移量下限：局部平坦处至少差这么多才算前景，0~255 |
| 比较方式 `Mode` | 比局部均值亮（≥） | 取比局部均值**亮** / **暗** / **约等于** / **不等于**的像素，界面显示中文、流程存成员名 |

- 每个像素跟**自己邻域**的均值比，所以图上的明暗梯度会被吸收掉——这正是它适合打光不均场合的原因。
- **模板必须明显大于目标特征尺寸**（算子说明原话）。模板取到目标同量级时，目标自己就被算进"局部均值"，
  结果是目标整体消失或只剩边缘一圈。目标多大，模板至少取它的 2~3 倍。
- `标准差倍数` 与 `绝对阈值` 是两道闸门：前者随局部对比度浮动，后者是不管局部多平坦都要跨过的固定门槛。
  **噪声多就加大前者，淡色目标被吞就加大后者**（旧版把偏移量偷偷除以 100、绝对阈值写死 30，
  现在这两个参数直接对应底层取值，填多少就是多少）。
- 「比较方式」选错的表现非常直接：**目标变背景、背景变目标**，整图反过来。
  暗字亮底选「比局部均值亮（≥）」，亮字暗底选「比局部均值暗（≤）」。

## 现场现象 → 先查什么

- **输出整张全黑**：① 区间太窄或落在目标灰度之外（用输入图取色核对）；② 勾了「反转」而目标本来就在这个区间里；
  ③ 上游某一步已经把图拉平了（比如「亮度调节」倍数填太小把高光压成一片同值）。
- **目标边缘锯齿、比原图粗了一圈**：二值化本身不承担平滑。在它**之前**放「高斯滤波」或「中值滤波」，
  不要放在它之后（0/255 图上再滤波只会把边糊软，边缘位置还是歪的）。
- **目标内部有洞**：命中不稳。先加大灰度区间余量，或在它前面加一步「灰度闭运算」。
- **图上一片碎点**：`StdDevScale` / `绝对阈值` 都调大，或在它前面加「灰度开运算」；碎点仍有残留时，
  把"按面积筛掉"交给下游 Blob 检测，别在这里用形态学硬磨。
- **一半图判得准、另一半全丢**：典型的光照不均，换「均值二值化」并把模板放大到覆盖亮暗渐变尺度。
- **彩色来料判不出目标**：自动转灰度走的是 RGB 加权，红字在蓝底上转灰度后可能几乎同值。
  在链上显式插一步「彩色空间转换」挑出反差大的那个通道（或转 HSV 取 S 通道），再接二值化。
