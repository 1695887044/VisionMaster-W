# 图像预处理 · 快速上手

> 分类：图像处理 ｜ 来源：插件 Plugin.PreProcessing

把**色彩与通道、几何调整、滤波、灰度形态学、图像增强、二值化、边缘检测**七族共 25 个算子串成一条处理链，
在同一个节点里逐步预览、单步启停、整链复制与按步导出，产出一张干净的图交给下游的匹配、测量、识别节点。

链的顺序就是执行顺序：上游的图进第 1 步，第 1 步的输出进第 2 步，最后一步的输出从 `Image` 端口流出。
本插件只做"图像进、图像出"：**不定位、不判定、不输出几何量**，这些请接各自的专用节点。

## 为什么值得用这一个节点

传统做法是每种处理各放一个流程节点：一次调参要在五六个节点间来回跳，连线一断就得重接，
而且"这一步到底把图改成了什么样"只能逐个节点跑一遍去看。收进一个节点内部的一条链之后：

- **逐步预览**：选中链上任意一步，直接看它的输入和输出，效果差在哪一步一眼定位；
- **单步启停**：取消勾选某算子的「启用」，图像原样透传，不用删步骤就能排除它的干扰；
- **失败隔离**：某个算子这一轮报错只跳过它那一步，图像继续往后流，整条流程不会因此中断；
- **整链搬运**：「复制整链」把所有步骤（含参数与启用状态）拷成文本，「粘贴到链尾」并到另一条链上。

## 5 分钟接好第一条链

1. 从工具箱的**图像处理**分组把「图像预处理」拖进流程，落在采集节点之后。
2. 双击节点打开配置界面，在「图像输入」区把 `SrcImage` 连到上游的输出端口（流程还没跑起来时，
   也可以在「图像路径」里手动指定一张图，让预览先动起来）。
3. 在右侧**算子库**里按顺序点击要用的算子，点一次就追加到处理链末尾（按钮悬停提示就是用途说明）：
   `彩色空间转换` → `固定框裁剪` → `均值滤波` → `直方图均衡` → `二值化`。
4. 选中链上第 1 步，在下方**算子参数**里改值；改完约半秒画面自动重算（右下角「刷新」是手动兜底）。
5. 用预览区的三选一核对：「原图」= 链的输入，「输入图」= 选中这一步的输入，「算子输出」= 选中这一步的结果。
6. 带框的算子（固定框裁剪、框外屏蔽）要**先把预览切到「输入图」再在画布上拖框**。
7. 点「确认」。**预览跟着参数即时重算，运行时用的是确认时落盘的那条链**——没确认就运行，跑的仍是旧链。

## 端口速查

| 端口 | 方向 | 说明 |
| --- | --- | --- |
| `SrcImage` | 输入 | 待处理图像，彩色/单通道都可以；必填，为空或图像未初始化时本步骤直接失败 |
| `Image` | 输出 | 链上**最后一步**的输出（不是选中那一步的）；尺寸可能被几何族算子改变 |
| `StepCount` | 输出 | 算子总步数，含被禁用的步骤 |
| `ActiveCount` | 输出 | 启用的算子个数 |
| `ActiveOperators` | 输出 | 启用的算子名按执行顺序用 ` → ` 连接；一个都没启用时输出 `(全部禁用)` |

## 常见接线

```
图像采集.OutputImage ──▶ 图像预处理.SrcImage
图像预处理.Image ─────▶ 模板匹配.SrcImage      （先去噪再匹配）
图像预处理.Image ─────▶ OCR 文本识别.Image      （先裁好、屏蔽干扰再切字）
图像预处理.Image ─────▶ 结果显示.SrcImage       （底图用处理后的，标注看得清）
```

工业上通用的链顺序（顺序错了参数调到死也没用）：

```
转灰度 → 裁剪/屏蔽 → 滤波 → 增强 → 形态学 → 二值化
```

边缘检测通常**单独走一条分支**，不插在主链末端：

```
转灰度 → 裁剪/屏蔽 → 滤波 → Sobel/Laplace → 二值化 → Blob/轮廓类下游
```

顶帽/黑帽也是"特征图"而不是"干净图"：它们输出的是被形态学清掉的那部分残差，
适合直接接二值化/Blob，不适合再当普通灰度图继续做亮度/对比度调整。

## 三条决定"现象与参数关系"的铁律

1. **禁用 = 透传**，不是"这一步没有输出"。关掉一个算子，画面立刻回到"没有它"的样子。
2. **单个算子出错只跳过那一步**，插件写一条含算子名与原因的 Warn，本步骤整体仍算成功。
   所以"画面看着不对但没有报警"是设计行为，要查日志里的"执行失败，已跳过"。
3. **图像所有权归插件**。输出端口的图由框架统一回收，链中间的临时图跑一步扔一张，
   正式运行不会把每步的图攒进内存（只有配置界面的逐步预览会保留中间图）。
