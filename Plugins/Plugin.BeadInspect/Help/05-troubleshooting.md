# 胶路检测 · 常见问题与排障

> 分类：缺陷检测 ｜ 来源：插件 Plugin.BeadInspect

下面的"现象"列写的都是**界面上会出现的原话**（步骤错误详情、日志、配置界面横幅/状态栏），
照着对号即可。判定用的字段（`IsOk` / `NgReason`）与执行失败（错误详情）是两回事，先看第四节。

## 一、执行失败类（步骤红，必须处理）

| 现象（原文） | 为什么 | 怎么改 |
| --- | --- | --- |
| `输入图像为空或未初始化` | `SrcImage` 没连、上游没出图或图已被回收 | 连上游图像端口；确认上游步骤本轮成功出图 |
| `未找到可用配方：请在配置界面新建配方并学习参考路径` | 配方库是空的（方案里没带配方，或库文本损坏后按空库处理） | 打开配置界面「新增」→ 载入参考图 → 拾取路径 → 学习；或确认接的端口给的是有配方的那个步骤 |
| `未知配方：{名字} 没有对应胶路配方（库里有：{名单}）` | `RecipeName` 给了名字但库里没有（大小写与空格都算不同） | 让上游给的名字与配方名逐字符一致；或在界面点「设为默认」并停接该端口 |
| `参考路径点列为空：请在配置界面拾取或导入胶路中心线` | 配方的点列还没录 | 画布左键拾取或「自动提取」，≥ 2 点后重新学习 |
| `参考路径第 {N} 个点格式无效（应为 [row, col]）` | 手工改过 `RecipeLibraryJson`，点列结构不对 | 别手改库文本；在界面表格里重录该点 |
| `参考路径点列 JSON 解析失败：…` | 点列文本被改坏 | 同上；必要时删掉该配方重建 |
| `参考路径至少需要 2 个点：请在配置界面拾取或导入胶路中心线` | 只拾了 1 个点 | 继续拾到 ≥ 2 点 |
| `参考路径退化（各点几乎重合）：无法生成有效曲线` | 点几乎全在同一个位置，生成不出有效曲线 | 重新沿胶条走向拾取，点要铺开 |
| `对齐模式为「匹配位姿」但未连接 AlignedImage：请连接匹配插件的对齐图输出，或改用其它对齐模式` | 选了匹配位姿却没有上游对齐图 | 接上游匹配插件的对齐图；或把模式改成「平面可变形」/「固定相机」 |
| `配方未学习：请先在配置界面载入参考图并点击「学习」` | 「平面可变形」模式下该配方没有参考图路径 | 点「① 配方库」的「载入」选参考图，再「学习」 |
| `参考图不存在：{路径}（换路径后需重新学习）` | 参考图文件移动/删除/换机器（落盘的是路径不是图） | 把文件放回原路径，或改路径后重新「学习」 |
| `图像对齐失败：平面匹配未找到匹配实例：请检查参考图与当前图是否为同一平面、对齐模式与矫正设置是否正确` | 搜索窗口里一个实例都没找到（0 命中） | 加大「⑤ 平面匹配搜索范围」的角度范围/缩放；确认参考图与当前图是同一平面 |
| `图像对齐失败：平面匹配分数 {分数} 低于阈值 {阈值}，请检查参考图与当前图是否为同一平面` | 找到了但相似度不够 | 降低 `MinScore` 前先确认光照/形变是否可接受；或换「匹配位姿」模式 |
| `目标胶宽 {值} 低于 HALCON 合法下界 6（#3716）：请把「目标胶宽」调到 ≥ 6` | 直接绕过界面传了过小的胶宽（界面输入会被自动夹到 6，正常走不到这条） | 把胶宽设为 ≥ 6；胶真的很细时应考虑换检测思路而不是硬压参数 |
| `创建胶路检测模型失败：…` / `平面模型准备失败：…` | 建模型阶段算法报错（路径异常、参考图内容不可用等） | 看冒号后面的原始原因；重新拾取路径、换一张干净参考图再学习 |
| `输出单位设为毫米，但既未连接标定变换也未填写像素当量：请补其一` | 要 mm 却没有当量来源 | 接标定插件的 `Transform`，或填 `PixelSizeMm` |
| `标定失配：当前图 {W}×{H} ≠ 标定图 {W}×{H}，换分辨率/换相机后需重新标定` | 标定是在别的分辨率/相机上做的 | 用当前相机重新标定；或临时把单位改回像素 |
| `标定变换的像素当量无效（MmPerPixel ≤ 0）：请重新运行标定` | 上游标定没给出有效当量 | 检查标定步骤是否成功、接的是不是它的 `Transform` |
| `骨架为空：平面区内没有分割出有效胶条，无法提取中心线` | 自动提取时在平面区域内分不出胶条 | 补/换「无胶参考图路径」；确认良品图里胶条完整、位姿与参考一致 |
| `提取点列不足（合并后少于 2 点）：请检查图像中的胶条是否完整` | 分割出了东西但合并后成不了一条线 | 手工在画布拾取，或换更干净的良品图 |
| `载入参考图失败：…` | 参考图文件读不出来（格式/权限/占用） | 换个常规格式（bmp/png/jpg/tif）确认文件可读 |
| `胶路检测失败：…` | 运行中抛出未预料异常（统一兜底话术） | 看后面的原始原因与日志；能把复现图存下来最好 |

## 二、配置界面被拒绝（横幅/状态栏，不落盘）

| 现象 | 含义 | 下一步 |
| --- | --- | --- |
| `学习失败：没有可学习的配方条目——先在「① 配方库」选一条，或点「新增」` | 当前没有编辑中的配方 | 先选/新增配方 |
| `学习失败：未设参考图路径——「平面可变形」对齐需要参考图（模板 + 坐标系基准）。请点「① 配方库」的「载入」选择参考图文件，或把「对齐模式」改成「固定相机」` | 只有平面对齐模式要求参考图 | 载入参考图，或换模式 |
| `学习失败：参考路径点列为空或格式无效——请在画布上左键拾取至少 2 个点（或点「自动提取」）` | 点列不可用 | 拾取/提取后重学 |
| `学习失败：参考路径至少需要 2 个点（当前 {N} 个）——继续在画布上左键拾取` | 点不够 | 继续拾点 |
| `请先载入图像（绑定输入图，或点「① 配方库」的「载入」选参考图）再拾取点` | 画布无底图，拾取被拒（没有图就没有坐标系） | 绑输入图或载入参考图 |
| 点「拾取矫正四点」后提示 `请先点「① 配方库」的「载入」选择参考图，再拾取矫正四点` | 四点拾取要在**原始参考图**上点 | 先载入参考图 |
| `已取消自动提取：原点列保持不变` | 你在覆盖确认框里选了"否" | 需要替换就重新点「自动提取」并选"是" |
| `自动提取失败：{原因}` | 提取链路某一步没过去 | 按原因处理；原点列不会被清空 |
| `已清除矫正四点：跳过矫正，直接用参考图建平面模型` | 正常提示（矫正四点非必需，但设了更稳） | 需要时重新拾取 |
| `参考图载入失败：{原因}` | 读文件出错 | 检查文件与路径 |

## 三、不报错但结果"看着不对"

| 现象 | 真实原因 | 怎么办 |
| --- | --- | --- |
| 整条判「缺胶」 | 极性选反（暗胶/亮胶只能二选一） | 在 ③ 配方参数把极性改成另一个再学习 |
| `ErrorCount` 比明细少、红标比预想少 | 长度小于 `MinErrorLength` 的碎段被丢弃（连计数一起丢） | 需要看到碎段就调小 `MinErrorLength` |
| 改了胶宽/容差但结果没变 | 忘了重新「学习」，或改的是插件级值而该配方填了自己的值（配方值优先） | 看列表行是否显示「参数已变·需重学」；确认改的是哪一层 |
| `BeadContours` 只有 1 个对象 | 只检出了一侧轮廓（另一侧没有） | 看标注图与 `NgReason`，通常是缺胶/严重偏移导致 |
| `AnnotatedImage` 是空的但判定数值都在 | 渲染只是"给人看"，画不出来时**不影响**端口数据 | 按数值判定继续；需要留证时检查图幅/字体环境后重跑 |
| 接了 `RoiRegion` 后坐标"看起来不对" | 它只缩小处理域，**不改变**任何输出坐标 | 不要用 ROI 位置去减坐标 |
| 第一次跑明显慢 | 模型句柄不随方案存盘，按指纹惰性重建（平面模型重建实测 100~360ms） | 同参数连续运行会复用，属正常；避免每轮换配方 |
| 标注图发到第 2 格而不是第 1 格 | 「显示窗口」选的就是那个窗口号（1~9，0 = 不发布） | 改成想要的窗口号 |
| 画布有图但状态栏还写着"尚未载入" | 底图与提示是同一处统一更新的，正常不会出现 | 记录复现步骤（换配方/换模式顺序）反馈维护者 |

## 四、判定语义：NG ≠ 失败

```
执行失败：图空 / 无配方 / 配方名不认识 / 路径退化 / 未学习 / 参考图缺失 /
          对齐未命中或分数不足 / 建模型失败 / 毫米换算缺来源
          → 步骤红、有错误详情、下游拿不到本轮结果
判定 NG：正常结果。Success 仍为 true，IsOk=false，NgReason 有内容，
          标注图与全部数值端口照常输出
```

下游要分流请用 `IsOk` / `NgReason` / `ErrorCount`，不要靠"步骤是否报错"来判断有无缺陷。

## 五、日志与自检线索

- 每轮成功都会写一行日志（判定字段取值为 `OK` 或 `NG`）：

```
{步骤名} 配方「{名}」错误段=N（缺胶a/太细b/太粗c/偏移d） 总长=Xpx 判定=OK
```

  「平面可变形」对齐成功还会写 `… 配方「{名}」平面匹配 score=0.000`——**分数贴近阈值**是最早的失效信号。
- 释放平面模型句柄失败会留痕（运行期进日志，配置期进调试输出），不会静默：句柄泄漏必须看得见。
- 界面下方常驻横幅会写「学习」的每条结论（含成功），不必翻状态栏那行小字。
