# 胶路检测 · 上手步骤

## 一、准备一张良品图

先用采集算子（或「相机设置」的预览）取一张**良品**的图，作为画参考路径的底图。

## 二、配置这个步骤

双击步骤（或右键「模块参数」）打开配置界面，按顺序做四件事：

1. **画参考路径**：沿胶路中心画一条参考路径——它定义"要沿哪条线找胶"。
   路径画在良品图的胶中线上，起点终点都留一点余量；
2. **设胶宽**：`TargetWidth` 填实际胶宽（像素量级），`WidthTolerance` 填允许的宽窄波动。
   > 量不准就先目测填，跑一遍看标注图再修——标注图会把参考路径和检出的左右轮廓画在一起，
   > 差多少一眼就能看出来；
3. **选极性**：深色胶选 `Dark`，浅色（发亮）的胶选 `Bright`。选反了的表现是"整条都判缺胶"；
4. **加配方**：给这条产品型号加一个配方条目（配方名建议就用产品型号），再点「设为默认」，
   这样 `RecipeName` 端口没接东西时也有一条可用配方。

## 三、跑一遍看标注图

编译并运行流程，在图像画布上看 `AnnotatedImage`：

- 轮廓贴不上胶沿 → 说明参考路径画偏了，或工件的姿态变化已经超出对齐能力（换 `PoseFromMatching` 模式并上游接匹配）；
- 整条全判「缺胶」→ 先查极性是否选反，再查参考路径是否落在胶上；
- 到处零零碎碎的「太细 / 太粗」→ 先把 `MinErrorLength` 调大滤掉碎段，再放大 `WidthTolerance`；
- 判定整体偏严/偏松 → 调 `WidthTolerance`、`PositionTolerance`，不要先动 `TargetWidth`（那是真实尺寸）。

## 四、上线前

- 用 `UnitOutput = Mm` 时，要么接上游标定插件的 `Transform`，要么把 `PixelSizeMm` 填准；
- `DisplayViewIndex` 决定标注图发到几号视图窗口；不想发就填 0（不影响判定与输出）；
- 回放几组 NG 样本，确认 `NgReason` 里报的类型与现场看到的缺陷一致后再接报警。
