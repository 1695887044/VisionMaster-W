# 胶路检测 · 界面与编辑

> 分类：缺陷检测 ｜ 来源：插件 Plugin.BeadInspect

配置界面分两栏：**左设置栏**（从上到下 ⓪~⑤ 六张卡 + 结果预览 + 怎么用）、**右侧画布工作区**（工具栏 + 结论横幅 + 拾取画布 + 底部状态条）。
左栏宽度固定 330px（不再有可拖的分栏条），内容超出高度时**整栏可滚动**——画布因此获得稳定余量。
界面里**没有任何业务计算**：点列、配方、学习、提取全在插件对象上，视图只转发按钮与鼠标事件。

## 一、六张卡在干什么

| 卡 | 里面有什么 | 注意点 |
| --- | --- | --- |
| ⓪ 输入绑定 | `SrcImage` / `RecipeName` / `AlignedImageIn` / `RoiRegion` / `Transform` 五个可链接编辑器 | 每个都能点"链接"接变量或上游端口；tooltip 里写了端口实名 |
| ① 配方库 | 列表（每行显示配方名、`N 点`、学习状态）+「新增」「删除」「设为默认」+ 参考图路径与「载入」+「自动提取输入（可选）」三栏（无胶参考图 / 提取用良品图 / **抽稀目标点数**） | 一行 = 一个产品型号；点选择配方会自动载入它的参考图 |
| ② 路径点列 | 三列表格（`#` / `Row` / `Col`）+ 每行「删」按钮 | 与画布**双向同步**：改数字=移点，画布加/删/拖也会刷新表格 |
| ③ 配方参数 | 胶宽(px)、容差(px)、位置(px)、极性 + 折叠的「高级：显式目标矩形」 | 这些是**本配方**的值；填 0 表示改用「④ 运行参数」里的插件级值 |
| ④ 运行参数 | 对齐模式、输出单位、碎段过滤(px)、显示窗口、**像素当量(mm/px)**、**输出对齐图** | 显示窗口 0 = 不发布到主界面；像素当量与输出对齐图见第五节 |
| ⑤ 平面匹配搜索范围 | 起始角(°)、角度范围(°)、缩放R最小/最大、缩放C最小/最大、**最低分数**、**金字塔层数** | 仅「平面可变形」模式生效；默认值来自范例实测，不改也能跑 |

卡「怎么用」里常驻一句话流程：新增配方 → 载入参考图 → 画布逐点拾取（或自动提取）→ 学习 → 可选拾取矫正四点 → 试运行看标注图。

## 二、画布手势

```
左键按下 ──┬─ 12px 内命中已有点 → 进入拖动改坐标（真正移动的第一下才记一步撤销）
           └─ 没命中 → 加一个新点，自动插到"离点击处最近的那一段"之间，走向不折返
右键按下 → 删除离点击处最近的点（50px 内才删，防误触）；拾取矫正四点期间右键不动手
Ctrl+Z   → 撤销上一步（加点/删点/拖动/清空/表格改动都算一步，最多存 100 步）
滚轮     → 缩放；「适应图片」按钮铺满整幅底图
```

画布下方常驻图例与提示（原文照抄，含竖线分隔）：

```
左键加点｜右键删点｜拖动改坐标｜Ctrl+Z｜滚轮缩放｜橙=路径 红=点 青=四角
```

叠加层走共享画布控件的标注通道：**橙**=参考路径（相邻点连线）、**红**=点（小十字）、**青**=矫正四点（十字 + 顺序连线，凑齐 4 点闭合）。

**没有底图时一切拾取都被拒绝**（没有图就没有坐标系），状态栏红字：
`请先载入图像（绑定输入图，或点「① 配方库」的「载入」选参考图）再拾取点`。
画布中央同时给空态提示「尚未载入图像 / 绑定输入图，或 / 点「载入」选择参考图文件」。

## 三、底图从哪来（四级优先）与它为什么重要

点列存的是**当前底图坐标系**的坐标，所以底图是谁，直接决定学出来的路径能不能用：

| 顺序 | 底图 | 状态栏提示（原文节选） |
| --- | --- | --- |
| ① | 参考图（矫正后） | `底图：参考图（矫正后）——路径点列存的就是该坐标系的坐标` |
| ② | 参考图（原始） | `底图：参考图（原始）——未设矫正四点（或非「平面可变形」模式），点列存原始参考图坐标` |
| ③ | 输入图兜底 | `底图：输入图（尚未设参考图）——若用「平面可变形」对齐，请点「① 配方库」的「载入」选择参考图文件；固定相机模式可直接拾取` |
| ④ | 都没有 | `尚未载入图像：绑定上游输入图，或在 ①配方库 点「载入」选择参考图文件` |

③ 兜底时若对齐模式是「平面可变形」，一拾点就会在按钮下方弹**橙色横幅**：

```
注意：底图是输入图而非参考图——「平面可变形」的点列必须落在参考图坐标系上。请点「① 配方库」的「载入」选择参考图文件后重新拾取，否则点「学习」会被拒绝
```

这是"只提示不禁止"：固定相机场景在输入图上拾取本来就是正确用法。底图切回参考图后该横幅自动折叠。

## 四、「载入」参考图

- 路径为空或文件已不存在 → 弹文件选择框（图像文件 `*.bmp;*.jpg;*.jpeg;*.png;*.tif;*.tiff`），选定后自动写回路径框并上屏；取消 = 什么都不动。
- 路径有效 → 直接载入（同一路径已缓存则不重复读盘）。
- 读图失败 → `参考图载入失败：…`；文件不存在 → `参考图不存在：{路径}`。
- 这一列路径**属于配方**：换配方就是换参考图。

## 五、学习 / 自动提取 / 矫正四点

| 按钮 | 前置条件 | 结果 |
| --- | --- | --- |
| 「学习」 | 至少 2 个点；「平面可变形」模式还需参考图路径有效 | 建 bead 模型（平面对齐再建平面模型），写学习指纹，行状态变「已学习」，预览出参考路径叠加图，横幅写成功 |
| 「自动提取」 | 填了「提取用良品图路径」且文件存在，参考图存在 | 差分（或 black-hat 回退）分割胶条 → 骨架 → 树直径合并 → 抽稀到「抽稀目标点数」（默认 40）；**覆盖原点列前弹确认**，失败不写空点列 |
| 「撤销」/`Ctrl+Z` | 撤销栈非空 | 回到上一步点列 |
| 「清空点列」 | 点列非空 | 清空，可撤销 |
| 「拾取矫正四点」 | 已载入参考图 | 进入四点模式：底图切**原始**参考图，依次点四角，第 4 点自动记录并重建平面模型，底图随后切**矫正后**参考图；再点一次退出 |
| 「清除矫正」 | 该配方有矫正四点 | 清空 `RectifyQuadJson`（空 = 跳过矫正，直接用参考图建平面模型） |
| 「应用目标矩形」 | 有 4 个源点（当前拾取或已存） | 用显式目标矩形（默认 20,20–420,660）替代自动推导 |

- 「学习」按钮在点数不足 2 时**置灰**（可用性绑的就是"点数够不够"），tooltip 会说明原因。
- 自动提取填两张图：**无胶参考图路径**是差分基准（实测贴合最紧），留空则回退 black-hat（覆盖度较差）；
  **提取用良品图路径**是"胶路完整、位姿与参考一致"的那张良品图。
- **抽稀目标点数**（默认 40，可填 10~500 的整数）决定自动提取后保留多少个路径点。
  40~80 点对检出结果几乎无影响，点数越多画布上的点越密、手工微调越费事。
  这一项**只对本次配置会话有效、不落盘**——它不是步骤配置项，重新打开配置界面会回到 40。
- 「拾取矫正四点」默认按源四点外接矩形 + 20px 边距**自动推导**目标矩形；该推导路径未过真值断言，
  需要精确坐标系请用「高级：显式目标矩形」。
- 每次点「学习」的**每条返回路径**（成功与被拒）都会把结论写在按钮下方的横幅里，不用翻状态栏。

## 六、像素当量与输出对齐图（④ 运行参数）

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 像素当量(mm/px) | 0（未填） | 只在「输出单位 = 毫米」且**没接**标定 `Transform` 端口时兜底；填 0 = 视为未填，毫米输出会失败并提示补来源。范围 0~1000 |
| 输出对齐图 | 勾选 | 勾上 = `AlignedImage` 输出端口给出对齐后的图（供下游复用，省一次对齐计算）；取消 = 该口输出为空，**对齐本身照做**（判定与标注图不受影响） |

像素当量与标定的优先级是固定的：**接了 `Transform` 就用标定值**，参数只在没接标定时生效
（标定还带图像尺寸校验，换分辨率/换相机后必须重新标定）。

## 七、最低分数与金字塔层数（⑤ 搜索范围）

| 项 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- |
| 最低分数 | 0.4 | 0 ~ 1 | 平面匹配得分低于它就判对齐失败。调高更严（可能把能用的对齐也拒掉），调低更宽容（可能接受错位） |
| 金字塔层数 | 5 | 1 ~ 10 的整数 | 匹配用的图像金字塔层数。层数多 = 更快，但工件越小/越模糊越容易漏；超出范围会被夹回 1~10 |

这两项与「起始角 / 角度范围 / 行列缩放」一起决定「平面可变形」的搜索行为，见《检测口径与调参》第四节。

## 八、为什么「极性」下拉是英文

`极性` 选项显示的是 `dark` / `light` 两个**算法字面量**，不是中文。这是有意的：
HALCON 建胶路模型时只认这两个字符串，界面直接把字面量摊开，避免"界面上叫暗胶、存盘写的是另一个词"这类歧义。
`对齐模式`（固定相机（不对齐）/ 匹配位姿 / 平面可变形（投影））与`输出单位`（像素 / 毫米）都是中文，
它们由枚举的显示特性提供，鼠标悬停的 tooltip 里给了各自的选择建议。
