# 胶路检测 · 快速上手

> 分类：缺陷检测 ｜ 来源：插件 Plugin.BeadInspect

沿一条**人工参考路径**检查胶条：按目标胶宽与容差把胶路切成分段判定，产出「缺胶 / 太细 / 太粗 / 位置偏移」
四类错误段、逐段长度与中心坐标、错误段轮廓、一张标注图，以及 `IsOk` 与 `NgReason`。
一个算子里可以放**多条配方**（一条 = 一个产品型号），运行时由 `RecipeName` 端口决定用哪一条。
它和「Blob 缺陷检测」的区别是：Blob 看**整片区域里冒出什么**，本算子看**沿一条既定线胶得对不对**。

## 一分钟理解它产出什么

```
一条参考路径（≥ 2 个点）+ 目标胶宽 + 宽容差 + 位置容差 + 极性
        ↓ 学习：建 bead 检测模型（+「平面可变形」模式再建平面模型）
运行时（每轮）
   ├── 对齐：把待检图搬回参考位姿（三模式，见检测口径页）
   ├── 检测：沿路径提取左右胶路轮廓，按宽度/位置偏差切段
   ├── 过滤：长度 < MinErrorLength 的碎段直接丢弃
   └── 输出
         IsOk / NgReason          判定与「缺胶 2 段、太细 1 段」这类原因串
         ErrorCount + ErrorTypes / ErrorLengths / ErrorRows / ErrorCols   逐段明细，四个数组逐项对齐
         NoBeadCount / TooThinCount / TooThickCount / MispositionCount    四类各自的段数
         TotalErrorLength         错误段总长（像素或毫米，随 UnitOutput）
         ErrorSegments / BeadContours / AlignedImage                        轮廓、左右胶路线、对齐图
         AnnotatedImage           标注图（橙=参考路径，绿=左右轮廓，红=错误段加粗，角上判定文字）
```

**记住一句话**：先把**一条良品胶路**学进去，再看标注图调容差——标注图把参考路径、检出的左右轮廓和
错误段画在同一张图上，差多少一眼能量出来，比先猜参数快得多。

## 第一次跑通（6 步）

1. **连输入图**：把上游图像（如 `图像采集.OutputImage`）连到本步骤的 `SrcImage`——必填，没图直接失败。
2. **建配方**：双击步骤打开配置界面，在「① 配方库」点「新增」（自动取名 `配方1`、`配方2`…）。
3. **给参考图**：点「载入」选一张良品图文件。默认对齐模式是「平面可变形」，参考图既是模板也是坐标系基准，
   这一步不能跳（只有「固定相机」「匹配位姿」两种模式不需要它）。
4. **画路径**：在画布上**左键**沿胶条中心线逐点拾取（至少 2 个点），右键删点、拖动改点、`Ctrl+Z` 撤销；
   点多了懒得调可以填「提取用良品图路径」后点「自动提取」。
5. **点「学习」**：横幅写「学习成功」才算数；此后改了胶宽/容差/位置容差/极性，列表该行会变「参数已变·需重学」。
6. **试运行**：看标注图与 `IsOk`，再按检测口径页调 `MinErrorLength` / `WidthTolerance`；
   「显示窗口」选主界面第几格显示标注图（0 = 不发布），点确定保存。

## 典型接线

```
图像采集.OutputImage ──▶ 胶路检测.SrcImage                    （必填）

【多产品切换】
变量/上游型号字符串 ──▶ 胶路检测.RecipeName                    （不接就用「设为默认」那条，仍无则取库首条）

【产线上先看对齐再检】
模板匹配.AlignedImage ──▶ 胶路检测.AlignedImage                （对齐模式选「匹配位姿」时才用）
ROI.MaskRegion        ──▶ 胶路检测.RoiRegion                    （可选：只在区域内检测，缩域提速）

【下游分流】
胶路检测.IsOk           ──▶ 比较/逻辑/上报：OK 放行、NG 报警
胶路检测.NgReason       ──▶ 结果上报 / 结果显示（文字）
胶路检测.AnnotatedImage ──▶ 结果显示 / 存图留证
胶路检测.ErrorCount     ──▶ 计数、报表
胶路检测.TotalErrorLength ──▶ 阈值判断（缺胶总长超 X mm 判 NG）
```

## 三个最容易踩的点（细节在后面的页）

1. **改了胶宽/容差必须重新点「学习」**：模型参数烧在指纹里，不重学就还是旧模型；
   配方库那行的「参数已变·需重学」就是提醒这件事。
2. **NG 是正常结果，不是执行失败**：判定 NG 时步骤照样「成功」，`IsOk` 为 false、`NgReason` 有内容。
   只有图空、没配方、对齐没命中、单位换算缺来源这类才是失败并给中文话术。
3. **输出单位选「毫米」必须有来源**：接标定插件的 `Transform`，或填 `PixelSizeMm`；两者皆无**直接失败**，
   不会静默按像素输出。

## 什么情况下该用它 / 不该用它

| 场景 | 用什么 |
| --- | --- |
| 胶条、焊道、密封线这类"沿一条线检查宽度与连续性" | **本算子**（四类分段判定就是为它设计的） |
| 目标位置每轮会跑偏，要先找出来 | 上游放「模板匹配」定位，本算子用「匹配位姿」模式接它的对齐图 |
| 面上任意位置的斑点、划伤、脏污 | 「Blob 缺陷检测」，不是本算子 |
| 只要一条路径的几何量（长度、角度） | 「卡尺测量」/ 几何类算子 |
| 工件有明显透视形变（印刷、柔性件） | 本算子的「平面可变形」模式（默认），必要时拾取矫正四点 |
