# 图像脚本 · 端口与参数

> 分类：图像处理 ｜ 来源：插件 Plugin.ImageScript

## 输入端口

本插件**没有固定输入端口**——输入端口全部由「输入变量」表逐行生成。

| 端口 | 必填 | 说明 |
| --- | --- | --- |
| 变量行 `Name` | 图形类必填 | 端口名 = 变量名 = 脚本里的变量名（三者同一个字符串）。类型由该行的「类型」下拉决定 |
| `Success` / `ErrorMessage` | — | 基类自带输出端口（见下表） |

声明类型 → 端口实际承载的 CLR 类型（决定能不能和上游连上）：

| 类型下拉 | 端口类型 | 用途 |
| --- | --- | --- |
| `HImage` | `HImage` | 图像 |
| `HRegion` | `HRegion` | 区域（`threshold` / `connection` 的产物） |
| `HXld` | `HXLDCont` | 轮廓/XLD（亚像素边缘、拟合线圆；注意界面写 `HXld`、类型是 `HXLDCont`） |
| `HObject` | `HObject` | 不确定是图/区域/轮廓时的通配 |
| `Int` / `Double` / `String` | `int` / `double` / `string` | 数值与文本 |
| `HTuple` | `HTuple` | HALCON 元组（数组） |

- **图形类（`HObject` / `HImage` / `HRegion` / `HXld`）必须连线**，手填不出图；未连线或上游图为空 → 直接失败，**脚本一行都不执行**。
- 控制类（`Int` / `Double` / `String` / `HTuple`）可以连线取上游值，也可以在该行右侧的常量框直接填；`HTuple` 手填按空格/逗号/分号切分，能转成数值的按数值给。
- 变量名默认来自过程接口：点「同步接口变量」把当前过程的接口刷进表格（**按名字合并**：同名保留你已声明的类型，新增的按名字猜类型，接口里没有的会被移除）。

## 输出端口

| 端口 | 说明 |
| --- | --- |
| 「输出变量」表逐行生成的动态端口 | 脚本跑完按声明类型从引擎取值：图形类走 `GetOutputIconicParam*`，控制类走控制参数元组再转类型 |
| `Success` | 本轮是否成功（编译/输入缺失/脚本异常都会置 false） |
| `ErrorMessage` | 失败原因（已经是中文可读文案） |
| `AnnotatedImage` | 脚本自绘效果图（`dev_display` / `dev_disp_text` 画完后由宿主回读的 HImage）。接「图像赋值」→ 全局 HImage → SCADA「图像显示」即可看到脚本画的缺陷/文字；与主界面窗口 1 收到的是同一张图。**固定端口，名字保留**：输出变量表里不要再叫 `AnnotatedImage`（同名会被跳过） |

- 声明了输出但脚本没写它 → 失败并提示"接口声明了它，但脚本没有写入"（不是 HALCON 那句 `Index out of range`）。
- 图形输出的「显示窗口」下拉选 1~9，就把这一路结果推到对应视图；区域/轮廓会**叠加画在第一路图像输入上**（无底图时按图形范围生成黑底画布）。

## 关键参数

> 完整参数与取值范围以流程中该步骤的「模块参数」界面为准，这里只解释含义。

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `Procedures` | 空（首次打开自动装默认脚本） | 全部过程脚本本体（接口 + 正文），随配置内嵌进 `.vms`，不是外部文件 |
| `SelectedProcedure` | 第一个非 `main` 过程名 | 本轮要运行的过程；运行下拉里**不含 `main`** |
| `InputVars` | 空 | 输入变量表：每行一个动态输入端口 |
| `OutputVars` | 空 | 输出变量表：每行一个动态输出端口 |
| 变量行 · `Name` | — | 变量名 = 端口名 = 脚本里的变量名。**改名字等于换端口**，原来连到这行的连线会断（连线按端口名锚定），要重连 |
| 变量行 · `Type` | 同步时按名字猜（见下） | 声明类型。改类型 → 端口按新 CLR 类型重建 |
| 变量行 · `Remark` | 空 | 备注。**会当两件事用**：输出端口的说明，以及随图信息里那一行的名字（没填就用变量名） |
| 变量行 · `DisplayWindow` | `0` | 0 = 不显示；1~9 = 推到主界面第几号视图窗口。**仅图形类输出有效** |

新增变量时的类型猜测规则（只是默认值，可以改）：控制类看名字首字母，`i…` → `Int`、`s…` → `String`、其余 → `Double`；
图形类看名字里含 `image` / `region` / `xld`|`contour`，都不含则 `HObject`。
⚠ 结论类文本变量（如 `Result` 存 `OK`/`NG`）会被猜成 `Double`，**要手动改成 `String`**（插件自带的默认脚本就是显式写好的）。

## 口径与失败策略

- **编译失败 = 本步骤失败**，不抛异常、不弹框：原因写进 `ErrorMessage`（带行号与中文提示），流程按失败分支走。
- **脚本运行期抛异常 = 失败**（HALCON 异常翻译成中文消息；画图环节单独归类成"画图失败"提示，与算法错误分开）。
- **没有超时**：脚本是本地代码，插件不设时限、不做沙箱；死循环会一直占着这条流程，需要自己控制循环次数。
- **急停**：执行透传流程的取消令牌，但脚本正文里读不到它——长循环请自己加退出条件，不要指望急停立刻打断一段大循环。
- **显示环节失败不判失败**：底图合成、区域/轮廓转图、发布预览失败都只跳过显示，不影响算法结果。
- **同内容复用编译结果**：改一个字就重编译；缓存条目超过 64 条整表清空。
- **空输入**：图形输入为空 → 立刻失败并点名是哪个变量（不会让 HALCON 去报天书错误）。
