# YOLO 目标检测 · 开发章节：不变量与守门断言

> 分类：图像处理 ｜ 来源：插件 Plugin.Yolo ｜ 读者：开发

守门文件：`FlowCanvasChecks\YoloChecks.cs`（46 条）。下面每条给"症状 → 机理 → 断言名"，断言名逐字取自该文件。

## A 组：违反就报错或结果明显不对

1. **症状** 摆上节点没配模型就运行，节点失败。
   **机理** 不允许抛异常，必须给可读原因（`尚未选择模型：…`、`模型文件不存在：…`）。
   **守门断言名** `未选模型 → 报失败且原因指向配置（不抛异常）`、`模型路径不存在 → 报失败且原因含「不存在」`、`模型不存在 → 明确报错而不是静默成功`。

2. **症状** 类别过滤写 `abc` 后节点失败并说明该填什么。
   **机理** 非法项不静默忽略——静默忽略等于用户以为过滤生效了。
   **守门断言名** `类别过滤填了非法值 → 报失败并说明该填什么（不静默忽略）`。

3. **症状** 换模型路径后仍用旧会话。
   **机理** 会话按路径键控；这一条盯的是路径比较（`OrdinalIgnoreCase`）与缓存复用。
   **守门断言名** `会话随模型路径切换（需要 ONNX 模型）`、`【核心】同一模型第二次获取命中缓存，未重复加载`、`会话进入进程级缓存…`、`插件 Dispose 后会话引用计数归零、缓存释放`。

4. **症状** 框整体偏移一个固定量。
   **机理** 忘了减补边或忘了除缩放。
   **守门断言名** `【核心】坐标换算回原图：减去补边再除以缩放系数`、`letterbox 宽图/高图 缩放系数与补边正确`、`越界框被夹进原图范围…`。

5. **症状** 框的尺寸对但位置八竿子打不着，或不报错。
   **机理** `crop_part` 行列写反；或越界未夹取。
   **守门断言名** `【核心】裁剪：裁到的是框所指的位置（白块在裁剪图内）`、`【核心】裁剪：框外的区域裁出来是全黑（证明行列没写反）`、`【核心】越界框被夹进图像范围（crop_part 越界不报错，必须自己夹）`、`【核心】边距把框推出图像时被夹取并留痕（不越界不报、越界必报）`、`没检测到目标时不做裁剪（返回空而不是随便裁一块）`。

6. **症状** 用分割或姿态模型时输出一堆像正常的乱框。
   **机理** 分割输出 `[1,116,8400]` 在**形状上**与检测不可区分，只能靠元数据 `task` 拦。
   **守门断言名** `已知歧义：分割模型的形状在几何上与检测无法区分（会被误读成 112 类）`、`【核心】task 元数据守卫：segment 模型被明确拒绝（形状拦不住的它能拦）`、`task 守卫：pose 也拒；detect 放行、元数据缺失时放行…`、`【核心】真实非目标模型（v2 网格布局）被守卫栏明确拒绝，且原因可读`。

7. **症状** 用 YOLOv5 导出模型时结果错但不报错。
   **机理** `[1,N,5+C]` 与 `[1,4+C,N]` 维度顺序相反，必须拒绝而不是按 v8 硬解。
   **守门断言名** `【核心】YOLOv5 风格的 [1,25200,85] 被明确拒绝（不按 v8 硬解）`、`布局校验：YOLOv8 的 [1,84,8400] 被识别（80 类）`。

8. **症状** 两个不同类别的重叠框只剩一个。
   **机理** NMS 跨类压制。缺陷检测里"异物"与"划伤"常完全重叠。
   **守门断言名** `【核心】NMS 按类别分别做：「异物」与「划伤」框完全重叠也互不压制`、`【核心】NMS 同类去重…`。

9. **症状** 类别名凭空多出几个假名字。
   **机理** 元数据没带 names 时必须占位，不许编造。
   **守门断言名** `模型没带类别名时用 class_N 占位，不编造名字`。

## B 组：违反不报错，只是精度静默下降

10. **症状** 检测率慢慢变差，日志干净。
    **机理** 预处理与训练不一致：直接拉伸而非 letterbox、补边用了 0 而不是 114、忘了 `/255`。
    **守门断言名** `【核心】端到端（受控张量）…`、`解码 3 条`（受控张量那一组）；单帧补边值靠源码常量 `PadGrayValue = 114` 核对。

11. **症状** 灰度图报 #3122 通道数不一致。
    **机理** 送进 `overpaint_gray` 的源图恒为 3 通道，画布必须无条件补成 3 通道。
    **守门断言名** 无断言，靠人工核对（喂一张单通道图跑一次试算）。

12. **症状** 空张量或全零输出把节点搞崩。
    **机理** 解码要能在 0 个候选时正常收尾。
    **守门断言名** `全零张量 → 解出 0 个（不崩）`。

13. **症状** 工具箱里找不到这个节点，或分组跑偏。
    **机理** `[Display]` 的 `GroupName` 被改动；宿主按它分组。
    **守门断言名** `插件带 [Display] 且归入「图像处理」组…`。

14. **症状** 下游接不住检测结果。
    **机理** 端口名或类型被改。
    **守门断言名** `输出端口契约齐全（数组 + 文本 + 裁剪图）`、`输出用法演示（端口值形态）`。

15. **症状** 现场换机后报 `DllNotFoundException`。
    **机理** onnxruntime 原生库没进宿主 exe 目录，或进程是 32 位。
    **守门断言名** `ONNX 依赖链路 set`、`真实推理链路 3 条`。

## 并行安全声明

带 `[ParallelSafe]`。成立的前提是三条：`YoloSession.Cache` 有 `CacheLock`、`Session.Run` 线程安全、
每轮推理不写共享可变状态。去掉锁或引入实例级缓存要**同时**摘掉这个特性，否则真并行下会出现"同模型多次加载"或字典竞态。
