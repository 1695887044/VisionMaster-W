# 深度学习分类 · 排错

> 分类：图像处理 ｜ 来源：插件 Plugin.DlClassify

## 六、现场排障（报错原文 → 查什么）

| 报错 / 现象 | 排查 |
| --- | --- |
| `尚未选择模型：请在节点配置里选择一个 .onnx 分类模型` | 没填路径 |
| `模型文件不存在：<路径>` | 路径填错 / 模型没部署；相对路径以**宿主程序目录**为基准核对 |
| `这个模型的任务类型是「目标检测/实例分割/…」（元数据 task=…）` | 用 classify 任务重新导出（见第一节命令） |
| `无法识别的输出形状 […]：期望分类模型的 [1, C]` | 这不是分类模型（检测 `[1,4+C,N]` / 分割 `[1,C,H,W]`），改用对应节点 |
| `输出类别数 1 不合理（分类模型至少 2 类）` | 导出异常或模型不是分类头 |
| `输出张量长度 N 小于类别数 C，模型输出与元数据不一致` | 模型被裁剪过/导出损坏，重新导出 |
| `图像通道数为 N，只支持 1 通道（自动补成 3）或 3 通道` | 上游先转成灰度或 RGB（常见于 4 通道 RGBA） |
| `无法确定模型输入尺寸：模型是动态形状…` | 手填`输入尺寸`（分类常见 224）。留 0 会明确报错，**不猜** |
| `加载 ONNX 模型失败：…` | ① 文件不是合法 `.onnx`；② `onnxruntime.dll` 没投递到宿主 exe 目录；③ 32 位进程（必须 x64） |
| 运行期 `DllNotFoundException: onnxruntime` | 原生库不在 exe 旁边（Windows 不递归搜 `Modules\`） |
| 运行期 `FileNotFoundException`（Tensors） | `System.Numerics.Tensors` 没随插件带，它**不在** .NET 9 共享框架里 |
| 日志出现"置信度偏低…请勿直接用于放行" | 这是提醒（阈值 0.6），不是故障。检查预处理是否一致，并确认下游门禁已搭好 |
| 步骤报 `执行已取消` | 流程被停止（本算子起手检查一次取消令牌）。属正常中断 |
| 换了模型路径但结果像旧模型 | 不该发生（会话按路径判变）。确认改的是**本步骤**的路径，且界面摘要已显示新文件名 |
