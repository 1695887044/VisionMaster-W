# 深度学习分类 · 开发章节：不变量与守门断言

> 分类：图像处理 ｜ 来源：插件 Plugin.DlClassify ｜ 读者：开发

守门文件：`FlowCanvasChecks\ClassifyChecks.cs`（39 条）。逐条给"症状 → 机理 → 断言名"。

## A 组：违反就报错或结果明显不对

1. **症状** 没配模型就运行，节点失败但不抛异常。
   **守门断言名** `未指定模型` 与 `路径不存在` 两条错误路径断言（报错文案分别指向配置界面与文件路径）。
2. **症状** 用检测或分割模型跑分类。
   **机理** 输出格式完全不同，硬算会给出看着正常的错概率；形状拦不住的靠元数据 `task` 拦。
   **守门断言名** `【核心】task 守卫：detect 模型被明确拒绝（附中文任务名）`、`segment 模型被明确拒绝`、`classify 放行`、`元数据缺失放行`。
3. **症状** 把检测当分类解读，得到 8400 类。
   **守门断言名** `【核心】布局：[1,84,8400]（检测）被拒绝…`、`【核心】布局：[1,2,224,224]（语义分割）被拒绝`、`[1,1] 只有 1 类 → 拒绝（分类至少 2 类）`。
4. **症状** 形状能读但类数离谱。
   **守门断言名** `布局：[1,3] 识别为 3 类`、`[1000]（无 batch 维）识别为 1000 类`、`[1,1,5] 识别为 5 类`。
5. **症状** 置信度全被压到接近均匀。
   **机理** 模型最后一层已接 Softmax，再归一一次不报错只压平分布。
   **守门断言名** `【核心】已是概率（和≈1）→ 原样保留，不再 softmax（否则分布被压平）`。
6. **症状** logits 直接当概率用，和不为 1。
   **守门断言名** `logits（和≠1）→ softmax…`、`全负 logits → softmax：和仍为 1（不因负值判成概率）`、`数值稳定：大 logits（1000/999）softmax 不溢出、和为 1`。
7. **症状** TopK 越界或为 0 时崩。
   **守门断言名** `K 被夹到类别总数（99 → 3）`、`K 下界为 1（0 → 1）`、`降序取前2`。
8. **症状** 类别名张冠李戴。
   **机理** `ClassNames` 与 `Scores` 必须同序，缺名只能占位。
   **守门断言名** `【核心】ClassNames 与 Scores 同序且全为真实名（TopK<类别数也不许错名）`、`class_N 占位`、`部分名/全占位`。
9. **症状** 默认行为变了（换了缩放模式或默认 TopK）。
   **守门断言名** `默认缩放模式 = Letterbox（不破坏长宽比的那一档）`、`默认 TopK = 3`。
10. **症状** 配置读写往返丢值。
    **守门断言名** `ModelPath 走源生成器 partial 属性（读写往返一致）`。
11. **症状** 预处理几何错（补边算错）。
    **守门断言名** `letterbox 宽/高 with exact numbers` 那一组、`stretch 模式：直接铺满画布、无补边`。
12. **症状** 会话没被复用或没被释放。
    **守门断言名** `真实模型会话+缓存+引用计数` 那一组（含 `CachedSessionCount` 归零）。

## B 组：违反不报错，只是精度或可信度静默下降

13. **症状** 精度慢慢掉，日志干净。
    **机理** `ResizeMode` 与训练时不一致。letterbox 与 stretch 都是"合法写法"，只有和训练对齐才是对的。
    **守门断言名** 无断言，靠人工核对（拿同一张图分别按两种模式跑，与训练框架的结果对照）。
14. **症状** 输入尺寸猜的，框和概率一起偏。
    **机理** 模型是动态形状且没填「输入尺寸」时**必须报错**，不许默认 224。
    **守门断言名** 无断言，靠人工核对（用动态形状模型且 `InputSize=0` 跑一次，看是否得到"无法确定模型输入尺寸"）。
15. **症状** 低置信结果被当成放行依据。
    **机理** `private const double LowConfidenceThreshold = 0.6;` 命中时写 Warn（不是 Fail），
    Warn 文本要含"本次结果不可信，请勿直接用于放行"，这样记录上传能把这一轮捞出来。
    **守门断言名** 无断言，靠人工核对（构造一次低分推理看日志里有没有 Warn）。
16. **症状** 取消后仍完成一次模型加载。
    **机理** `RunAlgorithm` 第一步判 `CancellationToken`，在任何加载之前。
    **守门断言名** 无断言，靠人工核对。
17. **症状** 灰度单通道图报错。
    **机理** 预处理要先补成 3 通道再喂模型（与 YOLO 同一族坑，`#3122` 类错误的分类侧版本）。
    **守门断言名** 无断言，靠人工核对。

## 并行安全声明

带 `[ParallelSafe]`，注释理由是"会话带锁、推理无共享可变状态"。
前提被破坏（例如把上一次推理结果缓存到实例字段供界面复用）时要**同时**摘掉该特性，否则并行流程会互相覆盖结果。
