# 卡尺测量 · 界面与编辑

> 分类：测量 ｜ 来源：插件 Plugin.CaliperMeasure

这一页讲**界面怎么用**：六张卡各管什么、画布上的搜索区怎么新建/拖动/删除、参数改了什么时候生效、
预览图上那几层颜色各代表什么。"为什么这样算"在第 4 页，"报什么错怎么修"在第 5 页。

## 一、界面地图

左右两列。左列是可滚动的参数卡，从上到下六张：

| 卡片 | 控件 | 作用 |
| --- | --- | --- |
| 图像输入 | 「输入图像」链接框、`重置搜索区` 按钮 | 绑 `SrcImage` 端口；按钮按当前类型重建默认搜索区（**会清掉现有区域**，摆好的要重新拖） |
| ① 测量类型 | 下拉「测量类型」+ 一行灰字提示 | 五类量选一；灰字实时写"当前测量类型需要 N 个（圆形/矩形）搜索区，已配置 M 个" |
| ② 搜索区与卡尺 | 数值框「卡尺数 N」、`搜索区列表`、`删除` / `重置` 按钮、`参数微调` 数值行 | 摆区的唯一入口；列表行显示 `名字 [形状]`，选中后下面出参数微调行 |
| ③ 找边参数 | 「平滑 Sigma」「边缘阈值」「极性」「选择」「插值方式」 | 剖面与找边闸门 |
| ④ 拟合参数 | 「拟合方式」「最大残差(px)」「最少点数」，圆直径多一行「环宽(px)」 | **只在三种拟合类出现**（点到线距/圆直径/角度），看不到不是坏了 |
| ⑤ 判定与标定 | 「标准值」「上公差」「下公差」「像素当量(mm/px)」+ 两行说明 | 规格与当量 |

右列一块：`标注图预览（可拖拽搜索区）`——上面是图，右上角写"改参数后自动刷新"，下面是三色信息栏
（绿=正常、橙=还能继续、红=失败）。**这块既是预览也是画布**：预览用的就是那张标注图，句柄照样能拖。

界面上钉死的两句提示，走查时反复用得上：

- 「① 测量类型」卡里：**一个步骤只测一个尺寸；要测多个尺寸请添加多个卡尺测量步骤。**
- 「② 搜索区与卡尺」卡里：**矩形要「横跨」被测的边缝：半长 L1 方向=扫描方向（与边垂直），半宽 L2 方向=卡尺阵列排布方向。**

## 二、改参数什么时候生效

| 你动的地方 | 生效时机 | 注意 |
| --- | --- | --- |
| 数值框（卡尺数 N、Sigma、边缘阈值、拟合三件、判定四件） | 约 200ms 防抖后自动重算预览 | 不用点任何按钮；防抖是因为整幅图 + N 把卡尺算一遍不便宜 |
| 下拉（测量类型、极性、选择、插值方式、拟合方式） | 同上，即时 | 切换类型**只补缺的搜索区，绝不删你摆好的**，也绝不改已有区的形状 |
| `参数微调` 里的文本框 | **失去焦点才写回** | 打完成绩要按 Tab 或点一下画布别处，不然画布不动——"改了没反应"九成是这个 |
| 画布上拖句柄 | 松手即回传，即时刷新 | 粗调用拖拽，精调用微调行，两边实时同步（同一个数据源） |
| 「输入图像」换图 / 接上上游 | 自动补足搜索区 + 刷新 | 只在配置界面里跑；产线每帧不会白烧一遍完整测量 |

## 三、搜索区怎么摆

**新建**：画布右键 → 区域 → 新建矩形 / 新建圆形。第一个默认叫 `搜索区1`，第二个 `搜索区2`（重名会自动跳号）。
**选中**：点画布上的区，或在 `搜索区列表` 里点行——两边联动，选中后 `参数微调` 出现该区的参数行。
**删除**：选中后按 **Del**，或点列表旁的 `删除` 按钮。焦点在文本框里时 Del 被当成编辑键，删除命令被有意挡住（防误删）；
先点一下列表里的区或画布空白处再按。
**重置**：`重置搜索区` 按钮按当前类型重建默认区（宽度/圆直径=1 个，其余=2 个；圆直径播种圆形）。

运算**只取列表前 N 个**（N = 类型所需个数）：多余的区留在列表里排在前面就会占位，
你以为在用第 3 个区，其实用的是第 1 个。用不上的请删掉。

### 形状参数（随方案存盘，运行期不变）

| 形状 | `参数微调` 里的名字 | 口径 |
| --- | --- | --- |
| 矩形 | 中心行(R)、中心列(C)、角度(Phi)、半长(L1)、半宽(L2) | Phi 存的是**弧度**；L1/L2 取绝对值使用，两者都不得小于 1px |
| 圆形 | 圆心行(R)、圆心列(C)、半径(Radius) | 半径取绝对值，不得小于 1px；半径同时决定圆周卡尺的分布位置 |
| 椭圆 | 圆心行(R)、圆心列(C)、旋转角(Phi)、长半轴(Ra)、短半轴(Rb) | **算法不收**：卡尺阵列只在矩形/圆周上均布，误建了会在运行时明确报错 |

摆放的硬口径（第 4 页第二节给算术）：**L1 = 扫描方向，被测边要垂直于它；L2 = 阵列排布方向，沿着边本身。**
测竖直边用 Phi=0（此时 L1 沿水平）；测水平边把 Phi 转 90°（约 1.5708 弧度）。

### 没有图时界面上会播种什么

首次打开配置界面（或换图后区数不足）时按当前类型补默认区：

- 矩形类：把图像按所需数量切成等宽竖条，取本条中心（中心行 = 图高一半，中心列 = 条带宽的一半 + 序号偏移），
  半长 L1 = 条带宽 × 35%，半宽 L2 = 图高 × 25%，Phi=0——正好"横跨"竖直走向的边，最常见的起手姿态；
- 圆直径：圆心取图像中心，半径取短边的 25%；
- 拿不到图像尺寸时回退按 640×480 计算（拖一下即可）。

只补"数量"，不纠正"形状"，也**绝不删/改你已摆好的区**——形状不对会在运行期给中文指引。

## 四、画布手势约定（与全仓库同一套）

- 画布控件由宿主统一提供（`ImageEdit`），插件只把 `PreviewImage`（只读）、搜索区集合、当前选中区三项接上去；
  右键新建、拖句柄、命中判定、缩放平移这些**全在控件里**，插件不实现第二遍；
- 冷启动（刚打开界面、图刚刚加载）第一次按句柄时，控件会**回放一次按下动作**，
  所以"第一下就抓住就能拖"，不需要先点一下激活；
- 命中容差（屏幕上 14 像素）只用于"点空白处取消选中"这类去激活判断；
  对其他对象的命中测试不带容差，所以别指望在框边 1px 处点一下就抓到框；
- `rectangle2` 的**半长 L1 沿列轴方向**（Phi=0 时水平）：这就是"测竖直边用 Phi=0"的由来；
- 拖动句柄改的是**弧度制 Phi 与像素制 L1/L2**，微调行显示的就是这几个原始值，没有隐藏的换算。

> 工件位置飘出搜索区时，卡尺**不会跟着走**——搜索区是配置期固定的。
> 表现就是"某把卡尺未检出边缘"。来料定位差就得先定位（模板匹配）再想办法把工件请回搜索区，别指望这里自己追。

## 五、预览图上有什么（图层从下到上）

`MeasureImage` 与这块预览用的是同一套渲染，图层顺序固定：

| 图层 | 样式 | 是什么 | 该看它判断什么 |
| --- | --- | --- | --- |
| 底图 | 原图 | 送进来测量的那张图（通道/位深由共享渲染件归一化后显示） | 搜索区有没有压在真实特征上 |
| 卡尺小矩形 | 黄，1px 描边 | N 把卡尺各自的位置与朝向 | 黄框是不是**横跨**特征、朝向是不是垂直于边 |
| 测量连线 | 青，2px 描边 | 量的到底是哪一段：宽度=每对边之间、两点距=两代表点之间、点线距=垂线段、圆直径=过圆心的直径线、角度=夹角弧 | 连线连的是不是你想量的两点 |
| 拟合几何 | 品红，2px 描边 | 拟合出的直线 / 整圆 / 两条线（宽度与两点距没有这一层） | 拟合几何贴不贴真实边 |
| 边缘点 | 绿十字，2px 描边 | 每把卡尺检出的那个亚像素点（十字臂长 12px、45° 斜放） | 十字有没有落在毛刺/杂边上 |
| 左上角文字 | 白底框，OK 绿字 / NG 红字 | 三行：判定、测量值（带单位）、偏差 | 一眼确认这轮的结果与单位 |

四列全用**描边**画（不填充），所以标注不会盖住被检特征本身。

## 六、信息栏三色口径

| 颜色 | 含义 | 典型文案 |
| --- | --- | --- |
| 绿 | 预览成功（判定 OK 也算成功） | `宽度/间隙：测量值=…（像素=…×当量） 标准=… 偏差=… 判定=OK 卡尺=5` |
| 橙 | 还没配好，但能继续 | `输入图像为空：请为上方「输入图像」指定图片，或连接上游图像端口` |
| 红 | 配置不合法或算法失败（**包括判定 NG**） | 任意一条失败原文（见第 5 页字典） |

文字与颜色**成对更新**，所以不会出现"失败变红后成功仍停红"。判定 NG 时信息栏是红的，
但流程里这一步是绿的（`Success` = true）——分流请用 `IsOk`，别看步骤红绿。

## 七、测量失败的预览表现

预览与流程跑的是**同一个算法核心**：算法失败时不产标注图、预览底图也会直接清空。
所以"预览区一片空白"通常等于"没测成"，先按信息栏那句红字查第 5 页，别把它当成界面坏了。
预览路径捕获到异常时**不弹框、不抛出**，只把原因写在信息栏（`预览失败：…`），改参数重试即可。

## 八、配置态与运行态是分开的

- 预览只在"为打开配置界面而创建的那个实例"上跑；运行实例从不订阅输入图变化、也从不跑预览。
  否则产线每帧会在 UI 线程多跑一遍完整测量（N 把卡尺 + 拟合 + 离屏渲染），界面变卡、CPU 白烧；
- 因此你在界面里看到的图 = 该实例自己算出来的标注图，而流程运行时的 `MeasureImage` 由流程那一轮产出；
  两者共用同一段代码，口径一致；
- 搜索区与全部参数随方案（`.vms`）存盘，运行期不变；改区/改参数需要**保存方案**才会影响产线。
