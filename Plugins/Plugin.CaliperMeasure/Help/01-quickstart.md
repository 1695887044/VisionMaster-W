# 卡尺测量 · 快速上手

> 分类：测量 ｜ 来源：插件 Plugin.CaliperMeasure

阵列式卡尺：在你摆的一个**搜索区**里自动均布 N 把卡尺做**亚像素找边**，支持**宽度/间隙、两点距、点到线距、圆直径、角度**五类量，
输出**物理值 + 与标准值的偏差 + OK/NG**，并给出标注图、拟合几何与原始边缘点。
**一个步骤只测一个尺寸**——界面上写得很明白，要测多个尺寸就加多个卡尺测量步骤。

## 一、定位：做什么、不做什么

| 它做 | 它不做（该找谁） |
| --- | --- |
| 量一个几何尺寸的**数值**并判 OK/NG | 定位目标在哪 → 「模板匹配」；匹配完的坐标可以拿来推着卡尺搜索区走 |
| 亚像素找边（边在两个像素之间也能给位置） | 有没有缺陷、缺陷多少 → 「Blob 缺陷检测」 |
| 把像素值乘标定当量换成 mm（角度除外） | 自己算当量 → 「标定」插件出 `MmPerPixel`，本算子只是接过来用 |
| 叠一张自带判定文字的标注图（`MeasureImage`） | 把**别的算子**的结果烧进图 → 「结果显示」；本算子只烧自己的四图层 |
| 输出一条线/一个圆/两个点这些几何（`FittedGeometry`、`EdgePoints`） | 裁剪、屏蔽、洗图 → 「ROI」「图像预处理」（它们改图，本算子只读图） |

为什么需要它：手工在图上画条线量距离，只量到**一个位置**——光照一变、毛刺一来，读数就漂。
卡尺把"在哪找边"交给**灰度剖面**，再用多个位置上的边一起出结果，单个坏点的影响被摊薄。
这就是"阵列式"三个字的价值：**同一件东西量 N 次，而不是量 1 次赌运气。**

## 二、五类量先对上号

| 类型（界面中文） | 需要几个什么形状的搜索区 | 一句话口径 |
| --- | --- | --- |
| 宽度/间隙 | 1 个矩形 | 一把卡尺一次给出**成对边**，取第一对边的对内间距，N 把取平均 |
| 两点距 | 2 个矩形 | 每个区把各自 N 个边点平均成**一个代表点**，量两代表点的欧氏距离 |
| 点到线距 | 2 个矩形（区 1 当"点"、区 2 当"线"） | 区 2 的 N 点拟合直线，取**点到无限直线的垂距** |
| 圆直径 | 1 个**圆形** | 沿圆周径向均布卡尺 → 拟合圆 → 直径 = 2 × 拟合半径 |
| 角度 | 2 个矩形 | 两条拟合线归一化成射线后取夹角，**固定落在 0~180°**，单位是度 |

算法链、均布算术、失败口径这些"为什么这样算"在第 4 页「找边与拟合口径」；
本页只管**从零跑通**。端口与参数的逐格对照在第 3 页。

## 三、第一次接这个算子：13 步走查

### 第 1 步｜把图接进来

在左列「图像输入」卡的「输入图像」行点链接按钮，选上游的图像输出（采集的 `OutputImage`、
预处理的 `Image`，或 ROI 的 `Domain_名字`——推荐 `Domain_`，坐标系不动）。
**期望**：信息栏不再写"输入图像为空：请为上方「输入图像」指定图片，或连接上游图像端口"。
**没做对**：接的是别的步骤的**裁剪图**（`Crop_名字`）也能跑，但坐标系搬走了，你对着原图想的搜索区位置会整体偏。
**判据**：右侧画布出现底图。信息栏变绿或变红都不算这一步的错（红是"还没配好"，不是"没接上"）。

### 第 2 步｜让画布上有真实的那张图

流程没跑起来时，在「输入图像」行直接指定一张图；已经接了上游就**试运行一次**，上游的图会自动进来。
**期望**：画布上出现未标注的原图或上一轮的标注图，搜索区压在图上看得见。
**没做对**：拿一张不相干的图调参 → 阈值、极性全调歪，换真图又要重来。
**判据**：把搜索区拖到某个特征上，那个特征在图上肉眼可见（不然无法判断边找得对不对）。

### 第 3 步｜选测量类型

在「① 测量类型」的下拉里选。
**期望**：下面灰字变成"当前测量类型需要 1（或 2）个矩形/圆形搜索区，已配置 …"；
选到点到线距/圆直径/角度时「④ 拟合参数」卡**冒出来**；选圆直径时再多了「环宽(px)」。
**没做对**：类型与实际要量的东西不匹配——缝隙用"两点距"量，得到的是两个平均代表点之间的距离而不是缝宽；
圆直径选了矩形区，运行直接报"不是圆形"。
**判据**：灰字里"已配置"的数字 ≥ "需要"的数字，且形状对（圆直径那行写的是"圆形"）。

### 第 4 步｜摆搜索区：数量与顺序

画布右键 → 区域 → 新建矩形（圆直径选新建圆形）。第一个默认叫 `搜索区1`，第二个 `搜索区2`。
两类量的区（点到线距/角度/两点距）要分清**谁当点谁当线**：列表里排第 1 的是"点"（或第一个搜索区），
排第 2 的是"线"。报错文案里的"第 1/第 2 个搜索区"就按这个顺序数。
**期望**：`搜索区列表` 出现对应行数，右侧画布出现可拖拽的手柄框。
**没做对**：多余的区留在列表里但排在前面——**运算只取前 N 个**，你以为在用第 3 个区，其实用的是第 1 个。
**判据**：把不用的区选中后按 Del 删掉，让列表数量正好等于需要数量。

### 第 5 步｜定扫描方向：让矩形横跨被测特征（决定成败）

选中搜索区，在 `参数微调` 里改 角度(Phi)/半长(L1)/半宽(L2)（改完按 Tab 写回），或直接拖画布句柄。
规则只有一条：**L1 方向 = 每把卡尺的扫描方向，被测边要垂直于它**；L2 方向 = 卡尺阵列铺开方向，**沿着边本身**。
测竖直边 → Phi 让 L1 指向水平（Phi=0 就是）；测水平边 → Phi 转 90°（约 1.5708 弧度）。
半长 L1 要**长过特征**：至少覆盖"缝宽 + 两边各一点余量"，扫描线从一侧穿到另一侧才叫扫得到。
**期望**：预览里出现**一排黄框**横跨那条边，个数 = 「卡尺数 N」（默认 5），它们沿 L2 方向并排铺开。
**没做对**：把 Phi 转 90° 或 L1 太短 → 直接报"未检出边缘…（请降低边缘阈值、放宽极性，或调整/放大搜索区）"；
文案给了三个候选，**方向错才是第一个**，别一上来就降阈值。
**判据**：数一下黄框个数 = 「卡尺数 N」；每个黄框的**长轴都穿过**那条边，而不是**贴着**那条边走。

### 第 6 步｜设卡尺数 N

「② 搜索区与卡尺」的数值框（默认 5，只收整数）。
**期望**：黄框个数立刻跟着变；预览重算后数值更平稳（多把取平均是这里最主要的抗噪手段）。
**没做对**：N 太大 → 每把的半宽被夹到"相邻间距的一半"（下限 0.5px），黄框挤成一条线，**不会更准，只会更慢**；
圆直径的 N 太小（例如 3~5）→ 点近共线，报"拟合圆退化"。
**判据**：跑 10 次手算极差（最大值减最小值），比改之前小就留着；圆直径起步按 16 把上下试。

### 第 7 步｜第一轮找边：先放宽、再收紧

第一次跑请**故意用宽容配置**：「极性」= 全部、「边缘阈值」先降到 10~15、「平滑 Sigma」保持 1.0、「插值方式」= 双线性。
**期望**：信息栏出绿字（形如 `宽度/间隙：测量值=…（像素=…×当量） 标准=… 偏差=… 判定=… 卡尺=5`），
画布上出现**绿十字贴在真实边上**、**青线连在想量的那两点**之间。
**没做对**：用默认阈值 30 跑弱对比边 → "未检出边缘"。这一步的意义是先让边"出来"，再谈选哪条。
**判据**：绿十字的位置肉眼就在边上（差半个像素以内）；十字落在噪声上说明阈值还得往回抬。

### 第 8 步｜收紧极性与选择，锁定要的那条边

看清图上明暗方向：沿扫描方向是"暗→亮"还是"亮→暗"，把「极性」从"全部"改成那个**单方向**；
再用「选择」决定一条卡尺上有好几条边时取哪条。
**取值口径（容易误解）**：本算子对"第一条"和"全部"取的是**同一个点**——都拿每把卡尺的第一个检出点（宽度取第一对边）；
只有"最后一条"会换到另一头。详见第 4 页第三节。
**期望**：绿十字只出现在你要的那条边上，测量值不再随隔壁对比度乱跳。
**没做对**：留着"全部 + 全部" → 测缝隙量到隔壁那条边，数值"很稳定地错"。
**判据**：把「边缘阈值」往上抬一档再降回来，检出点不变 = 锁住了；一变就说明还有第二条候选在竞争。

### 第 9 步｜逐层看这张预览

停下来只看预览，四层逐个确认（颜色含义见第 2 页第五节）。
**期望**：黄框横跨 / 绿十字贴边 / 青线连对的那一段 / 品红拟合几何（若有）贴着真实边或圆周。
**没做对**：
- 青线连的不是那两个点 → 回第 8 步；
- 品红线明显斜于真实边 → 杂边把拟合拽歪（挪搜索区、加大「卡尺数」，或检查「拟合方式」别是最小二乘）；
- 圆直径的青线（直径线）比真实圆小一圈 → 只扫到一小段弧，回第 11 步加大环宽或重新套圆。

**判据**：**看着不对就别信数值**——图上确认过再谈精度，这是后续所有调参的前提。

### 第 10 步｜"建参考"：定标准值与上下公差

本算子没有模板学习那种动作，"建参考"就是**把这个尺寸的规格钉下来**，两种来源按顺序选：
① **有图纸**：「标准值」填名义值，「上公差」「下公差」填允许偏差（下公差填**负数**做非对称，例如 +0.05 / −0.02）；
② **没图纸**：拿一件确认合格的良品连跑 5~10 次，看 `MeasureValue` 的平均值当标准值的**草稿**，
公差先用"分散度的一半再放大一档"起步，量块/仪表对数后再改。
**注意单位**：标准值与公差的单位必须与测量值一致（长度类是 mm 或你手填当量后的单位，**角度类填的是度**）。
**期望**：判定从默认全 NG 变成 OK（良品），信息栏出现"判定=OK"。
**没做对**：出厂 标准值/上公差/下公差 = 0/0/0 是**有意的零容忍**（通用算子不假装知道你产品规格）。
不改就永远 NG——这是提醒你去填，不是坏了。
**判据**：`Deviation` = `MeasureValue` − 标准值 手算能对上；判定规则是 下公差 ≤ 偏差 ≤ 上公差（正好等于边界算 OK）。

### 第 11 步｜定像素当量（长度类的命门）

优先把「标定」步骤的 `MmPerPixel` 输出连到本步骤的 `MmPerPixel` **输入端口**；
没有标定步骤再手填「⑤ 判定与标定」里的「像素当量(mm/px)」（默认 1.0 = 直接输出像素值）。
手填算法：拿已知尺寸的标准件，`当量 = 实际尺寸(mm) ÷ 量到的像素数`。
**期望**：`MeasureValue` 与量具读数同量级；信息栏括号里的 `像素=…×当量` 能手算复核。
**没做对**：
- 接了上游但上游本轮失败/值为 0 或 NaN → **步骤直接判失败**，文案写明"像素当量来自上游连线但无效…"并给两条处置。
  这是设计：**不会拿旧值硬算**；
- 没接线时忘了改手填值 → 结果整体偏一个倍数（默认 1.0 就是纯像素值）。

**判据**：把当量改成 2 倍，测量值应当**正好翻倍**（角度类除外，角度永远不变）。
配置界面的试运行会把上游当量**桥接**进端口，此时端口值优先于手填——"试运行所见 = 运行所得"。

### 第 12 步｜连续运行压噪声，验证重复性

连着跑 20~50 轮（同一种件），看 `MeasureValue` 的分散度与平均值。
**期望**：极差落在现场允许值内；`EdgePoints` 的十字位置肉眼稳定。
**没做对**：
- 数值来回抖 → 先加大「卡尺数 N」，再适当加大「平滑 Sigma」；仍抖就看绿十字是否压在毛刺/倒角/杂边上，把那个位置的搜索区挪开；
- 偶发"未检出"而大多数轮正常 → 极性没收紧，或某把卡尺压到反光带（挪区/降阈值/加 Sigma）；
- 平均值系统性偏 → 先查当量，再查摆位，**最后才怀疑公差**。

**判据**：故意拿一个带毛刺/脏污的样本跑一遍，看结果还贴不贴真值。
样图实测口径：12px 毛刺下点到线距真值 196.5，`Tukey` 得 196.5、`最小二乘` 被拽到 191.092——
要换最小二乘，先确认自己有没有这个耐受度。

### 第 13 步｜接下游（CSV / 上报 / 结果显示）

- **存档追溯（SPC）**：「CSV记录」加列，把列的端口连 `MeasureValue`（格式 `F3`）、`Deviation`（格式 `+0.###`）、`IsOk`；
  要留证据图就连 `MeasureImage` 到那个插件的「图片」列端口；
- **报 MES**：「结果上报」的字段端口连 `IsOk` / `MeasureValue`；上报时机可用「上报触发」端口控制；
- **上屏/叠别的结果**：`MeasureImage` 已自带四层标注与判定文字，直接发布即可；还要叠别的结果就拿它当「结果显示」的 `SrcImage` 底图；
- **做补偿/分拣**：`MeasureValue`、`Deviation` 连「C#脚本」算补偿量。

**判据**：跑一轮后 CSV 那行的数值、正负号、位数与界面信息栏完全一致；NG 样本回放时 `Deviation` 的方向与幅度确实和缺陷一致，再接报警。
**分流请用 `IsOk`，不要用步骤的红绿**——NG 时 `Success` 仍是 true。

## 四、典型接线

```
图像采集.OutputImage ──▶ 卡尺测量.SrcImage          （或 ROI.Domain_测量区 ──▶ SrcImage：坐标不变，最省事）
预处理.Image         ──▶ 卡尺测量.SrcImage          （边缘更清晰，卡尺更稳）
标定.MmPerPixel      ─────▶ 卡尺测量.MmPerPixel     （推荐：当量跟着标定走，标定本轮失败当场判失败）

卡尺测量.MeasureValue ──▶ CSV记录.<列名>            （动态端口，端口名 = 你起的列名；格式给 F3、单位 mm）
卡尺测量.Deviation    ──▶ CSV记录.<列名>            （格式 +0.###）
卡尺测量.IsOk         ──▶ 结果上报.<字段名>          （上报字段同样是动态端口）
卡尺测量.MeasureImage ──▶ 结果显示.SrcImage          （要再叠别的结果时用它当底图；它已自带四层标注）
卡尺测量.EdgePoints   ──▶ 结果显示.r1 / 存档         （复核边缘到底落在哪）
```

> **搜索区不吃「ROI」插件的输出**：卡尺的搜索区存在本步骤自己的画布里（随方案存盘），
> ROI 插件的框是用来限定"看哪里"的另一套东西。两者形状参数写法相同（矩形/圆），但不共用、不互相引用。

## 五、跑通之后的三条硬判据

1. **图上对**：绿十字贴边、青线连你想量的两点、黄框横跨特征；
2. **数对**：当量翻倍测量值翻倍（角度不变），`Deviation` = 测量值 − 标准值 手算可复核；
3. **稳**：连跑 20 轮极差落在现场允许值内，带毛刺样本不会把数拽跑。

三条里有任何一条不成立，先按第 5 页的症状表定位方向，别急着改公差。
