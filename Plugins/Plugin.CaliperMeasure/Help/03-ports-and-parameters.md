# 卡尺测量 · 端口与参数

> 分类：测量 ｜ 来源：插件 Plugin.CaliperMeasure

这一页是**对照表**：端口名与类型、界面字段与出厂默认值、合法区间与越界怎么处理、枚举的界面中文与实际存储值、
哪些东西随方案存盘。全部按源码逐条抄写，界面显示什么这里就写什么。

## 一、输入端口

| 端口 | 类型 | 必填 | 说明（源码原文） |
| --- | --- | --- | --- |
| `SrcImage` | HImage | 是 | 待测量的输入图像。1 通道灰度直接用；3 通道彩色自动转灰度；**其它通道数直接报错**（不猜） |
| `MmPerPixel` | double | 否 | 像素当量（mm/px）：接「标定」插件 MmPerPixel；未接=用手填值。默认端口值 0 |

`MmPerPixel` 的取值优先级（三分支，第 4 页第六节给理由）：

1. **已连线**（连到本步骤端口，或链接了运行时变量）→ 以**上游值为权威**，照常走安全夹取；
   上游值 ≤0 / NaN / Infinity → **明确判失败**并给两条处置，**绝不静默回退**到手填值；
2. **未连线但端口值 > 0** → 用端口值。这一条覆盖配置界面的**试运行**：桥接会把上游实际值灌进端口手动值
   （并清掉连线），此时与运行期同口径取值，保证"试运行所见 = 运行所得"；
3. **未连线且端口值 ≤ 0**（从未接过的常态）→ 用手填的「像素当量(mm/px)」。

## 二、输出端口

| 端口 | 类型 | 说明（源码原文） |
| --- | --- | --- |
| `MeasureValue` | double | 测量值（已乘像素当量）。长度类单位是当量后的单位（mm），角度类是度 |
| `Deviation` | double | 与标准值的偏差（带符号）：测量值 − 标准值，测大为正、测小为负，与测量值同单位 |
| `IsOk` | bool | 判定结果（true = OK 合格）。**NG 不算执行失败**，`Success` 仍是 true |
| `MeasureImage` | HImage | 标注图（卡尺 + 边缘点 + 测量连线/拟合几何 + 判定文字）。渲染失败时它是**空**，测量结果照样有效 |
| `FittedGeometry` | HXLD | 拟合几何（直线/圆/角度两线；宽度与两点距=测量连线） |
| `EdgePoints` | HXLD | 检出的原始边缘点（十字 XLD），给下游复核或存档 |

另有基类的 `Success`（本步跑没跑通）与 `ErrorMessage`（失败原因 / NG 原因）。

**清零口径**：每轮开头 `MeasureValue`、`Deviation` 置 0、`IsOk` 置 false——基类的自动回收只管
`IDisposable` 的图像/XLD 端口，double/bool 会把上一轮的值原样留着。所以失败轮下游读到的是 0/false，不是上一件的脏数。

**N 把卡尺不生成 N 个端口**：全部卡尺矩形合成一个 XLD 对象集，改卡尺数不会把下游的线弄断。

## 三、参数全表（16 个随方案存盘的字段）

> 完整参数与取值范围以流程中该步骤的「模块参数」界面为准，这里给的是源码里的默认值与区间。
> 「界面区间」= 数值框的校验范围；「运行期夹取」= 算法真正使用的夹取范围（老方案/手改文件喂进来的越界值走这条，静默夹取）。

| 界面字段（默认值） | 存储键 | 界面区间 | 运行期夹取 | 调大会看到什么 | 调小会看到什么 | 什么症状说明它错了 | 和哪些字段互相牵制 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 测量类型（宽度/间隙） | `MeasureKind` | 五项选一 | — | 换的是口径不是幅度：切到拟合类多出「④ 拟合参数」卡，切到圆直径多「环宽(px)」 | 切回宽度/两点距时拟合参数卡**收起**（不是删了你的值） | 类型与要量的东西对不上：缝用量成两点距得到"两个平均点距"；圆直径用矩形区直接报"不是圆形" | 搜索区数量与形状、`环宽` 只在圆直径生效、`FittedGeometry` 端口语义 |
| 搜索区列表（空则自动播种） | `CaliperRegions` | 画布右键新建 | 形状/参数长度/尺寸校验 | — | — | 报"需要 N 个…实际只有 M 个""不是矩形/不是圆形""尺寸过小""中心超出图像范围" | 只取列表**前 N 个**；名称用于回写与报错指认 |
| 卡尺数 N（5） | `CaliperCount` | 1~1000，只收整数 | 1~1000，NaN 按 1 | 更稳（多点平均）、更慢；黄框更密，每把半宽被夹到"相邻间距一半"（下限 0.5px），**过密不再提精度** | 更快，但单点噪声权重变大；圆直径的 N 太小会点近共线 → "拟合圆退化" | 数值来回抖（太小）；节拍顶不住（太大）；拟合类报点数不足 | `半宽(L2)`（间距 = 2·L2/N）、`最少点数`（可用点数 ≤ N）、圆直径弧间距与 `环宽` |
| 平滑 Sigma（1.0） | `Sigma` | 0.4~100 | 0.4~100，NaN/Inf 按 0.4 | 剖面更圆滑、抗噪更强，但边"发糊"、过渡带中心定位变钝，弱边可能被抹掉 | 高频起伏被当成边，十字乱跳（配过低阈值时尤其明显） | 十字落在噪声上（太小）；弱边检不到、边位置系统性偏移（太大） | `边缘阈值`（Sigma 大 → 导数峰值小 → 需要更低阈值）、`插值方式` |
| 边缘阈值（30） | `EdgeThreshold` | 1~255 | 1~255 | 只承认强对比；弱边/低对比直接"未检出边缘" | 噪声、纹理、脏污都被当边，检出点跳、数值抖 | 报"未检出"（太大）；数值抖、十字不在边上（太小） | `极性`（单方向能挡掉一半假候选）、`Sigma`、光源强度 |
| 极性（全部） | `Polarity` | 暗→亮 / 亮→暗 / 全部 | — | "全部"最宽容、也最容易跳到隔壁对比度上 | 单方向更严，选反了就**整条检不到** | 量到隔壁那条边、数值"稳定地错"（该收紧）；整把未检出（选反了） | `选择`、`边缘阈值`、宽度类型的"第一对边" |
| 选择（全部） | `Select` | 第一条 / 最后一条 / 全部 | — | 不适用。口径：**"全部"与"第一条"取同一个点**（每把卡尺第一个检出点，宽度取第一对边） | 不适用；只有"最后一条"会换到扫描方向另一头 | 想锁最外侧那条边却选了"全部" → 一直量到最内侧 | `极性`（两者一起决定"锁定哪条边"） |
| 插值方式（双线性（亚像素，默认）） | `Interpolation` | 最近邻 / 双线性 / 双三次 | — | 双三次：过渡更平滑、最慢 | 最近邻：最快，但只能落在整像素上，有半个像素量级的系统性量化误差 | 精度要求亚像素却用了最近邻；节拍极紧且只要求 ±1px 可以降它 | `Sigma`、图像分辨率、节拍 |
| 拟合方式（Tukey 抗离群（推荐）） | `FitAlgorithm` | 最小二乘 / Huber / Tukey | 仅拟合类生效 | 抗离群更强：毛刺点几乎不参与拟合 | 最小二乘等权，**一个坏点能拽歪整条线/圆**（实测 12px 毛刺：Tukey 196.5、最小二乘 191.092） | 换个毛刺位置数值就跳（该用鲁棒档）；边本来就干净、还嫌慢可以降 Huber | `最大残差`（中位数口径与鲁棒档配套）、搜索区摆位 |
| 最大残差(px)（1.0） | `FitMaxError` | 0.05~1e6 | 0.05~1e6 | 容忍弯边/杂边，但错得更远才报（等于放宽质量闸门） | 稍微有点弯就报"拟合残差过大（主体点残差 … px > 允许 … px）" | 拟合类反复报残差过大：先确认特征直不直、区摆得对不对，**不要顺手放到 10** | `拟合方式`、`卡尺数`、`半长/半宽` 摆位 |
| 最少点数（3） | `FitMinPoints` | 2~1000，只收整数 | 2~1000 | 数据不够就报"只收集到 N 个边缘点，少于最少点数 …" | 两点拟出的线毫无冗余，噪声直接进结果（圆还额外受 3 点数学下限约束） | 拟合类报点数不足；或数值抖且线明显歪 | `卡尺数`（可用点数 ≤ N）、`拟合方式` |
| 环宽(px)（30，仅圆直径） | `AnnulusWidth` | 2~1e5 | 2~1e5 | 容得下更大的圆心/半径手摆误差，但更容易扫进相邻特征（隔壁孔边、反光带） | 圆摆稍不准就"圆周卡尺未检出边缘…或增大环宽" | 圆周卡尺未检出（太小）；检出点在隔壁特征上、圆拟歪（太大） | 半径、`卡尺数`（弧间距小 → 半宽夹到间距一半）、圆周卡尺中心越界 |
| 标准值（0） | `StandardValue` | ±1e9；与测量值同单位（角度类填**度**） | ±1e9 | 不适用（它是名义值不是闸门） | 不适用 | 默认 0 = 零容忍，一跑就 NG；单位填错（mm 与 px 混）时偏差量级离谱 | `上公差`/`下公差`、`像素当量`（改了当量要重填标准值） |
| 上公差（0） | `UpperTolerance` | ±1e9 | ±1e9 | 越宽松，NG 越少（别拿它当"消除报警"的手段） | 越严；填 0 且下公差 0 = 零容忍（出厂默认） | 良品反复 NG 且 `Deviation` 很小 → 公差比现场要求紧 | `标准值`、`下公差`、测量值重复性 |
| 下公差（0） | `LowerTolerance` | ±1e9，**允许填负**做非对称公差（例如 +0.05 / −0.02） | ±1e9 | 填正数会把"偏小也算合格"的范围推大（一般不是你要的） | 填大负数 = 允许测小 | 只报"超出下公差"或只报"超出上公差"时，说明公差带不对称方向填错了 | `标准值`、`上公差` |
| 像素当量(mm/px)（1.0） | `PixelSizeMm` | 界面 1e-6~1e6 | 1e-9~1e6（手填与上游连线值走同一条夹取） | 测量值整体按比例放大（**角度不受影响**） | 整体按比例缩小 | 结果整体偏大/偏小一个倍数 | `MmPerPixel` 端口（接线就盖过它）、`标准值`/公差（单位跟着变） |

## 四、枚举：界面显示什么、方案里存什么

界面一律显示中文（`Display` 名称），**方案文件里存的是英文成员名**——导出或手改 `.vms` 时按成员名填。

| 字段 | 界面中文 | 存储成员名 |
| --- | --- | --- |
| 测量类型 | 宽度/间隙、两点距、点到线距、圆直径、角度 | `Width`、`PointToPoint`、`PointToLineDistance`、`CircleDiameter`、`Angle` |
| 极性 | 暗→亮、亮→暗、全部 | `DarkToLight`、`LightToDark`、`All` |
| 选择 | 第一条、最后一条、全部 | `First`、`Last`、`All` |
| 插值方式 | 最近邻（整像素）、双线性（亚像素，默认）、双三次（亚像素） | `Nearest`、`Bilinear`、`Bicubic` |
| 拟合方式 | 最小二乘、Huber 抗离群、Tukey 抗离群（推荐） | `Regression`、`Huber`、`Tukey` |

## 五、搜索区条目存了什么

`CaliperRegions` 是一个列表，每个条目三样东西：

| 字段 | 内容 |
| --- | --- |
| `Name` | 搜索区名（`搜索区1`、`搜索区2`…；自动跳号不重名）。拖拽与参数微调**按名字回写**，改名等于断链 |
| `ShapeType` | 形状（矩形 / 圆形 / 椭圆） |
| `Params` | 形状参数数组：矩形 5 项（中心行、中心列、角度 Phi〔弧度〕、半长 L1、半宽 L2）；圆形 3 项（圆心行、圆心列、半径） |

界面上的"参数微调"行、列表显示文本都是从这三样派生的，**不落盘**；
重开方案时按 `Params` 重建句柄，所以手改 JSON 时数组长度必须与形状匹配（长度不够会报"参数不完整"）。

## 六、类型与显示口径

| 项目 | 口径 |
| --- | --- |
| 坐标系 | 全部图像像素系 `(Row, Col)`；画布上的角度(Phi) 存**弧度** |
| 输出角度 | **度**，固定落在 0~180°（归一化过，不会把 150° 的楔角报成 −30°） |
| 长度类数值 | 像素测量值 × 生效像素当量；**角度不乘当量**（量纲无关） |
| 偏差显示 | 带符号（`+0.###` / `-0.###` / 正好 0 显示 0） |
| 摘要行 | 形如 `类型：测量值=…（像素=…×当量） 标准=… 偏差=… 判定=OK/NG 卡尺=N`；角度类型改写成 `…°（角度不受像素当量影响）` |
| NG 留痕 | `Success` 保持 true，原因写进 `ErrorMessage`（"偏差 … 超出上/下公差（… ）"），摘要行尾部带"（…）" |
| 判定边界 | 下公差 ≤ 偏差 ≤ 上公差 为 OK，**正好等于边界算 OK**（留了极小浮点容差防抖动） |

## 七、日志会写什么

| 时机 | 级别 | 内容 |
| --- | --- | --- |
| 每轮测量成功（含判定 NG） | Info | `步骤名 摘要行`（口径同上一节） |
| 算法失败（配置不合法 / 未检出 / 拟合失败） | Error | `步骤名 失败原因原文`，同一条写进 `ErrorMessage` |
| 异常兜底 | Error | `步骤名 卡尺测量失败：异常信息` |
| 标注图渲染失败 | Warn | `步骤名 标注图渲染失败，MeasureImage 将为空：异常信息`（测量结论不受影响） |

失败原因的逐条原文与处置在「报错字典」（第 5 页第二节），共 34 条。
