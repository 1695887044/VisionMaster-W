# 数学计算

> 分类：数据处理 ｜ 来源：插件 Plugin.Utility

对两个数做**一步**运算，把结果作为 `Result` 输出给下游。工具箱里最省事的"算一下"节点。
本页只讲**定位**和**三步上手**；端口的类型、默认值、必填性查「端口与参数」，
按现象找原因查「排障」，六个运算类工具的共同机制查「开发：结构、契约与不变量」。

## 什么时候用它

流程里要算一个补偿量、一个差值、一个半径（面积反推）、把像素当量换算成毫米——
用算子拼要么得引入额外的中间步骤，要么根本表达不了（比如 `a^b`、`log`）。
本节点把 17 个一元/二元运算收成"选运算类型 + 填两个数"，纯计算、无外部依赖。

**不该用它的事**：多步公式（要串几个节点）、保留指数的格式化（`Round` 不带位数参数）、
整数专用运算（全程 `double`）、atan2 那种象限判别（成员里没有，走「图像脚本」/「C#脚本」）。

## 原理一句话

读三个输入端口的**实际生效值**（连线值优先于面板手填值），按 `Operation` 走一次 `switch`，
算出一个 `double` 写进 `Result`。**没有动态端口**——端口固定四个，改参数不会增减端口，
改名也不会断线（名字写死为 `Operation` / `A` / `B` / `Result`）。

## 三步上手

```
① 工具箱（分组「数据处理」）拖出「数学计算」，落到流程线上。
② 双击节点 → 参数面板三行：A、B、Operation。
   要上游的值就点该行右侧的链接图标连线；只填常量就直接在框里打数字。
③ 选 Operation（下拉里是英文成员名，见下表），下游从 Result 取结果。
```

## 运算类型一览（界面上显示的就是这个成员名）

| 成员名 | 算式 | 用到 | 越界时给什么 |
| --- | --- | --- | --- |
| `Add` | a + b | A、B | 溢出得正负无穷，不报错 |
| `Subtract` | a − b | A、B | 同上 |
| `Multiply` | a × b | A、B | 同上 |
| `Divide` | a ÷ b | A、B | **b 为 0 时结果 `NaN`**（源码显式判过，连 `0/0` 也是 `NaN`） |
| `Power` | a 的 b 次方 | A、B | 负数开非整数次方给 `NaN` |
| `Sqrt` | √a | A | a 为负给 `NaN` |
| `Abs` | a 的绝对值 | A | — |
| `Sin` / `Cos` / `Tan` | 三角函数 | A | **a 是弧度**，不是角度 |
| `Atan` | 反正切 | A | **结果是弧度**，要角度自己乘 180/π |
| `Log` / `Log10` | 自然对数 / 常用对数 | A | a ≤ 0 给 `NaN` |
| `Exp` | e 的 a 次方 | A | 溢出得正无穷 |
| `Round` | 取整 | A | .NET `Math.Round`，**银行家舍入**：`2.5 → 2`、`3.5 → 4` |
| `Floor` / `Ceiling` | 向下 / 向上取整 | A | — |

一元运算只看 `A`，`B` 里填什么都没用。

## 口径（决定"该不该判失败"的那三条）

- **算式跑完这一步就是绿的**——哪怕结果是 `NaN`。框架契约是"默认成功、显式失败"，
  正常路径一行都不写 `Success`，所以除零、负数开方、对负数取对数都只给 `NaN`，**不判失败**。
  要拦住 `NaN` 请在下游接「数值比较」或判定步骤。
- **只有抛异常才红**：记日志 `{实例名} 运算失败: {消息}`，同时 `Result` 置 `NaN`、
  `Success=false`、错误信息 = 异常消息。
- **可以出现在并行分支里**：类上标了 `[ParallelSafe]`（判据：无共享状态、无 IO、微秒级返回）。

## 典型接法

```
像素测量.Value      ──▶ 数学计算.A
标定助手.MmPerPixel ──▶ 数学计算.B
                       数学计算.Operation = Divide        （B 不能为 0）
                       数学计算.Result   ──▶ 数值比较.A   （阈值判定）
                                          └─▶ 类型转换.Input（Target=String 后上报）
```

算偏心量：两路 `Subtract`（实测 − 名义）→ 两路 `Power`（B 填 2）→ `Add` → `Sqrt`。
同一个节点重复用，只改 `Operation`。
