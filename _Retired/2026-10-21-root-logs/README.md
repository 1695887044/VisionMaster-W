# 根目录历史日志（2026-10-21）

本目录是 **2026-10-21 根目录整理**时从仓库根移出的 797 个命令输出文件：
`.log` / `.out` / `.err` / `.txt`，合计约 93 MB。

## 为什么留着而不是直接删

本机 `git` 命令不在 PATH（`.git` 目录存在但无法用 `git` 回滚），所以这一批先"移动留痕"。
其中多数是历史构建/门禁/探针的输出（`_fcc_*.log`、`_phase2_*.log`、`_mainui_*.log` 等），
排查旧问题时可能还要翻。

## 处置建议

- **保留一周**（到 2026-10-28）用于回溯；
- 之后整目录删除即可，不参与构建、不影响任何工程；
- 新产生的日志一律写 `artifacts/logs/<yyyyMMdd>/`，不要再落根目录（见 AGENTS.md §36 C9）。

## 例外说明

`_chem_build.log` 是迁移期间另一个后台构建正在写的文件，构建结束后才移入本目录。
