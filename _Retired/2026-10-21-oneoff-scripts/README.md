# 一次性脚本（2026-10-21）

本目录是 **2026-10-21 根目录整理**时从仓库根移出的 18 个一次性 PowerShell 脚本：

- `uia-*.ps1`（9 个）：UI Automation 临时取点/取控件脚本；
- `_crop*.ps1`（2 个）：截图裁剪；
- `_dwv_*.ps1`（4 个）：停靠面板可见性排查用的一次性 grep/对比脚本；
- `_grep_*.ps1`（2 个）：临时检索；
- `_diff_checks.ps1`：门禁输出差异对比；
- `baseline.ps1`：早期基线脚本。

## 约定

- 这些脚本**不再维护**；需要同类操作时在 `tools/` 下重写，而不是从这里翻旧脚本改。
- 根目录只保留 `pack.ps1` 一个长期脚本（交付打包）。
- 一次性脚本的正式归宿是 `tools/oneoff/`；验证完即删或归档到这里。
