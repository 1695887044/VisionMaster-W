## ⚠️ 最需要记住的三条

1. **动态端口由变量表驱动**——变量表里的**名字 = 端口名 = 脚本里的变量名**，三者是同一个字符串。
2. **必须用 `dev_*` 显示算子**。原生 `open_window` / `set_color` / `disp_text` **照样编译通过、也不报错**，但它们画的是另一个窗口——**效果图会静默变空白**。老写法由 `LegacyDisplayShim` 自动改写。
3. **`dev_disp_text` 必须 7 参**（5 参简写编译不过）；`open_window` 的 mode **只接受 `'buffer'`**。

## 维护约定

1. **只改主文档**。`图像脚本插件.md` 是唯一事实来源；归档件只作历史留档。
2. **动态端口必须在 `ApplyConfigValues` 里重建**（编译器的 `LinkPorts` 之前），否则按名连线失败。
3. **窗口句柄三条铁律**：交给引擎的必须是"新容器"（`new HTuple(_win.H)`），**绝不能**把内部 `_win` 交出去（会 `#2453`）；`HTuple.Clone()` 对句柄型抛 `#2455`；`Append()` 会偷走句柄。
4. **不要改回"判空式行尾注释清理"**——`Area := Width * Height` 曾被误判成行尾注释悄悄变成 `Area := Width`。"不报错但算错"是最危险的失效模式，**宁可放行让引擎报错**。
5. **xshd 里 `#` 必须写成 `\#`**，`Span` 下不能直接放 `Rule`，块注释 `*/` 需转义——否则编辑器空白不可编辑。
6. **修 bug 必须同时补回归断言**（建议新增 `FlowCanvasChecks/ImageScriptChecks.cs`），并在主文档第 4 章记录「现象 → 原因 → 修法」。
7. 模板库里 `'elongation'` 那条注释是错的（HALCON 23.05 不支持），应同步修正。
