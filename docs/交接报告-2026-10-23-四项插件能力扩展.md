## 6. 踩过的坑（这一轮新踩的，写下来省下一次）

### 6.1 HALCON 托管 API 与文档不一致（三次踩）

| 错误 | 真实签名 |
| --- | --- |
| `CS1501 AbsDiffImage 没有 5 参重载` | `AbsDiffImage(image1, image2, out result, mult)` —— **只有 4 参，没有 add** |
| `CS0117 HOperatorSet 不含 CountRegion` | 用 `AreaCenter(region, out area, out _, out _)` 取面积 |
| `CS7036 GetNccModelParams 缺 metric` | `GetNccModelParams(id, out levels, out angleStart, out angleExtent, out angleStep, out metric)` —— **5 个 out**（`GetShapeModelParams` 是 9 个） |

**教训**：本仓 `DLL/Halcon/halcondotnet.dll` **无 xml 文档**，签名只能靠编译或
grep 仓内既有调用点确认，不能凭 HALCON 原生文档（HDevelop 写法）推断。

### 6.2 窗口句柄 API vs 图像对象 API

`HOperatorSet.SetColor` / `DispText` / `HMessage` 的第一个参数都是 **`HTuple` 窗口句柄**，
不是 `HObject`。想在图像对象上写文字必须走离屏烘焙 → 而本仓只许 `AnnotationBaker` 做（R36）。
**结论**：插件里想给图加标题，正确做法是 `PublishPreview(image, viewIndex, title, info, null)`，
不是自己画字。

### 6.3 `InputPort<T>.Value` 是 `object?`

业务代码一律用 **`ActualValue`**。用 `Value` 不只是拿不到强类型，还会引出
`m.IsInitialized()` 与 `IModuleCatalogCommonExtensions.IsInitialized<T>(IModuleCatalog)`
的推断冲突（`CS0411`）。

### 6.4 `PublishPreview` 没有 params 重载

五参重载是 `(image, viewIndex, title, IEnumerable<ImageInfoRow>?, IEnumerable<MeasureAnnotation>?)`。
传数组给第 4 个参数、期望后面还有可变参数，会得到
`CS1503 无法从 "ImageInfoRow[]" 转换为 "IEnumerable<MeasureAnnotation>"`。

### 6.5 `RunAlgorithm` 必须 `public override`

基类里是 `public`，写成 `protected` 报 `CS0507`。

### 6.6 构建被宿主锁住

`Modules\Plugin.X.dll` 被开着的 VisionMaster 进程锁住 → `MSB3027/MSB3021`。
**不要杀进程**，加 `-p:ModulesDir=<暂存目录>\` 投递改道。另：本机 `dotnet build`
必须加 `-m:1 -nodeReuse:false`，否则多进程构建静默失败（报"生成失败 / 0 个错误"）。

### 6.7 `VisionMaster.sln` 是 CRLF + 无 BOM

用 Python 拼锚点必须全按 `b'\r\n'`；按 LF 拼会 `anchor count 0`。

### 6.8 Bash 里传中文给 PowerShell `-Command` 会被拆参数

`powershell -NoProfile -Command "...$t.Replace(...)"` 含中文/引号时 ParserError
（`缺少")"`）。**改文件内容一律用 read + write 工具**，不要拼 powershell 单行。

### 6.9 沙箱子目录 ACL 可能缺 WRITE_OWNER

`workspace-write` 模式下曾出现 `D:\C#\VM` 根可写、子目录全 DENIED
（`MC1000 ... Access to the path '...obj\...MarkupCompile.cache' is denied`）。
修法是 `diagnose-windows-sandbox-acl` skill 的脚本授权（记录在
`D:\C#\VM-artifacts\acl-recovery\`）。本轮会话已是 `danger-full-access`，未再复现。
