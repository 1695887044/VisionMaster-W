## ⚠️ 最需要记住的三条

1. **本插件零 HALCON 算子**——它不 new、不 copy、不 Dispose 任何 `HImage`，只把引用交给写入器。
2. **写入的是引用，不是快照**。上游原地修改同一 `HImage` 会影响变量。要"冻结一帧"应由上游产出新实例。
3. **图像变量的值不落盘**（`HImage` 无法 JSON 序列化）——**重启后画面无图**。

## 维护约定

1. **只改主文档**。`图像赋值插件.md` 是唯一事实来源；归档件只作历史留档。
2. **不要重复声明 `Success` / `ErrorMessage`**——会影子隐藏基类成员，表现为"永远报失败且错误信息为空"（CS0108 教训）。
3. **端口类型不要用枚举**（经 `InputValues` 往返会抛 `InvalidCastException`），一律用 string。
4. **失败必须给可直接展示的中文原因**，禁止静默失败、禁止"无条件报成功"。
5. **运行期只写不增**：不要加"变量不存在就自动创建"。
6. 建议后续补 `FlowCanvasChecks/ImageAssignChecks.cs`（空图 / 变量名空 / 变量不存在 / 类型不符 / 成功写 HImage / 引用语义）。
