共性结论（比单个控件更重要）

① 触摸目标尺寸没有统一口径

轴面板命令键刚改成 44，但点位表行内按钮 22px、位表单格、选择器档位都远小于 44。 建议把"可操作控件命中区 ≥ 44px"写成全局令牌（`HmiTouchTarget`），所有可点图元引用它，而不是各自写死。

② "断线 / 未知"缺第三态

指示类（Indicator / Lamp / 部分设备符号）只有开/关或三态（停/运行/故障）， 但通讯中断时显示的是"上一次的值"——假状态比无状态更危险。建议统一加 `Unknown` 态（灰 + 斜纹）。

③ 同一语义两套画法

Pump/Valve/Motor 与 Symbol 的同类设备外观不同、 运行色也不同。新工程应该只用 Symbol（30 种、状态一致）；老三个保留兼容但工具箱里该标注"旧"。

④ 编辑期可改性没有统一规则

PipeRun 是典型：看起来可拖、可改尺寸，实际被路由器改写。建议给图元加一个统一的 `IsLayoutLockedByCode` 语义，属性面板据此把几何项置灰并提示"由系统计算"。

本轮只有 3 条 P1（Indicator 缺断线态、StateView 互斥字段风险、PipeRun 可改却无效）。 其余 20 余条是 P2/P3——不建议一次性全改：这些控件大多数现场没在用， 先把 P1 三条和共性①（触摸令牌）做掉，比铺开改 20 个控件更划算。
