二、壳怎么来的

A顶栏 72px：品牌/站点 · 运行状态胶囊 · 模式胶囊 · 当前步 · 节拍/本件 · 报警 chip · 操作员 · 时钟。只放 L1 状态。

D右信息栏 340px：报警 → KPI → 明细/权限 → 跳转，顺序固定，不把报警压最下。
E底栏 32px：连接延迟/丢包、模式、方案名、版本、时钟。只读，不放按钮。

四、图像采集怎么处理

  • 采集步骤统一用 Folder 模式（FolderPath + FileIndex 逐张轮播，每轮重新列目录），一个图库文件翻一页就是一条产环节拍；
  • 画面上用 Hmi.ImageView 绑图像变量显示实时图（绑定键 Source，可绑），由运行态数据泵把 HImage 转成位图刷新；
  • 静态对照图上 Hmi.Picture 绑方案内相对路径（键 SourcePath，不可绑）；
  • 已知偏差：本探针离屏渲染没有运行态数据泵，Hmi.ImageView 恒显示"无图像"占位；真出图必须在 VisionMaster.exe 里验证。

D 方案为什么改成「轴控件搭配」

改之前的问题：v2 的 D 方案自己画了四张轴卡、3×3 点动盘、独立点位表、四轴状态表——这些控件本身就有，画面上等于同一件事画了两遍。

改之后：主区直接放 Hmi.AxisConsole 320×470Hmi.AxisPanel 280×280Hmi.AxisPointTable 340×300，一个控件类三个预设，随页面需要选一个。轴选择器做到控件里（下拉），画面不再重复列四根轴。

控件本身就有的（不要重复画）：轴下拉、位置大字、8 个灯（使能/到位/运动/原点/报警/正限位/反限位/急停）、速度、6 个命令键（使能/◀点动/点动▶/回零/停止/清报警）、点位表（示教/定位/速度可编辑）、操作结果提示。

控件真的没有的（橙色候选，不是已实现）：3×3 八向点动盘、步长与倍率、目标位置数字输入、历史回放。本次只在页面上用 Hmi.SelectorSwitch / Hmi.IOField 做替代或标候选，不改控件。

安全与权限（AxisPanelElement 已经内建）

  • 点动按住才动：按下 CaptureMouse 起，抬起 / 移出 / 失去捕获三路都发停止；控件卸载时兜底再发一次停止。
  • 回零长按 0.5 s 才触发（防误触），切轴时对旧轴显式发停止——停是安全动作，不过权限门禁。
  • 权限在按下之前判：CanOperate 绑在按钮容器 IsEnabled 上，角色不够时按钮是灰的，不是按了没反应。

方案 D 为什么要单列

  • 前三套方案（A/B/C）虽是产线设备，但界面重心在「检测结果」；D 的重心是运动本身：轴位置、速度、跟随误差、互锁、回零、点动、点位示教。
  • 触摸屏现场最费页面的是点动与回零：按钮要够大（≥ 56 px）、要能按住、要防误触，所以 D-02 单独占一整页。
  • 机构示意用 Hmi.Panel 里的 SVG 几何拼出来，位置数值与四轴卡片一一对应，不是装饰图。
  • 图元落点：Hmi.AxisPanel（紧凑预设 280×280）、Hmi.AxisConsole（轴控台 320×470）、Hmi.AxisPointTable（点位表）、Hmi.MultiTrend（速度/跟随误差曲线）、Hmi.DataGrid（轴状态与追溯表）、Hmi.KpiBoard（运动 KPI）。

安全与权限（不能省）

  • 手动模式软禁自动：进入 D-02 时自动流程被禁，顶栏状态胶囊变黄并显示 MANUAL。
  • 点动「按住才动」：鼠标按下运动、抬起/移出/失去捕获立刻停（对应 CanOperate 每拍重算 + CaptureMouse）。
  • 回零长按 0.5 s：防误触；回零顺序 Z → X → Y → R（先抬 Z 防撞）。
  • 参数改动需二次确认：D-03 下发参数要确认，落审计（谁、何时、改了哪几项）。
  • 急停始终可达：每页右栏与 D-02 点动盘都有红色急停入口，不做隐藏。
