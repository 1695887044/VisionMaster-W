    <h3>四、图像采集怎么处理</h3>
    <ul>
      <li>采集步骤统一用 <strong>Folder 模式</strong>（<code>FolderPath</code> + <code>FileIndex</code> 逐张轮播，每轮重新列目录），一个图库文件翻一页就是一条产环节拍；</li>
      <li>画面上用 <code>Hmi.ImageView</code> 绑<strong>图像变量</strong>显示实时图（绑定键 <code>Source</code>，可绑），由运行态数据泵把 <code>HImage</code> 转成位图刷新；</li>
      <li>静态对照图上 <code>Hmi.Picture</code> 绑方案内相对路径（键 <code>SourcePath</code>，不可绑）；</li>
      <li><strong>已知偏差</strong>：本探针离屏渲染没有运行态数据泵，<code>Hmi.ImageView</code> 恒显示"无图像"占位；真出图必须在 <code>VisionMaster.exe</code> 里验证。</li>
    </ul>
    <h3>五、已知偏差（逐项列明）</h3>
    <ol>
      <li>字体度量：WPF 与浏览器渲染中文行高略有差异，按 §30 允许；</li>
      <li>滚动条宽度：设计稿用浏览器原生滚动条，WPF 需套自定义样式；</li>
      <li><code>Hmi.ImageView</code> 出图见上；</li>
      <li><code>Hmi.KpiBoard</code> 的设计态数值为空串，本稿用真实数字示意；</li>
      <li><code>Hmi.AxisConsole</code> / <code>AxisPanel</code> 的实际尺寸与本稿示意盘不同，复刻时按控件真实布局重排；</li>
      <li>趋势图为 SVG 示意，真机是 <code>Hmi.MultiTrend</code> 按变量实时绘制。</li>
    </ol>
