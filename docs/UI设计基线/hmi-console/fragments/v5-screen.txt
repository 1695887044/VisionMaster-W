                  <tr><td>按钮角标</td><td>单步时两个点动键角标显示 <code>−1 / +1</code>（随档位变）；连续时不显示角标</td><td>不用低头看上面的选择器，也知道按下去走多少</td></tr>
                  <tr><td>停止语义</td><td>连续：松手/移出/失去捕获三路 JogStop（不变）；单步：一次定位完成即结束，按钮可连点</td><td>两种模式的「停」本来就不同，不要强行统一成一种</td></tr>
                  <tr><td>灰态</td><td><code>CanOperate=false</code> 时整行与按钮一起灰掉，不静默空跑</td><td>沿用 <code>CheckCanRun</code> 的「出口 + 选中轴 + 权限」三闸门</td></tr>
