参数微调搜索区1

矩形要「横跨」被测的边缝：半长 L1 方向=扫描方向（与边垂直），半宽 L2 方向=卡尺阵列排布方向。

04找边参数

越大越抗噪、边缘定位越糊；常用 1.0，HALCON 要求 ≥ 0.4。

相邻像素最小灰度差；太大找不到边，太小噪声当边。常用 30。

沿扫描方向允许哪种明暗跳变；不确定就选「全部」。

一条卡尺上有多条边缘时取哪条；宽度/间隙取第一条配对。

05拟合参数仅拟合类测量

Tukey 对离群点降权，推荐；最小二乘会被单个坏点拽歪整条线/圆。

边缘点到拟合几何距离的中位数上限，超限判拟合失败。

直线 2 点定线、圆 3 点定圆；默认 3。

每把卡尺沿半径方向扫描的总宽度，覆盖圆心/半径摆放误差；默认 30 = ±15px。

06判定与标定下公差 ≤ 偏差 ≤ 上公差

名义尺寸；默认 0 是「零容忍」起点，提示你去填实际规格。

物理值 = 像素测量值 × 像素当量；默认 1.0 = 直接输出像素值（未标定）。

接线取值：把「标定」插件的 MmPerPixel 输出连到本步骤的输入端口「MmPerPixel」，运行时自动以标定当量为准（本框数值作为未接线时的兜底）。

判定：下公差 ≤ 偏差 ≤ 上公差 为 OK；默认标准值/上下公差均为 0（零容忍），因此默认即为 NG。
