## 一、v1 复审结论

v1 是「忠实复刻现有 WPF」的保守稿，六条结构性问题（详见设计稿 §00）：

| # | 问题 | 后果 |
| --- | --- | --- |
| 1 | 层次扁平：组头 32px + 行 32px 完全均匀，分隔只有发丝线 | 长面板（趋势 34 行）滚到哪里、哪组有错，全靠记忆 |
| 2 | 固定左标签是根矛盾：64px 截断、80px 勉强 | 成对数值、布尔、事件行根本不需要左标签，一半行在为不需要的标签付宽度 |
| 3 | 成对数值各占一行 | X/Y、宽/高、偏移、值域被拆散，面板长度翻倍 |
| 4 | 绑定带挂在行下（每绑一个 +20px） | 绑定多时面板显著变长；「值输入 + 绑定带」双份信息，权重颠倒 |
| 5 | 事件/动画只是文字行加勾选 | 「勾选=存在」与「展开=编辑」耦合；复合配置无容器感 |
| 6 | 白底描边输入铺满灰底（框中框） | 几十个描边框抢视线；现代工具用底色差表达输入区 |

**结论：允许推翻。v2 不保留 v1 的样式与布局，只保留信息架构（分组、行、落盘键、语义）。**

## 二、v2 设计原则（五条）

1. **三层深度**：雾白面板底 → 纯白卡片（淡蓝灰描边 + 极浅投影）→ 浅灰 filled 输入（无边框，聚焦才亮描边）。层次靠底色差表达，不靠三层描边。
2. **混合标签**：按字段形态选布局——长文本用上标签、成对数值一行两列、其余左标签 72px。三条规则消灭截断。
3. **复合配置卡片化**：事件/动画是折叠卡——勾选管「配没配」，箭头管展开，摘要常显；动作/档位卡有序号徽标与状态条。
4. **绑定即状态**：绑定后输入框本体变成变量 chip（ƒ + 变量名 + ✕），不另占一行；ƒx 按钮实心主色。
5. **语义色收敛**：晴空蓝=可交互/焦点/选中；琥珀=待完成；赤红=错误/危险；苔绿=成功。四色各管一件事，不混用。

**信息架构唯一变化**：多曲线趋势的 4 条曲线收成「曲线卡」（颜色点 + 名称 + 值 + ƒx 同行），4 个曲线颜色从「外观」组移入「数据」组卡——外观组 8 → 4、数据组 11 → 7。**落盘键全部不变。**

## 三、整体布局结构

### 3.1 面板纵向骨架（300px）

```text
┌────────────────────────────────────────┐
│ 对象头（约52px，白底）                  │ 34px 图标块（晨雾蓝底·主色线性图标）
│   [图标块] 名称(13/600)  锁定 [开关]    │ + 名称 + 类型键（等宽小字）/ 页面模式显示尺寸
├────────────────────────────────────────┤
│ 工具行（约48px）                        │ [🔍 搜索属性(filled，全宽)] [折叠全部]
├────────────────────────────────────────┤
│ 滚动区（雾白底，左右10px内边距，卡距8px）│
│  ╭ 卡片：基本（白底·圆角10·淡蓝灰描边）╮ │
│  │ 组头38px：组名(12.5/600) 计数 点 箭头│ │
│  │ 名称   上标签 + 输入                 │ │
│  ╰────────────────────────────────────╯ │
│  ╭ 卡片：外观 ─────────────────────────╮ │
│  │ 填充色  色块 …           [ƒx]        │ │
│  │ 边框粗细 | 圆角     ← 成对网格       │ │
│  │ ☐ 危险动作                           │ │
│  ╰────────────────────────────────────╯ │
│  …（每组一张卡；事件/动画是复合卡）…     │
├────────────────────────────────────────┤
│ dock 页签 34px：属性 | 图层 | 图元工具箱 │ 选中项主色 + 2px 下划线
└────────────────────────────────────────┘
```

### 3.2 三种字段行（布局体系，规则只有三条）

| 形态 | 适用字段 | 结构 |
| --- | --- | --- |
| ① 左标签行 | 颜色、下拉、单数值、只读 | 72px 标签（≤5 字）+ 编辑器 + 22px 槽位（ƒx） |
| ② 上标签字段 | 名称、文字、说明 | 标签在上（11px 石板灰），控件全宽，永不截断 |
| ③ 成对网格 | X/Y、宽/高、边框粗细/圆角、字号/字重、偏移/值域 | 一行两列，各列 10.5px 小标签在上 |

布尔行与复合卡不占标签列；规则判断只看「标签长度 + 字段是否成对」，无例外表。

### 3.3 复合卡（事件 / 动画 / 曲线）

- **事件卡**：头部 = 勾选（存在）+ 事件名（12/600）+ 摘要（「N 个动作」/「未完成」）+ 箭头；配置中的卡头是主色柔底。展开区有边界（上分隔线 + 内边距）：执行前确认 → 动作卡列表 → 添加按钮。
- **动作卡**：左侧 2.5px 状态条（完成透明 / 未完成琥珀）+ 序号圆徽 + 类型下拉 + ↑↓✕（18px 图标钮）+ 参数区；未完成原因就地一行（琥珀小字）。
- **动画行**：与事件卡同构；勾选行晨雾蓝底，摘要右对齐（「0~1 → 前景红 · 2 档」/「未选变量」琥珀）；展开区：启用开关 + 变量行 + 范围/档位卡。
- **曲线卡（趋势数据组）**：表头（空/名称/值/空）+ 4 行「颜色点 + 名称输入 + 值输入 + ƒx」；绑定行行下以轻量小字标注（ƒ + 变量名 + ✕，无边框无底色）；卡底脚注说明色点来源。

## 四、样式说明

### 4.1 配色（名称 / 视觉描述，不写编码）

| 名称 | 视觉描述 | 用途 |
| --- | --- | --- |
| 雾白 | 带一点冷调的近白 | 面板底 |
| 纯白 | 无色相的白 | 卡片、弹出层 |
| 浅灰 | 比卡面深半档的中性灰 | filled 输入底 |
| 淡蓝灰 | 极浅、略带蓝的灰 | 卡片描边、发丝分隔 |
| 墨黑 | 近黑的深灰蓝 | 主文字、工具提示底 |
| 石板灰 | 中等偏深的冷灰 | 次级文字、标签 |
| 雾灰 | 浅冷灰 | 占位、单位、弱化说明 |
| 银灰 | 更浅的灰 | 禁用文字 |
| 晴空蓝 | 明快、沉稳的品牌蓝 | 主色：焦点、选中、主按钮、ƒx 激活、链接 |
| 晨雾蓝 | 主色兑大量白的柔底 | 选中行、配置中的卡头、绑定 chip 底 |
| 赤红 | 偏砖红的警示红 | 非法描边/文字、删除悬停、危险动作 |
| 琥珀 | 偏橙的暖黄 | 待完成：未选变量、组头错误点 |
| 苔绿 | 沉稳的绿 | 成功（预留） |
| 深蓝黑 | 近黑的蓝 | 画布上下文（非面板域） |
| 浅晴蓝 | 明亮的天蓝 | 画布内强调与曲线一（图元域） |

规则：面板域只用前 13 个；深蓝黑/浅晴蓝属于画布图元域，不进面板。所有底色差构成三层深度，描边只出现在卡片与弹出层。

### 4.2 字阶 / 尺寸

- 字阶：13（对象名）/ 12.5（组名）/ 12（正文与输入）/ 11.5（左标签）/ 11（上标签、辅助）/ 10.5（计数、单位、脚注）；等宽字体只用于类型键。
- 高度：输入 28（紧凑 24/22）、卡头 38、对象头约 52、dock 页签 34、图标钮 20。
- 间距：卡距 8；卡内字段距 7；卡体水平内边距 11；滚动区左右 10。
- 圆角：卡 10、输入 7、chip/色块 6、对象头图标块 9、弹出层 12。
- 阴影两级：卡片「浮起一层纸」、弹出层「明显悬浮」；其余靠描边与底色差。
- 图标：16px 线性、1.5px 圆头描边、单色继承文字色；搜索/链接/锁/页/图元/趋势/上下移/删除/折叠。
- 动效：120–160ms ease-out；折叠、箭头、开关、弹出淡入；不做位移动画。

### 4.3 状态一览

| 状态 | 表达 |
| --- | --- |
| 焦点 | 输入变白底 + 主色描边 + 主色柔光环（用外层容器换色，行不抖） |
| 悬停 | 输入底加深半档；卡头雾蓝底 |
| 选中/已配置 | 晨雾蓝底（卡头、动画行） |
| 绑定 | 编辑器本体 → 变量 chip（晨雾蓝底·深蓝字·ƒ 记号·✕）；ƒx 实心 |
| 非法 | 赤红描边 + 浅红底 + 行下赤红原因；组头出赤红点 |
| 待完成 | 琥珀左条 + 浅琥珀底 + 琥珀小字；组头琥珀点 |
| 只读 | 浅灰 chip + 等宽字；系统计算的行加锁图标、标签降级 |
| 禁用 | 文字降为银灰，底色不变 |
| 搜索 | 命中卡强制展开；计数「命中/总数」；无结果空态卡 + 清除搜索 |

## 五、代码实现

### 5.1 设计稿实现（已落地）

`design.html`（v2）自包含：内联 SVG symbol 图标集、CSS 变量即配色表、原生 JS 状态机（约 120 行）。

面板 DOM 骨架（一屏看懂结构）：

```html
<div class="panel">
  <header class="ph">…图标块/名称/类型键/锁定开关…</header>
  <div class="tools">
    <div class="sr"><svg/><input data-search-input><button class="clr">✕</button></div>
    <button class="tico" data-fold><svg/><!— 折叠全部/展开全部 —></button>
  </div>
  <div class="scroll">
    <section class="grp" data-total="N">
      <button class="gh"><span class="gname">外观</span><span class="cnt">5</span><i class="chev"></i></button>
      <div class="gb">
        <div class="fr"><span class="lb">填充色</span><div class="ed">…</div><span class="slot">[ƒx]</span></div>
        <div class="fp"><div class="pc"><span class="lb2">边框粗细</span>…</div><div class="pc">…</div></div>
        <div class="brow"><input type="checkbox" class="ck"><span class="bl">危险动作</span></div>
      </div>
    </section>
    <section class="grp">…事件卡：.ev（.ev-h 勾选+摘要+箭头 / .ev-b 动作卡列表）…</section>
  </div>
  <nav class="dtabs">属性 | 图层 | 图元工具箱</nav>
</div>
```

核心状态机（JS 要点）：

- **卡片折叠**：点组头切 `.closed`；「折叠全部」按当前状态整体切换并换图标（fold/unfold）。
- **搜索**：输入即过滤行（`.fr/.fs/.fp/.ev/.an/.series/.brow` 的 `data-search` 文本）；命中卡加 `.search-open` 强制展开、计数变 `命中/总数`；零命中显示 `.pn-empty` 空态卡；清除后恢复。
- **事件/动画**：勾选 `change` → `.is-on`（控制展开区存在与摘要）；点头部（非输入）→ `.is-open`（控制展开）。两个状态源解耦。
- **绑定演示**：点 ƒx → 行切 `.is-bound`，CSS 用「chip 显示 / 输入隐藏」完成替换。
- **取色板**：`data-palette` 开对应 `.pal`，点外部全关。
- **截图模式**：`?shot=<节>&only=<对象>` 只渲染目标卡，供证据图与验收对照。

核心 CSS（节选，完整见文件；注释用颜色名称）：

```css
.panel{width:300px;background:雾白;display:flex;flex-direction:column;}
.scroll{display:flex;flex-direction:column;gap:8px;}
.scroll>*{flex:none;}                    /* 关键：卡片不许被压缩，只能滚动 */
.grp{background:纯白;border:1px solid 淡蓝灰;border-radius:10px;box-shadow:浮起一层纸;}
.in{height:28px;background:浅灰;border:1px solid transparent;border-radius:7px;}
.in:focus{background:#fff;border-color:主色;box-shadow:主色柔光环;}
.fr.is-bound .in{display:none;}  .fr.is-bound .bchip{display:flex;}
.ev.is-on .ev-h{background:晨雾蓝;}      .ev.is-on.is-open .ev-b{display:block;}
```

> 踩坑备注：`.scroll` 是定高 flex 列时，卡片默认 `flex-shrink:1` 会被压扁截断——必须 `flex:none`，让内容溢出交给滚动。
