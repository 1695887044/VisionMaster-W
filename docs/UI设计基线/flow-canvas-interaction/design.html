流程画布 · 交互设计基线 v0.1 草案 · 自绘（C2）交互规格
交互规格（评审用）
滚轮 以光标为中心缩放（0.01×~4×）　中键拖/空格+左键拖 平移
左键 选中　Ctrl+左键 增减选　空白处左键拖 框选
拖节点 移动选中集　拖到另一节点上 改执行顺序（显示插入线）
从右缘圆点拖到左缘圆点 建数据连线（非法落点显示红虚线）
右键 节点 / 连线 / 空白 三套菜单　双击节点 打开步骤参数
Delete 删除选中　Ctrl+A 全选　Esc 取消/取消连线
缩放 < 0.40 不画文字；< 0.15 只画色块（LOD 三档，见左上角读数）
就绪 选中 0 LOD 全细节 绘制 0/0 一帧 0.0 ms Web 设计稿仅作设计媒介，不进入构建、不部署（AGENTS.md R126）
