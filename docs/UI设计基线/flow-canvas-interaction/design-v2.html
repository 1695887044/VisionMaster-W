v0.2 三个改动（针对 v1 的否决理由）
① 单列梯形排列：按执行顺序自上而下，容器用缩进 + 左侧竖线表达层级，分支并列成列—— 不再把整棵树摊成二维，也不再有"节点飘在远处"
② 引用只画正交短线：同一页且相邻（≤6 行）画 H-V-H 折线； 跨页 / 远距离不画长线，改成目标行上的 ← 源名 标签，点标签跳到源所在页
③ 限量显示：一页最多 120 步（可调 40/120/300），只有当前页进入渲染与命中测试； 底部翻页，页码与"共 N 页"常显
