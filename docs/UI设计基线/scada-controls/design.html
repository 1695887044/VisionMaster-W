02

设计原则：双上下文，一套控件

运行态是深色工业画面，编辑态是浅色 Web 工作台。控件规格只有一份，颜色通过令牌切换，不复制两套模板。

状态先于装饰

颜色只表达状态：灰=停、绿=运行、黄=警告、红=故障/报警。装饰色一律用中性面与 accent，不占用语义色。

双上下文

运行画面深色（#0E1318），编辑工作台浅色（#F7F8FA）。控件只换令牌，不换结构、不换尺寸。

一眼读懂

标签 11.5~12px，正文 12.5px，关键读数 20~28px；数字一律等宽 tabular，避免跳动与错位。

五态齐全

交互控件必须有 Normal/Hover/Pressed/Focus/Disabled；过程图元额外有 Selected/Locked/NoData。缺一态视同未完成（R115）。

工业几何

过程符号用 1.5px 线宽、清晰的轮廓与留白；容器 8px 圆角，数据控件 4~6px，过程符号不随意加圆角。

令牌化

颜色、字号、圆角、间距只引用资源键；视图内 0 个十六进制值。新增键只追加，不改既有键语义（R140/R141）。

同一控件，两种画面
左：运行画面（深色） · 右：编辑/浅色画面（浅色）。结构、尺寸、状态完全一致。

遗留与待确认：哪些是纯 UI，哪些要动契约

本版只做设计基线，不改 WPF 代码。下列 D 项按“是否需要新契约”分组，复刻时逐项确认。

D1
画面级主题（深色 / 浅色）

控件默认值目前是“每属性一个固定值”，无法随页面主题切换。需要 ScadaPage.Theme + 控件默认值解析，或页面级令牌注入。

契约扩展影响全部图元
D2
无数据 / 通信断线状态

DeviceState 只有 Stopped/Running/Fault。建议加 Unknown（灰蓝 + 虚线轮廓），由运行态在变量断线/超时时写入。

契约扩展StateVisualElement / 绑定器
D3
表盘警告 / 报警阈值区

设计稿里的黄/红弧段目前没有属性承载。需要 WarningMin/Max、AlarmMin/Max 或复用报警定义。

契约扩展GaugeElement
D4
过程动画（泵叶轮旋转 / 管道流动）

属于视觉增强，需统一节拍源与性能预算；本版先静态，避免每图元一个定时器。

视觉增强可延后
D5
按钮键盘激活

ButtonElement 是 ContentControl，当前只有鼠标事件。要么补 Space/Enter，要么先设 Focusable=False，不要让焦点态成为假象。

行为契约ButtonElement
D6
趋势曲线空态 / LIVE 徽标

SampleCount 已是公开属性，模板可加空态覆盖层；不需要新契约。

纯 UIChartTrendElement
D7
轴控台字号底线

8px/9px 表头与行内按钮统一抬到 10px；点位行高 23→26。只改模板，不改数据。

纯 UIAxisPanelElement
D8
底板标题栏圆角

把写死的 3,3,0,0 改成跟随 CornerRadius 的绑定/裁剪；不改坐标语义。

纯 UIPanelElement
D9
数值域只读 / 可写视觉

只改模板与样式，IsEditable、Mode、编辑/提交/校验逻辑全部不动。

报警条密度与两行行高
