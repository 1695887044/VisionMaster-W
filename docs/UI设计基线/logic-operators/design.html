所有逻辑算子共享一套“节点 + 端口 + 线”的语法，家族色只表达类别，不表达真假。

1家族色条：只标类别，不标真假
2门形 glyph：Path 几何，WPF 可直接画
3输入端口：空心圆，左侧
4输出端口：实心圆，右侧
5表达式：等宽字体，实例名在上
6类型徽标：AND / IF / SR / MUX

家族色不参与真假判断；真假只由端口填充、线型与状态徽标表达，色盲用户仍能分辨。

07

WPF 复刻

每个算子对应的视觉模板、端口与状态实现；全部使用 WPF 原生能力。

节点 = Border + Path + Ellipse

Border 负责圆角/描边/底色，Path 画门形，Ellipse 画端口，TextBlock 画名称/表达式。每个算子一个 DataTemplate，用 DataTemplateSelector 按 Kind 选模板。

画布 = ItemsControl + Canvas

节点用 Canvas.Left/Top 定位；连线用 Path + PathGeometry（正交折线，StrokeLineJoin=Round）；端口吸附由 Thumb/Adorner 完成。

状态 = DataTrigger

真/假/非法/运行/禁用全部走 DataTrigger 或 VisualStateManager：端口填充、描边颜色、虚线、透明度。真值表用 UniformGrid + Ellipse。

家族 算子 端口 WPF 视觉实现 状态 / 交互

只用 WPF 原生效果

圆角 Border.CornerRadius、渐变 LinearGradientBrush、阴影 DropShadowEffect、虚线 StrokeDashArray、透明度 Opacity、端口 Ellipse、门形 Path、真值表 UniformGrid。没有 CSS 滤镜、混合模式、遮罩或 Web 字体。

容器 = Grid + 子 Canvas

IF / Switch / Parallel 用 Border 容器 + Grid 泳道；分支子节点仍是普通节点模板；容器只负责分组、分支标签与输入端口，不改变子节点的渲染。

可访问性与性能

每个端口挂 ToolTip 与 AutomationProperties.Name；节点阴影只在卡片层使用，连线不挂 Effect；大画布用 VirtualizingStackPanel/分层 Canvas 控制数量。
