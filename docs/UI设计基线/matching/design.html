怎么用

① 流程里把本节点的 Image 连到上游；② 打开窗口点「执行」把上游图带进来，或填参考图路径点「载入」；③ 在图上右键 → 新建矩形/圆形/椭圆，框住模板特征；④ 点「创建模板」；⑤ 按需调整提取参数，改完重新点「创建模板」。

分数下限找不到目标先降到 0.3 看看是不是光照变了；误匹配就往上调，或换一块更独特的模板区域。

画框要领：框住目标上稳定、独特、随产品一起动的特征（丝印、边角组合、安装孔位），不要框到反光面或会变的区域。

关键改动（v1）
01
模板库成为左栏第一屏列表 + 新增 / 删除 / 设为默认 + 配方名 + 上游图像 + 参考图路径同区；仍是 Library / EditingEntry 双向绑定。
02
参数按“提取 / 匹配 / 输出”分层提取参数改完需要重新学习；匹配参数运行期立即生效；两组不再混在一起。所有 NumericBox 与校验规则原样保留。
03
参考图升级为工作区保留 ImageEdit 与全部 ROI / 涂抹绑定；空态与错误态是覆盖层，不折叠画布，避免“已设图后恢复不重绘”。
04
模板预览常驻ImageReadOnly.HImage = TemplatePreviewImage 常驻可视树；无预览时用覆盖层显示“创建模板后显示特征预览”，不切 Visibility。
05
状态徽标三态前置未学习 / 已学习 / 参数已改·需重新学习 由 IsTemplateCreated / IsModelStale 驱动；参数改动的橙提醒在列表头与预览条同时可见。
06
颜色全部令牌化颜色映射 Dialog* / PluginPreview* 公共令牌；视图 XAML 零十六进制。共享字典与共享控件不改。
07
五态与可达性hover / pressed / focus / disabled 全量；图标按钮 30×30 且 Padding=0（R68），焦点环走 DialogFocusVisual，ToolTip 走 DialogToolTipStyle。
契约保留（一个都不能改）
C1
DataContext = 插件实例 + IPluginConfigView宿主靠 viewObj.DataContext as IPluginConfigView 取 OnConfirm；不引入独立 VM。
C2
两个 LinkableValueEditorImage（上游图像）与 RecipeName（配方名端口）；Port / StepData 原样保留，只设 Label="" 外置标签。
C3
ImageEdit 全部绑定HImage=DisplayImage、DrawObjectList=CanvasRois、ActiveRoi=CanvasActiveRoi、BrushRadius=BrushSize、SmearDraw/SmearErase/SmearMode 逐字保留；控件常驻。
C4
ImageReadOnly = TemplatePreviewImage模板预览控件类型、HImage 绑定与 HALCON 缩放/右键菜单不变；不折叠已设图控件。
C5
SelectedItem / 类型Library + EditingEntry（对象）、DisplayViewIndex（int 0~9）、SmearModeIndex / PolarityIndex（int）全部保留。
C6
命令与状态三档新增 / 删除 / 设为默认 / 载入 / 创建模板 / 清除 / 清除涂抹；StatusMessage + StatusLevel（Info / Warning / Error）原样消费。
明确延后（需新增功能或契约）
D1
加载骨架 / 蓝色加载态需要 VM 新增 IsPreviewLoading 或 PreviewState；当前 StatusLevel 只有三档。
D2
尺寸 / 文件大小需要 VM 新增只读属性；本稿预览头只显示模式与状态。
D3
放大 / 缩小HalconBase 只有 FitToWindow() / FitToImage()，没有公开 zoom 方法。
D4
打开所在文件夹需要新增 Process.Start("explorer.exe", ...) 行为。
D5
模板库导入 / 导出 / 批量复制需要新的持久化/命令契约，本版不做。
D6
撤销 / 重做画布 ROI 与参数目前没有撤销栈；不在本轮 UI 改造范围。
