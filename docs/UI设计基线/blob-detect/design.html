1 二值化 分割方式

上下限填反了会按区间自动排序，不会报错。

自动求分割点（最大类间方差法），适合来料灰度整体漂移、不方便固定阈值的场合，无需额外参数。

窗口要略大于缺陷宽度；标准差权重越大越严格，检出的越少。

固定阈值下由灰度区间决定极性，检测目标与亮暗同检自动隐藏。

2 特征筛选 噪点 / 形状 / 触边

筛选掉的不计数也不判定；判定规格在下方第 4 区，两者是两回事。面积单位是像素。

3 形态学 去毛刺 / 连断桥

开/闭运算填 0 表示跳过该步（默认两步都跳过）。合并半径把间距小于 2 倍半径的几段连成一个缺陷。

4 判定规格 OK / NG

判定：个数超出上/下限、单个面积或总面积超出上限，任一命中即 NG。填 0 = 不启用该项。

5 输出 发布 / 单位 / 排序

接「标定」插件的 MmPerPixel 输出时，运行时以标定值为准；判定仍按像素做。

数组端口与 Defects 端口按同一顺序逐项对齐，下游按同一索引取即可对上号。

关键改动（V1）
01
左栏五区 + 图像输入，固定顺序图像输入 → ① 二值化 → ② 特征筛选 → ③ 形态学 → ④ 判定规格 → ⑤ 输出；19 个数值字段按 2 列紧凑排布，标签在上、控件在下。
02
参数控件统一 32px数值框、下拉、按钮统一 32px（Web 36px，WPF 为 640×560 最小档压缩 4px）；数值等宽、校验规则与上下限原样保留。
03
二值化方式驱动分区显隐固定阈值只显示上下限；自动阈值只显示说明；动态阈值显示 4 个局部参数；检测目标与亮暗同检按 ShowDetectTarget / ShowDualPolarity 显隐。
04
预览升级为工作区预览头（标题 + 缺陷计数 + 适应窗口 / 1:1）+ 页签条（图像视图 / 数据输出）+ 深色画布 + 状态栏；只接现有 FitToWindow() / FitToImage()。
05
两块画布都保留ImageReadOnly.HImage = PreviewImage 常驻，不用 Collapsed 显隐；HistogramPlot 的 Data / ShowThresholdMarkers / ThresholdLow / ThresholdHigh 绑定原样。
06
数据输出不抢图像高度缺陷清单与直方图放在「数据输出」页签；点清单行仍触发 DefectList_SelectionChanged → 高亮并自动切回图像视图。
07
状态栏三档StatusMessage + StatusLevel（Info / Warning / Error）；不新增第四档，空串显示「就绪」。
08
颜色全部令牌化映射 Dialog* / Plugin* 公共令牌；视图 XAML 内 0 个十六进制颜色，不改共享字典与共享控件。

C6
19 个 NumericBox每个 Value 绑定、Minimum/Maximum/DecimalPlaces 与 NumberValidationRule 逐项保留，不换控件类型。
C7
