关键改动（v1）
01
三栏工作流保留，层级重排左「输入端口」、中「数据来源」、右「绑定设置」；列头带步骤号与数量徽标，顶部上下文条常驻当前步骤与绑定进度。
02
输入端口列表升级搜索 + 全部 / 未绑定 / 已绑定筛选；行内显示类型标签、绑定状态与地址；已绑定行带绿色勾，未绑定一眼可辨。
03
数据来源分组与筛选全局变量 / 运行时变量 / 上游算子分组；搜索 + 全部 / 变量 / 上游算子页签；每项显示输出端口数量。仍绑 TreeNodes / SelectedNode。
04
绑定设置英雄区目标端口 → 数据来源的连线预览；已绑定 / 常量 / 功能预设三种状态一眼可辨；提供「清除绑定」，走既有 UnbindCommand。
05
绑定方式显式二选一上游端口 / 常量值；常量输入带目标类型提示与「会替换当前上游连线」警示，避免「填了常量把线悄悄拆了」。
06
候选端口列表类型标签、已绑定标记、类型不兼容置灰 + 原因；支持搜索与「显示全部」；单击选中、双击直接绑定，仍走 DoublockClickBindCommand。
07
功能预设独立成组枚举端口不再出现常量框；选项卡片显示中文名 + 写入值（值与显示分离，写入仍是成员名），复用 PresetOptions / SelectPresetCommand。
08
空态 / 单绑 / 数组索引中栏空态与右栏空态分开；单绑定模式收敛为单目标端口；数组→标量用行内索引面板，不再弹二级对话框（VM 需小幅交互编排扩展）。
09
底部状态条与可达性左侧显示当前选择与绑定结果，右侧键盘提示 + 主次按钮；全令牌化、图标按钮 30×30 + Padding=0（R68）、焦点走 DialogFocusVisual。

契约保留（一个都不能改）
C1
DataContext = VariableBindingViewModelPrism AutoWireViewModel 与宿主 RegisterDialog 的绑定不变；不引入独立 VM。
C2
VM 属性DisplayDataPort / SelectedInputPort / TreeNodes / SelectedNode / DisplayPorts / SelectedOutputPort / ShowAllPorts / ConstantValue / HasFunctionalEnumPort / PresetOptions 全部保留。
C3
命令入口ConfirmCommand / CancelCommand / DoublockClickBindCommand / SelectPresetCommand / UnbindCommand 全部保留；「清除绑定」只是把既有 UnbindCommand 接到界面上。
C4
类型判据唯一TypeHelper.CanBindTo 是列表过滤与双击校验的唯一尺子；IsBindable / IncompatibleReason 语义不变。
C5
bindKey 口径ConditionStep / WaitStep 用端口 Description（变量 Guid），其余用端口 Name；ResolveBindKey 三处一致。
C6
连线协议LinkReference.Kind、TargetVariableId、数组下标写进 TargetPortName 的约定不变；不靠显示串反推类型。
C7
单绑定模式不直写目标步骤的 LinkedSources；只通过 BoundLink 回传，选定后自动确认。条件节点不会被写入中文描述垃圾键。
C8
窗口行为无边框自绘标题栏 + WindowDragBehavior；可缩放、最小 1000 × 640；SizeToContent=Manual 保留。
v1 明确延后（需新增功能或契约）
D1
多选批量绑定需要 VM 新增选中集合与批量命令；本批保持单端口逐个绑定。
D2
来源树内联展开当前保持「选来源 → 选输出端口」两级；把端口直接展开进来源树需要新的树形模板与 VM 结构。
D3
变量当前值预览候选行显示变量当前值需要运行时读值契约；本批只显示类型与描述。
D4
最近使用 / 绑定历史需要持久化与排序策略；本批不新增状态。
D5
从画布拖拽连线到弹窗跨窗口拖放需要新的交互契约；本批保留弹窗内选择。
