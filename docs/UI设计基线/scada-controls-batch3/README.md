## 三、R111 六项（设计基线必填）

### 1. 布局

- 每个控件一节，统一 **左演示 / 右口径** 两栏；演示区固定深色运行态，口径区给规则、属性、状态矩阵。
- 演示区内的控件按真实运行画面排布：属性卡、按钮行、状态条自下而上，不为了展示而打散层级。
- 组合屏按 1280×720 设计，容器等比缩放；顶栏 / 工艺图 / 趋势 / 计数 / 历史五区不互相抢主视觉。
- 运行画面信息层级：**状态 → 数值 → 操作 → 追溯**。历史表永远在底部或抽屉，不压主工艺图。

### 2. 间距

- 间距刻度 **4 / 8 / 12 / 16 / 24 / 32**；卡片内边距 10~14，卡片间距 10~12，区块间距 24。
- 控件高度 **32 / 36 / 44** 三档；触摸部署的按钮与滑块拇指命中 ≥44。
- 表格行高 33（与既有 DataGrid 一致）；状态条与控件间距 12。
- 线/箭头的端点手柄 7px 半径，视觉直径 14（命中容差 14px，与 R52 同口径）。

### 3. 配色令牌

沿用 `Scada.Controls\Themes\ScadaTokens.xaml` 的 20 个 `Hmi*` 令牌，本批**只新增 4 个**：

| 新令牌 | 值 | 用途 |
| --- | --- | --- |
| 禁用遮罩 | `rgba(14,19,24,.58)` | 启用对象动画的禁用态；固定遮罩，不做透明度动画 |
| 编码表面 | `#FFFFFF` | 二维码/条码底；唯一允许的纯白底，不随主题反色 |
| 编码墨色 | `#0F172A` | 二维码/条码模块与条 |
| 声音强调 | `#F59E0B` | 报警喇叭、静音倒计时 |

状态色只表达状态：灰停、绿运行、黄警告、红故障；accent 青蓝只做交互/焦点/当前项。历史与实时的区别靠**查询条 + 时间范围 + LIVE 徽标**，不靠换色。

### 4. 字号字重

七档不变：**10 / 11.5 / 12.5 / 14 / 16 / 20 / 28**。

| 场景 | 字号 / 字重 |
| --- | --- |
| 大数值（运行时长、产量、速度） | 28 / 600，等宽 |
| 中数值（节拍、卡内数值） | 20 / 600，等宽 |
| 控件正文、标签 | 14 / 400~600 |
| 表格正文 | 12 / 400，等宽列用 tabular-nums |
| 辅助说明、状态角标 | 11.5 / 400 |
| 表格表头、单位 | 10.5 / 700，字距 .04em |

所有数字（时间、计数、尺寸、坐标）一律 `tabular-nums`；小数点按列对齐。

### 5. 五态

每个交互控件必须齐 **Normal / Hover / Pressed / Focus / Disabled**；过程控件再加 **Current / Dragging / Loading**。

| 控件 | 额外状态 |
| --- | --- |
| 页面背景 | 未设置（背景色）/ 已设置 / 文件缺失 / 基座继承 / 弹窗页 |
| Hmi.Picture | 未加载 / 已加载 / 文件缺失 / 多选禁用 / 运行态无操作 |
| Hmi.Line | Normal / Hover / Selected（2px accent + 手柄）/ Locked（金色）/ Disabled |
| 增量减量按钮 | 按下 / 长按重复 / 写入中 / 写失败回弹 / 越限 / 无权限 |
| DataGrid 历史源 | Loading（骨架行）/ Empty / Unavailable / Rows / 选中行 |
| QRCode / Barcode | 正常 / 空值 / 超长拒绝 / 绑定丢失（末值 + 橙点） |
| 启用对象 | 启用 / 禁用·联锁 / 禁用·权限 / 禁用·无数据 / 隐藏 |

### 6. 交互细节

- **页面背景**：归属于页面，铺满、压底、不参与框选/复制/命中；默认「适应」不裁切，留边用背景色；基座背景可继承，页面自己设了就覆盖、不叠加；缺失时回退背景色，运行态不弹窗。
- **内容图片**：`Hmi.Picture` 默认 200×160，可拖动、参与布局与命中；用于 logo、产品图、操作指引。
- **线**：端点拖到图元边缘 10px 内吸附；锁定后手柄消失、颜色转金；线宽 <6 时按 6px 容差命中。
- **增量**：首次 300ms 后开始重复，间隔 80ms；松开/移出/失焦立即停；越限夹紧并提示；失败回弹。
- **历史**：查询 1.2s 骨架行；Empty 给改范围建议；Unavailable 保留上次结果 + 重试；翻页 8 条/页（设计稿），实现默认 50。
- **编码**：超长拒绝并保留上次有效图形；绑定丢失保留末值 + 橙点；不反色、不圆角。
- **启用对象**：禁用是交互闸门（点击/键盘/拖拽全不响应），右上角原因角标，悬停整句原因。
- **对象事件**：只发用户操作，不发程序灌值；同一控件 100ms 内合并；动作失败不改行状态。
- **多曲线**：游标吸附最近采样点；缺采样画断口；暂停冻结视图不补历史。
- **声音**：默认关；静音 5 分钟自动恢复；紧急级不可静音；确认最后一条即停。
- **运行计时**：运行信号为假时暂停；1 分钟粒度落盘；复位需 Engineer + 二次确认 + 审计。

### 方案文件夹与资源（2026-10-23 补，用户口径）

- **方案 = 一个文件夹**：`<方案名>\<方案名>.vms` + `Image\` + `Alarms\`；现有 `SolutionAssetFolders` 已按这个约定实现，本批不改结构。
- **图片拖入即复制进 `Image\`**：`.vms` 只记相对路径（如 `Image\pid-layout.png`），绝不写绝对路径、绝不引用方案目录之外的文件。
- **查重与命名**：同名同内容（哈希相同）复用已有文件；同名不同内容重命名为 `name (2).ext`，不覆盖。
- **另存为带走资产**：`SolutionAssetFolders.CopyAlongside` 已实现；目标目录已有同名文件不覆盖，失败只提示、不回滚保存。
- **孤儿文件**：删除图元/换图不自动删文件（避免误删别的页面还在引用的图）；后续可做「清理未引用资源」。
- **迁移/备份 = 复制整个文件夹**：不做软件级全局图片库；多方案复用走「另存为 + 替换」，不引入共享引用。

## 七、边界与已知偏差

### 本批不做

- **页面背景不做成图元**：否则会进框选/复制/图层排序，锁图层也挡不住全选；它必须是页面属性。
- **不做软件级全局图片库**：方案文件夹自带 `Image\`，多方案复用走「另存为 + 替换」，不引入共享引用。
- **配方**：单独一批。
- 报表、PDF/浏览器/数据库视图、文件浏览、I/O 监视：属宿主能力。
- 多语言 / 状态列表：横切能力，等出口需求明确。
- 多边形 / 贝塞尔 / 动态画线：场景窄。
- 圆形进度条 / 旋钮 / 跑马灯 / XY / 3D 饼图 / GIF：P2/P3。
- 正交自动路由：线只做手拖折线。

### 设计稿的诚实边界

- **二维码与条形码是示意矩阵**（按内容哈希生成 + 定位图案），**不可扫描**；实现阶段接 ZXing，按纠错等级/静区/最小模块输出。演示的是绑定、状态与排版，不是编码算法。
- 图片样例是内联 SVG（Logo/产品/底图），不是真实方案资产；实现后走 `Image\` 目录。
- 声音用 WebAudio 合成，仅用于评审；WPF 走 `SoundPlayer`/NAudio，音型一致。
- 历史数据、事件日志、趋势采样都是页面内模拟数据，不代表真实数据源性能。

### 平台差异（写进复刻清单）

| 项 | 差异 |
| --- | --- |
| Web 运行态 | 6 个新 TypeKey 都要补渲染器；历史查询/声音/本地图片按镜像处理 |
| 声音 | 浏览器自动播放限制，Web 默认静音，需用户手势 |
| 二维码 | 两端共用宿主编码结果，不让浏览器自己编码 |
| 本地图片 | Web 由宿主下发已栅格化位图，不暴露路径 |
| 触摸 | 增量长按需 `CaptureMouse/CaptureTouch`，滑出即停 |
| DPI | 线宽/箭头按 DIP；二维码最小模块按物理尺寸校验 |

| Q5 | 运行计时落盘粒度？ | 1 分钟，掉电丢失 ≤1 分钟 | 精度 vs 写盘频率 |
| Q6 | 对象事件是否含程序灌值？ | 不含，只认用户操作 | 影响操作记录真实性 |
| Q7 | MultiTrend 默认独立量程？ | 是，混单位是常态 | 共享量程需同单位 |
| Q8 | 增量动作是否允许字符串变量？ | 不允许，配置期拒绝 | 避免静默错写 |
| Q9 | 页面背景默认填充方式？ | 适应（不裁切），留边用背景色 | 工程图被裁掉一块是功能错误 |
| Q10 | 页面背景与基座背景叠加还是覆盖？ | 覆盖，不叠加 | 两张整页背景叠起来从来不是意图 |
| Q11 | 资源目录名固定 `Image` 还是可配？ | 固定 `Image`（已有约定） | 可配会让迁移与备份多一层解释成本 |
| Q12 | 同名不同内容覆盖还是重命名？ | 重命名 `name (2).ext`，不覆盖 | 覆盖会悄悄改掉别的页面正在用的图 |
| Q13 | 是否允许 `Image\` 下建子目录？ | v1 扁平；按页面分组后置 | 子目录会让引用路径与清理逻辑复杂一档 |
| Q14 | 删除引用后自动删文件吗？ | 不自动；后续做「清理未引用资源」 | 自动删会误删多页共用的图 |
