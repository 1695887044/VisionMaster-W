关键改动（v1）
01
行高统一到 36px 现状同一张表里开关 24px、文本框 32px、数值框 44px（NumericBox 的 MinHeight=32 又叠了 Padding=10,6）。v1 把三类控件统一为 36px 高、8px 圆角、单行 48px 节奏。
02
颜色全部走令牌 生成器里写死的 #DCDFE6 / #606266 / #409EFF / #F5F7FA 换成 Dialog*Brush；扁平外框的 229,229,229 换成 DialogBorderBrush。改主题只改令牌。
03
校验从"仅 TextBox"扩到全控件 现状 ValidationProcessor 只对 TextBox 生效、且只在 LostFocus 触发。v1 把错误态定义成行级（红底 + 红描边 + 行内错误文案），数值框 / 下拉 / 开关同样可承载。
04
嵌套对象改为内联块，不再长出第二层页签 现状 NestedPropertyGridGenerator 直接 new 一个完整的 CardPropertyGrid，子网格自带 TabControl。v1 用左侧强调条 + 浅底的内联块表达层级，块头标注实际类型名。
05
只读与权限不足分开表达 只读 = 虚线边框 + 浅底（"看得见但改不了"）；权限不足 = 禁用 + 锁图标 + 一行原因说明。现状两者都只是变灰加一把红色 emoji 锁。
06
扁平式标签列留白对齐 现状标签侧 Padding 16,12,32,12、控件侧 16,8,16,8，上下差 4px 导致行节奏不稳。v1 两侧同为 10px / 14px 竖向对齐。
07
底部状态条 左侧胶囊显示分组数与校验结论，右侧是取消 / 确定。校验未通过时胶囊转红，状态从"13 个可见属性"变成"1 个字段校验未通过"。
08
卡片式左栏替代灰底页签条 现状左栏 128px 灰底、选中项只有一条 3px 竖线。v1 是 176px 浅底导航：图标 + 组名 + 条目计数，选中项变白底卡片 + 左侧强调条。
契约保留（一个都不能改）
C1
BindingObject + INotifyPropertyChanged 数据源仍是任意 POCO / BindableBase；订阅、跨线程封送、换绑时解绑旧监听的行为不变。
C2
[SuperDisplay] 可见性契约 只渲染带该特性且 Visible == true 的公开实例属性；没有特性的属性一律不显示。
C3
生成器 Priority 命中顺序 Nested(10) / Numeric(110) / ComboSource(105) / Enum·Option·Struct·Bool(100) / Type(0) 的降序命中与回退不变。
C4
RequireRefresh = 整表重建 保持 UpdatePropertyGrid(preserveSelectedTab: true)，不做"只重建触发者所在页签"的优化——多态字段与它驱动的子对象常不在同一页签。
C5
分组与排序规则 Group 优先于 GroupPath；GroupOrder 按数值比较（"10" 排在 "2" 后）；组内按 Order。
C6
页签懒加载 + 事件按实例挂 只建页签头、选中才构建内容；SelectionChanged 记实例而非布尔标志，模板被换过时能重新挂上。
明确延后（需新增契约）
D1
分组内错误汇总 需要在页签头上显示"该组有 N 个错误"。当前处理器管线是逐属性执行，没有跨属性的汇总状态。
D2
脏值与回滚 属性面板是即时写属性，点"取消"不回滚。要支持"待应用 / 撤销"需要在 BindingObject 之外引入草稿层。
D3
字段级搜索与重置 需要按 Name / Description 建索引，以及"重置为默认值"的元数据来源。
D4
跨页签联动高亮 RequireRefresh 已能整表重建，但"定位到被驱动的那个字段"需要新的聚焦契约。
