关键改动（v1）
01
结果项成为主工作区左栏只放配置，右侧整块用于结果项列表；每项一张卡，增删、启停、改名与行内连线同屏完成。
02
表单节奏统一标签 12px / 控件 36px / 帮助 11.5px；底图与结果项行仍由 LinkableValueEditor 承载，Port / StepData 原样。
03
判定与文字位置分组显示窗口、判定项、NG 值、图上叠字集中；九宫格改为 3×3 可点按钮，仍写 TextAnchor 枚举。
04
边界值就地解释显示窗口 0 / 边距 0 / 字号 1.0 / 绘制上限 10~2000 都在字段下方写明后果，不让用户靠试。
05
空态与停用态结果项为 0 时给虚线空态与添加入口；停用项保留配置、整行降透明度，仍可编辑名称与取值。
06
全令牌化颜色映射 Colors.xaml / PluginConfigColors.xaml；只在本视图派生样式，不改共享字典与共享控件。
07
五态与可达性hover / pressed / focus / disabled 全量；图标按钮 30×30 且 Padding=0（R68），焦点环 DialogFocusVisual，ToolTip DialogToolTipStyle。
