## 五、已知偏差与边界

| 项 | 说明 |
| --- | --- |
| 选中光晕 | 真机是 Nodify `ItemContainer` 的 `SelectedBrush`（`FlowCanvasNodeSelectedGlowBrush`）+ 模板 2px 描边；本页用等效的 `box-shadow` 近似 |
| 运行脉冲 | 状态点在 Running 时有 0.8s 往复透明度动画，本页静态呈现 |
| 字体度量 | 本页用浏览器渲染，与 WPF `TextBlock` 的字符间距可能有 1px 内差异 |
| 悬停态 | 连接点悬停依赖节点 `IsMouseOver`，本页用"连接点·悬停"变体静态呈现 |

## 九、连接点：不显示（2026-10-24 用户决定）

**视觉上一个像素都不画**。真机模板只保留 12×12 的**透明命中区**，拖线手势照旧可用。

| 落点 | 改动 |
| --- | --- |
| `FlowCanvasView.xaml` 的 `FlowConnectorStyle` | 四条显隐触发器（悬停浮现 / 已连线常显 / 拖线显形 / 拖线压灰）全部停用并留注释；控件本身仍存在、仍可命中 |
| `design.html` | 连接点样式改为 `display:none`；状态矩阵里两格「连接点·悬停 / 已连」换成「无连接点（当前）」 |
| `design-containers.html` | 容器页本来就没画连接点，规格表同步标注「不显示」 |

**副作用（需要知道）**：画布上不再有任何「可以拖线」的视觉提示。建立数据引线的入口只剩两条：
右键节点 →「编辑绑定…」，或按住卡片左/右缘的透明命中区拖到目标。
如果发现用户找不到拖线入口，只需恢复「拖线手势中显形」这一条触发器（其余三条保持停用）。
