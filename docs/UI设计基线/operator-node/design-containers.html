② 与 design.html（叶子算子卡）配套使用：两者合起来才是画布的完整视觉基准。
③ 打开方式：在仓库根 python -m http.server 8770，访问 /docs/UI设计基线/operator-node/design-containers.html（图标字体走相对路径）。
