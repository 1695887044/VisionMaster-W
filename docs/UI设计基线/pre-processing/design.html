关键改动（V1）
01
三栏工作区替代“左库 / 中图 / 右链”老布局左 280px 输入与算子库、中间预览工作区、右侧处理链 + 参数；间距与卡片节奏统一到 ImageAcquisition V2 的 12/16px 体系。
02
预览升级为工作区预览头 + 目标分段（原图 / 输入图 / 算子输出）+ 工具条（适应窗口 / 1:1 / 刷新 / 导出）+ 状态栏；全部接现有方法或命令。
03
处理链行信息重排步号 + 启用勾选 + 算子名 + 参数摘要；选中行用主色浅底，停用行整行淡化，与 IsMuted 触发器一致。
04
参数面板保留反射生成仍由 FlatPropertyGrid / CardPropertyGrid 绑定 SelectedOperator；视图只改容器、标题与空态，不改共享控件内部。
05
算子库分组更紧凑组标题 + 可点击行，悬停用主色浅底；点击仍走 AddOperatorCommand，参数是 OperatorDescriptor。
06
加载警告与操作反馈前置LoadWarning 显示为琥珀色横幅；ActionHint 落在预览状态栏，空串显示“参数改动会自动重算预览”。
07
颜色全部令牌化映射 Colors.xaml 的 Dialog* 与 PluginConfigColors.xaml 的 PluginPreview*；视图 XAML 十六进制颜色 = 0。
08
五态与键盘可达hover / pressed / focus / disabled 全量；图标按钮 30×30 且 Padding=0（R68），焦点环走 DialogFocusVisual，ToolTip 走 DialogToolTipStyle。
契约保留（一个都不能改）
C1
DataContext = 插件实例 + IPluginConfigView宿主靠 viewObj.DataContext as IPluginConfigView 取 OnConfirm；不引入独立 VM，否则确认不保存。
C2
LinkableValueEditor 只包裹不替换Port=SrcImage、StepData=StepData 原样；标签外置（Label=""），控件内部链接 / 解除链接逻辑不动。
C3
ImageEdit 常驻HImage=DisplayImage、DrawObjectList=CanvasRois、ActiveRoi=CanvasActiveRoi 逐字保留；不用 Visibility=Collapsed 显隐已设图的画布。
C4
SelectedOperator / DisplayViewIndexListBox.SelectedItem=SelectedOperator（对象）、ComboBox.SelectedIndex=DisplayViewIndex（int 0~9）；类型不能换。
C5
全部命令与三档状态语义Add/Remove/MoveUp/MoveDown/Clear/Refresh/Copy/Paste/Export/DeleteBox 原样；本插件无 StatusLevel，状态由 LoadWarning + ActionHint 表达，不新增第四档。
明确延后（需新增功能或契约）
D1
加载骨架 / 蓝色加载态需要 VM 新增 IsPreviewLoading 或 PreviewState；本版只用现有状态字段。
D2
图像尺寸 / 文件大小需要 VM 新增只读属性；本版预览头只显示“预处理预览”与当前预览目标。
D3
放大 / 缩小按钮HalconBase 只有 FitToWindow() / FitToImage()，没有公开 zoom 方法；本版不做。
D4
打开所在文件夹 / 系统导航需要新增 Process.Start 或宿主导航契约；本版不做，也不造死按钮。
