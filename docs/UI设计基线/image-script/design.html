* 第1步 彩色转灰度：机器视觉大多在灰度图上做，数据量小一半
count_channels (Image, Channels)
if (Channels >= 3)
rgb1_to_gray (Image, GrayImage)
else
copy_image (Image, GrayImage)
endif
 
* 第2步 阈值分割：亮于 ThreshMin 的像素连成候选区域
threshold (GrayImage, Region, ThreshMin, 255)
 
* 第3步 拆分与筛选：粘连的拆成一个个，再按面积甩掉噪点
connection (Region, ConnectedRegions)
select_shape (ConnectedRegions, Targets, 'area', 'and', MinArea, 1e7)
count_obj (Targets, Number)
 
* 第4步 判定：数出个数就能判 OK/NG
if (Number > 0)
Result := 'NG'
else
Result := 'OK'
endif

01
两栏固定分工左 356px 配置轨（过程 + 变量表），右侧脚本工作区自适应；不再让 380px 左栏和编辑器互相抢宽。
02
过程管理卡片化编辑目标 / 运行过程两个下拉 + 六个动作按钮；仍是原来的 EditProcCombo / RunProcCombo 与 Click 处理器。
03
变量行卡片化每个变量一张小卡：变量名 + 类型下拉 + 连线/固定值；类型下拉仍写 ScriptVarDef.Type，端口经 PortsVersion 锚点重建。
