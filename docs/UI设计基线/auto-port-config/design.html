设计要点（V1）
01
Step 信息前置，不再只有标题 标题下新增只读步骤卡：步骤名、面板来源、输入 / 必填 / 已链接三个统计。数据全部来自 IStepConfigData 与端口集合，不新增业务字段。
02
一行一个端口的扫描节奏 左侧「中文描述 + 端口键 + 类型徽章」，右侧固定 190px 控件，链接 / 清除固定在行尾。10 个端口一屏可扫，不靠横向滚动。
03
三种端口形态一眼分清 可填常量 = 输入框；不可文本输入 = 「需链接变量」虚线按钮；枚举 = 下拉 + 锁图标（封闭候选，只能选、不提供链接）。
04
已链接状态是“地址”，不是“值” 链接后显示只读地址条（如 图像采集_0.Image），颜色与链接按钮同步变为主色；解除后恢复固定值输入，语义与 LinkableValueEditor 一致。
05
空态给下一步，不给白板 没有端口时显示图标 + 原因 + 提示（确认 / 取消 / 执行仍可用），并指出 [StepConfig] 不会出现在本面板，避免用户误以为界面坏了。
06
状态只复用宿主三档 执行中 / 成功 / 失败全部由 PluginConfigShellViewModel.StatusText 驱动，不新增 StatusLevel 枚举；执行中禁用「执行」，避免重复点。
契约保留（一个都不能改）
C1 生命周期 AutoPortConfigView 仍实现 IPluginConfigView；Initialize(stepData) 幂等重建，OnConfirm 委托 _plugin.OnConfirm。
C2 端口来源 仍从 _plugin.Inputs.Values 取实时端口，按 Name 排序；不使用 PortDefinition 快照。
C3 唯一编辑入口 LinkableValueEditor 仍是每行唯一编辑控件；Port / StepData / 链接与清除行为原样保留。
C4 窗口策略 仍由视图自己设置 Width=560、SizeToContent.Height、MinHeight=180、MaxHeight=760；仅内容滚动上限 420→600。
C5 外壳不动 PluginConfigShellView 的头部 / 页脚 / 执行 / 取消 / 确认与状态文案全部复用，不在本视图内复制。
明确延后（需要新增功能或契约）
D1 · [StepConfig] 编辑入口 当前兜底面板只渲染 InputPort。要显示「轴回零 / 轴停止」等插件的 [StepConfig] 属性，需宿主暴露反射属性表与统一写路径。
D2 · 布尔开关 / 枚举卡片 布尔端口当前由 LinkableValueEditor 的文本框承载（显示 true）。改成开关需要扩展共享控件，本版不做。
D3 · 搜索 / 分组 / 校验 端口没有分组元数据；搜索、按必填筛选、行内校验提示都需要新契约或 VM 状态，本版保持单列直出。
D4 · 输出端口只读区 配置窗口只负责输入；输出端口属于流程连线与运行结果，不在本面板展示。
D5 · 参数说明 Tooltip 端口 Description 已是人话标签；更长的帮助文本没有数据来源，需插件侧补元数据。
D6 · 宽窄双档 设计稿提供 560 / 640 两档预览；产品仍固定 560，640 只用于说明窄窗口拉伸时的布局行为。
