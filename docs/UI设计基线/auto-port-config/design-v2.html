设计要点（v2 → v2.1 的增量）
01
两段的层级靠「轨道颜色 + 段徽章 + 行尾图标」三重区分 输入参数段：顶边浅主色轨 + 段徽章「🔗 可连线」；插件参数段：左侧中性竖条 + 段徽章「🏷 仅本步骤」。 行尾也一致：可连线行给 🔗，纯常量行给 🏷。用户不用读标签，看图标就能判断「这行改完流程别处会不会变」。
02
名字类端口在「可连线」段里也不给 🔗（R33） 轴名 / 卡地址是「名字」不是「值」，挂绑定 = 允许上游把一个值当名字送进来。段徽章说的是「这一段可以连线」， 行尾锁图标说的是「这一行不行」——两者不矛盾，锁的 tooltip 直接写原因。
03
分级提示三级，位置统一在编辑框正下方 info（灰/主色 ℹ，说明性：如数字解析失败）、warn（橙 ⚠，可继续操作但要注意：两个空候选态）、 error（红 ⛔，挡住确认：超范围/非法值）。颜色只是提示级别，错误态才是唯一会染框的。
04
「同一个控件两态」必须画出来（场景 2 / 3 / 4） 空候选时是「可手填输入框 + 提示」，候选回来时同一个位置变成下拉、提示消失，不是换了一个控件。 设计中明确写「不新增控件类」：IsHandFillFallback 与 IsOptionPort 互斥即可。
05
只读项「不假装能编辑」 集合 / 自定义配置类等无编辑形态的 [StepConfig]：虚线只读框显示当前值摘要，下方灰字「该类型暂不支持在此编辑」， 行尾无动作。绝不把它画成灰掉的正常输入框——灰掉的框会让用户反复点。
06
加载 / 空 / 错误三态都有明确视觉（R116） 加载：段内含一行主色浅底说明 + 两条骨架行（1.1s shimmer，骨架动效不受 150~200ms 限制，因为它表达「持续进行」）； 空：虚线卡片 + 图标 + 原因 + 下一步；错误：行内红色 ⛔ + 外圈红描边 + 页脚状态胶囊转红。
