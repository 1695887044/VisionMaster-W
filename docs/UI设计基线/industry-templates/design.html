A顶栏：产线名、运行模式、节拍、批次、报警、操作员、时钟。一眼回答“这条线现在正不正常、谁在操作”。
B左导航：总览 / 工艺流程图 / 趋势 / 报警 / 配方 / 报表 / 设置；底部固定连接状态。
C主工作区：上半是工艺流程图（罐、泵、阀、管道、灌装机、关键测点），下半是 60 秒关键趋势。设备状态直接落在流程图上，不做第二套。
D右信息栏：实时报警 → 生产 KPI → 设备状态 → 当前批次，固定从上到下的处置顺序。
E底栏：PLC 连接、采集周期、节拍、方案与版本；不放操作按钮。

信息层级

  1. L1 是否正常：顶栏运行状态 + 未确认报警数；异常时先看到红色。
  2. L2 哪里异常：工艺流程图上的设备状态与关键测点（液位/流量/压力/温度）。
  3. L3 趋势与指标：关键趋势 + 右栏 KPI，判断是瞬时波动还是持续偏离。
  4. L4 处置：报警列表逐条确认、批次进度、配方入口。

A顶栏：单元名、自动/手动、节拍、当前步、报警、操作员、时钟。当前步直接上顶栏，操作员不用先找流程卡。
B左导航：总览 / 手动操作 / 自动流程 / 点位管理 / 报警 / 参数 / 维护；底部固定总线状态。
C主工作区：三轴状态卡（位置/速度/负载/8 状态灯/操作按钮）→ 自动流程步序 → I/O 联锁。按“先看能不能动、再看在哪一步、最后看许可条件”的顺序排。
D右信息栏：生产 KPI → 报警 → 点位表 → 维护提醒；点位表只显示摘要，详细编辑进“点位管理”。
E底栏：总线、循环时间、轴使能数、方案与版本。

信息层级

  1. L1 能不能动：使能 / 急停 / 限位 / 报警；异常时轴卡与顶栏同时变红。
  2. L2 现在在哪一步：自动流程步序 + 当前步耗时 + 预计完成。
  3. L3 轴在哪、怎么动：三轴位置/速度/负载 + 手动操作按钮。
  4. L4 为什么不能启动：I/O 与联锁矩阵；绿=满足、红=不满足、灰=旁路。

A顶栏：工位名、相机、触发模式、帧率、模型版本、报警、操作员、时钟。模型版本必须上顶栏，换型后一眼能确认。
B左导航：实时检测 / 图像回放 / 配方管理 / 统计 / 报警 / 标定 / 设置；底部固定相机状态。
C主工作区：大图 + 检测结果（左图右果）→ 最近检测明细 → 班次统计 + 通过率趋势。图像上直接标 OK/NG 框与缺陷标签。
D右信息栏：当前配方（含标准样图缩略图）→ 相机与光源 → 报警 → 触发与编码器。
E底栏：相机连接、帧率、触发模式、模型版本、方案与版本。

信息层级

  1. L1 当前件 OK/NG：结果大徽标 + 图像上的红/绿检测框；NG 时红色同时出现在顶栏报警、结果卡、明细行。
  2. L2 哪里 NG：缺陷位置、类型、置信度、尺寸；图像框与结果明细一一对应。
  3. L3 是偶发还是趋势：最近检测明细 + 班次统计 + 通过率趋势。
  4. L4 为什么：配方/阈值、相机曝光/增益/光源、触发与编码器状态。
