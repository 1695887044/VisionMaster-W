## 定位

这是 SCADA 监控模板的**完整界面套件**：主画面不再单张交付，而是补齐操作员从“看总览”到“处理报警/追溯操作”的完整闭环。

```text
总览 → 监控 / 手动 / 自动 → 报警条 → 报警日志 → 操作记录
```

- 7 个界面共用同一副公共壳：顶栏 / 左导航 / 右信息栏 / 底栏。
- 左导航固定 7 项；当前页高亮；报警条带未确认计数徽标。
- 报警条与报警日志双向跳转；操作记录是审计终点，可反查关联报警与来源页面。
- 手动 / 自动切换必须二次确认；自动 → 手动会暂停当前批次。

| --- | --- | --- | --- | --- | --- |

| 03 | 手动 | 单设备启停、调频、复位 | 设备列表 + 单设备控制面板 + 最近操作 | 联锁条件 / 当前报警 / 操作权限 | 查看全部操作 → 操作记录；切换自动 → 自动 |

| 06 | 报警日志 | 历史报警查询、详情、导出 | 筛选栏 + 报警日志表 + 报警趋势 | 报警详情 / 操作 / 统计 | 查看实时报警 → 报警条；关联操作 → 操作记录 |

**跳转纪律**

1. 左导航永远可见，当前页高亮；不要用“返回”替代左导航。
2. 顶栏报警 chip 永远去 05 报警条，不直接去报警日志。
3. 手动 ↔ 自动切换必须二次确认；自动 → 手动先暂停批次。
4. 报警条“查看全部”去 06；06“查看实时报警”回 05，形成双向。
5. 07 操作记录是审计终点，任何页面都能进；从 07 反查 06 / 03 / 04。
6. 底栏只放只读状态，不放操作按钮。

## 公共壳（A~E）

```text
┌──────────────────────────────────────────────┐
│ A  TOP BAR   site / mode / alarm / user / clock│
├────────┬───────────────────────────┬─────────┤
│ B NAV  │ C WORKSPACE               │ D RAIL  │
│ 7 项   │ 当前页工作面               │ 报警    │
│        │                           │ KPI     │
│        │                           │ 明细    │
├────────┴───────────────────────────┴─────────┤
│ E  STATUS BAR   connection / cycle / version  │
└──────────────────────────────────────────────┘
```

| 区 | 内容 | 约束 |
| --- | --- | --- |
| A 顶栏 | 站点、运行/手动模式、节拍/当前步、报警、操作员、时钟 | 只放 L1 状态；报警入口始终可见 |
| B 左导航 | 总览 / 监控 / 手动 / 自动 / 报警条 / 报警日志 / 操作记录 / 设置 | 7 项 + 设置；当前页高亮；报警条带未确认徽标 |
| C 主工作区 | 工艺图 / 测点 / 设备控制 / 步序 / 报警表 / 日志表 | 只放当前页的判断与操作 |
| D 右信息栏 | 报警 → KPI/状态 → 明细/权限/跳转 | 顺序固定；不把报警压到最下面 |
| E 底栏 | 连接、周期、批次/模式、方案与版本 | 只读，不放按钮 |

## 复用约束

1. **公共壳原样复用**：A/B/D/E 四区不改结构；只替换 C 区。
2. **左导航 7 项固定**：总览 / 监控 / 手动 / 自动 / 报警条 / 报警日志 / 操作记录；设置放最后。
3. **顶栏只放 L1 状态**：站点、模式、报警、用户、时钟；启停按钮留在工作面。
4. **手动/自动切换必须确认**：自动 → 手动先暂停批次；手动 → 自动需启动许可满足。
5. **报警条与报警日志双向**：报警条“查看全部”去日志；日志“查看实时报警”回报警条。
6. **操作记录是审计终点**：不可修改、保留 90 天、可导出 CSV；从记录可反查报警与来源页面。
7. **候选图元不当作已实现**：`SequenceStep` / `DataTable` / `ChartBar` / `MultiTrend` 只在设计稿中标注。
8. **不引入新技术决策**：本轮不定义数据源、通信、流程触发、权限与部署方式。
