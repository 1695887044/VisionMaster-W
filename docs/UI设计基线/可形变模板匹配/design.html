怎么用
  1. 先选算法（局部非刚性 / 平面透视）。
  2. 选参考图并「载入」。
  3. 选 ROI 形状，填中心/半长/半宽（v1 数值）。
  4. 点「学习模板」，状态变「已学习」。
  5. 连上游 Image，运行看结果。
  6. 改创建期参数会变「参数已改·需重新学习」。

设计说明（R111 六项）
01
布局与间距960×680；左栏 368px 配置轨 + 右栏工作区；内容区 padding 16/20，栏间距 16；控件 36px，字段间距 10px。640 窄档左栏 300px，结果区单列 + 滚动。
02
配色令牌全部走 Dialog* / PluginPreview* 既有语义令牌；WPF 视图零十六进制。见下方「令牌映射」。
03
字号与字重标题 15/600；分区标题 12.5/600；标签 12/500；正文 11.5；帮助 11.5；表格 11.5；数字等宽用 Cascadia Mono / Consolas。
04
五态默认 / 悬停 / 焦点 / 禁用 / 错误；按钮、输入框、状态胶囊、算法卡片都定义。见下方「五态对照」。
05
交互细节算法卡片点击切换参数组；ROI 形状切换更新数值标签与画布；学习按钮在「未学习/参数已改」时高亮；结果表按分数降序显示；过渡 150ms。
06
局部 / 平面差异局部显示「平滑度」，输出 DeformedContours / RectifiedImages；平面隐藏平滑度，输出 HomMat2D。两种模式的 Row/Column 都由参考点推导。

契约保留（一个都不能改）

#契约为什么不能动
C1DataContext = 插件实例 + IPluginConfigView宿主靠 viewObj.DataContext as IPluginConfigView 取 OnConfirm；换独立 VM = 确认不保存。
C2NumericBox + NumberValidationRuleROI/角度/缩放/分数等数值的解析、范围校验、提交时机都在控件里；只改外观，不换控件。
C3ImageEdit / ImageReadOnly（若使用）HALCON 显示/缩放/右键菜单/ROI 交互依赖控件 DP；必须常驻可视树，不折叠。
C4TemplateJson / OnConfirm模型载荷、LearnedAlgorithm、LearnedSignature 随方案落盘；视图不能另存一份。
C5StatusMessage / StatusLevel只有 Info / Warning / Error 三档；状态胶囊与底部状态栏共用同一来源。
C6端口契约：MatchCount/Score/Row/Column/Scores/Rows/Columns/DeformedContours/HomMat2D/RectifiedImages/MeasureImage端口名与类型是下游 API；本稿不新增/改名/改类型。

  • 多模板 / 配方库（v2 升级路径：List<DeformableTemplateEntry> + TemplateLibraryJson）。
  • PlanarCalibDeformableModel（需要相机内参/位姿）。
  • VectorField 输出、平面模式 RectifiedImages、批量学习/批量重建。
  • 画布 ROI 拖拽（M3 增量；v1 只做数值 ROI + 只读预览）。
  • 实时性调参表、假 timeout、自动参数推荐。
