v1

把散落的系统 MessageBox 与 EasyDialog 纯代码弹窗，收成 UI 库里的一个公共组件： 语义图标 + 结构化的「详情」区 + 主次分明的按钮 + 键盘可达。本页是设计媒介，不是交付物（R126）； 确认后再按本基线复刻到 WPF，复刻证据与差异清单另附。

审查清单

请重点看这几项，确认后冻结 v1
  • 详情区是否成立：路径从一段话里拎出来，做成「标签 + 数量 + 等宽路径 + 复制」，比原对话框更好扫读。
  • 主次是否清楚：「打开目录」是唯一主色按钮，「稍后再说」是次要按钮；不再出现两颗同宽的「是(Y)/否(N)」。
  • 危险确认是否安全：红色只给「删除分组」，且默认焦点在「取消」，Enter 不会执行删除。
  • 四种语义是否够用：信息 / 成功 / 警示 / 危险，图标底色与语义一一对应，不再用系统黄三角。
  • 480 宽是否够：现场恢复的两行详情在 480 下完整可读；560 档留给更长的路径或多行说明。
  • 是否保留 Y / N：界面只显示动作文字，Y/N 作为隐藏快捷键保留，老用户不必改习惯。

四种语义

图标块 36 × 36 / 圆角 10；底色取语义浅底，描边同族
信息 Info
流程提示、可继续的说明、需要用户选择下一步。
成功 Success
保存完成、编译通过、上传成功；通常只有一个「好」。
警示 Warning
现场恢复、通讯未连接、参数可能不生效。
危险 Danger
删除、覆盖、放弃未保存修改；主按钮红色，默认焦点在取消。

按钮组合

按钮高 32 / 圆角 8 / 间距 8；主操作永远在最右
单按钮 · 告知
只报告结果，不需要决策。Enter / Esc 都关闭。
双按钮 · 选择
本组件的主形态。取消在左、主操作在右；Esc 走取消。
三按钮 · 保存决策
用于「关闭前有未保存修改」。不保存是次要按钮，不涂红。

组件 API 建议

宿主沿用 EasyDialog 的透明遮罩窗口与线程保护，只替换卡片视觉 
// UI 库：UI.CustomControl.MessageDialog
// 不新建第二套弹窗引擎：内部仍走 EasyDialog 的遮罩窗口 / 并发锁 / 取消保护，
// 只把 BuildDialogUI 的纯代码视觉树换成这套卡片。
var result = MessageDialog.Show(new MessageDialogOptions
{
    Severity      = MessageSeverity.Warning,
    Title         = "上次运行的现场",
    Message       = "检测到 1 份未保存的方案草稿，已归档到下面的位置。",
    Details       =
    {
        new("方案草稿", "1 份", @"Autosave\recovered"),
        new("崩溃现场", "1 个", @"crash_reports\20261020-091233"),
    },
    Hint          = "可用「打开方案」载入草稿继续编辑。",
    Question      = "现在打开草稿所在目录吗？",
    PrimaryText   = "打开目录",
    SecondaryText = "稍后再说",
    // 危险动作：PrimaryTone = MessageTone.Danger，且默认焦点自动落在取消
});

if (result == MessageResult.Primary)
    Process.Start(new ProcessStartInfo("explorer.exe", $"\""{dir}\"") { UseShellExecute = true });

改前 → 改后

同一个「上次运行的现场」场景
上次运行的现场✕
检测到 1 份未保存的方案草稿，已归档到： Autosave\recovered 可用「打开方案」载入继续编辑。 是否现在打开所在目录？
改前：系统 MessageBox（不可样式化）
  • 系统字体与方角按钮：和青蓝设计系统不是一套语言，同屏切换像两个软件。
  • 黄三角是唯一语义：信息 / 成功 / 警示 / 危险全用同一颗图标，分不出轻重。
  • 路径埋在正文里：不可复制、不可悬停看全，长路径直接换行。
  • 「是(Y)/否(N)」不可自解释：用户得先读完整段话才知道「是」是什么动作。
  • 没有主次：两颗按钮同宽同色，「是」还被系统默认框包住。
  • 没有焦点与键盘契约：Esc、Enter、Y/N 的行为由系统决定，无法和产品口径对齐。

改后（见上方舞台）：语义图标块 + 结构化详情 + 动作化按钮 + 明确键盘契约； 全部走 Dialog* 令牌，换肤时跟着变。

标题 / 正文 / 问题DialogMessageTitle / DialogMessageLead / DialogMessageHint / DialogMessageQuestion（Dialog.Message.xaml）。

按钮新增组件按钮族 DialogMessagePrimaryButton / DialogMessageSecondaryButton / DialogMessageDangerButton（定义在 FluentAliases.xaml，基于 FluentButtonStyle，分别用 DialogAccentBrush / Dialog 描边与文字令牌 / DialogDangerBrush）；不复用 DialogPrimaryButton——它指向 Fluent 的 #0078D4，会把青蓝体系劈成两套蓝（见 README 决策 D1）。
焦点 / ToolTip所有可聚焦控件挂 DialogFocusVisual；复制、关闭、超长路径挂 DialogToolTipStyle（R135）。
键盘主按钮 IsDefault、次按钮 IsCancel；危险场景把 IsDefault 放到取消；PreviewKeyDown 里接 Y/N。
危险场景默认焦点 = 取消；主按钮红色但不是 IsDefault；文案「删除分组」明确动作对象。
迁移调用点先接 EasyDialog.ShowSync 家族（视觉统一），再逐处替换 MessageBox.Show（App 现场恢复、布局加载/重置、图像视图、报警历史）。每处保留原命令与返回值语义。
