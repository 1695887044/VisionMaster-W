这一版改了什么（只动 chrome，内容与语义零改动）

优先级位置现状改法理由
P0底栏 · 方案路径 完整路径挤在 26px 高栏里，截成「…综合测试台（测试员版…」，两头都没信息 只显方案名，完整路径进悬浮提示 底栏回答「现在什么状态」，不回答「文件在哪」；路径属于方案属性
P0命令条 · 不可用对比度 暂停 / 继续 / 单步 / 停止 与可用的编译/运行长得一样，只有一点点灰度差 不可用降到 #CBD5E1 并禁用命中；可用项补 28px 命中区 未启动时只有三个按钮能点，现在七个看起来都能点
P1底栏 · 分隔线 9 条 TextBlock "|" 当分隔线，间距 4/6/8/10 混用 统一 1px 分隔块（12px 高），项内 7px 内边距 竖线是文字，会跟字体基线漂移，也挤占 26px 栏的横向空间
P1底栏 · 高度与命中区 26px，字号 12px，项无内边距，可点区域只有文字本身 28px + 每项 24px 可点区域 底栏可点项不少（用户、方案、控制台），26px 下点哪都差一点
P1顶栏 · 模式切换 四个平铺文字，无快捷键提示 灰底分段控件 + ^1…^4 角标（选中色仍是现有紫色） 四个平铺文字读不出「四选一」，也看不出有快捷键
P1顶栏 · 文件操作分组 新建/打开/保存 与 搜索/全局变量/硬件/配方 同权重混排 三个文件操作收成一组，与全局命令之间加分隔（仍保留图标，不藏进菜单） 两段语义不同，但都要一眼可达；上一版把它们藏进菜单是过度设计
P1顶栏 · 中央 只有文件夹图标 + 方案名 方案名 + 目录尾段（胶囊底），完整路径进提示 中央是视线落点，补上「在哪」而不只是「是谁」
P1日志 · 警告入口 71 条警告只是一个数字，看不出是筛选按钮 「● 警告 71」做成可点筛选项（选中态浅橙底） 71 条警告是当前最该看的东西，却最难点
保留底栏 · 告警 KPI 「告警」是产线告警计数，与日志面板的 71 条警告不是同一个指标，本稿不合并、不改名、不换成警告胶囊。
保留命令条 · 颜色语言 绿=运行、红=停止、灰=不可用，沿用现有语义，不引入蓝色主按钮。
