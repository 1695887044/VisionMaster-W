06交互与边界

  • 跟手：跟随指针移动，不参与命中测试（IsHitTestVisible=false，库内固定），不挡放置目标。
  • 落子即消失：成功/取消/Esc 都由 gong 的放置端关闭（本轮已修：画布改为 IsDropTarget）。
  • 不表达"能不能放"：浮层只说明"正在拖什么"；能不能落由光标效果与状态栏文案负责（Break/Continue 的循环归属闸门）。
  • 屏幕边缘：Popup 不自动翻转，靠近右/下边缘可能被裁切——库行为，本次不改。
  • 长名字：名称与分类行各自省略；完整名称在工具箱条目悬停预览里看。

07已知偏差（R130 预判）

  • 双层阴影不可复刻：WPF 每个元素只有一个 Effect；真机用单层 DropShadowEffect 近似（比本稿略"平"，允许偏差）。
  • 渐变图标块：需要新增 CategoryChipBrushConverter（分类色 → 18%→7% 渐变）；若实现成本被否决，回退为 v1 的 12% 纯色底（差异仅图标块内部）。
  • 字体度量：本稿用系统 UI 字体，WPF 用应用默认字体；截断点可能差 1~2 个字符。
  • 动效：本稿 150ms + 上浮；WPF 只有库的 Fade，无上浮。
  • DPI：本稿按 100% 出图；125%/150% 下按 DIP 缩放。
  • 分类行文案：直接用 ToolItemModel.Category；未知分类显示"未分类"还是原字符串需在实现时定（建议原字符串，空则"未分类"）。
