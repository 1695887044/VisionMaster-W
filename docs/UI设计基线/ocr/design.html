关键改动（v1）
01
取消固定 1000×620，改为自适应两栏左栏 356px 配置轨 + 右侧识别区工作区；根视图只保留 MinWidth/MinHeight，交给宿主 960×680 外壳。
02
识别区画布升级为工作区保留 h:ImageEdit 常驻与原绑定（DrawObjectList/ActiveRoi/HImage）；不改控件、不折叠已设图控件。
03
参数分层不变常用 6 项在前，高级参数收进 Expander；每个高级项保留原有 ToolTip 说明，不新增参数。
04
试算结果可读性ResultSummary 放进等宽结果块；Hint 同时出现在状态行与试算卡，长文不挤占画布。
05
图像输入只包裹不替换LinkableValueEditor 保留 Port/StepData；Label="" 外置标签，链接/解除链接仍走控件自带按钮。
06
颜色全部令牌化映射 Dialog* / PluginPreview* / ScadaSecondaryTextBrush；视图 XAML 内 0 个十六进制颜色。
契约保留（一个都不能改）
C1
DataContext = 插件实例 + IPluginConfigView宿主靠 viewObj.DataContext as IPluginConfigView 取 OnConfirm；不引入独立 VM。
C2
Image 端口的 LinkableValueEditorPort="{Binding Image}"、StepData="{Binding StepData}"；端口持久化、变量链接、解除链接都在控件里。
C3
ImageEdit 识别区画布ActiveRoi="{Binding CanvasActiveRoi, Mode=TwoWay}"、DrawObjectList="{Binding CanvasRois}"、HImage="{Binding DisplayImage, Mode=OneWay}" 原样保留。
C4
参数与结果绑定TextIsDark / 四个字符尺寸 / 高级参数 / RoiSummary / Hint / ResultSummary 全部保留原属性名与类型。
C5
两个功能入口「清空识别区」→ ClearRoi()、「试算一下」→ TryPreviewRecognize()；视图只转发，不改业务逻辑。
本版明确延后（需新增功能或契约）
D1
加载骨架 / 蓝色加载态需要插件新增 IsPreviewLoading 或 PreviewState；当前只有 Hint 文本。
D2
尺寸 / 文件大小需要插件新增只读属性；本版画布头只显示固定说明。
D3
放大 / 缩小按钮ImageEdit 继承 HalconBase 的 FitToWindow()/FitToImage()；本版不放工具条按钮，右键菜单保留。
D4
打开所在文件夹 / 系统导航需要新增行为或宿主契约；OCR 配置没有文件路径入口，不适用。
D5
StatusLevel 三档状态OcrPlugin 没有 StatusMessage/StatusLevel；本版用 Hint 做状态行，不新增枚举、不伪造状态。
