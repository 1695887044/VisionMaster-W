只支持「目标检测」模型。分割 / 姿态 / 分类模型的输出格式不同，会被明确拒绝（不会拿错格式硬算）。

检测参数常用三项

低于它的候选直接丢弃。调高会减少误检、调低会减少漏检。默认 0.25。

同类框重叠超过它就只留置信度高的那个。默认 0.45；按类别分别做，异类重叠不会被压制。

按置信度排序后截断，避免异常图上刷出成千上万个框。0 = 不限。

高级参数（多数场景不用动）

letterbox 的目标边长。模型元数据里有静态尺寸时留 0 即可；动态形状才需要手填（常见 640）。

只保留指定类别索引的目标。填错会明确报错，不会静默当成不过滤。

「最佳目标裁剪图」向外扩张的边距。下游要做精细测量时给几像素余量，避免把目标边缘切掉。

关键改动（v1）
01
两栏固定分工左 356px 配置轨（图像输入 → 检测模型 → 检测参数 → 高级参数 → 试算），右侧预览工作区自适应；不再是一列卡片从头滚到尾。
02
单页信息架构取消隐式分组，按「输入 → 模型 → 参数 → 试算」排布；「高级参数」收进原生折叠区，默认收起，不占首屏。
03
表单节奏统一标签 12px、控件 36px、帮助 11.5px；数值字段右对齐并启用 tabular-nums；ModelPath 与七个 [StepConfig] 属性绑定原样保留。
04
模型摘要升级为信息卡仍是只读文本（绑 ModelSummary），但放进等宽信息卡：输入/输出形状、task、类别名一眼可见，选错模型时这里是第一线索。
05
预览升级为工作区保留 ImageReadOnly；用 ContentControl + DataTemplate 按需创建（有图才实例化），工具条只接现有 FitToWindow() / FitToImage()。
06
试算结果独立结果面板仍绑 ResultSummary；有目标 / 0 个目标 / 失败三态用语义色区分，失败文案由插件原样给出，视图不重写业务判断。
07
颜色全部令牌化映射 PluginConfigColors.xaml / Colors.xaml；只在本视图派生样式，不改共享字典与共享控件；视图 XAML hex=0。
08
五态与键盘可达hover / pressed / focus / disabled 全量；图标按钮 30×30 且 Padding=0（R68），焦点环走 DialogFocusVisual，ToolTip 走 DialogToolTipStyle（R135）。
契约保留（一个都不能改）
C1
DataContext = 插件实例 + IPluginConfigView宿主靠 viewObj.DataContext as IPluginConfigView 取 OnConfirm；不能换成独立 VM，否则确认等于没保存。
C2
Image 端口的 LinkableValueEditor只此一个 LinkableValueEditor：Port="{Binding Image}"、StepData="{Binding StepData}"；端口持久化、变量链接、解除链接都在控件里。
C3
ImageReadOnly.HImage = DisplayImage保留 HALCON 显示 / 缩放 / 右键菜单；ContentControl.Content 绑 DisplayImage，模板内 HImage="{Binding Mode=OneWay}"（HImage 默认双向，裸 {Binding} 会抛）。
C4
七个 [StepConfig] 属性ModelPath / ConfidenceThreshold / NmsIoU / MaxDetections / InputSize / ClassFilterText / CropMargin；类型与属性名不改，持久化键不变。
C5
命令与生命周期OnBrowseModelClick / OnTryDetectClick / OnViewLoaded / TryPreviewDetect / ShowUpstreamImage 行为不变；Hint / ResultSummary / ModelSummary 原样消费。
C6
本插件没有的契约不伪造Yolo 没有 Mode / SelectedCameraOption / DisplayViewIndex / StatusLevel；本版不新增这些属性，也不把 Hint 包装成假的四档状态。
明确延后（需新增功能或契约）
D1
加载骨架 / 蓝色加载态需要 VM 新增 IsPreviewLoading 或 PreviewState；本版只做空态 / 错误态。
D2
图像尺寸 / 文件大小需要 VM 新增只读属性（HImage.GetImageSize / FileInfo.Length）；本版预览头只显示模型文件名与「上游图像 · 只读」。
D3
放大 / 缩小按钮HalconBase 只有 FitToWindow() 与 FitToImage()，没有公开 zoom 方法；本版不做这两个按钮。
D4
打开所在文件夹需要新增 Process.Start("explorer.exe", ...) 行为；本版不做。
D5
检测框叠加需要把 Detections 的框画进预览图（或新增叠加层属性），属业务 / 渲染改动；本版预览只显示上游原图，结果以左侧试算文本为准。
D6
类别名列表 / 类别选择器模型元数据里的类别名当前只做只读摘要；做可选列表需要新增 VM 只读集合与选择状态，本版不做。
