关键改动（v1）

    
01
接口变量轨与脚本工作区分栏左侧固定 356px（窄档 280px）承载输入 / 输出变量与 Context 速查，右侧编辑器占满剩余空间；640 宽下不再横向溢出。

    
02
变量行改为两段式卡片第一行「名字 + 类型 + 删除」，第二行「连线 / 手填」或「显示窗口 + 备注」。LinkableValueEditor 仍是唯一入口，Port/StepData/PortsVersion 原样保留。

    
03
输出变量按类型收敛只有 IsIconic（HImage / HRegion / HXld / HObject）才显示「显示窗口」；非图形输出把宽度留给备注。仍绑 DisplayWindow int（0~9）。

    
04
编辑器成为主工作区保留 AvalonEdit（行号 / 高亮 / 智能提示 / 右键菜单 / 错误行标红）；编辑器保持浅色，因为 CSharpHighlighting 是浅色语法配色。

    
05
校验结果变成状态栏「校验脚本」仍走 ValidateScript()；ValidationResult 空串显示为「尚未校验」，✔ / ✘ 分别映射成功 / 错误三档视觉，不再在 code-behind 写死颜色。

    
06
空态与窄档齐备无变量时每张卡片给虚线空态；640 宽时隐藏编辑器副标题与状态栏右侧标签，保留核心信息。

    
07
颜色全部令牌化映射 Dialog* / Plugin* 既有令牌；视图 XAML 零十六进制。图标按钮 30×30 + Padding="0"，焦点走 DialogFocusVisual。

    
08
不造死按钮新增 / 删除 / 校验都是现有 Click 处理器；「校验脚本」额外暴露为视图级 ICommand 适配器，供批量冒烟验证命令绑定，不新增业务行为。


    
契约保留（一个都不能改）

    
C1
DataContext = 插件实例 + IPluginConfigView宿主靠 viewObj.DataContext as IPluginConfigView 取 OnConfirm；不引入独立 VM。

    
C2
输入变量的 LinkableValueEditorPort 由 InputPortConverter 按「变量名 + 插件 + PortsVersion」多绑定取动态端口；StepData 绑插件当前配置会话。链接 / 解除链接 / 手填全在控件内。

    
C3
AvalonEdit 编辑器控件类型、ShowLineNumbers、CSharpHighlighting、CSharpIntelliSense、ScriptEditorBehavior、右键菜单与错误行标红全部保留。

    
C4
ScriptText / InputVars / OutputVars三者是 [StepConfig] 持久化属性；ScriptText 仍由 TextChanged 回写，变量集合仍直接绑定，增删仍触发动态端口重建。

    
C5
ScriptVarTypes / ValidationResult类型下拉仍用 ScriptVarTypes（StepConfigOption.ForEnum，显示中文、值仍是成员名）；校验结果仍是 ValidationResult 字符串，不新增状态枚举。


    
明确延后（需新增功能或契约）

    
D1
加载骨架 / 编译中状态需要新增 IsValidating 或异步校验契约；当前 ValidateScript() 是同步调用。

    
D2
编辑器字体 / 缩放设置AvalonEdit 支持缩放，但插件没有公开设置项；本轮不新增配置。

    
D3
打开 / 保存脚本文件需要新增文件对话框与持久化路径；当前脚本只随 .vms 保存。

    
D4
代码格式化需要引入 Roslyn Formatter 或第三方格式化器；本轮不做。

    
D5
变量重命名联动脚本正文需要跨「变量表 ↔ 编辑器文本」的引用分析；当前改名只影响端口名，不改脚本里的字符串。

    
D6
试运行按钮由宿主 PluginConfigShellView 统一提供；插件视图不重复造。
