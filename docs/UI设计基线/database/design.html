设计边界（与 R3 架构评审一致）
  • 数据库页负责配置 + 封装：添加/编辑/删除 profile；管理命名语句（SQL + 参数定义 + 测试）；不做流程执行。
  • 插件层只调用：Plugin.Database 只选 ProfileId + StatementId + 填参数；SQL / 连接串不进入 .vms。
  • 身份稳定：ProfileId / StatementId 用 GUID；显示名可改，改名不断链；有引用时禁止删除（已确认）。
  • SQLite v1：文件路径 + 读写/只读；无密码。SQL Server/MySQL 后续版本；密码走 DPAPI，.vms 只存 CredentialId。
  • 安全硬闸：只允许命名语句 + 参数化；单条语句；只读 profile 只允许 Query；测试写操作回滚；日志不记参数值。
  • 视觉：全部走 Dialog* 令牌；不新增硬编码颜色；圆角/间距按 README 刻度。
