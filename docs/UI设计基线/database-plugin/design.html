设计边界
  • 插件只调用封装好的语句：ProfileId + StatementId + 参数值；SQL / 连接串不在插件窗口出现。
  • 参数由语句定义生成：名称/类型/必填/默认值来自数据库页的命名语句；插件不新增/删除参数。
  • 输出固定：Query / Execute / WriteRow 各自固定输出端口，不做任意 SQL 列映射。
  • 只读 profile 禁止写步骤：与数据库页、宿主服务同一判据。
  • 测试默认回滚：与数据库页一致；取消回滚需二次确认。
  • 视觉：全部走 Dialog* 令牌；不新增硬编码颜色。
