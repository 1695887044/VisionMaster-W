覆盖与要点

  • 覆盖：HardwareManagerView.xaml（52 高标题栏 / 左 210px 域导航 + 系统健康 + 当前方案 / 右四页 TabControl，页签头由左栏导航替代 / 52 高 footer）。导航项与页名逐字取自 VM：概览、相机、通讯、运动控制；页头「急停」只在运动控制页（MotionEmergencyStopCommand，子页整体禁用时它仍可点）。
  • 改动要点：① 左栏导航统一「图标 + 名称 + 右侧异常计数」，计数为 0 时整块隐藏（HasCount）；② 三张域卡改成「卡头（状态点 + 域 + 档位 + 打开）+ 摘要 / 细节 / 异常三行」，卡片由 Grid 等高，现状 MinHeight=174 保留；③ 「当前异常」行从 3 列 Grid 改为「点 + 标题·说明 + 时间右对齐」；④ 「未加载方案」条放在页头与域卡之间，用标签 + 一句话，不压住刷新按钮。
  • 跳转关系：域卡「打开」与左栏导航都落到相机 / 通讯 / 运动控制页；相机页与通讯页分别内嵌 CameraSettingsView / CommunicationSettingsView（IEmbeddedDialogPage，嵌入时隐藏子视图自己的标题栏与关闭按钮）。
  • 文案问题（设计建议，不是缺陷）：无设备时汇总仍显示「全部设备状态正常」（IssueSummary 只看 IssueCount），与三张卡的「未启用」互相矛盾；建议无设备时改成「未配置任何硬件」。
  • 需要新增的接口：HardwareManagerViewModel.IsAllIdle（三域 HasData 全为 false）用于上面的空态文案分支；其余（IssueCount / HasCount / IsHealthy / IsSolutionMissing / HasPermissionHint）已存在。
