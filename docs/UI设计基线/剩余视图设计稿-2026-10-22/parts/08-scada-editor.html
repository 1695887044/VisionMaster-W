覆盖与要点

  • 覆盖：ScadaEditorView.xaml（顶栏两组 WrapPanel + ScadaCanvas + 浮层 SelectionToolbar / 缩放胶囊 + 空态 Border）、ScadaEditorViewModel.cs（BasePageSummary / UndoLabel / Pages）
  • 改动要点 1：顶栏保持一行 44px、按组折行（左组＝画面/基座 + 新建/删除 + 撤销/重做，右组＝网格/吸附 + 缩放 + 运行画面 + 更多）。现状已是两组 WrapPanel，设计稿只钉"排不下时右组整组掉第二行"，不逐个按钮折
  • 改动要点 2：不要恢复常驻格式栏——选中时浮 6 颗（左/中/右对齐 ‖ 置顶/上移 ‖ 更多），其余排列命令留在"更多"与画布右键菜单（图层归属 / 叠放次序 / 对齐与分布 / 等尺寸等间距 / 剪贴板）
  • 改动要点 3：顶栏唯一实心主按钮是「运行画面」；删除画面是图标按钮（稿内用 ✕ 占位，落地是 FA 垃圾桶 U+F1F8），撤销/重做用"图标 + 中文"两个 TextBlock（图标字体无中文字形）
  • 改动要点 4：本文件其实零处真实色值——"4 hex"是注释里出现的色号（#E9EEF5 / #E2E8F0 / #F1F5F9），代码里颜色全走 Scada* / Dialog* 令牌，这条不用改。要守的是另一条：顶栏按钮必须自带 Template，否则吃应用级 Fluent 隐式样式（实测 21px、渐变描边、圆角 5）
  • 改动要点 5：空态三件套（18px 标题 + 12px 正文 + 主按钮）现有，保留；禁用态统一 Opacity 0.4，不做"灰字 + 灰底"两套
  • 需要新增的接口：无
  • 未验证项：窄档折行宽度由 UpdateToolbarLayout 现算，设计稿只表达"允许两行"，不钉像素阈值
