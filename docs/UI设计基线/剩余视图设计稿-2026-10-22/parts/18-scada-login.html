覆盖与要点

  • 覆盖：ScadaLoginView.xaml（左品牌 300 / 右操作区，三段可见性由 IsLoggedIn + SelectedTabIndex 的 MultiDataTrigger 决定）、ScadaLoginViewModel.cs、ScadaUserStore.TryValidate（错误文案来源）
  • 改动要点 1：8 处 hex 全在左栏品牌（渐变 #0B1F33→#0C3B57→#0B5F7A + 三支白透明度 + 文字 #EAF6FF / #B7D9EC）；应上移为 Brand 令牌组（BrandSurface / BrandText / BrandMuted / BrandCard / BrandDivider），视图里不留色值
  • 改动要点 2：登录按钮不禁用（空用户名/密码时由存储报「请输入用户名」/「请输入密码」）；失败提示占 MinHeight=18 一行，输入即清除——不要在输入框上加红框抖动
  • 改动要点 3：出厂密码提示条只在 ShowDefaultPasswordHint 为真时出现，右侧「立即修改」跳到改密页并预填账号（不预填密码）
  • 改动要点 4：三页共用同一个「关闭」位置；「用户管理」只在管理员时出现（CanManageUsers），它是一道界面门，真正的拒绝在 VM 的 EnsureAdmin
  • 改动要点 5：改密页「新密码 / 确认新密码」两列等宽、ChangeMessage 成功绿 / 失败红（ChangeSucceeded 切换）；成功不自动跳回登录页，否则绿色提示会跟着页面一起消失
  • 需要新增的接口：无。已知偏差（2026-10-22 已闭合）：本稿左栏用浅色 surface-2 表达，真实是深青渐变。复刻时已把品牌色上移为 Colors.xaml 的 BrandSurfaceGradientBrush / BrandTextBrush / BrandMutedBrush / BrandCardBrush / BrandCardBorderBrush / BrandDividerBrush 六个令牌，ScadaLoginView.xaml 已 hex=0；本稿的浅色示意仅作版式参考，实际配色以令牌为准
  • 已复刻（2026-10-22）：视图三段（未登录 / 已登录 / 改密）与全部绑定保留；后端 ScadaUserStore + 会话 ScadaAccessPolicy 的端到端链路已加断言（9 条，含改密落盘回读）
