覆盖与要点

  • 覆盖：ScadaToolboxView.xaml（搜索行 42 + 我的模板 + 图元分组 + 条目/模板两套行模板）、ScadaToolboxViewModel.cs（Groups / TotalCount / HasTemplates / Templates）、BuiltInElements.cs（DisplayName / TypeKey / Category）
  • 改动要点 1：不要加内嵌标题——面板头已经写着「图元工具箱」，总数挪到搜索行右端（10px 次要色）；搜索行固定 42px
  • 改动要点 2：分组是扁平 28px 组头（chevron + 名称 + 右端计数），不是卡片。必须自带 Template：应用级 Fluent 的隐式 Expander 是"圆角卡片 + 内边距 + 投影"，会把分组撑成一叠白卡片
  • 改动要点 3：条目 30px = 悬停才出现的抓手 → 22×22 分类色图标块 → 名称 → 右端 9px 类型键（MaxWidth 74，长键如 Hmi.AlarmBanner 不许把行顶出可视区）
  • 改动要点 4：空态是本稿新增——现在搜索无结果时 ItemsControl 直接渲染 0 项，整块空白，用户分不清"没匹配"还是"工具箱没加载"。需补标题 + 正文 + 清空入口（本稿画的那颗「清空搜索」按钮需要新命令，见下）
  • 改动要点 5：「共 N 种」现在是注册表总数（TotalCount 只在构造时赋值），搜索时数字不变；建议改成筛选后的可见条数，否则会出现"显示 0 条却写着共 28 种"
  • 改动要点 6：可见总数是 28，不是注册表 29——Hmi.AxisPointTable 的 ShowInToolbox=false（BuiltInElements.cs:521-527），ScadaToolboxViewModel 的 _all 按这个标记过滤（:76-78）；分类计数因此是 基础 5 / 操作 3 / 指示 3 / 数值 7 / 工艺 5 / 报警 2 / 运动 2 / 数据 1
  • 需要新增的接口：ScadaToolboxViewModel 补 HasGroups / EmptyHint（搜索无结果态用）、ClearSearchCommand（空态那颗按钮），并把 TotalCount 改成随 SearchText 通知的筛选计数（或新增 VisibleCount）
