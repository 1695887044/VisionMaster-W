覆盖与要点

  • 覆盖：ScanGroupEditorView.xaml（上卡 = 可编辑组表，下卡 = 只读运行诊断，底栏 取消 / 确定）。列名与按钮逐字取自 XAML：组名 / 周期 (ms) / 变量数 / 段数 / 排序；组名 / 目标周期 / 实测周期 / 达成率 / 异常段 / 状态；新增组 / 一键预设 / 删除 / 复制到：/ 复制。
  • 改动要点：① 上卡工具栏把「组数上限」移到卡头右侧（现状在标题栏，与工具按钮抢同一行）；② 一键预设的 6 个档位（100 / 500 / 1000 / 5000 / 10000 / 60000 ms，括号里是 联锁 / 快速 / 常规 / 工艺 / 统计 / 归档）保持为按钮 + 菜单，不做成第二排按钮；③ 达成率列现在是「90px 进度条 + 百分比」，共享 CSS 无进度条 class，本稿只画百分比 + 状态标签，WPF 侧保留原进度条；④ 异常段用 1/2 而不是只报分子，正常时显示 —（FaultedText 原口径）。
  • 边界态：空组（只有默认组、变量数 0、诊断区空态）；诊断空态文案逐字取自 VM StatsHint 三种情形之一（连接不存在 / 连接未建立 / 该连接还没有已注册的变量）。
  • 需要新增的接口：ScanGroupStatRow.StatusKey（ok / warn / err / idle）—— 现在分档色由 VM 直接给 StatusColor 十六进制（#12B76A / #F79009 / #E5484D / #909399），换肤时动不了；其余（GroupCountHint / HasLiveStats / StatsHint / CanDeleteSelected）已存在。
