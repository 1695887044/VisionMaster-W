覆盖与要点

  • 覆盖：ScadaRuntimeWindow.xaml（顶条 + 画面区 + 弹窗层 + 报警抽屉挂载 + 底条 26）、ScadaRuntimeWindow.xaml.cs（ApplyRunWindowMode / OnCanvasSizeChanged / ElapsedText 回填）、DefaultScadaAccessPolicy.cs（LoginStateText）、ScadaAlarmHistoryViewModel.cs（UnacknowledgedText）
  • 改动要点 1：22 处 hex 收进深色令牌——现在 BarBrush #22262C / BarLineBrush #33383F / 窗口底 #16191D / TextBrush #D6DAE0 / MutedTextBrush #8A929E / StopBrush #C0392B（描边 #E05A4A、hover #D9453A、pressed #A5342A）/ 报警开关 #2A2F36 · #3A4048 · #323841 · #2B4C7E · #4A8FE0 / 弹窗框 #151C23 · #3A4A5C / 遮罩 #A603070C。它们与 ScadaTokens.xaml 的 Hmi* 是两个色系，必须先在令牌层合并
  • 改动要点 2：顶条分工固定——左＝"我在看哪一页"的读数区（运行画面 + 页面菜单 + ← 返回），右＝动作区（报警历史 + 停止运行）。没有关闭按钮、不绑 Esc：运行态退出必须是一个看得见的动作（触摸屏上没有键盘）
  • 改动要点 3：报警徽标只在有未确认报警时亮出来（数到 0 整块收掉），>99 显示 99+；报警历史用 ToggleButton 表达"抽屉开着"，不用红底（红色已被停止运行占住）
  • 改动要点 4：底条只放读数——设计尺寸 / 视口 / 适配 / 操作者，右端"加载耗时"由宿主在首帧渲染后回填（领域层拿不到那一帧）。无边框最大化时主界面状态栏被盖住，操作者至少能在这里看到自己哪一档权限
  • 改动要点 5：弹窗层与报警抽屉都是覆盖层——加列或改 Margin 会让画布 SizeChanged → FitToScreen，操作员打开面板时画面会"跳一下"
  • 需要新增的接口：无代码接口。需要新增令牌：运行窗口壳一组（壳底 / 顶底条 / 条分割线 / 停止钮三态 / 报警开关四态 / 弹窗框 / 遮罩），建议放 ScadaTokens.xaml 的 Hmi* 命名空间下，宿主浅色令牌不要混进来
  • 已知偏差：共享 CSS 只有 Dialog* 浅色令牌，本稿正文按浅色示意结构；落地时整块换 Hmi*（HmiCanvasBackgroundBrush #0E1318 / HmiSurfaceBrush #151C23 / HmiBorderStrongBrush #3A4A5C / HmiTextBrush #E6EEF7 / HmiTextMutedBrush #7C8A99 / HmiDangerBrush #EF4444）
