覆盖与要点

  • 覆盖：ScadaSystemSettingsView.xaml（标题 45 + 说明 + ui:CardPropertyGrid 420 高 + 数值项约定 + 错误条 + 底栏 取消/确定）、SystemSettingsDraft.cs（六个分组常量）、ScadaSystemSettingsViewModel.cs（Title「系统设置」/ InitialGroup / ErrorMessage）
  • 页签事实纠正：简报说三个页签（运行窗口 / 安全与留档 / 画布），草稿类里实际是**六个**：运行窗口、安全与留档、画布、日志、服务与启动、并行执行；安全与留档内部还有二级分组（会话 / 历史留档 / 账号），由 CardPropertyGrid 渲染成 Expander 卡片
  • 改动要点 1：11 处 hex 是 Element-UI 老色（#409EFF/#909399/#F56C6C/#FEF0F0/#DCDFE6 …）+ 黑色硬投影 DropShadowEffect Opacity=0.15 ShadowDepth=3；应整体换成 Dialog* 令牌 + DialogCardShadow（柔和低透明度），这是本批「最不像同一套设计系统」的一页
  • 改动要点 2：正文一行都不写字段清单——加一项只改草稿类的属性；视图只提供外壳。改这一页时必须保持这个前提，不要在 XAML 里补字段
  • 改动要点 3：数值项一律收字符串、确认时统一解析（属性面板的 NumericBox 遇清空会写 NaN），错误只落在底部一条红带，格式为「「字段名」请填整数，当前填的是「原值」。」
  • 改动要点 4：说明与约定两句必须常态可见（不靠 ToolTip）：「0 或负数 = 不限制 / 永不清理」是最容易被猜错的语义；字段级详细说明才放 ToolTip
  • 需要新增的接口：无（页签由 InitialGroup 指定落点，已够用）
