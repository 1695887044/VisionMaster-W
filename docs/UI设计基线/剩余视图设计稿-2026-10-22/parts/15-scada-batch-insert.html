覆盖与要点

  • 覆盖：ScadaBatchInsertTemplateEditor.xaml + .xaml.cs（ScadaBatchInsertTemplateViewModel：CountText 10 / StartIndexText / ColumnsText 5 / GapXText 20 / GapYText 20 / OriginXText / OriginYText / TemplateSummary / StatusText）
  • 尺寸事实纠正：简报说按 340 设计，源码是 Width="620"、MinHeight="360"、EasyDialog.ShowSync("批量插入模板", editor) 的独立弹窗；340 里放不下「生成数量 + 起始序号」这一对（各 90 定宽 + 90 标签 = 360）。若真要嵌检查器，字段必须改成单列堆叠（本页不另出窄档，理由在此）
  • 改动要点 1：字段是扁平七项（模板 / 数量 / 起始序号 / 列数 / 水平间距 / 垂直间距 / 起点 X Y），标签一律右对齐 90 定宽；两列成对排布时同行等高（FieldBox 统一 28）
  • 改动要点 2：数值一律存文本、解析推迟到 TryBuildPlan——输入框不许做即时纠正，否则「打到一半」会被改成 0；错误只在状态块里说
  • 改动要点 3：状态块现在是一块 ScadaPanelBackgroundBrush 灰底 + 次要色文字，成功/失败/警告三种结果长得一样；应按结果换语义令牌（成功 / 危险 / 警告）并保留「整批不插入」这句
  • 改动要点 4：模板摘要（TemplateSummary）紧贴字段区左缩进 90，用次要色；模板为空时显示「请选择模板」
  • 需要新增的接口：无（状态文案已由 VM 产出；若要给状态块加语义级别，需要在 VM 上补一个 StatusLevel，属可选增强）
