覆盖与要点

  • 覆盖：ScadaGridColumnsEditor.xaml + .xaml.cs（ColumnEditRow：Header / Variable / WidthText / Align / Format / Monospace；DroppedCount）
  • 尺寸事实纠正：简报说它是「340px 检查器里的子编辑器」，但源码是 EasyDialog.ShowSync("配置列", editor) 的独立弹窗，MinWidth=760 / MaxHeight=460，六列定宽 140+72+88+104+80 共 484 已超过 340。本稿主态按真实 760 出，340 只作为「将来嵌进检查器」的提案（列改卡片、字段改上下两行）
  • 改动要点 1：表头与行共用同一套列宽（140 / * / 72 / 88 / 104 / Auto），字号 11 次要色；行高由 CellBox 的 26 撑开，不要给行再加外边距
  • 改动要点 2：未绑定变量 = 输入框描边与底色换危险令牌（ScadaDangerBrush + ScadaInvalidBackgroundBrush），并在弹窗底部把「会被丢掉」说在明处——DroppedCount 已经数出来了，现在没有任何地方显示它
  • 改动要点 3：行内 ↑ ↓ ✕ 是 24×24 固定格子，必须保持 Padding="0"（R68），不要挂全局 Button 样式；删除用危险色文字，上移/下移用次要色
  • 改动要点 4：Monospace 目前只做往返、界面上没有对应控件；若要在本弹窗里暴露，需在模型与 codec 上加一个勾选项（本轮不改模型）
  • 需要新增的接口：无（340 嵌入方案需要 ScadaPropertyViewModel 增加一个「内嵌承载」入口，属后续提案）
