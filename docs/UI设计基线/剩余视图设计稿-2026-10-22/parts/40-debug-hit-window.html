覆盖与要点

  • 覆盖：DebugHitWindow.xaml（430 宽、按内容定高、标准窗框，Title = Header）+ DebugHitViewModel（Header / FlowName / StepName / CanOpenParameters / SuppressThisRun）。文案逐字取自 XAML 与 Shell：标题两态「断点命中」/「单步暂停」，上下文两行「流程：{0}」/「步骤：{0}」，按钮「继续」「单步」「停止」「打开步骤参数」，勾选框「本次运行不再提示」，未定位占位「（未能定位命中步骤）」。
  • 改动要点：① 12 处硬编码色（#409EFF / #606266 / #DCDFE6 / #F5F7FA / #ECF5FF / #E6A23C / #303133 / #909399 / #FFFFFF）全部换 Dialog* 令牌，两套自绘按钮样式（HitPrimaryButton / HitSecondaryButton）改为 DialogPrimaryButton / DialogSecondaryButton；② 命中图标从橙色实心圆改为语义警示色圆点 + 标题同色，避免"橙 = 警告"与真故障混淆；③ 按钮行把「继续」放最左（建议动作），「打开步骤参数」靠右单独一组；④ 快捷键说明从 ToolTip 提升为一行 11px 辅助文字（现场不看 ToolTip）。
  • 边界态：单步暂停 + 步骤未定位（参数按钮置灰、勾选框已勾）；两种标题态都画了。窗口是非模态单实例，点 ✕ 只 Hide()，应用退出链才真正销毁。
  • 需要新增的接口：无（Header / FlowName / StepName / CanOpenParameters / SuppressThisRun / ExecutionCommand / OpenParametersCommand 均已存在）。
