覆盖与要点

  • 覆盖：ScadaPropertyView.xaml（对象头 + 搜索行 + 分组 Expander + 行模板族 + 空态）、ScadaPropertyViewModel.cs（HeaderTitle / HeaderSubtitle / EmptyTitle / EmptyHint / MatchesSearch）、ScadaPropertyGroups.cs（组名与次序）
  • 改动要点 1：一个面板两种编辑对象——选中图元列图元属性，没选中列画面属性；空态判据是 HasRows，不是 HasElement（否则水印会盖在画面属性上）。四种成因四句话：未选择对象 / 还没有组态画面 / 这个图元本机不认识 / 没有匹配的属性
  • 改动要点 2：行结构固定三列——64 标签 + 编辑器 + 26 的 ƒ 槽。不可绑行也占着 ƒ 槽（否则整列右缘参差）；Bool 行改整行勾选、标签与勾选框同一行，编辑器列收起
  • 改动要点 3：已绑行在下方挂一条"已绑带"（ƒ + 变量名 + ✕），与上一行同列对齐；非法值标红并在行下就地写原因，不能只挂 ToolTip
  • 改动要点 4：事件行与动画行独占整行（不排标签列）——事件走 ScadaEventEditor（勾选 + 动作卡），动画走"勾选 → 启用 / 选变量 / 范围 / 档位卡"；两者都带"还没选变量，这条动画运行时会跳过"这类黄字兜底。注意：事件组不是每个图元都有——描述符没声明 Events 的图元整组不出现，本稿的 Hmi.Pump 就属于这种（BuiltInElements.cs:304-329 无 Events），所以上面没有画事件组；要看事件行长什么样请换 Hmi.Button / Hmi.TextField 这类声明了事件的图元
  • 改动要点 5：分组不再套卡片（组头 32px + 下沿 hairline + 行直接铺在面板底色上），计数改成胶囊徽标；「锁定」是开关（32×18）不是勾选框，其余 Bool 行仍是勾选框
  • 改动要点 6：3 处真实 hex 全在同一颗按钮上（EditAxisList 的「选择轴…」：#FFF5F7FA / #FFDCDFE6 / #FF303133）——换成令牌，与「选择列…」那支已经走令牌的统一；面板其余颜色早已全走 Scada* 令牌
  • 需要新增的接口：无（EmptyTitle / EmptyHint / HeaderTitle / HeaderSubtitle / HasRows 均已存在）
