校验失败 错误条（表上方一条红带）

已存在同名报警 [1#电机温度]，请更换名称。

报警名在同方案内必须唯一；留空会被拒绝并回灌原名。写回是即时的，所以错误条不会挡住表格操作。

覆盖与要点

  • 覆盖：ScadaAlarmConfigDialogView.xaml（工具条 + 口径提示 + 错误条 + 7 列 DataGrid + RowDetails + 底栏「关 闭」）、ScadaAlarmConfigDialogViewModel.cs（Title「报警配置」/ CountHint「共 N 条报警」/ KindOptions 7 项 / SeverityOptions 3 项 / VariableDisplay「未选变量」）
  • 改动要点 1：唯一 3 处 hex 是错误条红底红边（#FEF2F2 / #FECACA），其余全走 Dialog* 令牌；错误条应改用 DialogDangerSubtleBrush 一类语义令牌，视图里不留色值
  • 改动要点 2：行内编辑控件必须等高——名称/阈值是 DialogGridInput，种类/等级是压到 30 高的 DialogCombo，46 高的行里不许顶到上下边
  • 改动要点 3：RowDetailsVisibilityMode=VisibleWhenSelected 是这张表的主结构：主字段七列 + 次要字段（回差/延时/断线、信息文本/故障原因/解决措施/附加信息）收进展开行，展开区底色用输入区底色区分
  • 改动要点 4：「删除」是红图标 + 中性文字（悬停不变红），「选择变量」的链接图标取强调色；两者都依赖选中行，未选中应置灰（HasSelection）
  • 改动要点 5：报警组是自由文本 + 历史值下拉（TextBox + 小箭头 + ContextMenu），不要换成 DialogCombo——它的模板没有 PART_EditableTextBox，IsEditable=True 会变成能敲字但看不见
  • 需要新增的接口：无
