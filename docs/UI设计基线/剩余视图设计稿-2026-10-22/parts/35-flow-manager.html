覆盖与要点

  • 覆盖：FlowManagerView.xaml（52 高标题栏 · 流程列表标题 + 240 宽搜索 · 五列 DataGrid · 底部四条说明）。列名与勾选框逐字取自 XAML：流程名称 / 调用方式（多选）/ 描述 / 状态 / 操作；勾选位为 定时、变量、子程序、HTTP；行内动作为 锁定 / 解锁 / 启用·禁用。
  • 状态文案取自 VM FlowItem.StatusText：🔒 已锁定（禁止运行） / ▶ 运行中 / ✓ 已启用 / ✗ 已禁用；调用方式汇总取自 FlowInvokeType.DisplayText()（无位 = 手动，多位用 / 连接，HTTP 位写作「HTTP外部调用」）。
  • 改动要点：① 调用方式列保留「四个勾选框 + 汇总一行」的两行结构（XAML 用 RowHeight=NaN + MinRowHeight=46 正是为了它不被裁），但把汇总改成 11px 次要色，勾选框与汇总之间留 4；② 状态列改成「语义色 + 文案」，锁定态用 .tag.err 观感；③ 行内动作收成 3 枚小胶囊（锁定 = 主色浅底、解锁 = 危险浅底、启用·禁用 = 中性），与 XAML 的 DialogChipButton 一致；④ 底部四条口径说明保留原文，但改成可折行的两列（现状四条长句靠 TextWrapping 硬撑，窄窗会顶宽）。
  • 不可达态：「无流程」画不出来 —— Home / Main / End 三条骨架流程每个方案都必须保留（XAML 说明第 4 条），所以最小行数恒为 3。本稿的边界态改用「搜索无匹配」，并设计建议新增空态遮罩：现在 DataGrid 直接空白，没有任何"没搜到"的提示。
  • 需要新增的接口：FlowManagerViewModel.IsFilteredEmpty（Flows.Count == 0 && SearchText 非空）供上面的空态绑定；FlowItem.StatusKey（ok / warn / err / idle）用于状态列取色 —— 现在只有 StatusText 一段文字，颜色靠文案里的符号区分。
