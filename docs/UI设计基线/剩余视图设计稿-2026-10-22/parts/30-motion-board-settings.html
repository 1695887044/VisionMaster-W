  • 覆盖：MotionBoardSettingsView.xaml（卡头部 + 设备标识 + 运动参数 3 列 + 轴映射表 + 贴底保存条）、MotionBoardSettingsTabViewModel（HeaderName / HeaderDetail / DriverText / ModelText / ConnectButtonText / ConnectionStateText）

  • 改动要点：3 处 hex 换令牌；卡头部 40×40 渐变图标块与 #330DA2E7 双层描边收成「浅主色底 + 主色图标」，与 26/27/28 的卡片头一致。

  • 改动要点：保存条固定贴底（不随滚动区滚走），文案保留「改完参数或轴映射后，点这里统一保存并生效」。
