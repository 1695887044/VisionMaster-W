覆盖与要点

  • 覆盖：CameraSettingsView.xaml（自绘标题栏 / 左 380px 列表 / 右详情 ScrollViewer / 底栏）。字段与按钮文案逐字取自 XAML：连接·断开、开始采流·停止采流、清零计数、删除相机、应用参数、方案加载后自动连接该相机。
  • 改动要点：① 列表行从 3 行（显示名 / 序列号 / 驱动）压成 2 行（名称 + 序列号·驱动），行高 62→44；② 右栏固定阅读顺序「操作 → 运行状态 → 溢出告警 → 采集参数 → 预览」，卡片间距 12→16；③ 溢出告警改成「浅红底 + 左侧语义条」，并把 OverflowCount 与告警放同一张卡（现状数字在上一张卡、告警在下一张卡，视线要跨卡）；④ 采集参数 8 项统一 .field 两列栅格，标签左对齐，输入框左缘对齐。
  • 边界态：未连接（计数全 0、无告警、预览空）与空列表两态都画了；「网络相机接入说明」卡（推帧地址 / 心跳地址 / 访问令牌）只在 IsNetworkCamera 时出现，本稿未画。
  • 需要新增的接口：CameraRowViewModel.StateKey（ok / warn / err / idle）—— 现在只有 StateText 文案，胶囊底色写死 DialogRowHoverBrush，导致「采流中」与「未连接」视觉同色；其余（HasPreviewImage / HasOverflow / IsConfigEditable / IsRuntimeOperable）已存在，无新增。
