覆盖与要点

  • 覆盖：ScadaTemplateParameterizeEditor.xaml + .xaml.cs（ScadaTemplateParameterizeViewModel：IndexText / NameRules / TextRules / Add·Remove 四条命令 / StatusText）、ScadaTemplateParameterizer
  • 尺寸事实纠正：简报说按 340 设计，源码是 Width="620"、MinHeight="470"、EasyDialog.ShowSync("参数化模板", editor)；340 放不下「查找 + 替换 + 删除」三件套（两条输入各 90 起 + 26 按钮），嵌检查器需改单列三段式，本页不出窄档
  • 改动要点 1：两块规则列表现在都是 MaxHeight=132 的灰底框，滚动条常驻；应改为「无规则时给空态文案、有规则时按行分隔」，否则用户看到的是两块说不清用途的空白
  • 改动要点 2：每条规则是「查找 → 替换」两列等宽 + 26×26 删除钮（Padding="0"，R68）；规则行之间 6px，行内输入 28 高
  • 改动要点 3：ScadaWarningBrush 那句「查找串包含前缀时，替换串也要带前缀」是**必读口径**（写成 Cylinder1 → Cylinder{i}），现在与正文同字号只换色，容易被跳过
  • 改动要点 4：状态块承载三类结果——成功（将改写 N 处 + 前 8 条）、无替换（提示按原样保存）、失败（如「数组下标必须是非负整数；留空表示不按数组下标参数化」）；三态要分色，现在一律次要色
  • 需要新增的接口：无（空态文案属纯视图补充；若要让状态块分色，需在 VM 上补 StatusLevel，可选）
