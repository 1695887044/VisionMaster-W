覆盖与要点

  • 覆盖：ImageView.xaml（16 行，只有宿主 Grid + 一个 ToggleButton）+ ImageView.xaml.cs（按 eViewMode 摆 1~9 格，每格一张 ImageGallery）+ Services\Core.Halcon\Themes\ImageGallery.xaml（大图 / 4px 分隔条 / 112 高单行缩略图条）。
  • 现状缺陷（只读记录，未改代码）：ImageView 构造函数里 ShowCanvas() 会 grid.Children.Clear()，把 XAML 里那个裸 ToggleButton 一起清掉 —— 它无 Content、无绑定，且第一帧之前就消失；建议删掉，或给它明确语义（布局切换 / 暂停跟随）后放到画布右上角工具位。
  • 改动要点：① 三态分开（采集关闭 / 首帧未到 / 画布未就绪），现在后两者都显示成空提示；② 缩略图条保持「只显示图片、信息全走悬停」，悬停延迟 250 ms、时长 60 s（现状 ToolTipService 已如此）；③ 每格独立清空 / 导出（右键菜单六项，含「锁定跟随」），导出按流程分文件夹落 PNG；④ 多格布局（1×1 / 1×2 / 2×2 / 3×3 …）由 SpecOf 表驱动，本稿只画 1×1。
  • 需要新增的接口：ImageCollectionService.State（Idle / Waiting / Ready / Unavailable）与对应的 ImageView.HintText 分支 —— 现在只有 BuildHint 的三段静态文案，无法区分「还没来帧」与「服务没起来」。
