1. 三种触发模式
连续采图 = 相机自由出图；软触发 = 流程每次取图前下发一次触发；上升 / 下降沿 = 由相机 IO 线触发，流程只等帧。曝光与增益在「软触发」下仍然生效，但在网络相机上由客户端决定。
2. 超时与队列
端口 默认值 说明
FrameTimeoutMs 3000 单次取图等待上限，超时按「无帧」处理并累加丢弃计数。
BufferCapacity 8 队列满时丢最旧一帧（计入「溢出丢帧」）。
HeartbeatTimeoutMs 3000 心跳停 3 秒判掉线，掉线清空队列计入「其它丢弃」。

覆盖与要点

  • 覆盖：HelpView.xaml（52 标题栏 / 40 工具栏 / 目录 + 分隔条 + 正文 / 26 状态栏）。工具栏按钮逐字取自 XAML：隐藏目录（ToggleTocLabel 在「隐藏目录 / 显示目录」间切）、上一步、打印、正文字号（小 / 标准 / 大）、显示开发章节；目录头「目录」+「命中 N 页」，搜索占位「搜索目录（只搜标题）」，无结果文案「没有匹配的目录」。
  • 正文页眉：标题 + 来源徽标三档 —— 软件内置（主色浅底）、插件名（灰底）、自动生成（虚线描边 + 透明底）；判据绑 PageSourceKind（Host / Plugin / Auto），不绑显示名。
  • 改动要点：① 目录行保留「左 2px 主色竖条常驻 + 选中浅蓝底」（现状靠透明描边占位，避免点选时文字横向抖动），本稿用 .row.sel 近似；② 分组行右侧统一「子项计数」，自动生成 用警示色角标；③ 正文定宽 780 居中不变，卡片之间加 12 留白；④ 状态栏左侧主色圆点 + 一句话来源说明，右侧 Esc 关闭。
  • 边界态：搜索无结果（命中 0 页 + 「没有匹配的目录」），并明确「右栏不清空」——现状 SelectedNode 保持不动，空目录不该把正文一起清掉。
  • 需要新增的接口：无（Nodes / Query / HasNoMatch / MatchPageCount / IsSearching / IsTocVisible / ToggleTocLabel / PageTitle / PageSource / PageSourceKind / FontSizeOptions / ShowDevDocs 均已存在）。
