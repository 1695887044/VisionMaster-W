  • 覆盖：ScadaLayerView.xaml（标题 + 未分层提醒 + 行模板 7 列 + 次序说明 + 新建按钮）、ScadaLayerViewModel.cs（HeaderText / LayerCountText / EmptyHint / UnassignedHint / ElementCountText / VisibilityTip / LockTip / OrderHintDetail）
  • 改动要点 1：26 处 hex 全部清零——面板 #FFF7F8FA、描边 #FFDCE0E6、正文 #FF303133、次要 #FF909399、禁用 #FFB0B4BA、行 hover #FFE9EFF7、含选中 #FFD8E8FA、锁定琥珀 #FFE6A23C、未分层 #FFFFF7E6 / #FFF5D9A0 / #FFB88230、行内按钮 hover #FFD6E4F5、底栏按钮三态。全部换成 Scada* / Dialog* 令牌
  • 改动要点 2：行高 26 保留（与工具箱条目 30 接近，两个面板并排不打架）；行内图标按钮 20×20 保留，上/下移与删除再小一号 18×18
  • 改动要点 3：状态色只表达状态——隐藏=更灰、锁定=琥珀、悬停只换底不换字色。悬停去抢字色会把"这层关着"这条信息盖掉
  • 改动要点 4：删除只在空层可用（灰着的垃圾桶本身就在说"先把这层的图元挪走"）；端点层的 ↑/↓ 置灰
  • 改动要点 5：底部那句「图层顺序不改变图元叠放」是防误判文案，不是装饰——图层次序不参与叠放计算，谁盖住谁只由 ZIndex 决定；完整解释挂在 ToolTip 里（指到画布右键「叠放次序」）
  • 改动要点 6：空态两种说法必须分开——有画面无图层（"点下方「新建图层」"）vs 没有画面（"打开方案并选中画面后…"）。本稿把现在那一段 11.5px 的 EmptyHint 升级成三件套（图标 + 标题 + 正文），与属性面板空态同一形态；文案仍由 EmptyHint 给，需要拆成标题/正文两句
  • 需要新增的接口：ScadaLayerViewModel 把 EmptyHint 拆成 EmptyTitle + EmptyHint（与 ScadaPropertyViewModel 同名同义），否则三件套只能写死标题
  • 已知偏差：稿内用 ● ○ ■ □ 代替 FA 眼睛/锁字形；行尾 ✕ 代表垃圾桶（U+F2ED）
