覆盖与要点

  • 覆盖：MotionBoardView.xaml（页头 + 260px 卡列表 + 胶囊页签 + 三页内容宿主 + 添加卡模态 + 居中确认 + 右下 toast）、MotionBoardViewModel（TabLabels / OnlineText / IsConfigEditable）
  • 关键结构事实：TabLabels 只有 3 项——卡设置 / 手动调试 / 点位列表；MotionBoardCamView 存在但没有挂进页签栏（SelectedTabIndex 夹取到 0~2），所以 27 的凸轮页在本分片里没有对应页签。
  • 改动要点：本页 0 hex（已全令牌化），只统一尺寸与层级——页头 60px、卡列表 260px、工作区圆角 12、卡片阴影只保留「浮起 / 卡片 / 弹窗」三级。
  • 改动要点：顶栏 6 个导航胶囊里 5 个是占位（设备管理 / 变量配置 / 工具箱 / 流程编排 / 轴配置），只保留一个高亮项；占位项用 tool 而非 tool active，不假装可点。
  • 改动要点：关闭按钮固定 30×30 且显式 Padding=0（R68：裸按钮会吃 Fluent 隐式内边距把 ✕ 切掉）；在线/离线从自绘 Border 改为 tag info / tag。
  • 改动要点：删光卡之后左栏给出「还没有运动卡，点右上角「添加」」，与中央「还没有可显示的设置项」同时出现——两句话分别回答"从哪加"和"为什么这里是空的"。
  • 需要新增的接口：无（若要开放电子凸轮页，需在 TabLabels 增第 4 项并在 MotionBoardView.xaml 加一个 SelectedTabIndex=3 的宿主，见 27）
