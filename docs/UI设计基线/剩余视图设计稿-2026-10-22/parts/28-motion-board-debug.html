覆盖与要点

  • 覆盖：MotionBoardDebugView.xaml（状态栏卡 + 命令统计 chip 条 + 三栏 [230 | 1fr | 270]）、MotionBoardDebugTabViewModel（CardStateText / StateLabel / WaitButtonText / HomeButtonText / MovingHint）
  • 关键结构事实：三栏宽度写死 230 / 1fr / 270，且三栏各自带 ScrollViewer——本页刻意不套外层滚动（套了内层拿到无限高度就失效，内容被窗口裁掉且没有滚动条）。
  • 关键结构事实：轴状态字有固定优先级 报警 > 正限位 > 负限位 > 运动中 > 已使能(·已回零) > 未使能，另有 未连接 / 无状态 / 映射停用 三种兜底；示例数据按这套语义给。
  • 改动要点：6 处 hex 换令牌；读数条的 #1A0DA2E7→#66F1F5F9 渐变与状态胶囊的三段色改成「浅底 + 主色数字 + tag」，与 27/29/30 同一套。
  • 改动要点：IO 格子从自绘 Border + 触发器改成 cards + dot（IN 只读、OUT 可点），输出格补 hover 边框；两栏路数取自设备能力（Capabilities.DigitalInputCount / DigitalOutputCount）：正运动卡典型 24 入 / 16 出；只有未连接时才是默认 8/8。
  • 改动要点：未连接态把"能点什么"写清楚——只留「连接」，读数与 IO 用空态说明，不显示一排点了没反应的按钮。
  • 需要新增的接口：无（状态字、按钮文案、提示条全部来自 VM；本页只做视觉重排）
