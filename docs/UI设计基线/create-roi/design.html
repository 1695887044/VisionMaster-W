关键改动（v1）
01
左栏配置轨 + 右侧 ROI 工作区图像输入、ROI 列表、参数微调、显示窗口各就各位；画布占据剩余全部空间，不再让参数面板挤压列表。
02
ROI 列表成为主区列表占据左栏剩余高度；行内显示名称 + 形状中文名；保留 SelectedItem = SelectedRoi、ListBoxAutoScroll 与删除/清空命令。
03
画布工具条分层第一行：原图 / 掩膜预览 + 排除模式；第二行：正常 / 绘制涂抹 / 擦除涂抹 + 笔刷 + 清除涂抹。全部沿用既有绑定与 SmearModeConverter。
04
参数微调双列排布五个参数（中心行/中心列/角度/半长/半宽）两列排布，仍绑定 SelectedRoi.ParamEntries，Text 编辑走 LostFocus。
05
空态用提示条无图时在画布上方显示提示条（不折叠 ImageEdit）；画布始终常驻，HImage 绑定逐字保留。
06
颜色全部令牌化映射 Colors.xaml / PluginConfigColors.xaml；只在本视图派生样式，不改共享字典与共享控件。
07
五态与键盘可达hover / pressed / focus / disabled 全量；图标按钮 30×30 且 Padding=0（R68），焦点环走 DialogFocusVisual。
契约保留（一个都不能改）
C1
DataContext = 插件实例 + IPluginConfigView宿主靠 viewObj.DataContext as IPluginConfigView 取 OnConfirm；不引入独立 VM。
C2
LinkableValueEditor：SrcImagePort="{Binding SrcImage}"、StepData="{Binding StepData}"；端口持久化、类型转换、变量链接、解除链接都在控件里。
C3
ImageEdit 常驻 + 五个绑定HImage="{Binding DisplayImage, Mode=OneWay}"、DrawObjectList="{Binding CanvasRois}"、ActiveRoi="{Binding CanvasActiveRoi, Mode=TwoWay}"、SmearDraw/SmearErase 双向；不折叠、不替换控件。
C4
MaskInvert / IsMaskPreview / SelectedRoiMaskInvert 是 [StepConfig] 布尔；IsMaskPreview 视图态；SelectedRoi 是 RoiItem 对象；类型不变。
C5
命令族DeleteSelectedCommand、ClearRoisCommand、ClearSmearCommand 与 Delete 键绑定原样保留；不新增功能入口。
C6
DisplayViewIndex 仍是 int下拉 SelectedItem 绑定 0~9 的 int 数组；不改写 [StepConfig] int DisplayViewIndex。
C7
无 StatusLevel本插件没有 StatusMessage/StatusLevel 属性；状态栏只显示选中 ROI 与 ROI 数量，不新增第四档或假状态。
明确延后（需新增功能或契约）
D1
加载骨架 / 蓝色加载态需要 VM 新增 IsPreviewLoading 或 PreviewState；本稿不扩展。
D2
图像尺寸 / 文件大小需要 VM 新增只读属性（HImage.GetImageSize / FileInfo.Length）。
D3
放大 / 缩小按钮HalconBase 只有 FitToWindow() / FitToImage()，没有公开 zoom 方法。
D4
打开所在文件夹需要新增 Process.Start("explorer.exe", ...) 行为。
D5
系统导航 / 前往相机设置需要新的宿主导航契约；本插件没有相机配置。
