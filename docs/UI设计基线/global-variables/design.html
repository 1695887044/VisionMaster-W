关键改动（v1）
01
左栏变成真正的来源导航按「本地与系统 / 通信连接」分组；节点显示图标、名称、状态副行与计数；选中态为白卡 + 左侧主色条。系统变量用锁图标与「只读」副行，和本地变量分开。
02
右栏卡片头建立来源上下文标题 + 变量数 + 当前来源 chip + 一句副标题；搜索、管理扫描组、添加变量固定右对齐。仍绑 SelectedSource / SelectedSource.Count / IsNetworkSource。
03
明细行改为两行式变量名 12.5px + 描述 10.5px；类型是中性 chip + 类型色点；数组根显示「N 项」，子行缩进 24px、40px 行高，仍走 Level / IsContainer / ToggleNodeCommand。
04
当前值单元格是编辑主入口质量点 + 提交式输入框 + 偏离时的 ↺；数组根是「摘要 + 编辑数组… + ↺」（v2）；图像与只读存储区显示只读提示。行为仍由 CellValueEditBehavior / CurrentValueText / IsValueDeviated 驱动。
05
空态与搜索无结果分开空来源显示「还没有变量 + 添加变量」；搜索无结果显示「没有匹配 + 清空搜索提示」。不再用一张空白表格冒充加载失败。
06
系统变量只读语义前置系统来源顶部常驻只读横幅；行内操作列只保留「复制变量名」+「只读」chip，不再显示点了只会弹提示的删除 / 重命名按钮。判据仍走 IsSystemOwned。
07
底部提示改成状态条左侧「N 个变量 · 来源 · 轮询/内存」；右侧键盘提示 Enter 提交 / Esc 取消 / ↺ 恢复初始值。原长段落说明移入 README 与 ToolTip。
08
全令牌化与可达性视图零十六进制；类型色复用既有语义族；图标按钮 30×30 + Padding=0（R68）；焦点走 DialogFocusVisual；表格横向滚动保留 Auto，星号列 MinWidth 不低于 80。
v2 数组编辑（本页新增）
09
数组根不再是「强制覆盖集合...」当前值格改成「等宽摘要（前 2 项 + …）+ 编辑数组… + 偏离时的 ↺」。摘要让用户不展开也能看出这组值是什么；入口文案说明它编辑的是当前值，不再是"强制覆盖"这种听不出后果的词。
10
元素行：就地改当前值 + 逐元素 ↺元素行仍走 CellValueEditBehavior 提交（只写 Value[i]）；偏离基准时该行出现 ↺，只恢复这一项。长度 / 增删这类结构改动不进表格，避免误点一下就整组错位。
11
数组编辑弹窗：默认只写当前值弹窗装填的是当前值（屏幕上看到的那组）。写入范围默认「只写当前值」；选「同时写初始值」才把新数组同时写进 DefaultValue。旧的「强制覆盖」是两者一起写且弹窗显示基准，用户点确定等于把运行值换掉——这条语义在 v2 被拆开，v3 把选择做成显式分段。
12
校验失败就地标红，不丢编辑点确定先逐项校验：出错的项红框 + 列表下方给「第 N 项「abc」无法转换为 Double」；弹窗保持打开，其余编辑原样保留。转换规则与当前值就地编辑同源（VariableValueConverter：不变文化、布尔认 1/0/是/否、拒绝千分位）。
v3 数组编辑弹窗优化（本页新增）
13
写入范围升级为分段选择「只写当前值 / 同时写初始值」两段放在一张范围卡里，右侧显示基准项数；下方一句话随选择变化——「初始值保持不变，↺ 仍回到原基准」/「新数组同时成为初始值」。比一个孤零零的复选框更容易在点确定前看清后果。
14
逐行基准值与「已修改」标记改过的行在输入框下方显示「● 基准：原值」（等宽字体 + ToolTip 全量）；行尾多一颗 ↺，只恢复这一项。没改过的行不显示基准行，保持列表安静。
15
修改量汇总与一键恢复底部显示「N 项已修改」（未修改时灰色「未修改」），旁边「恢复全部为基准」在有修改时才可点；标题副行同时给出「当前 N 项 · 基准 M 项」，长度不同一眼可见。
16
校验语义不变v2 的「弹窗内校验、失败不关窗」保持不变；v3 只重排信息层级与操作密度，不改回传契约（Array / Variable / SyncBaseline）。

C8
系统 / IO 变量只读IsSystemOwned / IsEditableNode / IsValueReadOnly 语义不变；删除、重命名的 VM 侧拦截仍在。
v1 明确延后（需新增功能或契约）
D1
「添加变量」弹窗改版当前是 EasyDialog.ShowPropertyGridAsync 框架属性网格；改版需要新的弹窗视图与草稿渲染契约，本批只保留入口。
D2
列选择 / 密度切换 / 排序需要 VM 新增列状态与排序命令；本批列集合固定。
D3
多选批量删除需要 VM 新增选中集合与批量命令；本批保持逐行删除。
D4
变量详情检查器需要 VM 新增 SelectedNode 与详情字段；本批不扩右栏。
D5
导入 / 导出变量表需要新的文件契约与校验；本批不做。
D6
历史趋势 / 迷你曲线需要按变量采样与环形缓冲；本批只显示当前镜像值。
