关键改动
01
模式选择改为 2×2 卡片替代 4 个单选 + GroupBox。图标、名称、用途说明与选中态同屏，窄窗口不再靠换行硬塞。
02
一屏完成配置取消「基本参数 / 图像参数」两级页签；「显示窗口」并入左侧「输出」区，不再为一个下拉单开一页。
03
表单节奏统一标签 12px、控件 36px、帮助 11.5px，行距 12px；去掉 MaxWidth 430 的硬截断，输入区随栏宽伸缩。
04
预览升级为工作区文件信息头 + 缩放工具条 + 深色画布 + 状态栏；空态、加载、错误三态齐备，路径与尺寸不再只靠一行状态字。
05
生产配置与调试分层网络推送把服务状态置顶；推送测试与接口说明收进「调试与接口」折叠区，生产参数保持干净。
06
相机状态前置显示名、序列号、连接状态同卡展示；未连接时直接说明「运行时会失败」，不再让用户等运行失败才知道。
07
颜色全部令牌化映射 Colors.xaml 的 Dialog* / Scada* 令牌，去掉 #666 / #333 / #999 / #FAFAFA / #DDDDDD 等内联灰阶。
08
五态与键盘可达hover / pressed / focus / disabled 全量定义；图标按钮 30×30 且 Padding=0，焦点环可见，避免字形被裁（R68）。
