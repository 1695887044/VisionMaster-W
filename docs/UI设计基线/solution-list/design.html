关键改动（v1）
01
保留“表格 + 右侧动作栏”的交互路径不改成工具栏或行内菜单；动作按「打开 / 清单 / 排序 / 危险操作」分组，建立主次，但仍全部是现有命令入口。
02
主次与危险语义归位“打开方案”“确认”走主色（DialogPrimaryButton）；“取消”走次要；“从清单移除”走危险色（DialogDangerButton）。不再出现“确认是红色、取消是蓝色”的倒置。
03
默认启动方案一眼可见新增「默认」列与底部默认路径状态条；判据是 Path == StartupSolutionPath，纯显示派生，不改 VM、不新增持久化字段。
04
注释单元格变成可见的编辑器安静输入框：hover 出现边界、focus 出现主色环与铅笔图标；仍绑 Comment，UpdateSourceTrigger=PropertyChanged 语义不变。
05
空清单有独立空态不再是“一块空白 + 列头”；空态直接给「添加当前方案」「浏览添加…」两个现有入口，与“未选中”状态分开。
06
列宽预算写死，消灭 28px 溢出Web 稿固定 40 + 152 + 176 + 72，路径列 minmax(220px, 1fr)；WPF 实现按比例 1.2* / 1.0* / 1.6*（960 下约 199/162/265，900 下路径 220），不再出现默认横向滚动条。
07
全部走公共令牌与共享样式根背景 DialogBackgroundBrush、卡片 DialogSurfaceBrush、按钮 DialogPrimaryButton / DialogDangerButton / DialogSecondaryButton、输入 DialogCellInputQuiet、空态 DialogEmptyState*；视图零十六进制。
08
键盘与可达性Esc 取消；Enter 在非输入框时确认、在注释框内提交本行；行与按钮都有可见焦点环；长路径用 ToolTip（DialogToolTipStyle）补全。
契约保留（一个都不能改）
C1
DataContext = SolutionListViewModelPrism RegisterDialog + ViewModelLocationProvider.Register 的接线不变；不引入独立 VM，视图不自己 new。
C2
三份核心状态Solutions / SelectedSolution / StartupSolutionPath 原样；清单仍是工作副本，取消不污染配置。
C3
9 个命令全部保留OpenCommand / SetStartupCommand / AddCurrentCommand / AddCommand / DeleteCommand / MoveUpCommand / MoveDownCommand / ConfirmCommand / CancelCommand。
C4
注释编辑语义Comment 的 TwoWay + PropertyChanged 不变；不改 Name（名称来自文件名，本批不做重命名）。
C5
序号是显示值Index 不持久化，由 RefreshIndexes() 按顺序重排；设计稿不把它变成可编辑字段。
C6
移除只动清单OnDelete 不删磁盘文件；若删的是默认方案，VM 会清空 StartupSolutionPath。这两条行为原样保留。
C7
确认与保存失败OnConfirm 只写变了的项；保存失败不关窗、弹错误提示（toast）；审计 ScadaAuditWriter 与署名口径不变。
C8
打开方案OpenCommand 校验文件存在、加载方案、切换工作区并关闭弹窗；不在本批改加载语义。
C9
宿主窗口标题栏、关闭按钮、窗口尺寸由 Prism DialogWindow 提供；视图只负责内容区，不新增自绘标题栏。
v1 明确延后（需新增功能或契约）
D1
搜索 / 筛选VM 没有 SearchText 或筛选集合；本批不新增。
D2
多选批量移除VM 只有单个 SelectedSolution；批量需要新的选中集合与命令。
D3
拖拽排序现有入口是 MoveUpCommand / MoveDownCommand；拖拽需要新的 Drop 契约。
D4
重命名方案名称名称来自文件名；重命名需要新命令与落盘规则。
D5
删除二次确认 / 撤销当前是立即从工作副本移除；确认框或撤销栈需要 VM 改动，本批只做危险色与文案澄清。
D6
未保存脏标记VM 没有 IsDirty；本批不新增“未保存”提示。
D7
打开文件所在文件夹需要新命令与 Process.Start 口径；本批不做。
D8
清单导入 / 导出需要新的文件契约与校验；本批不做。
