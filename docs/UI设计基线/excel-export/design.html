Excel报表
把 CSV 账本导出成带图片超链接的 Excel 报表：表头冻结可筛选，点文件名看高清原图
01报表来源（CSV 账本）
上游 CSV 记录

指向上游『CSV 记录』步骤写出的账本。占位符：{源步骤} {StepName} {yyyy} {yyyy-MM} {yyyy-MM-dd}。

留空 = 使用本步骤名；要与 CSV 记录步骤写账本的目录名一致。

实际读取 →
D:\Records\CSV记录1\2026-10\2026-10-20.csv
账本已找到
02报表输出
xlsx · 可筛选

输出目录与文件名都支持占位符；文件名不以 .xlsx 结尾时自动补。

哪一列做成可点击的图片链接；默认『图片路径』与 CSV 记录插件的图片列同名。

实际写出 →
D:\Records\Excel报表1\2026-10\报表\2026-10-20_报表.xlsx
03报表选项
何时导 · 导哪些行

导出方式决定何时自动导出；勾选项决定报表内容。

仅手动：流程执行时不导出，只在面板点『立即导出』。

端口：导出触发（bool，非必填）。WPF 里由 LinkableValueEditor 承载，只包裹不改内部。

表头冻结 / 自动筛选：打开 Excel 就能筛 NG。

04立即导出
后台线程

按当前配置马上导一份，不跑流程。

尚未导出
点『立即导出』按当前配置生成报表。

导出结果只显示在本面板；报表默认不阻断生产。

状态: 待执行 耗时: 0 ms
关键改动（v1）
01
四段纵向卡片改为两栏工作台左栏「来源 + 输出」负责“导什么”，右栏「选项 + 立即导出」负责“怎么导、现在导”；960 宽下不用来回滚动，640 窄档仍保持两栏并允许列内滚动。
02
路径从纯文本升级为“模板 + 实际路径”保留 SourcePathTemplate / OutputDirectoryTemplate / ReportFileNamePattern 原绑定；下方只读预览仍绑 SourcePathPreview / OutputPathPreview，不新增计算属性。
03
账本存在性前置沿用现有 SourceExistsText 的即时校验（File.Exists），改成带图标的行内状态：找到 = 绿、缺失 = 红、未配置 = 灰。没有新增文件读取或业务判断。
04
导出方式的条件行保留ExportPolicy=OnTrigger 时才显示「触发信号」行；仍用 EnumEqualsToVisibilityConverter + LinkableValueEditor，Port=TriggerPort、StepData 绑定不变。
05
选项按“内容”分组五个 CheckBox 的布尔绑定原样保留；用 WrapPanel 自动换行，640 窄档不会把「导出失败阻断流程」裁掉。
06
立即导出变成动作卡按钮入口在实现里走视图本地 ExportNowCommand（转发到 Plugin.ExportNow()）；IsExporting 经 InverseBoolConverter 置灰；LastResult 从一行彩字升级为结果面板（空闲/导出中/成功/失败四态）。
07
颜色全部令牌化映射 Dialog* / Plugin* 公共键；视图 XAML hex=0；不新增第二套蓝/灰，不改共享字典与共享控件。
08
五态与键盘可达输入框 / 下拉 / 按钮均有 hover、pressed、focus、disabled；图标按钮 30×30 且 Padding=0（R68）；焦点环走 DialogFocusVisual；ToolTip 走 DialogToolTipStyle。
契约保留（一个都不能改）
C1
DataContext = 插件实例 + IPluginConfigView宿主靠 viewObj.DataContext as IPluginConfigView 取 OnConfirm；不引入独立 VM，确认才会写回 InputValues。
C2
TriggerPort 的 LinkableValueEditorPort=TriggerPort、StepData 原样保留；该端口非必填，未连线不算参数缺失。本插件没有 BrowseCommand，因此不造「浏览」按钮。
C3
ExportPolicy / ExportPoliciesItemsSource=ExportPolicies、SelectedItem=ExportPolicy（枚举）；条目文案仍由 ExportPolicyLabelConverter 提供，值仍是枚举成员。
C4
五个文本配置属性SourceStepName / SourcePathTemplate / OutputDirectoryTemplate / ReportFileNamePattern / LinkColumn 全部保留 UpdateSourceTrigger=PropertyChanged。
C5
五个布尔配置属性FreezeHeader / AutoFilter / OnlyRowsWithImage / OpenAfterExport / BlockOnFailure 原绑定；不合并、不改默认值。
C6
导出入口与结果ExportNowCommand → ExportNow()；IsExporting 置灰、LastResult 展示。本插件没有 StatusLevel / Mode / SelectedCameraOption / DisplayViewIndex，不虚构这些绑定。
明确延后（需新增功能或契约）
D1
浏览 / 选择目录插件没有 BrowseCommand，也没有 LinkableValueEditor 之外的路径选择契约；本轮只保留手填 + 变量链接。
D2
打开报表 / 打开所在文件夹需要新增 Process.Start 行为；现有只有「导出后打开报表」布尔配置，不额外造按钮。
D3
账本行数 / 文件大小 / 最近导出历史需要新增只读属性或持久化字段；本轮不碰业务模型。
D4
加载骨架 / 进度条现有只有 IsExporting 布尔，没有进度/阶段信息；用「正在导出…」结果态代替，不新增第四档状态。
