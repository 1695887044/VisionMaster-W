## 4. 出稿顺序与理由

1. **第 1 批**：主界面常驻面板，用户每天看到，且硬编码色最多（`LogView` 51 处、`MonitorView` 23 处）。先做这批能立刻改变第一印象。
2. **第 2 批**：SCADA 编辑工作台。`scada-controls` 明确把宿主视图排除在外，是当前最大的设计真空。
3. **第 3 批**：设置类弹窗。使用频率中等，但都是"设置一次、长期不用"，风险低。
4. **第 4 批**：SCADA 弹窗族 + 运动板卡。数量多、单个小，最后批量处理。

## 5. 每份设计稿的交付物

按 `docs/UI设计基线/README.md` 与 `AGENTS.md` R126-R128：

```text
docs/UI设计基线/<页面名>/
  README.md      版本、覆盖范围、设计要点、令牌映射、复刻约束、已知偏差、未纳入项
  design.html    自包含、可点击、含默认态/关键状态/边界态
  evidence/      设计稿分段渲染 PNG（评审留档）
```

硬约束：

- 视图内 0 个十六进制色值，颜色全部映射到 `Colors.xaml` / `ScadaTokens.xaml` 的语义令牌（R117/R140）。
- 每个可交互控件五态齐全（R115）；加载/空/错误三态必须有明确视觉（R116）。
- 图标按钮 30×30 + `Padding="0"`（R68）；焦点 `DialogFocusVisual`，ToolTip `DialogToolTipStyle`（R135）。
- 数字等宽 `tabular-nums`；字号刻度 11/12/13/15/20；圆角 6/8/12/16。
- **不造死按钮**：只接现有命令与属性，新增功能进延后清单。
- 不改任何 WPF 代码：本轮只出设计稿，等用户逐页确认。
