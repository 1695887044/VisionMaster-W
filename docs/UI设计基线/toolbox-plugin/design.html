插件工具箱 v2 · 紧凑精修

范围：主界面「视觉图像 / 流程画布」右侧检查器里的 插件工具箱（ToolView）与它的收起胶囊。目标是“更精致、更小巧”：去掉重复标题、压缩行高与留白、把图标收进浅色徽章、给滚动条留 gutter；不改变拖拽、悬停预览、星标收藏、分组折叠、列表/网格切换这些既有交互。

1去掉重复标题停靠页签已经写「工具箱」，内容区再写一遍 14px 标题 + 26px 胶囊是重复信息。改成 24px 工具条：左侧 56 个算子，右侧列表/网格切换；首屏直接多出一行。
2图标进浅色徽章分类/算子图标从“裸彩色字形”改成 18/20px 圆角徽章，底色 = 分类色 12% 透明。既保留分类识别，又让行高更稳、视觉更安静。
3行高与留白列表 34→30、分组头 30→28、搜索 32→28、收藏提示 30→22；水平内边距 14→10，分组内容 4→4/4。整列密度提升约 12%，不靠缩字号。
4滚动条 gutterFluent 是覆盖式滚动条；滚动区右侧留 10px，卡片/分组头不再被滚动条压住。长名称统一 TextTrimming，不再硬裁。
5星标与搜索收藏星改成暖金色（语义色），默认隐藏、悬停显形；搜索命中片段用主色浅底高亮，输入后出现清空按钮。拖拽、悬停预览、分组折叠保持原行为。
6收起胶囊更小轨道 24→18，胶囊 20×64~100 → 16×48~72；图标 9px、标题 8px，悬停 2px 主色竖线。右栏收起时给画布多让 6px；WPF 保留 6px 右移避开窗口 resize border。

已知偏差（Web 设计稿 → WPF）

项处理
字体度量Web 与 WPF 的 Microsoft YaHei 行高/字宽略有差异；以 WPF 实测截图验收，不按 Web 像素死扣
滚动条Fluent 覆盖式 12px；WPF 用 10px 右侧 gutter + TextTrimming，不改成全局细滚动条
图标设计稿用 FA Solid 码点；WPF 复用现有 Icon 字体与分组图标，不新增图标资产
标题移除面板在浮动窗口里仍有窗口标题；ToolView 内不再重复“工具箱”
清空按钮/空态需在 ToolViewModel 增加 ClearSearchCommand / HasFilteredResults（小改，另行评审）
胶囊尺寸20→16 / 轨道 24→18 需要改 Shell.xaml 模板与冒烟断言，随 WPF 批次一起做；保留 6px 右移避开 resize border
