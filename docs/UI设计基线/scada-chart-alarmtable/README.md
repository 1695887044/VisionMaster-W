## 三个图元各解决什么

| 图元 | 回答的问题 | 与相邻图元的分工 |
| --- | --- | --- |
| 柱状图 | 几个对象**彼此比高低**（班次 / 设备 / 工位） | 趋势图管"随时间怎么变"；KPI 管"一个大数字" |
| 饼图 | 整体里**各占多少**（合计有意义时） | 合计无意义的量不要用饼图（用柱状图） |
| 报警汇总表 | 当前报警**清单 + 逐条确认 + 静音** | 报警条只读、滚动；报表管历史与导出 |

## 内部评审记录（2026-10-25，自评）

评审口径：`AGENTS.md` §30（视觉/状态/交互/令牌）、R73/R174（模板与绑定陷阱）、
R138/AX10（配置型数据每拍重读 + 指纹短路）、R140（颜色令牌）、R41（手册）。

| # | 发现 | 判定 | 处理 |
| --- | --- | --- | --- |
| V1 | **报警表的数据源是硬前置**：需要"当前活动报警列表 + 单条确认 + 静音状态"三样 API。若 `ScadaAlarmEngine` 只暴露聚合状态，本图元只能做成只读表 | **阻塞项** | 实现前先读引擎契约；不满足则先补 API（带断言），再画表。设计稿已按"可确认"出 |
| V2 | 柱状图负值时纵轴只按最大值算 → 负柱画到框外 | 修正 | §3 已改为"范围取 [min(0,min), max(0,max)]" |
| V3 | 超目标只变红，色觉差异用户看不出 | 修正 | 改为"变红 **+ 数值加粗** + 小三角"（三重编码） |
| V4 | 饼图图例用绝对坐标（`lx+250`）排数值，长标签会重叠 | 修正（实现注意） | 实现里用两列 `Grid`/`UniformGrid`，不用绝对坐标；设计稿演示不受影响 |
| V5 | 报警表每拍重建整表会打断操作员正在点的"确认"按钮 | 实现注意 | 与 AX10 同一纪律：**每拍重读 + 指纹短路**，只有变化才重建行；行内按钮按行 Id 定位 |
| V6 | 报警表"已确认"是否等于"消失"？ | 明确口径 | 确认 ≠ 消失：已确认未恢复的仍在表里（灰显）；恢复才消失。已写进 §9 |
| V7 | 新增 3 个 TypeKey 会让 Web 渲染器覆盖闸变红 | 实现注意 | 按 WR 例外清单登记 `KnownMissingWebRenderers`（+3）并同步计数断言，不假装已支持 |
| V8 | 饼图单一片 100% / 0 值片 | 实现注意 | 100% 画整圆（不走两段圆弧拼）；0 值片不画、图例不显示 0.0% |
| V9 | 报警表静音横幅是演示态常显 | 修正 | 实现里只在静音期显示；设计稿保留常显以便评审看到该状态 |

**评审结论**：设计可进入实现，但 **V1 未落实前不写报警表代码**（其余两条图元不受阻）。
三条修正已回写 `design.html`；四条"实现注意"进实现清单。

## 实现前置（开工前必须确认/补齐）

1. `ScadaAlarmEngine`：活动列表（含 `ActivatedAt / Severity / Name / ConditionText / TriggerValue / Acknowledged`）、
   单条确认（写审计 + 权限键 `ScadaPermissionKeys.Acknowledge`？）、静音状态（复用 `ScadaSoundAlarmService.IsMuted`）。
2. 列配置编解码：`BarSeries` / `PieSlices` 两个 bag key（与 `ReportColumns` 同一套 `ScadaReportCodec` 范式），
   含"空列丢弃、重复标签警告、变量名解析不到 → 灰柱/忽略并点名"。
3. Web 渲染器例外登记（+3）与 `[WR3]` 计数上限同步。
4. 手册：三个 TypeKey 各一页（R41 计数口径按"带 `[Display(GroupName=…)]` 的类"）。
