柱状图 / 饼图 / 报警汇总表 —— 设计基线 v1

三个图元，两个解决「对比」、一个解决「确认」。所有交互都能点；末尾 7 条待你拍板。

0 · 结论与取舍

柱状图 Hmi.BarChart

一个变量一根柱：班次产量、设备稼动、工位良率。
支持目标线与"超目标变红"。

饼图 Hmi.PieChart

占比构成：良率分布、报警级别占比、能耗构成。
支持环形与"小片并入其他"。

报警汇总表 Hmi.AlarmTable

当前报警清单 + 逐条确认 + 静音。
列固定、按级别与时间排序。

共同取舍：三者都不引入新数据源。柱/饼用「变量名 + 标签」的列表（与报表列同一套编解码范式）， 报警表直接读报警引擎的当前活动列表（与报警条同一份数据）。

1 · 柱状图：用途与属性

现场要回答的问题

「哪个班/哪台设备/哪个工位高、哪个低？」——趋势图回答"随时间怎么变"，柱状图回答"彼此比一比"。

典型：班次产量对比、设备稼动率、各工位良率、各通道计数。

属性（v1 就这些）

属性说明
数据列表：标签 + 变量名 + 颜色(可选)，按名字解析变量
方向竖向 / 横向（横向适合标签长）
最大值0 = 自动取最大柱；>0 固定（同一屏多图对齐时用）
目标值0 = 不画；>0 画一条虚线，超过的柱变红
显示数值柱顶/柱尾标数值
排序保持配置顺序 / 降序 / 升序
数值格式如 F0 / P1，空 = 0.###

各工位产量（今日）

3 · 柱状图：状态与边界

状态表现
设计期画等高的 4 根灰柱 + 提示「设计期不读变量」，不连数据
无数据空坐标系 + 居中「没有配置数据列」
部分缺失缺失柱画灰色斜纹 + 图例标「未解析」，其余照常
超目标该柱变红 且数值标签加粗（不只靠颜色，色觉差异用户也能看出来）+ 柱顶小三角，不闪烁（闪烁留给报警条）
柱数过多> 24 根时自动转横向并缩字号；> 60 根提示"改用数据表格"
负值以 0 为基线向下画，颜色同主色；纵轴范围取 [min(0, 最小值), max(0, 最大值)]——只按最大值算会把负柱画到框外
不做：堆叠柱、分组柱、双 Y 轴。它们会让属性面板从 7 项涨到 20 项，而现场 95% 的对比是一根柱一个量。 真要多系列时用「多趋势」或「数据表格」。

4 · 饼图：用途与属性

现场要回答的问题

「整体里各占多少？」——饼图只在"合计有意义"时成立（良品+不良=总数、各类能耗=总能耗）。

典型：良率分布（良/不良类型）、报警级别占比、能耗构成、停机原因占比。

属性

属性说明
数据列表：标签 + 变量名 + 颜色(可选)
形态实心 / 环形（环形中间可显示合计或标题）
显示百分比 / 数值 / 两者 / 不显示
图例右侧 / 底部 / 不显示
小片合并0 = 不合并；如 0.03 = 小于 3% 的并入「其他」
起始角默认 -90°（12 点方向起，顺时针）

6 · 饼图：状态与边界

状态表现
设计期4 等分灰饼 + 「设计期不读变量」
合计为 0空心圆 + 「本班没有计数」（不是画一个满圆）
单一片 100%整圆 + 图例只有一项；不显示"0.0%"的零片
负值忽略该片并在图例标「负值已忽略」——占比里没有负数
片数过多> 8 片自动启用「其他」合并（阈值 2%），并在图例注明合并了几项
不做：3D 饼、多环、饼+柱混合。饼图本身只适合"少数几类看占比"，超过 8 类一律建议换柱状图。

7 · 报警汇总表：用途与列定义

它和「报警条」的分工

报警条：页面顶部一条，滚动显示最新几条，只读，让人"知道有事"。

报警汇总表：一页里的完整清单，能确认、能静音，让人"把事处理掉"。

两者读同一份活动报警列表，不各存一份。

列（固定，不可配）

列内容
级别圆点 + 文字（严重/警告/提示）
时间触发时刻 HH:mm:ss
名称 / 说明报警定义名 + 触发条件摘要
当前值触发值（读不到显示 —）
状态未确认 / 已确认（已恢复的自动消失）
操作确认（需权限）

列固定是刻意的：这是操作件，不是报表。要自定义列请用数据表格。

当前报警

点「确认」会把该行变灰并标已确认；确认按钮在只读态下整列消失（不是灰掉——灰掉会让人以为"再点一下就好"）。

9 · 报警汇总表：权限 / 状态 / 空态

状态表现
无报警绿底空态「系统正常 · 当前没有报警」，不显示表头
有未确认严重级行左侧 3px 红条 + 级别圆点；表头显示「未确认 N 条」
已确认整行变灰，操作列按钮消失
只读（无确认权限）操作列整列隐藏；表头右侧标「只读」
静音中表格上方一条浅黄提示「已静音 30 分钟 · 严重级仍会响」+「取消静音」
条数过多按「级别 → 时间倒序」排，超出 MaxRows（默认 50）时表内滚动，不翻页
报警恢复行立即消失（活动列表语义）；历史请用报警历史/报表
确认与静音不是一回事：确认 = "我看到了"（逐条，写审计，带操作者）； 静音 = "先别响"（全局、限时、严重级不受影响）。两个按钮放两处：确认在行内，静音在顶栏。

10 · 选型速查

想要用
几个对象比高低（一班/一台/一个工位）柱状图
整体里各占多少（合计有意义）饼图
随时间怎么变趋势 / 多趋势
一个大数字 + 单位KPI 板 / IO 域
知道有报警（只读、滚动）报警条
处理报警（确认、静音）报警汇总表
一段时间 + 汇总 + 导出打印报表

Q3 饼图默认形态：环形还是实心？（本稿环形）
