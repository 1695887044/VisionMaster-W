为什么去掉「流程 ▸」子菜单：当前 12 项里有 9 项藏在二级菜单里，每次都要多一次悬停； 而菜单本身只有 320px 宽、12 项在 512px 高度内放得下。分组标题（流程 / 配置 / 运行 / 方案） 比子菜单更快扫读，也让「批量设置显示窗口」这类新命令有固定归属。

C · 变体：双行说明式（340px，与步骤菜单同款）零新样式面，但菜单总高约 660px

C1 · 默认态（完整 12 项）
取舍：双行式直接复用 StepContextMenuStyle / StepMenuItemStyle （44px 行、28px 图标底片、13/11px 双行、页脚），与流程栏步骤右键完全一致，不需要新增任何样式； 代价是 12 项 × 44px + 4 个分组标题 ≈ 660px，在 1366×768 这类窗口高度下会超出可视区 （模板里的 ScrollViewer 会接管，但滚动菜单不好用）。

建议：默认用 A（320px / 32px 行 / 512px 高）；如果后续菜单项还要增加， 或者希望"和步骤菜单长得一模一样"，再切到 C，并同时把「流程管理 / 变量事件」挪到二级。
