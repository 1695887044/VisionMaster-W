## 2. 分批实施计划

### 批次 0：参考实现（已完成）

- `Plugin.ImageAcquisition`：设计基线 v2 + `ContentControl` 预览宿主 + 24 条 UI 冒烟 + 5 张渲染证据 + gate 2691/0。
- 作为其余插件的模板；不重复改造。

### 批次 1：低风险表单型（10 个）

**顺序**：

1. `Plugin.Utility` / `VariableAssignmentView`（144 行，无 HALCON）
2. `Plugin.CodeReader`（168，单预览）
3. `Plugin.DlClassify`（192，单预览 + 少量 Numeric）
4. `Plugin.Yolo`（209，单预览）
5. `Plugin.ExcelExport`（266，无 HALCON）
6. `Plugin.ImageScript`（291，无 HALCON）
7. `Plugin.CSharpScript`（299，无 HALCON）
8. `Plugin.ResultDisplay`（360，无 HALCON）
9. `Plugin.DataRecord`（416，4 个 Linkable，无 HALCON）
10. `Plugin.ResultUpload`（570，无 HALCON）

**特点**：以表单/列表为主，HALCON 画布最多 1 个；适合先打通 SOP 的静态/运行时冒烟模板。
**风险**：`DataRecord`/`ResultUpload` 的端口/命令较多，需逐项核对 `OnConfirm`；`ResultDisplay` 有文字位置/九宫格等已有断言（R39），不要碰其业务逻辑。

### 批次 2：单画布 / ROI / 多端口（9 个）

**顺序**：

1. `Plugin.ColorRegion`（248，单画布）
2. `Plugin.Ocr`（248，单画布）
3. `Plugin.CreateRoi`（249，ROI 画布）
4. `Plugin.ColorCheck`（331，ROI 画布）
5. `Plugin.PoseTransform`（315，11 个 Linkable 端口）
6. `Plugin.PreProcessing`（402，画布 + 2 个 PropertyGrid）
7. `Plugin.CaliperMeasure`（563，画布 + 51 Numeric）
8. `Plugin.Matching`（667，2 画布 + 60 Numeric）
9. `Plugin.Calibration`（779，画布 + 28 Numeric；已有 `--calibration` 冒烟可扩展）

**特点**：HALCON 画布/ROI 交互是核心；必须遵守"不要折叠已设图的画布"规则，优先保持画布常驻或按需创建。
**风险**：`CreateRoi`/`CaliperMeasure`/`Matching`/`Calibration` 的画布交互已有专门断言（`CreateRoiChecks`/`CaliperMeasureChecks`/`MatchingChecks`/`CalibrationChecks`），改 UI 前先确认这些断言仍能跑；不要在 XAML 里替换 `ImageEdit`/`ImageReadOnly` 控件。

### 批次 3：大型多面板（2 个）

1. `Plugin.BlobDetect`（933，2 画布 + 98 Numeric + 12 DataGrid）
2. `Plugin.BeadInspect`（1013，2 画布 + 18 DataGrid + 5 Linkable）

**特点**：多画布 + 数据网格 + 大量数值参数；UI 改动面最大，放最后。
**风险**：`BlobDetectChecks`/`BeadInspectChecks` 已有像素级断言（R36/R37/R38），改 UI 前先跑一遍基线；不要在视图里复制离屏烘焙逻辑（R36）。

### 每批的执行纪律

- **一次只改一个插件**；当前插件 UI 冒烟全 PASS、gate 0 失败、文档落盘后，再开下一个。
- 每个插件按 SOP §5.0→§5.10 顺序；设计基线先确认再改 WPF。
- 每个插件一份 `docs/code-changes/YYYY-MM-DD-<plugin>-Web化.md`，按 SOP §10 模板写"改动点 / 与 ImageAcquisition 差异 / 验证 / 遗留"。
- 每批结束做一次批次汇总：变更清单、冒烟/渲染/gate 结果、遗留问题；最后做全项目汇总。

## 3. 不改造清单（无自定义视图）

以下项目/类**不实现** `IPluginCustomViewProvider`，走框架 `AutoPortConfigView` 或纯驱动/算法路径，本 SOP 不修改：

| 项目 | 说明 |
| --- | --- |
| `Plugin.Camera.Hikvision` | 相机驱动，无自定义配置视图 |
| `Plugin.Camera.Network` | 网络相机驱动，无自定义配置视图 |
| `Plugin.GeometryFinder` | 走框架自动参数面板 |
| `Plugin.GeometryRelation` | 走框架自动参数面板 |
| `Plugin.ImageAssign` | 走框架自动参数面板 |
| `Plugin.Motion.Steps` | 运控步骤，走框架自动参数面板 |
| `Plugin.Motion.Virtual` | 虚拟运动驱动，无自定义配置视图 |
| `Plugin.Motion.ZMotion` | 正运动驱动，无自定义配置视图 |
| `Plugin.RunFlow` | 走框架自动参数面板 |

**特例**：`Plugin.Utility` 项目里只有 `VariableAssignmentPlugin` 实现自定义视图；同项目的数学/逻辑/比较/类型转换等插件走自动参数面板，**不改造**，只改 `VariableAssignmentView.xaml`。
