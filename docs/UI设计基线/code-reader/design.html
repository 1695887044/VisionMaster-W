关键改动（v1）
01
单页两栏，配置与预览同屏左 356px 配置轨、右预览工作区；不再把试算结果埋在按钮下面，结果区独立成块。
02
图像输入只保留唯一入口LinkableValueEditor 绑定 Image 端口；本插件没有文件浏览功能，所以没有「浏览」按钮，也不新增。
03
码制家族可读码制下拉仍绑 Symbology（存 HALCON 原始名）；右侧家族徽标由 Is2D 驱动，二维码参数卡只在二维时出现。
04
预览是只读工作区保留 ImageReadOnly；无图时用纯 WPF 空态，有图才由 DataTemplate 创建控件，避免折叠后不重绘。
05
试算结果与提示分层Hint 讲「下一步怎么做」，ResultSummary 只放试算输出；不把结果混进提示文字。
06
全令牌化颜色映射 Colors.xaml / PluginConfigColors.xaml；视图内零十六进制，不改共享字典。
07
五态与键盘可达hover / pressed / focus / disabled 全量；图标按钮 30×30 + Padding=0（R68），焦点环走 DialogFocusVisual。
08
只读信息不冒充配置输出端口只做静态说明（Codes / Count / Text），不新增可编辑控件，也不改变端口契约。
契约保留（一个都不能改）
C1
DataContext = 插件实例 + IPluginConfigView宿主靠 viewObj.DataContext as IPluginConfigView 取 OnConfirm；不引入独立 VM。
C2
LinkableValueEditor(Image)Port={Binding Image}、StepData={Binding StepData} 原样保留；HImage 端口不可文本输入，只显示占位与 🔗。
C3
ImageReadOnly.HImage = DisplayImage经 ContentControl + DataTemplate 承载，模板内 HImage="{Binding Mode=OneWay}"；控件类型、缩放、右键菜单不变。
C4
Symbology / Polarity / TimeoutMs码制与极性用 SelectedValue + SelectedValuePath 存 HALCON 原始值；超时仍是 int 的 TextBox 绑定。
C5
试算 / 提示 / 结果TryPreviewRecognize()、Hint、ResultSummary、Is2D、两个选项集合原样消费；本插件没有 Mode / SelectedItem / StatusLevel，不凭空添加。
明确延后（需新增功能或契约）
D1
加载骨架 / 蓝色加载态需要 VM 新增 IsPreviewLoading 或状态枚举；当前只有 Hint / ResultSummary 两段文字。
D2
图像尺寸 / 文件大小需要 VM 新增只读属性（HImage.GetImageSize / FileInfo.Length）；本稿预览头只显示「上游图像 · 只读」。
D3
放大 / 缩小按钮HalconBase 只有 FitToWindow() / FitToImage()，没有公开 zoom；本稿只保留「适应窗口 / 1:1」。
D4
打开所在文件夹 / 系统导航需要新增 Process.Start 或宿主导航契约；本插件图像来自上游端口，没有文件路径，故不提供。
D5
试算三档状态 / 耗时需要 VM 新增 StatusLevel / 耗时属性；本稿只用结果区文字表达，不扩展状态枚举。
