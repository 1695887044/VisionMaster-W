## 定位

本文件是「Web 设计基线 → 用户确认 → WPF 复刻 → 同屏截图验收」四步流程的**第 ① 步**产物，口径沿用
`docs\UI设计基线\插件自定义视图Web化改造SOP.md`（R126-R132）与 R111（落纸六项：布局 / 间距 / 配色令牌 /
字号字重 / 五态 / 交互细节，见 `design.html` 的 S5）。

Web 只作设计媒介：**不进入构建、不部署、不作为第二客户端维护**（R126）。它也不是 R191 暂停的 `Web\` 工程方向。

## 一句话方向

**把"选变量名"从行内控件收敛成一个弹窗**：名字列变成只读块（名字 + 设备 + 类型 + 状态徽标），点它开窗；
弹窗左侧是**按设备分组**的虚拟化候选列表（搜索 + 类型筛选），右侧是选中项详情；运行时作用域多一个"直接用列表外的名字"出口。

## v2 变更（2026-10-29 晚，用户提出）

**问题**：两台 PLC 都有变量 `A`，选择器无法区分，也没法说明"这个 A 是哪台设备的"。

**v2 改了什么**：

| # | 改动 | 位置 |
| --- | --- | --- |
| 1 | 列表按设备分组（组头 28px 吸顶：设备名 + 协议 + 在线点 + 计数），组序 = 设备 → 本地变量 | S1 列表 |
| 2 | 同名跨设备时行内出现设备 chip（Warning 色）；只在一台存在时不重复显示 | S1 行 / S0 名字块 |
| 3 | 详情卡「来源」显示 `设备「L1」· Modbus TCP` | S1 详情 |
| 4 | 搜索同时匹配设备名，结果保留分组 | S1 工具行 |
| 5 | 新增状态卡「同名跨设备」（L1/L2 都有 `Alarm[90]`） | S3 第 5 态 |
| 6 | 行内名字块加设备 chip；提示改为「写入设备「L1」的全局变量…」 | S0 |
| 7 | 数据结构：`VariableOption` 加 `DeviceName`/`IsNameDuplicated`，`AssignmentRow` 加 `VariableId`，运行期按 Id 写 | 方案书 §5.7 |

**为什么必须连数据结构一起改**：只改界面会得到"两行看起来不同、写下去还是同一个"的半成品 ——
候选快照现在按名字去重（`PluginVariableOptions.cs:55-67`），第二台设备的同名变量**根本进不了下拉**；
运行期又只按名字写（`IGlobalVariableWriter.cs:26` 无 Id 重载）。详见方案书 §5.7。

## 为什么改（Step 0 探针实测，2026-10-29）

| 场景 | 实测 | 结论 |
| --- | --- | --- |
| 全局候选浮层 2,414 条（现实现） | 打开 **5,741 ms**，实例化 **2,416** 个容器 | `ItemsControl` 结构上不虚拟化 |
| 全局候选浮层 10,000 条 | 打开 **8,671 ms**，实例化 **10,002** 个容器 | 线性恶化，几万条不可用 |
| 运行时名字下拉 2,414 条 | 打开 **4,358 ms**，实例化 **2,414/2,414** | Fluent ComboBox 模板**也不虚拟化** |
| `LinkableValueEditor` 封闭集合下拉 10,000 项 | 填充 2 ms，打开 **7,433 ms**，实例化 **10,000** | 同族隐患（通讯变量名会撞上） |
| 目标形态原型 5,000 条 | 首次布局 **265 ms**，只实例化 **6** 行，过滤 **26 ms** | 虚拟化 + `ICollectionView.Filter` 可达 |
| 32 行 × 2,414 条重建 | **559 ms**，累计 **1,274,592** 个候选对象 | 按行复制候选的二次项 |

## 已知偏差（设计稿 vs 现实现）

| # | 项 | 说明 |
| --- | --- | --- |
| 1 | 交互次数 | 改一行名字从"点开浮层 + 选"（2 次）变成"点开弹窗 + 选 + 关"（3 次）；缓解：`Enter` 直接确定并关闭，实际是"点开 + 回车" |
| 2 | 弹窗宽度 | 880 是设计值；若宿主弹窗容器固定 1180（与 `VariableBindingView` 一致），横向留白增加，列表可变宽 |
| 3 | 颜色令牌 | 设计稿用 `#vp-*` 变量表达；WPF 复刻必须映射到 `UI\Controls\Themes\Colors.xaml` 的既有令牌（R140），不得新增 hex |
| 4 | 设备身份 | 用连接名（`NetworkVariableModel.ConnectionName`）表达，仓库里没有独立"设备 Id"；连接改名后组标签跟着变，但写入按 `VariableId`，不受影响 |
| 5 | 组头吸顶 | Web 用 `position:sticky`；WPF 需 `ListBox.GroupStyle` + `VirtualizingPanel.IsGrouping=True`，观感可能有 1~2px 差异，须在复刻验收时逐项核对 |
