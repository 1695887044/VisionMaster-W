变量名选择弹窗 · 设计基线

v2

用途：「变量赋值」名字列（以及后续 DataRecord / ResultUpload / CSharpScript 等所有"写到哪个变量"的字段）的唯一选择入口。 本稿把现在的行内浮层 + 可编辑下拉收敛成一个弹窗：名字列变成只读块，点它开窗。

v2 增补：全局变量按所属设备分组。两台 PLC 都有 Alarm[90] 时，v1 只能显示两行同名； v2 用组头（设备「L1」/ 设备「L2」/ 本地变量）+ 同名行设备 chip 表达归属，并按 VariableId 寻址写入。

依据（Step 0 探针实测，2026-10-29）：全局浮层 2,414 条打开 5.7 s / 实例化 2,416 个容器； 运行时下拉 2,414 条打开 4.4 s / 2,414 个容器；目标形态（虚拟化列表）5,000 条只实例化 6 行、过滤 26 ms。

本稿是 R111/R126/R128 的设计基线（HTML 媒介）：不进入构建、不部署、不作为第二客户端维护。 它不是 R191 暂停的 Web\ 工程方向。审查通过后按本稿复刻 WPF，验收以"同一屏、同一状态"截图对照。

5五态

  • 候选行：默认 / 悬停（Surface-2）/ 聚焦（2px Primary 内缩描边）/ 选中（Primary-Soft + 左条）/ 失效（Danger-Soft + 红字 + 不可选）。
  • 按钮：默认 / 悬停（Primary-Strong）/ 按下（同悬停 + 内阴影由平台给）/ 聚焦（2px 外描边）/ 禁用（40% 透明 + 禁点）。
  • 搜索框：默认 / 聚焦（Primary 描边 + 2px 光晕）/ 有内容（右侧出现清除 ✕）/ 禁用不出现。
  • 输入（运行时手输）：默认 / 聚焦 / 非法（红边 + 行内原因，如"名字不能含空格"）。

6交互细节

  • 打开：点行内名字块（整块，含键盘 Space/Enter）→ 弹窗；当前名字若在列表里则选中并滚到可见；不在列表里则出现在顶部"已失效"项。
  • 搜索：输入即过滤（150 ms 去抖不必加，过滤本身 26 ms / 5,000 条）；高亮命中片段；同时匹配设备名（输入 "L2" 可只留 L2 的变量），结果保留分组不扁平化。
  • 分组：按设备（连接名）→ 本地变量；组头 28px 吸顶，显示 设备名 + 协议 + 在线点 + 计数；组内按名字排序。
  • 同名消歧：同一名字在多台设备上存在时，行内出现设备 chip（Warning 色）；只在一台上存在时不重复显示（组头已表达设备）。
  • 类型筛选：下拉选项来自候选类型去重；与搜索是"与"关系。
  • 确定：写回名字并关闭；未改动时确定等同取消（不写）。
  • 运行时手输：输入非空且不在列表 → 「使用」可用；点击后直接写回并关闭（不要求再点确定）。
  • 失效项：可选（用于"保留原名字"），确定时原样写回；不自动替换、不静默清空。
  • 关闭：Esc 两段式（先清搜索再关窗）；点遮罩不关闭（防误触丢选择）。
