交互规则

  • 确认开关挂在事件钩子上，不是单条动作上；一次确认覆盖整串动作。
  • 默认关闭，老工程行为不变；勾选后才弹窗。
  • 确认文案可自定义；留空走默认「确定执行『对象』的『事件』操作吗？」。
  • 动作表里出现 停止流程 / 轴停止 / 轴失能 时，编辑器显示「危险动作」标记，弹窗用红色主按钮。
  • 无动作时不弹确认框（执行侧本来就把空动作表当没配）。

复刻约束

  • 复用现有 ScadaEventEditor 与 ScadaEventEditorViewModel，只加一行开关 + 一个文本框，不新开控件。
  • 文案与错误提示复用现有 ScadaSecondaryTextBrush / ScadaWarningBrush，不新增颜色。
  • 不改变现有事件勾选/动作表的布局与顺序；确认行放在事件勾选框下方、动作表上方。

弹窗规则

  • 字段只用 MessageDialog 现有槽：Title / Message（对象·事件）/ Hint（动作摘要 + 后果）/ Question（是否继续）/ 双按钮。
  • 普通动作：Warning 图标 + 主色主按钮；危险动作：Danger 图标 + 红色主按钮。
  • 默认焦点始终在「取消」；Enter = 取消，Esc = 取消，Y 也取消（危险场景不再无条件触发主操作）。
  • 确认 = 按动作表顺序执行；取消 = 一条动作都不执行，记 Warn 日志 + 一条审计「Skipped」。
  • 权限不足：不弹确认、不执行、提示无权限（权限闸门在扫钩子之前）。
  • 无弹窗环境（断言/离线）→ 返回 false，按取消处理，绝不静默放行。

复刻约束

  • 弹窗走 MessageDialog.Show(options)，替换现有 ScadaConfirmationService 里的 EasyDialog。
  • 不新增弹窗控件；沿用 Dialog* 令牌与 MessageDialog 的焦点/键盘契约。
  • 不承诺副标题/结构化详情：MessageDialog 现有槽位只有 Message/Hint/Question；设计稿已按此收敛。
  • 480 为默认宽；轴控台长文案实测不够时用 560 宽档。

状态规则

  • 运行中：「启动」禁用、「暂停」可用、「恢复」隐藏/禁用、「停止」可用、「复位」禁用。
  • 已暂停：「恢复」变主按钮、「暂停」禁用、「启动」禁用、「停止」仍可用、「复位」禁用。
  • 暂停在节点边界生效，不是立即冻结当前节点；页面状态以引擎回报为准。
  • 只有连续运行可暂停；单次执行（RunOnce）不支持暂停，动作会跳过并记 Warn，不能报“已暂停”假成功。
  • 恢复从当前步继续；停止后不能恢复，只能复位/重新启动。
  • 切换手动：运行中先确认并暂停；已暂停可直接切。
  • 状态驱动：推荐在「暂停」钩子里同时放 PauseFlow + WriteVariable(Paused=1)，「恢复」钩子放 ResumeFlow + WriteVariable(Paused=0)；页面用该变量 + 可见性/外观动画显示“已暂停”。P0 不新增流程状态源。

复刻边界

  • 自动页是用户组态页面模板，不是固定 WPF 视图；WPF P0 提供的是「暂停流程/恢复流程」动作类型与运行态行为。
  • “已暂停”由同钩子的 WriteVariable 驱动，不依赖新的流程状态源；模板演示该配置。
  • 设计稿为同屏缩略，按钮高 22px；WPF 复刻用 Hmi.Button 的 30px 档，禁用不隐藏。
  • 按钮的五态（Normal/Hover/Pressed/Focus/Disabled）沿用现有按钮样式，不新造。

暂停 / 恢复语义

  • 暂停：流程存在且连续运行中 → 请求引擎暂停；未运行/单次执行 → 跳过并记 Warn；已暂停 → 幂等成功。
  • 恢复：流程存在且运行中 → 请求引擎恢复；未运行 → 跳过并记 Warn；未暂停 → 幂等成功（本就运行）。
  • 暂停不是急停：它停在节点边界，已下发的动作不撤回；急停仍走停止/轴停止。
  • 停止后不能恢复，只能复位或重新启动。

复刻映射

  • ScadaEventHook.RequireConfirmation + ConfirmationMessage：事件钩子字段，老 .vms 缺省为关闭/空。
  • ScadaActionType.PauseFlow = 16 / ResumeFlow = 17：末尾追加，不改既有数值。
  • IScadaFlowRunner.Pause/Resume → IFlowEngine.PauseSession/ResumeSession。
  • ScadaActionDispatcher.Dispatch：动作执行前过确认闸门；取消则整串跳过。
  • ScadaConfirmationService：由 EasyDialog 换成 MessageDialog（Warning/Danger，默认焦点取消）。
  • ScadaEventEditor：事件勾选框下方加确认开关 + 提示文本框；动作行加两个流程动作触发器。
