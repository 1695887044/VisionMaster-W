为什么需要它

  • 旧方案没有结果输出步骤：它们用 <工位>_Result 变量；显式配置后不用再靠命名约定猜。
  • 判定表/逻辑运算直接给 bool 端口：步骤端口模式不用额外加变量。
  • 自动模式保留回退链：结果输出步骤 > 配置变量 > 配置端口 > 约定变量 > 未判定。
  • 不改流程图：不自动插入步骤、不自动改变量；配置只影响宿主解析。
