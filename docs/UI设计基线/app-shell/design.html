动效与焦点

· 悬停 / 选中底色：120–150 ms ease
· 运行脉冲：1.6–1.8 s 循环，仅运行态
· 菜单 / 右键 / 通知：120–180 ms 淡入 + 位移
· 遵循 prefers-reduced-motion，动效可关闭
