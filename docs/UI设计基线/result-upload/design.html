关键改动（v1）

      

        
01

        
报文预设改为 2×2 卡片4 个 RadioButton 套卡片模板，IsChecked 仍走 EnumConverter 写 PayloadKind；切换后的 IsFieldTable / IsNotify / IsRawJson 与预览刷新逻辑原样触发。

      

      

        
02

        
左配置、右报文左侧回答「发到哪、怎么发、什么时候发」；右侧把「字段表 + 模板 + 实际发出 + 测试发送」放在同一工作区，字段表获得完整宽度，不再挤在 540px 的单列里。

      

      

        
03

        
字段表仍是唯一入口Fields / Headers 的 ObservableCollection 绑定、AddField() / AddHeader()、行内删除事件全部保留；来源=端口的字段仍生成动态输入端口。

      

      

        
04

        
报文预览升级为深色工作区绑 PayloadPreview（只读、实时）；组报文失败时以红色显示「无法预览：原因」，与真实发送共用同一套 HttpPayloadBuilder。

      

      

        
05

        
连接参数分层URL / 超时常驻；请求头、钉钉加签、证书校验收进「高级连接」折叠区。四个属性与命令绑定不变，生产参数不再和发送策略混在一起。

      

      

        
06

        
测试发送与日志同卡TestSend()、IsTesting（置灰）、LastResult（成功绿 / 失败红）、RecentLogs（最近 50 条）集中展示；刷新按钮只调既有 RefreshRecentLogs()。

      

      

        
07

        
颜色全部令牌化映射 Colors.xaml / PluginConfigColors.xaml；只在本视图派生样式，不改共享字典与共享控件。视图 XAML 十六进制颜色 = 0。

      

      

        
08

        
五态与可达性hover / pressed / focus / disabled 全量定义；图标按钮 30×30 且 Padding=0（R68），焦点环走 DialogFocusVisual，ToolTip 走 DialogToolTipStyle。

      


      
契约保留（一个都不能改）

      

        
C1

        
DataContext = 插件实例 + IPluginConfigView宿主靠 viewObj.DataContext as IPluginConfigView 取 OnConfirm；不引入独立 VM。

      

      

        
C2

        
TriggerPort 的 LinkableValueEditorPort / StepData 原样保留；只在「上报时机=触发端口」时显示。

      

      

        
C3

        
字段表 / 请求头集合ObservableCollection<UploadFieldDef> / ObservableCollection<HttpHeaderDef>；行内删除走 Fields.Remove / Headers.Remove，不换集合、不改持久化。

      

      

        
C4

        
枚举与 int 类型PayloadKind / SendTiming / FieldSource / BuiltInField 仍是枚举；TimeoutMs / RetryCount 仍是 int，setter 的夹取规则不变。

      

      

        
C5

        
命令与结果TestSend()、IsTesting、LastResult、RecentLogs、RefreshRecentLogs() 原样消费；不新增命令。

      

      

        
C6

        
PasswordBox 桥请求头值仍走 PasswordBoxHelper.BoundPassword（只打码不加密，持久化仍是明文随方案保存）。

      


      
明确延后（需新增功能或契约）

      

        
D1

        
加载骨架 / 发送进度条需要 VM 新增 IsPreviewLoading 或进度属性；本版只用 IsTesting 置灰 + 「正在发送…」文案。

      

      

        
D2

        
字段拖拽排序需要新的拖拽行为与集合重排逻辑；本版保持「添加 / 删除」两动作。

      

      

        
D3

        
模板语法高亮需要自绘编辑器；本版用等宽文本框 + 帮助文字说明占位符。

      

      

        
D4

        
日志导出 / 清空需要新命令；本版只保留「刷新」。

      

      

        
D5

        
请求头导入 / 导出需要文件 IO 与新的持久化格式；本版保持手工增删。

      

      

        
D6

        
连通性探测需要新的网络行为；本版用「立即发送」做真实验证。

      


      
状态清单（本页可点击）

      

        
S1

        
默认态MES 字段表；sn / result 走端口，time 走内置时间戳；URL 已填；预览显示三字段 JSON；日志为空或最近三条。

      

      

        
S2

        
发送中「立即发送」置灰，结果区显示「正在发送…」，日志追加 INFO。

      

      

        
S3

        
成功结果区绿色「✔ HTTP 200（业务成功）」，日志 INFO；成功关键字命中。

      

      

        
S4

        
失败结果区红色「✘ HTTP 500 …」，日志 ERROR；失败原因可读。

      

      

        
S5

        
空 URLURL 清空；预览仍可看；点「立即发送」返回「✘ 请先填目标 URL」，不发起请求。

      

      

        
S6

        
空字段字段表删空；预览显示「无法预览：字段表没有启用的字段…」；仍可继续编辑。

      

      

        
S7

        
通知 / 原始 JSON字段表变成占位符值池；通知模式显示内容模板，原始 JSON 模式显示 JSON 模板；预览随之切换。
