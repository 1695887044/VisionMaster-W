关键改动（v1）
01
两栏信息架构左栏「账本文件 + 图片记录」配置轨，右栏「列定义 + 试写」工作区；配置与表格分离，列多时只滚表格、不推走配置。
02
列定义表重做6 列行：启用 / 列名 / 来源 / 取值 / 格式 / 删除；来源切换后取值单元格在「端口编辑器 / 变量名输入 / 内置字段下拉」三态间切换，仍是同一份 RecordColumnDef。
03
端口编辑器按需创建只有 Source=Port 的行才创建 LinkableValueEditor；非端口行不再实例化空端口编辑器（批量冒烟要求每个编辑器 Port != null）。
04
图片记录模式卡片3 档「不存图 / 仅NG存图 / 每件存图」卡片；非「不存图」时才创建图片端口编辑器，切回「不存图」立即销毁，端口重建仍由 PortsVersion 驱动。
05
试写结果状态化把裸文本升级为「未试写 / 成功 / 失败」三态横幅，只消费既有 TestResult 的 ✔/✘ 前缀；不新增 StatusLevel 或写入状态属性。
06
全令牌化与可达性视图零十六进制；代码后置的硬编码绿/红改为 DialogSuccessTextBrush / DialogDangerTextBrush 查找；图标按钮 30×30 + Padding=0（R68），焦点走 DialogFocusVisual。

v1 明确延后（需新增功能或契约）
D1
加载 / 写入中骨架需要 VM 新增 IsWriting 或 WriteState；当前只有 TestResult 文本。
D2
账本文件大小 / 行数需要 VM 新增只读属性（FileInfo.Length / 行数统计）；v1 不显示。
D3
打开记录目录需要新增 Process.Start("explorer.exe", ...) 行为；v1 只显示路径模板。
D4
列模板导入 / 导出需要新的序列化与文件对话框契约；v1 只做逐列编辑。
D5
列拖拽排序需要拖放行为与撤销；v1 顺序由添加顺序决定，删除后可重新添加。
D6
账本内容预览需要读取 CSV 的只读服务；v1 用「测试写一行」验证。
