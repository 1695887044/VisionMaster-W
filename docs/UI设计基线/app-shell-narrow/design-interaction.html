A / B 交互细化：控制台怎么收、专注怎么退

A = 控制台 32 ⇄ 240；B = 专注图像时左右栏 0 ⇄ 340/320。两套动作互不干扰：专注只动左右栏，控制台保持进入前的状态。

设计媒介，不是交付物（R126）。尺寸按 1310×829 DIP；控制台裁切为 1:1，专注整帧按 0.68。

实现落点：
  • Shell 新增 IsImageFocusMode；进入时记下左右 pane 的 DockWidth、可见页签、选中页，再按现有 HidePanel 收起两侧全部 anchorable；退出按相反顺序 ShowPanel 并还原宽度。
  • 浮动 pill 与边缘手柄是 Shell 停靠区上的覆盖层（Grid.Row=2），只在 IsImageFocusMode 时可见；不要写进 AvalonDock 模板。
  • Esc 用窗口级 KeyBinding，并在有模态窗口时让路；Ctrl+Shift+F 只在视觉图像文档选中时生效。
  • 退出专注必须走在 ApplyShellMode 之前，否则模式收敛会与恢复逻辑互相覆盖。

设计稿只表达交互与状态，不代替真机像素级验收（R129/R132）。A 的抽屉条与 B 的左右栏恢复都要在真窗口上验一次：进入/退出各一次、切模式各一次、重启一次。
