模式边界调试/自由显示胶囊；组态模式右栏是属性/图层/图元，胶囊规则相同；运行模式右栏隐藏，胶囊不显示

实现落点（第一版，2026-10-26）：
  • 已实施：AvalonDock 的 auto-hide 页签是库内部控件（实测 LayoutAnchorable.TabItem=null，视觉树只有左栏页签），拿不到实例换模板；改用 Shell 覆盖层 InspectorCapsuleRail（24px 轨道、20×64~100 胶囊、点击钉回 300 列）+ ShellViewModel.InspectorCapsules。见 app-shell-narrow/README.md §9.4。
  • 未做：300 覆盖浮层、滑出动画、Esc/点外部收回、跨模式保留（切模式按模式默认恢复）、计数徽标。浮层若要做，需要自定义承载面板内容，不能依赖库的 auto-hide tab。
  • 持久化：ApplyScadaPanelMode/ApplyShellMode 的 respectUserHidden 让启动/布局加载不把已收起的工具箱 Show 回来；布局里的 Hidden 状态就是持久化，不需要额外 CollapsedPanels 属性。
  • 图钉沿用库的 auto-hide 命令；AutoHideWidth=300 已加到 4 个右侧面板（为后续浮层预留）。
