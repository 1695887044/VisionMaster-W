流程栏（ProcessView）· 设计基线 v2

设计媒介，不是交付物（AGENTS.md R126）。v2 方向：更平、更轻、层级更清楚—— 分组头改为整行 section bar，状态改用柔和底色，分支改为整行子标题，去掉多余的描边与胶囊。

  • 分组头 = 整行 section bar：左侧 3px 身份色条 + 类型标签 + 名称，右侧「2 分支 · 2 算子」与状态图标。分组是"章节"，不再是一个小胶囊。
  • 状态用柔和底色，不用硬描边：失败 #FEF2F2、运行 #F0FDF4；状态列仍保留感叹号/脉冲点，色盲可辨。
  • 分支 = 整行子标题：浅蓝底 + 1px 发丝边，计数右对齐；悬停时底色与描边各提一档。空分支用虚线框。
  • 算子行 40px / 分支 32px / 分组 36px：4px 节奏，行内信息两行（名称 + 类型），耗时右对齐。
  • 运行态脉冲：蓝点 1.6s 扩散环，表达"此刻在跑"；成功只留绿点，不抢色。
  • 数字等宽：计数、耗时、统计行用 tabular-nums，纵向对齐不跳动。
  • 图标块 26px / 圆角 7：比原来的 24px 更松弛；失败/运行行上改用白底，避免与行底色糊在一起。
  • 层级引导线：#E2E8F0 发丝线，14px 缩进；不再用几乎看不见的 #EEF2F7。

4. 相对现状的变更点

前半是 v1 已确认的功能性修正（仍适用），后半是 v2 的现代化改版。

#现状基线理由
1失败：算子红边 + 名字前 ×；等待节点只有红点；容器只有红 !统一：状态列感叹号 + 名字红 + 类型行红 + 柔和红底；容器同样处理；去掉 ×同一语义三套画法；× 易误读为关闭
2失败步骤名字右移约 15px标记进状态列，名字始终对齐同层步骤名必须共用竖线
31 算子：10px #A8ABB211px #66708A，右对齐、等宽数字原对比度 2.2:1
4分支胶囊吞掉悬停反馈整行分支自己响应悬停分支是拖放落点
5容器名 12px 常规13px SemiBold层级不能反转
6容器名无 ToolTip补 ToolTip="{Binding StepName}"截断后可看全名
7等待节点图标重复与算子行同构：第二行「等待 · 条件」，不单独占 chip冗余
8引导线 #EEF2F7#E2E8F0（1.23:1）原线基本不可见
