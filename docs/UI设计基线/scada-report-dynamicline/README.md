## 要回答的两个问题

### Q：报表看着都是死数据，能绑什么？

**绑的是列，不是表**：每列配 `表头 + 绑定变量 + 列宽 + 对齐 + 格式串`；
**行来自 CSV 账本**（方案目录 `History\yyyy-MM-dd.csv`），按时间范围查询。
设计期刻意不查数据（只画空表 + 一句提示），所以看起来"死"——运行态进页即查。

报表的定位是「**一段时间 + 汇总 + 能导出/打印**」：
班次报表（交接班签字）、日报月报（导出给主管）、追溯明细（回查某批次）。

### Q：动态画线到底干嘛用？

一条从中心出发的线，**长度**和**角度**是两个独立的数据属性，各自可绑一个变量：

- 液位 → 长度（0~100% 伸缩）；
- 阀开度 / 风向 → 角度（0° 向右、顺时针）；
- 两者一起 = 一个图元表达两个自由度（动画通道做不到）；
- **段数 > 1** = 锯齿折线，用来示意振动 / 料流 / 抖动。
