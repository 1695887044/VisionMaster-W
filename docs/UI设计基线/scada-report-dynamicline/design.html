报表图元 & 动态画线 —— 它们解决什么问题

这不是新功能说明书，而是回答两句现场话：「报表看着都是死数据，能绑什么？」、 「动态画线到底拿来干嘛？」。所有交互都能点。

0 · 一句话结论

报表不是「把变量贴到表里」，而是把 CSV 账本按时间段取出来，做成班次报表 / 日报，并能导出 Excel、打印。 你绑的不是整张表，是每一列绑哪个变量；行来自历史流水，所以设计期看起来是空的——这是刻意的。

动态画线是一条从中心出发的线，长度和角度各自可以绑一个变量，所以一条线能被两个量同时驱动 （液位定长短、阀开度定方向）；段数 > 1 就变成锯齿，用来示意振动 / 料流 / 报警抖动。

1 · 报表图元到底是什么

它做三件事

取数按时间范围（今天 / 本班 / 自定义）从 CSV 账本里捞记录。

成形明细逐行照抄；汇总按班次分组算（产量 / 合格数 / 合格率 / 均值…）。

带出画面导出 xlsx / csv、打印带页脚页码——这是「把数据带出画面」，所以走权限与审计。

它不做什么

✗ 不做实时刷新显示（那是「数据表格」的活）。

✗ 不做趋势曲线（那是「趋势图」的活）。

✗ 不做数据录入（报表是只读视图）。

一句话：报表回答「昨天这班干了多少、合不合格」，不是「现在这个值是多少」。

2 · 三个误区，逐个拆

1
「看着都是死数据」
设计器里看到的空表 + 一句提示是刻意的（设计期不查数据：否则一选中图元就去读盘、甚至弹文件对话框）。 运行态一进来就按默认范围查一次，之后由「刷新间隔」或手动刷新驱动。
✓
实际行为：进页即查 → 表格出数 → 顶条显示「共 N 行 · 查询耗时 xx ms · 上次刷新 hh:mm:ss」。 无数据时是「该范围内没有记录」，不是空白表。
2
「没办法绑定」
能绑，但绑的粒度是「列」不是「表」：每列配 表头 + 变量名 + 列宽 + 对齐 + 格式， 运行时按变量名去账本里取值。一张 6 列的班次报表 = 6 个变量 + 5 个聚合口径。
✓
为什么不做「整表绑一个变量」：一个变量只有一个值，一张表要几十行 × 几列。 真正的数据源是账本（CSV 历史），列配置只是「告诉报表该显示哪几列、怎么格式化」。
3
「想象不到用途」
最典型的三张表：班次报表（每班产量/合格率，交接班签字用）、 日报/月报（按天汇总，导出给主管）、追溯表（某段时间某批次的明细，出问题回查）。
✓
判断标准：需要「一段时间的记录 + 汇总 + 能导出/打印」→ 用报表； 只想「看最近几条」→ 用数据表格。

                        │

                        ▼
              ┌───────────────────────────┐
              │ 明细模式：逐行照抄          │──▶ 屏幕分页（每页 N 行）
              │ 汇总模式：按班次分组聚合     │──▶ 导出 xlsx / csv（整份结果，不是当前页）

账本由已有的历史记录链路写入；报表不产生数据，只读。没有账本时报表显示「未接入历史数据源」。

4 · 配置三步（右边可点）

① 选范围与模式：时间范围（今天 / 本班 / 最近 7 天 / 自定义）、明细 or 汇总、刷新间隔。

② 配列：点「配置列」弹编辑器——每行一个列：表头、绑定变量、列宽、对齐、格式串。

③ 配外观：标题、斑马纹、行高、每页行数；导出/打印按钮是否显示、需要什么权限。

列编辑器里「变量名」是按名字解析的（与绑定同一口径），填错不会崩，运行时该列显示「—」并在日志点名。

配置列（设计器弹窗） ＋ 添加列
表头绑定变量宽度对齐格式
时间时间140左HH:mm:ss
产量产量0（占满）右F0
合格数合格数90右F0

宽度填 0 = 占满剩余；变量名为空的行确认时会被丢掉。

5 · 运行态（可点：切模式 / 翻页 / 导出）

班次生产报表
范围 共 24 条记录 当前账号：操作员 · 可导出/打印

点「导出 xlsx」只会弹一条模拟回执——真实实现里这一步会先判权限（按下前），成功后写审计（谁 / 什么范围 / 多少行 / 写到哪）。

6 · 什么时候用报表，什么时候别用

你想要该用为什么
看最近 20 条采样，切页就没了也没关系数据表格实时缓冲，轻；不需要聚合与出纸
看某个量最近 1 小时的曲线趋势图 / 多趋势报表是表格形态，不做曲线
交班时要一张「本班产量 / 合格率」的表，签字、导出 Excel报表按范围取数 + 聚合 + 导出打印 + 审计
客户要查上个月某批次每一件的明细报表（明细 + 自定义范围）分页只渲染一页，几千行也不卡
想看一个数现在是多少IO 域 / 数值显示报表不承担实时读数

7 · 动态画线是什么

一条从控件中心出发的线。它只有两个「会动」的数据属性：

长度占控件短边的比例 0~1，可绑变量 → 线随值伸缩。

角度度，0 = 向右，顺时针为正，可绑变量 → 线随值转动。

段数1 = 直线；> 1 = 锯齿折线（幅度可调），用来示意振动 / 料流 / 抖动。

和「动画」通道的区别：动画是「一个值 → 图元的某个外观」（位置、尺寸、透明度）， 一条线只能吃一个值。动态画线把长度和角度拆成两个独立的数据属性， 所以能同时被两个变量驱动——这是动画通道表达不了的。

8 · 两个独立数据属性，意味着什么

液位定长短

长度绑 T101.液位%：0% 缩到中心，100% 顶到边。

开度定方向

角度绑 V201.开度：0° 向右，90° 向下（顺时针）。

两个一起用

风向标 / 机械臂姿态 / 料流方向 + 流量：一个图元吃两个量。

9 · 现场演示（拖滑杆 = 模拟变量在变）

Hmi.DynamicLine · 属性面板等价物
线（主色） 控件中心 控件边界（短边 = 长度 100%）
Length=0.62　Angle=35　Segments=1
段数 > 1 的画法：沿主线方向来回折（锯齿），幅度按控件短边比例算。 它不是「多段折线编辑器」，是「一条会抖的线」——用于振动、料流、报警抖动的示意，不做精确轨迹。

10 · 用途清单（现场真会用到的）

场景绑什么效果
罐体液位指示Length ← 液位%（0~100）液位越高线越长，与旁边的罐体图元呼应
阀门开度 / 风向标Angle ← 开度（0~360）线跟着转，一眼看出方向
料流 / 泵出口Length ← 流量，Angle 固定有流量才伸出来，停泵就缩回
振动 / 报警抖动Segments=6~12，Length 固定锯齿示意抖动；报警时再用闪烁
机械臂姿态示意Angle ← 关节角度，Length ← 臂长一个图元表达两个自由度

11 · 选型速查

需求图元
一段时间 + 汇总 + 导出打印报表（Hmi.Report）
最近 N 条实时缓冲数据表格（Hmi.DataGrid）
一个值 → 位置/尺寸/透明度动画（任意图元都能挂）
一个值 → 线的长短或方向动态画线（Hmi.DynamicLine）
两个值 → 长短 + 方向动态画线（这就是它存在的理由）
固定管身 + 流向箭头管道（Hmi.Pipe）/ 管线（Hmi.PipeRun）
