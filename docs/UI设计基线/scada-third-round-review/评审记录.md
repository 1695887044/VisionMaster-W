## 一、轴面板 `Hmi.AxisPanel`（证据最充分）

**图**：`axispanel-unconfigured.png`（未配置轴，按钮与状态区完整可见）

### 应用工程师（工艺 + 电气·运动）

| # | 发现 | 级别 |
| --- | --- | --- |
| A1 | 状态区八个点（使能/到位/运动/原点/报警/正限位/反限位/急停）**只靠灰/亮区分** | ~~P1~~ → **用户裁定不改** |
| A2 | 命令区只有 5 个按钮位：使能、点动◀、点动▶、回零、停止、清报警。**"失能"没有独立按钮**——是"使能按钮再点一次"还是根本不允许失能？规则不可见 | ~~P1~~ → **不是问题**：使能是切换开关，绿=使能、灰=失能 |
| A3 | 未配置轴时整块显示"未配置轴"，但按钮仍可点（图像上按钮是正常态）——点了会怎样？应整块禁用并给原因 | P1 |
| A4 | 位置显示 `— mm`、目标 `— mm`：**"下发值"与"实际值"没有标签区分**，只有两个 `— mm` 一上一下 | P2 |
| A5 | "设计预览（运行后显示实时值）"这句在运行态会消失，但设计期与运行期差异没有其它提示 | P3 |

### 前端设计师

| # | 发现 | 级别 |
| --- | --- | --- |
| U1 | **停止按钮是红底**且与其它按钮同尺寸——危险分级做对了一半：停止该更宽/更靠边（触摸误触时最先够到的是它） | P2 |
| U2 | 点动模式（连续/单步）是分段控件，位置在"点动"标题**上方**，视觉上属于"速度"那一组，分组归属含糊 | P2 |
| U3 | 六个按钮的命中区约 76×32，触摸屏上偏小（目标 ≥ 44 高）；按钮间距 6px 也偏紧 | P1 |
| U4 | 状态点与文字的基线不齐（点 8px、字 12px），整块看起来"毛" | P3 |
| U5 | 未配置轴时右上角"未配置轴"是灰色小字，与正常态无差异——空态应更明确（整块降饱和 + 居中提示） | P2 |

### 运动安全评审

| # | 发现 | 级别 |
| --- | --- | --- |
| S1 | **未配置轴时按钮不禁用**：这是"点了没反应"与"点了动错轴"之间最危险的一档（A3 同条） | P1 |
| S2 | 停止按钮在任何状态下都必须在、都可点——图上成立；但**没有"命令已下发/已到位"两态区分**（R99），操作员会以为按下即到位 | P1 |
| S3 | 急停状态点只作为状态显示，**没有与"停止"按钮的联动说明**（急停断开时点动是否仍可发） | ~~P2~~ → **不处理**：需要时在流程里断使能，界面层不重复兜底 |

## 四、裁定表

> **用户裁定（2026-10-25）**：A1（状态点只靠颜色）**不改**；A2（失能入口）**不是问题**——轴使能本来就是
> 切换开关，使能态绿色、失能态灰色，点同一个控件切换；S3（急停与点动）**不处理**——需要时在流程里断使能，
> 界面层不重复兜底。其余结论全部认同。
> **P1 由 8 条调整为 6 条**：未配置轴按钮禁用、命中区 44、下发/实际值标签、表格两种空态、设计期列头、报警条未接源。
