高级参数
序列分析（日常保持默认）

默认 35%：比线间缝再暗 35% 的对比度幅度才算可靠的暗线。线色普遍偏浅时调小。

默认 92：亮度最高的 8% 视为白线。日志出现「丢弃过长可靠区间」时把它调小。

默认 4 行：连续这么多行都可靠才算一根线，用来滤掉噪点。

默认 0.33：一根线不可能占掉剖面三分之一以上，占到了就是背景混进来了；填 0 = 不做保护。

默认 0.30：给「补出来」的那几根取色时的窗口半宽，单位是线距的比例；线距很密时调小。

颜色判据阈值（13 项，随方案落盘）

阈值编辑器是共享控件 ColorThresholdEditor，本版不改其外观与参数名。

配方按实测根数匹配

一行一条：产品名 = 颜色1,颜色2,...；井号开头是注释；颜色词只有 黑/白/灰/紫/蓝/绿/黄/红/玫红/橙 才认得出来；某一位写 * 表示这一位不检。

运行期按实测根数匹配（期望序列的长度就是这条配方要求几根）；另有「期望序列」输入端口，端口填了就以端口为准。

怎么用

① 在流程里把本节点的 Image 连到上游；② 打开本窗口点「执行」，上游图像显示在右侧；③ 在图上右键 → 新建矩形，框住整条线束；④ 再点「执行」或「试算一下」核对结果。

第一次点「执行」会报「尚未框选采样区」——那是对的：此时图已经上屏，框完再执行一次即可。

本算子认「一维颜色序列」（线序 / 色带 / 排线通用），矩形长轴判为线束走向；要检「一块区域是什么颜色」请用「区域颜色检查」。

输出运行结果

0 = 不投射；1~9 对应主界面视图窗口。
