设计要点与契约保留
1
模式是卡片，不是单选2×2 卡片（像素当量 / 九点 / 透视 / 网格）；WPF 仍是 RadioButton + EnumConverter 写回 Mode，类型不变。
2
标定图只包裹、不替换LinkableValueEditor 的 Port/StepData/BrowseCommand 原样保留；只把标签外置、浏览按钮外置。路径已链接变量时外置浏览/空态选择按钮隐藏（链接态写端口值不会触发 ValueChanged）。
3
标定表是工作区行状态（有效/半填/空）用点名颜色区分；「取点」「预填」逐行命令不变；表格仍是 ItemsControl 绑 PointRows。
4
内参标定折叠默认收起，避免长期占屏；展开后字段、命令、结果区与现状一一对应，不改变内参业务语义。
5
画布常驻ImageEdit 不因无图而 Collapsed；空态/错误态是画布上方 Auto 行信息条（HwndHost 会盖住 WPF 覆盖层）。HImage / DrawObjectList / ActiveRoi / Annotations / IsPickMode 绑定逐字保留。
6
取点态前置橙色横幅盖在画布上方，一眼分清「点图是取点」还是「拖标记」；只接现有 IsPickingPoint / PickHintText / CancelPickCommand。
7
状态只有三档StatusLevel = Info / Warning / Error；颜色走 DialogSuccess/Warning/Danger 令牌，不新增第四档。
8
全令牌化视图 XAML 零十六进制颜色；使用 Dialog* 与 PluginPreview* 既有公共令牌，不修改共享字典。
C
契约保留C1 DataContext=插件；C2 LinkableValueEditor；C3 ImageEdit 画布；C4 Mode/SelectedItem/Command；C5 StatusMessage/StatusLevel 三档；C6 导入导出/锁定/内参命令。
D
明确延后加载骨架、文件大小、放大/缩小、打开所在文件夹、系统导航；均需新增功能或契约，本版不做。
