检查参数随方案落盘

多个用逗号分隔，命中任一即可；写 * 表示只报颜色不判定。颜色词只有 黑 / 白 / 灰 / 棕 / 红 / 玫红 / 橙 / 黄 / 绿 / 蓝 / 紫。

0~1，默认 0.6（60%）；区域里有反光 / 边界过渡时适当调低。

主色：红（占 96%） 中位色：R214 G38 B42（采样 400 点） 明细：红:96%、暗红:3%、灰:1% 判定：合格　红 96% ≥ 60%

高级参数

默认 400；区域很大时不必调大，抽稀是均匀的，投票不会偏。

0 = 不投射；1~9 对应主界面视图窗口。

颜色判据阈值（13 项，随方案落盘）

阈值编辑器是共享控件 ColorThresholdEditor，本版不改其外观与参数名。

怎么用

① 在流程里把本节点的 Image 连到上游；② 打开本窗口点「执行」，上游图像显示在右侧；③ 在图上右键 → 新建矩形 / 圆形 / 椭圆，框住要检的那块；④ 填期望颜色，再点「执行」或「试算一下」核对。

第一次点「执行」会报「尚未框选采样区」——那是对的：此时图已经上屏，框完再执行一次即可。

本算子认「一块区域是什么颜色」（不看顺序）；要检线序、排线、一排色带的顺序，请用「颜色序列检查」。两者共用同一套颜色词与判据。
