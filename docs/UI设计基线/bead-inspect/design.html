关键改动（v1）
01
两栏固定分工左侧 330px 设置轨（可滚动），右侧画布工作区自适应；取消左右拖拽条，画布获得稳定余量。
02
画布是唯一主操作面工具栏 + 结论横幅 + 画布标题 + 操作提示 + 画布 hero 同卡；参数、点列、预览全部在左栏，画布不再被下方卡片挤压。
03
点列是紧凑复核表1 个 DataGrid（4 列：# / Row / Col / 删），行高 28、单元格内边距 8,2；编辑提交仍走 CellEditEnding。
04
配方库前置选型 → 载图 → 拾取的第一步；列表行显示点数与学习状态，新增 / 删除 / 设为默认三个入口不变。
05
结果横幅常驻视口学习 / 自动提取 / 矫正的结论挂在工具栏正下方，空串折叠；三档颜色复用 ActionBannerLevel。
06
状态条两行StatusMessage + BaseImageHint 常驻；底图是输入图兜底时用 Warning 色提示坐标系风险。
07
结果预览常驻ImageReadOnly 不再随无图折叠；无图时是纯 WPF 覆盖层，有图时控件从未折叠过，避免恢复后不重绘。
08
全令牌化 + 五态颜色全部走 Dialog* / Plugin* 公共令牌；按钮 hover / pressed / focus / disabled 全量；图标按钮 30×30 + Padding=0。
v2 增量（补 5 个既有属性的界面入口）
V1
④ 像素当量(mm/px)PixelSizeMm 落在「碎段过滤」右侧同列，区间 0~1000（NumberValidationRule）。只在「输出单位 = 毫米」且未接标定 Transform 时兜底，0 = 未填。
V2
④ 输出对齐图OutputAlignedImage 用 DialogCheckBox（15px 方框 / 4px 圆角），与像素当量同行右列、底对齐；取消 = AlignedImage 输出为空，对齐本身照做。
V3
⑤ 最低分数 / 金字塔层数MinScore 0~1、PlanarNumLevels 1~10 且 IntegerOnly；接在搜索范围网格第 4 行，与既有 6 个字段同款 32px 输入框 + 等宽数字。
V4
① 抽稀目标点数ExtractTargetPoints 10~500 且 IntegerOnly，放在「自动提取输入（可选）」折叠区最后一行；下方常驻一句 「仅本次配置会话生效，不落盘」——它不是 [StepConfig]，InputValues 仍是 25 个键。
V5
不改插件、不加令牌5 个属性在插件上本来就存在；本版只加视图入口，全部复用既有 BeadInput / BeadFieldLabel / BeadHint / DialogCheckBox，未新增任何共享令牌。
