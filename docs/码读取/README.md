## ⚠️ 最需要记住的两条

1. **本节点不做定位**——它只吃一张上级已经裁好的小图。上级裁剪时要**把码完整包住、留点余量，别贴边裁**（`reduce_domain` 后码没完全落在域内会找不到）。
2. **没读到码不算失败**——`Success=true` + `Count=0`，只写 Info 留痕。判定交给下游用 `Count` 做。

## 维护约定

1. **只改主文档**。`码读取插件.md` 是唯一事实来源；归档件只作历史留档，不再更新。
2. **新增码制**只改 `CodeSymbology.cs` 的表，并在主文档 2.4 节同步码制表。存盘值用 HALCON 原始名，查不到时报明确错误，**不静默退回默认码制**。
3. **修 bug 必须同时补回归断言**（`FlowCanvasChecks/CodeReaderChecks.cs`），并在主文档第 4 章记录「现象 → 原因 → 修法」。
4. **新增参数前先确认该家族的 `set_*_param` 是否真的接受**（一维不接受 `polarity`，会 `#3286`）。多一个旋钮就多一处要现场理解的东西。
5. **引擎句柄必须在 `Dispose` 里释放**（基类管不到引擎内部句柄）。
6. **HALCON 相关新坑**统一追加到主文档 4.5 节的踩坑表。
