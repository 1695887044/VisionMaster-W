## 三、验收口径

### A · StateView

- 一个 TypeKey `Hmi.StateView`，不新增 `GraphicSwitch`/`GraphicIO`/`WordLamp`。
- 属性：`Value`、`StateListId`、`Presentation`（Text/Image/TextAndImage；不用 `Both`，避免与 Line 的 `Both=双向` 撞译名）、`Interaction`（None/Toggle/WriteValue）、`ClickValue`、`ImageStretch`；`StateListMissing` 只读。
- 列表条目：`Image`（方案内相对路径）、`Color`（#AARRGGBB 文本）、列表级 `DefaultImage`；旧 `.vms` 为空时行为与 P1-1 文本态一致。
- 列表优先；缺失不静默回退 Options；无匹配用 DefaultText/DefaultImage；图片缺失虚线占位。
- 点击只在 `Interaction != None` 且权限/写通道/绑定齐备时写回；写成功发 `ObjectChanged`，二态补 `Opened/Closed`。
- 管理器显示 Image/Color 列；引用数同时统计 ComboBox + StateView。
- 断言：模型/序列化、列表优先、缺失、无匹配、图片解析、只读、Toggle/WriteValue、权限拒绝、版本刷新、管理器副本写回。

### B · SubPage P1a

- 一个 TypeKey `Hmi.SubPage`，固定页 + 只读；`TargetPageId/Name`、`Fit`、`ShowBackground`、`MissingBehavior`（占位/保留上次）。
- 目标页只允许普通页；禁止弹窗页、自引用、A↔B 循环；缺页/无权/未选都有明确占位，不显示空白页。
- 嵌套画布数据绑定必须活：SubPage 自己持有 `ScadaRuntimeBinder`（或等价方案），卸载 `Stop()` 退订阅；不要求子页交互事件。
- 断言：目标页解析、循环拒绝、缺页/无权/未选、绑定刷新、卸载无订阅残留、固定页不随导航变化。

### C · 位操作

- `ScadaActionType` 末尾追加 `SetBit=24`、`ResetBit=25`、`ToggleBit=26`；不动 1~23。
- `ScadaAction.BitIndex` 可空；`null` = Bool 整体写，`0..31` = 整型位号。
- dispatcher 复用 `_values.TryResolve` + `handle.Value` + `handle.TryWrite`；整型读-改-写，越界/非整型/非 Bool 拒绝并写清原因；审计文案与 `WriteVariable` 同句式。
- 动作编辑器显示变量 + BitIndex；Bool 变量可留空，整型必须 0~31。
- 断言：Bool 置位/复位/取反；整型 bit0/bit31/越界；变量缺失；写失败；`Describe`/`Detail`；枚举数值稳定性。

## 四、构建与验证

- 构建一律 `dotnet build <csproj> -m:1 -nodeReuse:false`；判据 **0 个错误且退出码 0**。
- 角色只构建自己涉及的工程；共享注册/接线由主会话完成后跑全量。
- 主会话最终跑 `tools\run_gates.ps1`（至少 `ScadaChecks` + `UIThemeSmokeTest` + `FlowCanvasChecks`），并核对日志条数。
- 任何角色发现必须改共享文件，**只报告，不改**；由主会话统一落。

## 五、评审

三项集成、构建、断言通过后，主会话再派一个只读评审角色，按以下口径逐项检查：

1. 契约与旧 `.vms` 兼容（新增字段为空时的行为）。
2. 线程/生命周期（SubPage binder 卸载、StateView 列表订阅、位操作写通道）。
3. 权限与失败路径（StateView 点击、SubPage 无权、位操作越界）。
4. 规则红线（R1/R3/R68/R140/R179/R182；无 Web 改动、无报警改动）。
5. 断言是否覆盖“正常 + 失败 + 反向”三类；是否存在只测 happy path。

评审只报告，不改代码；主会话按报告决定修复或留待下一批。
