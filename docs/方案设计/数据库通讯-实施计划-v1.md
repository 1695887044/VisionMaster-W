### 2.1 SQLite 可离线构建运行（实跑证据）

本机 NuGet 缓存已有全套包：`Microsoft.Data.Sqlite 8.0.10`、`SQLitePCLRaw.{core,bundle_e_sqlite3,lib.e_sqlite3,provider.e_sqlite3} 2.1.6`。

## 五、契约草案（M1 定稿，之后不再改签名）

```csharp
namespace Core.Interfaces.Database;

public enum DbProviderKind { Sqlite }                 // v1 只有一种；将来加成员不破坏
public enum DbOpenMode { ReadWrite, ReadOnly }
public enum DbStatementKind { Query, Execute, WriteRow }
public enum DbErrorKind { None, Transient, Deadlock, Timeout, Constraint, Syntax, Permission, NotFound, Unknown }

public sealed class DbProfileInfo
{
    public Guid ProfileId { get; init; }
    public string Name { get; init; } = "";
    public DbProviderKind Provider { get; init; }
    public string FilePath { get; init; } = "";        // 只给界面展示；日志里按需脱敏
    public DbOpenMode OpenMode { get; init; }
    public int TimeoutSeconds { get; init; }
    public int MaxRows { get; init; }
    public bool IsEnabled { get; init; }
}

public sealed class DbStatementParameter
{
    public string Name { get; init; } = "";            // 不含 '@'
    public string DbType { get; init; } = "Text";      // Text/Integer/Real/Boolean/DateTime/Blob
    public bool IsRequired { get; init; }
    public string DefaultValue { get; init; }
    public string Description { get; init; } = "";
}

public sealed class DbStatementInfo
{
    public Guid StatementId { get; init; }
    public Guid ProfileId { get; init; }
    public string Name { get; init; } = "";
    public DbStatementKind Kind { get; init; }
    public string SqlPreview { get; init; } = "";      // 插件窗口只读预览
    public IReadOnlyList<DbStatementParameter> Parameters { get; init; } = Array.Empty<DbStatementParameter>();
    public int TimeoutSeconds { get; init; }
    public int MaxRows { get; init; }
    public int MaxAffectedRows { get; init; }
    public bool IsEnabled { get; init; }
}

public sealed class DbParameterValue
{
    public string Name { get; init; } = "";            // 不含 '@'
    public object? Value { get; init; }
}

public sealed class DbCommandOptions
{
    public int TimeoutSeconds { get; init; }
    public int MaxRows { get; init; }
    public int MaxAffectedRows { get; init; }
    public CancellationToken CancellationToken { get; init; }
}

public sealed class DbQueryResult
{
    public IReadOnlyList<string> Columns { get; init; } = Array.Empty<string>();
    public IReadOnlyList<IReadOnlyList<object?>> Rows { get; init; } = Array.Empty<IReadOnlyList<object?>>();
    public int RowCount { get; init; }
    public bool Truncated { get; init; }
    public double ElapsedMs { get; init; }
}

public sealed class DbExecutionResult { public int AffectedRows { get; init; } public double ElapsedMs { get; init; } }
public sealed class DbBatchResult { public int SucceededRows { get; init; } public int? FailedRowIndex { get; init; } public double ElapsedMs { get; init; } }
public sealed class DbTestResult { public DbQueryResult? Query { get; init; } public DbExecutionResult? Execution { get; init; } public bool RolledBack { get; init; } public double ElapsedMs { get; init; } }

public interface IDatabaseAccess
{
    // 元数据（纯本地，不连库）
    IReadOnlyList<DbProfileInfo> ListProfiles();
    bool TryGetProfile(Guid profileId, out DbProfileInfo info, out string? error);
    IReadOnlyList<DbStatementInfo> ListStatements(Guid profileId);
    bool TryGetStatement(Guid statementId, out DbStatementInfo info, out string? error);

    // 连接
    bool TryTest(Guid profileId, out string? versionText, out double elapsedMs, out string? error);

    // 执行（一次调用 = 一个事务）
    bool TryQuery(Guid statementId, IReadOnlyList<DbParameterValue> parameters, DbCommandOptions options,
                  out DbQueryResult result, out string? error);
    bool TryExecute(Guid statementId, IReadOnlyList<DbParameterValue> parameters, DbCommandOptions options,
                    out DbExecutionResult result, out string? error);
    bool TryExecuteBatch(Guid statementId, IReadOnlyList<IReadOnlyList<DbParameterValue>> rows, DbCommandOptions options,
                         out DbBatchResult result, out string? error);

    // 测试（默认事务内执行后 ROLLBACK；commitForReal=true 才真写，UI 必须二次确认）
    bool TryTestStatement(Guid statementId, IReadOnlyList<DbParameterValue> parameters, DbCommandOptions options,
                          bool commitForReal, out DbTestResult result, out string? error);
}
```

要点（实现时逐条对照）：

1. **不暴露** `DbConnection/DbTransaction/DbDataReader`；连接与事务在服务内 `using` 释放。
2. 所有方法**同步**（与 `ICommVariableAccess` 一致），插件在工作线程调用；`CancellationToken` 进 `DbCommandOptions`。
3. `TryGetStatement` 按 `StatementId` 全局唯一（不是"profile 内唯一"），简化插件侧寻址。
4. `NullDatabaseAccess` 每个方法返回 `false` + 中文原因（"当前执行环境没有接入数据库服务"），插件只判返回值。
5. `ListProfiles`/`ListStatements` 允许返回空集合；`TryGetXxx` 取不到给 `NotFound` 语义的中文原因。

## 六、里程碑明细

### M1 · 契约 + `Core.Database`（3~4 人日）

**做**

1. `Core.Interfaces\Database` 全套 DTO + `IDatabaseAccess` + `NullDatabaseAccess`（§五）。
2. `DatabaseStore`：`databases.json`（exe 同目录），`SchemaVersion=1`；读失败→空库+日志，写盘 temp + `File.Replace`/`File.Move(overwrite)`，**同时 catch `IOException` + `UnauthorizedAccessException`**（R180）。
3. `DatabaseService`：
   - profile/语句的 CRUD（宿主页用；插件只读元数据）；
   - `SqliteConnectionStringBuilder { DataSource, Mode = ReadWrite|ReadOnly, Pooling = true }`；
   - 每连接 `PRAGMA busy_timeout=<TimeoutSeconds*1000>`；**不改 `journal_mode`**（不擅自改用户库的持久属性）；
   - 一次调用 = 一个事务；`Query` 用只读命令，`Execute/WriteRow/Batch` 显式事务；
   - `MaxRows`：读 `MaxRows+1` 行判断 `Truncated`，超出部分丢弃；
   - `MaxAffectedRows`：事务内执行后取影响行数，超限 → **回滚** + `Constraint` 类错误；
   - 取消：`CancellationToken` 注册 `command.Cancel()`；
   - 错误分类：`SqliteException.SqliteErrorCode`（5 BUSY / 6 LOCKED → `Transient`；19 → `Constraint`；8 READONLY → `Permission`；1 → `Syntax`；其它 → `Unknown`），错误文案带 SQLite 错误码与"下一步建议"；
   - 审计日志：profile 名、语句名、Kind、行数、耗时、错误类别、`Environment.UserName`；**不记参数值、不记 SQL 全文**（记 SQL 的 SHA256 前 8 位）。
4. `StatementValidator`（保存时 + 执行前各跑一次）：
   - 单条语句（去掉注释与字符串字面量后，不允许分号后还有非空内容）；
   - 参数占位符 `@name` 与参数表**双向一致**（缺/多都拒）；
   - `Query`：只允许 `SELECT`/`WITH`，或只读 PRAGMA 白名单（`table_info`/`table_list`/`index_list`/`foreign_key_list`）；禁 `ATTACH`/`DETACH`/写 PRAGMA；
   - `Execute`：`UPDATE`/`DELETE` 必须含 `WHERE`；v1 拒绝 DDL；
   - `WriteRow`：只允许 `INSERT`（含 `ON CONFLICT` 的 UPSERT），单行。
5. `DatabaseModule`：注册 `DatabaseService` 为 `IDatabaseAccess` 单例 + `DatabaseStore`；退出任务 `Dispose`（清池）。
6. 单元自测（先写在 `DatabaseChecks` 里，M4 补全分层）：参数化（把 `' OR 1=1 --` 当**值**传，必须只当值）、事务回滚、截断、影响行数超限回滚、只读档拒写。

### M2 · `Plugin.Database` 三步骤 + 视图（3~4 人日）

**共用基类 `DatabasePluginBase : VisionPluginBase`**

```csharp
[StepConfig] public Guid ProfileId { get; set; }
[StepConfig] public Guid StatementId { get; set; }
[StepConfig] public ObservableCollection<DbStatementParameterDef> Parameters { get; set; }  // 模式快照 + 值
[StepConfig] public bool FailFast { get; set; }        // 写默认 true，读默认 false
[StepConfig] public int TimeoutSeconds { get; set; }   // 0=用 profile 值
public override void ApplyConfigValues(IStepConfigData stepData) { base.ApplyConfigValues(stepData); RebuildParameterPorts(); }
protected void RebuildParameterPorts() { /* 每个参数一个 InputPort<object>，名字=参数名，IsRequired=必填且无默认 */ }
```

- 参数端口**必须**在 `ApplyConfigValues` 重建（运行实例不走 `Initialize`）。
- 参数值来源：已链接 → 运行时从端口取值；未链接 → 端口常量值。
- 执行前组装 `List<DbParameterValue>`，`DbType` 按快照转换（`Text/Integer/Real/Boolean/DateTime/Blob`）；转换失败给"参数 @x 期望 Integer，实际 'abc'"这种可定位文案。
- 失败语义：
  ```csharp
  protected override bool RethrowOnException => FailFast;
  // 服务返回 false 时：
  Fail(error); if (FailFast) throw new InvalidOperationException(error);
  ```
  先 `Fail` 再抛，避免 `ErrorMessage` 被基类的 `"InvalidOperationException: "` 前缀污染；`RethrowOnException => FailFast` 才让"抛"真正中断当轮（否则基类吞掉，只红不停线）。
- 输出固定（§三 D4 已含 `Truncated`）：

| 步骤 | 输出 |
| --- | --- |
| Query | `Scalar(object)`、`RowsJson(string)`、`RowCount(int)`、`Columns(string)`、`Truncated(bool)`、`ElapsedMs(double)` |
| Execute | `AffectedRows(int)`、`ElapsedMs(double)` |
| WriteRow | `Accepted(bool)`、`AffectedRows(int)`、`ElapsedMs(double)` |

- `RowsJson`：`[{ "列名": 值 }]`，数值保持数值、`null` 保持 `null`、`byte[]` 转 base64；列名重复时后者覆盖（并在 `Columns` 里保留原名）。
- `RowCount=0` **不算失败**：`Success=true`、`Scalar=null`、`RowsJson="[]"`。
- 只读 profile + `Execute/WriteRow`：执行前直接拒（`Fail`，文案"只读数据库不允许写操作"），不连库。
- Kind 与语句类型不匹配：执行前拒（"该步骤需要 WriteRow 语句，当前语句是 Query"）。

**视图**：`DatabasePluginView.xaml` 按 `docs/UI设计基线/database-plugin/` 复刻（左栏 profile/语句卡 + SQL 只读预览，右栏参数行 + 输出行 + 测试 banner）。参数行用 `LinkableValueEditor`；profile/语句下拉来自 `PluginConfigContext.Database`（拿不到时空态 + 说明）。测试按钮调 `TryTestStatement(..., commitForReal:false, ...)`，banner 必须写"已回滚，未写入数据"。

## 七、关键实现口径（易踩点，写进代码注释与帮助页）

1. **动态端口重建时机**：`ApplyConfigValues` 里，`base` 之后、`LinkPorts` 之前。放 `Initialize` = 运行实例永远没有参数端口（静默"参数缺失"）。编译期灌值点只有 `Engine\FlowCompiler.cs:883` 一处。
2. **端口名 = 参数名（不含 `@`）**，与 SQL 里的 `@name` 一一对应；重名只建一个端口（照 DataRecord）。
3. **`FailFast` 的实现必须"先 Fail 再抛 + `RethrowOnException => FailFast`"**；只抛不覆盖 `RethrowOnException` 会被基类吞掉，表现为"步骤红、线照跑"。
4. **一次调用一个事务**；`TryTestStatement` 的 `commitForReal=true` 只允许 UI 二次确认后传，服务日志要记"测试提交"。
5. **只读档双保险**：连接串 `Mode=ReadOnly` + 语句 Kind 白名单；不要只靠 SQL 前缀判断。
6. **参数化**：只允许 `AddWithValue("@name", value)`；插件源码静态扫描禁止 `SqlCommand`/`DbCommand`/字符串拼接（硬闸 2）。
7. **`.vms` 里不许出现 SQL/路径/密码**：只存 `ProfileId`、`StatementId`、参数模式快照与参数值。
8. **引用检查要深遍历**：容器（For/While/If/Parallel）里的步骤同样算引用，浅层遍历会漏。
9. **`databases.json` 原子写**：temp + 替换，catch `IOException` + `UnauthorizedAccessException`（R180，本仓已踩过两次）。
10. **不擅自改用户库**：不设 `journal_mode`、不建表、不迁移；只读写用户自己的数据。
11. **插件缓存**：新增 `Plugin.Database.dll` 会触发 `PluginCache` 的"未登记 DLL"判据 → 自动全量重扫，无需手工清缓存（但要确认日志里出现失效原因）。
12. **帮助手册三数字**：M 档 = 4 用户页 / 2 开发页 / 开发章节 ≥150 行（R61：派工单必须抄这三个数字）。

## 八、风险与缓解

| # | 风险 | 影响 | 缓解 |
| --- | --- | --- | --- |
| R1 | SQLite 原生库在 `pack.ps1` 产物里缺失（publish 与 build 的 RID 行为不同） | 现场一用就 `DllNotFoundException` | M4 强制核对产物 + 用打包后的 exe 跑一次写库；必要时在 `Core.Database.csproj` 加 `<RuntimeIdentifier>win-x64</RuntimeIdentifier>` 或显式 `<None CopyToOutputDirectory>` |
| R2 | 参数模式快照与语句定义漂移（有人改了参数表没重开步骤） | 运行期"参数 @x 未提供/多余" | 服务端做**权威校验**并给出可定位文案；插件窗口打开时对比快照并提示"语句已变化，请确认参数" |
| R3 | SQL 校验用前缀扫描，复杂 SQL（CTE 里带 DELETE、注释包裹）可能误判 | 保存被误拒 / 漏放 | 先剥离注释与字符串字面量再判；规则保守（宁可拒）；`DatabaseChecks` 覆盖正反例各 10 条 |
| R4 | 长查询占住流程线程 | 节拍卡死、停止不响应 | 强制超时（profile + 语句两级取小）、`CancellationToken` 注册 `command.Cancel()`；停止时步骤记 Skipped 不是 Failed |
| R5 | SQLite 并发写 `SQLITE_BUSY` | 偶发写失败 | `busy_timeout` + `Transient` 分类；写步骤 `FailFast` 默认 true，失败要停线而不是吞 |
| R6 | 删除引用检查漏掉容器内步骤 | 删除后流程编译失败 | 深遍历 + `DatabaseChecks` 造一条"并行分支里引用"的反例 |
| R7 | 插件窗口与宿主页两处测试语义漂移 | 用户看到两种结论 | 两处都只调 `TryTestStatement`，禁止各写一套事务逻辑 |
| R8 | 帮助手册欠账导致 HM16/HM17 红 | 收尾被闸拦住 | M2 交代码时同步交手册，别留到 M4 |
