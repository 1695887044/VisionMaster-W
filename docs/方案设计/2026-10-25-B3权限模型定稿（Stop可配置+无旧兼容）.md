# B3 权限模型定稿（Stop 可配置 + 无旧兼容）

> 日期：2026-10-25
> 决策：在 B2（用户组 + 命名权限集合，≤32）基础上再改四条。本文件是规格、B 设计、计划、B0 基线、D5、测试报告的唯一口径；与旧文冲突时以本文件为准。

## 一、四条变更

| # | 决定 | 具体口径 |
|---|---|---|
| 1 | **Stop 也是普通按钮** | 删除 `SafetyStop` 与“Stop 恒放行”。`Stop` 是普通权限 Key；默认三个模板都含 `Stop`；自定义组可取消，保存时红字警告“该组将无法停止设备”，需二次确认。`JogStop` 跟随 `Stop`。**唯一保留的系统安全动作**：点动中权限被收回/登出时，系统自动补发 `JogStop`（不是用户按钮，不受组权限限制），防止轴继续走。 |
| 2 | **不兼容旧方案（硬切）** | 新 `ScadaUsers.json` 只写 `Name/Salt/Hash/Iterations/GroupId`，**不再有 `Role`**；旧 5 字段 `Role` 文件**不自动迁移**，直接 fail-closed，提示“旧账号文件格式不受支持，请重建账号”；不写回 `Role`，不提供旧格式导入。 |
| 3 | **删除守卫查组 + 按钮** | 删除权限前扫描：所有组的 `Permissions` + 全方案页面/图元的 `RequiredPermission`；任一引用即拒绝，并报“N 个组 / M 个按钮引用”。 |
| 4 | **运行态弹登录** | 运行态 SCADA 画面/图元未授权点击 → 弹登录 → 登录后重判 → 有权限则继续原操作；工程菜单/管理页仍灰显 + 回执。Stop 也走这条：无 Stop 权限时点停止会弹登录；默认模板含 Stop，避免默认锁死。 |

## 二、权限目录（15 条内置，最多 32）

`ViewRuntime / ControlRun / Start / Initialize / Stop / ReportQuery / AxisJog / AxisSpeedConfig / EditStructure / Compile / SaveSolution / HardwareRuntime / HardwareConfig / SystemConfig / UserAdministration`

- 没有 `SafetyStop`；`Always`（登录/帮助/浏览）是系统级恒放行，不进目录。
- 上限 32 条（含 15 内置，17 个自定义槽位）；到 32 禁止新建。
- 新建：填显示名 → 生成稳定 Key；改名只改显示名；内置不可删；被组/按钮引用不可删；删除后 Key 不复用。

## 三、默认模板与示例组

| 组 | 权限 |
|---|---|
| 模板·操作员 | ViewRuntime + ControlRun + Start + Initialize + Stop + ReportQuery + AxisJog |
| 模板·工程师 | 操作员 7 项 + EditStructure + Compile + SaveSolution + HardwareRuntime + AxisSpeedConfig |
| 模板·管理员 | 全部 15 条 |
| 普工（自定义） | ViewRuntime + Start + Stop |
| 产线操作员（自定义） | ViewRuntime + ControlRun + Start + Initialize + Stop + ReportQuery + AxisJog |
| 厂家（自定义） | 全部 15 条 |

> 默认模板含 Stop 是“安全默认”，不是“恒放行”。现场人员可在组编辑里取消 Stop；取消时 UI 必须警告并二次确认。

## 四、判定

```text
Can(requiredKey):
  if requiredKey == Always: return true
  if requiredKey empty/unknown: return false
  return currentGroup.Permissions.Contains(requiredKey)
```

- 没有 Stop 特例；Stop 与其它 Key 完全一样。
- 未知组/空集合 → 拒绝，不回落。
- 自动 `JogStop` 是系统安全动作，直接调出口，不经过 `Can`。

## 五、文件

`Users/ScadaUsers.json`（裸数组，新格式）：

```json
[
  { "Name": "admin", "Salt": "...", "Hash": "...", "Iterations": 100000, "GroupId": "tpl-admin" },
  { "Name": "op1",   "Salt": "...", "Hash": "...", "Iterations": 100000, "GroupId": "G-lineop" }
]
```

- 没有 `Role`；旧 5 字段文件 fail-closed。
- `Users/ScadaGroups.json`：`{ Id, Name, Permissions: string[], IsBuiltIn }`。
- `Users/ScadaPermissions.json`：`{ Key, Name, IsBuiltIn }`，最多 32 条。
- 三文件缺失：权限目录/组自动种内置模板（不写盘），首次保存再落；用户文件缺失走 `BookSource=Factory`（新方案，不是旧兼容）。
- 写盘顺序：权限目录 → 组 → 用户；任一失败回滚三者；同时 catch `IOException` + `UnauthorizedAccessException`（R180）。

## 九、风险声明

- 取消 Stop 权限会让该组无法停止设备；默认模板含 Stop，取消时必须二次确认。
- 自动 `JogStop` 是唯一保留的系统安全动作；它不是用户按钮，不受组权限限制。
- 硬切旧账号文件会让现有方案需要重建账号；这是用户明确选择的 A 方案。
