# 图像质量前置检查（对焦 / 曝光 / 对比度 / 饱和 / 镜头脏污）· 方案与验证报告

- 日期：2026-10-27
- 状态：可行性报告（未改代码）
- 建议落点：新增 `Plugin.ImageQuality`（图像质量检查），放在采集之后、算法之前
- 一句话结论：**先做“指标 + 可选阈值”的轻量前置检查，不做黑盒总分；阈值按配方标定，OK/NG 交给判定表。** 这是投入最小、对现场误判收益最大的一块。

## 1. 为什么做

### 1.1 现场最贵的误判，往往不是算法错，而是图不能用

- 散焦、过曝、欠曝、对比度太低、镜头脏污时，Blob/匹配/读码/OCR 都会给出“看起来合法”的结果：分数偏低但过阈值、码读不出、字符拒识、缺陷数异常。
- 现场常见处理是“人看一眼图”，或者把阈值调松；前者不可复制，后者把真实缺陷一起放过去。
- 批量流程（如 `pcb_focus` 121 张散焦图）里，**每一张都先判“这张图能不能用”**，比事后解释“为什么这一张 NG”便宜得多。

### 1.2 现在没有这个能力

- 仓内没有图像质量插件；`PreProcessing` 只有滤波/阈值/形态学等“处理”算子，不回答“图是否可用”。
- `BlobDetect`/`ImageDiff`/`Ocr`/`CodeReader` 各自带业务阈值，但没有“成像质量”这个前置维度。
- 现场只能用 `Sobel/Laplace + 阈值` 自己搭链，指标口径、ROI、归一化各写一套，换产品就漂。

### 1.3 和判定表的分工

按“算法只输出数据、判定交给判定表”的原则：

- `ImageQuality` 输出**指标**（对焦分、曝光分、对比度、饱和度、脏污分、明细），不写死 OK/NG；
- 需要自动拦截时，用「判定表」给每个指标配阈值（或直接接 `IsUsable` 可选端口）；
- 这样同一套指标可以按产品/工位配不同阈值，不用改插件。

## 2. 方案（v1）

### 2.1 定位与放置

```text
图像采集 → 图像质量检查 → 预处理 → 算法（Blob/匹配/读码/OCR） → 结果显示
```

- 输入：`Image`（必填）、可选 `Roi`（只检查产品区域）、可选 `ReferenceImage`（脏污/背景基线）。
- 输出：指标 + 明细 + 可选 `IsUsable`（只有配置了阈值才写）。
- 不做图像修改；不烘焙、不开窗；不写全局变量。

### 2.2 指标与算法口径

| 指标 | 口径（建议） | HALCON 参考算子 | 说明 |
| --- | --- | --- | --- |
| 对焦 Focus | ROI 内梯度能量归一化：`sobel_amp` 的 `sum_abs` 均值 / 基线；或 `laplace` 方差 | `sobel_amp` / `laplace` + `intensity`/`variance` | 散焦图分数单调下降；不同纹理要按基线归一化 |
| 曝光 Exposure | 均值/中位灰度、0/满量程截断比例、动态范围 | `min_max_gray` / `gray_histo` / `intensity` | 过曝看高光截断比例，欠曝看低端堆积 |
| 对比度 Contrast | 灰度 P5~P95 展宽、标准差 | `gray_histo` / `variance` | 低对比图算法阈值会失稳 |
| 饱和度 Saturation | 彩色图逐通道截断比例；HSV 的 S 通道均值/最大值 | `decompose3` + `trans_from_rgb` + `min_max_gray` | 单色图跳过，输出 NaN/0 并说明 |
| 镜头脏污 Dirt | 背景均匀性：中值/均值背景与残差的低灰度斑块面积/对比 | `median_image`/`mean_image` + `abs_diff_image` + `threshold` + `connection`/`select_shape` | 有 `ReferenceImage` 时做差分更稳；无参考时用局部均匀性 |
| 噪声 Noise（可选） | 平坦区残差标准差 | `estimate_noise` | 与对焦分开，避免“噪声高=清晰”误判 |

所有指标输出 0~1 的归一化分 + 原始值；归一化基线来自配方（良品批次的 P5/P50/P95），不写死常数。

### 2.3 端口（建议）

| 端口 | 类型 | 说明 |
| --- | --- | --- |
| `Image` | `HImage` | 必填 |
| `Roi` | `HRegion` | 可选；只检查产品区 |
| `ReferenceImage` | `HImage` | 可选；脏污/背景基线 |
| `FocusScore` / `ExposureScore` / `ContrastScore` / `SaturationScore` / `DirtScore` | `double` | 0~1 归一化分 |
| `FocusRaw` / `ExposureRaw` / `ContrastRaw` / `SaturationRaw` / `DirtRaw` | `double` | 原始指标（给现场调阈值） |
| `IsUsable` | `bool` | **可选**：只有配置了阈值才写；默认不判定 |
| `Reason` / `Details` | `string` / `string[]` | 哪一项不达标、实测/阈值 |
| `QualityMask` | `HRegion` | 可选：脏污/低质量区域，供结果显示 |

### 2.4 阈值与判定

- **默认 metrics-only**：不配阈值就不写 `IsUsable`；下游用「判定表」按产品配阈值（复用动态结果端口/运行时变量那套）。
- 需要“快速前置拦截”时，在插件里给每项配 `Min/Max`，`IsUsable` 只作为便利输出；不改变指标本身。
- 阈值必须按配方/产品标定：良品批次 P5（下限）/P95（上限），并记录样本数；换镜头/光源/曝光时间要重标。

## 3. 怎么验证（核心）

### 3.1 合成真值矩阵

| 用例 | 做法 | 期望 | 反向判据 |
| --- | --- | --- | --- |
| 对焦 | 对一张清晰图做 Gaussian blur（σ=0,0.5,1,2,3,4,5） | FocusScore 单调下降；Spearman ρ ≤ -0.95 | 去掉梯度/换成常数图，分数不变 → 红 |
| 曝光 | 亮度 γ / 增益扫描，制造 0%/1%/5%/20% 截断 | 截断比例与解析值误差 ≤0.5 个百分点 | 把截断比例写死为 0 → 红 |
| 对比度 | 线性拉伸/压缩（对比度 0.2~2.0） | ContrastRaw 随拉伸单调上升 | 用固定常数 → 红 |
| 饱和度 | 彩色图逐通道加亮到截断；灰度图 | 彩色截断比例上升；灰度输出 NaN/0 且说明 | 灰度图强行算饱和度 → 红 |
| 脏污 | 均匀背景 + 已知半径/灰度的暗斑（1~20 个） | DirtScore 随斑块面积/对比上升；检出区域覆盖已知斑块 | 干净图误报 → 红；漏检已知斑块 → 红 |
| 噪声 | 平坦区加 Gaussian 噪声（σ=0~10） | Noise 上升，Focus 不应同步上升 | 把噪声当清晰度 → 红 |

合成图用 HALCON 现场生成，不依赖外部样图；每张图的真值可笔算。

### 3.2 真图验证（仓内现成样本）

- **对焦**：`解决方案\视觉样例对拍\Image\pcb_focus\` 121 张散焦序列。按文件名序号/已知焦距排序，FocusScore 必须随散焦程度单调下降；在清晰段/散焦段各取 5 张做人工标注核对。
- **曝光/对比度**：`label\` 10 张、`smd\` 11 张、`qrcode\` 9 张；另做合成过曝/欠曝版本，确认指标方向正确。
- **脏污**：在 `pcb_focus` 的干净背景图上叠加已知暗斑；再用真实脏污图（如有）做盲测。
- **重复性**：同一张图连续跑 10 次，指标差异 < 1e-6；换 ROI 后指标按预期变化（不是常数）。

### 3.3 与 HALCON 参考实现对拍

- 在断言宿主内用 HALCON 现算同一指标（`sobel_amp`/`laplace`/`variance`/`min_max_gray`/`gray_histo`/`decompose3`+`trans_from_rgb`），与插件输出逐项比对：
  - 原始指标相对误差 ≤ 1%（对焦/对比度/曝光）；
  - 截断比例绝对误差 ≤ 0.5 个百分点；
  - 脏污检出区域与参考 `threshold+connection+select_shape` 的面积差 ≤ 5%。
- 对拍必须**同 ROI、同通道、同归一化**；ROI 不同直接判失败，不比较。
- 反向：把插件的梯度算子换成另一种（如 `laplace`→`sobel`）分数应变化；若不变，说明指标没真正接算子。

### 3.4 集成验证

- 在 `pcb_focus` 批量流程前插入质量检查：清晰段全部 `IsUsable=true`，散焦段按阈值拦截；统计“拦截后算法误判数”与“误拦良品数”。
- 与「判定表」联调：质量指标 → 判定表阈值 → 运行时变量；验证不写全局、全局映射走变量赋值。
- 性能：5MP 图单次检查目标 ≤ 50ms（待实测；脏污差分最重，可只在 ROI 内做）。

### 3.5 验收标准（建议）

1. 合成真值：对焦单调性 ρ ≤ -0.95；曝光截断误差 ≤0.5pp；对比度单调；脏污检出率 ≥90%、干净图误报 ≤1 张/100 张。
2. 真图：121 张散焦序列的 FocusScore 与已知散焦程度一致（人工抽检 10 张全对）。
3. 对拍：与 HALCON 参考指标误差在 3.3 的容差内。
4. 反向：至少 6 条“改坏必红”的断言（见 3.1 表）。
5. 集成：批量流程中良品误拦 ≤1%，已知坏图拦截率 ≥95%。
6. 性能：5MP ≤50ms（或写明实测值与降级策略）。

## 4. 风险与边界

- **阈值强依赖产品/光源/镜头**：没有通用分数；必须按配方标定，报告里不能给“万能阈值”。
- **脏污 vs 纹理**：纹理背景上的暗斑容易误报；有 `ReferenceImage` 时用差分，没有时只能给“疑似”分，不硬判。
- **对焦 vs 低对比**：低对比图梯度天然低，Focus 会低；需要同时看 Contrast，避免把“低对比良品”判成散焦。
- **彩色/灰度**：饱和度只对彩色图有意义；灰度图输出 NaN/0 并写明跳过。
- **性能**：全图脏污差分在 5MP 上可能超 50ms；v1 限定 ROI，必要时降采样。
