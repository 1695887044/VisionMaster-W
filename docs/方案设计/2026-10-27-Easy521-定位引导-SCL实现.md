# Easy521 定位引导 —— SCL 实现（2026-10-27）

> 方案与判据见 `docs\方案设计\2026-10-27-智能相机直连汇川Easy-定位引导落地方案.md`（v2）。
> 本文只给可抄的代码：数据块布局、求解器、引导换算、ATAN2 兜底、梯形图降级版。
>
> **前提（已确认）**：相机为**华睿 R4013MG-07M-RGG01 智能读码器**（1280×1024，视野 116×92mm@150mm，
> p≈0.09mm/px），**无内置标定、只能出像素**，且**没有匹配工具——定位只能靠"码的位置"**；
> 轴由本台 Easy521 控制；机械坐标单位 0.1mm；PLC 支持 REAL。
> 相机侧的详细结论见方案第十四节。

## 一、Easy521 上必须先确认的四件事

代码本身与型号无关，但下面四条决定"怎么落"：

| # | 要确认 | 影响 | 不满足时 |
|---|---|---|---|
| 1 | AutoShop 是否支持 **ST**（结构化文本） | 决定用第一节的 ST 还是第八节的梯形图降级版 | 走第八节 3 点精确解 |
| 2 | 是否有四象限 **ATAN2** | 没有就用第二节的 `FC_Atan2` 兜底（必须做，不要假设有） | 用兜底版 |
| 3 | **断电保持区**容量与配置方式 | 标定系数与示教数据必须掉电不丢 | 加大保持区；不够就把采集数组改为"标定完即清" |
| 4 | **Modbus TCP 客户端**能力 | 决定 PLC 轮询相机还是相机写 PLC | 只有 RS485 就走 Modbus RTU 主站 |

第 2 条不要跳过。很多小型 PLC 只有单参数 `ATAN`，直接调 `ATAN2` 编译不过；
而手写象限修正最容易出的错是"角度在 ±90° 附近突然翻 180°"，且只在某些朝向出现。

## 二、ATAN2 兜底

```pascal
FUNCTION FC_Atan2 : REAL
VAR_INPUT
    Y : REAL;
    X : REAL;
END_VAR
VAR
    a : REAL;
END_VAR
BEGIN
    IF X = 0.0 AND Y = 0.0 THEN
        FC_Atan2 := 0.0;
        RETURN;
    END_IF;
    IF X = 0.0 THEN
        IF Y > 0.0 THEN FC_Atan2 := 1.570796327; ELSE FC_Atan2 := -1.570796327; END_IF;
        RETURN;
    END_IF;

    a := ATAN(Y / X);
    IF X < 0.0 THEN
        IF Y >= 0.0 THEN
            a := a + 3.141592654;
        ELSE
            a := a - 3.141592654;
        END_IF;
    END_IF;
    FC_Atan2 := a;      // 弧度，范围 (-π, π]
END_FUNCTION
```

单测 8 个方向：`(1,0)→0`、`(1,1)→π/4`、`(0,1)→π/2`、`(-1,1)→3π/4`、
`(-1,0)→π`、`(-1,-1)→-3π/4`、`(0,-1)→-π/2`、`(1,-1)→-π/4`。

## 三、数据块布局（断电保持）

```
DB_Calib
├─ 采集区
│   CalN            : INT          // 已记录点数
│   PtR[0..15]      : DINT         // 整像素 Row
│   PtC[0..15]      : DINT         // 整像素 Col
│   PtX[0..15]      : REAL         // 机械 X，0.1mm
│   PtY[0..15]      : REAL         // 机械 Y，0.1mm
├─ 求解结果
│   a11,a12,a21,a22,a31,a32 : REAL // X = a11·R + a12·C + a31；Y = a21·R + a22·C + a32
│   RmsPx, MaxPx    : REAL         // 残差（px）
│   MmPerPx         : REAL         // 当量，**0.1mm/px**
│   Aniso           : REAL         // 各向异性 %
│   CalValid        : BOOL
│   CalDate         : DINT         // yyyymmdd，HMI 显示
├─ 示教
│   R0, C0          : DINT
│   Theta0          : REAL         // 度
│   X0, Y0          : REAL         // 0.1mm
│   ThetaR0         : REAL         // 度
├─ 参数
│   ImgW, ImgH      : INT
│   DXMax, DYMax    : REAL         // Δ 包络，0.1mm，建议 1.2×半个视野
│   RmsMax          : REAL         // 默认 0.6
│   MaxPxMax        : REAL         // 默认 1.5
└─ 运行
    LastSeq         : INT
```

**为什么机械坐标全程用 0.1mm**：标定直接用 PLC 的轴位置（0.1mm）参与求解，
输出也是 0.1mm，**一个单位换算步骤都没有**。v1 方案里那个 `×10` 可以删掉。
代价是系数与上位机/HALCON 不可逐位比对——但本方案没有上位机参与，这个代价不存在。

## 四、采集一个点

```pascal
FUNCTION FC_RecordPoint : INT
VAR_INPUT
    Index    : INT;      // 0..15
    Row, Col : DINT;
    X, Y     : REAL;     // 0.1mm，取自 PLC 自己的轴位置
    CamOk    : BOOL;     // 相机 Status.OK
END_VAR
BEGIN
    FC_RecordPoint := 0;
    IF Index < 0 OR Index > 15 THEN FC_RecordPoint := 1; RETURN; END_IF;
    IF NOT CamOk THEN FC_RecordPoint := 2; RETURN; END_IF;      // NG 点绝不许混入
    IF Row < 0 OR Row >= DB_Calib.ImgH
    OR Col < 0 OR Col >= DB_Calib.ImgW THEN FC_RecordPoint := 3; RETURN; END_IF;

    DB_Calib.PtR[Index] := Row;
    DB_Calib.PtC[Index] := Col;
    DB_Calib.PtX[Index] := X;
    DB_Calib.PtY[Index] := Y;
    IF DB_Calib.CalN < Index + 1 THEN DB_Calib.CalN := Index + 1; END_IF;
    DB_Calib.CalValid := FALSE;      // 一改动就作废旧标定
END_FUNCTION
```

**调用方义务**：记录前必须确认轴已停稳（连续两次读轴位置差值 < 1 个单位）。
运动中读轴位置与相机像素不同步，会得到系统性错点——这是九点标定最常见的"残差莫名其妙大"的原因。

## 五、求解器（9 点最小二乘，归一化 + 3×3 克莱姆）

与上位机 `CalibrationMath.TrySolveAffine` + `Solve3` 逐行对应。
**归一化不是可选优化**：直接对 `Row≈几千` 的法方程求解，条件数很差，REAL 只有 7 位有效数字，
不归一化会算出一个"看起来正常"的错矩阵。

```pascal
FUNCTION FC_SolveAffine : INT
VAR_TEMP
    i, N : INT;
    cr, cc, scale, d : REAL;
    u, v : REAL;
    Suu, Suv, Svv, Su, Sv : REAL;
    Sux, Svx, Sx, Suy, Svy, Sy : REAL;
    m00, m01, m02, m11, m12, m22 : REAL;
    c00, c01, c02, c11, c12, c22 : REAL;
    det, trace : REAL;
    A1, B1, C1, A2, B2, C2 : REAL;
    a11, a12, a21, a22, a31, a32 : REAL;   // 局部，最后才提交
    lenRow, lenCol : REAL;
    r, c, ex, ey, dd : REAL;
    sumSq, maxD : REAL;
END_VAR
BEGIN
    FC_SolveAffine := 0;
    N := DB_Calib.CalN;
    IF N < 3 THEN FC_SolveAffine := 1; RETURN; END_IF;

    // ---- 1. 质心 ----
    cr := 0.0; cc := 0.0;
    FOR i := 0 TO N-1 DO
        cr := cr + DINT_TO_REAL(DB_Calib.PtR[i]);
        cc := cc + DINT_TO_REAL(DB_Calib.PtC[i]);
    END_FOR;
    cr := cr / INT_TO_REAL(N);
    cc := cc / INT_TO_REAL(N);

    // ---- 2. 尺度 = 最大半径 ----
    scale := 0.0;
    FOR i := 0 TO N-1 DO
        d := SQRT( (DINT_TO_REAL(DB_Calib.PtR[i]) - cr) * (DINT_TO_REAL(DB_Calib.PtR[i]) - cr)
                 + (DINT_TO_REAL(DB_Calib.PtC[i]) - cc) * (DINT_TO_REAL(DB_Calib.PtC[i]) - cc) );
        IF d > scale THEN scale := d; END_IF;
    END_FOR;
    IF scale < 1.0 THEN FC_SolveAffine := 2; RETURN; END_IF;      // 点全重合

    // ---- 3. 归一化累加（u,v 落在单位圆内）----
    Suu:=0.0; Suv:=0.0; Svv:=0.0; Su:=0.0; Sv:=0.0;
    Sux:=0.0; Svx:=0.0; Sx:=0.0; Suy:=0.0; Svy:=0.0; Sy:=0.0;
    FOR i := 0 TO N-1 DO
        u := (DINT_TO_REAL(DB_Calib.PtR[i]) - cr) / scale;
        v := (DINT_TO_REAL(DB_Calib.PtC[i]) - cc) / scale;
        Suu := Suu + u*u;   Suv := Suv + u*v;   Svv := Svv + v*v;
        Su  := Su  + u;     Sv  := Sv  + v;
        Sux := Sux + u * DB_Calib.PtX[i];
        Svx := Svx + v * DB_Calib.PtX[i];
        Sx  := Sx  + DB_Calib.PtX[i];
        Suy := Suy + u * DB_Calib.PtY[i];
        Svy := Svy + v * DB_Calib.PtY[i];
        Sy  := Sy  + DB_Calib.PtY[i];
    END_FOR;

    // ---- 4. 3×3 对称正规方程 ----
    m00 := Suu; m01 := Suv; m02 := Su;
    m11 := Svv; m12 := Sv;  m22 := INT_TO_REAL(N);

    det := m00 * (m11*m22 - m12*m12)
         - m01 * (m01*m22 - m12*m02)
         + m02 * (m01*m12 - m11*m02);
    trace := m00 + m11 + m22;
    // 共线判据与上位机同一口径（无量纲，REAL 下同样成立）
    IF det <= 1.0E-4 * trace * trace * trace THEN FC_SolveAffine := 3; RETURN; END_IF;

    // 伴随矩阵（对称矩阵的伴随仍对称）
    c00 := m11*m22 - m12*m12;
    c01 := -(m01*m22 - m12*m02);
    c02 := m01*m12 - m11*m02;
    c11 := m00*m22 - m02*m02;
    c12 := -(m00*m12 - m01*m02);
    c22 := m00*m11 - m01*m01;

    A1 := (c00*Sux + c01*Svx + c02*Sx) / det;
    B1 := (c01*Sux + c11*Svx + c12*Sx) / det;
    C1 := (c02*Sux + c12*Svx + c22*Sx) / det;
    A2 := (c00*Suy + c01*Svy + c02*Sy) / det;
    B2 := (c01*Suy + c11*Svy + c12*Sy) / det;
    C2 := (c02*Suy + c12*Svy + c22*Sy) / det;

    // ---- 5. 还原到原坐标 ----
    a11 := A1 / scale;
    a12 := B1 / scale;
    a21 := A2 / scale;
    a22 := B2 / scale;
    a31 := C1 - A1*cr/scale - B1*cc/scale;
    a32 := C2 - A2*cr/scale - B2*cc/scale;

    // ---- 6. 当量 / 各向异性 ----
    lenRow := SQRT(a11*a11 + a21*a21);      // 沿 Row 走 1px 是多少 0.1mm
    lenCol := SQRT(a12*a12 + a22*a22);
    IF (lenRow + lenCol) <= 0.0 THEN FC_SolveAffine := 4; RETURN; END_IF;

    // ---- 7. 残差（px）----
    sumSq := 0.0; maxD := 0.0;
    FOR i := 0 TO N-1 DO
        r := DINT_TO_REAL(DB_Calib.PtR[i]);
        c := DINT_TO_REAL(DB_Calib.PtC[i]);
        ex := a11*r + a12*c + a31;
        ey := a21*r + a22*c + a32;
        dd := SQRT( (ex - DB_Calib.PtX[i])*(ex - DB_Calib.PtX[i])
                  + (ey - DB_Calib.PtY[i])*(ey - DB_Calib.PtY[i]) )
              / ((lenRow + lenCol) / 2.0);
        sumSq := sumSq + dd*dd;
        IF dd > maxD THEN maxD := dd; END_IF;
    END_FOR;

    // ---- 8. 全部通过才提交 ----
    DB_Calib.a11 := a11;  DB_Calib.a12 := a12;
    DB_Calib.a21 := a21;  DB_Calib.a22 := a22;
    DB_Calib.a31 := a31;  DB_Calib.a32 := a32;
    DB_Calib.MmPerPx := (lenRow + lenCol) / 2.0;
    DB_Calib.Aniso   := ABS(lenRow - lenCol) / DB_Calib.MmPerPx * 100.0;
    DB_Calib.RmsPx   := SQRT(sumSq / INT_TO_REAL(N));
    DB_Calib.MaxPx   := maxD;
END_FUNCTION
```

**注意第 8 段的位置**：所有中间量先算在局部变量里，全部检查通过才一次性写进 DB。
中途 `RETURN` 时 DB 里的旧系数保持原样——不会出现"系数写了一半"的半坏状态。

### 5.1 合入判据（HMI 点「计算」后）

```pascal
err := FC_SolveAffine();
IF err <> 0 THEN
    报警(ErrCodeToText(err));            // 1 点数不足 / 2 点重合 / 3 共线 / 4 当量异常
ELSIF DB_Calib.RmsPx > DB_Calib.RmsMax THEN
    报警('残差超限：检查轴是否停稳、是否有 NG 点混入、相机是否装歪');
ELSIF DB_Calib.MaxPx > DB_Calib.MaxPxMax THEN
    报警('单点残差超限：重录最离谱的那个点');
ELSE
    DB_Calib.CalValid := TRUE;
    DB_Calib.CalDate  := 当日日期;
END_IF;
```

| 指标 | 通过 | 期望值 / 不通过说明 |
|---|---|---|
| `RmsPx` | ≤ 0.6 px | 9 点 + 整像素的期望约 **0.33px**（0.41×√(1−6/18)）。>0.6 说明模型不够 |
| `MaxPx` | ≤ 1.5 px | 单点离谱 = 那个点手滑，重录它 |
| `Aniso` | < 5% | 略大正常（非方像素）；大且残差也大 → 查相机是否被非等比缩放 |
| `MmPerPx` | 与"视野宽÷像素数"相符 | 明显不符 = 轴位置单位读错、或相机做了降采样 |

## 六、求解器自检（**没有上位机时，这是唯一的质量证据**）

用已知系数造一组无噪声合成点，跑同一段求解代码，比对还原结果。
**不需要相机、不需要轴、不需要动设备**，几秒钟出结果。它把"算法抄错了"和"现场装得不好"彻底分开。

```pascal
FUNCTION FC_SolveSelfTest : BOOL
VAR_TEMP
    i : INT;
    nSaved : INT;
    rSave, cSave, xSave, ySave : ARRAY[0..15] OF REAL;   // 或逐点存到局部数组
END_VAR
BEGIN
    // ---- 备份现有采集数据 ----
    // （实现时把 PtR/PtC/PtX/PtY 与 CalN 整份拷到备份区，结束时还原）

    DB_Calib.CalN := 9;
    FOR i := 0 TO 8 DO
        DB_Calib.PtR[i] := 100 + (i MOD 3) * 800;
        DB_Calib.PtC[i] := 100 + (i / 3) * 800;
        // 目标系数：a11=2.0 a12=0.1 a21=-0.1 a22=2.0 a31=-500 a32=-300（0.1mm 单位）
        DB_Calib.PtX[i] :=  2.0*DINT_TO_REAL(DB_Calib.PtR[i])
                          + 0.1*DINT_TO_REAL(DB_Calib.PtC[i]) - 500.0;
        DB_Calib.PtY[i] := -0.1*DINT_TO_REAL(DB_Calib.PtR[i])
                          + 2.0*DINT_TO_REAL(DB_Calib.PtC[i]) - 300.0;
    END_FOR;

    FC_SolveSelfTest := (FC_SolveAffine() = 0)
        AND (ABS(DB_Calib.a11 -   2.0) <= 0.01)
        AND (ABS(DB_Calib.a12 -   0.1) <= 0.01)
        AND (ABS(DB_Calib.a21 +   0.1) <= 0.01)
        AND (ABS(DB_Calib.a22 -   2.0) <= 0.01)
        AND (ABS(DB_Calib.a31 + 500.0) <= 0.5)
        AND (ABS(DB_Calib.a32 + 300.0) <= 0.5)
        AND (DB_Calib.RmsPx <= 0.001);

    // ---- 还原备份的采集数据与系数 ----
END_FUNCTION
```

**两项都要查**：
- **系数还原**验证「反归一化公式」——`a31 := C1 - A1*cr/scale - B1*cc/scale` 这段最容易抄错；
- **`RmsPx ≈ 0`** 验证「求解闭合」。

只查残差不够：同一处 bug 可能让两边抵消（算出的系数错、但用它算残差也自洽地小）。

自检不通过就**禁止保存标定结果**，HMI 直接报"求解器异常，请联系开发"。

## 七、运行期引导换算

```pascal
FUNCTION_BLOCK FB_VisionGuide
VAR_INPUT
    Enable   : BOOL;     // = CalValid AND 运行允许
    Seq      : INT;      // 相机结果序号
    Row, Col : DINT;     // 整像素
    Angle    : REAL;     // 度（相机约定见方案 3.3）
    CamValid : BOOL;     // 相机 Status.OK
END_VAR
VAR_OUTPUT
    DX, DY : REAL;       // 0.1mm
    DTheta : REAL;       // 度，(-180,180]
    Valid  : BOOL;
    HasNew : BOOL;       // 本拍消费了一条新结果
    Fault  : INT;        // 0=OK 1=相机NG 2=像素越界 3=超包络 5=未标定
END_VAR
VAR
    r, c, rad, rad0 : REAL;
    sinT, cosT, sinT0, cosT0 : REAL;
    Xm, Ym, Xm0, Ym0 : REAL;
    vx, vy, vx0, vy0 : REAL;
END_VAR
BEGIN
    Valid  := FALSE;
    HasNew := FALSE;
    Fault  := 0;
    DX := 0.0; DY := 0.0; DTheta := 0.0;

    IF NOT Enable THEN Fault := 5; RETURN; END_IF;
    IF Seq = DB_Calib.LastSeq THEN RETURN; END_IF;     // 没有新结果，保持上一拍输出
    DB_Calib.LastSeq := Seq;
    HasNew := TRUE;

    IF NOT CamValid THEN Fault := 1; RETURN; END_IF;
    IF Row < 0 OR Row >= DB_Calib.ImgH
    OR Col < 0 OR Col >= DB_Calib.ImgW THEN Fault := 2; RETURN; END_IF;

    r := DINT_TO_REAL(Row);
    c := DINT_TO_REAL(Col);

    // ---- 位置（0.1mm，全程无换算）----
    Xm := DB_Calib.a11*r + DB_Calib.a12*c + DB_Calib.a31;
    Ym := DB_Calib.a21*r + DB_Calib.a22*c + DB_Calib.a32;

    Xm0 := DB_Calib.a11*DINT_TO_REAL(DB_Calib.R0)
         + DB_Calib.a12*DINT_TO_REAL(DB_Calib.C0) + DB_Calib.a31;
    Ym0 := DB_Calib.a21*DINT_TO_REAL(DB_Calib.R0)
         + DB_Calib.a22*DINT_TO_REAL(DB_Calib.C0) + DB_Calib.a32;

    DX := Xm - Xm0;
    DY := Ym - Ym0;

    // ---- 角度（仿射：与位置无关，基准 φ0 在相减时抵消，不用单独存）----
    rad  := Angle            * 0.017453293;
    rad0 := DB_Calib.Theta0  * 0.017453293;
    sinT := SIN(rad);   cosT := COS(rad);
    sinT0:= SIN(rad0);  cosT0:= COS(rad0);

    // 逐字对应 PoseTransformMath.cs:466-475：
    // dx = 机械 X 分量、dy = 机械 Y 分量（不要按变量名想当然）
    vx  := DB_Calib.a21*sinT  + DB_Calib.a22*cosT;
    vy  := DB_Calib.a11*sinT  + DB_Calib.a12*cosT;
    vx0 := DB_Calib.a21*sinT0 + DB_Calib.a22*cosT0;
    vy0 := DB_Calib.a11*sinT0 + DB_Calib.a12*cosT0;

    DTheta := (FC_Atan2(vy, vx) - FC_Atan2(vy0, vx0)) * 57.29577951;

    // 归一化到 (-180, 180]
    WHILE DTheta >  180.0 DO DTheta := DTheta - 360.0; END_WHILE;
    WHILE DTheta <= -180.0 DO DTheta := DTheta + 360.0; END_WHILE;

    // ---- 包络：单位错/系数坏/用错工位，全部在这里被抓住 ----
    IF ABS(DX) > DB_Calib.DXMax OR ABS(DY) > DB_Calib.DYMax THEN
        Fault := 3;
        RETURN;
    END_IF;

    Valid := TRUE;
END_FUNCTION_BLOCK
```

**输出给运动**：目标位姿 = `(X0 + DX, Y0 + DY, ThetaR0 + DTheta)`。
若机器人转角正方向与机械系相反，`DTheta` 取反——**由验收第 7 步确定，不要猜**。

镜像标定（`det<0`）会让转角自然取反，这是矩阵的正确结果，不要再"校正一次"。

### 7.1 调用侧的时序

```
每 10ms（或每扫描周期）:
   读相机 (Seq, Status, Row, Col, Angle)     ← 一个 Modbus 请求整块读
   FB_VisionGuide(Enable := CalValid, Seq := ..., Row := ..., Col := ..., Angle := ..., CamValid := Status.OK)
   IF FB.HasNew AND NOT FB.Valid THEN 报警(FB.Fault); END_IF
   IF FB.HasNew AND FB.Valid     THEN 下发目标位姿; END_IF
```

**超时**：`HasNew` 连续 200ms 为 FALSE 且已发触发 → 报警，不动作。
超时后沿用上一次坐标 = "同一个零件被抓两次"的经典事故。

## 八、只有梯形图时的降级版：3 点精确解 + 独立验证点

如果 AutoShop 不支持 ST，9 点最小二乘要写成 90 级梯形图（累加 + 变址），
调试成本高。改用**三点精确解**：没有循环、没有累加、没有 3×3 伴随，全是直白四则运算。

```pascal
// 取 3 个点（建议视野四角里挑 3 个，铺得越开越好）
uR := PtR1 - PtR0;   uC := PtC1 - PtC0;      // 像素空间基向量 u
vR := PtR2 - PtR0;   vC := PtC2 - PtC0;      // 像素空间基向量 v
UR := PtX1 - PtX0;   UC := PtY1 - PtY0;      // 机械空间对应的 U
VR := PtX2 - PtX0;   VC := PtY2 - PtY0;      // 机械空间对应的 V

det := uR*vC - uC*vR;                         // = 像素三角形有向面积 ×2
IF ABS(det) < 1.0 THEN 失败(三点共线); END_IF;

a11 := (UR*vC - VR*uC) / det;
a12 := (VR*uR - UR*vR) / det;
a21 := (UC*vC - VC*uC) / det;
a22 := (VC*uR - UC*vR) / det;

a31 := PtX0 - a11*PtR0 - a12*PtC0;
a32 := PtY0 - a21*PtR0 - a22*PtC0;
```

**为什么这里不用归一化**：三点法用的是**差分向量**（`P1−P0`、`P2−P0`），
已经天然去中心化了，不存在"原点远离点集中心"的条件数问题。这是它比最小二乘好写的原因。

**代价必须写清**：
- **参数方差更大**。3 点定 6 个参数，零冗余，每点的 ±0.5px 量化误差直接进系数，
  比 9 点最小二乘差约 √3 倍。视野 1000px 时系数误差约 0.5/1000 = 5e-4 相对 →
  场内最大约 0.5px ≈ 0.05mm。**占掉 0.1mm 公差的一半**。
- **拟合残差恒为 0**，所以必须用**额外的验证点**（第 4、5 点）算残差：

```pascal
// 验证点（不参与求解，所以残差是诚实的）
FOR k := 3 TO N-1 DO
    ex := a11*PtRk + a12*PtCk + a31;
    ey := a21*PtRk + a22*PtCk + a32;
    d  := SQRT((ex-PtXk)*(ex-PtXk) + (ey-PtYk)*(ey-PtYk)) / MmPerPx;
    ...
END_FOR;
```

验证点的残差**比 9 点最小二乘的残差更可信**（后者是拟合残差，偏乐观）。
所以哪怕只有梯形图，也建议采 6 个点：3 个求解、3 个验证。

**取舍建议**：如果确认 AutoShop 支持 ST，用第五节的 9 点最小二乘（参数更稳、代码更长）；
只有梯形图才用这一节。

## 九、验收步骤（按顺序）

| # | 步骤 | 判据 | 依赖硬件 |
|---|---|---|---|
| 1 | `FC_Atan2` 单测 8 方向 | 全部对 | ❌ |
| 2 | `FC_SolveSelfTest` | 6 个系数还原、`RmsPx < 0.001` | ❌ |
| 3 | 通信连通 | Seq 随触发递增，Status 正确翻转 | ✅ |
| 4 | **INT32 字序** | 相机显示 1000，PLC 读到的也是 1000 | ✅ |
| 5 | 九点标定 | `RmsPx ≤ 0.6px`、`MaxPx ≤ 1.5px`、`MmPerPx` 与视野相符 | ✅ |
| 6 | 回第 5 点复测 | 算出的 (X,Y) 与该点实际轴位置偏差 ≤ 0.1mm | ✅ |
| 7 | **平移验证** | 标准件沿机械 X 移 10mm → `DX ≈ 100` 单位、`DY ≈ 0` | ✅ |
| 8 | **角度方向验证** | 标准件转 +10° → `DTheta = +10°`（或 −10°，与机器人转角正方向一致）；不转时 ≈ 0 | ✅ |
| 9 | NG 路径 | 拿走零件 → `Fault=1`，不动作；**不能沿用上一次坐标** | ✅ |
| 10 | 超时路径 | 拔网线/串口 → 200ms 内报警 | ✅ |
| 11 | 重复性 | 同一零件连续测 30 次，`DX/DY/DTheta` 极差 ≤ 精度目标 | ✅ |

**第 1、2 步不依赖任何硬件，应当最先做完。** 它们把"算法抄错了"和"现场装得不好"分开——
否则残差大时你无法判断该查代码还是查安装。

**第 7、8 步是唯一可靠的约定验证**。角度零点/正方向错了，X/Y 完全正常，只有第 8 步能抓出来。

## 十、还没定、但不影响开工的三件事

1. **相机角度约定**（零点在 Col+ 还是 Row+、顺时针还是逆时针）——第 8 步现场验证，
   必要时在 `FB_VisionGuide` 入口加一次变换。
2. **有效位改用硬线**。R4013MG 有 3 路光耦隔离输出（OPT_OUT0/1/2），
   建议 `OPT_OUT0`=读码 OK、`OPT_OUT1`=结果就绪、`OPT_OUT2`=NG/无码。
   **坐标走 Modbus、有效位走硬线**——硬线比寄存器状态位可靠，也不会因为 Modbus 读失败而拿到旧坐标。
   若坚持只走 Modbus，则 `CamValid` 接 `Status.OK`，并加"连续 N 次坐标完全相同就报警"的弱兜底。
3. **Modbus TCP 还是 RTU**——寄存器表与时序不变，只改底层配置。
   相机的 "Modbus" 是 TCP 还是 RTU、Easy521 能否做 TCP 客户端，这两条要先查。

### 10.1 与相机型号相关的两个额外注意

- **自动对焦必须锁定**。R4013MG 支持电动对焦/一键自动对焦，焦距一变视野就变，
  整份标定立即失效，而且症状是"慢慢漂"。标定前锁定，运行中禁止对焦。
- **码的大小决定定位精度**。读码器从码的边界反算中心，码越小误差越大。
  码边长建议 ≥50px（0.09mm/px 下约 4.5mm）；小于 20px 时可能到 ±1~2px，会吃光 0.1mm 公差。
  第 11 步的 30 次重复性就是量这一项。
