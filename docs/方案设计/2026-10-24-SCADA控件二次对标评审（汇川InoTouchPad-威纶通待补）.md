## 五、真正值得补的（按本项目排序）

### P1：决定“像不像商业 HMI”，且现在补成本最低

1. **状态列表（文本列表 / 图形列表）+ 状态图元**
   - 手册第 8 章：位（0/1）、位号（0-31）、范围三种模式；文本列表和图形列表被 符号IO域、字按钮、位按钮、文本开关、位指示灯、字指示灯、图形开关、图形IO域、I/O 监视共用。
   - 现在 `ComboBox.Options`、Lamp 四色都是每图元一份；同一套状态在十个图元上要配十份，改一处漏九处。
   - 建议：领域层加 `ScadaStateList`（Id/Name/Mode/Entries），页面或方案级共享；先做一个 `Hmi.StateView`（按状态显示文本/图片/两者），图形开关/图形IO域/字指示灯都用它 + 模式属性，不新增三个 TypeKey。
   - 成本 L（模型 + 编辑器 + 控件 + 属性面板 + Web 渲染器 + 断言）。

2. **画中画 `Hmi.SubPage`（嵌入页视图）**
   - 在一个矩形里显示另一张页，按变量切页；只当前页通信。多工位总览、设备局部放大、公共趋势区都用得上。
   - 现有弹窗/基座页解决的是“浮层/公共层”，不是“嵌进画布的页视图”。
   - 成本 M/L（运行态子会话/数据泵生命周期 + 裁剪 + 变量切页）。

3. **报警三事件（激活 / 取消激活 / 确认）**
   - 手册 7.5.2 明确这三条是报警对象事件；现在 `ScadaEventType` 有 13 条，唯独缺报警生命周期。
   - 价值：报警时自动切报警页、启动录像/记录、确认后复位某个按钮；比“靠变量值间接推”可靠。
   - 成本 S（报警引擎已有三事件，接到页面/图元钩子即可）。

4. **位操作动作（置位 / 复位 / 取反）**
   - 现在写布尔量只能 `WriteVariable` 写 0/1；取反要两条动作，且读改写有竞态。
   - 成本 S（动作枚举 + 分发器 + 属性面板一行）；需要变量支持位地址时再补位偏移。

### P2：客户会问，但可以用现有控件顶一阵

- **棒图**：扩 ProgressBar 的刻度/上下限/限制线，不新建 TypeKey（S/M）。
- **比例移动 / 对角线移动动画**：缩放与斜向位移；罐体、阀门、机构示意常用（M）。
- **圆形进度条 / 旋钮 / 仪表 Plus**：外观型，三个都可做成 Gauge 的 `Style` 变体或独立控件；先做圆形进度条（M）。
- **定时器控件 + 超时事件**：画面局部定时；与流程定时分开（S/M）。
- **GIF / 多边形 / 贝塞尔 / 动态画线**：绘图/动画型；多边形和 GIF 优先（M）。
- **变量监视 / I/O 监视**：DataGrid + 位表；如果现场要“一个字节 8 位”的表，做一个 `Hmi.BitTable`（M）。
- **组数据视图 / 数据记录启停**：在 DataGrid 历史源上补“记录组 + 开始/停止”（M）。

### P3 / 不适用

- **报表 / 操作记录 / 用户管理 / 文件浏览 / PDF / 浏览器 / 数据库视图**：宿主级能力或独立插件更合适；做成页内图元会把权限、文件对话框、WebView2 安全边界带进画面模型。客户明确要再做。
- **故障码查询**：汇川伺服/PLC 专用；本项目可做通用 CSV 码表，但优先级低。
- **流程图 / 软件容器 / 海康摄像机 / 物联网卡 / WiFi 系列**：不适用或已有替代（流程栏、插件图像、宿主网络配置）。

## 七、结论

- 37 个 TypeKey 对汇川 68 项：**22 直接对应 / 15 可近似 / 31 无对应**；31 项里约 6 项是嵌入式专用、约 10 项可由宿主或现有控件替代。
- **不是“图元数量不够”，而是三块横切能力**：共享状态列表、嵌入页视图、报警生命周期事件。这三块补齐后，图形开关/图形 IO 域/字指示灯/多语言/报警联动会一起解锁。
- 下一批建议只做 P1 四项（状态列表 + 状态图元、画中画、报警三事件、位操作动作）；P2 里优先棒图与比例移动。
- 威纶通：拿到 EasyBuilder Pro 操作手册（PDF/CHM）后，按本文同一张表再补一次差异；当前结论对“两家共有对象”成立，对“威纶通特有对象”不下结论。
