> 日期：2026-10-25

> 范围：方案级用户管理（`Users/`）的权限目录、用户组、账号文件、判定、界面、守卫、断言与对规格/计划/B0 的影响。

## 一、定稿口径（四条硬变更）

| # | 决定 | 落地口径 |
|---|---|---|
| 1 | **Stop 是普通权限** | 删除“安全停止恒放行”权限，以及“Stop 不受组权限限制”的旧说法；`Stop` 是普通命名权限 Key。默认三个模板都含 `Stop`；自定义组可取消，保存时红字警告“该组将无法停止设备”，需二次确认。手动 `JogStop` 跟随 `Stop`。**唯一保留的系统安全动作**：点动中权限被收回/登出时，系统自动补发 `JogStop`（不是用户按钮，不受组权限限制），防止轴继续走。 |
| 2 | **不兼容旧方案（硬切）** | 新 `ScadaUsers.json` 只写 `Name / Salt / Hash / Iterations / GroupId`，**没有 `Role`**；旧 5 字段账号文件**不自动迁移**，加载即 fail-closed，提示“旧账号文件格式不受支持，请重建账号”；不写回旧字段，不提供旧格式导入。 |
| 3 | **删除守卫查组 + 按钮** | 删除权限前扫描：所有组的 `Permissions` + 全方案页面/图元的 `RequiredPermission`；任一引用即拒绝，并报“N 个组 / M 个按钮引用”。 |
| 4 | **运行态弹登录** | 运行态 SCADA 画面/图元未授权点击 → 弹登录 → 登录后重判 → 有权限则继续原操作；工程菜单/管理页仍灰显 + 回执。`Stop` 也走这条：无 `Stop` 权限时点停止会弹登录；默认模板含 `Stop`，避免默认锁死。 |

### 1.1 已废弃口径（勿实现）

- 固定编号 + 数值组合的旧权限模型，以及按二进制位做包含判断的判定；
- 恒放行的“安全停止”权限、代码强制给每个组补该权限；
- 三档角色全序比较、按角色推导必需角色、旧角色数值映射/迁移/写回；
- 旧 5 字段账号文件的兼容读取与自动补 `GroupId`；
- “Stop/JogStop 不需要登录、不受组权限限制”的旧文案（自动 `JogStop` 除外，见 §四）。

## 二、权限目录（15 条内置，最多 32 条）

| # | Key | 显示名 | 说明 |
|---|---|---|---|
| 1 | `ViewRuntime` | 看运行画面 | 运行态画面/图元可见 |
| 2 | `ControlRun` | 运行控制 | 启动/暂停/继续等运行控制 |
| 3 | `Start` | 启动 | 启动流程/设备 |
| 4 | `Initialize` | 初始化 | 初始化/回零前置 |
| 5 | `Stop` | 停止 | **普通权限**；停止与手动 `JogStop` 用同一 Key |
| 6 | `ReportQuery` | 报表查询 | 报表/审计查询 |
| 7 | `AxisJog` | 轴点动 | 点动/回零等轴运行态操作 |
| 8 | `AxisSpeedConfig` | 定位速度配置 | 轴速度/定位参数 |
| 9 | `EditStructure` | 改结构 | 改流程/画面结构 |
| 10 | `Compile` | 编译 | 编译流程 |
| 11 | `SaveSolution` | 保存方案 | 保存方案 |
| 12 | `HardwareRuntime` | 硬件运行态 | 点动/回零/使能等硬件运行态 |
| 13 | `HardwareConfig` | 硬件配置 | 硬件参数配置 |
| 14 | `SystemConfig` | 系统配置 | 机器/系统设置 |
| 15 | `UserAdministration` | 用户管理 | 用户/组/权限目录管理 |

- `Always`（登录/帮助/浏览）是系统级恒放行，不进目录；`Can(Always)` 直接 `true`。
- 目录不含任何“安全停止恒放行”Key；`Stop` 就是普通一条，没有特例。
- 上限 32 条（含 15 内置，17 个自定义槽位）；到 32 禁止新建。
- 新建：填显示名 → 生成稳定 Key；改名只改显示名；内置不可删；被组/按钮引用不可删；删除后 Key 不复用。
- 删除守卫：扫所有组 + 全方案页面/图元；拒绝时报“N 个组 / M 个按钮引用”。
- `RequiredPermission` 是字符串 Key（下拉选目录）；空 = 不限制（普通按钮）。
- 权限目录是方案级 `Users/ScadaPermissions.json`，跨方案不共享。
- 判定用 `HashSet<string>`，Key 逐字比较（大小写敏感）。

## 三、用户组：三个只读模板 + 自定义组

### 3.1 组清单

| 组 | Id | 类型 | 权限 |
|---|---|---|---|
| 模板·操作员 | `tpl-operator` | 内置模板（只读） | `ViewRuntime`、`ControlRun`、`Start`、`Initialize`、`Stop`、`ReportQuery`、`AxisJog` |
| 模板·工程师 | `tpl-engineer` | 内置模板（只读） | 操作员 7 项 + `EditStructure`、`Compile`、`SaveSolution`、`HardwareRuntime`、`AxisSpeedConfig` |
| 模板·管理员 | `tpl-admin` | 内置模板（只读） | 全部 15 条 |
| 普工 | `G-worker` | 自定义 | `ViewRuntime`、`Start`、`Stop` |
| 产线操作员 | `G-lineop` | 自定义 | `ViewRuntime`、`ControlRun`、`Start`、`Initialize`、`Stop`、`ReportQuery`、`AxisJog` |
| 厂家 | `G-vendor` | 自定义 | 全部 15 条 |

### 3.2 规则

- 默认模板含 `Stop` 是“安全默认”，不是“恒放行”。现场人员可在组编辑里取消；取消时 UI 必须红字警告并二次确认。
- 模板组固定、只读：名称/权限/删除都不可改；要差异就建自定义组。
- 自定义组可新建、改名、改权限、删除；组名唯一；组 Id 稳定，改名只改 `Name`。
- 空组（无任何权限）允许保存，但提示“该组登录后什么也做不了”。
- 取消 `Stop`：红字“该组将无法停止设备”；若组含 `AxisJog`，追加“点动中只能靠系统自动 JogStop”；二次确认后才保存。
- 删除组：有用户引用不可删，提示“先迁移 N 个用户”；最后一个含 `UserAdministration` 的组不可删/不可取消该权限；最后一个管理员用户不可删/不可降级；不能删自己；`admin` 用户不可删。
- 组内 Key 必须存在于权限目录；判定时未知 Key 一律 `false`，不回落。

## 四、判定

```text
Can(requiredKey):
  if requiredKey == Always: return true
  if requiredKey empty/unknown: return false
  return currentGroup.Permissions.Contains(requiredKey)
```

- 没有 `Stop` 特例；`Stop` 与其它 Key 完全一样。
- 未知组/空集合/空 Key/未知 Key → `false`，不回落放行。
- 未登录 = 无组/空集合 → 除 `Always` 外拒绝；运行态受保护操作走“弹登录 → 重判”。
- 手动 `JogStop` 跟随 `Stop`；自动 `JogStop` 是系统安全动作，直接调出口，**不经过 `Can`**。
- 组/权限变化、方案切换、登录/登出后，四个命令统一 `RaiseCanExecuteChanged()`；`CanExecute` 与 handler 首行都走同一个 `Can`。
- Web：ticket/session 携带 `GroupId` + `Permissions` 快照；服务端按快照判，客户端只做灰显，不信任客户端。
- 组权限变化 → 撤销该组用户的 Web 会话（`RevokeGroup` / `GroupChanged`，与现有 `UserChanged` 同族）。
- 判定用 `HashSet<string>`；Key 逐字比较，大小写敏感。

## 五、文件与持久化

### 5.1 `Users/ScadaUsers.json`

保持**裸 JSON 数组**，每条恰好 5 个字段：

```json
[
  { "Name": "admin", "Salt": "...", "Hash": "...", "Iterations": 100000, "GroupId": "tpl-admin" },
  { "Name": "op1",   "Salt": "...", "Hash": "...", "Iterations": 100000, "GroupId": "G-lineop" }
]
```

- 字段固定为 `Name / Salt / Hash / Iterations / GroupId`，**没有 `Role`**。
- 新写入只写 `GroupId`，不写任何旧兼容字段。
- 旧 5 字段账号文件（第 5 字段为角色数值）**不自动迁移**：加载即 fail-closed，提示“旧账号文件格式不受支持，请重建账号”；不写回、不导入。
- `GroupId` 缺失/为空 → 视为旧格式，fail-closed。
- `GroupId` 指向不存在的组 → 该用户拒绝（`Always` 除外），错误含组 Id；不回落 `admin`。
- 密码仍 PBKDF2 + `Salt` + `Iterations`；默认 `admin/admin123`；Web 拒绝默认密码。

### 5.2 `Users/ScadaGroups.json`

```json
[
  { "Id": "tpl-operator", "Name": "模板·操作员", "Permissions": ["ViewRuntime","ControlRun","Start","Initialize","Stop","ReportQuery","AxisJog"], "IsBuiltIn": true },
  { "Id": "tpl-engineer", "Name": "模板·工程师", "Permissions": ["ViewRuntime","ControlRun","Start","Initialize","Stop","ReportQuery","AxisJog","EditStructure","Compile","SaveSolution","HardwareRuntime","AxisSpeedConfig"], "IsBuiltIn": true },
  { "Id": "tpl-admin", "Name": "模板·管理员", "Permissions": ["ViewRuntime","ControlRun","Start","Initialize","Stop","ReportQuery","AxisJog","AxisSpeedConfig","EditStructure","Compile","SaveSolution","HardwareRuntime","HardwareConfig","SystemConfig","UserAdministration"], "IsBuiltIn": true },
  { "Id": "G-worker", "Name": "普工", "Permissions": ["ViewRuntime","Start","Stop"], "IsBuiltIn": false },
  { "Id": "G-lineop", "Name": "产线操作员", "Permissions": ["ViewRuntime","ControlRun","Start","Initialize","Stop","ReportQuery","AxisJog"], "IsBuiltIn": false },
  { "Id": "G-vendor", "Name": "厂家", "Permissions": ["ViewRuntime","ControlRun","Start","Initialize","Stop","ReportQuery","AxisJog","AxisSpeedConfig","EditStructure","Compile","SaveSolution","HardwareRuntime","HardwareConfig","SystemConfig","UserAdministration"], "IsBuiltIn": false }
]
```

- Schema：`{ Id, Name, Permissions: string[], IsBuiltIn }`。
- `IsBuiltIn=true` 的三个模板只读；`false` 为自定义组。
- `Permissions` 是权限 Key 的集合，不存编号/数值。
- 组内 Key 必须存在于权限目录；未知 Key 判定为 `false`。

### 5.3 `Users/ScadaPermissions.json`

```json
[
  { "Key": "ViewRuntime", "Name": "看运行画面", "IsBuiltIn": true },
  { "Key": "ControlRun", "Name": "运行控制", "IsBuiltIn": true },
  { "Key": "Start", "Name": "启动", "IsBuiltIn": true },
  { "Key": "Initialize", "Name": "初始化", "IsBuiltIn": true },
  { "Key": "Stop", "Name": "停止", "IsBuiltIn": true },
  { "Key": "ReportQuery", "Name": "报表查询", "IsBuiltIn": true },
  { "Key": "AxisJog", "Name": "轴点动", "IsBuiltIn": true },
  { "Key": "AxisSpeedConfig", "Name": "定位速度配置", "IsBuiltIn": true },
  { "Key": "EditStructure", "Name": "改结构", "IsBuiltIn": true },
  { "Key": "Compile", "Name": "编译", "IsBuiltIn": true },
  { "Key": "SaveSolution", "Name": "保存方案", "IsBuiltIn": true },
  { "Key": "HardwareRuntime", "Name": "硬件运行态", "IsBuiltIn": true },
  { "Key": "HardwareConfig", "Name": "硬件配置", "IsBuiltIn": true },
  { "Key": "SystemConfig", "Name": "系统配置", "IsBuiltIn": true },
  { "Key": "UserAdministration", "Name": "用户管理", "IsBuiltIn": true }
]
```

- Schema：`{ Key, Name, IsBuiltIn }`；最多 32 条。
- 15 条内置，剩余 17 个自定义槽位；到 32 禁止新建。
- `Always` 不进文件；`Stop` 是普通一条。

### 5.4 缺失、写序与回滚

- 三文件缺失：权限目录/组自动种内置模板（不写盘），首次保存再落；用户文件缺失走 `BookSource=Factory`（新方案，不是旧兼容）。
- 写盘顺序：权限目录 → 组 → 用户；任一失败回滚三者。
- 临时文件 + `File.Move(overwrite: true)`；同时 catch `IOException` + `UnauthorizedAccessException`（R180）。
- 失败不显示“保存成功”；错误横幅含路径与异常类型。
- 组/权限目录文件损坏 → fail-closed（不拿出厂管理员兜底），错误横幅 + 路径/异常类型。

### 5.5 G14 规格变更

原 G14“账号文件格式逐字不变”改为：

> `ScadaUsers.json` 仍是裸数组，但字段固定为 `Name / Salt / Hash / Iterations / GroupId`，不再有 `Role`；`ScadaGroups.json` 与 `ScadaPermissions.json` 为新增文件；旧 5 字段账号文件不受支持，加载即 fail-closed，不迁移、不写回。

这是规格变更，必须写进规格书“迁移矩阵”：迁移矩阵只写“无迁移，旧文件 fail-closed”，不写旧角色映射。

### 6.4 权限目录弹窗

- 列表：名称 / Key / 使用组数 / 类型（内置/自定义）；顶部计数“已定义 N/32”；「＋ 新建权限」。
- 新建：填显示名 → 生成稳定 Key；到 32 条禁止新建。
- 改名：只改显示名，Key 不变。
- 删除：内置不可删；被任何组或任何按钮/图元引用时不可删；拒绝时报“N 个组 / M 个按钮引用”；删除后 Key 不复用。
- 组编辑弹窗的复选框动态来自本目录。

### 6.5 运行态登录

- 运行态 SCADA 画面/图元未授权点击 → 弹登录 → 登录后重判 → 有权限则继续原操作；无权限则拒绝并提示“需要 X 权限”。
- `Stop` 也走这条：无 `Stop` 权限时点停止会弹登录，未授权前不下发停止；默认模板含 `Stop`，避免默认锁死。
- 工程菜单/管理页仍灰显 + 回执，不弹登录。
- 自动 `JogStop`：点动中权限被收回/登出时，系统直接补发，不弹登录、不经过 `Can`。
- 示例：普工点“轴点动” → 需要 `AxisJog` → 弹登录 → 产线操作员登录后继续。

### 6.6 在线会话与审计

- 在线会话：用户组列；组权限变化时撤销该组会话。
- 审计：说明列可带 `[group=...]`；7 列结构不变。
- 未授权交互统一按 §6.5；不在每个菜单点击上弹窗。

## 七、安全守卫（缺一即红）

1. 至少一个组含 `UserAdministration`，且至少一个用户属于该组。
2. 三个模板组只读：不可改名、不可改权限、不可删除。
3. 自定义组被用户引用时不可删；提示“先迁移 N 个用户”。
4. `admin` 用户不可删；不能删自己；不能把最后一个管理员降成无 `UserAdministration` 的组。
5. `Stop` 是普通权限：默认模板含 `Stop`；取消时必须红字警告 + 二次确认；代码不得强制给每组补 `Stop`，也不得让 `Stop` 绕过 `Can`。
6. 未知组/未知 Key/空集合 → 拒绝，不回落放行。
7. 组/权限目录文件损坏 → fail-closed（不拿出厂管理员兜底），错误横幅 + 路径/异常类型。
8. 写权限目录/组/用户任一失败 → 三者回滚，不显示“保存成功”。
9. 删除权限前扫描所有组 + 全方案页面/图元 `RequiredPermission`；任一引用即拒绝并报计数。
10. 自动 `JogStop` 必须保留：点动中权限被收回/登出时直接调出口，不受组权限限制；删掉即红。
11. Web 服务端必须按 `Permissions` 快照判权；客户端灰显不作数。

## 十一、风险与对标边界

### 11.1 风险

- 取消 `Stop` 权限会让该组无法停止设备；默认模板含 `Stop`，取消时必须二次确认。
- 自动 `JogStop` 是唯一保留的系统安全动作；它不是用户按钮，不受组权限限制。
- 硬切旧账号文件会让现有方案需要重建账号；这是用户明确选择的方案。
- 运行态无 `Stop` 权限点停止会弹登录；现场必须确保至少有一个可用账号/组带 `Stop`。
- 权限目录上限 32；到上限需删旧或合并。
- 组/权限目录文件损坏 → fail-closed，可能暂时无法管理；错误横幅给路径/异常类型。

### 11.2 与汇川对标的边界（不抄的部分）

- 不抄用户等级 1~20：与操作权限集合正交，本期不做。
- 不抄工程级账号：仍是方案级 `Users/`，方案隔离不能丢。
- 只抄一半未授权弹登录：运行态 SCADA 画面/图元弹登录；工程菜单/管理页仍灰显 + 回执。
- 不抄默认密码/超级密码：PBKDF2 + 默认 `admin123` + Web 拒绝默认密码。
- **与汇川不同**：我们把 `Stop` 作为普通可配置权限（默认模板含 `Stop`、取消需二次确认），而不是不可配置的恒开动作；唯一保留的系统安全动作是自动 `JogStop`。
