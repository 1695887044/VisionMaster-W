## 34. 通讯数组与地址偏移（R149-R155）

| # | 判据 |
|---|---|
| R149 | **数组元素个数必须落盘（`VariableDto.Length`），且 `BuildAddressConfig` 要在 `DataType` 之后写 `Length`**（`DataType` setter 会重置 `Length`）。`AddressOffset`/`UseLegacyAddress`/`ElementByteLength` 同样落盘；`UseLegacyAddress` 只在 `ModbusAddress`（S7 无 5 位写法），Core 侧用反射设置。 |
| R150 | **数组解码按元素大小循环、字序用连接配置；变更检测按内容逐元素比较**（`HslHelper.ConvertTo<T>` 只取头部字节；数组每拍新实例，按引用比会让 `ValueChanged` 每拍触发）。`byte[]` 保留逐字节快路径。守门：`CommChecks` C22-6/C22-7。 |
| R151 | **数组写入只走整组替换，元素行只读**：① 长度 = `AddressConfig.Length`；② 元素归一到声明类型；③ 写租约；④ 运行互锁（打开前 + 确认时各查一次）；⑤ 字符串定长编码后下发。`Value` setter 隐式写仍跳过数组。UI 网络数组根走 `NetworkArrayRoot`、元素行走 `ReadOnlyChild`，**不得复用本地 `ArrayRoot`/`EditableChild`**。守门：C24-1~C24-8、`[G]` 十条、`--global-variables` 三条。 |
| R152 | **`Address` 是原始协议地址，不是 `4xxxx` 编号**（写 `"0"`/`"1"`，指定区域用 `x=3;0`/`x=1;0`）。**「40001 写法」是每变量开关、默认关闭；打开后按存储区区间换算，不匹配时 `Validate` 失败**。绝不自动识别 5 位地址。地址偏移单位是**地址单位**（Modbus 寄存器/位、S7 字节），默认 0。守门：C22-1~C22-5。 |
| R153 | **跨度超单请求上限（Modbus 120 寄存器 / S7 110 字节）直接拒绝，不做分块**；创建入口与规划器两处都拦。 |
| R154 | **字符串宽度两个口径**：`string` 的 `Length` 是**总字节数**（默认 20）；`string[]` 的 `Length` 是**元素个数**，另需 `ElementByteLength`。写入 ASCII + 尾部补 0、超长明确失败；读回 `TrimEnd('\0')`。缺 `ElementByteLength` 的 `string[]` 由规划器跳过并记日志。守门：C23-1~C23-5、C24-5~C24-8。 |
| R155 | **`ArrayEditor` 网络模式与本地模式共窗但语义分家**：网络模式 `ShowBaselineControls=false`、`CanEditStructure=false`、`Title`「写入数组」、确认直接 `TryWriteToValue`；本地模式三条语义不许改。新增绑定走 `ShowBaselineControls`/`CanEditStructure`/`FooterSummary`。**网络数组必须等当前值到齐才能确认**（空表确认会把整段写成 0）。守门：`[G]` 两条 + 本地数组既有断言。 |

## 35. 设备变量表导入导出（R156-R165）

| # | 判据 |
|---|---|
| R156 | **只按变量名匹配，不支持 Excel 改名**；文件内重名与跨来源撞名都是错误行。**空白单元格默认值按列语义给**（`TryParseInt/Double` 对空白返回 `true/0`，拿 0 会把 DB 号/元素个数/缩放/位偏移读错）：DB 号 1、元素个数 1、缩放 1、位偏移 -1、站号/地址偏移/工程偏移 0。守门：`[IO]` 20+ 条。 |
| R157 | **更新必须 ReRegister，回滚清单先入再动集合**（地址/扫描组/区域合并读/类型在注册时抄成快照）。新增/更新/待删都先进清单再 Add/赋值/Remove。**数组初始值列按设计忽略**，更新时不许把 `DefaultValue` 基准清成 null。守门：`[IO]` 三条。 |
| R158 | **地址是结构化列，预览列只读**（存储区/偏移/位偏移/站号/DB号/元素个数/每元素字节数/地址偏移/40001 写法），导入端不解析复合地址串。导出导入必须覆盖 Modbus（Tcp/Rtu）、S7（含 DB 号）、三菱 MC、欧姆龙 Fins。扫描组未知回落默认组且**不自动建组**；显示分组未知可按选项建（默认开）；删除缺失默认关闭。守门：`[IO]` MC/Fins 往返等。 |
| R159 | **`DataGrid.RowHeight` 是 `double`，写 `Auto` 构造期抛异常**（编译期全绿）→ 用 `RowHeight="{x:Static sys:Double.NaN}"` + `MinRowHeight`。**`Run.Text` 默认 TwoWay**：绑只读计数必须显式 `Mode=OneWay`。守门：`--global-variables` 静态闸。 |
| R160 | **`RadioButton` 卡片等宽必须显式 `HorizontalAlignment="Stretch"` + `HorizontalContentAlignment="Stretch"`，模板里 Border 与 ContentPresenter 也 Stretch**（只写外层 Grid `*` 列不够）。 |
| R161 | **xlsx 导出先写同目录临时文件再 `File.Move(..., overwrite: true)`**，不许"先 Delete 目标再 SaveAs"；临时文件保持 `.xlsx` 后缀（MiniExcel 按扩展名选格式），失败在 finally 删。 |
| R162 | **更新行空白「初始值」= 保持原值（含 null），新增行 = 类型默认值**；数组初始值列忽略且更新保留基准。类型变更：标量用新初始值、数组清基准/镜像（镜像走 `UpdateMirrorValue`，绝不经 `Value` setter 写设备）。守门：`[IO]` 四条。 |
| R163 | **字符串标量跨度与数组同闸**（`(isArray \|\| isStringScalar)`）；**协议专属列**非空但不适用必须报错；**地址类型与协议不一致必须判更新并重建**（MC↔Fins 的 `D100` 可相同）。守门：`[IO]` 四条。 |
| R164 | **回滚与重注册失败必须可观测**：`ReRegister` 返回 bool，导入在 false 时抛错并回滚；回滚逐项收集错误，失败抛 `DeviceVariableImportException`（Message 写"已回滚"或"回滚未完全成功：…"）。`Apply` 是 public，服务层自守运行锁并复核"Existing 仍在集合 / New 名未被占用"。守门：`[IO]` 两条。 |
| R165 | **静态闸剥注释、Run 断言全部 OneWay、渲染档量等宽**：`Contains`/regex 直接扫会被注释假绿（先 `<!--.*?-->`）；`Run.Text` 必须抓 `Mode=TwoWay` 变体；R160 等宽必须用 `ActualWidth` 实测。守门：`UIThemeSmokeTest` 静态段 + `RenderIoDialogs`。 |
