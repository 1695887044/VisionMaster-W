## 18. 停靠面板恢复可见（R58-R59）

| # | 判据 |
|---|---|
| R58 | **恢复可见一律走 `LayoutHelper.ShowPanel`/`ShowAnchorable`，别处不许写 `anchorable.IsVisible = true`**。四条判据：① `!IsHidden` 先 return；② `PreviousContainerIndex < 0` 判废（库只判上界，`-1` 塞进 `Insert` 抛 `ArgumentOutOfRangeException`，坏记忆永久留着）；③ 记忆列仍挂在当前 `LayoutRoot`；④ **Show 后再看一次 `IsVisible`**（`PreviousContainer==null` 时库不抛也不显示）。判废走 `AnchorToHomePane`，落点四档顺序不改；必须 `InsertChildAt(ChildrenCount, …)`；挂回进门先判 `IsVisible`；**反射只读，绝不写库私有状态**。守门：`RunPanelModeChecks` 的恢复可见组（⑥a/⑦a 是库行为反证；条数以方法内 `Check(` 为准）+ `LayoutVisibilityCheck` LV0~LV7（10 条，进常规 gate）。 |
| R59 | **读隐藏记忆只有一条口径：`LayoutContent` 同名属性走 `GetProperty`**（`PreviousContainer`/`PreviousContainerId` 是 protected，`PreviousContainerIndex` 是 public，底层字段不同名）。取不到时返回 `int?`，**null 算"不知道"不是 0**；断言取不到就**故意判红不判跳过**。静态扫描只扫第一方目录并排除 `bin\obj`；判据收在"去注释后仍含 `AvalonDock` 的文件"，**不开豁免清单**。 |

守门：`RunPanelModeChecks` 的恢复可见组 + `LayoutVisibilityCheck` LV0~LV7（进常规 gate）。

## 读法

1. 写"恢复可见"代码前先数四条：`!IsHidden` 早退、`PreviousContainerIndex < 0` 判废、记忆列还在 `LayoutRoot`、Show 后复查 `IsVisible`——少一条，坏记忆就会留在布局里且不报错。
2. 断言取不到隐藏记忆时**判红不判跳过**（R59）：跳过会让"环境不支持"吃掉真实回归，反证纪律同 §11 R38。
3. 静态扫描不开豁免清单：判据是"去注释后仍含 `AvalonDock` 的文件"，新文件自动入扫。
