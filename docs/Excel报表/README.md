## ⚠️ 最需要记住的三条

1. **报表里没有图片二进制**，只有指向磁盘原图的 `file:///` **外链**。原图被删/挪走，链接就断。
2. **MiniExcel 读 CSV 必须显式给 `excelType: ExcelType.CSV`**，否则按 xlsx 解析**直接抛**。
3. **`{源步骤}` ≠ `{StepName}`**：前者 = 上游 CSV 记录步骤名；后者 = 本 Excel 报表步骤名。

## 维护约定

1. **只改主文档**。`Excel报表插件.md` 是唯一事实来源；归档件只作历史留档。
2. **MiniExcel 读 CSV 必须传 `excelType: ExcelType.CSV`**（删了必抛）。
3. **OOXML 注入三处缺一不可**，且每处都有 schema 约束：
   - `sheet1.xml`：挂链接样式 + 改短显示名 + 追加 `<hyperlinks>`（**位置在 `autoFilter` 之后、`drawing` 之前**）
   - `sheet1.xml.rels`：`Type` 必须是**纯 URI**（用 XName 会变 Clark 记法 → Excel 报"需要修复"）
   - `styles.xml`：追加蓝色下划线字体（**`CT_Font` 子元素顺序固定**：`u` 在 `sz/color/name` 之前）
4. **克隆"数据格样式"而非末位 cellXfs**（末位是时间格式 `numFmtId=21`）。
5. **先写 `.tmp` 再原子替换**——绝不留半个损坏的报表。
6. **占位符展开长 token 优先**（防 `{yyyy-MM-dd}` 被 `{yyyy}` 截胡）。
7. **默认不阻断生产**（`BlockOnFailure=false`）——报表是给人看的附属产物。
8. 建议后续补 `FlowCanvasChecks/ExcelExportChecks.cs` 固化 T1~T10。
