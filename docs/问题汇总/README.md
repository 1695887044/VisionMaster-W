## 维护约定

1. **命名**：`日期-主题.md`（与 `docs\code-changes\` 同款命名，便于按时间排序）。
2. **状态行必带**：每篇讨论稿开头写清 日期 / 状态 / 来源角色；状态取"讨论稿 · 待拍板 / 已拍板 / 结论已吸收"。
3. **口径标注**：数字类结论必须标注来源口径（估算 / 静态统计 / 未经构建验证 等）；未经仓库构建验证的内容不得表述为"已验证"。
4. **决策落地后**：实施记录写进 `docs\code-changes\`；结论被相关主文档吸收；本目录讨论稿保留作为决策过程记录，不再作为现行事实来源。
5. **不直接修改 `docs\归档\` 中的文件**（归档件只作留档，约定见 [`../归档/README.md`](../归档/README.md)）。
