# HTTP 收图服务端依赖接入（Watson 7.2.0 离线落地 + API 实测）

为「HTTP 收图 → 视觉处理 → HTTP 反馈」这条链准备服务端。本文件只覆盖**依赖接入与工具链验证**这一里程碑，
服务端业务代码（路由 / 静态 Hub / 流程触发 / 结果组包）在后续记录中单独成篇。

---

## 一、需求与决策

### 1. 需求

已锁定 6 项架构决策（框架层服务端 + 静态 Hub 传图、请求指定流程、同步等待结果、按流程分流并行、
扩展现有采集插件注入图像、Token 校验 + 监听内网、响应含判定与指定输出字段）。
唯一待决的是**服务端选型**，且硬约束为：

> 不要授权、不要管理员运行。

### 2. 选型结论

| 分支 | 结论 |
|---|---|
| 服务端形态 | **方案 C：轻量库 Watson（NuGet 包名 `Watson`）7.2.0** |

**为什么是 7.x 而不是 6.x —— 这是本次最容易踩的坑：**

- v6.x 下 `WatsonWebserver` 与 `WatsonWebserver.Lite` **两个包并存**，前者走 **http.sys**，
  仍需注册 URLACL / 管理员权限，等于绕一圈回到原点。
- **v7.x 已移除 http.sys 依赖**，改由自己的 `TcpListener`（HTTP/1.1、HTTP/2）+ `QuicListener`（HTTP/3）承载，
  因此监听内网地址**不需要** URLACL、**不需要**管理员。
- 包名是 `Watson`，**不是** `WatsonWebserver`（后者是 v6 时代的包名）。

**顺带排除的既有选项**：本仓已引用的 `HslCommunication` 自带 `HttpServer`，一度看像「零新依赖」的免费午餐，
但实测其 `Start(int port)` **硬编码了 `http://+:{port}/` 前缀**（`DLL\HslCommunication\Enthernet\HttpServer.cs` L191-207），
`+` 通配符必须注册 URLACL 且要管理员，正好命中要避开的约束，**故不采用**。

### 3. 落地方式决策

**放弃 `dotnet add package`，改用手动下载 nupkg → 落地 `DLL\Watson\` + HintPath。**

原因：本机 NuGet 还原走不通。`dotnet add package Watson` 报
`NU1301: 502 Bad Gateway`（代理拦截 `api.nuget.org/v3/index.json` 与 V2 的 `FindPackagesById()` 查询端点）。
但 V2 的**包下载端点** `https://www.nuget.org/api/v2/package/{id}/{ver}` 可用，于是手动取包后
照抄本仓 `DLL\Halcon\halcondotnet.dll` 的既有范式落地。

好处：彻底离线、不碰全局 NuGet 源、换任何机器都能直接编译。

### 3. API 签名实测（反射探针，临时工程不入仓库）

XML 文档只收录**有注释**的成员，`Webserver.Routes` 等关键成员查不到，故在 `%TEMP%\watsonprobe\`
建了 `net9.0` 反射探针直接读 DLL 元数据。核实到的签名：

```csharp
// 类型归属：Webserver : WebserverBase（Routes 在基类上，不在 Webserver 上）
WebserverSettings settings = new WebserverSettings("0.0.0.0", 19000);   // ctor(string hostname, int port, bool ssl = false)
Webserver server = new Webserver(settings, defaultRoute);               // ctor(WebserverSettings, Func<HttpContextBase, Task>)

server.Routes.AuthenticateApiRequest = async (HttpContextBase ctx) => ...;  // Func<HttpContextBase, Task<AuthResult>>
server.Post("/upload", async (ApiRequest req) => ..., auth: true);          // Func<ApiRequest, Task<object>>

server.Start();   // Start(CancellationToken token = null)
server.Stop();
server.Dispose();
```

**三个与官方 README（master 分支）不一致、必须按实测为准的点：**

| 项 | README 写法 | 7.2.0 实测 | 影响 |
|---|---|---|---|
| 收原始字节 | `req.Http.Request.Data` 返回 `byte[]` | **`Data` 是 `Stream`**；原始字节要用 **`DataAsBytes`**（`byte[]`，只读） | 直接照抄 README 会编译不过 |
| 路由管理器 | `server.Routes.PreAuthentication.Static.Add(...)` | 类型是 `RoutingGroup`（有 `.Static/.Content/.Parameter/.Dynamic/.WebSockets`），但 `RouteManager` 这个类型**不存在** | 走高层 `server.Post(path, handler, auth)` 更简洁 |
| 类型命名冲突 | — | **`WatsonWebserver.Core.HttpMethod` 与 `System.Net.Http.HttpMethod` 同名** | 工程开了 `ImplicitUsings`，`System.Net.Http` 默认在范围内，`HttpMethod` 裸写会 `CS0104 不明确的引用`，必须全限定 |

`HttpContextBase` / `HttpRequestBase` / `HttpResponseBase` / `ApiRequest` / `AuthResult` 均为**非 sealed 的普通类**
（`HttpRequestBase`、`HttpResponseBase` 为 abstract），`AuthResult` 字段为
`AuthenticationResultEnum{Success,NotFound,Expired,PermissionDenied,Invalid}` 与
`AuthorizationResultEnum{Permitted,DeniedImplicit,DeniedExplicit}`。

### 4. 端到端冒烟（真起服务 + 真发 HTTP）

同一探针工程内启动服务端并向自己发请求：

```
[srv] listening=True prefix=http://0.0.0.0:19000/
[cli] no-token    -> HTTP 401
[cli] with-token  -> HTTP 200 body={"ok":true,"size":8}
[srv] received=8 token=Bearer secret
=== SMOKE PASS ===
[srv] stopped
```

逐条对应四个前提，全部成立：

| # | 验证点 | 结果 |
|---|---|---|
| 1 | **普通用户权限**下监听 `0.0.0.0`（非 127.0.0.1） | 成功，无异常、无提权 |
| 2 | 原始二进制字节无损接收 | 8 字节，首尾值 `10`/`80` 校验通过 |
| 3 | Token 校验拦截 | 无 token → 401，正确 token → 200 |
| 4 | 返回匿名对象自动序列化为 JSON | `{"ok":true,"size":8}` |

## 四、已知边界

1. **仅 HTTP，未启用 HTTPS**。`WebserverSettings` 第三参 `ssl` 默认 `false`；内网部署口径下暂不启用。
2. **未做并发压测与长稳**。冒烟只覆盖单请求路径，`Watson` 在并发收图 + 大图（数 MB）下的内存与吞吐未测。
3. **未验证 HTTP/2、HTTP/3**。`SupportsHttp2` / `SupportsHttp3` 属性存在但未实测，当前按 HTTP/1.1 使用。
4. **探针工程在 `%TEMP%\watsonprobe\`，不入仓库**。后续若需复验 API 或复跑冒烟，该目录即为现成脚手架；
   清理后需按本文件「三、3 / 三、4」重建。
5. **`DLL\Watson\` 是二进制分发**，升级版本时需同步替换 5 个 DLL 与 XML，并重新核对依赖树是否有增减。
6. **`WatsonWebserver.dll` 内部命名空间为 `WatsonWebserver`**（与程序集名相同），
   `using WatsonWebserver;` 与 `using WatsonWebserver.Core;` 两条都要引。
