## 2. 一张图看懂这个功能

```
寄件人（外部程序 / 相机客户端）
   ├─ 网络推送通道 ──► HttpImageServer（19000）──► ImageHub（按流程分格的收件箱）
   └─ 相机通道     ──► NetworkCameraServer（19100）──► 每台相机一条传送带（帧队列）
                                                      │
                             图像采集插件（取件工）◄────┘
                                                      │
   取到的图 → 后续算法步骤 →（可选）投到主界面视图窗口 → 图像集 → 画布格子
```

四种采集模式：**指定图像 / 文件目录 / 网络推送 / 相机采集**（逐步说明见技术文档 §1.2 与 §4.2）。

| 类别 | 路径 | 为什么留在原地 |
| --- | --- | --- |
| 插件本体 | `Plugins\Plugin.ImageAcquisition\` | 构建系统按 `Plugins\` 目录生效（`Directory.Build.targets` 负责把 DLL 投递到 `Modules\`）；`VisionMaster.sln` 与 `FlowCanvasChecks.csproj` 都按此路径引用。搬它属**构建级重构** |

| 预览契约 | `Shard\Core.Controls\Events\`（`ImagePreviewCapture.cs` / `PluginPreviewExtensions.cs` / `ImageDisplayEvent.cs`） | 被所有会推预览的插件共用 |
| 宿主服务 | `VisionMaster\Services\ImageCollectionService.cs`、`HttpImageServer.cs`、`ImageBytesCodec.cs`、`Services\Camera\*` | 宿主基础设施：图像集 / 收图服务被多个功能共用 |
