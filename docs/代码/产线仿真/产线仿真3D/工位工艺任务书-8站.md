### 1.4 公共状态机与故障分级

每站统一状态：

```
Idle → Ready → Cycle → Verify → Done
                  ↘ Fault → Recovery → Ready
```

| 状态 | 进入条件 | 允许动作 |
|---|---|---|
| `Idle` | 上电/复位后，未使能 | 只允许 Home/使能 |
| `Ready` | 已回零、已使能、安全门关闭、无报警 | 允许 CycleStart |
| `Cycle` | 收到启动且托盘到位 | 执行本站动作 |
| `Verify` | 动作完成，等待视觉/测量结果 | 只读检测，不再运动 |
| `Done` | 判定完成，结果已写入履历 | 允许放行/剔除 |
| `Fault` | 任一 Fatal/Recoverable 故障 | 停止运动，等待复位 |
| `Recovery` | 人工确认、清除故障、重新回零/使能 | 只允许复位动作 |

故障分级：

| 级别 | 例子 | 响应 | 恢复 |
|---|---|---|---|
| **Fatal** | 急停、安全门打开、跟随误差超限、刀未到位 | 停站/停线，切断使能 | 人工复位 + 重新回零/啮合 |
| **Recoverable** | 视觉低置信度、标记缺失、单件超差 | 跳过本站/剔除该件，继续下一件 | 自动，连续 3 次升级 Fatal |
| **Warning** | 接近限位、补偿量接近上限、光源衰减 | 记录并提示，不停止 | 自动 |

### 1.5 公共安全约束

1. **急停**：停类别 1（受控减速后断使能）；切刀/推杆回安全位；凸轮脱开；输送线停；必须人工复位。
2. **安全门/光幕**：本站 50ms 内停止运动；门未关不允许切刀下压、推杆动作、压装下行、装配插入。
3. **切刀/推杆防护**：防护罩未关闭时，切刀/推杆输出被硬件互锁禁止（软件再判一次）。
4. **失电/断气**：切刀回上位、推杆回原位、压头回上死点、夹爪保持（真空件掉落在接料盘内）。
5. **不允许自动重启**：任何 Fatal 故障后必须人工确认，禁止上电自恢复。

### 1.6 术语与符号

| 符号 | 含义 |
|---|---|
| `v` | 线速（编码器实测，mm/s） |
| `m` | 主轴/输送编码器位置（mm） |
| `PhaseMm` | 凸轮相位偏置（mm）；`Target = table(Wrap(m + Phase))` |

### 1.7 三种运行场景（空跑 / 联调 / 验收）

同一套世界、同一套程序，三种使用目的不能用一套跑法。LineSim 用 `--mode` 区分，**谁驱动世界、谁下判断**是唯一分界。

| 场景 | 启动 | 谁驱动世界 | 有没有料 | 仿真器做什么 | 用来验什么 | 出口 |
|---|---|---|---|---|---|---|
| **空跑** | `--mode dry` | 仿真器自己（带/轴动，不按按钮） | **一件都没有** | 不做任何判定 | 程序能不能跑起来、时序对不对、报警里有没有"空料误报" | 界面无红、无异常退出 |
| **联调/虚拟调试** | `--mode sim`（默认） | 上位机/PLC | 由上位机叫料 | 只演算与应答，不做判定 | 真程序接进来能不能控制世界 | 动作与上位机预期一致 |
| **演示** | `--mode demo` | 仿真器自己（含上料、替操作员按按钮） | 有 | 不做判定 | 让人看动作、学互锁 | 画面动起来、互锁能解释 |
| **验收** | `--mode accept` | 上位机/PLC | 由上位机叫料 | 采证 + 逐条判定，产出报告 | 满足判据了吗 | `report.json/.md` 全绿 |

**空跑的三条硬要求**（`SelfTest.CheckDryRun` 钉住）：

1. 开场不上料，`pieces[]` 必须为空；
2. 轴已使能、输送带已开（世界是活的，否则"空跑"退化成"什么都不发生"）；
3. 跑 3 秒后仍然没有料——防止"开场不铺、后面又按节拍偷偷上料"。

对照断言：同一个 `DemoDriver` 把 `feedParts` 打开必须真有料，证明空跑是**开关**而不是没实现。

**空跑的判据口径**：不判"有没有检出缺陷"，只判"程序链路有没有断"。具体是：

| 项 | 判据 |
|---|---|
| 通信 | 运控 `hello`/`poll` 正常，无 watchdog 停机 |
| 运动 | 每个运动命令 `accepted`，且轴真的动了（位置变化 >0.1mm） |
| 相机 | 每台相机 `/trigger` 返回 2xx 且能取到帧 |
| 视觉 | 空工位必须判"无工件"，不能因缺料报设备故障 |
| 安全 | 空跑不应触发任何限位/急停/跟随误差 |
| 状态机 | 全站停在 `Ready` 或 `Idle`，不出现 `Fault` |

### 1.8 快慢速与精度补偿

**同一套程序、同一套相机，跑 200mm/s 和 500mm/s 的结果不该一样。** 仿真器若"不管多快位置都对"，它只能证明语法没错，证明不了"这套工艺在目标节拍下够不够准"。

#### 三条退化来源

| 来源 | 公式 | 物理含义 |
|---|---|---|
| 运动模糊 | `blur_px = v × T_exp ÷ mmPerPx` | 曝光期间工件在动 → 边缘糊 → 亚像素中心偏移 |
| 视觉陈旧 | `lag_mm = v × T_v` | 触发到结果回来这段里工件还在走 → 系统性滞后 |
| 跟随滞后 | `follow_mm = v² ÷ (10 × accel)` | 轴追速度阶跃的稳态误差 |

#### 停走式 vs 连续式（决定"要不要补偿"）

| 工位类型 | 判定 | 拍照时工件速度 | 结论 |
|---|---|---|---|
| **停走式**（S1/S3/S4/S5/S7/S8） | 轴停稳后拍照 | **0** | 三条退化全为 0，**任何线速都免补偿** |
| **连续式**（S2 飞剪 / S6 分选） | 拍照时料仍在走 | 线速 | 三条全中，按阈值判是否补偿 |

> 这张表是唯一事实源（`SpeedAccuracy.MotionOfStation`）。把停走站也按"要补偿"算，会让补偿量恒为非零常数，既不合现场事实，也让"免补偿"这个结论永远出不来。

#### 补偿判据与补偿量

| 判据 | 阈值 | 超限后怎么办 |
|---|---|---|
| 模糊 | ≤1px | **补不掉**（信息已丢）：缩短曝光，或降速；给出该相机+曝光的**最高线速** |
| 视觉滞后 | ≤0.5mm | 前馈补偿：把目标点按 `v × T_v` 前移，或提前 `T_v` 触发 |
| 跟随滞后 | ≤0.1mm | 提前下发：目标点按 `v²/(10a)` 预置 |

**补偿后残余误差** = 只剩模糊那部分。这才是"提速后精度还能不能达标"的判据。

#### 各站速度验收（两组对照）

| 站 | 慢速组（200mm/s） | 高速组（500mm/s） | 提速必须做什么 |
|---|---|---|---|
| S1 | 抓取 ≤±0.2mm | 同左（停走式，理论上不受影响） | 只需保证"轴停稳再拍"，不许边动边拍 |
| S2 | 切标 ≤±0.5mm | 切标 ≤±0.8mm | 必做：相位前馈 + 曝光降到 ≤160µs（否则模糊 1.25px） |
| S3 | 特征 ≤±0.05mm | 同左（停走式） | 无 |
| S4 | 压深 ≤±0.05mm | 同左（停走式） | 无 |
| S5 | 融合 ≤±0.2mm | 同左（停走式） | 无；但转台时间会吃节拍 |
| S6 | 剔除 ≤±1mm | 剔除 ≤±1.5mm | 必做：`T_v` 前馈 + 跟踪相机确认 |
| S7 | 装配 ≥99% | 同左（停走式） | 无 |
| S8 | 读取率 ≥99.9% | 读取率 ≥99%（要降速或频闪） | 必做：`blur_px ≤1`，否则降速或频闪 |

**反向验收**（防"永远免补偿"的假绿）：把 S2 的曝光调到 1000µs，在 500mm/s 下必须判"需补偿且模糊超限"；把 S6 的视觉延迟注入到 30ms，必须判"滞后超限"。两条断言都不出现即视为模型失效。

### 1.9 相机视场（能拍到哪一段）

每台相机的视场在产线方向上是一段区间：

```
fov_mm   = width × mmPerPx
fovMin   = centerMm - fov_mm/2
fovMax   = centerMm + fov_mm/2
```

| 用途 | 判据 |
|---|---|
| 检测覆盖率 | 工位作业区（±80mm）必须被 `[fovMin, fovMax]` 完全覆盖 |
| 相邻相机重叠 | 同类型相邻工位视场允许不重叠（各站只看本工位） |
| 标定前提 | `centerMm` 取**本工位首轴停位**，不是设计值 |

**大屏可视化**：`/api/camera/{serial}?w=320` 返回该相机此刻的实拍 PNG（服务端降采样，2.5MB → 42KB），3D 里按 `fovMin/fovMax` 画出视场框。

> **取图与取帧是两件事**：`/snapshot` 不进帧队列、不增加 `triggers`。大屏刷新若走 `/trigger`，会和真正在取图的上位机抢队列，现场表现是"上位机偶尔少一帧"，而这个副作用在仿真器侧完全看不出来。断言 `SelfTest.CheckCameraSnapshot` 钉住这一点。

## 2. S1 视觉定位上料

### 2.1 教学目标

手眼标定（eye-in-hand）+ 视觉位姿 → 4 轴 PTP 抓取；来料随机 ±5mm/±5°；低置信度主动重拍；抓取滑移的放置补偿。

### 2.2 设备与参数

| 轴 | 行程 | 最大速度 | 最大加速度 | 重复定位 | 说明 |
|---|---|---|---|---|---|
| `S1.X` | 0–800 | 1000 | 3000 | ±0.02 | 龙门横梁 |
| `S1.Y` | 0–400 | 1000 | 3000 | ±0.02 | 龙门滑座 |
| `S1.Z` | 0–200 | 500 | 2000 | ±0.02 | 升降/吸嘴 |
| `S1.R` | ±180 | 360°/s | 1800°/s² | ±0.01° | 旋转轴（新增） |

| 相机 | 参数 |
|---|---|
| 型号/安装 | 手眼相机，装在 Z 轴下端，随动；工作距离 120mm |
| 分辨率/像素当量 | 1600×1200，**0.08mm/px**，FOV 128×96mm（覆盖 120×80mm 产品） |
| 曝光/触发 | 500µs，软触发；频闪光源 |
| 标定 | 2D 手眼（旋转+平移），9 点标定；残差 ≤0.1mm |

| IO | 类型 | 说明 |
|---|---|---|
| `DI_PART_AT_PICK` | DI | 取料位有件 |
| `DI_PALLET_AT_S1` | DI | 托盘到位 |
| `DI_VACUUM_OK` | DI | 真空建立 |
| `DI_GUARD_S1` | DI | 安全门关闭 |
| `DO_VACUUM` | DO | 真空阀 |
| `DO_PALLET_STOP` | DO | 托盘挡停 |

### 2.3 动作流程

```
Idle → Ready
  ↓ CycleStart（托盘到位 + 取料位有件）
Capture1：Z 到取料上方 60mm，手眼相机拍散件
  ↓ 视觉：模板匹配 + 亚像素中心 + 角度 + 置信度
Decide：置信度 ≥0.9 → 抓取；0.7–0.9 → 换高度/换角度重拍（最多 2 次）；<0.7 → 剔除并报警
Pick：PTP 到抓取点上方 20mm → 下降到 Z_pick → 真空 ON → 等待 DI_VACUUM_OK（≤100ms）
MoveToPallet：抬升 50mm → PTP 到托盘上方 → 手眼相机拍托盘定位标记
Place：按托盘标记 + 抓取滑移补偿下放 → 真空 OFF → 抬升
Verify：手眼相机拍放置结果（偏移/角度）
Done：写 poseAtS1，放行
```

### 2.4 关键时序

| 时刻 | 动作 | 预算 | 截止 |
|---|---|---|---|
| t0 | 托盘到位 + 取料位有件 | — | — |
| t0+0 | 触发 Capture1 | — | — |
| t0+0.5 | 曝光结束 | 0.5ms | — |
| t0+6 | 图像读出完成 | 5.5ms | — |
| t0+16 | 视觉结果（中心/角度/置信度） | 10ms | ≤20ms |
| t0+20 | 运动命令下发 | 4ms | ≤25ms |
| t0+250 | 到达抓取点 | 230ms | ≤300ms |
| t0+300 | 真空建立 | 50ms | ≤350ms |
| t0+500 | 到达托盘上方 | 200ms | ≤550ms |
| t0+700 | 放置完成 | 200ms | ≤750ms |
| t0+850 | 放置验证结果 | 150ms | ≤900ms |
| t0+900 | Done / 写履历 | — | **≤1200ms（节拍 2.0s）** |

### 2.5 视觉→运动

**像素→相机坐标**

```
x_cam = (u - cx) * mmPerPx
y_cam = (v - cy) * mmPerPx
```

**手眼变换（2D）**

```
[x_base]   [cosθ_h  -sinθ_h] [x_cam]   [tx_h]
[y_base] = [sinθ_h   cosθ_h] [y_cam] + [ty_h]
```

θ_h、t_h 由 9 点标定得到；残差 >0.1mm 判标定失效，禁止自动运行。

**抓取目标**

```
P_pick = P_base + R(θ_part) * [x_cam, y_cam]
R_cmd  = θ_part（限 ±180°，超过 ±5° 才转 R，避免无谓动作）
```

**放置补偿（抓取滑移）**

```
slip = P_pick_actual - P_pick_nominal     // 由放置验证反算
P_place = P_pallet_mark + clamp(slip, -1.0, +1.0)
```

**置信度与重拍**

- `conf ≥ 0.90`：直接抓取。
- `0.70 ≤ conf < 0.90`：Z 抬高 20mm 重拍；仍低则换环形光角度重拍；最多 2 次。
- `conf < 0.70` 或检测到两个以上粘连件：不抓，写入 `poseAtS1.confidence`，S6 剔除。

**放置验证**

- 偏移 >0.3mm 或角度 >0.5°：允许重放 1 次；仍超差 → NG，S6 剔除。

### 2.6 异常与安全

| 异常 | 检测 | 响应 | 恢复 |
|---|---|---|---|
| 取料位无件 | `DI_PART_AT_PICK=0` | 等待，超 5s 报警 | 补料后自动继续 |

### 3.3 动作流程

```
Idle → Ready（已回零/使能/门关）

WaitMark：主轴到 m = 160（切点前 80mm）
PreCapture：触发相机；视觉输出：
   - 标记中心相对画面中心 (du, dv) → e_mark
   - 标记完整性/污染（0/1）
   - 置信度 conf
Predict：m_mark_cut = m_mark_capture + v * (t_cut - t_capture)
Correct：e = m_mark_cut - 240；Phase_cmd = -e
   - |e| > 8mm → SkipCut + Reject（不硬追）
   - |e| ≤ 8mm → Phase 斜坡到 Phase_cmd（≤2mm/10ms）
CutWindow：主轴 180–300；主轴 210 刀下压；主轴 240 切点；主轴 270 刀抬起

Done：写 cutAtS2；下一周期从 600 开始
```

### 3.4 关键时序（名义 300mm/s，周期 2000ms）

| 主轴位置 | 时刻（周期内） | 动作 | 预算/截止 |
|---|---|---|---|
| 0 | 0ms | 周期开始，刀上位 | — |
| 160 | 533ms | 前触发拍照 | 触发抖动 ≤1ms |
| 160+ | 558ms | 视觉结果 | T_v ≤25ms |
| 200 | 667ms | 相位修正完成 | 距切点 ≥133ms |
| 210 | 700ms | 刀下压 | T_a ≤20ms |
| 230 | 767ms | 刀到低位（DI_KNIFE_DOWN） | 超时 15ms 判故障 |
| 240 | 800ms | 切点 | e_cut 记录 |
| 270 | 900ms | 刀抬起 | — |
| 275 | 917ms | 后触发拍照 | — |
| 275+ | 942ms | 切后结果 | T_v ≤25ms |
| 600 | 2000ms | 下一周期 | 节拍 2.0s |

### 3.5 视觉→运动

**标记位置误差**

```
e_mark_capture = (u_mark - cx) * mmPerPx + L_offset
e_mark_cut     = e_mark_capture + v * (t_cut - t_capture)
```

`L_offset` 是相机中心到切点的固定偏移（标定值）；正方向 = 膜前进方向。

**相位修正（符号约定）**

```
Phase_cmd = -e_mark_cut
```

- 标记晚到（`e_mark_cut > 0`）→ `Phase` 为负 → 切点推迟到更大的主轴位置。
- 标记早到（`e_mark_cut < 0`）→ `Phase` 为正 → 切点提前。
- `|Phase_cmd| > 8mm`：不追，跳过本刀并剔除该膜段。
- 斜坡：`Phase += clamp(Phase_cmd - Phase, -2, +2)` 每 10ms；斜坡期间监视跟随误差，>2mm 时降到 1mm/10ms。

**切后验证**

```
e_cut = x_cut_edge - x_mark_center
L_cut = m_cut_actual - m_cut_prev
```

- `|e_cut| ≤ 0.5mm` 且 `|L_cut - 600| ≤ 1.0mm` → OK。
- 否则 NG；并把 `Phase_bias += -0.2 * (L_cut - 600)`（限 ±1mm）作为下一件的慢补偿。

**缺陷决策**

| 视觉结果 | 动作 |
|---|---|
| 标记完整、conf ≥0.9、无缺陷 | 正常切 |
| 标记完整、conf ≥0.9、缺陷在标记 ±20mm 内 | 跳过本刀，膜段剔除 |
| 标记完整、缺陷在膜段其他位置 | 正常切，`cutAtS2.defect=1`，S6 剔除 |
| 标记缺失/破损/conf <0.8 | 跳过本刀，膜段剔除；连续 3 次停线 |
| 视觉超时 >25ms | 跳过本刀，膜段剔除；连续 3 次停线 |

### 3.6 异常与安全

| 异常 | 检测 | 响应 | 恢复 |
|---|---|---|---|

### 4.4 关键时序

| 时刻 | 动作 | 预算 |

### 4.5 视觉→运动

```
ΔWCS = (Δx, Δy, Δθ) = measured_blank_pose - nominal_blank_pose

| t0+835 | 慢压到位 | ≤400ms |
| t0+935 | 保压结束 | 100ms |
| t0+1135 | 回程结束 | ≤200ms |
| t0+1165 | 压后测量 | ≤30ms |
| t0+1200 | Done | ≤1.5s（节拍 2.0s） |

### 5.5 视觉→运动

```
d_cmd = H_avg - H_target + d_comp
e = H_final - H_target
d_comp_next = clamp(d_comp - 0.5*e, -0.05, +0.05)
```

- 力-位移包络：`F(z) = k*z + c*v`，k 正常 100–400N/mm；超出即判"压装异常"。
- 压装深度误差 `|e| ≤0.05mm`；连续 3 件同向超差 → 停线检查模具/来料。
- `H_avg` 测量不确定度 ≤0.01mm（9 点标定 + 5 点平均）。

### 5.6 异常与安全

|---|---|---|---|
| 工件缺失 | `DI_PART_S4=0` | 不压 | 等料/剔除 |
| 测量超差 | `|H_avg-H_nominal|>0.2` | 不压，剔除 | 自动 |
| 压头不在上死点 | `DI_PRESS_TOP=0` | 禁止启动 | 回上死点 |

```

- 对焦指标：Tenengrad/Laplacian 方差；峰值搜索步距 0.1mm，范围 ±2mm。
- 码值唯一性：本地最近 10000 条 + 数据库；重复即报警。
- 读码失败：3 组曝光都失败 → NG，送 NG 道，不写追溯。

### 9.6 异常与安全

| 异常 | 检测 | 响应 | 恢复 |
|---|---|---|---|
| 无码 | 3 组曝光均无码 | NG，送 NG 道 | 自动 |
| 读不出 | 解码失败 | 3 组重试；仍失败 NG | 自动 |
| 重复码 | 唯一性检查 | 报警，NG | 人工处理 |
| 数据库写失败 | 写库超时/异常 | 停线，报警 | 人工恢复 |
| 运动模糊 | `blur_px > 1` | 降速/频闪 | 自动 |
| 货叉未到位 | `DI_FORK_INPOS=0` | 禁止取放 | 复位 |
| 库位占用 | 目标库位有货 | 改道/报警 | 人工 |
| 急停 | `DI_ESTOP=0` | 停堆垛机/货叉 | 人工复位 |

## 12. 开放问题

1. **S2 的膜切工艺是否要落在托盘线上**：当前设定"连续膜切 600mm 段，覆盖到托盘"，需要确认物理可实现性；若不可，S2 改为独立切膜单元，托盘只接收切好的膜段。
2. **S6/S7 的物理顺序**：现有世界 ST6 是分选、ST7 是检测；本任务书把 S6 分选放在 S7 装配之后（先装配再分选）。需要确认是否调整物理顺序，或把 S7 装配放到 ST12（返修位）。
3. **S9/S10 选修**：锁螺丝、打磨是否进入正式课程表。
4. **追溯库形态**：本地 JSON/SQLite 还是外部数据库；影响 S8 写库失败用例。
5. **视觉模型精度**：S3 的 0.02mm/px、S4 的 0.02mm/px 是仿真参数；真机选型需按 FOV/景深复核。
