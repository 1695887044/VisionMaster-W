## ⚠️ 最需要记住的三条

1. **脚本必须是"顶层语句"**——Roslyn 的 `CSharpScript` **会忽略手写的 Main / 自定义入口，只执行顶层**。可以定义 class / 方法 / LINQ，但"干活"的语句要在顶层。
2. **命名空间遮蔽**：本工程命名空间末段就叫 `CSharpScript`，**会遮蔽 Roslyn 同名类型**——必须用 `global::Microsoft.CodeAnalysis.CSharp.Scripting.CSharpScript`。
3. **引用集整目录扫描不能删**——`halcondotnet` 在 `deps.json` 里是 `"type": "reference"`，**不会进 TPA**。少了整目录扫描就会出现"测试能过、现场报 `HImage could not be found`"。

## 维护约定

1. **只改主文档**。`C#脚本插件.md` 是唯一事实来源；归档件只作历史留档。
2. **动态端口必须在 `ApplyConfigValues` 里重建**（`LinkPorts` 之前），否则按名连线失败。
3. **`ScriptVarType` 按数值持久化**（`.vms` 里 `"Type": 6`）——**新增枚举成员只能追加到末尾**，不能插队/改序。
4. **引用集整目录扫描不能删**；白名单改动 / 新增 dll 都要**重启宿主**（引用集只构建一次）。
5. **防影子替换**：与宿主同名的扩展 dll 一律不加载（halcondotnet 版本冲突教训）。
6. **xshd 里 `#` 必须写成 `\#`**，`Span` 下不能直接放 `Rule`——否则编辑器空白不可编辑。
7. **失败契约**：脚本抛异常 = 失败；`Context.Fail()` = 显式失败；**返回值不作为状态**。
8. 建议后续补 `FlowCanvasChecks/CSharpScriptChecks.cs`（默认脚本可编译 / 动态端口 / `Context.Fail` / 输出类型错误中文提示 / 白名单 7 级判定 / 引用集含 HalconDotNet）。
