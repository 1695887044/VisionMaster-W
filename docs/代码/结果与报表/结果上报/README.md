## ⚠️ 最需要记住的三条

1. **异步队列不占节拍**（默认 `AsyncMode=true`）——流程线程只做"取值 + 组 JSON + 入队"（微秒级），HTTP 在后台线程。MES 挂了也拖不垮检测。
2. **类型保真**——端口值是 `double` 就写 `12.3` 而不是 `"12.3"`，**MES 数值型字段校验靠它**。
3. **中文不转义**——`UnsafeRelaxedJsonEscaping`，否则 `件A判定OK` 变成 `\u4EF6`，钉钉/企微看不懂。

## 维护约定

1. **只改主文档**。`结果上报插件.md` 是唯一事实来源；归档件只作历史留档。
2. **动态端口必须在 `ApplyConfigValues` 里重建**（`LinkPorts` 之前），否则按名连线失败。
3. **`HttpPayloadBuilder` 纯内存无 IO**——**预览与真实发送必须共用同一套逻辑**，保证"面板看到的"和"服务器收到的"永远一致。
4. **中文不转义**：序列化与 `{名}` 注入**都**要用 `UnsafeRelaxed`（口径必须一致）。
5. **UTC 转换只有一个出口**（`FormatTime`）——内置时间戳与值池 DateTime 都要走它。
6. **失败必须说话**：`IsNg` 判定升级（数值比 → 布尔比 → 字符串比），不许静默成功。
7. **测试件 `allowSpool:false`**——测试失败不该污染真实断网账本。
8. **跨线程**：异步模式 `LastResult` 在队列线程赋值 → 摸 UI 必须 `Dispatcher.BeginInvoke`。
9. **实时件永远优先**，补传不插队；补传沿用原 `X-Upload-Id`。
10. 建议后续补 `FlowCanvasChecks/ResultUploadChecks.cs`。
