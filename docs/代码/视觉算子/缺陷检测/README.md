## 维护约定

1. **只改主文档**。`Blob缺陷检测插件.md` 是唯一事实来源；归档件只作历史留档，不再更新。
2. **新增内容先进主文档**，确定需要保留历史过程时，再把过程记录单独归档到本目录。
3. **修 bug 必须同时补回归断言**（`FlowCanvasChecks/BlobDetectChecks.cs`），并在主文档第 4 章记录「现象 → 原因 → 修法」。
4. **端口只增不改**：既有 7 个输出端口的名字/类型/顺序一律不动，老方案连线不受影响。
5. **新增筛选/判定参数**必须分清"筛选"（算不算缺陷）与"判定"（合不合格），并在主文档 1.3 节体现。
6. **HALCON 相关新坑**统一追加到主文档 4.5 节的踩坑表。
