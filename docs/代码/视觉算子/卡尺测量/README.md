## ⚠️ 最需要记住的一条

> **矩形要「横跨」被测的边/缝**：半长 **L1** 方向 = 扫描方向（与边垂直），半宽 **L2** 方向 = 卡尺阵列排布方向。
> 摆错了不是"测不准"，而是**根本扫不到边**。详见主文档 1.1 节与附录 C 案例 6。

## 维护约定

1. **只改主文档**。`卡尺测量插件.md` 是唯一事实来源；归档件只作历史留档，不再更新。
2. **几何约定必须写探针实测裁决**，不能靠推理（φ 约定、均布方向都曾因推理出错被推翻）。探针要覆盖 `φ≠0` 的非对称位置，否则测不出来。
3. **尽快补 `FlowCanvasChecks/CaliperChecks.cs`**，把主文档 5.5 节的真值表（宽度 40.0 / 两点距 220.0 / 点线距 196.5 / 圆直径 200 / 角度 30-90-150）固化成正式断言——当前验证靠已删除的临时脚手架，不可复现。
4. **修 bug 必须同时补回归断言**，并在主文档第 4 章记录「现象 → 原因 → 修法」。
5. **每把卡尺必须全部检出**，缺一把即失败——不做"部分平均"（计量最危险的失败模式是"错误但不出错"）。
6. **HALCON 相关新坑**统一追加到主文档 4.5 节的踩坑表；注意 `fit_line` 与 `fit_circle` 的 algorithm 值集是两套。
