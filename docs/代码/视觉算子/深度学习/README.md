## ⚠️ 最需要记住的三条

1. **模型是客户资产，不内置**；`task` 不匹配的模型被**明确拒绝**（不会拿错格式硬算）。
2. **不做 OK/NG 判定、不做结果投射**——只输出"是什么/多少分"，判定交下游。
3. **归一化/缩放选错是静默故障**：分类输出"已是概率"与"logits"要判别（否则分布被压平）；`ResizeMode` 按训练预处理选。
