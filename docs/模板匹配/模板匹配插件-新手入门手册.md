## 0. 先认识它：这个插件是干嘛的？

它是机器视觉软件里的一个**功能模块（插件）**，名字叫**"模板匹配"**。

打个比方：你在产线上要找一块零件的"位置"和"朝向"——比如"这个螺丝孔在画面左上角、歪了 5 度"。
人工看一眼很容易，但机器需要一种办法自动完成。模板匹配就是干这个的：**先告诉机器"目标长什么样"（学习），以后每次来一张新图，机器就自动找出目标在哪里、转了多少度。**

插件输出的结果不是一张图，而是几个数字和一张"画好框"的图：

- 目标中心在第几行、第几列（精确到小数）
- 目标转了多少度
- 匹配得有多准（分数 0~1）
- 一张在原图上画了轮廓和文字的**标注图**，方便人直接看结果

## 1. 设计思想

### 1.1 核心原理：它比的是"形状"，不是"像素"

很多人听到"模板匹配"会以为是把一张图存下来、后面来一张新图就逐像素对比。
**本插件用的不是这种笨办法**，而是业界标准的**形状匹配（Shape-Based Matching）**：

- 学习时，它不只记住一张图，而是从你框出的区域里**提取"边缘特征"**（哪里有明暗边界、边界朝哪个方向）。
- 寻找时，它在一张新图上**只找这些边缘特征的组合**，并不要求像素一模一样。

好处一目了然：
- 光照稍微变亮变暗、对比度变化，**照样能找得到**（因为比的是"形状/边"，不是"颜色/亮度"）。
- 目标稍微转个角度、远近距离变一点（缩放），也找得到（只要你开了对应开关）。

> 小知识：**边缘特征**可以想象成"把一张照片描成线稿"。两张照片只要线稿能对上，就认为是同一个东西。

### 1.2 目标：输出"位置 + 朝向"，并顺手帮你摆正

插件最终给你两样东西：
1. **位姿**（位置 + 角度）——下游的抓取、测量、裁剪工具要用它。
2. **一张"归一化图像"**（可选开关）——把目标"掰"回标准位置、标准角度再输出，这样下游那些"固定位置画框"的工具（裁剪、卡尺、Blob 分析等）**不用任何改动**就能直接用，产品哪怕歪着来也不怕。

### 1.3 架构思路：像积木一样拼进流水线

插件不是孤立运行的，它遵循整套软件的插件规范，可以拖到**流程画布**里，和其他步骤串成一条自动线：

- **端口（Port）**：左边接"上游图像"和"配方名"，右边输出"分数/位置/角度/标注图"等。把它理解成"插头的输入输出端"即可。
- **配置态 vs 运行态分离**：你在配置界面里"教"它模板（学习），保存进方案文件；运行时它只负责"找"，不弹界面、不让人点。
- **模板库（多配方）**：一条产品一个"配方"。换产品时，只要给一个"配方名"（也可以连一根线自动切换），它就自动换对应的模板去匹配。

## 2. 技术特点

下面这些是本插件相对"裸用算法"做得更省心、更稳的地方。看不懂没关系，知道"有这些能力"即可。

| 特点 | 通俗解释 |
|---|---|
| **形状模型 + 缩放变体** | 核心算法来自 HALCON。目标会远近变化时，自动建"缩放模型"，远近都能认。 |
| **金字塔加速** | 算法先把图"缩小好几倍"粗找一遍、再放大细找。层数越多越快，但太小目标可能漏。一般 4~6 层。 |
| **角度/缩放范围** | 你告诉它"目标最多转 ±15 度"或"大小在 0.5~2 倍之间"，模型就只在合理范围里找——又快又稳。 |
| **梯度阈值（对比度门限）** | 决定"多明显的边才算特征"。太高特征太少、太低会把噪声当特征。设 0 则由算法自动定。 |
| **极性（白黑方向）** | 光照会反相（亮变暗）时选"忽略极性"；平时用"使用极性"更快更准。 |
| **涂抹排除区** | 反光面、偶尔变动的图案，可以"涂掉"不让它学习，避免误学。掩膜随方案保存。 |
| **原点锚定（自校正）** | 学习时内部做一次"自己找自己"，自动修正 1~2 像素的系统性偏差，保证输出位置 = 你画框的中心。 |
| **配方驱动切换** | 运行时按"配方名"端口自动选模板，多产品共线不用来回改配置。 |
| **位姿归一化图像** | 把目标刚性变换回标准位姿再输出，下游固定框工具零改动通用。 |
| **模板随方案保存** | 模型以 base64 形式存在方案文件里，换电脑、重开软件都不丢。 |
| **失败也留标注图** | 就算没找到目标，也会输出"原图 + 红字原因"，产线上能立刻看到现场，不黑屏。 |

## 3. 使用方式

### 3.1 安装与配置

- 插件已内置在 `Plugins/Plugin.Matching` 工程里，**正常编译软件即可使用**，无需额外安装。
- 它依赖机器视觉算法库（HALCON）。只要软件本身能跑（能显示相机图），模板匹配就能用。
- 在流程画布里找到"模板匹配"节点，拖到画布上即可。

### 3.2 配置界面长什么样

打开节点配置界面，你会看到**左边参数、右边图像**的布局，参数区分成四张卡片：

1. **① 模板**：管理模板库（新增/删除/设为默认）、选参考图、画框、**创建模板**按钮、模板预览。
2. **② 提取参数**：决定"模型怎么学"（角度范围、步长、梯度阈值、极性、缩放、金字塔层数）。**改这里任意一项，都必须重新点"创建模板"**（界面右上角的状态徽标会变橙色提醒你）。
3. **③ 匹配参数**：运行期参数（分数下限、匹配数、重叠、激进度），改完**立即生效**，不用重建模板。
4. **④ 输出**：配方名端口、运行显示窗口、是否输出归一化图。

### 3.3 一步步操作（照做就行）

> 思路：先接图 → 把一张"标准样品"的图弄进来 → 框住特征 → 学习 → 以后自动找。

1. **接上游图像**
   在流程画布上，把"图像采集"之类的上游节点的输出，连到本节点的 `Image` 端口。
   （也可以直接在配置界面里填"参考图"路径载入一张局部图，单独调模板时用。）

2. **把图带进配置界面**
   连好线后，在流程里**试运行一次**，上游图就会自动传进来显示在右侧画布；
   或没连线时，在"参考图"框里填一张本地图片路径，点"载入"。

3. **框选模板区域**
   在右侧图上**右键 → 新建矩形 / 圆形 / 椭圆**，把目标上**稳定、独特、会跟着产品一起动**的特征框起来，
   例如丝印、边角组合、安装孔位。**不要框反光面或会变的区域**（这类可以后面用"涂抹编辑"挖掉）。

4. **点"创建模板"**
   按钮在点完后会学习模型，并随方案保存。状态徽标变绿表示"已创建"。

5. **按需调参（可选）**
   - 目标会转一点角度：在"提取参数"里设好最小/最大角度（如 ±15°）。
   - 目标远近会变：勾选"启用缩放匹配"，设好最小/最大比例。
   - 这些改完**再点一次"创建模板"**。

6. **运行**
   连线跑流程即可自动定位。结果会通过端口给出（位置、角度、分数）并在主界面显示标注图。

### 3.4 输出端口一览（接下游用）

| 端口名 | 含义 |
|---|---|
| `Score` | 最高分实例的匹配分数（0~1，越接近 1 越像） |
| `Row` / `Column` | 最高分实例的中心行 / 列（亚像素精度） |
| `Angle` | 最高分实例的角度（度） |
| `MatchCount` | 本帧命中几个目标 |
| `Rows/Columns/Angles/Scores/Scales` | 所有命中实例的数组（按分数从高到低） |
| `MeasureImage` | 标注图：原图 + 命中轮廓 + 判定文字 |
| `AlignedImage` | 位姿归一化图（目标被摆回标准位置，需手动勾选开启） |

### 3.5 调参口诀（新手最常问）

- **找不到目标**：先把"分数下限"降到 0.3 试试，往往是光照变了。
- **误匹配（乱报）**：把"分数下限"往上调，或换一块更独特的模板区域。
- **产线不稳、偶尔漏**：把"搜索激进度"调小（0.5~0.7）。
- **找得慢**：收窄角度/缩放范围、减少金字塔层数里不必要的部分。
- **改了"提取参数"（②区）**：**一定要重新点"创建模板"**，否则还是用旧模型。
