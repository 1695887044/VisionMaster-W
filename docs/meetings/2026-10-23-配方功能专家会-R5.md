# 2026-10-23 配方功能专家会 · R5（界面与操作员流程定稿）

- 输入：R3 数据模型 + R4 运行期 + 三份界面/交付提案（ui / hmi / docs）
- 性质：只读评审；未构建、未截图、未改 XAML
- 结论：**界面定稿**。四个面、一份状态快照、三个新下沉控件；管理器独立弹窗；
  操作员可切换（含点位配方需勾安全确认），编辑限工程师；首件确认放在保存之前。

## 一、四个面（职责与边界）

| 面 | 入口 | 职责 | 不做 |
| --- | --- | --- | --- |
| 配方管理器 | 文件菜单「配方管理」（与「方案列表」同级），Ctrl+R | 新建/复制/删除/捕获/比较/应用/应用并保存/导入导出 | 不控流程、不写 PLC、无第二套撤销、不编辑 `.vms` 其它配置 |
| 操作员 chip + 快速切换 | 标题栏居中列、方案名右侧；点 chip 出浮层（搜索+最近 5 条）→ 确认框 | 显示当前配方与状态、发起切换 | 不编辑内容、不新建删除、不显示参数值 |
| SCADA 运行态底条 | 现有 26px 底条左组 | 只读「配方 A · 偏离 3」 | 无切换控件、无应用按钮 |
| Web 运行态 | 运行页顶条右侧（v1.1） | 同上三项、同文案 | 只读，R132A 边界内 |

- chip 必须在**标题栏**，不能进 RunBar：RunBar 在 Config 模式整条 Collapsed（`Shell.xaml:1306-1308`），
  而换型常在组态模式做。反证：切到组态模式，chip 仍须可见可点。
- 状态栏**要加**「当前配方」一格：运行/调试/自由模式放左段运行态组，组态模式放静态组态段
  （两段互斥，不是一段加条件）；退路是右段（始终可见）。
- 管理器入口放文件菜单，**不进「视图」**（视图 8 项全是 ShowPanel/分屏，语义是「显示什么」）；
  **不改 `SolutionAction`**（公共契约，值可能落进 Layout.xml）。快捷键只给「打开管理器」Ctrl+R；
  应用/应用并保存**永不给全局热键**（不可撤销且有机械后果，唯一手势应是确认页按钮）。

## 二、配方管理器

- 布局：左侧 320px 列表 + 右侧详情（头 64 / 参数表 `*` / 底栏 56）。
- 列表列 4 列：选中 2px 条 | 名称 `1*` | 编码 88 | `v3` 44 | 状态 chip 64；
  更新人/时间进详情头（8 列必截名称）。
- 参数表列：勾选 32 | 目标 `1.3*` | 类型 96 | 配方值 `1.2*` | 当前值 `1.2*` | 差异 chip 88。
- **控件 = DataGrid（`DialogDataGrid` 家族）**：
  - 不用 `ListView+GridView`：`GridViewColumn.Width` 只收 double、无星号列，两个值列必写死像素，1000 档溢出。
  - 不用 `FlatPropertyGrid`：它是反射单对象编辑器，没有「配方值/当前值」双侧对照与行级状态位；
    `RequireRefresh` 整表重建会丢正在编辑的行（R104）。
- 动作三处：工具条（新建/复制/删除/导入/导出）、详情底栏（捕获/比较/应用 primary/应用并保存 secondary/关闭 ghost）、
  列表右键（复制/删除/设为当前）。
- 新下沉 3 个键（进 `UI/Controls/Themes/Dialog/`）：
  ① `DialogRecipeStateChip`（当前/偏离/未保存/回滚未完成/悬空，五面复用）；
  ② `DialogDiffRowStyle`（2px 左条 + 行底 + 行尾 chip，参数表与摘要两处）；
  ③ `DialogValueCompare`（等宽双值 + 箭头 + 差异高亮，两处）。
  其余全复用 `DialogCardBorder/Title`、`DialogDataGrid*`、`DialogChip*`、`DialogEmptyState*`、
  `DialogPrimary/Secondary/Danger/Ghost/IconButton`、`DialogInput/SearchInput/Combo/CheckBox`、
  `DialogFocusVisual`、`DialogToolTipStyle`。

## 三、切换确认框（独立第三弹窗）

- 必含：名 + 编码 + `ContentVersion v3`（等宽）+ 状态 chip；更新人/时间（本地时区，绝对+相对）；
  上次应用（人/时间/版本）；`当前 → 目标`（未应用 / A(v2) / 同配方须写「仅修复偏离」）；目标集总数与三类分解。
- 差异摘要：三组（步骤参数/本地变量/运动点位）× 四计数（修改/不变/孤儿/类型不符；点位组第四项换「轴缺失/越界」）。
  组默认折叠只显计数 + 前 3 条，框内展开滚动，不新开窗。
- 点位组：组头 chip +「写入点位不改流程路径」；行显 `轴名·P3`、位置、速度（0=「沿用控制器」）；
  离线/未回零/未使能/轴停用逐行警告。
- **被 v1 排除的项必须列出**（网络变量、触发源变量、HImage/路径/相机 Settings）→ 放「本次不会改动」折叠区，
  逐条给原因，且不计入「修改」。判据：R2 D3 要显式拒绝，界面不能让人以为整机换型完成。
- 按钮：
  - 硬失败（孤儿/已链接/类型不符/网络变量/点位前置/运行中/回滚锁定）→ 主按钮 disabled、标题「无法应用」、逐条「定位」；
  - 软警告（软限位/轴停用/离线/未回零）→ 主按钮转 warning、文案「仍要应用（N 项警告）」、默认焦点落「取消」；
  - 应用 = Primary + IsDefault；应用并保存 = Secondary（审计不可用时 disabled）；取消 = Ghost + IsCancel。
- 目标集与未保存改动重叠 → 第二层三选一，默认取消。

## 四、四种状态 × 三个面（同一份 `RecipeStatusSnapshot`）

| 态 | 标题栏 chip | 状态栏 | SCADA 底条 |
| --- | --- | --- | --- |
| 已应用未保存 | 黄点「A·未保存」 | 「A v3·已应用未保存」+ 保存链接 | 黄点「A·未保存」 |
| 已偏离 | 橙点「A·偏离 3」 | 「A v3·偏离 3 项」+ 悬停明细 | 橙点「A·偏离 3」 |
| 回滚未完成 | 红点「回滚未完成」 | 红条「N 项未恢复」+ 两出口 | 底条上方整行红条 |
| 配方悬空 | 红点「配方悬空」 | 「已丢失」+ 清除指针 | 「配方 —（悬空）」 |

- 标题栏只显一个，优先级：回滚 > 悬空 > 未保存 > 偏离；全量进 ToolTip。
- 状态栏放 column 0（组态模式那一列本就空着，零新增占位）。
- 刷新：偏离订阅 `FlowModel.Version` + 变量写通知；点位无 INPC → 每拍重读 + 指纹短路（R138），500ms；
  防抖 300ms 合并；应用/保存/切换后强制立即刷一次。
- 回滚锁定横幅必须挂在**主窗口**（RunBar 之下、停靠区之上新增 Auto 行），不能在任何弹窗内——
  关窗即失去唯一出口；不能挂 RunBar 内（Config 下 Collapsed）。

## 五、权限矩阵（定稿）

| 动作 | 未登录 | 操作员 | 工程师 | 管理员 |
| --- | --- | --- | --- | --- |
| 查看 | ✓ | ✓ | ✓ | ✓ |
| 切换/应用 | ✓（含点位配方需勾「我已确认轴处于安全状态」） | ✓ | ✓ | ✓ |
| 编辑/新建/复制/删除/捕获 | ✗ | ✗ | ✓ | ✓ |
| 导入/导出 | ✗ | ✗ | ✓ | ✓ |
| 发布/设为默认 | ✗ | ✗ | ✗ | ✓（v1.1） |

- 判据：R4 §六「应用不动轴」，安全性押在全轴静止 + 运行门闸，不押角色；收给工程师会让夜班无法换型。
- 禁用理由三处同文案：ToolTip「需要「工程师」权限，当前是「操作员」」+ 弹窗底部 hint + 审计 Denied；
  **禁用件必须 `ToolTipService.ShowOnDisabled=True`**，否则 WPF 禁用后 ToolTip 不弹。
- 必须订阅 `ScadaAccessPolicy.PropertyChanged` 触发 `RaiseCanExecuteChanged`，否则「已登录但按钮还灰」。

## 六、命令与宿主集成

- 命令（宿主 `RecipeService`，不放 Core）：
  `OpenManager`、`Apply(RecipeId)`、`ApplyAndSave(RecipeId)`、`Capture(RecipeId)`、`CreateFromCurrent`、
  `New`/`Duplicate`/`Rename`/`Delete`/`ClearActive`、`Import`/`Export`、`RefreshDeviation`。
- 状态：`State`（Idle/Sealing/Prechecking/Applying/Verifying/Committed/CommittedUnsaved/RollbackFailed/Rejected/Cancelled）、
  `SaveState`（NotRequested/Saving/Saved/Failed）、`ActiveRecipeId/Name/ContentVersion`、
  `IsDeviated/DeviationCount/DeviationSummary`、`HasRollbackFailure/RollbackItems`、`IsDangling`、
  `CanApply/CanApplyAndSave/CanCapture/CanEdit`、`IsAuditAvailable`、`StatusText/StatusTone`、`LastError`。
- 判权位置：① `CanExecute` 每次现算（不缓存）→ 按钮置灰；② 执行体首行再判一次；
  ③「应用并保存」额外判 `IsAuditAvailable`。
- 命令体必须自带 try/catch：`AsyncDelegateCommand` 吞异常（`ShellViewModel.cs:795-799`），应用失败被吞=假成功。
- `CommittedUnsaved` **不加标题 `*`**：本仓刻意没有 IsDirty；加 `*` 等于引入第二套脏判据。
  改为 chip 自带「未保存」角标 + 状态栏后缀「·未保存」。
- 退出不新增阻塞式确认：沿用 `Autosave` 草稿 + 下次启动提示；chip 上明示「已应用·未保存」。
- 「应用并保存」抽 `SaveToPathAsync(path)`：布局 Capture + 变量 Capture + 通讯 Capture + `SaveAsync` + 回写路径 + `CopyAlongside`；
  成功提示移出抽取段；`CopyAlongside` 仅路径不同时调用。未落盘方案强制另存。
- 切换方案：`ActiveRecipeId` 随 `SolutionModel` 走，不迁移；UI 订阅 `Workspace.PropertyChanged(CurrentSolution)`，
  不挂 4 个 `SwitchSolution` 调用点。`CommittedUnsaved` 时切方案必须三选一「先保存/放弃并切换/取消」。

## 七、现场 SOP（定稿，首件在保存之前）

| 步 | 谁 | 看什么 | 失败怎么办 |
| --- | --- | --- | --- |
| 0 停线清料 | 操作员+班长 | 无运行中、SCADA 已退出运行窗口、工位无在制件 | 停不下来→排障页；禁止带件切 |
| 1 选配方 | 操作员 | 名+Code+ContentVersion+LastAppliedAt | 权限不足→叫工程师；悬空→先清指针 |
| 2 预检 | 系统出报告，工程师确认 | 五类差异、点位前置、软限位警告、网络/触发源拒绝 | 整单拒绝：按报告修，不许逐条跳过 |
| 3 应用 | 系统执行，操作员旁站 | 状态机到 Committed；拒绝原因 | RolledBack→值已回原样，可修后重试；RollbackFailed→红横幅，只走两出口 |
| 4 首件确认 | 操作员+质检 | 首件结果与 Code 对应；chip 仍是「已应用未保存」 | 不合格：未保存→「从磁盘重载」；已保存→前向切回上一配方 |
| 5 保存+审计 | 工程师 | 审计两行（应用/保存）；无「审计不可用」横幅 | 保存失败→保留内存值、CommittedUnsaved，不得关机 |
| 6 量产 | 操作员 | 底条配方名+版本、偏离=0 | 偏离>0→停线，重新应用或捕获成新配方 |

- **首件在保存之前**是本设计的现场价值：不合格时一次「从磁盘重载」即回旧值，不污染配方、不留假审计。
- 操作员必须看到的 6 件事：当前配方（名/Code/版本）、保存态、偏离（点数+首个目标）、
  回滚未完成（未恢复项+锁定）、能不能切（运行中/封门中/权限不足）、横幅区（审计不可用/旧版覆盖/轴身份未建立）。
- 培训三页：操作员（六个看板/七步 SOP/四状态处置/何时叫工程师）、工程师（候选与捕获/五类差异/保存链/版本 2.0）、
  排障（拒绝原因字典/回滚未完成/审计失败/悬空与旧版覆盖）。每页 3 个「不要」。

## 八、验收场景（8 个，含 2 个失败场景）

1. 正常闭环（应用→首件→保存→审计两行）：改坏=写入后把值悄悄改回旧值，终检必须红。
2. 运行中拒绝（含暂停）：改坏=删「封门后复判」，应红。
3. 未保存三选一：改坏=默认由「取消」改成「先保存再应用」，应红。
4. 第 N 项失败整单回滚：改坏=逆序改顺序，数组/引用场景红。
5. **失败**：回滚中再抛：改坏=去掉「锁定后续 apply」，应红。
6. **失败**：保存失败（只读目录）：改坏=保存失败后回滚值，应红（值须仍新、CommittedUnsaved）。
7. 悬空+旧版覆盖：改坏=自动选第一个配方，应红。
8. 点位（Speed=0 保留、越界不夹取、引用不换实例）：改坏=把越界值夹到限位，应红。

## 九、v1 已知边界（必须进手册）

B1 不写 PLC：网络变量整单拒绝，PLC 设定值走「按配方号自取」或流程写变量。
B2 仅停止态（暂停算运行），无排队、无热切换。
B3 全方案单一配方。
B4 无撤销栈：撤销=前向切回上一配方（新审计行），保存后同样。
B5 白名单外不随配方走（通讯地址、卡/轴映射、软限位、曝光增益、模型/模板/路径、HImage、动态列名、触发源变量）。
B6 点位只改配置，流程仍按步骤 Target。
B7 跨机台只支持整份 `.vms` 复制（带走地址与布局）；单条导出导入 v1.1。
B8 警告放行：离线/未回零/未使能/轴停用/报警/软限位越界不夹取、不做快照校验；AxisId 空的轴不可配方化；
旧版打开丢配方只告警。
