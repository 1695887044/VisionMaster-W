## 12. 中止条件与退出条件

**立即中止（整批）**

1. `validate-plans.ps1` 不是 `OK` 或计数不等于 `47 / 26 / 205`；
2. 出现两个 `VisionMaster` 实例（`SingleInstanceCheck` 会踢掉先启动的那个）；
3. 任一 `high` 风险计划在二次确认环节未获人工确认；
4. 任一计划报 `MISSING_SELECTOR` 且该步是后续步骤的前提（按契约升级回 planner）；
5. 产品异常退出 / 主窗口消失（`PRODUCT_DEFECT`，只报告不改码）。

**单条中止**：`on_fail=stop_and_report` 的步失败 → 记 FAIL（含步号/期望/实际/证据路径），跳到下一条计划；`high` 风险计划失败 → 整批停。

**退出条件**

- 42 个执行项每项都有状态（PASS / FAIL / BLOCKED / UNVERIFIED / SKIPPED / NOT RUN），**不允许空白**；
- 汇总行写六类计数，不写「全部通过」；
- 失败项带步号 + 期望 + 实际 + 证据路径；
- 证据落点：`artifacts\logs\20261026\plan-<id>.log`、`artifacts\render\20261026\<batch>\<id>-step-<n>.png`、`artifacts\logs\20261026\uia-<id>-step-<n>.txt`；
- runner 收工必须写 `docs\架构文档\交接报告\交接报告-20261026-首轮测绘-宿主壳弹窗插件.md`（五段）并更新 `docs\工程纪律\分册-AI操作与exe测试踩坑.md`（报「新增 N / 合并 M」）。

### 15.4 六状态口径（v2 唯一口径）

| 状态 | 判据（v2） | 本批次例子 | 禁止用法 |
|---|---|---|---|
| `PASS` | 所有步骤 `expect` + 后置断言成立，证据齐全 | 29 `comm-test` 出「测试成功」toast | — |
| `FAIL` | **步骤执行了**，但某步 `expect` 不成立 | 40 `solution-new` 后状态栏方案名没变 | 前置不满足时记 FAIL |
| `BLOCKED` | 环境级缺件：进程 / 端口 / 夹具缺失 / 仿真器起不来 / 权限 | P0-5 未起 → 28/29/30 记 BLOCKED | 把产品断言失败记 BLOCKED |
| `SKIPPED` | 前提不成立且**可反证**（R38）：前置条件写明、有据可查 | 33 夹具无配方候选参数 → SKIPPED，理由「夹具无配方候选参数」 | 无理由的跳过 |
| `UNVERIFIED` | **执行了**但无可观察证据（toast 未捕获、截图缺失） | 39 行确实消失但截图未落盘 | 把「没跑」记成 UNVERIFIED |
| `NOT RUN` | 没执行（前序中止 / 批次提前收工） | 23 之后整批中止时，24–41 记 NOT RUN | 并入 PASS 或 SKIPPED |

**三条硬边界**

1. **前置不满足**：环境缺件 → `BLOCKED`；前提不成立但环境正常 → `SKIPPED` + 理由。二者都不记 `FAIL`。
2. **`FAIL` 只用于「跑到了、判据不成立」**，必须带步号 + 期望 + 实际 + 证据路径。
3. **`UNVERIFIED` 只用于「跑了但没证据」**；没跑就是 `NOT RUN`，不许折算（R183）。
