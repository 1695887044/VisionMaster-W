# 测试批次单（batches）

> 本目录是 **planner → runner 的唯一交接物**：每一轮桌面端测试一个批次单。
> 契约与模板见 [`../测试身份契约.md`](../测试身份契约.md) §3；角色定义在 `.zcode/agents/vm-test-planner.md` 与 `vm-test-runner.md`。

## 约定

1. 文件名：`<yyyyMMdd>-<主题>.md`（例：`20261026-冒烟-方案与流程.md`）。
2. **只追加、不改旧版**：计划有错就出 `v2` 新文件（或在同一文件里追加"v2"小节，旧内容保留），runner 不改批次单。
3. 新增批次单后，在本文件「索引」表追加一行；否则 `tools\audit_docs.ps1` 会报 ORPHAN。
4. 批次单里不写密码/令牌/坐标；高风险动作必须标 `risk=high` 并写二次确认方式。
5. 执行证据不落这里：日志/截图/UIA dump 在 `artifacts\`，结论在 `docs\架构文档\交接报告\`。
