## ⚠️ 最需要记住的三条

1. **异步写入不占节拍**——流程线程只做"取值 + 格式化 + 入队"（微秒级），写磁盘在后台线程。
2. **列定义 = 动态端口**——`来源=端口`的列会自动长出一个 `InputPort<object>` 输入端口，列名就是端口名。
3. **宁旁路不丢账**——Excel 独占打开时重试 3 次，仍失败则改写入 `xxx_conflictN.csv` 并 WARN。

## 维护约定

1. **只改主文档**。`数据记录插件.md` 是唯一事实来源；归档件只作历史留档。
2. **节拍纪律不能破**：流程线程只做"取值 + 格式化 + 入队"，磁盘 IO 一律交给 `RecordingHub` 后台线程。
3. **动态端口一律 `IsRequired = false`**（允许"先定义、后连线"），否则编译期报 `[参数缺失]`。
4. **编码/分隔符/追加模式固定**（UTF-8 带 BOM + 逗号 + `FileMode.Append`），不要加配置项——这是刻意的。
5. **数值格式化一律 `InvariantCulture`**（防德语区逗号当小数点毁掉列对齐）。
6. **存图必须 `CopyImage` 深拷贝**（`HImage.Reference` 在当前版本不存在）。
7. **取过序号就必须挂好退出冲刷钩子**（`NextSequence` 里 `EnsureStarted()`），否则边车不落盘、重启序号回绕、图片撞名。
8. **清理只认"文件名带日期"的 csv**，名字无日期的文件一律不动（保守不出错）。
9. 建议后续补 `FlowCanvasChecks/DataRecordChecks.cs`，把 T1~T7 固化。
