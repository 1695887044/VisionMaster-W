## ⚠️ 最需要记住的三条

1. **`IsRequired = false` 必须显式写**——`InputPort.IsRequired` 默认 `true`，手填型端口不写就等于用不了。
2. **枚举不能经 `InputValues` 往返**——会抛 `InvalidCastException`，作用域等一律用 **string**。
3. **不要重复声明 `Success` / `ErrorMessage`**——影子隐藏基类成员（CS0108），表现为"永远报失败且错误为空"。

## 维护约定

1. **只改主文档**。`工具插件集.md` 是唯一事实来源；归档件只作历史留档。
2. **本工程不新增 `[StepConfig]`**——没有自定义视图的插件，宿主只列输入端口，写成 `[StepConfig]` 就没有编辑入口。
3. **手填型端口必须显式 `IsRequired = false`**。
4. **端口类型不用枚举**（经 `InputValues` 往返会炸）——用 string + 运行期白名单校验。
5. **复用基类 `Success`/`ErrorMessage`**，不重复声明。
6. **契约"默认成功、显式失败"**：吞异常路径必须显式报失败；**失败分支必须 `return`（短路）**，否则 ErrorMessage 被洗空。
7. **变量池类型守门**：可转换则转（记 Warn），不可转换显式失败——防"分支集体不走且流程照跑"的静默故障。
8. **作用域认不出就报错**，不许"不是 Global 就当 Runtime"。
9. 建议后续补 `FlowCanvasChecks/UtilChecks.cs`（覆盖数值比较 / 逻辑运算 / 类型转换 / 数学计算）。
