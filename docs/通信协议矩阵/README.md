# docs/通信协议矩阵

设备通讯协议的**现行对照表**：协议 × 地址规则 × 数据类型 × 读写方向 × 代码位置。

## 文件

| 文件 | 内容 |
|---|---|
| [`通信协议矩阵.md`](通信协议矩阵.md) | 各协议（Modbus TCP/RTU、S7、OPC UA、TCP/UDP 自定义等）的地址语义、数组与偏移规则、单请求上限、驱动类与配置模型落点 |

## 这份表解决什么问题

改通讯驱动时最容易踩的三类坑，判据都收在这张表里（对应 `AGENTS.md` §34 R149-R155）：

1. **地址是原始协议地址，不是 `4xxxx` 编号**（R137）。`40001` 写法是每变量开关、默认关闭。
2. **数组元素个数必须落盘**，且 `BuildAddressConfig` 要在 `DataType` **之后**写 `Length`（R149）。
3. **跨度超单请求上限直接拒绝**：Modbus 120 寄存器 / S7 110 字节（R153）。
