## 踩过的坑（本轮）

- 断言里的样例数据把「其他」写成 5/91 = 5.5%，高于 3% 阈值 → 合并不发生，断言红。
  **阈值类断言必须让样例真的落在阈值两侧**，否则测的是"没合并"而不是"该合并的合并了"。
- `double.ToString("{{bad}}")` **不抛异常**（自定义格式里的花括号是字面量），
  要触发 `FormatException` 得用非法**标准**格式串（本轮用 `"Q"`）。
