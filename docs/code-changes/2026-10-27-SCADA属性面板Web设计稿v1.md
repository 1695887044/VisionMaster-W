## 踩过的坑

1. **`file://` 里的 `#`**：`D:\C#\VM` 含 `#`，直接拼 URL 会被当片段标识，Edge 截图报 `NO FILE`。必须 `[System.Uri]::new($path).AbsoluteUri` 或手写 `C%23`；中文路径也要 percent-encode。
2. **Edge 无头截图的窗口尺寸竞态**：批量循环启动多个 `msedge --headless=new` 时 `--window-size` 会被忽略，输出固定 756×488。一次只跑一张；加 `--virtual-time-budget=3000` 让布局稳定；每次用唯一 `--user-data-dir`。
3. **`--force-device-scale-factor` 默认不是 1**：本机默认 DPI 让 1500×1200 的截图实际只有 1200 CSS 宽，主稿被裁。布局核对用 `--force-device-scale-factor=1`；要清晰证据再用 2。
4. **`main` 的 26px 外边距**：`?shot=` 模式只重置了 body padding 与 section margin，忘了 `main{margin-top:26px}`，导致 860 高的编辑器整体下移 26px，底部页签被裁。已在 `body.shot main{margin:0}` 修正。
5. **面板内滚动**：`.panel` 的 flex 子项默认 `min-height:auto`，内容把面板撑高、页签被推到视口外；需要 `min-height:0` + `.hero-view` 网格 `minmax(0,1fr)`。调试用 `?debug=1` 把 `getBoundingClientRect` 写进 `<title>`，比截图猜快。
6. **规格网格第 4 列溢出**：`repeat(4,minmax(0,1fr))` 的 grid item 默认 `min-width:auto`，内容仍会撑破；加 `.spec{min-width:0}` + `.spec .body{overflow:hidden}`。
7. **动作卡下拉被挤窄**：`select{flex:1}` 与 `.grow{flex:1}` 平分剩余宽度；动作卡头部把 `.grow` 改为 `flex:0`，下拉才拿到整段。
8. **颜色行的 44px 色块在截图里像整行**：按缩放估读会误判；裁剪放大后确认是 44×20。教训：像素判断先裁剪放大，别按整图比例猜。
