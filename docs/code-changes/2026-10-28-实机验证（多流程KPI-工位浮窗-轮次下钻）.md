## 5. 踩过的坑

1. **关窗被弹层吞**：浮窗开着时 UIA Invoke `CloseWindow` 报 `INVOKED` 但进程不退；先关弹层再关窗（台账 C-46）。
2. **行虚拟化**：屏幕外的工位行不在 UIA 树里，按名字找不到；改用视口内的行（C-47）。
3. **参数同名**：`param([string]$Map)` 与 `$map = ... | ConvertFrom-Json` 是同一变量，解析结果被转成字符串，映射全丢（C-48）。
4. **方案副本**：只拷 `.vms` 会导致图像/资产读不到，必须整目录复制；跑完按"原路径 2 次 / 测试路径 0 次"验证还原（C-49）。
5. **启动草稿框**：跑过流程后方案变脏，下次启动弹「上次运行的现场」，必须先关（C-37）。
6. **窗口尺寸变化**：两次启动窗口大小不同（Layout 落盘），坐标类断言不可跨轮复用；一律按控件名 + 回读值。
