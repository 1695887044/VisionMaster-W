# SCADA 模板参数化（批量插入与数组元素绑定）

- 日期：2026-10-21
- 范围：`VM.Scada`、`VM.Core`、`VM.Scada.Controls`、`VisionMaster`、`ScadaChecks`
- 目标：在 SCADA 中复刻威纶通 EasyBuilder Pro 模板的**设计期**用法——选中一组图元存为模板，批量生成 N 个实例，每个实例把 `Control[0]` / `State[0]` / “设备 0” 换成对应序号。

## 1. 需求与结论

两种变量形态都要支持：

| 形态 | 变量 | 模板里的引用 | 展开后 |
|---|---|---|---|
| A | 100 个独立变量 | `Control[{i}]` | 每个实例绑 `Control[0]`、`Control[1]`… |
| B | 1 个数组变量 | `Control[{i}]` | 每个实例绑数组根 `Control` + `ArrayIndex = i` |

结论：**设计期参数化展开 + 轻量关联模板**。每个实例展开成普通图元（编译/运行链路与粘贴、再制完全一致），同时记录 `TemplateId / TemplateIndex / TemplateRevision`；模板被「用当前选中更新」后，画面上的关联实例整块刷新。不做运行时 faceplate 渲染引擎（没有“实例参数面板”与“逐实例覆盖”）。

## 2. 作者路径（用户怎么用）

1. 画好一个模板面板，绑定 `Control[0]` / `State[0]`，文字写 `设备 0`。
2. 选中**至少 2 个**图元 → 右键「存为模板…」（单控件不允许存模板，也不允许成组）：
   - 输入模板名；
   - 弹「参数化模板」编辑器：
     - 数组下标（可空）：把 `Control[0]` / 数组根 + `ArrayIndex 0` 改成 `Control[{i}]`；
     - 名称/变量名替换规则（可多行）：图元名、绑定/动画/动作变量名；
     - 界面文字替换规则（可多行）：属性文字、动作文本/值、确认消息；
     - 三条规则可以同时用，都留空 = 按原样保存；
   - 确认后弹「将改写 N 处」确认框，列出前 8 条 `旧 → 新`。
3. 替换规则是**显式**的，不猜数字：
   - `Cylinder1` → `Cylinder{i}`、`手动 1` → `手动 {i}`；
   - 名称与文字分别填替换串，避免查找 `Cylinder1` 时把 `_Manual` 后缀一起吃掉；
   - 多行规则按从上到下顺序执行。
4. 批量插入：编辑器工具栏「批量插入模板」→ 选模板、数量、起始序号、列数、间距、起点。
   - 起始序号默认取模板保存时选的下标（旧模板默认 0）；
   - 校验通过才插入；任一变量解析失败整批不插入；
   - 整批只占**一条**撤销记录；中途异常按“插入前图元集合”回滚，零残留、零撤销记录。
5. 单实例拖入：工具箱把模板拖到画布。
   - 参数化模板会弹「插入模板序号（{i} 的值）」，直接填 1 就是“把 0 换成 1”；
   - 参数化模板走与批量插入同一套展开/校验；
   - 非参数化模板保持旧行为（原样物化），避免老模板因变量暂时找不到而拖不进来；
   - 一个实例的所有图元共用 `GroupId`，点中任一图元选中整组；单图元模板不建组。
6. 关联模板更新：工具箱模板行右键「用当前选中更新模板…」。
   - 用当前选中的图元覆盖模板定义，`Revision +1`；
   - 编辑器订阅 `TemplateUpdated`，把所有 `TemplateId` 相同且 `TemplateRevision` 较旧的实例按各自 `TemplateIndex` 重新展开；
   - 保留实例位置、`GroupId`、图层、旧最小 Z；旧选中与新图元有交集时恢复选中；
   - 整次刷新只占一条撤销；某个实例展开失败时保留旧实例并给出警告，其余实例照常刷新。

令牌语法：`{i}`、`{i+1}`、`{i-1}`、`{i:000}`；`{{` / `}}` 是字面花括号；未知 `{x}` 原样保留；数字一律不变区域性格式化。

## 3. 实现要点

### 3.1 引用模型显式化

- `ScadaVariableRef(VariableId, VariableName, ArrayIndex)`。
- `ScadaBinding` / `ScadaAnimation` / `ScadaAction` 增加 `ArrayIndex`（-1 = 整个变量）与 `ToReference()`；`Bind/BindVariable` 增加带下标重载。
- 快照 `ScadaBindingSnapshot` / `ScadaAnimationSnapshot` / `ScadaActionSnapshot` 同步加 `ArrayIndex`；`ScadaClipboardPayload.CurrentVersion` 4 → 5。
- `ScadaPage.TrySetBinding` 增加带下标重载；改名级联（图元绑定/动画/动作/报警）保留原下标。
- `ScadaChangeScope.AbortCurrent()`：批量失败时清空根账本并让 Dispose 不压栈。

### 3.2 数组元素值通道

- `RegistryScadaValueSource.TryResolve(ScadaVariableRef, ...)`：
  - 先按 Id/名字解析根变量；
  - `ArrayIndex >= 0` 时校验 `DataType.IsArray`、长度、越界；
  - 返回 `ArrayElementHandle`。
- `ArrayElementHandle`：
  - 元素身份 = `SHA1("scada-array-v1|rootId|index")`，只用于运行态订阅键，不落盘；
  - 同根同下标稳定、不同下标不同、不等于根 Id；
  - `ValueChanged` 只在**本元素**值真的变化时触发（否则元素 0 变化会给元素 1 的断线报警续命）；
  - 本地数组通过 `IArrayElementWritable` 就地写 + `NotifyValueChanged`；
  - 网络数组通过 `DeviceAddressBase.TryCreateElementAddress` 生成**单元素地址**后直接下发（Modbus 按寄存器/位步长、S7 按字节步长），不做“读整组→改一项→写回”；其它协议不支持时明确拒绝。
- `ScadaRuntimeBinder`、`ScadaValueWriter`、`ScadaActionDispatcher` 全部改用 `ToReference()`。
- `IScadaValueSource` 新重载的默认实现对数组元素**显式返回不支持**，不静默退化成根变量。

### 3.3 模板展开与批量插入

- `ScadaTemplateParameterizer` 两条入口：
  - `TryParameterize`：存模板时把具体数组下标改成 `{i}`（只认 `[n]` 后缀和“数组根 + ArrayIndex”，不猜下划线后缀）；
  - `TryReplace`：显式“查找/替换”，名称规则与文字规则**各是一个列表**（`ScadaTemplateReplaceRule`），按顺序执行；覆盖普通变量名、图元名、死文字、动画/动作变量名、动作文本/值/确认消息。名称/文字替换串分开，避免 `Cylinder1 → {i}` 把 `_Manual` 后缀一起吃掉。
- 模板物化自动成组：`ScadaClipboard.Materialize(..., groupAll: true)` 给一个实例的所有图元共用一个 `GroupId`；拖入模板与批量插入都开启，粘贴/再制保持原行为。批量插入时每个实例各自成组；**单图元模板不建组**（单控件不允许存模板/成组）。
- `ScadaTemplateExpansion.TryPlan`：
  - 每份实例 JSON 深拷贝，绝不改模板库原文；
  - 替换图元名、属性文本、绑定/动画/动作变量名、动作文本/值/确认消息；
  - 在当前工程重新解析每个引用（模板可能来自另一个方案，旧 Id 不可信）；
  - 精确名优先（支持 A 形态），失败再拆 `Base[index]`（B 形态）；
  - 未参数化的引用在名字失败后按 Id 兜底（变量改名场景）；带 `{i}` 的引用不回退 Id；
  - 跳过停用绑定/动画的解析，但仍替换令牌（以后启用不会看到字面量 `{i}`）；
  - 按引用逐条收集“没有 `{i}`”的警告，不再被文字里的令牌掩盖；
  - 任一错误整批不产出计划。
- `ScadaTemplateBatchInserter`：
  - 外层 `page.BeginEdit` 包住 N 次 `ScadaClipboard.Materialize`，嵌套作用域合并成一条撤销；
  - 网格落点（列数/间距/起点）；
  - 失败按“插入前图元集合差集”回滚 + `AbortCurrent`。
- `ScadaBatchInsertTemplateEditor`：模板/数量/起始序号/列数/间距/起点 + 校验结果。
- `ScadaEditorViewModel.BatchInsertTemplateCommand` 与 `InsertTemplateAt`：批量与拖入共用展开路径；警告在插入前以确认框展示。

### 3.4 关联模板（轻量 faceplate）

- `ScadaElement` 新增并落盘：`TemplateId`（空=非模板实例）、`TemplateIndex`（`{i}` 值）、`TemplateRevision`（插入时模板版本）。
- `ScadaClipboard.Materialize` 新增可选参数：`templateId / templateIndex / templateRevision / groupIdOverride / startZ / layerIdOverride`；刷新时用旧 `GroupId`、旧最小 Z、旧图层，避免整块跳到最上层或换组。
- `ScadaTemplateStore`：
  - 模板记录新增 `Revision`（新模板从 1 开始）；
  - `TryUpdate` 用当前选中覆盖定义、`Revision +1`、广播 `TemplateUpdated`；
  - `GetRevision` 供插入路径记录实例版本。
- `ScadaTemplateInstanceRefresher`：
  - 按 `TemplateId + GroupId` 找实例，只刷新 `TemplateRevision < 当前 Revision` 的实例；
  - 按实例的 `TemplateIndex` 重新展开模板；
  - **先移除旧图元、再物化新图元**（否则名字查重会把新图元改成 `_2`）；物化失败/数量不符时删新、把旧图元原样挂回；
  - 保留位置（旧外接框左上角）、`GroupId`、图层、旧最小 Z；
  - 外层一个 `ScadaChangeScope`，整次刷新一条撤销；单个实例失败不影响其它实例。
- `ScadaEditorViewModel` 订阅 `TemplateUpdated`，刷新后按旧/新 Id 交集恢复选中；失败时把警告集中展示。
- 工具箱模板行右键新增「用当前选中更新模板…」；`ScadaToolboxViewModel` 通过可空构造参数接编辑器（测试仍可 `new ScadaToolboxViewModel()`）。

### 3.5 选择器与报警

- `IScadaVariablePicker` 增加带下标的 `Pick` 重载；属性面板、动画、写变量动作、报警配置都传下标。
- 选择器对数组变量显示“数组下标”输入：
  - 越界（长度已知时）与非法整数直接禁用确认；
  - 打开时先设置当前下标再 `ApplyFilter`，预选数组元素后直接确定不会改绑元素 0；
  - 结果缺下标键时按 -1 处理。
- `ScadaAlarmDefinition` 增加 `ArrayIndex`；报警引擎用 `ToReference()` 解析；改名级联保留下标；`CanCarry`/`Slot`/`CarrySlot` 纳入下标比较。
- 报警行、写变量动作行显示 `Control[3]` 而不是根名。

### 3.6 兼容与版本

- `.vms` 旧数据缺 `ArrayIndex` → 默认 -1（历史行为），不需要迁移代码；缺 `TemplateId/TemplateIndex/TemplateRevision` → 空/ -1 / 0，按普通图元处理。
- 剪贴板/模板负载 v5；`ScadaTemplateStore.CurrentVersion` 1 → 2：旧版本软件读到 v2 模板文件会只读，避免把 v5 模板当“不可用”跳过再存一次抹掉。
- 模板记录新增 `ParameterIndex`、`Revision`；旧记录缺字段按 0 处理。
- 旧模板（未参数化）仍可按原样拖入；批量插入时若存在未参数化引用，会弹确认警告。
- 单成员组仍不合法：`TryGroupElements` 要求至少 2 个目标；单控件也不能存模板（`SaveSelectionAsTemplate` / `TryUpdateTemplateFromSelection` 都要求至少 2 个图元）。

## 5. 复核补记（名称替换与自动成组）

本轮按"看起来能用、实际绑错"的路径复查后补了四条：

1. **名称替换后清空 `VariableId`**：模板快照里原来的 Id 指向"存模板时那一个变量"。名字改成 `Cylinder{i}_Manual` 后，若某实例名字解析失败，展开器的 Id 回退会把所有实例悄悄绑回原变量（带 `{i}` 的名字不会触发，但常量改名会）。`TryReplace` 与 `TryParameterize` 现在都在名字变化时把 `VariableId` 清成 `Guid.Empty`，宁可在展开时明确报"找不到变量"。
2. **单控件不允许存模板/成组**：`SaveSelectionAsTemplate` 与 `TryUpdateTemplateFromSelection` 都要求至少 2 个图元；`TryGroupElements` 同样要求至少 2 个。`Materialize(groupAll: true)` 对单图元不发组号。关联模板的实例身份只对“多图元模板”成立。
3. **预览剩余条数按 `changed` 算**：`changes` 只保留前 20 条做预览，原来的"另有 N 条"用 `changes.Count - 8` 会少报；现在用总改写数。
4. **确认框补数组下标摘要**：同时做数组下标参数化时，预览会多一行"数组下标 0 → {i}（N 条引用）"，不再只显示名称/文字改动。

TP12 共 8 条断言：名称替换同时改图元名/绑定/动画/动作/文字；三个 `VariableId` 均被清空；展开后实例 1 绑 `Cylinder1_Manual`；两个图元共用同一个非空 `GroupId`；点中组内任一图元能展开整组；单图元模板不建组；多行规则（名称两条 + 文字两条）全部生效；两个按钮的事件动作 `Control[0]` / `State[0]` 参数化为 `Control[{i}]` / `State[{i}]`。

## 6. 已知边界

1. **网络数组单元素写**：Modbus/S7 已支持按元素地址直接写（只动目标元素，不做整组读改写）；其它协议地址类未实现 `TryCreateElementAddress` 时会明确拒绝，不会静默退回整组写。
   - **S7**：`byte[]` 可写单字节（`DB1.DBB3`）；`string[]` 按每元素固定字节块写（`DB1.DBB24`，长度 = `ElementByteLength`）。
   - **Modbus**：`byte[]` 拒绝（寄存器 16 位粒度，按字节写会覆盖同寄存器另一半）；`string[]` 只有元素宽度为偶数、按寄存器对齐时才支持，奇数宽度明确拒绝。
2. **数据表格列等属性袋里的变量引用**不会自动参数化/校验：需要手写 `{i}`，且运行态按精确名解析；后续接入 `ScadaVariableRef` 后再补。
3. **Web 页面快照**的 binding/animation DTO 还没有 `ArrayIndex`；Web M1.5 接入数组前必须补契约。
4. **带 `{i}` 的参数化模板在变量改名后**不会按 Id 兜底（快照 Id 是“存模板时那一个具体变量”，回退会把所有实例绑回它）；需要重新存模板。未参数化模板支持 Id 兜底。
5. **`.vms` 降级**：旧版本软件不认 `ArrayIndex`，保存后会丢下标；本次未递增 `ScadaDocument.CurrentSchemaVersion`，降级往返需按“旧版本不支持数组元素绑定”处理。
6. **`byte[]`** 仍被选择器当作数组（要求下标）；变量管理把 `byte[]` 当整块处理，二者口径尚未统一。
7. **性能**：每个实例一份 JSON 深拷贝；100 实例可接受，更大批量需改成结构化克隆/共享模板。数组元素订阅按元素扇出，100 元素 × 50Hz 为 O(N) 读取，当前可接受。
8. **默认落点**为 (0,0)，批量插入前建议在对话框里填起点或先滚到空白区域。
9. **下划线命名**（`Cylinder1_Manual`）不再靠“自动猜下标”，但可以用名称查找/替换显式参数化：查找 `Cylinder1`、名称替换 `Cylinder{i}`。`TryParameterize` 的自动下标模式仍只认 `[n]` 和数组根 + `ArrayIndex`，避免把恰好以数字结尾的标量误当家族成员。
10. **同名独立变量优先于数组元素**：工程里同时存在独立变量 `Control[0]` 和数组根 `Control` 时，模板引用 `Control[0]` 会先命中独立变量（A 形态优先）；需要绑数组元素时请避免同名独立变量。
11. **回滚删除失败**：`ScadaTemplateBatchInserter` 逆序删除新增图元时未检查 `TryRemoveElement` 返回值；极端情况下若删除失败，错误文案仍说“整批已回滚”，可能留残图。
12. **拖入路径的 WPF 自动化**：拖入已改为走 `ScadaEditorViewModel.InsertTemplateAt`（与批量共用展开），但 `ScadaChecks` 只覆盖了展开/批量模型层，未自动点击真实拖放。
13. **数组长度未知时**：选择器只能做“非负整数”校验，越界要到运行态由值源拒绝；长度可从当前值/默认值/地址配置取得时，选择器会即时拦住越界。
14. **关联模板是“刷新式”，不是运行时 faceplate**：实例没有独立参数面板；更新模板会覆盖实例上的手工修改。需要逐实例改属性时，先把它当普通图元改，或复制一份再断开关联。
15. **更新模板会重新走参数化编辑器**：如果当前选中已经是展开后的具体实例（`Cylinder1_Manual`），必须在编辑器里重新填 `Cylinder1 → Cylinder{i}` 等规则；否则会把具体名字写回模板定义。确认框会列出改写项，留空保存前请确认预览。
16. **复制/粘贴关联实例会丢 `TemplateId`**：剪贴板快照只搬图元内容，不搬关联身份；粘出来的是静态图元，不再跟模板更新。
17. **删除模板不清理实例**：实例保留 `TemplateId`，刷新时提示“模板不存在”，需要手动删掉或重新插一份。
18. **刷新会压平图层**：新图元统一放回旧实例第一个图元的图层；模板内跨图层的结构在刷新后不再分层。
19. **多行替换规则没有正则/启用开关**：按从上到下顺序执行，后面的规则会命中前面产生的文本；需要暂时停用某条就删掉它。
