## 四、下一步

### 4.1 建议的定义（条文）

**一句话**：算法插件只产出可复现的业务结果（数值、语义几何、状态），不产出任何已渲染的像素或样式；
「结果显示」是唯一的呈现合成器，只读上游结果、产出可丢弃的呈现（覆盖层 + 标注图），不改、不拥有、不释放上游对象。

**四条不变量**

1. **单一所有权**：每个 `HImage/HRegion/HXLD` 只有一个所有者（创建它的插件实例）；端口只传借用；
   下游不释放、不跨轮持有；留存必须 `CopyImage/CopyObj`；**禁止透传输出口**。
2. **端口契约**：端口名 + 类型 + 单位 + 坐标系是 `.vms` 的持久契约；**不许同名改义**；
   废弃只能走「新增端口 → 迁移 `.vms` → 删除旧口」。
3. **渲染分离**：算法不烧字、不画几何、不输出标注图；显示层只读上游结果；显示失败不得改变算法 `Success`。
4. **单一产出者**：同一类信息在图上只有一个产出者；每个（流程，窗口）每轮只有一个发布者（结果显示）。

**烧录 / 覆盖层的划分（裁决）**

| 层 | 内容 | 归属 |
|---|---|---|
| 结果层 | 判定、数值、几何轮廓、区域、缺陷编号、测量线 | **必须能进 `AnnotatedImage`**（`BakeOverlay` 默认开，或统一走 `rN` 烧录） |
| 交互层 | ROI 手柄、选中高亮、十字线、悬停、涂抹、调试轮廓 | **只走覆盖层**，不进存档 |

同一份图层清单、两个后端；覆盖层不得成为结果的唯一载体；不允许两套各画各的。

**几何端口选型**

| 用途 | 类型 | 理由 |
|---|---|---|
| 语义几何（点/线/圆/椭圆/轮廓） | `GeometryParam` | 无句柄、可序列化、跨插件 |
| 像素域几何（缺陷区域、码框、轮廓） | `HRegion` / `HXLD` | 原生零转换；生产者持有、下游借用 |
| 显示提示（可选） | `List<MeasureAnnotation>` | 带 Color/LineWidth，属呈现契约，**不作算法主契约** |
| 数值 | 现有 typed scalar / `HTuple` | `object` 只作兼容层，不作标准结果类型 |

**例外（不拆）**：CodeReader（已完成）、ImageScript（脚本自绘即产物）、ImageDiff（差分图即产物）、
采集/预处理/位姿跟随、Matching/Bead 的 `AlignedImage`、各插件配置态预览、
Bead 在 `OutputAlignedImage=false` 时的 `AnnotatedImage`（兼容逃生口）。

### 4.3 验收判据（含反向）

1. **端口面**：旧口 0 个、新几何口类型正确；反向——把旧口加回或写进 `.vms` 必须红。
2. **链路**：`SrcImage` 来自原始图、几何口来自算法、算法 `DisplayViewIndex==0`、每（流程，窗口）每轮恰好一个发布者；反向——改回 1 必须红。
3. **事件内容**：`Annotations` 非空且数量/颜色/线宽正确；几何带像素 > 阈值、背景带 < 阈值；反向——几何口置空必须红。
4. **无双烧**：纯黑底 + 一条已知线，像素统计与"只烧一次"参考值比对；把已烧图当 `SrcImage` 必须翻倍 → 红。
5. **存图语义**：`AnnotatedImage` 是新句柄、含文字与结果层几何、不含交互层；若不含覆盖层，Help 必须写明且下游验收不得声称"带框"。
6. **多流程真插件**：真实 `ImageCollectionService` + 真实插件，每（流程,窗口）恰好一帧；反向——去掉 `PreviewScope.Begin` 必须红。
7. **产物/门禁**：DLL mtime ≥ 源码、Help 内嵌资源数 == `.md` 数、Help 中旧端口名 0 次、`run_gates.ps1` exit 0。
8. **覆盖不缩水**：各宿主通过条数不下降；新断言做变异反证（改坏→红→还原→绿）；跳过型断言清零或配正对照（R38）。

## 五、踩过的坑

1. **`Dispose()` 没有透传防御**：轮首回收有 `IsUpstreamLinkedValue`（`VisionPluginBase.cs:201`），
   `Dispose()`（`:95-102`）无条件释放所有输出值 → 透传口会在插件释放时把上游图一起释放。
   所以不是"小心透传"，而是"根本不许透传"。
2. **同名不同义是最坏的过渡**：编译全绿、`结果显示` 照常烧字，截图看起来"有标注"，只是算法几何没了；
   `SampleFlowsReplayChecks` 只数帧数，抓不到。
3. **`HRegion` 接不进 `OverlayContours`**：`FlowCompiler.IsLinkable` 用 `IsAssignableFrom`，
   `HRegion` 与 `HXLD` 是兄弟类型 → 编译期红。别到接线时才试出来。
4. **`AnnotatedImage` 不含覆盖层**：`ResultDisplayPlugin.cs:58-64` 明写"只画在图像窗口上，不烧进"。
   下游 DataRecord/ImageAssign 存图会静默丢几何。
5. **算法 `DisplayViewIndex=1` + 结果显示同窗口 = 双发布**：两条都发帧，后到的覆盖先到的，
   可能看到裸图；迁移时必须把算法步骤归零。
6. **断言网抓不到"停烧字"**：只有 Blob 编号一条咬文字像素，其余只断言"图非空"。先织网再动插件。
7. **`AGENTS.md` 只剩 51 字节**：新增硬规则前先下沉分册，否则静默截断（§0 已写明超限后果）。
