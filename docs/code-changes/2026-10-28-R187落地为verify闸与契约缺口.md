## 踩过的坑

1. **"全文不许有盘符"是拍脑袋判据**：写规则时没查代码，实际锚定能力只存在于资产管线。**判据必须先问"谁负责解析这个字段"**，否则闸会红在自己的验收语料上，然后被"标已知"绕过——比没有闸更坏。
2. **`RelativePath` 的祖先链判错了**：数组项里 `RelativePath <- JObject 项 <- JArray <- 集合属性`，`prop.Parent?.Parent` 只到 JArray，判 `is JProperty` 恒假，两条检查静默不跑。第一版变异测试只红了 1 条（上跳），另两条没触发——**变异测试要逐条确认"红的是我以为的那条"**，不能只看"有红"。
3. **变异脚本里的字符串替换可能空转**：用 `Replace` 改 1.6MB JSON 时模式没匹配上，替换是静默 no-op，于是"变异"根本没发生（红的全是"文件不存在"）。合成小用例比改大文件可靠。
4. 又一次踩 `cmd` 的 `|`：`powershell -Command "... | ForEach-Object ..."` 里嵌套 `\"` 会提前闭合外层引号，管道被 cmd 截走。**含引号和管道的 PowerShell 片段一律写临时 `.ps1` 用 `-File` 跑**（R2 本来就这么要求）。
