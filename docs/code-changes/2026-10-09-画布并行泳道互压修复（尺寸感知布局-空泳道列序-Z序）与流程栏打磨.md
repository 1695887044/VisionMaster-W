## 五、本批钉死的口径（守门点）

1. **包含链与列序是几何不变量**："分支内步骤 ⊆ 泳道 ⊆ 容器框"与"同级列不相交"，`[C]`/`[V5]` 双段守门（含"老图纸脏坐标 → 整理后恢复"的正反例）。
2. **空泳道必须不同址、按列序排布**（含全空场景）：`[V5]` 用 `Overlaps`/同址判定钉死，不再允许"多处空泳道贴同一坐标"。
3. **叠放层次由深度 + 身份决定，与集合序无关**：`[B]` 断言精确 `ZOrder`（3/4/8/5），场景 H 渲染自检 `Panel.ZIndex` 绑定真的生效 + items 宿主必须是 `Panel`（`Panel.ZIndex` 只对 Panel 的子元素排序）。
4. **重排的排位足迹与最终折叠态同源**：`[U]` 四条深容器折叠断言钉死"点一下真翻、整理不篡改现场"。
5. **常量单一数值源**：画布同名常量是 Core 的别名（改数值只改 `FlowLayoutStore`），防两边漂移击穿不变量。
