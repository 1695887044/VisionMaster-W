## 二、三条语义（本批核心）

1. **装填当前值**：弹窗读 `Value`（表格里那组），不再读 `DefaultValue`。
2. **默认只写当前值**：`ApplyArrayEdit` 总是写 `Value`；`DefaultValue` 只在勾选「同时写入初始值（基准）」时写。
   旧「强制覆盖集合...」两者一起写，且弹窗显示基准——流程写过数组后点确定等于把运行值换掉。
3. **校验在弹窗内**：`Confirm` 先逐项转换，失败项红框 + 底部「第 N 项：…」，弹窗保持打开；旧实现关窗后才转换，一个错字丢掉整批编辑。

## 三、顺带修掉的缺陷

| # | 缺陷 | 根因 | 修法 |
| --- | --- | --- | --- |
| 1 | 数组「恢复初始值」判据永远不对 | `IsValueDeviated` 用 `Equals` 比数组 = 比引用；弹窗写的是新实例 → 内容一致也判"已偏离"；新建数组两者同实例 → 元素改动同时改基准 | 逐元素 `ArrayContentEquals` |
| 2 | 元素就地编辑后订阅方不刷新 | `current.SetValue(...)` 引用未变，`Value` setter 的 `SetProperty` 短路，`ValueChanged` 不触发 | `IValueChangeNotifier` 显式广播 |
| 3 | 运行时数组长度变化后子行不重建 | `OnVariableValueChanged` 只 `RefreshValueDisplay` | `ShouldRebuildArrayRows`（`max(当前值, 基准)` 与子行数比较）+ `RefreshTree()`；编辑中不重建 |
| 4 | 数组根没有「恢复初始值」入口 | ↺ 只在 `EditableRoot` 态渲染，数组根是 `ArrayRoot` 态 | 数组根单元格补 ↺（绑 `IsValueDeviated`） |
| 5 | 元素无法单独复位 | 只有元素行输入框 | `ResetElementCommand` + 逐元素 ↺（基准里存在该下标才显示） |
| 6 | 运行中可以整体替换数组 | `DeleteVariable` 有运行中互锁，数组覆盖没有 | `ExecuteEditArray` 加同口径互锁 |
| 7 | 数值文本接受千分位 | `Convert.ChangeType` 默认允许 `NumberStyles` 的千分位 | `VariableValueConverter` 对数值类型显式拒绝 `,` |
| 8 | 批量转换报错是英文且不指项 | `TryBuildArray` 直接返回 `ex.Message` | 逐项走 `VariableValueConverter`，前缀「第 N 项」 |
| 9 | string 空串被写成 null（与提示"文本空串"不符） | `IsNullOrWhiteSpace` 分支对引用类型给 null | string 元素原样保留 |

> 以下 10-17 是 2026-10-21 独立审查（reviewer）抓出的问题，已在本批闭合。

| # | 缺陷 | 根因 | 修法 |
| --- | --- | --- | --- |
| 10 | 默认工作区的数组（`VariableFactory.CreateLocal` 建的）基准与当前值同实例：元素编辑会静默改掉基准，且逐元素比较因 `ReferenceEquals` 判"未偏离" | 工厂把同一个 `defaultValue` 同时赋给两个属性 | 工厂与 `AddLocalVariable` 对数组克隆一份给 `DefaultValue`；补「不同实例 + 编辑后基准不变」断言 |
| 11 | 基准比当前值长时，多出来的元素行显示 ↺ 但点击无效（`ResetElementValue` 要求当前值有该下标） | `IsElementDeviated` 只看基准 | 增加"当前值也含该下标"前置条件；补 baseline 更长的断言 |
| 12 | 运行中互锁只在打开弹窗时查，落地不复查（弹窗期间流程可能已启动） | `OnArrayEditorClosed` 直接应用 | 落地前再查 `RunState`，运行中提示并丢弃 |
| 13 | 编辑中外部改了数组长度、用户按 Esc → 子行停在旧长度 | 编辑中跳过重建，取消路径没有模型事件 | `VariableNode.ValueEditCompleted`（提交/取消都发）→ VM 复查 `ShouldRebuildArrayRows` |
| 14 | `Value=null` 时长度判定直接放行，与 `CreateChildNodes` 的 max 口径分叉 | `ShouldRebuildArrayRows` 要求 `Value is Array` | 当前值按 0 计，`max(当前值, 基准)` 比较；补 null 断言 |
| 15 | `ChildDefaultValueText` 死路径仍会同时改基准与当前值、不广播、空串写 null | 视图已不绑定但属性还在 | 删除该属性、其断言与 `ChildOf` 辅助方法 |
| 16 | 弹窗 VM 复用未复位勾选/错误条；移动行不清错误；复位不结束编辑态 | 生命周期细节 | 打开时复位 `SyncBaseline`/`ErrorText`；移动后 `ClearError()`；复位前 `CancelEditValue()` |
| 17 | `VariableNode.cs` 文件头叠了 6 个 BOM | 历史编辑事故 | 归一为无 BOM UTF-8（严格解码自检通过） |

## 七、v3 数组编辑弹窗优化（同日）

> 用户指令：「数组编辑的那个弹窗也要走 Web 设计稿优化」。
> 设计基线：`docs\UI设计基线\global-variables\` **v3**（v1/v2 语义不变，只重排弹窗的信息层级与操作密度）。

### 7.1 设计变化

| 位置 | v2 | v3 |
| --- | --- | --- |
| 写入范围 | 一行复选框 + 一段说明 | 范围卡：分段选择「只写当前值 / 同时写初始值」+ 右侧基准项数 + 一句话后果说明（随选择变化） |
| 行 | 输入框 + 上移/下移/删除 | 改过的行在输入框下显示「● 基准：原值」，行尾多一颗 ↺（只恢复这一项） |
| 标题 | 「类型 · 当前 N 项」 | 「类型 · 当前 N 项 · 基准 M 项」 |
| 底部 | 添加元素 + 总数 + 取消/确定 | 添加元素 + 总数 + 「N 项已修改」（未改时灰色）+「恢复全部为基准」（无修改时置灰） |
| 尺寸 | 620 × 640 | 640 × 660（最小 540 × 540） |

### 7.2 实现

- `ArrayEditorRow` 增加 `BaselineText` / `HasBaseline` / `IsChanged`；
- VM 增加 `_baseline` 快照、`ChangedCount` / `HasChanges` / `ChangedSummary`、`ScopeHint` / `IsCurrentOnly`、
  `WriteCurrentOnlyCommand` / `WriteBothCommand` / `ResetRowCommand` / `ResetAllCommand`；
- 行比较按元素类型转换后做（"12.50" 与 "12.5" 视为相同），转换失败按"已修改"；
- 每改一行只重算该行与总数，不重建列表（保住焦点）。

### 7.3 两处实现坑（都已由出图/断言兜住）

1. **分段选择不能用 `ToggleButton`**：它会先在本地翻转 `IsChecked`，命令再写回同一个值时 OneWay 绑定不发通知，
   段会停在"两段都没选中"。改用 `Button` + 内联 Style 的 `DataTrigger`（绑 `IsCurrentOnly` / `SyncBaseline`）。
2. **`DialogIconButton` 自带 `MinWidth/MinHeight=30`**：24px 的行内按钮必须显式写 `MinWidth="0" MinHeight="0"`，
   否则 4 颗按钮合计 120 > 108 列宽，最左那颗会被输入框盖住（首轮出图抓到；表格层的 22/24px ↺ 同样补了覆盖）。
