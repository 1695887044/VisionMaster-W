# 项目资产页面补全：模型元数据 / 缩略图 / 真导出 / 真筛选

## 当前状态

资产页此前有三类"看起来能用、其实没用"的地方，本轮全部改成真实行为：

- 模型导入不再只判扩展名，会读 ONNX 输入尺寸与标签；
- 图像/图片模板的详情里有真缩略图；
- `导出资产包` 真的产出 zip（清单 + 文件本体）；
- 相机 / 标签筛选是真下拉，来自当前页签里的真实取值；
- 原来的两个死按钮改成「排序切换」和「清除筛选」。

## 已做

1. **ONNX 元数据**
   - `ProjectAssetImporter.ReadOnnxMetadata`：读第一个输入形状的最大两维当 W/H，标签取 custom metadata 的 `names`/`classes`/`labels`。
   - **用反射调用** `Microsoft.ML.OnnxRuntime.InferenceSession`，不建立编译期依赖：断言宿主或精简部署缺这个程序集时静默返回 null，不让"读元数据"把导入弄挂。
   - 导入后 `ModelAsset.InputWidth/InputHeight/Labels` 有值，资产页技术参数直接显示。
2. **真缩略图**
   - `ProjectAssetExporter.TryLoadThumbnail`：`BitmapCacheOption.OnLoad` 一次性解码（不锁文件），超过 240px 等比缩放并 `Freeze`。
   - 图像资产、图片类模板、派生采集图都有缩略图；其它资产仍显示图标。
   - 详情预览：有缩略图显示图，没有才回落图标（`HasThumbnail` / `HasNoThumbnail` 双可见性）。
3. **真导出**
   - `ProjectAssetExporter.TryExport`：写 `manifest.tsv`（类型/名称/Id/版本/文件/SHA-256）+ `files/{kind}/{assetId}.{ext}`，先写 `.tmp` 再替换。
   - zip 内路径统一用 `/`（`Path.Combine` 在 Windows 给 `\`，解压工具会把它当文件名的一部分）。
   - 标定/配方没有独立文件，导出时明确拒绝，不产出空包。
   - 导出按钮改为 `SaveFileDialog` 选落点，不再只往剪贴板塞一段文本。
4. **真筛选**
   - 相机下拉：取当前页签里真实出现的 `Camera` 值（去重排序），首项「全部相机」。
   - 标签下拉：取作用域首段（`ST3 · 精密测量` → `ST3`、`整线` → `整线`），首项「全部标签」。
   - 选项按页签刷新；选中值消失时回落到「全部」，避免筛出 0 条却看不出原因。
   - **绑定用 `SelectedItem` 而不是 `SelectedValue`**：WPF 里 `SelectedValue=""` 常被当成"未选择"，下拉会显示空白框。
   - `FilterOption` 重写 `ToString()`：本仓 `DialogCombo` 是自定义模板，只写 `DisplayMemberPath` 不生效，界面会显示 `VisionMaster.ViewModels.FilterOption` 类型全名。
5. **死按钮转真功能**
   - 「最近更新」→「排序切换」：在最近更新 / 名称排序之间切换，`SortButtonText` 反映当前状态。
   - 「筛选」→「清除筛选」：清空搜索 + 相机 + 标签。
6. **断言**
   - `ProjectAssetsUiProbe` 新增筛选/排序 12 条 + 导出 9 条：
     - 图像页相机下拉只有「全部相机」且显示文案正确；
     - 标定页出现真实相机 `NET-STATION-02`，筛选后列表真的变少；
     - 标签下拉来自作用域，筛选后仍有数据；
     - 清除筛选命令清空三处条件并恢复全量；
     - 名称排序结果确实是升序且不丢条目；
     - 导出 zip 存在、含 `manifest.tsv` 与 `files/image/...` 文件本体；
     - 无资产时导出被拒绝且原因可读；
     - 缩略图可解码且已缩放，文件不存在时为 null。

## 顺手修的既有偶发红

`FlowCanvasChecks` 两处假运动卡竞态（都不是本轮改动引入）：

- 「假设备命令失败后进入安全停机」：Connect 后状态还在切换窗口，`Move` 被 `Rejected_NotConnected` 静默拒掉 → 改成有界重试。
- 「运动中 Home 被拒」：运动命令放在 `using` 块里，块结束时命令被释放（=取消），轴已停下 → 让运动命令活到判据之后，并先等一帧状态轮询。
