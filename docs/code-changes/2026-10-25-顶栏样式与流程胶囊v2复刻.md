## 五、踩过的坑

1. **运行中的 `VisionMaster` 锁 DLL**：探针/冒烟构建报 MSB3027；用 `-p:BuildProjectReferences=false` 跳过重建依赖即可（新 DLL 已在 `VisionMaster\bin`）。**不要杀用户的进程**。
2. **探针普通窗口客户区 324×185**：标题栏 + 边框扣掉 16×39；要 340×224/112 必须无边框 + `SizeToContent`。
3. **高度账差 4px**：胶囊行有 4px 下边距（最后一行也算），底栏 26→22 正好抵消；总高 112/224 不变。
4. **模式按钮 hover 背景会覆盖选中背景**：模板触发器优先级高于样式 Setter；去掉 hover 的背景，只改前景。
5. **单徽标优先级靠触发器顺序**：调用（循环/外部/子）先写，角色（零/主/尾）后写；后者命中即覆盖。
6. **选中名称加粗**：`DataTrigger` 绑 `IsSelected` 必须用 `RelativeSource AncestorType=ListBoxItem`，不能直接绑 DataContext。
7. **根目录 `$null` 杂散文件**：cmd 重定向误写，`audit_root` 判 `FILE $null`；移到 `artifacts` 后手动 exit 0。
8. **`run_gates` 的假红/假绿**：日志 4 步红但底层日志 OK/0 错，脚本却 exit 0；这是闸门缺陷，不是 UI 结论。以后判闸门要同时看「行状态 + 底层日志 + 进程退出码」三处。
