## 2. 已做

### 2.1 新增落盘骨架 `tools\vms-generator\Program.CcgSolutionFolder.cs`

- `SourceImageMap`：样图库按主题分子目录（`blister\`、`caliper\`、`label\`、`packaging\`、`brake_disk\`），
  方案 `Image\` 是平铺一层，故建映射表；表里没有的图直接抛，不静默产出空引用。
- `SourceImagePathOf`：只接受 `Image\文件名`（带子目录直接抛），反查映射要求唯一命中。
- `WriteFolderSolution`：校验 `SolutionName` 与落盘名一致 → 建目录与四个子目录 → 按引用收集图片并复制
  （同名同内容 SHA-256 复用，同名不同内容 `name_<hash8>.ext` 改名，绝不覆盖）→ 序列化 →
  `AssertNoExternalPath` 自检 → UTF-8 无 BOM 写出 → 打印落点、图片清单。
- `AssertNoExternalPath`：遍历全部 JSON 字符串值，命中盘符路径或 `..\`/`../` 即判红；
  方案内资产（`SourcePath`/`SourceImagePath`）另加一条 `^Image\\[^\\]+$` 形状校验。
- `CcgCsvRecord` / `CcgExcel`：方案内相对输出目录（`History\{StepName}\{yyyy-MM}\` 等），
  替代全仓共用的 `CsvRecord`/`Excel`（后者写 `D:\Records\...` 绝对路径）。

## 6. 踩过的坑

| 现象 | 根因 | 修法 |
|---|---|---|
| `FileNotFoundException: 样图不存在：...\Image\images\blister_01.png` | 方案内路径是平铺 `Image\blister_01.png`，而样图库按主题分子目录 | 建 `SourceImageMap` 做"源子目录 → 平铺文件名"映射 |
| `外部路径自检失败：...D:\Records\{StepName}\{yyyy-MM}\` | 共用 `CsvRecord` 写绝对目录 | 新增 `CcgCsvRecord`/`CcgExcel` 写 `History\...` |
| `[致命断连] 'D1-爪口宽度' 引用的上游节点不存在` | 跨流程接 `CalibrationPlugin.Transform`；编译器断连检查按流程作用域找上游，且标定守卫会比对标定图尺寸（640×480 vs 1280×1024）必然失败 | 删掉 Transform 连线，当量只走全局变量 `CalMmPerPixel` |
| `[连线断开] 上游 '...卡尺前处理' 不存在输出 'MeasureImage'` | `ResultDisplay` 图端口叫 `SrcImage` 不叫 `Image`；且图源指到了没有该输出的预处理步骤 | 图源指卡尺的 `MeasureImage` 输出，端口名保持默认 |
| `[连线断开] 上游 '调用工位X' 不存在输出 'Ok'` | `RunFlowPlugin` 输出端口是 `Invoked` | 改判 `!Invoked` |
| `[连线类型不匹配] 期望 Double，但上游 'Global' 提供的是 Boolean` | 布尔变量喂了数值比较 | 布尔汇总改走 `LogicOperationPlugin`（A/B 都是 bool） |
| `Cannot deserialize the current JSON array ... into StepModel` | `JArray` 被 `Add` 进 `Steps` 形成嵌套数组（踩了两次） | 一律 `AddRange`，并在改完后核对步骤总数 |
| `Hmi.DataGrid` 永远停在"还没配置采集" | 列定义属性键是 `GridColumns`（`ScadaDataGrid.Key`），不是 `Columns` | 改键名 |
| 卡片整块空白 | 绑定了变量的 `Hmi.Text` 没有非空占位初值 | 给 `TextProps` 塞占位文案 |

环境类：`ops_bash` 在本机不可用（`CreateFileMapping ... Win32 error 5`），全程 `pwsh`；
`dotnet build` 必须带 `-m:1 -nodeReuse:false`（AGENTS.md R179），否则静默失败；
`[IO.File]::ReadAllLines` 传相对路径会解析到 `D:\C#\VM\.Plugins\...`，一律用绝对路径。
