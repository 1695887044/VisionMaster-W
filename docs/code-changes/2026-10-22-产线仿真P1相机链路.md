## 2. 已做

### 2.1 `tools/LineSim`（仿真器侧）

- `tools/LineSim/World/Renderer.cs`（新增）：`RenderGray(camIndex, width, height, exposureUs, tick, axisMm, beltMm, out RenderTruth truth)`。背景竖向渐变 40→70；工件矩形中心 `partCx = 120 + worldXmm*1.2`、`partCy = height*0.55`、半宽 90 / 半高 60、内部 120→180、边缘 20px 衰减；`exposureGain = clamp(exposureUs/10000, 0.5, 2.0)`；噪声 `NextGaussian()*2.5`，种子 `Mix(camIndex*0x9E3779B97F4A7C15, tick)`。
  - `RenderTruth(WorldXmm, PartCenterXpx, PartCenterYpx, HalfWidthPx, HalfHeightPx)` **只给断言与 artifacts**，不进帧头。
- `tools/LineSim/Net/CameraServer.cs`（新增）：`TcpListener` 手写最小 HTTP/1.1（不用 `HttpListener`——Windows 绑 `http://127.0.0.1:port/` 需 urlacl，非管理员会失败）。路由 `GET /health`、`POST /camera/{serial}/trigger`、`POST /camera/{serial}/config`、`GET /camera/{serial}/stream`。
  - 帧格式：`int32 LE headerLen | headerJson(UTF-8) | int32 LE pixelLen | pixels`；帧头字段 `tick/cam/w/h/ch/bits/exposureUs/gain/seq/ts`。
  - 每相机通道容量 8（对齐 `CameraSettings.BufferCapacity` 默认），满则丢最旧并计 `dropped`。
  - 世界状态在 `lock (world.Gate)` 内快照，**渲染在锁外**执行（几毫秒的渲染不能占着 1kHz tick 的锁）。
- `tools/LineSim/Program.cs`：`Serve()` 起相机通道；`Options.CameraPort = 19500` + `--camera-port`；`--trace` 同时打开运控与相机日志；`finally` 里先停相机再停运控。
- `tools/LineSim/SelfTest.cs`：新增 `CheckCameraPipeline()`（14 条）。

### 2.2 `Plugins/Plugin.Camera.Sim`（上位机侧驱动）

- `Plugin.Camera.Sim.csproj`：`net9.0`（不带 `-windows`）、只引 `Shard/Core.Interfaces`、`<EmbeddedResource Include="Help\**\*" />`。
- `SimCameraDevice.cs`：`[Display(Name="产线仿真相机", GroupName="相机")]`，派生 `CameraDeviceBase`。
  - 端点：`ResolveEndpoint()` 优先环境变量 `VM_LINESIM_CAM`（`host:port`），否则常量 `127.0.0.1:19500`（设计 §9.1 的 V1 裁决：插件拿不到宿主配置，端点走插件常量 + 环境变量）。

  - `OpenCore()`：`GET /health` 并校验 `cameras[].serial` 含本相机序列号（大小写不敏感、不模糊匹配）→ 起心跳。

  - 收流：`HttpCompletionOption.ResponseHeadersRead` 长连接逐帧解码，断线 1s 重连；帧头 64KB / 像素 64MB 上限。
  - `SourceName = linesim-{serial}-{seq:D6}.png`（**不含 tick / 位置等真值**）。

## 5. 踩过的坑

1. **`UseWPF=true` 的隐式 using 集合不含 `System.IO`**（第三次命中）：`CameraServer.cs` 缺 `using System.IO;` → `CS0103: 当前上下文中不存在名称"IOException"`。凡 `UseWPF=true` 工程碰 `Stream/IOException` 都必须显式 using。
2. **`HttpListener` 在非管理员下绑 `http://127.0.0.1:port/` 会因 urlacl 失败** → 相机流改 `TcpListener` 手写最小 HTTP，别为了省事换回去。
3. **渲染不能持世界锁**：1kHz tick 每拍 500μs 预算，一次 1280×1024 合成是毫秒级。正确姿势是锁内快照 → 锁外渲染 → 入队。
4. **探针的 `args[0]` 不可信**：`run-probe.ps1` 会追加 `--nologo`，把 `args[0]` 当路径用会报"找不到 LineSim.exe：--nologo"。改成只认 `--linesim <path>`。
5. **构建失败时旧 exe 还在**：`--selftest` 会照常打印上一次的结果（R65 同族）——先看构建输出再跑。
