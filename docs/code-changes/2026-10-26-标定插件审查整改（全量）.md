## 五、踩过的坑

- **CAL-1 的触发条件比报告写的窄**：`CaltabDescrFile` 会触发 `RefreshStatus`，但**不进** `BuildInputSignature`，
  所以不会推进 stamp；真正会推进的是 `Intrinsics`/`UndistortBeforeCalibration`。断言必须用后者。
- **`Modules\` 被运行中的 VisionMaster 锁住**：插件工程的 `CopyPluginToModules` 会失败（MSB3027/MSB3021）。
  本轮先 `-p:ModulesDir=<临时目录>` 构建插件、宿主 `-p:BuildProjectReferences=false`，等进程退出后再正常重建。
  **不要杀用户的进程**。
- **2 通道 `Compose3` 不抛**（HALCON 23.05 实测），4 通道才会在 `PaintXld` 报 #1401；
  改叠加预览时按"1/2/3/4 通道分别处理"写，别按通道数猜。
- **`PaintXld` 3 通道 + 3 元组静默不上色**：`AnnotationBaker` 的 `BakeObj` 是已验证的替代路径；
  `[PT] AnnotationBaker` 断言直接量绿色通道。
- **手眼结果持久化别再反解显示串**：显示串是 3 位小数，反解会丢精度且受 Culture 影响；
  直接存 `Mat4.ToArray()`，显示/解析统一 Invariant。
- **枚举文案两处来源**：`StepConfigOption.ForEnum` 已经读 `[Display(Name)]`，视图直接绑它的 `Display`，
  不要再在 XAML 里手写中文。
