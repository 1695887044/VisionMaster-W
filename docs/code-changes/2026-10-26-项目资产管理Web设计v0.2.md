## 踩过的坑

- **flex 子项收缩**：`preview-card` 在详情滚动列里被压成 9.33px，预览图溢出到元数据后面；修法是 `flex: 0 0 auto` + 明确高度。
- **HALCON 坐标**：`(Row, Col)` / Y 向下，不能按屏幕坐标画；A/B 同行水平线才是像素当量。
- **假精度**：两点标定 0 自由度，不允许显示 `RMS 0.000 px`；残差要按标定方式给或明确“不适用”。
- **状态混轴**：生命周期、保护、验收是三件事；锁定不是危险色。
- **交互数据一致性**：切换资产行必须同步详情和元数据，否则点 `BoardAlign` 仍显示 `LineCalib` 的当量。
- **数字一致性**：页签计数、列表计数、健康度必须同源；`6/6` 与方案 `24` 要分开表述。
