3. **焦点环就地画、不挂 `DialogFocusVisual`**：后者在 `Dialog.Misc.xaml`，而本分册只自合并
   `Colors.xaml`（R30：跨册 `StaticResource` 解析期直接抛）。就地用 `DialogAccentBrush` 加粗描边，
   与全仓 2px 环同形。

## 5. 踩过的坑

| # | 现象 | 原因 | 解法 |
| --- | --- | --- | --- |
| 1 | `MC3024 已设置 Button.Style 属性，并且只能设置一次` | 同一个 `Button` 上既写了 `Style="{StaticResource …}"` 属性，又写了 `<Button.Style>` 元素 | 二者只能留一个；用 `Button.Style` 时把属性删掉 |
| 2 | 图标全是豆腐块 □ | 用了 App 级 `{StaticResource Icon}`（`VisionMaster\App.xaml`），探针宿主里这个 `FontFamily` 解析不到；同文件的 `DialogIconFont` 正常 | 统一改用 Dialog 分册自己的 `{StaticResource DialogIconFont}`——两者指向同一个 otf，但只有后者在探针里可靠 |
| 3 | `InvalidOperationException: 无法对只读属性 SearchText 进行 TwoWay 绑定` | 探针用匿名对象喂 DataContext，匿名类型属性只读；搜索框 `Text` 默认 TwoWay | 换成有 setter 的 `FlowManagerProbeContext` |
| 4 | 断言「RunState 变化 → 重发 StatusKind」判红，明细却是 `RoleBadgeToolTip` | `Refresh()` 一口气重发十几个派生属性，测试只记了**最后一个** `PropertyName` | 收进 `List<string>` 再判 `Contains`——拿最后一个比会把正确实现判红 |
| 5 | `CSC CS2012 无法打开 VisionMaster.dll（被 .NET Host 锁定）` | 上一轮构建的临时 WPF 宿主进程尚未退出 | 隔一次重跑即可（`tasklist` 已查不到该 PID）；不是常驻 `VisionMaster.exe` |
| 6 | 探针第一版渲出来"仅子程序"没了 | 删「调用关系」列时只搬了 chips，漏了 `IsSubroutineOnly` / `Manual` 两种派生说明 | 补 `DerivedNote`（中性色）+ `ConfigNote`（琥珀警告），两者互斥让位，同一时刻只出一行 |
