# 资产化三项落地：手眼入标定目录 / 标定源图接资产 / 模板条目参考图接资产

## 一、当前状态

评审（`docs/架构文档/交接报告/交接报告-2026-10-28-资产化插件覆盖评审.md`）列出的三项已实现并验证：

1. **P1 手眼结果入方案标定资产目录**（`ICalibrationCatalog`）+ 资产页类型标签补 `手眼标定` 分支；
2. **P2 标定源图可挂图像资产**（单图标定：像素当量/九点/透视/网格；批量内参仍用文件夹）；
3. **P2 模板条目参考图可挂图像资产**（Matching / DeformableMatching，条目级）。

三项共用同一块新能力：**配置态的「资产 Id → 绝对路径」快照**。

## 二、已做

### 1. 契约：配置上下文补资产路径快照（`Shard\Core.Interfaces\IPluginConfigContextProvider.cs`）

- `PluginConfigContext.Assets`：`List<AssetPathOption>`，元素含 `AssetId / Kind / Name / AbsolutePath / Version`，
  `Caption` 供下拉显示、`AssetIdText` 供 `SelectedValuePath`（避开 Guid↔string 在"清空选择"时的转换失败）。
- `PluginConfigAssetPaths.TryResolve(context, assetId, expectedKind, out path, out error)`：
  配置态解析口径，判据与运行期 `ProjectAssetPathResolver` 一致（Id 合法、类型必须匹配、路径必须非空），
  报错点名"两边类型"，不让用户对着空画布猜。

> 为什么必须新开这条通道：`ProjectAssetPathResolver` 要 `IExecutionContext`，而**配置态没有**。
> 这三处（标定源图、条目参考图）恰好都只在配置态读盘——没有快照就只能让用户手填绝对路径，
> 而那正是资产系统要消灭的东西。

### 2. 宿主：组装快照（`VisionMaster\ViewModels\DialogViewModels\PluginConfigShellViewModel.cs`）

`BuildConfigContext()` 增 `Assets = BuildAssetPathOptions()`；逐个文件资产调用
`SolutionProjectAssetResolver.TryResolve` 取值——**归档拦截、越界校验、文件存在性三处判据复用运行期那一份**，
避免出现"界面上选得到、跑起来报已归档"。

## 四、未做 / 已知边界

- **批量内参标定（文件夹 / 图列表）未接资产**：`ProjectAssetPathResolver.TryResolve` 只返回单文件路径，
  一个 image 资产表达不了 N 张图。要闭环需新增「图集/清单」类资产，属独立批次。
- **手眼资产改名没有独立入口**：目前靠 `CatalogAssetName` 配置项；资产页侧暂无重命名 API。
- **Deformable 的界面级效果未断言**：`_isConfigInstance` 只在 `GetConfigView` 里置真，而它会 `new` 一个 WPF 视图；
  断言宿主不建窗口，因此只断言了 `LearnTemplate` 的失败语义 + 条目字段 JSON 往返。
  Matching 侧用公开的 `LoadPreviewImage` 覆盖了"资产优先/不退回"的完整链路。
- **资产版本更新不会让进程内推理会话失效**（评审 §5.3 的 P1）：本轮未动，Yolo/DlClassify/DlSegment/DlAnomaly
  的会话缓存仍只按路径做键。

## 五、踩过的坑

1. **`SetConfigContext` 的接收者是 `_pluginView` 而不是 `_plugin`**：`VisionPluginBase : IPluginConfigView`，
   所以实现写在插件类上是对的；若写成独立视图类反而收不到（宿主只在 `_pluginView` 上判接口）。
2. **Guid↔string 的 `SelectedValue` 绑定在"清空选择"时会抛转换失败**（表现为选完跳回），
   故 `AssetPathOption` 额外给 `AssetIdText` 字符串投影。
3. **`vms-generator` 的并行会话会污染门禁**：样例流程被重写后，`样例流程编译通过` 与
   `形变匹配_*：流程编译通过` 一起红；判据是看 `pre-pair-*` 备份时间戳，不要急着怀疑自己的改动。
4. **cmd 壳里不能直接接 PowerShell cmdlet**（`| Select-Object` 报"不是内部或外部命令"），
   后台跑脚本一律 `powershell -File`，不加管道。
5. **中文路径不能进 `-Command`**（R2 的真实复现）：`Select-String -Path 'D:\C#\VM\解决方案\...'` 直接报路径不存在，
   改用 `Get-ChildItem -Recurse -Filter *.vms` 拿对象。
