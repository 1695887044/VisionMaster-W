## 五、踩过的坑

1. **属性名含 `Color` 会被色名静态扫描拦住**：`OverlayColors = ""` 被判成非法色名字面量；
   改成 `OverlayPalette`（语义也更准），不要往白名单里塞空串。
2. **`GetLineWidth()` 无 out 参数**：HALCON 23.05 的 `HWindow.GetLineWidth()` 直接返回
   `double`，不是 `out HTuple`；写错编译报 CS1501。
3. **`OverlayLabels` 顺序必须与 `OverlayContours` 一致**：读码流程用 `Codes`；
   若上游过滤过空串导致数量不一致，多出的轮廓不标字（不要按名字猜）。
4. **`AnnotatedImage` 不含覆盖层**：覆盖层只画在图像窗口；要存“带框的图”需要另做。
5. **线宽要还原**：`RenderAnnotations` 画完必须 `SetLineWidth(previousWidth)`，
   否则下一次普通重绘会沿用覆盖层线宽。
