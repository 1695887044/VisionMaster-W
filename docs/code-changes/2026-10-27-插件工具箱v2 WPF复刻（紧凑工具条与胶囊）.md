## 五、踩过的坑

- **探针拖拽源期望值写反**：`ToolView.xaml` 早已设 `UseDefaultEffectDataTemplate="False"`（2026-10-23 为去掉库内置英文浮层），探针却还断言 `true`；改为 `false` 后才与真实接线一致。
- **搜索高度量错对象**：直接找 `TextBox` 量到 26（内容区），不是搜索壳 28；改为按 `x:Name="SearchShell"` 找外层 `Border`。
- **主滚动区找错**：`Descendants<ScrollViewer>` 第一个命中的是 `TextBox` 内部滚动；加 `Grid.GetRow(s) == 3` 过滤。
- **离屏宿主的 `IsVisible` 不可靠**：无窗口时 `IsVisible` 恒 false；空态断言改查父面板 `Visibility`。
- **搜索高亮 Run 选错**：图标字形也是 `Run`，先按 `r.Text == "图像"` 过滤再断言颜色。
- **收藏条目出现两次**：收藏组和原分类组各一份，图标都应保持分类色；收藏组**组头**才是暖金色。拆成两条断言，避免把“收藏组里的条目”误判成金色。
- **`UIThemeSmokeTest` 编译错误**：新检查用了未声明的 `shell` 变量；补 `var shellText = File.ReadAllText(path);` 并改用 `shellText`。
- **16px 胶囊不是整宽可点**：右侧 6px 让位后只有左半区命中；真机点击 (1267,120) 成功，日志三条齐全。不要用“点胶囊中心”做自动化坐标。
- **并发会话**：本轮期间其它会话在跑 `run_gates -Only UIThemeSmokeTest,HelpProbe -SkipBuild`、`FlowCanvasChecks`，并改动资产目录；构建锁/资产红不能直接归因本批。收尾 gate 必须等它们结束。
