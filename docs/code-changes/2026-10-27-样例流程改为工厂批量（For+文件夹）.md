## 五、踩过的坑

1. **`For.Index` 是 0 基**：`FileIndex` 直接接 `For.Index`，文件夹模式按 0..N-1 取图；
   不要手动 +1。
2. **文件夹模式不能用 `ImageAssetId`**：非空时 `ImageAcquisitionPlugin` 直接报
   “只适用于单文件采集模式”；必须置空。
3. **`FolderPath` 要绝对路径**：`AcquireFromFolder` 直接 `Directory.Exists(相对路径)`，
   按进程 cwd 解析，不认方案根；目录仍在方案 `Image\` 内。
4. **`ForStep` 的 `Children` 是 `StepCollection` 数组**：手写 `.vms` 时要
   `Children[0].Steps = [...]`，不能把步骤直接塞进 `flow.Steps`。
5. **断言要递归找步骤**：`flow.Steps.OfType<ActionStep>()` 现在找不到循环体里的步骤，
   必须走 `IContainerStep.Children` 摊平（`FlattenActionSteps`）。
6. **`JObject` 移动步骤要深拷贝**：直接把已有 `JObject` 塞进新 `JArray` 会改父节点，
   原 `Steps` 数组被清空/抛异常；用 `DeepClone()`。
