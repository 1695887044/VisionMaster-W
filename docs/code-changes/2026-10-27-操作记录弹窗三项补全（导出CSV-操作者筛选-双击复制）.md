## 已做

### 1. 导出 CSV（设计稿 §6：导出当前筛选结果，不是当前页）

- `OperationsLogViewModel.TryExportCsv(path, out error)`：按当前筛选条件（分类/操作者/时间/关键字）**全量**查询（`QueryPage(offset:0, limit:int.MaxValue)`）后写文件；UTF-8 **带 BOM**（Excel 打开中文不乱码，同 `ScadaAlarmHistoryWriter` 口径）+ RFC 4180 转义 + 含表头；失败不抛，原因回给界面。
- `ExportCommand`：保存对话框选路径（与项目资产导出同一做法，`Microsoft.Win32.SaveFileDialog`）→ 落盘 → 页脚提示「已导出当前筛选结果 → 路径」。
- 视图：筛选条右侧新增「导出 CSV」按钮（`DialogSecondaryButton`）；页脚左侧新增瞬时提示（VM `Feedback`/`HasFeedback`）。

### 2. 操作者下拉（下面这句是重点：界面以前没接，现在真的接上了）

- `SqliteSoftwareOperationLog.QueryActors(limit=200)`：`GROUP BY actor` 按出现次数降序；空操作者不入列；fail-open。
- VM：`ActorOptions`（首项「全部」）、`SelectedActor`；`RefreshActors()` **只在候选真的变化时重建集合**——不能无条件 `Clear()`：ComboBox 的 `ItemsSource.Clear()` 会把 `SelectedItem` 推成 null（TwoWay 回写）→ 洗掉用户当前选中 + 触发多余重查（用 `_suppressReload` + `SequenceEqual` 短路）。
- 视图：筛选条「分类」与「时间」之间新增「操作者」下拉（`DialogCombo`）。

### 3. 双击复制明细（键盘 ↑/↓ 移动选中 = ListBox 默认行为，无需改）

## 踩过的坑

- **ComboBox `ItemsSource.Clear()` 会把选中项推成 null（TwoWay 回写）**：重建候选列表必须"有变化才动 + 重建期间抑制 Reload"，否则用户正在筛的操作者会被静默洗掉，并多触发一次查询。
- 导出"当前筛选结果"的正确做法是**按筛选条件重新全量查询**，不能拿界面 `Rows`（那是当前页，200 条封顶）——断言用 205 条夹具把这个口径钉死。
- 本机普通 shell 里没有 git（PATH 不含），仓库操作用的便携版：`D:\Program Files\WorkBuddy\resources\vendor\PortableGit\cmd\git.exe`（VS 2022 自带的那份也可用）。
