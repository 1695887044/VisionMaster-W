# SCADA 图元动画：值 → 外观 / 位置 / 可见性（手册 7.5.1）

对标 InoTouchPad 官方帮助手册第 7 章「控件」，本期落地手册 7.5.1 的四类常见动画：
**外观变化**（含 7.5.1.1 闪烁）、**水平移动**、**垂直移动**、**可见性**。

---

## 一、需求与决策

### 1. 需求
一个图元上，把「某个变量的值」映射成三样东西之一：
- **外观**：按值落进哪一档，换前景色 / 底色（多档值表，档内可再勾闪烁）；
- **位置**：按值在区间内的比例，把图元在 X 或 Y 方向上从「设计位置」线性推到「结束位置」；
- **可见性**：值落进区间就隐藏 / 显示。

### 2. 关键决策（逐条已与用户确认）

| # | 决策点 | 结论 |
|---|---|---|
| 1 | 四种动画取哪四个 | 外观变化 + 水平移动 + 垂直移动 + 可见性 |
| 2 | 7.5.1.1 闪烁要不要一并做 | 一并做（作为「外观变化」档位上的一个勾） |
| 3 | 配置入口形态 | 属性面板内嵌「动画」区，不另开弹窗 |
| 4 | 运行态由谁驱动 | 并入既有 `ScadaRuntimeBinder`，不新起一套泵 |
| 5 | 一个图元上同类型动画能有几条 | 至多一条（`GetOrAddAnimation` 复用、`RemoveAnimation` 摘除） |
| 6 | 动画行最左复选框的含义 | 代表「配没配这条动画」：勾上 = `GetOrAddAnimation`，取消 = `RemoveAnimation` |
| 7 | 「跑不跑」由谁管 | 展开区里另放一个独立「启用」复选框绑 `ScadaAnimation.IsEnabled`，与上一个勾各管一件事 |
| 8 | 外观档位怎么排 | 一张卡片两行：第一行「值 [低] ~ [高]」+ ↑/↓/✕；第二行「前景[色块] 背景[色块] ☑闪烁」 |
| 9 | 档位取色入口 | 复用属性栏那套色板弹窗 |
| 10 | 动画是否随图元复制粘贴 | 跟着走，`ScadaClipboardPayload` 版本 1 → 2 |
| 11 | 闪烁的相位从哪来 | 全画面统一节拍 `ScadaBeatSource`，不每个图元各起一个定时器 |

### 3. 设计要点（为什么这么做）

- **依赖单向**：换算规则全部落在 `Scada`（领域层，零 WPF）里的纯函数上，
  控件层只负责「把算出来的数落成 WPF 属性」。这样换算规则可以脱离界面单独验。
- **一个入口**：动画的增删改一律走 `ScadaElement` 的四个 API，不直接动 `Animations` 列表。
- **失败要看得见**：动画配错了（范围下限比上限大、值转不成数字、变量找不到）不许静默，
  一律进日志 + 打控件角标，且角标只撤自己那一个。
- **停用 = 干净**：`IsEnabled = false` 的动画既不订阅变量也不打点，便于现场「临时关掉一条看现象」。
- **不漂移**：移动动画的起点每次都现读 `Element.X / Y`，不是从上次落点再挪，反复刷新不会累积误差。

## 三、验证结果

命令：

```
dotnet build VisionMaster.sln -v q --nologo
dotnet run --project ScadaChecks\ScadaChecks.csproj --no-build
```

- 编译：**0 错误**（38 个既有警告，均为历史遗留的 `CS8600/CS8602/CS8604`，与本次改动无关）。
- 断言：**通过 1545 / 失败 0**（新增 41 条动画断言全绿）。

### 断言分六段，各钉一类口径

| 段 | 验什么 | 代表断言 |
|---|---|---|
| ① 领域层纯函数 | 换算规则逐条钉死，不碰 WPF | 闭区间命中（0 与 100 都算）；档位重叠先命中先用；半配档位跳过且求值恒 true；比例换算 50→200；超限夹取；单点范围阶跃；垂直读 `EndY` 不读 `EndX`；范围非法给出中文原因 |
| ② 一图元一类型一条 | `GetOrAddAnimation` 复用 / `RemoveAnimation` 未配返回 false | `ReferenceEquals` + `Animations.Count` |
| ③ 剪贴板往返 | 动画跟着图元复制粘贴，档位表不许丢一段 | `Version == 2`；逐字段往返（变量名 / 档位 / 闪烁位 / 两个颜色 / `EndX`） |
| ④ 运行态落点 | 数据泵按类型分流到控件 | 10 个控件 / 命中 7 未命中 1 / 解析 8 次 / 订阅 7 个；`Left` 170、`Top` 220；外观第一档红+黄；可见性命中即 `Collapsed`；换档未配的一项回落设计色；全不命中恢复设计外观；坏范围与坏值各打一个红标（+ 建表时「变量没找到」的黄标，共 3 个） |
| ⑤ 闪烁相位 | 相位来自全画面统一节拍 | 只有配闪烁的图元挂节拍（订阅数 1）；开闪立刻 `Opacity = 1`；650ms 后 `0`、再 600ms 后 `1` |
| ⑥ 摘表收场 | 退订阅、回设计值、计数归零 | `Stop` 后订阅 0 / 计数 0 / 角标 0 / `Left`·`Top`·前景·可见性·`Opacity` 全回设计值；摘掉运行上下文后节拍订阅归零 |

## 四、已知边界

1. **本期只做四种动画**。手册 7.5.1 里还有尺寸变化、旋转、缩放等，未做。
2. **一个图元上同类型动画只能有一条**。想对同一个变量做两段不同的位置映射，得换一种动画类型或拆图元。
3. **移动动画是「设计位置 → 结束位置」的线性插值**，终点只有一个；不支持多段折线轨迹。
4. **闪烁半周期固定 500ms**（`ScadaElementBase.BlinkHalfPeriodMilliseconds`），未开放给用户配置。
5. **闪烁只改 `Opacity`**，不改颜色、不改可见性，因此不参与「可见性合并」那套判定。
6. **外观档位的颜色只支持单色**（`SolidColorBrush`），不支持渐变、图片、透明度。
7. **剪贴板负载版本升到 2**：新负载老版本程序读不了（不向前兼容）；老负载（v1）新程序能读，读出来动画为空。
8. **配置入口 UI 已就绪，但「独立『变量事件』弹窗」仍未做**——那是 r3 的剩余项，与本期动画无关。
9. **本期断言只在断言宿主里跑**（STA 线程 + 手动 `FlushNow()` / `PumpDispatcher()` 推时间），真机上的手感（动画跟手程度、闪烁是否刺眼）仍需现场确认。
