# 变量管理下拉框「整框可点」修复（2026-09-17）

## 一、需求与决策

### 现象
变量管理对话框（`GlobalVariableView`）中三个下拉框（数据类型 / 所属连接 / 存储区）：
- **只有右侧小箭头那一小块能点开**；
- 鼠标移到框内文字区域，既不响应点击，指针也不变手型；
- 视觉上箭头被挤到框的左边缘、紧贴文字（截图可证）。

### 根因
`ModernCombo` 模板把「外观」和「点击热区」拆成了两个**兄弟元素**：

| 元素 | 职责 | 问题 |
| --- | --- | --- |
| `Border x:Name="Box"` | 画底纹/边框/圆角 | 只负责好看，没有 `ToggleButton` 语义，点了不展开 |
| `ToggleButton`（自带模板只有一个 10px 宽的 `Path` 箭头） | 点击热区 | **尺寸被内容撑到只有箭头那么大**，命中范围=箭头 |

也就是说，"看起来的框"和"能点的框"不是同一个东西 —— 用户点在 `Border` 上，
而 `Border` 根本不是按钮，自然毫无反应。

### 决策
参照本项目**已被验证可用**的写法（[DefaultStyle.xaml](../../UI/Controls/Themes/DefaultStyle.xaml) 全局 ComboBox 模板、
[ExcelExportView.xaml](../../Plugins/Plugin.ExcelExport/ExcelExportView.xaml) 的 `ModernComboBase`）：

> **一个 `ToggleButton` 同时承担「外观」和「热区」** —— 边框、底纹、圆角、箭头全部画在
> ToggleButton 自己的 `ControlTemplate` 里，并显式 `HorizontalAlignment/VerticalAlignment=Stretch` 铺满整框。

这样"看得见的框"必然等于"点得到的框"，从结构上杜绝此类回归。

同时做了三件配套动作：
1. 悬停 / 展开 / 禁用三个状态触发器**从 ComboBox 层下沉到 ToggleButton 模板内部**
   （用 ToggleButton 自己的 `IsMouseOver` / `IsChecked` / `IsEnabled` 驱动，`IsEnabled` 会从 ComboBox 继承下来）。
2. `Cursor="Hand"` 显式写在 ToggleButton 上，保证整框都是手型。
3. `ContentPresenter`（显示选中项）保持 `IsHitTestVisible="False"`，叠在热区之上不吃点击。

## 二、修改文件清单

| 文件 | 改动 |
| --- | --- |
| `VisionMaster/Views/DialogViews/GlobalVariableView.xaml` | `Style x:Key="ModernCombo"` 的 `ControlTemplate` 重构（约 L166-260） |

具体 diff 要点：
- 删除独立的 `Border x:Name="Box"`；
- `ToggleButton` 新增 `x:Name="Chrome"`、`HorizontalAlignment="Stretch"`、`VerticalAlignment="Stretch"`、
  `Cursor="Hand"`，并把 `Background/BorderBrush/BorderThickness` 改为 `TemplateBinding` 接收；
- 箭头 `Path x:Name="Arrow"` 移入 ToggleButton 模板内的 `Border x:Name="Bd"`（带 `CornerRadius="8"`）；
- 新增 ToggleButton 模板内触发器：`IsMouseOver` → 边框 `#CBD5E1`；`IsChecked` → 边框与箭头变主色 `PrimaryBrush`；
  `IsEnabled=False` → 底纹 `#F1F5F9`；
- ComboBox 层 `ControlTemplate.Triggers` 只保留 `IsEnabled=False` 时的 `Foreground`（去掉原先引用已删除 `Box` 的两条）。

**未改动**：`ItemTemplate` / `ItemContainerStyle` / `DisplayNameTemplate` / `ConnectionOptionTemplate`、Popup 内部结构、
三个 ComboBox 的用法（`Style="{StaticResource ModernCombo}"` 调用方零改动）。

### 经验沉淀
> 自定义 ComboBox 模板时，「可见外框」和「点击热区」**必须是同一个元素**。
> 拆成兄弟元素时，只要热区元素被内容撑小，就会出现"只有箭头能点"的经典故障。
> 判定口诀：**框画在谁身上，就由谁去 `IsChecked` 绑 `IsDropDownOpen`。**
