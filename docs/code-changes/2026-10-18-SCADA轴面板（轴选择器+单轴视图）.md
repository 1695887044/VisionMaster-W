# SCADA 轴面板（轴选择器 + 单轴视图）

日期：2026-10-18
范围：轴面板（轴选择器 + 单轴视图 + 自带操作按钮）。同日的运动命令与系统变量分支另见
`2026-10-18-SCADA组态运动命令族.md` 与 `2026-10-18-系统变量分支（运动轴只读投影）.md`。

## 1. 背景与用户裁定

用户要的是"调试台"形态：**一个控件只显示一根轴**，设计期多选候选轴，运行期用下拉框切换；
不在一个控件里同屏显示多轴。

据此裁定：

| 决策点 | 结论 |
| --- | --- |
| 控件形态 | 轴选择器 + 单轴视图（下拉框在控件内部） |
| 面板能力 | 显示：位置/速度/使能/到位/限位/报警；操作：**使能/失能、点动（按住）、回零（长按 0.5s）、停止、清报警**；可用 `ShowCommands=false` 退回纯监视 |
| 视觉 | 参考 `web-70060145-source` 的暗色控制台：近黑卡片、珊瑚红强调、等宽数字、状态灯 |
| 候选来源 | 只能从工程里**已启用**的轴中多选，不允许自由文本 |
| 身份 | 轴需要稳定 `AxisId`（与变量 `VariableId` 同一口径：Id 优先、名字兜底） |

关键定性：**这不是 `ScadaBinding`**。轴候选是设计期配置（存属性袋），运行期选哪根轴是控件状态；
把它塞进数据泵会去解析一个不存在的变量。属性行因此是 `Kind=AxisList`、`IsBindable=false`。

## 3. 运行期数据流

```
IMotionDevice.PollStatusCore（驱动自己的 10ms 轮询）
      │  GetAxisStatus（读缓存，不发通信）
      ▼
MotionStatePublisher（100ms，后台线程）
      │  整表交换：Dictionary<AxisId, ScadaAxisInfo/Sample>
      ▼
IScadaAxisSource
      │  轴面板在 ScadaBeatSource（200ms，UI 线程）里拉当前轴
      ▼
AxisPanelElement（写自己的只读 DPs → 模板渲染）
```

三条口径：

1. **拉模式**：不按值变化推事件，避免一屏几十个面板刷爆 UI 线程。
2. **每拍每物理轴只读一次**：多个面板绑同一根轴也只在发布器读一次。
3. **离线不编 0**：拿不到快照给 `IsValid=false`，面板显示"—"并给出原因；0 是合法位置，会把"不知道"伪装成"在原点"。

切换轴的安全语义（本轮只读，但为下一批命令预留）：

- 切换只改显示目标，不改模型；
- 当前轴被移除/停用时**保留选中**并标"（已移除）/（不可用）"，不静默跳到别的轴；
- 单轴时下拉框收起，只显示轴名。

## 6. 风险与边界

| 风险 | 处置 |
| --- | --- |
| 历史轴身份不稳定 | 确定性 Guid（卡 Id + 物理轴号）；迁移后随保存落盘 |
| 轴改名断链 | 面板/选择器按 `AxisId`；名字只做展示与旧数据兜底 |
| 轴被删/停用 | 保留选中并标不可用；不自动跳轴 |
| 离线显示 0 | 明确禁止；`IsValid=false` + "—" + 原因 |
| 高频刷新 | 发布 100ms、面板拉 200ms、只读缓存；不按值推事件 |
| 线程 | 发布器后台线程；面板只在 UI 节拍读快照；`Changed` 不在 UI 线程 |
| 旧 `.vms` | 新字段缺失取默认；`AxisOptions` 缺失=空清单；不影响旧画面 |
| 属性面板误绑 | `AxisOptions` 标 `IsBindable=false`，不挂 ƒx |
| 单控件多实例 | 选择状态在控件实例上，互不共享 |
