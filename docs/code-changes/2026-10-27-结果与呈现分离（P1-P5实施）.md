## 五、踩过的坑

1. **PowerShell 5.1 绑不上 Newtonsoft `JObject` 的索引器**：`$obj['k'] = v` 会命中 `Item[int]`
   （报"无法将值 SrcImage 转换为 Int32"），`$a['x']['y'] = v` 直接不可赋值。改用 `.Property()/.Add()`
   也不行（`Property()` 被解析成枚举器）。最后改用 `System.Text.Json.Nodes` 写了个一次性 C# 工具
   （`tools\oneoff\_VmMigrate`，用完即删）。
2. **`MeasureAnnotation.LineWidth` 是 `double`**：`int w = a.LineWidth > 0 ? a.LineWidth : 2;` 编译不过，
   要显式 `(int)Math.Round(...)`。
3. **`HRegion` 接不进 `OverlayContours(HXLD)`**：`FlowCompiler.IsLinkable` 用 `IsAssignableFrom`，
   两个类型是兄弟。把端口声明成 `HObject` 才能同时收，运行时 `InputPort` 有 `rawValue is T` 快路径。
4. **`BakeOverlay` 默认值就是契约**：默认 true 会让 A1b（"覆盖层不烧像素"）打红——不是断言错，
   是新口径下该断言测的是 `BakeOverlay=false` 那条路；已拆成 A1b/A1c 两条。
5. **加了 `[StepConfig]` 就会改 `InputValues` 键数**：Bead 有一条"26 个键"的硬断言，必须同步成 27
   （它守的是"新入口没被顺手加进落盘"）。
6. **改 Help 必须重建插件**（R42/R62）：`.md` 是内嵌资源，`Modules\` 的 DLL 不会自己刷新。
7. **残留的断言宿主进程会锁 exe**：`FlowCanvasChecks (14248)` 让构建报 MSB3027，先结束它再构建。
