## 1. 耦合矩阵（SOP §5.1）

> 判定原则：任何"控件是某个端口/命令/配置属性的唯一入口"的行，标为"只能包裹/改外观"，不重写。

| 区域/元素 | 当前绑定/契约 | 功能依赖 | 可重构级别 |
| --- | --- | --- | --- |
| 根布局 | 无 | 纯布局 | 自由 |
| 图像输入 | `cv:LinkableValueEditor Port="{Binding Image}" StepData="{Binding StepData}"` | 端口持久化、类型转换、变量链接/解除链接；`Image.PropertyChanged` → `ShowUpstreamImage()` | **只能包裹**，控件与 `Port`/`StepData` 不能换 |
| 模型路径 | `TextBox Text="{Binding ModelPath, UpdateSourceTrigger=PropertyChanged}"` + `OnBrowseModelClick` | `[StepConfig]` `ModelPath`；`ResolvePath`（相对宿主目录）；`EnsureSession` 路径变化换会话 | **只能包裹**，属性名/类型/更新时机不变；浏览逻辑保留 |
| 模型摘要 | `TextBlock Text="{Binding ModelSummary}"` | `EnsureSession()` / ONNX 元数据（输入输出形状、task、类别名）；选错模型的第一线索 | 只读展示，绑定保留 |
| 置信度阈值 | `TextBox Text="{Binding ConfidenceThreshold}"` | `[StepConfig]` double；`YoloParams.ConfidenceThreshold` | 只能包裹，类型与属性名不变 |
| NMS 重叠阈值 | `TextBox Text="{Binding NmsIoU}"` | `[StepConfig]` double；`YoloParams.NmsIoU` | 只能包裹 |
| 最多保留目标数 | `TextBox Text="{Binding MaxDetections}"` | `[StepConfig]` int；`0 = 不限` | 只能包裹 |
| 输入尺寸 | `TextBox Text="{Binding InputSize}"` | `[StepConfig]` int；`0 = 模型元数据静态尺寸` | 只能包裹（高级折叠区） |
| 类别过滤 | `TextBox Text="{Binding ClassFilterText}"` | `[StepConfig]` string；`ParseClassFilter` 明确报错，不静默不过滤 | 只能包裹（高级折叠区） |
| 裁剪边距 | `TextBox Text="{Binding CropMargin}"` | `[StepConfig]` int；`YoloCrop.CropBest` 越界夹取 | 只能包裹（高级折叠区） |
| 试算 | `OnTryDetectClick` → `TryPreviewDetect()` | 与运行期共用 `TryDetect`；写 `ResultSummary`；模型/阈值/letterbox 诊断 | 保留行为；改为视图本地 `TryDetectCommand` 转发 |
| 预览 | `h:ImageReadOnly HImage="{Binding DisplayImage, Mode=OneWay}"` | HALCON 显示/缩放/右键菜单；`DisplayImage` setter 在 UI 线程释放旧 `HImage` | **只能包裹**：控件类型与 `HImage` 绑定保留；改为 `ContentControl` + `DataTemplate` 按需创建 |
| 预览工具条 | 无（旧视图无工具条） | `HalconBase.FitToWindow()` / `FitToImage()` 既有公开方法 | 可新增按钮，但只接既有方法 |
| 提示/结果 | `Hint` / `ResultSummary` / `ModelSummary` | 插件原样提供的文案；本插件没有 `StatusLevel` | 只换布局与语义色，不改文案/判定 |
| 生命周期 | `GetConfigView` → `new YoloView { DataContext = this }`；`Loaded` → `OnViewLoaded()` | 宿主靠 `DataContext as IPluginConfigView` 取 `OnConfirm`；`OnViewLoaded` 刷上游图与模型摘要 | 保留构造/`DataContext`/`Loaded` |
| Mode / SelectedItem / DisplayViewIndex / StatusLevel | **本插件没有这些属性** | — | **不新增、不伪造** |

## 3. 改动点

1. **整页重写 `YoloView.xaml`**：两栏（左 356px 配置轨 + 右预览工作区）；左栏按「图像输入 → 检测模型 → 检测参数 → 高级参数 → 试算」单页排布；高级参数收进原生 `Expander`，默认收起。
2. **模型信息卡**：`ModelSummary` 放进等宽只读信息卡；模型路径输入 + 「浏览」按钮；保留相对路径说明与「只支持 detect」说明。
3. **检测参数表单化**：置信度 / NMS / 最多目标数三项采用「标签 + 右对齐数值框 + 帮助文字」；`InputSize` / `ClassFilterText` / `CropMargin` 收进高级折叠区；数值框启用 `Typography.NumeralAlignment="Tabular"`。
4. **预览工作区**：`ContentControl PreviewHost` + `DataTemplate` 内 `h:ImageReadOnly HImage="{Binding Mode=OneWay}"`；有图才创建控件；空态（等待图像输入）与错误态（模型加载失败）为纯 WPF 覆盖层；左上「只读预览」角标；工具条「适应窗口 / 1:1」接既有 `FitToWindow()` / `FitToImage()`。
5. **试算结果卡**：`ResultSummary` 独立成结果卡；正常 / 0 个目标 / 失败三态用 `Dialog*` 语义令牌区分（`ResultStateConverter` 只读文本前缀，不改业务）。
6. **状态栏**：`Hint` 原文 + 右侧 `ModelPath`；本插件没有 `StatusLevel`，不伪造四档。
7. **颜色全令牌化**：视图 XAML `hex=0`；全部颜色走 `Dialog*` / `PluginPreview*` / `Scada*` 既有令牌；**未新增公共令牌**。
8. **`YoloView.xaml.cs`**：保留默认构造、`Loaded`、两个预览缩放转发；新增 `BrowseModelCommand` / `TryDetectCommand`（转发既有逻辑）、`ModelFileNameConverter`、`ResultStateConverter`、`YoloStateConverter`、`RelayCommand`；`FindVisualChild<ImageReadOnly>` 从 `PreviewHost` 取模板内实例。
9. **`YoloPlugin.cs` 两处 nullable 注解**：`InputPort<HImage>` 的 `null` → `null!`；`BestCrop.Value = BuildBestCrop(...)!`。仅消除既有 CS8625/CS8601 编译警告，运行期语义不变。

## 4. 与 ImageAcquisition V2 的差异

| 维度 | ImageAcquisition V2 | Yolo v1 |
| --- | --- | --- |
| 信息架构 | 4 个采集模式 2×2 卡片 + 模式专属参数 + 输出 | 无模式；固定「输入 → 模型 → 参数 → 高级 → 试算」 |
| 左栏 | 模式卡片 + 单页参数 + 底部固定「输出」 | 单页参数 + 试算（随左栏滚动，避免固定卡占掉表单高度） |
| 预览头 | 图像文件名 + 模式标签 | 模型文件名（`ModelPath` 的文件名；空则「检测预览」）+ 「上游图像 · 只读」 |
| 预览工具条 | 适应窗口 / 1:1 / 目录刷新 | 适应窗口 / 1:1（没有目录刷新） |
| 空态 | 按模式分 4 种空态 + 选择图片/文件夹按钮 | 单一空态「等待图像输入」，无按钮（图像只能来自上游/变量） |
| 错误态 | 预览加载失败 + `StatusMessage` | 模型加载失败 + 固定下一步 + `ModelSummary` |
| 状态栏 | `StatusMessage` / `StatusLevel` 三档 | `Hint` 原文；无 `StatusLevel`，不伪造 |
| 结果区 | 推送测试结果文本 | 试算结果卡（正常 / 0 目标 / 失败三态） |
| 参数控件 | 4 个 `LinkableValueEditor` | 1 个 `LinkableValueEditor`（Image）+ 7 个 `[StepConfig]` TextBox |
| 新增令牌 | 5 个 Dialog + 5 个 Preview | **0 个**（全部复用既有令牌） |

## 7. 遗留问题 / reviewer 重点

1. **未新增插件特定断言**：按本轮约束，`UIThemeSmokeTest\Program.cs` / `.csproj` / `PluginViewSmoke.cs` 是共享文件，未修改；批量冒烟已覆盖 `DataContext`、`LinkableValueEditor.Port`、`OnConfirm`、`hex=0` 与初始态渲染。建议 reviewer 重点复核：
   - 展开「高级参数」后三个 TextBox 的绑定（`InputSize` / `ClassFilterText` / `CropMargin`）与 `OnConfirm` 写回值；
   - `BrowseModelCommand` / `TryDetectCommand` 在真实宿主中的可执行性（视图本地命令，`RelativeSource AncestorType=UserControl`）；
   - `ContentControl` 模板内 `ImageReadOnly` 在真机窗口中的创建时机与 `FitToWindow` / `FitToImage`。
2. **预览证据边界**：`ImageReadOnly` 是 HALCON `HwndHost`，`RenderTargetBitmap` 不捕获其内容；`Plugin.Yolo-YoloPlugin.png` 展示的是空态布局，真实图像预览需真机窗口验证。
3. **既有文案不一致（未改业务）**：`TryPreviewDetect()` 在无图时写 `"先点「载入」把示意图读进来再试算"`，但本视图没有「载入」按钮（图像来自上游/变量）。这是插件既有文案，本轮未改；建议后续在业务文案里改成「先在「图像输入」绑定上游图或变量」。
4. **未做项**：加载骨架、图像尺寸/文件大小、放大/缩小、打开所在文件夹、系统导航、检测框叠加、类别名列表/选择器（见设计基线 README 的 D1-D6）。
5. **`UIThemeSmokeTest` 构建警告**：`HslCommunication.csproj` 的 `System.Resources.Extensions` 解析警告是第三方工程既有警告，与本插件无关；`Plugin.Yolo` 本身 0 警告。
