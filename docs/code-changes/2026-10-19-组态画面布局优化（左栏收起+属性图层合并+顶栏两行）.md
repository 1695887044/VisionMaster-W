# 组态画面布局优化（左栏收起 + 属性/图层合并 + 顶栏两行）

日期：2026-10-19
范围：
- `VisionMaster/Shell.xaml`（右栏合并、工具箱宽度、窗口最小尺寸）
- `UIThemeSmokeTest/ShellCopy.xaml`（结构副本同步，R44）
- `VisionMaster/Services/LayoutHelper.cs`（模式收敛：左栏、日志、标签选中；结构版本 v4）
- `VisionMaster/Views/ScadaEditorView.xaml`（顶栏拆两行）
- `UIThemeSmokeTest/Program.cs`（新增 ③b 三条断言）

## 现象

1280 窗口下进入组态设计，画布只剩约 **140px** 宽的一条竖带；顶栏的「画面」下拉框之后全部被裁。
右侧三列（属性 260 + 图层 240 + 图元工具箱 300 = 800）+ 左栏 340 把中央挤没。

## 改动

### 1. 组态模式收起左栏（+340px）

`ApplyScadaPanelMode(scadaDesign: true)` 额外 Hide `Panel_FlowListView` / `Panel_ProcessView`；
退出组态时 `ShowPanel` 恢复（走 `ShowAnchorable`，R58）。
组态设计里图元绑的是变量、不是流程步骤，左栏不参与。

### 2. 属性 + 图层合并成一个 pane 的标签页（+240px）

`Shell.xaml` 里把 `Panel_ScadaLayerView` 挪进 `Panel_ScadaPropertyView` 所在的
`LayoutAnchorablePane`（260 宽），删除原独立 240 列。右侧从 260+240+300 收成 260+260。

- **面板归属变了 → `CurrentLayoutSchemaVersion` 3 → 4**（R43）。旧 `Layout.xml` / `DefaultLayout.xml`
  会被拒一次，回退 Shell.xaml 默认布局；用户此前拖的布局会失效（升级必读）。
- `ScadaDesignPanels` 顺序改为「图层 → 属性 → 图元工具箱」：两者同 pane 时最后 Show 的成为当前标签，
  属性是主面板必须最后。
- `ShowPanel` 对 `LayoutAnchorable` 补 `IsSelected = true`：同一 pane 的标签页切换看的是
  `IsSelected`，`IsActive` 是"整个 DockingManager 的活动内容"，少这一句会停在最后 Show 的标签上。

### 3. 图元工具箱 300 → 260（+40px）

搜索框 + 分组列表在 260 下足够。

### 4. 组态模式收起底部日志（+199px 高度）

`ApplyScadaPanelMode(true)` 把日志所在 pane 的高度收成 **1px**，退出时恢复原高度。
不用 `HidePanel`：日志/监控栏/设备状态共用 pane，隐藏一个会把整组收起，且丢失用户的标签选择。

**为什么是 1px 不是 0**：AvalonDock 的 `DockHeight` 会把 0 夹回原值（实测 `set0` 读回 200），
1px 正常生效；视觉上就是一条边线。`_savedLogPaneHeight != null` 作为幂等判据（不能用高度判断，
收起后是 1 不是 0）。

### 5. 组态顶栏拆两行

`ScadaEditorView.xaml` 顶栏从"左右两个 StackPanel 的 DockPanel"改成两行：

- 第 1 行：画面 / 基座 / ＋新建 / ▾ / 删除 / 撤销 / 重做；
- 第 2 行：网格 / 吸附 / － / 比例 / ＋ / 适应 / 1:1 / ▶ 运行画面。

每行各自套横向 `ScrollViewer`：面板再窄也只会出滚动条，不会把按钮裁掉（运行按钮首当其冲）。

### 6. 主窗口最小尺寸

`Shell.xaml` 增加 `MinWidth="1200" MinHeight="760"`：固定面板不会让路，窗口再小只会把画布挤没。

## 效果（1280 窗口）

| 项 | 改前 | 改后 |
| --- | --- | --- |
| 左栏 | 340 | 0（组态模式下收起） |
| 属性 + 图层 | 260 + 240 | 260（标签页） |
| 图元工具箱 | 300 | 260 |
| **画布宽度** | **≈ 140** | **≈ 760** |
| 底部日志高度 | 200 | 1（组态模式下） |

## 验证

- `dotnet build VisionMaster` → **0 错误**。
- `UIThemeSmokeTest` 新增 ③b 三条全部 PASS：
  - 组态模式收起左栏（程序/流程栏），退出后恢复；
  - 组态模式把底部日志收成 1px 条，退出后恢复 200；
  - 属性/图层在同一个 pane（标签页），组态模式默认选中属性。
- 既有面板模式 ①②③、流程栏列宽 ⑨、出厂快照 ⑩ 全部仍绿；仅剩既有 vendored GridView 红灯。

## 升级影响

- 结构版本升到 4：**首次启动会丢弃用户已保存的布局**（`Layout.xml` 被跳过，回退默认布局），
  之后按新布局重新保存。方案（.vms）内嵌的旧布局同样会被版本闸拒绝。
- 组态模式下左栏与日志收起属于"模式收敛"，不是结构变更，不额外升版本；
  退出组态后按原位置/原高度恢复。
