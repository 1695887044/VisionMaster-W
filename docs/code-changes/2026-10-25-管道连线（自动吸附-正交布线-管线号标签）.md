### 关键设计（为什么这么定）

- **模型只存连接关系，不存折点**：`FromId/FromPort/ToId/ToPort` 落进属性袋，折点每次现算。拖动设备不需要"重画管线"，也不会出现坐标漂移。
- **外框写回模型**：管道仍是"有位置的子元素"（选中框、命中、图层、序列化全部照旧），但外框是**布局结果**，所以走 `Detached`（不进撤销栈）。
- **订阅端点而不是等画布通知**：端点模型自己发 `PropertyChanged`，管线订阅它就能重排；画布不必为"哪些图元连着哪些管线"建反向索引。
- **标签是基类 `Text`**：不新开字段，直接吃到现有的绑定管线（`TextProperties.Text(..., isBindable: true)`）。

## 三、未做 / 边界（v1 明确）

| 项 | 说明 |
| --- | --- |
| 只支持**顶层图元**之间连线 | 底板里的子图元不参与（父子偏移会让绝对走线算错）；`TryConnect` 会明确拒绝并给原因 |
| 一个连接口只接一根 | 已占用的口在 `TryConnect` 里拒绝；画布手势也不会吸附到已占用的口 |
| 端点不可在属性面板改 | 只读展示 Id；要改就删掉重连（避免做一个"选图元 + 选口"的弹窗，v1 先不铺） |
| 没有折点手柄 | 走线全自动；要"手工掰一下"是下一版 |
| 管线交叉不断线 | 没有"跳桥/断开"画法 |
| 标签是固定 160 宽的居中盒 | 长标签会省略号；要更宽就调字号或换文字图元 |
| Web 渲染器 | 并入 Web 统一批次；`[WR]` 例外清单 11 → **12** |

## 五、踩过的坑

| 坑 | 现象 | 处置 |
| --- | --- | --- |
| 一横一竖的拐点写反 | 从"上出线"接到"左进线"时，先向上出直段又折回穿过自己（[PR2] 直接红） | 混合方向的拐点统一取 `(对端 X, 本端直段 Y)`，两个方向共用一条规则 |
| 断言里把"同轴"算错 | 两个矩形 Y 不同 → 端口本来就不在同一水平线，却断言"直连" | 测试数据改成同一 Y；断言失败先怀疑自己的数据 |
| 画布在断言里一个容器都不造 | `EnumerateControls()` 返回 0 | 画布自己也要套 `Style`（`PART_ElementLayer` 在模板里），只 `ApplyTemplate` 不够 |
| 只读 DP 用公开属性写 | `InvalidOperationException：属性已注册为只读` | 一律用 `XxxPropertyKey`（`ReportElement` 那批也踩过，见同日另一篇） |
| 控件写自己的外框 | 会被 `Refresh()` 用模型旧值覆盖 | 写回**模型**（`Detached`），不是写 `Canvas.Left` |
| 并发会话互相踩 | `ScadaChecks\obj\...dll` 被占用（别人在跑/在编）、gate 的 `raw-build-*.out` 被另一个 gate 覆盖 | 换 `-p:OutputPath` 编到临时目录跑断言；gate 等对方跑完再复跑 |
