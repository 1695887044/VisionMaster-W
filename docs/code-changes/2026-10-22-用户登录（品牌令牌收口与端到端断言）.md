## 3. 改动点

### 3.1 `Colors.xaml`：新增登录品牌令牌组

| 键 | 值 | 用途 |
| --- | --- | --- |
| `BrandSurfaceGradientBrush` | `#0B1F33 → #0C3B57 → #0B5F7A`（135°） | 左栏品牌底 |
| `BrandTextBrush` | `#EAF6FF` | 品牌区主文字 |
| `BrandMutedBrush` | `#B7D9EC` | 品牌区次要文字 |
| `BrandCardBrush` | `#14FFFFFF` | 品牌区卡片底（8% 白） |
| `BrandCardBorderBrush` | `#26FFFFFF` | 品牌区卡片描边（15% 白） |
| `BrandDividerBrush` | `#33FFFFFF` | 品牌区装饰圆环（20% 白） |

**为什么不复用 `Dialog*`**：品牌区是**深色语境**（深青渐变 + 半透明白卡），与弹窗浅色面语义相反。混用会让"改弹窗底色"顺手把品牌区也改浅——那是一次没人预期的连带修改。渐变只能是 `LinearGradientBrush`，所以键名带 `Gradient` 后缀。

### 3.2 `ScadaLoginView.xaml`：改令牌、零硬编码

- 删掉 6 个局部键（`LoginBrandGradient` / `LoginBrandTextBrush` / …），改为引用 `Brand*`；
- 就地合并 `Colors.xaml`（断言宿主没有应用级资源，不合并会在解析期抛"找不到资源"，R22）；
- 结果：`hex=0`，`Brand*` 引用 22 处。

### 3.3 `UIThemeSmokeTest`：新增 `RunLoginChecks()`（12 条）

分两段：**界面静态契约** + **后端真实回环**（用临时账号文件，不碰程序目录的 `ScadaUsers.json`）。

| # | 判据 |
