# A 类标注接入「结果显示」并合成 SCADA 最终图

## 1. 背景

SCADA 的 `Hmi.ImageView` 只显示 HImage 像素，没有覆盖层通道。颜色检查 / 颜色区域 / 几何查找 / 几何计算 / C# 脚本 / 图像脚本的标注此前只走 `PublishPreview` 覆盖层，SCADA 看不到。

本轮按「每个工位一张最终展示图」落地：

- A 类插件只输出**托管标注列表**（`List<MeasureAnnotation>`），不烘焙、不开窗、不增加 HALCON 调用；
- 「结果显示」已有烘焙件，新增消费该列表，把标注与文字/几何一起烧进 `AnnotatedImage`；
- 用户把 `AnnotatedImage` 接「图像赋值」→ 全局 HImage → SCADA，桌面/Web/CSV/导出/报警留存吃同一张图。

## 3. 性能口径

- A 类插件：只多一个 `List<MeasureAnnotation>`（每轮几十个对象），**没有新增烘焙/开窗/像素搬运**。
- 「结果显示」：本来每轮就无条件烘焙（`DisplayViewIndex=0` 也烘）；消费标注只多几条 `disp_line`/`disp_text`，相对全幅 dump 可忽略。
- `BakeWhenNotDisplayed=false` + `DisplayViewIndex=0`：连底图都不读，直接返回——这是本轮唯一能让现有方案**变快**的开关。
- 真正新增的成本在「图像赋值」的 `CopyImage`、变量保留两代图、以及 SCADA 打开时的 `ToBitmapSource`（5MP 彩色实测 14.08ms/次，一个变量只转一次）。不需要上画面的工位不要接变量。

## 5. 接线（用户侧）

1. 每个工位保留一个「结果显示」，`SrcImage` 接该工位原图；结果项接该工位的数值/文本。
2. A 类插件的 `Annotations` 接到「结果显示」任意一个空闲结果项。
3. `结果显示.DisplayViewIndex=0`，`BakeWhenNotDisplayed=true`。
4. `结果显示.AnnotatedImage → 图像赋值.InputImage`，变量按工位命名（`Img_ST1`…）。
5. SCADA 每页的 `Hmi.ImageView.Source` 绑自己的变量；图元放大到至少 640×480。

## 6. 已知边界

- `GeometryFinder` / `GeometryRelation` 的运行时 `Annotations` 断言在 `GeoDemoCheck` 里，演示方案 `解决方案\几何工具演示.vms` 缺失时整段跳过；本轮只做到编译通过 + 代码路径同构。
- `ImageScript.AnnotatedImage` / `CSharpScript.Marks` 本轮没有专门运行时断言（构建通过；端口为固定端口，动态输出同名会被跳过）。
- 未量化全幅 `DumpWindowImage` 的单轮耗时；5MP 真机 500 轮实测仍待做（R105）。
- 未改用户的 `.vms` 接线；上面的接线需要用户/下一轮在方案里落地。
