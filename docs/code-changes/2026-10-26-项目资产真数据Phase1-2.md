## 已做

1. **数据模型**
   - `Core/Models/Assets/ProjectAssetModels.cs`：`SolutionAssetBase`、`TemplateAsset`、`ModelAsset`、`ImageAsset`。
   - `SolutionModel` 新增 `TemplateAssets` / `ModelAssets` / `ImageAssets`，均为具体类型集合，不走多态基类。
   - `SolutionPaths` 新增 `Assets` 目录；`EnsureStructure`、另存为复制、`SolutionAssetFolders` 同步。
2. **只读目录**
   - `VisionMaster/Services/SolutionProjectAssetCatalog.cs`：投影五类资产、扫描流程引用、读取文件尺寸/哈希、派生内嵌配方和采集图像。
   - 标定显示 `LineCalib` 的 `PixelScale`、`1.0 mm/px`、源图 640×480、残差 0，并明确标“预置基线”。
   - 图像 14 条按 `Image\...` 相对路径解析；本地文件存在、尺寸、SHA-256 来自磁盘。
   - 配方 `BeadA` 从 `RecipeLibraryJson` 解析：参考图、无胶参考图、31 个参考点、目标宽度/极性。
3. **导入**
   - `VisionMaster/Services/ProjectAssetImporter.cs`：
     - 图像 → `<方案根>\Image\`
     - 模板 → `<方案根>\Assets\Templates\`
     - 模型 → `<方案根>\Assets\Models\`
     - 复制前算 SHA-256；同内容已存在则拒绝；同名不同内容自动加 `(2)`。
     - 图像读取宽高；所有资产写 `AssetId`、版本 1、创建/更新时间、操作者、相对路径、哈希、大小。
4. **UI**
   - `ProjectAssetsViewModel` 改为依赖 `IReadOnlyWorkspaceContext`，从目录加载真实数据。
   - 顶部按钮改为“导入资产 / 刷新列表”；删除“新建演示草稿”浮层和 mock 生成代码。
   - 空页签显示“当前页签暂无资产”，不再出现空白详情头/标定预览。
   - 健康度把“派生 / 内嵌”计入可用，图像/配方页不再显示 0%。
   - 列表徽标保持 22px 居中（沿用上一轮修复）。
5. **验证**
   - `ProjectAssetsUiProbe` 加载真实 `.vms`，断言五类数量、徽标布局，并在临时方案目录跑导入/重复/序列化/反序列化断言。
   - `ScadaChecks` 更新目录契约（StructureFolderNames 6 项、AssetFolderNames 5 项），3107 条通过。
   - `tools\run_gates.ps1` **14 步全绿**；`FlowCanvasChecks` 3708 条 0 失败。

## 踩过的坑

- `SolutionPaths.StructureFolderNames` / `SolutionAssetFolders.AssetFolderNames` 被 `ScadaChecks` 用精确条数钉住；新增 `Assets` 必须同步更新 `SolutionFolderChecks` 的 SF18/SF19 与 `SolutionUserChecks` 的 SL-a2/SL-a3。
- 空页签如果只隐藏列表，右侧详情会留下空白头/标定预览；必须用 `HasSelectedAsset` 同时控制详情卡和空态卡。
- 导入器不能用 `File.Replace` 做资产复制（受限环境会拒绝）；用临时文件 + `File.Move`，并在 finally 清理。
- 图像路径必须相对 `.vms` 所在目录解析；用仓库根会全部“找不到文件”。
- 资产 Id 不要为派生文件/内嵌配方现造 Guid；派生用 `file:` / `step:` 键，持久化资产才用 Guid。
