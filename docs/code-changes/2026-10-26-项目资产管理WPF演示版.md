## 踩过的坑

- **XAML Style 里不能设 `WindowStartupLocation`**：它是普通 CLR 属性不是 DP，`Setter.Property` 为 null，弹窗打开即 `XamlParseException`。已移除。
- **Prism 弹窗尺寸由内容决定**：只设 WindowStyle 的 Width/Height 不够，UserControl 不固定宽高时窗口会被内容撑大（实测 2834px 宽）；固定 `Width=1280 Height=850` 后恢复正常。
- **内容高度会撑破固定窗口**：详情 TabControl 内容过高时底部操作栏被裁；给 TabControl 加 `MaxHeight=500`，并用临时布局日志确认 `actionsBottom=835 < 850`。**最终修法**：把四个操作按钮移出详情卡片，放到根层右下角固定操作卡（`Grid.Row=1` + `VerticalAlignment=Bottom`，不参与页面/详情高度计算），卡片 `Height=68`、内层两行各 `28`、按钮 `Height=28 MinHeight=0 Padding="6,0" FontSize=12`、外层 `Margin="0,0,20,24"`。
- **文字被裁的根因不是行高不够，而是 Fluent 按钮的默认内边距**：`DialogPrimaryButton` / `DialogSecondaryButton` 继承 `FluentButtonStyle` 的 `MinHeight=32` 与 `Padding=12,6`；只把行高压到 26、把 `MinHeight` 清零，内容区仍只剩 `26-12=14px`，14px 字被上下切掉。必须同时覆盖 `Padding`（本处 `6,0`）并降到 12px 字。**判据**：渲染图里四个标签完整；按钮内容区高度 ≥ 字行高。临时渲染入口已删除，`--project-assets` 启动开关已删除。
- **Grid 单元格里的 Border 默认 Stretch**：类型/状态徽标只写了 `HorizontalAlignment=Left`，没有 `VerticalAlignment=Center`，于是被 62px 行高拉成整行高；徽标内 `TextBlock` 又默认贴顶，造成“背景框大、文字不居中”。修法是徽标 `Height=22` + `VerticalAlignment=Center`，且内层 `TextBlock` 也 `VerticalAlignment=Center`。**只改 Border 不改 TextBlock，文字仍会贴顶。**
- **探针字体不能用字符串构造 `FontFamily`**：`new FontFamily("pack://application:,,,/UI;component/...#Font Awesome 6 Pro Solid")` 会把整串当字体族名，`TryGetGlyphTypeface` 返回 false，渲染全是豆腐块。必须用 `new FontFamily(new Uri("pack://application:,,,/UI;component/Asserts/FontFamilys/"), "./#Font Awesome 6 Pro Solid")`。`UserManagementUiProbe` 里同样的字符串写法仍是豆腐块，未在本轮修。
- **模型 `ModelPath` 为空不能假装可用**：演示状态必须显示“未绑定”。
- **WPF 没有 Web 的媒体查询**：当前只做 1280 演示窗口，窄屏/WPF 自适应是下一批工作。
- **gate 既有红灯**：`ScadaChartSeriesEditor.xaml` 6 个颜色 `Tag` 字面量触发 R140 静态扫描；已把颜色候选移到 code-behind（`ChartColorOption`），XAML 只留绑定。根目录 `$null` 空文件也已删除。
