## 踩过的坑

- **`Style.Triggers` 不能夹在 Setter 中间**（XAML 编译报 MC3088「属性元素不能位于元素内容的中间」）：触发器要么在全部 Setter 之前、要么之后；本仓写法放最后。
- **斑马行用 `DataTrigger + (ItemsControl.AlternationIndex) + TemplatedParent` 在行模板里不生效**（渲染实测全白底）；改成 Style 级 `Trigger Property="ItemsControl.AlternationIndex"` + 容器 `Background` + 模板 `TemplateBinding` 后正常（像素核对 #F8FAFC）。
- 探针里 Prism **无参 `DelegateCommand` 只有 `CanExecute()`**（没有 `CanExecute(object)` 重载）；视图类在 `VisionMaster.Views.DialogViews` 命名空间，探针要额外 `using`。
- 并发构建窗口仍在（本轮被运行中的 `VisionMaster.exe` 锁宿主 bin、被另一会话抢 `Plugin.Matching` obj 各挡一次）；处理仍是"等它退再构建"（台账 A-01 / C-13）。
