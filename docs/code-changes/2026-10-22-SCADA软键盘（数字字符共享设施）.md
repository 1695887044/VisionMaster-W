# SCADA 软键盘（数字 / 字符共享设施）

> 日期：2026-10-22 ｜ 范围：P1 软键盘 ｜ 状态：桌面端已实现，键盘专项断言通过，待真机确认

## 1. 背景

触摸屏部署的硬门槛：数值域 / 文本域进入编辑时，不能依赖系统软键盘（现场常被禁用或遮挡输入框）。
本轮把软键盘做成运行窗口的**共享设施**，不是新图元：

- 数字布局：7 8 9 ⌫ / 4 5 6 清除 / 1 2 3 ± / 0 . Esc 确定；
- 字符布局：ASCII 字母 / 数字 / 常用符号，Shift 单次大写、空格、清除、退格；
- 提交仍走输入控件原有的 `CommitEdit()`（校验、类型转换、权限、写变量一条路径）；
- 取消走 `CancelEdit()`，不写变量。

## 3. 关键决策

### 3.1 键盘是共享设施，不是图元

- 不新增 TypeKey、不进 `.vms`、不进属性面板；
- 所有输入控件共用同一套键盘，避免"数值域一套、文本域一套"两套状态机；
- Web 不做九宫格键盘（浏览器已有软键盘），M2 沿用浏览器键盘与同一套校验文案。

### 3.2 打开/关闭只认 IsEditing

`TextFieldElement.BeginEdit()` / `IOFieldElement.BeginEdit()` 成功后 `IsEditing=true`，控件发冒泡事件；
窗口接住后弹键盘。`CommitEdit()` 成功、`CancelEdit()`、外部 LostFocus 提交、切页/关窗都会把
`IsEditing` 翻回 false，窗口据此收键盘。没有另写"点击判据"，与设计基线"与现有编辑入口同一处"一致。

### 3.3 按键不抢焦点

键盘根与所有按键 `Focusable=False`、`IsTabStop=False`：输入控件内部的 TextBox 一直持有焦点，
点键盘不会触发 LostFocus → CommitEdit。显示文本直接绑目标的 `EditText` DP，
物理键盘打字与软键盘点击走同一个 DP，不维护第二份输入状态。

### 3.4 提交失败不关键盘

`CommitEdit()` 失败时输入控件保持 `IsEditing=true` 并写 `EditError`；键盘 `确定` 后重新读取错误，
键盘保持打开、错误显示在键盘显示区。改一下就能重提，原值不被覆盖。

### 3.5 摆放规则

目标在缩放画布上时用 `TranslatePoint` 把**四个角**换算到窗口坐标再取包围盒（不拿模型 X/Y 或未缩放的
`ActualWidth` 直接算，否则 0.6 倍画布下会左右偏 `(1-Zoom)*width/2`、上下判错）；旋转元素也一并兜住。
默认放在字段下方；下方放不下翻到上方；左右按字段中心对齐并夹回画面区，至少留 8px。

键盘层放在**根 Grid、跨三行、ZIndex 40**：压在弹窗层（20）与报警历史抽屉之上，顶/底栏也在遮罩内——
点顶栏同样算"点键盘外"，先取消本次编辑，不会把半截输入提交掉。键盘本体用固定设计宽
（数字 344 / 字符 560）+ `Viewbox StretchDirection=DownOnly`，窗口再小等比缩小；长文本在显示区截断，
不会把键盘撑出画面区。提交失败后错误行出现/消失会改变高度，窗口在 `SizeChanged` 里重摆一次。

## 5. 边界与未做

1. **密码模式未做**：现有 `TextFieldElement` 没有 Password 属性；设计稿的 Password 状态属于后续增强。
2. **中文输入**：字符键盘只做 ASCII；中文走系统输入法（设计基线明确不承诺 Unicode 键盘）。
3. **点键盘外 = 取消**：窗口遮罩拦截外部点击并 `CancelEdit`；这与桌面 TextBox 的"点外部提交"不同，是按设计基线的触摸语义做的取舍。
4. **无真机截图**：键盘尺寸/按键观感、九宫格摆放需真机确认；断言只覆盖行为与接线。
5. **全量断言未全绿**：`FlowListView.xaml` 一条与本项无关的失败；其余 2455 条通过。
6. **Release 未构建**：打包前需 Debug/Release 都重建（R55 同族）。
