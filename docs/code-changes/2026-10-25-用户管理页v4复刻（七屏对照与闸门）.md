## 五、踩过的坑

1. **TabControl 放进固定 44px 行 → 内容区高度 0**：页签栏是 44，但 `DialogTabControl` 模板的 `PART_SelectedContentHost` 在同一控件的第二行；把整个 TabControl 塞进 44px 行，内容自然全是空白（截图里只剩页签和底栏）。页签高度应由 TabItem 的 MinHeight 决定，TabControl 自己占 `*`。
2. **`DialogQuietButton` 的 `Padding=12,0` + `Width=32` 把关闭图标切成一条斜线**（R68 的原样复现）：固定尺寸图标按钮必须显式 `Padding="0"`，否则内容区只剩 6px。
3. **`DialogCombo` 的 `SelectionBoxItem` 在部分路径下退化成对象 ToString**：截图里下拉显示 `ScadaGroupOption { GroupId = …, Name = … }`。给 `ScadaGroupOption.ToString()` 返回显示名兜底；根因（`SelectionBoxItemTemplate` 未生效）未深挖，属 UI 库待查项。
4. **两个 ListBox 共用一个 `SelectedGroup`，`TwoWay` 会互相清空**：另一侧列表把 `SelectedItem` 置 null 时写回 VM，刚选中的组立刻被抹掉。改 `Mode=OneWay` + `SelectionChanged` 写 VM，另一侧只清显示。
5. **新目录里的 store 重读后仍是 `BookSource=Factory`**：文件不存在时 Load 会种出厂 admin 并把来源记成 Factory，页头挂「当前使用出厂账号」横幅。落盘后必须再 `Load()` 一次，来源才翻到 Solution。
6. **32/32 差一条**：内置 15 + 手工加 16 = 31。先补设计稿里的自定义示例（`RecipePublish` → 显示名「配方下发」），再加 16 才到 32。
7. **满额态行内表单没收起**：屏幕上同时出现「32/32 已满」和「创建」表单。满额截图前先 `CancelCreateCommand`。
8. **权限目录底栏说明被切**：16 行 × 27 + 28 表头正好吃满，说明区只剩 50px 放两行 11 号字。行高降到 26、说明区 `MinHeight=62` 后正常。
9. **XML 注释里不能出现 `--`**：`<!--  ---------- 账号 ----------  -->` 直接 MC3000。分节注释改成 `<!--  账号  -->`。
10. **构建输出在 cmd 里是 936 乱码**（R183 同源）：`dotnet build` 的中文提示按控制台代码页输出，直接读是乱码；把输出重定向到文件后用 rg 抓 `error [A-Z]+[0-9]+`，别用 findstr 匹配中文。
