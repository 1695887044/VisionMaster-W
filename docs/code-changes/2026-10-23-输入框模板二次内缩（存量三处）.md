# 输入框模板二次内缩：存量三处一起修（NumericBox / PasswordBox / 插件结果框）

> 日期：2026-10-23 ｜ 范围：`UI/Controls/Themes/NumericBox.xaml`、`UI/Controls/Themes/Controls/Input.xaml`（PasswordBox）、`Plugins/Plugin.ImageAcquisition/ImageAcquisitionView.xaml` ｜ 状态：三处已修，探针 Debug+Release 实测 + 全量 gate 复绿

## 1. 背景

上一轮修了运动板卡的 `MbTextBox`（见 `2026-10-23-运动板卡设备标识文字被切（TextBox模板二次内缩）.md`），同时用静态扫描点出另外三处"`PART_ContentHost` 再吃一层 `Padding` 换算的 `Margin`"。本篇是这三处的收口。

判据同前：**控件的 `Padding` 由控件自己内缩一次**；模板再套一层就等于内缩两遍，固定高度的小框会被压扁（`viewportH < extentH`，文字上下被切）。

## 2. 三处改动

| 位置 | 原写法 | 改法 |
|---|---|---|
| `UI/Controls/Themes/NumericBox.xaml` | 内容宿主 `Margin="{TemplateBinding Padding}"` | 去掉 Margin（内缩交给控件）；单位后缀左移 6px 补回间隔（`0,0,10,0` → `6,0,10,0`） |
| `UI/Controls/Themes/Controls/Input.xaml`（PasswordBox） | 外层 `Grid Margin="{TemplateBinding Padding}"` 包着密码宿主 + 明文宿主 + 眼睛按钮 | 外层 Grid 不再吃 Padding；密码宿主交给控件内缩；`PlainTextHost`（`Padding=0`，不会二次）自己吃 `Margin="{TemplateBinding Padding}"`；眼睛按钮补 `0,0,10,0` |
| `Plugins/Plugin.ImageAcquisition/ImageAcquisitionView.xaml` | `ResultTextBoxStyle` 的内容宿主 `Margin="{TemplateBinding Padding}"` | 去掉 Margin（多行只读结果框，`Padding=8` 交给控件） |

## 3. 实测（临时探针：套真样式/真视图资源，量 `PART_ContentHost`）

|---|---|---|

## 4. 顺带查清的一件事：UI 那份 PasswordBox 模板在运行期被 Fluent 盖住

`VisionMaster/App.xaml` 的合并顺序是 `Core.Halcon → UI → Fluent`，隐式样式按**后合并者优先**解析。探针实测（读 `Application.Current.Resources[typeof(PasswordBox)]`）：

- 运行期拿到的样式：`Padding=10,5,10,6`（.NET 9 Fluent 的值）；
- 把 Fluent 临时摘掉再取：`Padding=10,8,10,8`（`UI/Controls/Themes/Controls/Input.xaml` 里那份）。

也就是说：**登录框现在用的是 Fluent 原生密码框，"显示密码"眼睛按钮与 `PlainTextHost` 那条明码通道实际不生效**（`PasswordBoxHelper` 本身只挂 `PasswordChanged`，双向绑定仍然工作，所以冒烟里的两条绑定断言是绿的，看不出这个差异）。

这次只把那份模板的二次内缩修对了（它一旦被启用就是对的），**没有改合并顺序**——那会把登录框外观整体换回自绘皮肤，属设计变更，需要单独一批 + 截图验收（R125/R132）。

## 6. 踩坑

1. **`VisionMaster.exe` 在跑时 Debug 输出与 `Modules\` 全被锁**（`MSB3027/MSB3021`）。不要杀用户进程；先用 Release 通道验证（探针加 `-c Release`），等进程退出后再补 Debug + `Modules\` 投递。
2. 插件工程的投递目标可以临时改向：`dotnet build ... -p:ModulesDir=<临时目录>`（`Plugins\Directory.Build.targets` 里 `ModulesDir` 只在为空时才取默认值）。
3. 同仓可能有**另一个会话在跑断言宿主**（本机实测 `FlowCanvasChecks` 被 DSH 的 bash 拉起），它会锁 `obj\`；这时按工程定向重建，别跑全量 sln。
4. `Border` 是 `Decorator`，没有 `FontFamily`；探针里要复刻字体继承得用 `TextElement.SetFontFamily`。
