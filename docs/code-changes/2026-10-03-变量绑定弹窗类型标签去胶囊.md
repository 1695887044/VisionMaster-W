# 2026-10-03 变量绑定弹窗：类型显示去胶囊（含断言假绿修复）

- 日期：2026-10-03
- 范围：`VisionMaster\Views\DialogViews\VariableBindingView.xaml`、`FlowCanvasChecks\VariableBindingCheck.cs`
- 触发：现场反馈"候选端口行的数据类型显示不对，不应该是椭圆"

---

## 缺陷 1：长类型名被塞进"胶囊"→ 渲染成横椭圆

### 现象与根因

右栏「绑定上游输出端口」的候选行里，类型文本（如「图像 (HImage)」）被套在 `DialogChip` 样式里。
`DialogChip` 的定位是**短角标**（"枚举" / "变量" / "已绑定"），而它在应用里**实际生效的是 Fluent 转发层**：
`FluentAliases.xaml`（最后合并、同名覆盖 Dialog 分册）把它重定义为 `BasedOn FluentChipStyle`，
其 `CornerRadius = FluentRadiusFull = 999` —— 即**全圆角胶囊**：

- 短文本（2 个字）→ 正常胶囊；
- **长文本（"图像 (HImage)"）→ 两端各成一个半圆，整块变成一颗横椭圆**（截图所见）。

### 修法：新增"标签"样式族（两层都定义）

| 位置 | 内容 |
| --- | --- |
| `UI\Controls\Themes\Dialog\Dialog.Chip.xaml` | 新增 `DialogTag` / `DialogTagText`：**小方圆角 4** + 1px 描边 + 浅底（底色与行悬停色不同，悬停/选中都不隐身） |
| `UI\Controls\Themes\Fluent\FluentAliases.xaml` | 同步转发：`BasedOn FluentChipStyle`，**显式覆盖 `CornerRadius = FluentRadiusSmall(4)`** + `FluentBorderBrush` 描边（不覆盖就会沿用 RadiusFull 又变回椭圆） |
| `VisionMaster\Views\DialogViews\VariableBindingView.xaml` | 类型名改用 `DialogTag`（完整类型名仍在 ToolTip） |

口径：`Chip = 胶囊（短角标）`，`Tag = 带底色的小方圆角（长文本，如数据类型）`。

## 缺陷 2（顺带发现）：样式收编契约整段"假绿"

`VariableBindingCheck.RunViewStyleContract` 仍在解析 `UI\Controls\Themes\DialogStyles.xaml`，
但该文件早已按领域拆成 `UI\Controls\Themes\Dialog\Dialog.*.xaml`（8 册）→ 解析失败 →
**整段静默跳过并计为通过**，连同它后面的 4 组子契约（窗口样式 / 资源键 / 弹窗窗框 / 已收编视图纪律）一起没跑。
椭圆能被放进来、没人拦，与这段契约空转直接相关。

修法：
1. 样式文本扫描**整个 Themes 目录**（含 `Dialog/` 分册）——不再绑定单一文件名；
2. **"在仓库内运行却定位不到文件"由跳过改为失败**（断言过期必须报出来），只有"根本不在仓库内运行"才允许跳过；
3. 合并链判据从"DialogStyles.xaml 在链上"改为"**每个 `Dialog.*.xaml` 分册都必须被 Generic.xaml 引用**"（漏挂一册 = 弹窗找不到资源）。

## 新增回归断言（`VariableBindingCheck`）

| 断言 | 锁定的性质 |
| --- | --- |
| 【绑定】类型名不进胶囊（DialogChip 只用于短角标，长文本会撑成横椭圆） | 候选行里 `DialogChip` 块内不得出现 `DataTypeName` 绑定 |
| 【绑定】类型名用 DialogTag（带底色的小方圆角标签） | 类型绑定必须包在 `DialogTag` 里 |
| 【形状】DialogTag 是小方圆角（≤6；两层都必须显式给，不得继承成胶囊） | 默认层与 Fluent 转发层都要显式给 `CornerRadius` 且 ≤6（或 `FluentRadiusSmall`）；缺失即判违规（继承 FluentChipStyle 的 RadiusFull=999 就是椭圆） |
| `RequiredDialogStyleKeys` += `DialogTag` / `DialogTagText` | 新键必须落在 UI 库（视图不许本地造） |
