# 工具箱胶囊与库自动隐藏页签重叠修复 — 2026-10-27

## 一、当前状态

- 用户真机截图发现：工具箱收起后，右边缘出现**两条竖排“工具箱”**，左边一条被右边的自定义胶囊遮住一半。
- 根因已定位并修复：AvalonDock 图钉自动隐藏会生成自己的 `LayoutAnchorControl`（33px 竖排页签），我们的 VS 式胶囊轨道是叠在 `DockingManager` 上的 18px 覆盖层；两者同时显示，形成重影。
- 修复后真机：右边缘只剩自定义胶囊；点胶囊工具箱正常钉回 300 列；流程导航等**没有自定义胶囊**的面板仍保留库页签。
- 验证：`VisionMaster` 构建 0 错误；`UIThemeSmokeTest` **143 通过 / 0 失败**（新增 2 条运行时断言 + 变异反证）；真机 UIA 枚举确认修复前后元素数量变化。

## 二、已做

### 2.1 `VisionMaster/Services/LayoutHelper.cs`

新增 `SyncAutoHideTabs(DockingManager?, IEnumerable<string>? capsuleIds)`：

- 从 `DockingManager` 可视树里找 `AvalonDock.Controls.LayoutAnchorControl`；
- `tab.Model is LayoutAnchorable` 且 `ContentId` 在 `capsuleIds` 里 → `Visibility = Collapsed`；
- 不在集合里的面板 → `Visibility = Visible`（保留流程导航等库页签）；
- 只改可视层 `UIElement.Visibility`，**不动** `IsAutoHidden` / `CanAutoHide` / 布局模型，`ToggleAutoHide()` 的收回路径不受影响。

新增私有 `FindVisualDescendants<T>`（先根序，供上面使用）。

### 2.2 `VisionMaster/ShellViewModel.cs`

`UpdateInspectorCapsules()` 末尾调用 `SyncAutoHideTabsWithCapsules()`：

- 立即同步一次；
- 再在 `DispatcherPriority.Loaded` 与 `ApplicationIdle` 各补一次（可视树在布局更新后才生成，立即同步时可能还没有 `LayoutAnchorControl`）；
- 传入的集合就是当前 `InspectorCapsules` 的 `ContentId` 列表。

### 2.3 `UIThemeSmokeTest/Program.cs`

2. **反证**：传空集合再同步，断言同一个 `LayoutAnchorControl` 回到 `Visible`（证明不是把页签永久删掉/藏死）。

## 五、踩过的坑

- **UIA 是定位重影的最快手段**：同一区域枚举出 `LayoutAnchorControl`（33px）和 `InspectorCapsuleItem`（15px）两个元素，直接证明是两套 UI 并存；只看截图容易误判成“文字被裁”。
- **`LayoutAnchorControl` 不是 `LayoutAnchorableTabItem`**：自动隐藏页签是前者，后者是文档标签；一开始在冒烟宿主里找错类型，一条诊断都打不出来。
- **无窗口的断言宿主不会生成 `LayoutAnchorControl`**：`ShellCopy` 只 `Measure/Arrange` 时可视树里没有自动隐藏页签；必须 `window.Show()`（屏幕外 `-4000`）+ `Dispatcher.ApplicationIdle`，与 R53 同口径。
- **不要用 `IsVisible=false` 或 `CanAutoHide=false` 消重影**：前者会把自动隐藏模型改成 Hidden 区，后者直接禁用图钉；两者都会破坏 `ToggleAutoHide()` 的收回路径。只改 `Visibility` 是最小侵入。
- **不要隐藏整个 `LayoutAnchorSide`**：会把没有自定义胶囊的面板（流程导航等）的恢复入口一起藏掉；按 `ContentId` 精确匹配。
- **立即同步往往太早**：`UpdateInspectorCapsules()` 跑在属性变更回调里，此时 `LayoutAnchorControl` 还没生成；`Loaded` + `ApplicationIdle` 两次补同步才稳。
- **冒烟宿主里 `window.Show()` 要放最后**：本轮把新检查放在所有既有检查之后，避免显示窗口改变前面测试的布局状态；`finally` 里 `ShowPanel` 恢复工具箱并 `Hide()` 窗口。
- **变异反证必须做**：注释掉同步调用后第一条断言立即红（`可见性=Visible`），还原后 143/0；证明这条闸不是“永远绿”。
