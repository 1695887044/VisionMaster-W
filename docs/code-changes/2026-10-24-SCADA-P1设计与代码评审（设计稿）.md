## 五、踩过的坑

- **IAB 浏览器不可用**：`browser.tabs.new()` / `agent.browsers.open()` 都报 `browser guest not attached (webview not ready)`；改用本机 Edge 无头 + CDP 做渲染与交互验证。探针脚本放 `tools/oneoff/`，用完已删。
- **Edge 无头进程残留**：`edge.kill()` 只杀父进程，子进程仍锁 `user-data-dir`，第二次跑探针报 `EBUSY: Affiliation Database`；按命令行含 `edge-p1` 批量 `Stop-Process` 后恢复。
- **报警时间线重复**：`alarmAdd` 与 `alarmFire` 各加一条，导致“报警取消/确认”出现两次；改成 `alarmFire` 只负责高亮事件卡，时间线只由按钮处理函数加一次。
- **整页截图过长**：1440 宽全页截图缩到 600px 高后文字不可读；改为按 section 裁剪 `03~06`，另出浅色首屏 `07`。
- **设计稿不是交付物**：按 R126 不进入构建、不部署；只作为设计媒介与验收对照。
