### 2.1 `tools/LineSim/`（独立进程，零 ProjectReference）

- `LineSim.csproj`：`net9.0-windows` + `UseWPF`（3D 视图在 P4 用，先占位），**不引用任何上位机程序集**（设计约束 C1）。
- `Program.cs`：子命令 `--serve` / `--headless --ticks N` / `--selftest` / `--check-ports` / `--version`，参数 `--seed` / `--speed` / `--motion-port` / `--trace`。
- `Kernel/WallClock.cs`：全进程**唯一**墙钟出口（S2 的静态前提）。
- `Kernel/SimClock.cs`：`TickMs = 1`，仿真时钟唯一来源。
- `Kernel/DeterministicRandom.cs`：xorshift128+ + SplitMix64 展开 + Box-Muller，不用 `System.Random`（跨运行可复现）。
- `Kernel/TickLoop.cs`：`RunHeadless` 能跑多快跑多快；`RunRealtime` 按墙钟配速，**落后 >200ms 丢 tick 不补跑**（`SkippedTicks` 记账，避免"补跑风暴"）。
- `World/Axis.cs`：梯形速度曲线 + 八种回零 + 机械端点夹持 + 点动 + 减速停/立即停。
- `World/World.cs`：P0 世界 = 2 工位 / 3 轴（`ST1.X` `-50..600`、`ST1.Z` `-40..0`、`ST2.Y` `0..900`）/ 8 进 8 出；**IO 由轴位置真推导**；`Digest()` 出 SHA256 世界摘要（S20 用）。
- `Net/MotionServer.cs`：端口 19510，TCP JSON-lines，`hello` 握手 + `enqueue/poll/estop/reset.estop/io.write/io.read/cancel`。
- `SelfTest.cs`：27 条断言（确定性、曲线、回零、限位、协议门禁）。

### 5.1 ScadaChecks 是**既有不稳定**，不是本轮引入（有反证）

同一份 `ScadaChecks.exe`、同一份 `Modules\`，连跑四次得到三种结果：

| 次 | 条件 | 结果 |
|---|---|---|
| A | gate 内（插件 DLL 在） | **崩溃**，末行 `Process terminated.` |

## 6. 踩过的坑（都会再踩，写下来）

1. **`UseWPF=true` 的工程隐式 using 集合里没有 `System.IO`** → `StreamReader` / `StreamWriter` / `IOException` 全报 CS0246。三个文件各补一行 `using System.IO;` 才过。
2. **世界开机不能停在限位上**。`ST1.Z` 行程 `-40..0`、`ST2.Y` 行程 `0..900`，都停 0 时限位位立刻为真，上位机 `MotionDeviceBase.DetectCriticalSignals` 会把任一轴的限位位升级成**设备级 Alarm**（真实卡同语义）→ 一连上就不可用。修法：`World` 构造里 `ParkAt(-20)` / `ParkAt(400)`。
3. **速度/加速度 `<=0` 不是"用 0.001 爬"，是"用卡级默认"**。原先统一 `Math.Clamp(x, 0.001, max)`，结果 `acc=0` 的命令让轴以 0.001mm/s² 加速，5 秒只走 0.019mm，现象酷似"下发了没动"。修法：`ResolveSpeed` / `ResolveAccel`，`<=0` 取轴级默认（100mm/s、1000mm/s²）。**这条与契约注释"<=0 用卡级默认值"一致**。
4. **重定向输出按 936 编码**：`LineSim.exe` 的 stdout 被管道接走时按 GBK 写出，采集端按 UTF-8 解码 = 乱码。`Main` 首行 `Console.OutputEncoding = new UTF8Encoding(false)`（R183 同族）。
5. **构建失败时旧 exe 还在**，`--selftest` 会照常打印上一次的结果 → 先看构建输出再跑（R65 同族）。
6. **探针不要吃任意 argv**：`run-probe.ps1` 会传 `--nologo` 之类的参数，把 `args[0]` 当路径用会报"找不到 LineSim.exe：--nologo"。改成只认 `--linesim <path>`。
