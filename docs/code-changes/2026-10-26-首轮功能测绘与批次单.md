## 5. 踩过的坑

| 现象 | 原因 | 规避 |
|---|---|---|
| 计划断言 `"保存成功"` 与源码 `"已保存到"` 不符 | 计划库是 2026-10-23 的快照，不是事实源 | 执行前按当前源码核 toast 文案；计划过期就升版本 |
| 阶段 4 把未落盘方案喂给「要求已落盘」的计划 | 前置条件只写在计划文件里，没有写进批次单的执行项 | 批次单每条执行项必须写前置；前置不满足记 SKIPPED/BLOCKED |
| 状态口径混用（FAIL / UNVERIFIED / SKIPPED） | 没区分"没跑""跑了没证据""跑了判据不成立" | 按契约 §5 六状态；没跑记 `NOT RUN` |
| 探针数量写 15，磁盘实际 16 | 交底数字过期 | 以 `tools/probes/probes.json` 逐条计数为准 |
| `findstr` 搜 UTF-8 中文计划断言无命中 | 控制台代码页 936（C-05） | 用 Read 工具或 `[IO.File]::ReadAllText(..., UTF8)` |
