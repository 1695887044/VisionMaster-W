## 五、ViewModel 侧新增能力（+913 / −185 行）

按职责分七组，每组都能回到 §6 的断言：

1. **投影层**：`PrimaryValueText`（阈值/断线秒数/`—` 三合一）、阈值单位槽、规则句、断线说明句、「待完成」提示——**文案一律由 VM 出，XAML 不写死**（D5）。
2. **就地编辑与校验**：数值走「解析一次、宽进严出」（非数字回灌原值 + 行内中文原因，模型一个数不动）；负数由领域层夹到 0；名称查重失败抛一次变更通知（否则输入框里留着被拒的新名）；清空落 `null` 不落空串。
3. **筛选**：搜索与组筛选是两个维度，叠加后 `显示 X / Y`；组候选 = 全部 + 本方案用过的组名（去重排序，与报警组历史值同源）；`ClearFilterCommand` 一键清两个维度。
4. **新增瞬态（P5）**：`OnAdd` 先清筛选（新行不能被旧筛选藏起来）→ 追加 → 选中 → `RowAdded` 事件通知视图滚动聚焦；「待完成」提示是**新增瞬态**，不跟着行漂（新增第二条后第一条的提示收起）。
5. **撤销作用域**：一次字段编辑 = 一条记录；等值写入不产记录；`Bind` 的多次属性写（Id + 名字 + 下标）包成一条，撤销/重做整体回退。
6. **回执**：删除后底栏给可撤销回执，6 秒倒计时；回执期间**隐藏全局撤销按钮**（不出现两个撤销入口），倒计时走完回执消失而撤销仍在。
7. **审计**：新建 / 修改 / 改名 / 选择变量 / 删除各落一条，署名来自注入的提供者，取不到回落「未登录」；**填了非数字不落审计**（没写进模型的事不该冒充「改过」）；失败也落一条。
