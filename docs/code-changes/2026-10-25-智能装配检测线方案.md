## 五、踩过的坑

- **插件属性名 ≠ 端口名**：`ImageAcquisition.OutputImage` 的端口叫 `Image`、`Delay.DelayTimePort` 的端口叫 `Delay`、`ResultUpload.TriggerPort` 的端口叫 `上报触发`、`ExcelExport.ReportPath` 的端口叫 `报表路径`。生成器必须先反射真实端口名，不能按属性名连线。
- **Calibration 像素当量必须给 A/B 两点**：只给 `SourceImage` 会报“A/B 两点尚未取全”。`ScaleARow/ScaleACol/ScaleBRow/ScaleBCol + KnownLengthMm` 必须同时写。
- **虚拟运动卡只有 3 轴**：方案里写 R 轴（第 4 轴）会在运行期报“轴号 3 超出范围”；本方案改为 X/Y/Z 三轴。
- **MotionWait 的 Target 不填默认 0**：`Move Z 5` 后如果 Wait 不写 Target=5，会在 Z=0 时提前返回，下一步 Move 报“正在运动中不能下发新命令”。
- **VariableAssignment 写 Int32 失败**：`JValue(850)` 在运行期被当成 `Int64`，写 `CycleTimeMs(Int32)` 报类型错误；改为把默认值写进变量快照，不再运行时赋常量。
- **DataRecord 的 `{StepName}` 带流程前缀**：实际落盘目录是 `History\Main.产线主记录\...`，Excel 的 `SourceStepName` 必须写 `Main.产线主记录`，否则报表找不到源账本。
- **ColorCheck 对图片/ROI 敏感**：`color_pieces_01.png` 找不到线束；换回样图库 `合成颜色_8bit.png` 并用原 ROI 才稳定通过。Blob 的 `MaxSingleArea/MaxTotalArea/MaxDefectCount` 必须按样图实际尺寸放宽，否则 `IsOk=false`。
- **UI 自动化点击会被前台窗口截走**：ZCode 主窗口在前台时鼠标坐标点击落在 ZCode 上；`vm-uia.ps1` 已补 `SetForegroundWindow`，并且必须先关闭启动时的“上次运行的现场”草稿弹窗。
