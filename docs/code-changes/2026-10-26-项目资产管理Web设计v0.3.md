## 踩过的坑

- **不能只在 README 写“WPF 边界”**：v0.2 深色稿仍把 rail/顶栏/底栏画进页面，用户一眼就看出和桌面端不搭；主题与壳层必须直接体现在设计稿。
- **现有桌面端不是深色**：SCADA 运行画面是深色，Shell 与工程页是浅色 Fluent；两者不能混用一套 token。
- **浅色不是简单反色**：状态色、选中行、hover、边框、阴影都要按浅底重配；直接反转会得到灰脏的卡片。
- **删除壳层后要重新量高度**：没有顶栏/底栏后 `main` 高度变化，详情面板需要重新确认预览、元数据、引用、版本历史与固定操作栏不溢出。
