# 语音播报（TTS）第一步：报警播报落地

日期：2026-10-25
范围：用户要求"语音播报（TTS 念出'一号罐液位高'）"的**第一步**——报警播报 + 队列骨架。
按约定顺序：① 报警播报 → ② `SpeakText` 动作 + 变量插值 → ③ 设置界面与启动自检。本次只做 ①。

## 一、当前状态

- 新增依赖 `System.Speech 9.0.0`（Windows 自带 SAPI，离线可用）。
- **报警会念出来**：报警产生时播一句「警告，一号罐液位高」（严重度 + 名称 + 消息）。
- 播报走**串行队列**：同一条报警 30 秒内只念一次、队列上限 3 条、更严重的报警抢占当前播报。
- **与提示音互斥**：说话期间压住报警提示音（`ScadaSoundAlarmService.Suspended`），播完恢复。
- `ScadaChecks` **3030 通过 / 0 失败**（新增 [AN1]~[AN6]）。

### 三条设计口径

- **只播"报警产生"**：不跟 `AlarmChanged`（否则恢复/确认也会念）。去重键 = `AlarmId@激活时刻`。
- **默认门槛 Warning**：Info 不念（现场提示音已经够了，念出来只是噪音）。
- **播报在后台线程串行**：`SpeechSynthesizer` 不是线程安全的；调用方可以在任何线程 `Announce`。
