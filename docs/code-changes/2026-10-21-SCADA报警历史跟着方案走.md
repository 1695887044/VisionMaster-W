# SCADA 报警历史跟着方案走（2026-10-21）

> 需求：报警信息要跟方案走，不能这次加载就看不到上次加载的报警；与图片一样放到解决方案根目录，每个方案维护自己的文件。

## 1. 问题

- 报警**定义**本来就跟着 `.vms` 走（`ScadaDocument.Alarms`）。
- 报警**历史**没有：
  - CSV 落在软件目录 `<exe>\Alarms`，所有方案共用一份；
  - 历史面板只读本轮 `ScadaAlarmEngine` 的内存流水（`RecentRecords`），关掉运行窗口再打开就空了；
  - CSV 只订阅 `AlarmRaised`，确认/恢复/清除的状态迁移不落盘，历史文件永远停在“激活”那一行。

## 2. 目录约定

以 `D:\Lines\Line1\Line1.vms` 为例：

```text
Line1\
  Line1.vms
  Image\                  ← 方案图片（与既有图片约定一致）
  Alarms\
    AlarmHistory.json     ← 历史面板恢复快照（本批新增）
    AlarmHistory-*.csv    ← 可读的报警流水（既有格式）
```

- 方案根目录 = `Path.GetDirectoryName(SolutionFilePath)`。
- 未保存的方案（`SolutionFilePath` 为空）回落到软件目录 `<exe>\Alarms`，至少不丢数据。
- “另存为”到新目录时，`Image\` 与 `Alarms\` 一起复制过去；目标已有同名文件时不覆盖，失败只提示、不回滚 `.vms` 保存。

## 3. 数据流

```text
ScadaDocument.Alarms（.vms 配置）
        │
        ▼
ScadaAlarmEngine（本轮运行，200ms 节拍判条件）
        │  AlarmRaised / AlarmChanged
        ▼
ScadaRuntimeHost.OnAlarmChanged
        ├─ ScadaAlarmHistoryWriter.Append → Alarms\AlarmHistory-日期.csv（每次状态迁移一行）
        └─ ScadaAlarmHistoryStore.Save     → Alarms\AlarmHistory.json（当前记录整体快照）
        │
        ▼
ScadaRuntimeContext.PriorAlarms（下次启动时从 JSON 读回）
        │
        ▼
ScadaAlarmHistoryViewModel：PriorAlarms + 本轮 RecentRecords 合并显示
```

## 5. 关键决策

| # | 决策 | 理由 |
| --- | --- | --- |
| 1 | CSV 与 JSON 分工 | CSV 是给人/Excel 看的事件流水；JSON 是给面板恢复的“当前记录快照”。面板要的是每条报警的最终态，自己从迁移行重新拼既易错又解释不了旧格式缺列 |
| 2 | 订阅 `AlarmChanged` 而不是只订阅 `AlarmRaised` | 激活时引擎同时抛两者；只订阅 `AlarmRaised` 会让确认/恢复/清除时间线永远不落盘 |
| 3 | 写 JSON 时必须 `Merge(prior, current)` | 只写本轮 `RecentRecords` 会在第一次报警时把上次加载的历史整批覆盖，正是用户反馈的“这次加载又看不到上次的报警” |
| 4 | 历史行 `CanAcknowledge=false` | 上一轮引擎已销毁，按 `AlarmId` 找不回去；给按钮只会点了没反应 |
| 5 | 未保存方案回落软件目录 | 新建方案还没保存时没有“方案目录”；先落软件目录保证不丢，保存后下次运行走方案目录 |
| 6 | 另存为复制资产 | 用户复制的是“这个方案”，不是只复制一个 `.vms`；图片与报警历史都应跟着走 |

## 6. 已知边界

- **方案根目录 = `.vms` 文件所在目录**：同一目录里放多个 `.vms` 会共用同一个 `Alarms` / `Image` 文件夹；约定是每个方案一个文件夹。只复制 `.vms` 文件不会带走 `Alarms` 历史，复制方案时请整个文件夹一起复制（或使用“另存为”，它会把 `Image` / `Alarms` 一起带过去）。
- **旧全局历史不自动迁移**：以前落在 `<exe>\Alarms` 的 CSV/JSON 无法判断属于哪份方案，保留原地；需要归档时手工复制到对应方案目录。
- **历史快照上限 2000 条**：与引擎内存上限、历史面板 `MaxRows` 对齐；更久远的查询看按天 CSV。
- **未保存方案**的历史暂存软件目录；保存后不会自动搬过去（可手工复制，或另存为时由 `SolutionAssetFolders` 复制旧目录资产）。
- **另存为复制资产不覆盖同名文件**：目标目录已有同名文件时跳过并提示，避免静默盖掉另一份方案的资产。
- 报警历史 JSON 每次状态迁移整体重写；报警极密集时会有 IO 开销，当前报警频率下可接受，后续可做防抖。
