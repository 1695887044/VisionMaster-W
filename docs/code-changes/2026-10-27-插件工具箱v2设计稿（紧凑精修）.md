## 二、已做

### 2.1 设计目标

用户口径“更精致、小巧一点”。三项目标：

1. 更紧凑：列表行 34→30、分组头 30→28、搜索 32→28、收藏提示 30→22。
2. 更精致：图标进 18/20px 浅色徽章、数量胶囊降一级、收藏星暖金色。
3. 不挡内容：滚动区右侧 10px gutter（Fluent 覆盖式滚动条），长名称统一省略号。

## 五、踩过的坑

- **整页 `fullPage` 截图会重复**：设计板高 2777、viewport 1200 时，IAB fullPage 截出来的图把页面上半段重复了一次。改为 `?view=top` / `?view=specs` 两个视图，各自高度 ~1450，viewport 截图干净。
- **8765 端口被别的会话占用**：`python -m http.server 8765 --directory D:\C#\VM` 启动后根目录是别人的 viz 目录；换 8766 并先用 `curl -o nul -w "%{http_code}"` 验证 `AGENTS.md`/设计稿都 200。
- **FA 字体路径**：设计稿用仓库内 `UI/Controls/Asserts/FontFamilys/Font Awesome 6 Pro-Solid-900.otf`，必须走 HTTP 服务（file:// 会被字体 CORS 拦）；`@font-face` 路径相对设计稿目录三层回仓库根。
- **设计基线约定**：`design.html` 不参与构建/部署；「现状」重建示意不能当验收证据，真机截图必须在 WPF 复刻后补。
- **胶囊再缩的下限**：从 20→18→16 是可行区间；14px 时 7.5px 竖排标题在 100% DPI 下难读，且点击热区太小。16px 需配 6px 右移（窗口 resize border 会吃掉右侧约 8px）。
