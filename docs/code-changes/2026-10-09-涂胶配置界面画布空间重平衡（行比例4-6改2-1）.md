# 2026-10-09 涂胶（BeadInspect）配置界面画布空间重平衡（行比例 4:6 → 2:1）

## 一、起因

用户真机反馈：「涂胶插件画面布局还是有问题，**图片的空间太小了**」。这是 2026-10-07 布局修复（右列改为 `Auto / 4* / 6* / Auto` 行模型）的遗留失衡。

## 二、根因

右列主 Grid（`BeadInspectView.xaml:425-436`）画布 `4*`、参数卡 `6*`——**参数卡拿的比画布还多**，加上参数卡上限 `PluginParamsCardMaxHeight=320` 在常规窗口即吃满，实测：

| 场景 | 行高实测 rows=[工具条,画布,参数卡,状态行] | 画布 |
| --- | --- | --- |
| 1490×880（用户尺寸） | `[130, 317, 320, 89]` | 仅 317px |
| 1152×664（复现态） | `[130, 168, 252, 90]` | 仅 168px（几乎无法拾取） |

上一轮定 4:6 的理由是「参数卡自然高 298，6/10 恰好让它不出滚动条」——代价是把画布压成了配角。

## 三、修复（画布变主，参数卡让位）

**`Plugins\Plugin.BeadInspect\BeadInspectView.xaml`**
- `:431` 画布行 `Height="4*"` → `"2*"`；`:434` 参数卡行 `Height="6*"` → `"1*"`。
- `:413-426` 行模型注释改写（记清两轮的取舍演变与实测值，防止按旧理由回退）。
- `:756-762` 路径点列 DataGrid `Height="150"` → `"120"`（点列是复核面，非主操作面）。

**`UI\Controls\Themes\PluginConfigColors.xaml`**（改前已 grep 全仓：三键仅本视图引用）
- `PluginCanvasMinHeight` 150 → **200**（拾取可用性地板）
- `PluginParamsCardMinHeight` 130 → **80**（内滚动兜底，只保证露出标题）
- `PluginParamsCardMaxHeight` 320 → **250**（高视口下不让参数卡长高抢画布）

**不变量**：新下限和 `200+80=280` 与旧 `150+130=280` 相等 → 极矮窗口（620×640）的总溢出量与基线逐位相同，第 4 行不被新推出视口。
