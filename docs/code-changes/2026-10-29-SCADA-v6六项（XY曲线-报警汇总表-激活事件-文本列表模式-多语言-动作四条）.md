## 二、已做

### 1. XY 曲线 `Hmi.XYChart`（新 TypeKey）

- 控件 `Scada.Controls\Elements\XYChartElement.cs` + 主题 `Themes\XYChartElement.xaml` + 描述符（`BuiltInElements.cs`）+ `Generic.xaml` 合并。
- 两个变量（`XVariable` / `YVariable`，名字类属性、不可绑）每拍取一对值追加一点，同一对值不重复追加；`MaxPoints` 环形缓冲；`AutoScale` 自动量程（留 5% 边距）或固定 `XMin/XMax/YMin/YMax`；网格/曲线色/点大小可配。
- 设计期与"变量未解析"都画提示，不画 0。
- **实现要点（与初版设计的偏差，已实测）**：曲线画在模板子元素 `XYChartSurface` 上，不是控件自身 `OnRender`——模板里的 `Border` 背景会盖住控件 `OnRender`，得到一张空图。与既有 `MultiTrendElement` + `TrendSurface` 同一范式。

### 2. 报警汇总表 `Hmi.AlarmTable`（新 TypeKey）

- 控件 + 主题 + 描述符 + `Generic.xaml`；数据取 `RuntimeContext.Alarms.ActiveAlarms`（引擎已按严重度排好）。
- 列：时间 / 报警名 / 级别 / 状态 / 确认；`MaxRows` 截断并在页脚给"还有 N 条"；空态 `EmptyText`；`Zebra` 斑马纹。
- 逐条确认 + 工具条"全部确认"；`Acknowledge` 返回 0 时区分"已经确认过"与"已经不在了"两种提示。
- **每拍重读 + 指纹短路**（`AlarmId|State|Severity|TimeTicks`），数据没变时不重建行——否则会换掉操作员正在点的确认按钮（R138/AX10 同款纪律）。

### 3. 激活 / 取消激活事件（`ScadaEventType.Activated = 14` / `Deactivated = 15`）

- 触发点唯一：`ScadaElementBase.ApplyAnimationEnable` 里 `_animationEnabled` 真翻转的那一次（早退保证边沿语义，数据泵每拍刷值不会重复发）。
- **运行停止/设计期刷新不发**：`ResetAnimationVisuals` 直接把 `_animationEnabled` 置 true、不经过该方法——停机不是"操作员被取消激活"。
- 声明给 9 个可交互图元：Button / BitButton / Symbol / Slider / IOField / TextField / ComboBox / SelectorSwitch / StateView。
- 属性面板零改动：事件行按描述符 `Events` 自动长出。

### 4. 文本列表三种匹配模式（范围 / 位 / 位号）

- `ScadaStateList.Mode`（落盘字符串 `Exact`/`Range`/`Bit`/`BitIndex`）+ `ScadaStateEntry.Min/Max`。
- `Find(int)` 按模式匹配：范围闭区间（重复区间取第一条）、位（非 0 取 `Value=1`）、位号（`Value` 是位号，该位为 1 即命中）。
- **默认仍是精确值**，旧 `.vms` 一条不用改；`Clone`/`CopyFrom`/JSON 往返都带新模式字段。
- 管理器界面：模式下拉 + 模式说明 + 范围模式下才出现的"最小/最大"两列。

### 5. 多语言

- 模型：`ScadaLanguage`（语言表：`LanguageId` + `Name` + `Key→Text` 条目 + `Version`）、`ScadaTextCatalog`（解析与收集键）、`IScadaLanguageService`。
- 方案级集合：`ScadaDocument.Languages` + `CurrentLanguageId`（持久化）+ `AddLanguage`/`TryRemoveLanguage`/`TryRenameLanguage`/`FindLanguage*`；`EnsureIdentity` 补缺失 Id、把指向已删语言的当前语言收回第一张。
- **解析约定**：文本属性以 `@` 开头即文案键（`@btn.start`），`@@` 转义成字面 `@`；三级回落"当前语言 → 任一语言 → 原样 `@键`"。
- 解析落点唯一：`ScadaElementBase.RefreshCore` 铺属性时过 `ResolveText`——所有图元、所有文本属性一次生效，新图元不必记得做多语言；**不碰绑定送来的运行值**。
- 设计期：`ScadaCanvas.TextResolver` 由编辑器注入（`document.CurrentLanguageId`）；运行态：`ScadaRuntimeContext.Languages`（`ScadaLanguageService` 单例，随方案现取）。
- 界面：`LanguageManagerView`（语言增删改名 + 词条表格 + "设为当前语言" + "从方案收集键"），入口在编辑器菜单「多语言…」。

### 6. 动作四条：登录 / 注销 / 切换语言 / 延时

- 枚举追加 `Logon=29` / `Logoff=30` / `SetLanguage=31` / `Delay=32`；`ScadaAction` 加 `LanguageId`/`LanguageName`/`DelayMs` 与 `Detail`/`Describe` 分支。
- **登录**：无条件弹登录窗（不复用 `ShowRuntimeAccessLoginPrompt` 的"已有权限直接放行"短路，否则点了登录什么都不发生）；**账号密码不进 .vms**。
- **注销**：经 `ScadaUserSessionAdapter`（把 `ScadaAccessPolicy` 的"未登录"文案归一成 null、void Logout 包成 bool + 原因）。
- **切换语言**：按 Id（优先）或名字；目标不存在当场失败并给原因，不静默留在原语言。
- **延时**：把同一钩子里**排在后面**的动作排到延时之后执行，当前调用立即返回；延时期间不阻塞 UI；日志记"剩余 N 条将在延时后执行"。
- 编辑器：动作下拉顺序里登录/注销紧跟导航族、切换语言/延时排尾部；语言用文本框填名字、延时用毫秒输入框。

## 五、踩过的坑

1. **模板背景会盖住控件 `OnRender`**：`Border Background={TemplateBinding Fill}` 的子元素画在控件自身 `OnRender` 之上，纯 `OnRender` 画图会得到一张空图。XY 曲线因此改成"模板里放一个 `FrameworkElement` 子元素来画"（与 `MultiTrendElement` 同法）。
2. **`ScadaActionDispatcher` 的延时不能阻塞**：`Thread.Sleep` 会冻住 UI；必须排到 `Dispatcher`。且剩余动作要重新包一个 `RequireConfirmation=false` 的临时钩子，否则会二次弹确认框。
3. **`ShowRuntimeAccessLoginPrompt` 有"已有权限直接 true"的短路**：直接拿它当"登录"动作会让操作员点登录毫无反应。新增 `ShowRuntimeLoginPromptAlways` 专用于该动作。
4. **`ScadaAccessPolicy` 的 `CurrentUserName` 未登录时返回"未登录"文案**：直接当用户名会拼出"原用户 未登录"。必须经适配器归一成 null。
5. **`VisionMaster\obj` 里积压的历史 `*_wpftmp.*` 会让构建报假错误**（"LanguageManagerView 没有 OnAddLanguageClick"之类，而成员确实在源码里）。`rmdir /s /q VisionMaster\obj` 后重建即恢复。这是 WIP 环境的既有问题。
6. **并发构建会互锁 `obj\UI.dll` / `ScadaChecks.exe`**：报 `CS2012 文件被占用` 不是编译错误，等对方进程退出或重跑即可；不要据此改代码。
7. **`docs_index` 会在派工过程中变脏**：任何一路新增 `docs/code-changes/` 条目都会让闸门首步判红。闸门脚本会自己重建索引，但**必须复跑一次**才算绿。
8. **同一仓库有另一个会话在并发改**：本轮闸门连跑六次，其中四次出现"与我无关的红"——`Communication\FreeProtocolConnection.cs` 被改到半成品（`EffectiveTimeoutMs` 未定义）、`Modules\` 下 `Microsoft.CodeAnalysis*.dll` 被运行中的进程锁住导致 `copy` 退出码 1、`obj\*.dll` 被 `.NET Host` 锁定报 `CS2012`、WPF `_wpftmp` 撞车报 `RG1000 shell.baml`。判据：**看报错文件是不是自己改过的**；不是就等对方落盘后重跑，**不要**去改别人的半成品，也不要把 `CS2012/MSB3027/RG1000` 当成编译错误去改代码。
