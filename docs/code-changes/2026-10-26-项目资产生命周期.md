# 项目资产生命周期：默认 / 冻结 / 版本历史 / 权限 / 审计

## 当前状态

资产页的四个操作不再只是提示或内存标记，全部走**单一写入口** `ProjectAssetService`：

- `设为默认`：按「类型 + 作用域」写 `SolutionModel.AssetDefaults`，同作用域互斥；
- `冻结版本`：写资产自身的 `IsFrozen`/`IsLocked`，冻结后拒绝内容写入；
- `版本历史`：每次写操作落 `SolutionModel.AssetVersionLog`（含操作者、动作、快照）；
- `权限`：全部写操作先过 `IScadaAccessPolicy`（权限 Key = `EditStructure`）；
- `审计`：每次允许/拒绝都落 `ScadaAuditWriter` 的 CSV。

## 已做

1. **数据模型**
   - `Core/Models/Assets/AssetLifecycleModels.cs`
     - `AssetVersionRecord`（AssetId / Kind / Version / 快照 / 动作 / 操作者 / 时间）
     - `AssetDefaultPointer`（Kind + Scope + AssetId）
     - `AssetVersionLog`（统一写入、查历史、单资产最多 50 条）
   - `SolutionModel` 新增 `AssetVersionLog` / `AssetDefaults`；`SolutionService.LoadAsync` 补空集合。
2. **写入内核**
   - `VisionMaster/Services/SolutionAssetWriter.cs`：按 Id 定位标定/配方/模板/模型/图像，读版本/哈希，读写冻结；快照按类型分流（标定存 Transform，文件资产存路径/哈希）。
   - `VisionMaster/Services/ProjectAssetService.cs`：
     - `TrySetDefault` / `TryToggleFreeze` / `TryRecordVersion` / `TryRollback`
     - `CheckWritePermission`（导入这类还没有资产 Id 的写操作）
     - 所有路径统一走 `TryAuthorize`：权限 → 存在性 → 冻结检查
3. **回滚**
   - 标定资产可真回滚：从 `SnapshotJson` 还原 `CalibrationTransform`，版本 +1，再记一条「回滚」。
   - 文件资产（模板/模型/图像）明确拒绝回滚并说明原因——快照里没有二进制，假装成功更坏。
   - **版本语义**：`设为默认 / 冻结 / 解冻` 只记录动作、不递增版本；`导入 / 改内容 / 回滚` 才递增。版本卡显示的是动作发生时的版本号。
4. **UI**
   - 资产页 `设为默认` / `冻结版本` 走服务，成功后刷新列表并提示「保存方案后落盘」。
   - 版本页新增「回滚到最新记录」按钮；版本卡显示动作、操作者、备注。
   - 列表与详情显示真实默认标记（`AssetDefaults`）与冻结状态。
   - 导入前先过权限闸门；导入成功后写一条「导入」版本记录。
5. **宿主接线**
   - `App.xaml.cs` 用工厂注册 `ProjectAssetsView` 的 VM，注入按当前方案新建的 `ProjectAssetService`；审计写入复用单例 `ScadaAuditWriter`。
6. **断言**
   - `ProjectAssetsUiProbe` 新增 `RunLifecycleChecks`：
     - 未登录时默认/冻结/导入都被拒并说明权限；
     - 登录后可设默认、冻结、解冻、写版本；
     - 冻结后拒绝内容写入；
     - 版本历史 ≥4 条且记录动作与操作者；
     - 文件资产回滚被明确拒绝；
     - 标定资产回滚后 `MmPerPixel` 恢复；
     - 审计 CSV 含被拒绝、允许的操作与操作者；
     - `AssetVersionLog` / `AssetDefaults` 进入 `.vms` 序列化。

## 未做 / 已知限制

- **文件资产没有二进制版本快照**：回滚只对标定开放；模板/模型/图像需要「旧文件保留策略」后才能真正回滚。
- **默认指针没有跨方案复用**：当前是方案级 `AssetDefaults`，不涉及软件级资产库。
- **权限 Key 复用「改结构」**：没有为资产单独新增权限项，避免动 15 条内置目录与相关断言；后续如需细粒度可新增 `AssetWrite`。
- **审计写入失败不阻断动作**：与 `ScadaAuditWriter` 既有口径一致（磁盘故障不应让按钮点了崩溃）。
- **版本历史无 UI 差异对比**：只记录动作/操作者/备注，没有逐字段 diff。
- **撤销栈未接**：资产写操作不进 `SolutionDraftService` 的撤销栈。
