## 三、工具箱"隐藏后没按预期"的结论

图钉是 AvalonDock 的 **auto-hide**，不是关闭：

- 隐藏前右列 pane 320、工具箱可见、pane 子项 1；
- 隐藏后 pane 子项 0、`IsVisible=False`、pane 控件 `ActualWidth=0`，工具箱进 Hidden 区（右侧竖条可点回来）。

看起来"没隐藏"的三种情况：

1. **自由模式**：同一 pane 里属性/图层/图元工具箱仍可见，图钉只隐藏工具箱一个标签，列不会收——这是 per-tab 语义；整列收起是 B 的专注模式。
2. **点了 X**：`CanClose=False`，关闭按钮不生效；隐藏要用图钉。
3. **切模式**：调试↔组态/自由按模式重新收敛，工具箱会回来；这是模式语义。

当前右侧 Hidden 竖条图标很小，容易被忽略；如果要做"整列收起 + 带文字返回入口"，走 B 或另加「收起检查器」按钮，不改 AvalonDock 模板。

## 六、踩过的坑

- **`SaveToString` 会先把控制台 pane 放回再序列化**（否则 `Layout.xml` 里没有它，下次启动直接消失）。所以"收起"状态不能靠 pane 是否存在来判断，必须另写根属性；否则每次保存都把收起状态洗成展开。
- **组态的 `Hidden` 不能原样持久化**：退出时在组态模式，`CurrentConsoleState=Hidden`；若写 `Hidden`，下次启动调试模式会没有控制台。写盘时按 `Collapsed` 处理。
- **`CaptureDefaultLayoutSnapshot` 也走 `SaveToString`**：它会在 `LoadFromString` 之前把默认状态应用到界面上；属性必须跟着快照一起写，`Reset` 才能恢复出"调试 32"。
- **断言宿主量不到 pane 控件宽度**：`UIThemeSmokeTest` 的 ShellCopy 窗口不 Show，`LayoutAnchorablePaneControl` 没实例化；最初的 ②b 断言因此报 `control=False`。改为断言布局模型（pane 变空 / `IsVisible=False` / `IsHidden=True` / 能恢复），宽度 320→0 由 `_ScadaUiProbe --right-pane-hide` 在真窗口量。
- **图钉 ≠ 关闭**：`CanClose=False` 的 X 是禁用的；用户点 X 不会隐藏。per-tab 图钉在自由模式不会收起整列，因为同一 pane 还有别的可见标签。
- **`ApplyScadaPanelMode(false)` 原来的 `RestoreLogPane` 是 A 的隐形回退**：它无条件把控制台展开 200，覆盖 `LoadFromString` 恢复的收起态；调试/自由分支删掉后，控制台状态只由启动恢复、切模式、用户 Toggle 维护。
