# 报表「从账本导入列」

日期：2026-10-25　状态：**已实现**；`ScadaChecks` 3043 通过 / 0 失败（含 `[RP40]` `[RP41]`）

## 起因

用户反馈：报表列的「来源列」是自由文本，第一次配报表完全不知道该填什么。
（口径澄清：报表列填的是**账本 CSV 的列名**，不是工程变量名；填错时查询会明确报
`账本里没有列「X」。现有列：…`。）

## 做了什么

1. **纯逻辑** `Scada/Models/ScadaReportImport.cs`：`ScadaReportColumnImport.FromHeader(header)`
   - 表头去空白；空列名与**重名列**（忽略大小写）跳过——同名两列时报表只取第一列，留着第二列等于骗用户；
   - 标题默认 = 列名；首列按时间列给 140px，其余列宽 0（占满剩余）；
   - 聚合方式一律 `None`（明细照抄），不替用户猜"该求和还是平均"。
2. **编辑器**（`ScadaReportColumnsEditor`）：
   - 底部新增「从账本导入列」按钮；
   - 读当前方案 `SolutionPaths.GetHistoryDirectory(...)` 下**最新**的 `*.csv`（先顶层、再递归），
     取首行 `CsvLedger.ParseLine` → 表头；
   - 已有列时先确认"将替换当前 N 列"；导入后底栏提示"已从 xxx.csv 导入 N 列（列名…）"；
   - 失败一律给可直接照做的中文：没有 History 目录 / 目录里没有 csv / 首行为空 / 读文件失败。
3. **接线**：`ScadaEditorViewModel.CurrentSolutionFilePath`（新公开属性）→
   `ScadaPropertyViewModel.OnPickReportColumns` 传给编辑器。目录口径与运行态报表取数**同一出处**。

## 断言

- `[RP40]` 表头去空白、跳过空列与重名列；首列 140px、其余 0；标题=列名、聚合=None。
- `[RP41]` 空表头（null / 空 / 全空白）返回空集合，界面据此提示"账本没有表头"。
