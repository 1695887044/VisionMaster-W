## 踩过的坑

- **不能直接删 R137 的表格行**：`audit_rules.ps1` C1 要求 R1-R190 每个编号都有归属行，删行会报 `C1 union incomplete, no owner for: R137`。正确做法是留一行废止墓碑（仍是归属行），把失效判据从行里删掉。
- **镜像侧不是从 AGENTS.md 正文抽取的**：`sync_constraints.ps1` 的正文来自 `tools\sync_constraints.block.json` 侧边车。只改 AGENTS.md 不会改镜像，必须同步改 sidecar 再重跑，否则 `-Check` 立刻报 DRIFT。
- **`-File script.ps1; echo` 会被 PowerShell 当成文件名**：`-File` 后面的 `;` 属于参数，报"不具有 '.ps1' 扩展名"。分两条命令跑，别在同一行接 `;`。
- **分册里的条数是"方法内第几条"**：`RunPanelModeChecks` 已从 5 条长到 26+ 条，"后 5 条"这种按序号写的判据最容易悄悄错位；改成按分组名 + "条数以方法内 `Check(` 为准"。
