# 方案 B：删「变量」档，取值统一走绑定弹窗

日期：2026-10-30
类型：规格变更（用户已拍板："项目没上线，枚举直接删、不考虑迁移"）+ 两个插件的 UI 收敛

---

## 1. 为什么做

`ColumnSource` / `FieldSource` 都有三档：`Port`（端口）/ `Variable`（变量）/ `BuiltIn`（内置）。

`Variable` 这一档的语义是**取值**（不是写名）：`RecordColumnDef.cs:12` 注释"从 context.LocalVariables **按名取值**"、
`UploadFieldDef.cs` 原注释"字段的**取值**来源"、`ResultUploadPlugin` 调 `TryResolveVariable(...)` 读值。

而 `Port` 那一档早就是 `LinkableValueEditor` 🔗 → `DataBindView` 绑定弹窗 → `LinkedSources`
（`DataRecordView.xaml:38-51` 的 `ColumnPortEditorTemplate`）。

**同一件事（取一个值）有两套交互**：一套能绑全局/系统/运行时/上游端口四类来源，另一套只能填一个名字。
方案 B = 把「变量」这档下线，让"取值"只剩一条通道：**绑定**。

## 2. 落地口径（与交接报告 §3.1 的差异，重要）

交接报告写的是"枚举直接删、不做迁移"，方案书 §6.1 写的是"不许删"。**本次按后者执行**，原因：

`ColumnSource` 现在是 `Port=0, Variable=1, BuiltIn=2`。删掉中间的 `Variable`：
- `BuiltIn` 变 1 → 旧 `.vms` 的 `"Source": 2`（本来就是内置）变成未定义值；
- 旧 `.vms` 的 `"Source": 1`（本来是取变量）反序列化成 `BuiltIn` → **静默变成"记时间戳"**。

这是"不报错、只错数据"的典型静默故障。代价只差两行标记，所以：

| 项 | 做法 |
|---|---|
| 枚举成员 | **保留**，标 `[Obsolete]`，**数值不变** |
| UI 下拉 | 过滤掉这一档（`ColumnSources` / `FieldSources` 改成显式两项数组） |
| 运行期分支 | **保留**（旧配置照旧取值） |
| 迁移逻辑 | **不做**（用户明确要求） |
| 旧配置提示 | 新增只读提示：告诉用户"这一档已下线，请改选「取值（绑定）」" |

## 5. 风险与边界

| # | 风险 | 处置 |
|---|---|---|
| 1 | 旧方案里 `Source=Variable` 的列**不会自动转换** | 用户已明确"不迁移"；旧列照旧取值，UI 给只读提示 + 指引。要转换只能用户手动改选「取值（绑定）」并重新绑定。 |
| 2 | 旧列的 `VariableName` / `VariableId` 字段**仍落盘** | 刻意保留：删字段会让旧 `.vms` 回读时丢数据，而这两个字段对新配置完全无害（新配置里恒为空）。后续若要清，需先确认没有旧方案样本。 |
| 3 | `IsTextDirty` / `MarkTextClean` 现在**无消费方** | `ApplyConfigValues` 里仍在调 `MarkTextClean`（无副作用），`RecordColumnDef` / `UploadFieldDef` 的字段定义保留。属"死代码待清"清单，不在本批删（删字段会改序列化面）。 |
| 4 | 运行时变量"手填名字"的能力**一并消失** | 这是方案 B 唯一真实功能退化。用户当时的诉求是"取值统一走绑定"，而绑定弹窗的运行时候选只列上游「变量定义」静态声明的（`FlowQueryHelper.cs:190-221`，判据类 `VariableDefinitionPlugin` 在本仓库不存在）。补法 = 交接报告 §3.4 的"手输出口"，未做。 |
| 5 | `VariableOptionResolver.CaptureId / ResolveTarget` 对这两个插件**不再被调用** | 保留（其余地方仍用：`C23`/`C24` 探针与未来的变量定义与赋值）。 |

## 6. 未做

1. **手输出口**（绑定弹窗底部"手填运行时变量名"）——方案 B 的功能补丁，独立批次。
2. **旧配置自动迁移**——用户明确不做。
3. **死代码清理**（`IsTextDirty` / `MarkTextClean` / `VariableOptionResolver` 在这两个插件的残留引用）——独立批次，删前要确认序列化面影响。
4. **视觉验收**——只做字符串级断言，没真跑界面看"旧配置提示条"的实际排版。
