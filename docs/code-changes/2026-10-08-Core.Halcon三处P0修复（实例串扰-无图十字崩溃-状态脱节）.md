# 2026-10-08 共享控件库 Core.Halcon 三个 P0 修复（DisplayImageInfo 串扰 / 无图关十字崩溃 / 十字状态脱节）

## 一、起因

2026-10-07 对 `Services\Core.Halcon`（HALCON 控件库：`HalconBase` 基类 + `ImageDisplay`/`ImageEdit`/`ImageReadOnly`/`ImageGallery` 四控件，被宿主与 14+ 插件视图引用）做了一轮只读审查，产出三个正确性问题（P0-1/2/3），用户拍板修复。审查报告全文见会话记录，本文只记录修复与验证。

## 二、根因与修复

### P0-1：`DisplayImageInfo` 的 DP 默认值是全实例共享的单例 → 跨画布像素读数串扰

- **根因**：`HalconBase.cs` 以 `new PropertyMetadata(new ImageInfo())` 注册 `DisplayImageInfo`——WPF 的 DP 默认值被**所有实例共享同一个引用**；全仓没有任何地方给该属性赋过实例值，所以应用内所有 HALCON 画布（图集默认模板本身就并排两个 `ImageDisplay`：`PART_Big` + 对比模式的 `PART_Big2`）共享同一个可变 `ImageInfo`。后设图的控件覆盖共享实例的 `Image`，鼠标悬停到另一画布时 `HSmart_HMouseMove` 按错误图像取灰度/RGB，`TryGetSampleChannels` 缓存也被污染重建。
- **修复**：构造函数里 `DisplayImageInfo = new ImageInfo();`——与 `DrawObjectList` 既有同款纪律（构造函数注释早已写明该坑，`DisplayImageInfo` 漏掉了）。
- **改动**：`Services\Core.Halcon\Base\HalconBase.cs` 构造函数 +4 行（含注释）。

### P0-2：无图状态点右键"隐藏十字"抛异常 + 关十字抹掉全部叠加层

- **根因**：`ShowImageCross(false)` 走 `RePaint()`，后者 `hWindow.DispObj(HImage)` 不判空——画布无图时异常逃进菜单点击链（右键菜单无外层处理）；即使有图，`RePaint` 只重画图像本体，ROI 轮廓/涂抹层/测量标注全部消失，直到下一次缩放/平移。
- **修复**：删除 `RePaint()`（全仓唯一调用方就是这里，grep 验证）；`ShowImageCross` 改为纯状态设置 + `RenderAll()`（它具备全部守卫与完整图层语义）。
- **改动**：`HalconBase.cs` 删 13 行 + 改 7 行。

### P0-3：十字开关与实际显示脱节

- **根因**：旧 `ShowImageCross(true)` 只在开的那一瞬 `PaintCross()` 画一次；此后任何缩放/平移/换图触发的 `RenderAll()` 都不含十字——用户一动鼠标十字消失而菜单仍打着勾。
- **修复**：新增 `_showCross` 状态字段；`RenderAll()` 在 `RenderAnnotations()` 之后、`flush_graphic=true` 之前按状态补画 `PaintCross()`（画在图层最后，不与其它图层争位）。`PaintCross` 自身的"无图守卫"（宽高 ≤0 或 hWindow null 直接返回）保留。
- **改动**：`HalconBase.cs` +6 行状态字段与逻辑。

## 三、回归断言（新增 `FlowCanvasChecks\HalconControlChecks.cs`，10 条全绿）

注册于 `Program.cs:183`（`ThumbnailChecks.Run()` 之后）。要点：

- **STA 纪律**：断言宿主 `Main` 非 WPF Application，WPF `Control` 构造在非 STA 线程抛 `InvalidOperationException`——全部探针（含"纯构造即可观测"的 P0-1）都在 STA 工作线程内跑，结果收集回主线程统一 `Check`（与 `BeadInspectChecks.CheckUI_BindingCard` 同款范式）。
- **[P0-1]** 两实例 `DisplayImageInfo` 不 `ReferenceEquals`；非空（模板绑定不断链）；设图后仍独立（图集双画布场景）。
- **[P0-2]** 无图状态关十字不抛；窗口未就绪（hWindow=null）时开/关均不抛（等价于右键菜单 `BuildInfoMenu` 回调路径，`ShowImageCross`/`RenderAll` 是 protected，经反射调用）。
- **[P0-3]** `_showCross` 默认 false；打开置位；模拟缩放/平移的 `RenderAll` 后仍为 true（补画语义）；关闭复位。反射取字段沿继承链向上找（`_showCross` 声明在基类、实例是派生类 `ImageDisplay`，不向上找会 `MissingFieldException`）。
- **伴生回归**：置空 `HImage` 清屏路径不抛（`HImageChangedCallBack` 既有行为）；合成图用 `GCHandle.Alloc(Pinned)` + `GenImage1(IntPtr)`（`GenImage1` 是复制语义，pin 只需覆盖调用期间——照 `ThumbnailChecks.GrayFrom` 范式；断言工程不开 `/unsafe`）。
