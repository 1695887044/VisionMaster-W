## 2. 已做

1. **逐件随机 SN**：C# 脚本步骤读序号变量 + 种子变量，算校验码后 `Variables.Set`，格式随方案不同；序号变量每件自增，保证一批内唯一。
2. **数据表格**：`Hmi.DataGrid` 配 `GridColumns` 列 JSON、`SampleVariable` 采行信号、`MaxRows=200`、`RowHeight=32`、`NewestFirst=True`。Main 每件把采行信号先置 `false` 再置 `true`，图元吃上升沿采一行。
3. **新增 `tools\probes\_VmsCompileProbe`**：补上"生成 .vms 之后没人验它能不能真的编译"这个空档。它按 R181 的纪律把 `Modules\`、`bin\`、`VisionMaster\bin\Debug\net9.0-windows\` 挂进 `AssemblyResolve`，走完整加载链（含 `VariablePersistenceService.Restore`），逐流程 `FlowCompiler.Compile`，退出码 0/1/2。
4. **`_ScadaUiProbe` 补 `ImageAssetResolver`**：`Hmi.Picture` 的 `SourcePath` 是"方案内相对路径"，控件靠宿主注入的解析器取值（`Scada.Controls\Elements\ScadaElementBase.cs:301`）。探针没有宿主，原先两张图恒为占位；补一个按"方案目录 + 相对路径"解析的解析器后正常出像素。

## 6. 踩过的坑（供下次照抄）

- `Op(key, ("K","V")...)` 的值必须是字符串，写数字直接 CS1503。
- `MathCalculationPlugin.Operation` 必须写英文枚举名，写整数在加载时抛 `InvalidCastException`。
- `ResultDisplay` 的图输入端口叫 `SrcImage`（`ResultDisplayPlugin.cs:51`），不是 `Image`；端口名写错会静默落成"参数缺失"。
- `CaliperMeasure` 的卡尺矩形必须**横跨**被测边：`Params=[中心行,中心列,角度Phi,半长L1,半宽L2]`，L1 沿扫描方向，L2 沿阵列排布方向。
- 生成器改完要重跑 `GenSolution.exe`，探针只读文件不看源码；改了生成器却没重新生成，校验的是旧文件。
