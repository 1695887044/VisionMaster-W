## 二、已做

### 2.1 右侧 gutter

`VisionMaster\Views\DialogViews\AutoPortConfigView.xaml`：

```xml
<ScrollViewer
    MaxHeight="600"
    Padding="0,0,12,0"
    HorizontalScrollBarVisibility="Disabled"
    VerticalScrollBarVisibility="Auto">
```

原因：`App.xaml` 的合并顺序是 `UI/Generic.xaml` → `PresentationFramework.Fluent`，Fluent 后合并，隐式 `ScrollBar`/`ScrollViewer` 样式覆盖仓库 `UI/Controls/Themes/Controls/Misc.xaml` 的 12px 样式；Fluent 是覆盖式滚动条，内容不留 gutter 时滚动条命中区会压在卡片右边缘/圆角上。12px 是 Fluent 滚动条命中区宽度。

### 2.2 提示文字省略号

同文件区块头提示：

```xml
<TextBlock
    Style="{StaticResource SectionHintTextStyle}"
    Text="常量直接填 · 需要上游供值点链接"
    TextTrimming="CharacterEllipsis"
    ToolTip="常量直接填 · 需要上游供值点链接" />
```

原来没有 `TextTrimming`，窗口/滚动条挤窄后文字在卡片右边界被硬裁；现在超长时显示省略号，悬停可看全文。

## 五、踩过的坑

- **Fluent 后合并会覆盖仓库滚动条样式**：`App.xaml` 里 `Fluent.xaml` 排在 `UI/Generic.xaml` 之后；`Misc.xaml` 的 12px ScrollBar 样式在弹窗里不生效，实际是 Fluent 覆盖式滚动条。
- **覆盖式滚动条不占布局列**：给 `ScrollViewer` 加 `Padding`（或给内容加 `Margin`）才是可靠 gutter；只改 `ScrollBar.Width` 不会让内容缩进。
- **`TextBlock` 默认不省略**：右对齐长提示在窄列里是硬裁，必须显式 `TextTrimming` + `ToolTip`。
- **并发实例锁产物**：标准 `bin\Debug` 被另一会话的 `VisionMaster.exe` 占用时，用 `-p:OutDir=<无尾斜杠目录>` 构建到独立目录验证；不要把“复制失败”当成代码错误。
