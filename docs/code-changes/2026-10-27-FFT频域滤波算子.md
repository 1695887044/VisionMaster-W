### 2.2 HALCON 算子与参数（实测口径）

| 步骤 | 算子 | 参数 |
| --- | --- | --- |
| 转实型 | `convert_image_type` | `'real'` |
| 正向变换 | `fft_generic` | `'to_freq', -1, 'sqrt', 'dc_center', 'complex'`（与 `fft_image` 逐像素相同，实测 real/imag 差 = 0） |
| 频域乘 | `convol_fft` | 频谱 × 自建实值掩膜 |
| 反向变换 | `fft_generic` | `'from_freq', 1, 'sqrt', 'dc_center', 'real'` |
| 归一化 | 复用 `RealToByteNormalized` | `min_max_gray` → `scale_image` → `convert_image_type('byte')` |
| 掩膜构造 | `gen_image1`（`'real'` + 固定 `float[]` 缓冲） | 逐像素解析生成，未用 `gen_filter_mask` |

关键实测值：

- **直流位置**：`fft_image` / `fft_generic('dc_center')` 的直流在 `(ceil(H/2), ceil(W/2))` ——
  64→(32,32)、63→(32,32)、65→(33,33)、5→(3,3)。
- **归一化频率**：用户口径 0~0.5（0.5 = Nyquist），半径（像素）= 频率 × `min(W,H)`。
- **`gen_lowpass` 的 CutoffFrequency 以 Nyquist = 1.0 计**（实测 0.5 → 半径 min/4），
  所以参考实现里要用 `截止 × 2`；本算子掩膜与 `gen_lowpass(2×截止, 'none', 'dc_center')` 逐像素相同（实测差 0）。
- **`gen_gauss_filter` 的 Sigma 是空域标准差**，频域响应 `exp(-2π²σ²f²)`（实测 off=1/2/4/8 四个点全对），
  要让"截止处 -6 dB"取 `σ = sqrt(ln2)/(π·sqrt2·截止)`；本算子高斯掩膜与该生成器逐像素相同（实测差 0）。
- **`fft_image_inv` 只输出 byte**：给 -100~100 的 real 图做 `fft_image` + `fft_image_inv`，
  回来是 0~100（负值被截），所以反向变换改用 `fft_generic(..., 'real')`。
- **`rft_generic` 与 `fft_image` 的复数布局不通用**：把 `fft_image` 的复频谱喂给
  `rft_generic('from_freq', ...)` 会抛 #1304（rft 是半频谱布局、直流在 (0,0)，且宽度是 W/2+1）。

### 2.3 掩膜口径（写进代码注释与手册）

- 低通：`gain = S(d / r)`；高通：`1 - S(d / rLow)`；
  `S` 在 `d = r` 处取 0.5（-6 dB）——理想档 `d <= r ? 1 : 0`，高斯 `exp(-ln2·x²)`，巴特沃斯 `1/(1+x⁴)`。
- 带通/带阻：先算"到环带的距离"`x = max(0, rLow - d, d - rHigh)`，过渡尺度取环带半宽 `(rHigh-rLow)/2`，
  环带内恒 1（带阻恒 0），环带外 1 个半宽处衰减到 0.5；理想档在环带边缘硬切。
- 陷波：`(0,0)` 与共轭点两处都要陷（实图像频谱厄米对称，只陷一半会让反变换实部畸变）；
  `KeepDc` 勾选时强制直流 bin 增益 = 1。
- 偏移按 `(-size/2, size/2]` 环绕折算，保证 ±f 到直流距离相等 → 掩膜天然厄米对称。

## 5. 踩过的坑

1. **`fft_image_inv` 只输出 byte（最致命）**。任务书要求 `fft_image_inv → 取实部`，但实测
   HALCON 23.05 的 `fft_image_inv` 把结果直接写成 byte：-100~100 的图反变换回来是 0~100。
   高通/带通/陷波的结果本来就有一半是负值，用它等于半波整流 —— 而且整流出来的二次谐波
   恰好落在"高频参照物"的 bin 上，断言里看起来像"高频没被滤掉"（实测带通 A/B = 1.99，
   和输入幅度比一模一样）。改用 `fft_generic('from_freq', 1, 'sqrt', 'dc_center', 'real')` 后
   同一组用例的 A/B 变成 8089。
   **判据**：反变换后 `get_image_type` 必须是 `real`，且结果最小值可以是负数。
2. **`rft_generic` 与 `fft_image` 的复数布局不通用**。把 `fft_image` 的输出喂给
   `rft_generic('from_freq', 'n', 'real', W)` 抛 #1304（控制参数 4 宽度非法）——
   rft 是半频谱布局（输出 65×96 对 128×96 输入、直流在 (0,0)），`fft_image` 是全频谱、直流居中。
   两族算子只能各自闭环。
3. **`gen_filter_mask` 表达不了这五类滤波**。23.05 的 `gen_filter_mask(ImageFilter, FilterMask, Scale, W, H)`
   的 `FilterMask` 只认 `'laws_ee' / 'laws_ss' / 'laws_rr'` 这类 Laws 纹理掩膜；
   `gen_lowpass/gen_highpass/gen_bandpass` 只有理想型且 CutoffFrequency 以 Nyquist=1.0 计
   （0.5 → 半径 min/4，与本算子 0..0.5 的口径差一倍）；高斯/巴特沃斯没有现成算子。
   → 掩膜按"到直流距离"逐像素解析生成（`float[]` + `gen_image1`），并用
   `gen_lowpass` / `gen_gauss_filter` 做对拍确认口径一致（实测逐像素差 0）。
4. **min/max 归一化会吃掉"衰减了多少"这个判据**。算子最后一步是 `RealToByteNormalized`，
   任何"整体缩放 + 平移"都被抹平：高斯低通 0.05 把 0.125 处衰减到 1.3%，输出的 max−min 仍是 255。
   → 断言改用**两条谱线的幅度比**（线性映射下不变）；为此合成图里专门放了一条低频参照物
   （3/128，幅度 20）。同理，`KeepDc` 对最终输出只是整体平移，归一化后不可观测，
   所以它只做存盘往返断言（语义正确性由掩膜实现保证）。
5. **`fft_generic` 的 Norm 必须成对**。`to_freq` 用 `'sqrt'` + `from_freq` 用 `'sqrt'` 往返恒等（实测）；
   `'none'` + `'none'` 会把结果放大 N 倍（128×128 → 值域 45 万级）。归一化虽然后面会吃掉倍数，
   但中间值越界会损失 float 精度，所以按 `fft_image` 的口径用 `'sqrt'`。
6. **陷波要陷两处**。实图像的频谱厄米对称，`(row,col)` 与 `(-row,-col)` 是同一个频率的两个 bin；
   只陷一半会让该频率变成复信号，反变换的实部出现畸变（表现为"陷波后条纹变成渐变亮带"）。
   → 掩膜里取到两个中心距离的最大值。
7. **`GenImage1` 的 `'real'` 是 32 位 float**，缓冲必须是 `float[]`（不是 `double[]`），
   否则读到的是把 double 的高低位当两个 float 的垃圾数据。
8. **PowerShell 探针里 `$H` 会被 `$h` 覆盖**（变量名大小写不敏感），
   直接把 `$HOperatorSet` 换成 `$H` 后一调用 `$H::GenImage1` 就报"Int32 不包含 GenImage1"。
