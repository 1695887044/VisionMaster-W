## 踩过的坑

1. **归属判定要用"表行"不能用"提及"**：AGENTS.md 里 `R108`/`R42` 这类编号在 §0 冲突表、§3 红线家族、指针里到处出现，按"出现即归属"会全部误判双归属。正解：只认 `| R… |` 表行开头，且解析时**跳过 §0**（它的表行是编号说明不是归属）。
2. **审计脚本首跑就把自己的 4 个 bug 抓出来了**（键缺前缀、§0 污染、前缀拼丢、分类顺序）——这正是"先建闸再搬家"的价值：如果先搬后建闸，这些误报会和真问题混在一起。
3. **整节搬运要检查"被别处按编号引用的规则"**：R42/R62/R55/R71/R16 被 §3 红线③家族点名，下沉后必须在指针的"最易踩"里保住编号与一句摘要，否则 §3 的引用指向一条注入层看不见的规则。
4. `run_gates.ps1 -Only` 的参数是**一个逗号串**（`-File` 绑定不切分），脚本内部自己 `-split ','`——传多个步骤名没问题，但**别用 `;` 串接第二条命令**（C-39：cmd 不认 `;`，会把后半段当参数传给脚本）。
