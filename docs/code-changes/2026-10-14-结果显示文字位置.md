## 一、起因与裁决

用户一句：**"你的显示插件 没办法控制文字的位置吗"**。

首轮落地时文字块是**写死左上角**的（方案说明书 §5.5 原文："不给用户配坐标"），现场的真实抱怨是"数值好好的，却压住被测工件"。给了四档候选，用户**只点**了第一档：

| 候选 | 用户裁决 |
| --- | --- |
| **九宫格锚点 + 边距 + 字号倍率** | ✅ **采纳**（本轮实现的就是它） |
| 再加：几何标签（点/线/圆的名字）偏移可调 | ❌ 落选 |
| 每个结果项自己配归一化坐标 | ❌ 落选 |
| 先不做，只是问问 | ❌ 落选 |

两个落选项**已写成非目标 N8**（不再当"顺手补齐"）：逐项归一化坐标换相机分辨率或改 ROI 之后会**静默错位**，而"某一行想单独放"的正解是**再接一个结果显示算子**（一个流程一个实例是 D3，为这一行破例不如多放一个算子）。这条理由同时写进了 `TextAnchorKind.cs` 的文件头注释，防止后来人从代码里看不出为什么没有坐标列。

## 三、为什么这么切（本轮的设计要点，不是"加了三个配置项"）

**水平与垂直分量必须分家，而且分给不同的人：**

| 分量 | 归谁 | 为什么只能是它 |
| --- | --- | --- |
| **垂直**（块高 → 上/中/下带） | `DisplayDraw.EmitStack()` | 块高 = **行数** × 行距，而行数要到类型分派 + 元素预算 `Take()` 全部走完才确定。烘焙件收到的是一堆独立 `BakeText`，它不知道"这一堆是不是一组" |
| **水平**（左/中/右贴边） | `AnnotationBaker` | 文字**像素宽度取决于窗口当前字体**，而只有 baker 持有窗口——静态扫描 ④c 明令插件自己零 `OpenWindow`/`SetPart`。调用方要么估宽（等宽字体也有小数点/负号/中文差异，估必歪），要么只能贴左 |

**"文字晚一点进 `Texts`"为什么安全**：烘焙件按**类别**画（`Shapes → Objects → Texts`，`AnnotationBaker.cs:148-150`，R37 定死的层序），所以推迟入列不改变图形与文字的先后。**副作用**：堆叠文字现在排在**几何标签之后**入列，也就是文字块会压在几何标签上面（原先两者按插入顺序混排）——要改层序只能改 plan 的入列顺序，**不要去改 baker**。

**兼容做法**：三处都用"默认即老行为"（`HAlign` 默认 `Left`、`Build` 三个新参全部可选），且这个承诺由两条断言分别在不同层证明（B8 像素层"默认 == 显式 Left"、U1 plan 层逐字段全等），不是口头保证。

## 五、偏离与本轮自踩的坑

1. **XAML 属性值里不许出现 ASCII 双引号**：提示文案写成 `Text="只搬"数值/文本"那一块…"` 直接截断属性、`XamlParseException`（另有一处 `ToolTip` 同样）。中文提示里必须用**全角 “ ”**。C# 注释与字符串里的中文引号不受影响，只在 XAML 属性值是雷。
2. **断言 bug 会长得像产品 bug**：U5 第一版拿 `MiddleCenter` 的 `Col`（= `W/2` = **200**）去和"自动边距"（**12**）比，报"margin=0 与自动同值 → 0→200，自动→12"，当时差点去改 `EmitStack`。正解是**在同一处坐标系里比**：`SameTexts(TopLeft, margin=0)` vs `SameTexts(TopLeft, margin=autoMargin)`。**先怀疑尺子，再怀疑产品。**
3. **演示方案 `解决方案\结果显示演示.vms` 本轮保持默认 `TopLeft`**（**有意偏离**，不是漏改）：两条像素断言把采样带写死在左上角——`ResultDisplayCheck.cs:395`（白底框 `BandMax(8..40, 8..200) ≥240`）与 C5 的 `DiffAreaInBand(8,8 → 120,400)`（`:1501`）。改锚点这两条会红，那是断言写死位置、不是回归。新能力由 B8 + U1~U9 覆盖。**下次要演示九宫格，就把这两条的采样带跟着锚点挪**，不要新加一条像素断言了事。
4. **几何标签不受锚点影响**（只有字号同比放大）——这是用户裁决的边界（落选项），不是实现未完成。
5. `docs\结果显示\结果显示插件方案说明书.md` §5.5 原文"不给用户配坐标"已就地改为"锚点/边距/字号可配，逐项坐标不给配"，理由与分工记在 **§14.17**；D7 加校正段（**结果项表一列都没加**）；非目标新增 **N8** 把两个落选方案钉住。
