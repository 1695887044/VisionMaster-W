## 一、V2 交付内容

### 1.1 局部变量（LocalVariable）

| 文件 | 改动 |
| --- | --- |
| `VisionMaster/Services/RecipeService.cs` | 捕获/预检/应用/终检/回滚支持 `RecipeTargetKind.LocalVariable`；新增 `PrepareVariablesForSave`；新增 `CanEdit`；注入 `ISharedVariableAccess`（默认 `GlobalVariableWriter`） |
| `VisionMaster/Services/RecipeSaveCoordinator.cs` | 「应用并保存」前调用 `PrepareVariablesForSave`，把活动配方的变量值回填到活变量，避免首件流程改写后把运行值烘进 `VariableSnapshots` |
| `VisionMaster/App.xaml.cs` | 退出草稿转存前先 `VariablePersistenceService.Capture`，让草稿包含变量当前值 |

规则：
- 只收 `LocalVariableModel`；网络变量/系统变量整单拒绝。
- **触发源变量**（`FlowModel.TriggerVariable` 指向的变量）捕获时跳过、应用时整单拒绝。
- 变量按 `VariableId` 寻址，写入走 `ISharedVariableAccess.TryWrite(id, "", value)`（Id 优先、空名字兜底）。
- 写后回读终检；失败逆序回滚。
- 保存前回填只作用于**活动配方的变量条目**；这是「配方是变量输入的唯一来源」语义，会覆盖首件流程写入的运行值。

### 1.2 `.vmrecipe` 导入导出

| 文件 | 内容 |
| --- | --- |
| `Core/Models/Recipe/RecipeFileModels.cs` | `RecipeFileDto`：FormatVersion / ExportedAtUtc / ExportedBy / SourceSolutionId / SourceSolutionName / ContentHash / Recipe |
| `VisionMaster/Services/RecipeFileService.cs` | 导出（原子写、UTF-8 无 BOM、SHA-256 指纹）；导入（只建定义、不应用、重新分配 RecipeId、ContentVersion=1） |
| `VisionMaster/ViewModels/DialogViewModels/RecipeManagerViewModel.cs` | 增加 `ImportCommand` / `ExportCommand` |
| `VisionMaster/Views/DialogViews/RecipeManagerView.xaml` | 左侧增加「导入」「导出」按钮 |
| `VisionMaster/App.xaml.cs` | 注册 `RecipeFileService` |

安全边界：
- `TypeNameHandling.None`；文件里出现 `$type` 整份拒绝。
- 出现 `Address` / `ConnectionName` / `Protocol` / `CardModel` / `DriverTypeKey` / `SoftLimitMinMm` / `SoftLimitMaxMm` / `CameraSettings` 等设备字段整份拒绝。
- 同名配方拒绝，不静默覆盖。
- 导入只建定义；`ActiveRecipeId`、当前参数值、`FlowModel.Version` 均不变。
- 导入要求工程师及以上登录。

### 1.3 断言扩展

`RecipeChecks/Program.cs` 从 62 条扩到 **77 条**，新增：
- 变量已捕获 / 触发源变量未捕获。
- 变量应用后值正确。
- 保存前变量回填。
- 触发源变量预检报错。
- 导出成功 / 导出文件无 `$type`。
- 导入成功 / 名称正确 / 内容版本=1 / 导入不应用 / 条目数正确。
- 含 `$type` 拒绝 / 含设备字段拒绝。
