## 二、改动 A：数据线默认隐藏（只显示执行顺序）

- `FlowCanvasViewModel` 新增 `ShowDataLinks`（`FlowCanvasViewModel.cs:363-378`）：bool **默认 false**（属性无显式初始化器 → bool 默认值；文档注释写明"默认关"与非法线例外口径）；setter 走 `SetProperty` 成功即 `RebuildInPlace()`，与 `ShowOrderLinks`（`:352-361`）配对。
- **渲染过滤点在 `BuildLinks` 的"聚合与合法性判定之后"**（`FlowCanvasViewModel.cs:1313-1332`）：
  - 同一对（生产方, 消费方）的多条端口绑定先在 `byPair` 合并成一根线（`:1287-1309`），再把多条绑定的合法性聚合成整线判定（`:1313-1318`）；
  - 之后才过滤：`!ShowDataLinks` 时从 `Links` 尾部移除 `!IsIllegal` 的线（`:1325-1332`）；
  - 为什么不能提前：在"加进 Links"处过滤，会让"后到的非法绑定挂在一根从未渲染过的线上"——同一对模块换个绑定顺序行为就变了（代码注释 `:1320-1324` 留档）。
- **非法线例外**：`ShowDataLinks=false` 只隐藏普通数据线；`IsIllegal`（SameListReversed / CrossBranch / ProducerAfterEnclosingContainer，判定 `:1270-1275`）的红虚线**照常渲染**——它是要用户去修的错误提示，不是噪声。`Illegal/Deferred/Hidden` 计数在过滤之前统计完毕（`:1188-1190`、`:1245-1247`、`:1263-1265`），警告条（`WarningVisibility`）同样不受开关影响。
- **工具条**：「数据线」CheckBox 加在「顺序链」**左侧**（`FlowCanvasView.xaml:668-680`），ToolTip 注明"非法连线始终显示"。
- **顶部提示行**改为「拖动模块排序 · 双击/右键开参数 · 圆点拖线连接 · 数据线默认隐藏」（`FlowCanvasView.xaml:656-661`）。

## 八、本批钉死的口径（守门点）

1. **数据线开关只关"普通线"**：非法线（红虚线）+ `Illegal/Deferred/Hidden` 计数 + 警告条 = 错误提示通道，任何开关都不得吞掉（X2 守门）。
2. **过滤必须晚于"聚合 + 合法性判定"**：同一对模块的多条绑定先合并成一根线、再按整线判定决定画不画——提前过滤是顺序敏感陷阱（代码注释 + 本记录留档）。
3. **画布"开参数"三入口（双击 / 节点右键 / 流程栏）共用 `StepParameterDialog` 分派**，不各自造入口；headless 无宿主 = 静默空跑。
4. **工具箱 → 步骤模型只经 `StepFactory` 一份**：类型分派与命名口径单点，流程栏 Drop 与画布 Drop 不再各抄一份。
5. **双击豁免按元素身份**（模板内 x:Name / 类型），不按 ToolTip 文案——文案会随主题改，改名坏掉最坏退回"双击开窗"，而不是静默吃掉折叠钮/连接点。
6. **画布拖入不撤销 = 与流程栏 Drop 同口径**（如将来要补，两边一起改）。

## 九、未决与已知限制（如实登记）

1. **真机交互未验**：本环境无法合成 OLE `DragEventArgs` 与真实双击手势——工具箱拖入只验到 VM 级（`DropToolAt`/`FindDeepestContainerAt` 断言）+ XAML 事件接线；**双击是否被 Nodify `ItemContainer` 的鼠标处理吃掉，需真机点一次**（探针把"命中路由"钉在真实现场图上，但那是反射直调，不等于真手势）。
2. **画布拖入无撤销**（口径同流程栏 Drop）；若要补，需设计"外部 Add"的时序（现由 `OnFlowStepsChanged` 区分内部写回，`FlowCanvasViewModel.cs:506-513`）。
3. **运行锁口径不对称**：画布新增入口（双击 / 右键模块参数 / 拖入）与既有画布节点菜单（编辑绑定 / 删除 / 禁用）一致，**不查运行态**（`FlowCanvasViewModel.cs` 全篇无运行态判据）；流程栏一侧有运行锁（`ProcessViewModel.cs:123-133`、`:306-307`）。统一属跨角色口径决策，未擅自扩面。
4. **数据线隐藏时端口连通点仍亮**（隐藏的是线，不是绑定状态）；若要"端口也随数据线一起熄灭"，改 `BuildLinks` 两处 `IsConnected` 赋值点即可（`FlowCanvasViewModel.cs:1305-1306`）。
5. **折叠容器参与落点命中已实现**（`FindDeepestContainerAt` 用含折叠态框的 `_frameRects`），但断言只覆盖展开态"最深容器"，折叠态未单独断言。
6. **并发编辑提示**：本批期间另有会话在改 `Core\Engine` 与 Case 分支（`BuiltIn_Case → CaseStep`、`CaseBranchChecks.cs`；`StepFactory.cs:41-43` 的 Case 分支即其后加）——本记录只记画布这条线，不涉及对方改动。
7. **"+30"口径未逐条对账**：见 §7.1（本记录按可指认的 27 条记）。
8. **码读取段 HALCON 混合图 QR 断言不稳定**：同一产物两次复跑 1 红 1 绿（见 §7.4），失败样本 `Count=0`；建议后续观察是否与 HALCON 官方样张/解码器环境波动相关，与本批无关。
