## 一、V3 交付内容

### 1.1 服务层

`VisionMaster/Services/RecipeService.cs` 新增：

| API | 语义 |
| --- | --- |
| `GetCandidates(Guid? recipeId)` | 列出可加入配方的参数：步骤参数 + 本地变量；排除已加入、已链接、隐藏、路径/模型/展示类、不支持类型、触发源变量 |
| `AddEntry(recipeId, kind, targetId, key)` | 把**当前值**加入配方；不改目标当前值；`ContentVersion++`；审计 |
| `RemoveEntry(recipeId, kind, targetId, key)` | 只删除配方定义；不改目标当前值；`ContentVersion++`；审计 |
| `Preview(recipeId)` | 应用前预览：`CanApply` / `Total` / `Modified` / `Unchanged` / `Errors` / `Warnings` + 逐条差异 + 预检报告 |

规则：
- 候选/添加都复用捕获时的白名单与类型校验；触发源变量、网络变量、链接端口、路径/模型类一律不出现。
- `Preview` 复用 `Validate` + `Compare`；预检有错误时 `CanApply=false`，UI 确认按钮禁用。
- 真正应用仍走 `Apply`，会再次全量预检；预览与确认之间即使有改动也不会半应用。

### 1.2 界面

`VisionMaster/Views/DialogViews/RecipeManagerView.xaml` + `RecipeManagerViewModel.cs`：

- 右侧新增「可添加参数」下拉 +「添加参数」按钮；选中候选后加入当前配方。
- 参数表支持选中行 +「删除参数」按钮（危险色）。
- 「应用 / 应用并保存」不再直接写入，先弹出**应用确认层**：
  - 差异摘要：`共 N 条 · 修改 M · 不变 U · 错误 E · 警告 W`
  - 逐条对照 DataGrid：目标 / 参数 / 当前值 / 配方值 / 状态
  - 「确认应用」/「取消」；预检有错误时确认按钮禁用
  - 确认后才调用 `RecipeService.Apply`；应用并保存再走 `RecipeSaveCoordinator`
- 切换配方会取消未确认的预览。

### 1.3 断言

`RecipeChecks/Program.cs` 从 77 条扩到 **89 条**，新增：
- 候选不包含已加入的 `Mode`、不包含触发源变量。
- 删除参数后 `ContentVersion` 递增、`Mode` 重新出现在候选。
- 重新添加 `Mode` 成功、重复添加被拒。
- 预览可应用 / 总条数=6 / 无错误。
- 改一个值后预览修改数=1。
- 链接端口后预览错误>0 且 `CanApply=false`。
