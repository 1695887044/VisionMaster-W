# SCADA 运行态 Web 客户端 M0.1 整改（2026-10-21）

> 范围：M0.1 复评指出的**契约 / 矩阵冲突**整改，把方案修到 v1.4、测试矩阵修到 v1.3，并建立/追加结果台账。
> 本轮**包含代码改动**（不是"只改文档"）：`ScadaRuntimeHost` 的 `AbortStart` / `TryGetCurrent`、`ScadaAuditWriter` 的 `_writeGate`、`ScadaUserStore` 的 `ResetPassword` CAS 与 `TryValidate` 复核、`ScadaWebModule` 的 `_registered` / `_initialized`、`ScadaWebModuleLoader` 的 `Prism*` 拒绝、`pack.ps1` 的 3c 校验，以及 `ScadaChecks` 的 RH10–RH18 / ML1–ML6 / UC16–UC18c 断言。M0.1 的初批（状态机、审计出口、账号锁、加载器）同样是本系列的代码产物，本记录给出锚点与证据。
> 上位纪律：`AGENTS.md` R38（跳过型断言必须能被反证）、R65（改断言宿主后不许 `--no-build`）、R42/R62（增量构建与不在 sln 里的工程会静默漏打包）；方案 §17（M0 门禁状态唯一来源）。

---

## 1. 背景

M0 的三个探针（`_WebProbe1/2/3`）已执行，但四角色评审 4/4 FAIL，M0 门禁未通过。M0.1 复评在"四条 blocking"之外又抓出一批**两份文档互相打架、或文档与代码打架**的条目：`RunStarted`/`RunStopped` 的抛出时机与签名、`/img` 的鉴权凭据、`AllOperators` 没有可执行的监管开关、容量与阈值三处不一致、`pageVersion` 跨页比较必然失败、负面用例的前置条件在协议上不成立、审计计数口径混用、M1 视觉闸门漏 DP、E26 的 256 超出合法范围、O02 与 R04 互相矛盾、§15 改动清单与实现脱节、§5.4 配置键写错。

这些问题的共同后果是：**实现按文档写会写出静默故障**（配置键被忽略、前缀拼两遍、跨页版本误判、图片 URL 变成可转发凭据），而编译期全绿。
