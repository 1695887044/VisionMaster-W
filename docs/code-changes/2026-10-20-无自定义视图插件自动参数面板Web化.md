## 功能契约保留

- `AutoPortConfigView` 仍实现 `IPluginConfigView`；构造签名 `(IVisionPlugin)` 不变。
- `Initialize(IStepConfigData)` 仍幂等：端口集合/顺序不变时复用现有行，变化时才清空重建；端口仍取 `_plugin.Inputs.Values` 并按 `Name` 排序。
- `OnConfirm` 仍委托 `_plugin.OnConfirm(stepData)`；`OnCancel` 仍委托 `_plugin.OnCancel()`。
- `OnLoaded` 仍设置 `Width=560`、`SizeToContent.Height`、`MinHeight=180`、`MaxHeight=760`；新增 `MinWidth=560` 抵消 `PluginConfigShellView` 的 640 保底宽度。
- `LinkableValueEditor` 仍是唯一编辑入口；`Port` / `StepData` / 链接 / 清除行为未改；共享控件未改。
- `PluginConfigShellView` 的头部 / 页脚 / 执行 / 取消 / 确认 / 状态文案未改。

## 与设计稿的已知差异

1. 链接态：WPF 用 `EditorShell` 浅主色底 + 描边，内部仍是 `LinkableValueEditor` 的蓝色下划线只读地址（未改共享控件）。
2. 需链接变量：WPF 用 `EditorShell` 浅灰底 + 实线描边，内部仍是 `PART_Placeholder` 文本 + 行尾链接按钮（WPF `Border` 无虚线）。
3. 字体度量、滚动条宽度、阴影层数按平台差异处理。
4. 布尔端口仍是文本框（显示 `True/False`），未做开关（D2）。
5. Step 区只读概览；`[StepConfig]` 属性编辑仍延后（D1）。
6. 端口集合变化时仍会重建行；`LinkableValueEditor` 没有卸载退订入口。`Initialize` 在端口集合/顺序不变时复用现有行，避免外壳与视图各调一次造成订阅累积；动态端口插件均有自定义视图，不走本面板。
