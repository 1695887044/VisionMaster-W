# Shell 四模式隔离（文档 / 面板 / 状态栏）

- 日期：2026-10-20
- 范围：`ShellViewModel.cs`、`Services/LayoutHelper.cs`、`Shell.xaml`、`UIThemeSmokeTest/Program.cs`
- 设计依据：`docs/UI设计基线/app-shell/design.html` 的“模式隔离”矩阵
- 目标：第 3 步——主布局与模式隔离；**不改 AvalonDock 面板归属/停靠结构**

## 改动清单

### 1. 模式模型

- `VisionMaster/ShellViewModel.cs`
  - 新增 `ShellMode` 枚举：`Debug / Run / Config / Free`。
  - 新增 `CurrentMode`（默认 `Debug`）与 `SetShellModeCommand`（参数 `Debug/Run/Config/Free`）。
  - `SetShellMode` 设置模式后调用 `LayoutHelper.ApplyShellMode`；用 `_applyingShellMode` 防递归。
  - `ApplyPanelMode` 改为按模式收敛：
    - 调试/运行/组态：直接走 `ApplyShellMode`；
    - 自由：始终保留全部面板（不再跟随“选中组态文档”收起算子工具箱）；
    - 增加 `LayoutHelper.IsApplyingShellMode` 让路，避免文档选中监听在收敛过程中递归。

### 2. 文档与面板收敛

- `VisionMaster/Services/LayoutHelper.cs`
  - 新增 `ApplyShellMode(manager, mode)`：
    | 模式 | 文档 | 左栏 | 右栏 | 底部 |
    | --- | --- | --- | --- | --- |
    | 调试 | 视觉图像 + 流程画布 | 流程导航 | 工具箱 | 日志恢复 |
    | 运行 | 运行驾驶舱 | 隐藏 | 隐藏 | 日志恢复 |
    | 组态 | 仅组态画面 | 隐藏 | 属性/图层/图元 | 日志收 1px |
    | 自由 | 全部 | 显示 | 全部 | 日志恢复 |
  - 文档不能走 `HidePanel`（它只处理 anchorable），新增 `HideDocument / RestoreDocument`：
    - 非当前模式文档从 `LayoutDocumentPane.Children` 摘出，按 `ContentId` 缓存原 pane + 原索引；
    - 切回允许该文档的模式时按原位置放回；pane 已失效则挂到第一个文档 pane。
  - `SaveToString` 在序列化前 `RestoreAllDocuments`，序列化后按 `_currentShellMode` 重新收敛文档——避免在组态模式退出时写出“只有组态画面”的 `Layout.xml`（下次启动会被覆盖度闸门拒绝，误伤用户布局）。
  - `LoadFromString` 只在反序列化**成功之后**清空隐藏文档缓存（版本闸门/反序列化失败时保留缓存，否则旧布局被拒会丢组态/驾驶舱文档）。
  - `IsApplyingShellMode` 标记收敛进行中，供 ShellViewModel 的文档选中监听让路。

### 3. 标题栏模式切换 + 状态栏

- `VisionMaster/Shell.xaml`
  - 标题栏文件操作后新增 `调试 / 运行 / 组态 / 自由` 四个分段按钮（`ModeButtonDebug/Run/Config/Free`），选中态用对应 soft/text 令牌。
  - 新增 `Ctrl+1..4` 快捷键绑定到 `SetShellModeCommand`。
  - 组态模式状态栏：隐藏流程运行状态组，显示“组态设计 · 1280×800 · 网格 20px · 选中图元”（当前为静态摘要，页面/缩放/选中图元后续接 ScadaEditor VM）。
  - 模式按钮颜色全部走 `LogicIf*/LogicFor*/LogicWhile*` 与 `Dialog*` 令牌，无新增硬编码颜色。

### 4. 断言

- `UIThemeSmokeTest/Program.cs`
  - 新增 `RunShellModeChecks()`，5 条：
    1. 调试：文档仅视觉图像/流程画布；
    2. 调试：左栏 + 工具箱可见，组态三面板隐藏；
    3. 组态：文档仅组态画面；左栏隐藏、组态三面板可见、算子工具箱隐藏；
    4. 组态：底部日志 1px；
    5. 运行：文档仅运行驾驶舱、左右栏隐藏；自由：四文档全部恢复、面板全部可见。
  - `Main` 返回码加入 `shellModeFailures`。

## 验证证据

- `dotnet build VisionMaster\VisionMaster.csproj`：**0 错误**。
- `UIThemeSmokeTest`：
  - 多格布局 / Shell 布局结构 / Panel 模式 / **Shell 模式隔离** / GridView / LogConsole **全部通过**。
- 模式断言在 ShellCopy 的真实 `DockingManager` 上跑，验证的是可见性矩阵与文档摘出/恢复，不是源码静态扫描。

## 已知边界 / 后续

1. **运行模式不是完整驾驶舱**：本轮只做“文档仅视觉图像 + 左右栏隐藏 + 日志恢复”，深色驾驶舱、KPI 条、大号停止按钮仍属于后续视觉批次。
2. **组态状态栏是静态摘要**：页面尺寸/缩放/网格/选中图元尚未绑定到 `ScadaEditorView`/`ScadaDocument`；当前只保证不显示流程运行态。
3. **文档隐藏方式**：通过从 `LayoutDocumentPane.Children` 摘出并缓存；用户把文档拖成浮动窗/拆分到第二个文档窗格时，模式收敛只处理主 pane，浮动文档可能仍显示。后续若需要严格隔离，需按 `EnumerateContents` 的 floating windows 一并处理。
4. **模式不持久化**：`CurrentMode` 默认 `Debug`，重启后回到调试；若要记住上次模式，需写入 AppConfig/方案配置并决定“布局恢复”的优先级。
5. **R43 版本沿革**：本轮先因新增 `Panel_RunCockpitView` 递增到 5；随后 2026-10-20 结构合并（程序面板并入流程导航、右侧三列收成单列检查器）递增到 **6**，旧 `Layout.xml` 会被结构版本闸门拒绝并回退默认布局。
6. **ShellCopy 未同步标题栏/状态栏**：R44 的同步要求针对 docking 子树；ShellCopy 有意剥掉了标题栏命令与输入绑定。若后续把模式按钮纳入冒烟结构，需同时补 ShellCopy 的 `shell` 命名空间与样式。
