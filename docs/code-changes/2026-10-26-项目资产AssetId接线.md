# 项目资产 AssetId 插件接线（模板 / 模型）

## 当前状态

- 项目资产页已能把方案级模板/模型/图像资产导入并落到方案目录。
- 本轮把 **AssetId 解析**接进插件运行期：
  - `MatchingPlugin.TemplateAssetId`（template）
  - `OcrPlugin.ModelAssetId`（model）
  - `YoloPlugin.ModelAssetId`（model）
  - `DlAnomalyPlugin.ModelAssetId`（model）
  - `DlClassifyPlugin.ModelAssetId`（model）
  - `DlSegmentPlugin.ModelAssetId`（model）
- `AssetId` 非空时优先于旧的 `ModelPath` / `TemplateLibraryJson`；为空时保留旧路径行为。
- 资产页引用扫描也改为 **AssetId 优先**，没有 Id 才按路径/名称回退。

## 已做

1. **契约**
   - `Shard/Core.Interfaces/Assets/ProjectAssetResolver.cs`：
     - `IProjectAssetResolver`
     - `ProjectAssetRef`（Kind / Name / RelativePath / AbsolutePath / ContentHash / Version）
     - `NullProjectAssetResolver`
     - `ProjectAssetPathResolver`（AssetId 优先、旧路径回退的共用口径）
   - `IExecutionContext.Assets` 默认属性；`ExecutionContext.Assets` 从当前方案懒建。
   - `Core/Services/SolutionProjectAssetResolver.cs`：按 Id 在标定/配方/模板/模型/图像集合中查找，文件资产返回绝对路径并校验不越出方案目录。
2. **插件**
   - Matching：`TemplateAssetId` 解析模板库 JSON 文件；文件必须是 `MatchingTemplateEntry[]`。
   - OCR：`ModelAssetId` 解析模型文件后交给 `OcrEngine.TryResolveModel`。
   - YOLO / DL 异常 / 分类 / 分割：运行期把 AssetId 解析成绝对路径，`EnsureSession` 优先使用；配置预览无上下文时回退 `ModelPath`。
3. **资产页**
   - `SolutionProjectAssetCatalog` 的模板/模型引用扫描：先看 `TemplateAssetId` / `ModelAssetId`，再看旧路径/名称。
4. **文档**
   - `docs/方案设计/AI生成VMS文件指南.md` 已补：
     - `Assets\Templates` / `Assets\Models` 目录；
     - `TemplateAssets` / `ModelAssets` / `ImageAssets` schema；
     - 插件 `TemplateAssetId` / `ModelAssetId` 示例与优先级；
     - 生成自检（AssetId 稳定、相对路径、文件存在、类型匹配）。

## 未做 / 已知限制

- **插件配置界面还没有资产下拉选择器**：字段是 `[StepConfig]`，当前需要从资产页复制 Id 或直接写 `.vms`；下一步在 `PluginConfigShellView` 增加统一资产选择器。
- 模板资产目前只接受 Matching 模板库 JSON；任意 `.shm/.ncm` 文件需要模板条目元数据，暂不直接支持。
- 配方资产 Id 还没有接进 `BeadInspect`（当前仍是内嵌 `RecipeLibraryJson`）。
- 图像采集步骤仍按 `FilePath`，没有 `ImageAssetId`；资产页只做派生展示。
- 旧路径回退保留，便于没有 AssetId 的现有步骤继续运行。
