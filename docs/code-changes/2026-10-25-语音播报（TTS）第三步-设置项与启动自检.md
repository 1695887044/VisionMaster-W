# 语音播报（TTS）第三步：设置项 + 启动自检 + 顶栏静音联动

日期：2026-10-25　状态：**已实现，编译通过（VisionMaster 0 错误），ScadaChecks 3034 通过 / 0 失败**

## 已做

1. **配置项**（`Core/Models/AppConfigModel.cs`）：`SpeechEnabled`（默认 true）、`SpeechRate`（-10~10）、`SpeechVoice`（空 = 系统默认）、`SpeechMinSeverity`（Info/Warning/Critical，默认 Warning）。
2. **设置界面**：`SystemSettingsDraft` 新增第 7 组「语音播报」四项（开关 / 语速 / 音色 / 报警播报最低级别），正文由 `CardPropertyGrid` 反射生成，**视图 XAML 一行未动**。`ScadaSystemSettingsViewModel` 补了读取、校验（语速整数）、变更审计（真变了才列）、写回四段。
3. **启动自检**：`App.OnInitialized` 新增 `RunSpeechCheckInBackground()`——后台查 `SapiSpeechEngine.Voices`，没有就落一行 Warn 指向系统语音设置，有就记一行 Info（数量与名字）。只报不拦，不进启动链（R57）。
4. **顶栏静音联动**：`ScadaMonitoringHost` 订阅 `ScadaSoundAlarmService.StateChanged`，`_announcer.Enabled = 配置开关 && !tone.IsMuted`；会话结束时解绑。紧急级报警仍不可静音（由声音服务原有的 `Mute()` 拒绝逻辑决定，播报侧不重复实现）。
5. **音色兜底**：配置里的音色本机没有时落一条 Warn 并沿用系统默认（`SelectVoice` 自身是静默忽略的）。
