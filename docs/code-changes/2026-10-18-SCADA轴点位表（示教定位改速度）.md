## 1. 用户裁定

> 「可以改，有足够的权限就可以改。」

所以运行期**允许**示教（写当前位置）与改速度；前提是操作者权限达到图元的 `RequiredRole`。
权限判定发生在**按下之前**（`AccessPolicy.CanOperate`），不通过就整块入口灰掉并给原因——
不是"按下去才发现没权限"。

## 3. 数据流

```
MotionDescriptor.Points（方案里的活对象，16 行/轴）
      │  MotionStatePublisher.TryGetPoints（现读，不缓存）
      ▼
IScadaAxisSource.TryGetPoints → AxisPointTableElement.Rows
      │
      ├─ 示教 → IScadaAxisCommandSink.TryTeach(axisId, index, 当前位置, 行速度)
      ├─ 定位 → IScadaAxisCommandSink.TryMove(axisId, 行位置, 行速度)
      └─ 改速度 → IScadaAxisCommandSink.TrySetPointSpeed(axisId, index, 新速度)
                        │
                        ▼
             MotionActionExecutor（与动作表同一个实例）
             · 定位走 CheckMove（软限位/使能/回零/忙）
             · 示教/改速度直接写 Points（随方案保存落盘）
```

## 4. 三条口径

1. **示教写的是"当前轴位置"**，不是行上原来的位置；速度用行上的值。
   所以示教前必须能读到有效快照（`ScadaAxisSample.IsValid`），离线时明确拒绝。
2. **定位走与动作表「轴绝对定位」同一条路径**：门禁、软限位、未使能、未回零、忙全部一致。
3. **运行期改配置不进撤销栈**：与变量改名级联同一口径——它不是设计期编辑，
   写的是方案活对象，随保存落盘。

## 5. 权限

| 位置 | 判据 |
| --- | --- |
| 按钮可用性 | `CanOperate` = 有命令出口 + 有选中轴 + `AccessPolicy.CanOperate(Element.RequiredRole)` |
| 行内速度框 | `CanEdit` = `CanOperate && ShowCommands`（关掉入口后变只读） |
| 命令执行前 | `CheckCanRun` 再判一次（防止命令被直接调用绕过按钮） |

`RequiredRole` 默认 null（不限制）；要"只有工程师能示教"，在属性面板把该图元的「操作权限」设成工程师。

## 7. 未决

1. **示教不校验软限位**：它记录的是轴当前所在位置；若当前位置本身在软限位外，
   后续「定位」会被门禁拒绝。是否要在示教时就提示，待现场反馈。
2. **点位名不可改**：本批只做示教/定位/改速度；改名仍走「运动卡设置 → 点位列表」。
3. **固定 16 行**：与 `MotionPointExtensions.PointsPerAxis` 一致，不支持增删（现场用点位号沟通）。
4. **真机未验证**：滚动列表在 16 行下的观感、行内速度框的输入手感。
5. **权限粒度**：目前是"整个点位表一个 RequiredRole"；若将来要"示教要工程师、定位只要操作员"，
   需要拆成两个权限位（本批没做，避免把权限模型复杂化）。
6. **外部改点位已支持自动刷新**：点位是配置、`List<MotionPoint>` 不是可观察集合，
   所以表在节拍里**每拍重读**一次，靠指纹（轴 Id + 每行 序号/名字/位置/速度）短路——
   没变时连行对象都不重建（不打断正在输入的速度框），变了才重建。
   所以「运动卡设置 → 点位列表」里改完，运行中的表下一拍（≤200ms）就能看到。
7. **参数设置与点位改名按用户裁定不做**：它们属于配置项，继续在「运动卡设置」里改。
