## 3. 关键缺陷与修法（均为生成器代码缺陷）

1. **步骤集合被整体塞入**：`steps.Add(initGrade)` 让 `JArray` 变成嵌套数组，反序列化直接抛
   `Cannot deserialize the current JSON array ... into type 'VisionMaster.Models.StepModel'`。
   修法 → `AddRange(steps, ...)`。**重写步骤序列后必须核对步骤总数**（本次曾误删 5 个步骤）。
2. **缺变量声明**：`AddIncVar(...,"CycleCount")` 使用了 `BuildVariables()` 里并不存在的 `CycleCount`。
   修法 → 在 `BuildBgaVariables()` 补 `Var("CycleCount", T_INT, ...)`。
3. **端口名错配（最易复发）**：辅助函数里抄来的链接键/端口名与插件真实声明不一致。
   - `CreateRoi` / `ImageDiff` 都**没有** `Image` 输出；`BlobDetect` **没有** `FollowedRegion`。
   - 正确端口见上表，出处：`CreateRoiPlugin.cs:61`、`ImageDiffPlugin.cs:55`、`BlobDetectPlugin.cs:85,88`。
   - **纪律：用任何链接键/端口名前，先 grep 插件源码的 `OutputPort`/`InputPort` 声明。**
4. **对象建了但没入数组**：`ngCmp` 已创建却漏了 `steps.Add(ngCmp)`，`IfStep` 因此连到不存在的上游，
   报 `[致命断连] 引用的上游节点不存在`。诊断手法：反序列化 `.vms` 按 `StepName` 搜，找不到即"没入数组"。
