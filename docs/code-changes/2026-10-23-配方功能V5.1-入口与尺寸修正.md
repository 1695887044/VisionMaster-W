## 一、改了什么

### 1.1 入口落点

**问题**：配方入口原先是一个带状态文字的按钮，放在标题栏**中央**、紧挨方案名。
那里是"当前方案是谁"的身份区，不是命令区；与顶栏右侧的全局变量/硬件管理也不在一处。

**修正**（`VisionMaster/Shell.xaml`）：
- 中央方案名右侧的配方 chip **删除**。
- 顶栏全局命令区（全局变量 / 硬件管理之后）新增配方图标按钮，绑定 `Recipe.OpenManagerCommand`，
  工具提示仍显示当前配方状态（`Recipe.ChipToolTip`）。
- 「系统」菜单新增「配方管理」项（与全局变量/硬件管理同组），菜单组说明改为
  「用户、变量、配方与硬件设置」。
- `UIThemeSmokeTest/ShellCopy.xaml` 同步（R44）：删 chip、补图标按钮与菜单项。

### 1.2 弹窗尺寸

**问题**：`RecipeManagerView` 只设了 `MinWidth/MinHeight`，Prism 的 DialogWindow 默认按内容自适应，
右侧 DataGrid 的星号列在"无行"时跟着窗口一起撑开 → 打开即接近全屏、大片空白。

**修正**（`VisionMaster/Views/DialogViews/RecipeManagerView.xaml`）：
- 显式 `Width=1100` / `Height=720` / `MinWidth=1000` / `MinHeight=640`。
- `SizeToContent=Manual`，`ResizeMode=CanResizeWithGrip`。
- **踩坑**：`WindowStartupLocation` 不是依赖属性，写进 `Style Setter` 会在 XAML 解析期抛
  `ArgumentNullException: Value cannot be null (Parameter 'property')`，表现为"点入口没反应"。
  已删除该 Setter；Prism 的 DialogWindow 默认就是 CenterOwner。
- 窗框改为全仓统一的自绘标题栏：`WindowStyle=None` + `AllowsTransparency` +
  `ui:WindowDragBehavior.IsWindowDraggable`（FlowCanvasChecks 的【窗框】两条由红转绿）。

### 1.3 内部排版

- 右侧行序：标题(64) → **参数工具栏(Auto)** → **表格(*)** → 重命名行(Auto) → 状态(Auto) → 页脚(56)。
  之前只改了 `Grid.Row` 没同步 `RowDefinition.Height`，症状是"工具栏被拉成一整屏、表格挤到底部"；
  本次把两处一起改并写了注释。
- 「删除参数」从底部重命名行移到参数工具栏，与「添加参数」同处；重命名行只留「重命名 / 清除生效」。
- 左侧捕获表单补三行标签：配方名称 / 产品编码（可空）/ 备注（可空）。
