### 1.3 关键设计

1. **令牌层带 `Dialog` 前缀**。因为 `CardBorder` / `CardTitle` / `PrimaryButton` 已被 8 个插件视图各自本地定义，共享层若用同名键会被「就近覆盖」，所以共享层的 22 个画刷 / 颜色令牌 + 35 支样式**一律 `Dialog` 前缀**，杜绝撞名。
2. **共享字典里绝不写隐式样式**。[DefaultStyle.xaml](file:///e:/VM/VisionMaster-W-master/UI/Controls/Themes/DefaultStyle.xaml#L1936) 已存在全局隐式 `<Style TargetType="DataGrid">`；[DefaultStyle.xaml](file:///e:/VM/VisionMaster-W-master/UI/Controls/Themes/DefaultStyle.xaml#L27) 起还有全局隐式 `<Style TargetType="TextBox">`（自定义 `ControlTemplate` + 聚焦下划线动画）。因此 `DialogStyles.xaml` 里 DataGrid 系列**全部带 `x:Key`**，各视图必须**显式**写 `Style="{StaticResource DialogDataGrid}"`；表格内联输入框则自带完整 `ControlTemplate`（`DialogGridInput`），避免被全局隐式 TextBox 模板静默改脸。
3. **卡片「投影层 / 内容层」分离**。`DropShadowEffect` 不挂在承载文字的 `Border` 上（会导致文字失去 ClearType 抗锯齿），改为 `DialogCardShadow`（空 `Border` 只承载投影）+ `DialogCardBorder`（真实内容）叠放两层。
4. **青蓝主色 `#0EA5E9`** 统一了原来的 `#17A2F2` 与 `#409EFF` 两种蓝，配套 `DialogAccentDarkBrush #0284C7` / `DialogAccentLightBrush #E0F2FE` / `DialogAccentSoftBrush #F0F9FF`。
5. **B6 错误可见**：`CommunicationConfig` 新增 `[JsonIgnore] LastError` / `HasError` / `ClearLastError()`；`AdvancedCommunicationManager` 在后台线程写错误时经 `SafeDispatch.BeginInvoke` 封送回 UI 线程；`Connected` 分支清空错误。视图层用 `DialogStatusPillTemplate`（胶囊 + ToolTip + 错误时 ⚠）。
6. **B3 批量操作**：新增 attached behavior `DataGridSelectionBehavior.BindableSelectedItems` 把只读的 `SelectedItems` 暴露为可绑定集合；VM 补 `SelectedCount` / `HasSelection` / `SelectedConfigs` + 13 个命令。注意 `int` 不能直接绑 `IsEnabled`，故派生 `HasSelection`。
7. **保留业务不变式**：扫描组编辑器的拖拽排序手柄、诊断进度条轨道宽 `BarTrackWidth = 90`（VM 内 `private const`，与 XAML 进度条容器宽度必须一致）、`StatusColor` 分档色（在 C# 内、属阈值语义）全部原样保留。

### 1.4 措辞 / 细节陷阱（本次踩到并已处理）

| 陷阱 | 说明 | 处置 |
| --- | --- | --- |
| `Border` 的 `Background` 为 `{x:Null}` 时整块不参与命中测试 | 自绘标题栏要 `ui:WindowDragBehavior.IsWindowDraggable` 生效，必须显式 `Background="Transparent"`，否则只在文字上拖得动 | 新版显式写 `Background="Transparent"` 并把原因写进注释 |
| 横向 `StackPanel` 不给子项宽度约束 ⇒ 里面的 `TextWrapping` 失效 | 口径提示整句会向右溢出卡片 | 改成两列 `Grid`（`Auto` 图标 + `*` 正文） |
| `StaticResource` 不允许前向引用 | `DialogDataGridColumnHeader` 必须先于 `DialogDataGrid` 定义 | 已遵守定义顺序 |

| ComboBox 热区只有箭头 | 需要把边框 / 底纹 / 箭头全画进 `ToggleButton` 模板（`x:Name="Chrome"`），选中项用 `ContentPresenter` + `SelectionBoxItemTemplate` 叠上层并 `IsHitTestVisible=False` | `DialogCombo` / `DialogComboInGroup` 按此实现，且**不能用 `DisplayMemberPath`** |

## 5. 已知边界

1. **三支弹窗的 UI 行为没有断言宿主**。`CommChecks` / `ScadaChecks` 覆盖的是数据契约与逻辑，XAML 视觉行为（跳色、拖拽、图标字形）**必须实机点验**。
2. **三个新图标码位未验证字体**：`&#xf05a;`（口径提示 info-circle）、`&#xf201;`（诊断标题 chart-line）、`&#xf0e4;`（诊断空态 tachometer）在全仓此前**零使用**，若 `Icon` 字体缺这些码位会渲染成缺字方框。实机若见方框，需换成已用过的码位（如 `f05a → f0c1`、`f201 → f080`）。
3. **`StatusColor` 分档色刻意不走令牌**：`ScanGroupStatRow.StatusColor` 的值在 VM（C#）内，属「未测 / ≥90% / 70~90% / <70%」阈值语义，不是主题色，因此保持 `{Binding StatusColor}` 原样；`BarTrackWidth = 90` 与 XAML 进度条容器宽度必须继续一致（已互相加注释提醒）。
4. **质量色（Good / Uncertain / Bad）同样不走 Dialog 令牌**：`#FF67C23A` / `#FFE6A23C` / `#FFC0C4CC` / `#FF909399` 是全项目约定，`ScadaChecks` 内有断言，改动会破断言。
5. **写超时 `SendTimeOut` 未映射**（本次只做了读超时 → `ReceiveTimeOut`）。若后续需要，属于独立改动。
6. **`ScanGroupEditorViewModel.CancelCommand` 未 `_statsTimer.Stop()`**（承前提出，未定论）。
7. **未做的增强**：B1 配置导入导出、B2 变量批量导入、B4 连接级变量数列、C2 `Configs` 改只读、C3 改名被拒时只回滚名字、连通测试改由一次轻量读判定设备活性。
