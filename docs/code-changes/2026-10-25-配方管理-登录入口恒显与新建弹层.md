# 配方管理：登录入口恒显 + 新建配方改为弹层手动勾选（2026-10-25）

## 一、起因（用户三条诉求）

| # | 用户原话 / 观察 | 落到代码里是什么 |
|---|---|---|
| 1 | 「配方管理这个登录按钮是不是没做好」→ 后续确认「**我点击新建没反应**」 | 空方案时左栏底部整块被 `ShowEmptyState` 收起，`IsCapturing` 打开的表单被父级吞掉，点了什么都看不见 |
| 2 | 「正常配方哪里所有所有参数，导入后还要一个一个地删除」 | `RecipeService.Capture` 只有全量重载，没有"只捕获勾选项"的能力 |
| 3 | 「已登录也保留一个『切换用户』按钮」（m01519 选定） | 权限条 `Visibility` 绑 `ShowPermissionBanner = !IsLoggedIn`，已登录时整条消失，没有任何换用户的入口 |
| — | 「默认全不勾、必须自己点」（m01080 拍板） | 候选表初始不预勾任何项，零勾选时创建按钮必须灰 |

另有一条**真缺陷**在排查中发现：宿主把登录出口传进来后存而不调（`RecipeViewModel._requestLogin` 只写不读、`ShowLoginDialog()` 全仓零调用），导致即使未登录，点「登录」也弹不出窗。

## 二、改动清单

### 1. `VisionMaster/ViewModels/RecipeViewModel.cs`

`RegisterLoginEntry` 由"只写不读"改为真正包一层：

```csharp
private void RegisterLoginEntry(Action request)
    => _requestLogin = () =>
    {
        ShowLoginDialog();   // 弹 ScadaLoginView + Refresh()
        request();           // 宿主原本想要的收尾刷新
    };
```

### 2. `VisionMaster/Services/RecipeService.cs`

- 新增 `CanOperate(out string error) => EnsureOperator(out error);`
- 新增 `ActorRoleName`（未登录时返回「未登录」，否则 `CurrentRole.DisplayName()`）
- `Capture(name, code, notes)` 改为转发 `CaptureCore(..., selection: null)`
- 新增重载 `Capture(name, code, notes, IReadOnlyCollection<(RecipeTargetKind Kind, Guid TargetId, string Key)> selection)`
- `CaptureCore` 在名称校验之后：`selection != null && Count == 0` → **直接失败**（消息「还没有勾选任何参数。请在候选表里勾上要存进配方的参数。」），**不静默退化成全量**
- 步骤参数循环与变量循环各加一条 `picked.Contains(...)` 过滤；`picked == null` 时短路，全量路径行为不变

### 3. `VisionMaster/ViewModels/DialogViewModels/RecipeManagerViewModel.cs`

- 权限区：`ShowLoginEntry => true`（恒显）；新增 `LoginButtonText`（未登录「登录」，已登录 `{ActorName}（{RoleLabel}）▾`）与 `LoginButtonToolTip`（无出口时说明「没有可用的登录出口（宿主未注入）…」）；新增 `RoleLabel => _service.ActorRoleName`
- `OpenCaptureCommand` 谓词由 `!IsBusy && CanEdit` 改为 `!IsBusy`，执行体走新的 `OpenCapture()`：无权限时先叫登录出口，登录后仍无权限则明确报「登录后仍没有新建配方所需的权限（需要工程师及以上）。」，**不再静默无反应**
- 新增 v2 弹层状态：`IsCreatingRecipe`、`CaptureSearchText`、`CaptureFilterIndex`、`CaptureCountText`、`CaptureCheckedCount`、`CreateRecipeButtonText`、`CaptureSelectionHint`、`ShowCaptureNoCandidates` 等
- 新增行模型 `RecipeCaptureCandidate : BindableBase`（`IsChecked` 在 `IsDisabled` 时忽略写入；`KeyText`/`TypeText`/`IsCheckedEnabled` 供 XAML 绑定）
- 新增命令：`CheckAllCaptureCommand`（只勾当前可见且可勾的）、`ClearCaptureChecksCommand`、`CreateRecipeCommand`、`CancelCreateCommand`
- `SelectedCandidate` 由自动属性改 `SetProperty`（`AddCandidateCommand` 的 CanExecute 观测它，自动属性下选中后按钮一直灰）

### 4. `VisionMaster/Views/DialogViews/RecipeManagerView.xaml`

- **权限条整块重写**：不再整体隐藏，改为「恒显 + 两面孔」——未登录黄底 + 锁图标 + 文案「当前未登录，只能查看配方…」+ 「登录」主色按钮；已登录淡底 + 人形图标 + 文案「已登录。切换配方需要操作员，新建 / 编辑 / 删除需要工程师。」+ `{ActorName}（角色）▾`
- **左栏底部去掉 `ShowEmptyState → Collapsed` 的 DataTrigger**（空方案时不再把唯一的「新建配方」入口收走）
- **删掉左栏 v1 内联卡片**（「从当前已确认的参数捕获」+ 三个输入框 + 捕获当前值/取消）：「新建配方」按钮改为恒显，点了直接开弹层，不再有"按钮消失换成表单"的两套并存
- **新增新建配方弹层**：`Grid.RowSpan="4"` 遮罩 + 860×640 卡片（照应用确认层范式），内部四段 = 标题 / 基本信息（名称·编码·备注）/ 勾选区（搜索 + 三档筛选 + 全选/清空 + 分组候选表）/ 底栏（`CaptureSelectionHint` + 取消 + `创建配方（N）`）

### 4.1 候选表布局（出图核对后迭代出来的三条硬约束）

| 约束 | 为什么 |
|---|---|
| 六列比例 `34 / 18* / 26* / 10* / 18* / 20*`，**最后一列必须是 `20*` 而不是 `*`** | 最后一列写 `*` 会被前面五个 `*` 挤到容器外，表头「说明」只剩一个"说"字 |
| `DataTemplate` 外层两行 Grid **不许写 `Height`** | 外层 `Height="32"` 会把 `Auto`（分组标题）+`32`（参数行）共 43px 裁到 32px，表现为"每组第一条参数看不见" |
| 「目标」列绑 `RecipeCaptureCandidate.TargetText`（恒空） | 目标名已由分组标题表达，每条参数再写一遍就是「匹配 / 匹配 / 匹配」三连，白占一列 |

分组行由 `RefreshCaptureGroupFlags()` 按**筛选后可见序列**重算 `IsGroupStart`（不是按完整列表的相邻关系），否则搜索/只看已勾时会出现只有一个空标题的分组。四个调用点：`CaptureSearchText` setter、`CaptureFilterIndex` setter、`OnCaptureCandidateChanged`（档位=1 时）、`BindCaptureCandidates` 末尾。

### 5. `VisionMaster/Views/DialogViews/RecipeManagerView.xaml.cs`

新增 `OnCaptureCheckCellClicked` + `IsInsideCheckBox`：勾选格整格可点（CheckBox 只有 13px、行高 32px），点在本体上则跳过避免切两次，走到 `Border` 边界即停避免顺着逻辑树爬到别的勾选框。

### 6. `tools/probes/_RecipeUiProbe/Program.cs`

- `[LoginEntry]` 无出口判据由「应隐藏」改为「**恒显且 ToolTip 有话说**」（旧期望在用户拍板换用户按钮后作废）
- `[CaptureEntry]` 整段按 v2 语义重写：弹层出现 / 默认零勾 / 零勾不可创建 / 勾 2 条创建后**落盘条目 == 勾选数** / 成功后弹层关闭
- 未登录那一跑单列判据：按钮可点 + 点下去弹登录 + 不偷摊弹层（用增量 `loginCallsBefore` 记账，不用累计值）
- 新增 `skipCaptureFlow` 参数与 `design-create.png` 场景（只出弹层图）

## 四、踩过的坑

1. **`[ScadaProperty]` 属性必须保留 `partial`**：`Scada.Controls/Elements/AxisPanelElement.cs` 里把 `JogMode` 改成非 partial → `error SPG0001`；Choice 型属性还得给 `Choices`，否则 `SPG0005`。
2. **资源键不能凭记忆写**：先后撞了 `DialogIconFontFamily`（真名 `DialogIconFont`）与 `DialogAccentSubtleBrush`（真名 `DialogAccentSoftBrush`），都是**加载期就抛 `XamlParseException`**。写完后应做一次「XAML 用到的键 vs 全仓 `x:Key`」的差集核对，差集为空再继续。
3. **探针期望要跟着设计决策一起改**：`ShowLoginEntry` 从"条件显示"改成恒显后，旧断言会红；这时要判断是**产品回归**还是**断言过期**，不能直接把断言删掉。
4. **构建被宿主进程锁**：`error MSB3027/MSB3021` 写着 `文件被"VisionMaster (39052)"锁定`，那是用户自己开着的程序，不能擅自结束——改用不重建的方式先跑，或等用户关闭。
