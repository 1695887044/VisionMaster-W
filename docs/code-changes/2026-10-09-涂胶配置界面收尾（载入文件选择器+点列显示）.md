# 2026-10-09 涂胶配置界面收尾修复（「载入」文件选择器 + 点列显示裁字/裁行）

## 一、起因（用户真机反馈，200% DPI / 视口 ≈914×547）

用户截图两问：「**这个载入是不是没有效果**」「**这个行列数据显示不全**」。

## 二、根因

### 问题一：「载入」没反应
- 全插件 grep `OpenFileDialog` **零命中**——此前没有任何文件选择器，用户在 200% 缩放窗口里要**手打完整参考图路径**再点「载入」。
- 路径为空时 `LoadRefImage()`（`BeadInspectPluginConfigView.cs:351`）只走 `:362` 写一行状态文字然后 return——就是"没反应"的观感（用户截图里路径框为空、底部状态"还没有参考图路径…"）。
- 接线本身没坏：`BeadInspectView.xaml:255 Click="OnLoadRefClick"` → `.xaml.cs` → `Plugin?.LoadRefImage()`。

### 问题二：点列"数据显示不全"
- 共享主题 `DataGridCell Padding=12,8` 是按对话框大表（`DialogDataGrid RowHeight=46`）设计的；本表 `RowHeight=24` → 内容槽 24-16=**8px**，装不下 14px 字号的一行（排版高 ≈18.6）→ 文字上下溢出被邻行吃掉 = **半截数字**（截图里 6 位小数成"半个字"）。
- 列头 `Padding=12,10` 再白吃 10px；`Height=168` 固定 → 11 个点只能露 5 行；删列按钮 20×32 超出 24 行高、溢出邻行。

## 三、修复

**问题一**（`BeadInspectView.xaml.cs:160-210` + 文案 7 处）：
- `OnLoadRefClick` 重写：路径为空或 `!File.Exists` → 弹 `OpenFileDialog`（Filter/Title 照 `Plugin.ImageAcquisition.ImageAcquisitionPlugin.BrowseFile:1131-1145` 范式；`InitialDirectory` = 路径框现有目录 → 否则 `BaseDirectory\Image\bead`）→ 选中写回 `entry.RefImagePath`（INPC 自动刷新路径框）→ `LoadRefImage()`；路径有效 → 原行为（不弹框）；取消 → 零改动。
- 新增 `public Func<string?, string?>? RefImagePicker` 实例级注入点（默认 null = 真弹框）：离屏探针/断言宿主弹不出模态框，用它走真实 Click 链路的代码级验证。**不用派生视图**——实测 XAML 根的 BAML 只能由它自己的类型 `LoadComponent`，派生类抛"组件不具有由 URI 识别的资源"。
- 文案同步 7 处 + ToolTip + 「怎么用」卡 + 画布空态提示："填路径并点载入" → "点「载入」选择参考图文件"。**学习失败横幅文案刻意压到与旧文案等长**——加长会让 914×547 横幅态画布从 300 掉到 285（多折一行），被"横幅态画布 ≥300"判据抓住，等长即回到 508×31/画布 300。

**问题二**（`BeadInspectView.xaml:126-152 / 367-403`）：
- 新增 3 个视图局部样式（全部 `BasedOn` 共享件，**不碰共享令牌**）：`BeadPointCell`（Padding 8,2）/ `BeadPointHeader`（Padding 8,4）/ `BeadPointEditBox`（EditingElementStyle，Padding 4,1 FontSize 12——主题 TextBox 自然高 35 会压住上下行）。
- DataGrid：`Height=168` → `MinHeight=140 / MaxHeight=286`（≈9 行内滚动）；`RowHeight` 24 → **28**（覆盖真机多并一层 Fluent 主题后的 14px 字号）；`#` 36→32、`Row/Col` 加 `MinWidth=84`（11 字符数值 66.2+16=82.2，余 9.6px）、删列 44→42、删按钮 MinHeight 20。
- `CellEditEnding`/`OnDeletePointRowClick`/`ItemsSource` 接线与绑定名一个没动。
