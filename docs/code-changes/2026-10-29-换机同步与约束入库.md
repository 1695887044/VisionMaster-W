## 踩过的坑

- **PowerShell 5.1 从原生进程读 stdout 按 936 解码**：`& git ls-files` 拿到的中文路径全是乱码，
  再用正常 Unicode 字符串去 `-like` 比对，`docs/工程纪律` 一度显示 `tracked=0`（假 0）。
  必须先 `[Console]::OutputEncoding = New-Object Text.UTF8Encoding($false)` 再比对。
  这是 R183「没跑和跑绿了要能分开」的同一家族：**统计口径错了，结论就是假的**。
- **cmd 单行 `set G=... & echo %G%` 不成立**：`%G%` 在整行解析时就展开，此时 `set` 还没执行。
  要么分多行，要么直接内联全路径。
- **VS 自带的 git 不在 PATH**：`D:\Program Files\Microsoft Visual Studio\2022\Community\Common7\IDE\CommonExtensions\Microsoft\TeamFoundation\Team Explorer\Git\cmd\git.exe`。
  直接 `git` 会报"不是内部或外部命令"，别据此判断"这不是 git 仓库"（ZCode 环境探测也报了 `Is a git repository: no`，同样是假阴性）。
