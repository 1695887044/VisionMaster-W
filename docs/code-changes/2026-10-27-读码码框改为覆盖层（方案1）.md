## 五、踩过的坑

1. **插件不再负责显示**：`MeasureImage` 已删除；不要再往算法插件里加 `CopyImage + PaintXld`，
   颜色/线宽属于显示层。
2. **`AnnotatedImage` 不含覆盖层**：覆盖层只画在图像窗口；要存“带框的图”需要另做
   （例如把 `OverlayContours` 也接一个渲染步骤），不要误以为 `AnnotatedImage` 带框。
3. **XLD 逐条取点**：`GetContourXld` 对“对象元组”不保证一次给出逐条数组，必须
   `CountObj + SelectObj + GetContourXld` 逐条处理；单条失败不影响其它条。
4. **`MeasureAnnotation.Polyline` 的点是 `[r1,c1,r2,c2,...]`**；少于 2 点跳过。
5. **`OverlayContours` 是固定输入**：`RebuildDynamicInputs` 只重建 `rN` 动态口，
   固定口不会掉；不要把它误加进 `Items`。
6. **帮助改动也算产物脏**：改了两个插件的 Help 后必须重建对应工程（R42/R62）。
