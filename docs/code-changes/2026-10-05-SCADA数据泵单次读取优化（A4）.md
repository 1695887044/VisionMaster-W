# SCADA 运行态数据泵：一次变化只读一次值（A4）

- 类型：性能优化（消除"逐目标重复读取"造成的 N 次全尺寸图像转换）
- 前置：A1/A2 图像采集链路整改（见 `docs/图像采集/`）
- 涉及工程：`Scada.Controls`（数据泵本体）、`ScadaChecks`（回归断言）
- 日期：2026-10-05

---

## 1. 改了什么

`ScadaRuntimeBinder.OnValueChanged`（值变化回调）原实现：

```csharp
foreach (var target in subscription.Targets)
    _dirty[target] = subscription.Handle.Value;   // ← 每个目标读一次
```

`Handle.Value` 的读取出口（`RegistryScadaValueSource.Value`）对图像变量执行**全尺寸 HImage → BitmapSource 转换**（典型 2~30MB 分配、0.07~14ms/次，量级见 A2 记录的性能表）。一个图像变量被 N 个图元绑定时，每次值变化做 **N 次**重复转换，且全部发生在 `_gate` 锁内。

改为：

```csharp
if (subscription.Targets.Count == 0)
    return;                                        // 空目标装配窗口：没有要写的地方，不为它白读

var value = subscription.Handle.Value;             // 只读一次（图像变量 = 只转一次）
foreach (var target in subscription.Targets)
    _dirty[target] = value;                        // 同一目标一帧内变多次只留最后一次
```

### 三个设计点（写下来给下一个人）

1. **读取必须留在锁内。**后进锁者读到的才是最新值——读取若挪到锁外，先读到的旧值可能后写入、盖掉后到的新值（两次变化并发时）。
2. **空目标守卫。**`GetOrAddSubscription` 先挂 handler、`BuildBinding` 后把 target 加进表——中间存在"订阅已挂、目标未挂"的极窄窗口，此时值变化会回调进来。原实现循环体为空、天然无事（但也不读值）；改法把读取提到循环外后，如果不守卫就会为空目标白读一次（图像变量 = 白做一次全尺寸转换）。跳过尾部 `QueueFlushIfDirty` 是安全的：本次没有制造脏值。
3. **不照搬 A2 的"先缩小再转"。**SCADA 画面元素显示尺寸可变、无固定上限（可全屏、可跨多显示器），缩小会在某些画面尺寸下损失清晰度。A4 只做"去重复"，不做"降分辨率"。

## 2. 验证证据

### 2.1 负向验证（断言必须能证伪）

把实现**临时改回旧写法**（逐目标读）重跑全套：

- 恰好 **1 条**失败，且正是新加的那条：`[×失败] 一次变化只读一次值 → 读取 2 次 / 两条绑定`；
- 其余 1691 条全部通过——证明断言精准、无副作用。

恢复改法后重跑：`[√通过] 一次变化只读一次值 → 读取 1 次 / 两条绑定`。

### 2.2 全量回归（常规）

`ScadaChecks`（非 stress）：**1692 通过 / 0 失败**。

新增断言位于 `[Z] 运行态数据泵` 段；`FakeValueHandle` 增加 `ValueReads` 读取计数（图像变量的读取=全尺寸转换，"一次变化一读"靠它钉住）。

### 2.3 长稳压测（--stress，含 S13-b 60 秒 soak）

全套 **1727 通过 / 0 失败**，其中长稳段数字：

| 项 | 数字 |
| --- | --- |
| 装配 | 1920×1080 / 200 图元 / 200 绑定 / 200 变量 |
| 节拍 | 目标 3000 拍（20ms × 60s），实跑 **2994 拍 = 20.04ms/拍** |
| UI | 最长停顿 47ms（< 1000ms 判据） |
| 内存 | 中途 31924KB → 终了 31741KB（±182KB） |
| 订阅 | 建表 200 → 中途 200 → 停止后 0 |

### 2.4 产物投递

`VM.Scada.Controls.dll` 三处（`Scada.Controls`、`VisionMaster`、`ScadaChecks` 的 bin）时间戳一致——宿主 bin 已更新，不是只更新了断言工程。
