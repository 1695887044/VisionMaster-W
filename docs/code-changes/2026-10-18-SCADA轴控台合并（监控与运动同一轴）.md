# SCADA 轴控台合并（监控、运动、点位共用同一个轴）

日期：2026-10-18
用户裁定：**轴运动与点位控制应合并为同一个控件**——拆成两个控件要分别绑定，而且
"运动指向 X、监控指向 Y"会产生误导。

---

## 1. 结论

一个控件类（`AxisPanelElement`）+ **一个 `AxisOptions` + 一个 `SelectedAxisId`**，
以三个 TypeKey 注册成三种预设：

| TypeKey | 工具箱 | 预设 | 用途 |
| --- | --- | --- | --- |
| `Hmi.AxisConsole` | ✅ | `ShowCommands=true`、`ShowPoints=true` | 完整调试台（新用户默认拖这个） |
| `Hmi.AxisPanel` | ✅ | `ShowCommands=true`、`ShowPoints=false` | 紧凑面板：只要状态与手动操作 |
| `Hmi.AxisPointTable` | ❌（`ShowInToolbox=false`） | `ShowCommands=true`、`ShowPoints=true` | **旧 TypeKey 兼容别名**，只为打开旧方案 |

**为什么不做成三个控件类**：三个类就要三份轴选择状态，正是用户要消除的"分别绑定"。
预设只差两个布尔默认值，用 `ScadaPropertyCatalog.WithDefaults(...)` 在描述符层覆盖即可，
控件类、数据绑定、命令链完全共用。

**为什么不让 `Hmi.AxisPanel` 默认打开点位**：旧方案里面板高度是存下来的（常见 200~280），
突然多出一块点位区会把状态灯和按钮挤扁——等于给所有老画面做了一次没有撤销的改版。
新 TypeKey 让合并体验从新拖入的控件开始，老画面不动。

## 2. 数据绑定：一条链路

```
AxisOptions (设计期 JSON: [{AxisId, Name}])   ← 唯一的设计期"轴绑定"
        │
        ▼
  SelectedAxisId（运行期状态，不落盘）
        │
        ├─► IScadaAxisSource.TryGetSample(id) ──► 位置/速度/8 个状态灯
        ├─► IScadaAxisSource.TryGetPoints(id) ──► 16 行点位
        └─► IScadaAxisCommandSink.*(id, …)    ──► 使能/点动/回零/停止/清报警
                                                  示教/定位/改速度
```

- 属性面板只有**一行**「候选轴」；不存在"面板绑一次、点位表再绑一次"。
- `ShowPoints` / `ShowCommands` / `PointsRows` / `JogVelocity` 是普通属性，不参与绑定。
- 点位区收起时**不读** `TryGetPoints`（懒加载），展开时立即刷一次。

## 3. 运动/监控轴的统一处理

### 3.1 切轴 = 先对旧轴收手，再换目标

```
SelectedAxisId 变化
  ├─ EndJogForAxis(e.OldValue)   ← 用旧 Id 直呼出口发 JogStop（不过权限/门禁：停是安全动作）
  ├─ 停掉回零长按计时器
  ├─ 清空上一次操作结果文案
  ├─ 重建下拉项 → 刷新快照 → 刷新点位 → 重算 CanOperate
  └─ 完成
```

**为什么不能用 `EndJog()`**：它按"当前选中轴"发停止，而切轴回调里 `SelectedAxisId` 已经是新值——
会把停止发给新轴，旧轴继续走。旧 Id 只能从 `e.OldValue` 拿。

### 3.2 一个轴失效：保留选中，不自动跳

轴被删/停用：下拉项标「已移除 / 已停用」，量值显示"—"，命令按钮全部禁用。
静默换轴会让操作员对着错误的对象按按钮。

### 3.3 权限：一处判定，三处生效

```
CanOperate = 有命令出口 && 有选中轴 && AccessPolicy.CanOperate(RequiredRole)
CanEdit    = CanOperate && ShowCommands
```

- 操作按钮 `IsEnabled=CanOperate`；
- 点位行「示教/定位」`CanExecute=CanOperate`；
- 速度框 `IsEnabled=CanEdit`；
- 命令执行前 `CheckCanRun` 再判一次（防绕过按钮直接调命令）。

### 3.4 点位与运动共用门禁

- 定位 → `TryMove` → `MotionMoveAbsolute` → `CheckMove`（软限位/未使能/未回零/忙）；
- 示教/改速度 → 直接写 `MotionDescriptor.Points`（不动轴，不做门禁，但校验数值有限、速度 ≥ 0）；
- 两者与动作表共用同一个 `MotionActionExecutor` 实例。

## 6. 未决（2026-10-19 晚已清零）

1. **旧画面迁移**：`ScadaDocument.MigrateLegacyAxisElements` 只在"整页仅轴面板 + 旧点位表"
   时自动合并；其余页面只给诊断提示、不动版面。
2. **`AxisOptions` 摘要随轴改名**：`MotionAxisRegistry.Changed` + 属性面板按 Id 取最新名。
3. **真机视觉复核**：已完成 320/280 离屏渲染与人眼复核；点动/长按手感仍需真机。
4. **三条运动口径**：停止/失能在报警态放行、使能只认 Online、清报警按 `PhysicalAxis` 单轴下发，
   并由轮询确认所有轴无致命信号后回 Online。
