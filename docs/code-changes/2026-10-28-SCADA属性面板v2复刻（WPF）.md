## 踩过的坑

1. **`MultiTrendElement` 是控件不是模型**：`element` 是 `ScadaElement`（数据），`MultiTrendElement` 是 WPF 控件；用 `element is MultiTrendElement` 编译报 CS8121。判据用 `element.TypeKey == "Hmi.MultiTrend"`。
2. **`Style.Triggers` 必须放在所有 `Setter` 之后**：插在 `Setter Template` 之前报 MC3088「属性元素不能位于元素内容的中间」；把 `Style.Triggers` 移到 `</Setter>` 之后。
3. **`RowEditorHost` 不能按 DataContext 的 `Kind` 选模板**：成对右列 / 曲线卡子行的 `Content` 是另一行，DataContext 不是行本身；按 `Kind` 会让右列用左列编辑器（字重显示 `Normal`）。改为 `Content.Kind` / `Content.IsReadOnly`（`RelativeSource Self`）。
4. **成对网格与曲线卡都做 view-only**：不改 `_rows` 的行账本，`Rows.Count` 与既有断言不动；`PairWith/PairOwner`、`SeriesCard` 只影响渲染与搜索带出。组头 `DisplayCount` 单独给（曲线卡 7）。
5. **类型行移除要同步断言**：`UniversalRows` 2→1、基本组 2→1、类型行测试删除；否则会集体假红。
6. **Bool 行绑定 chip**：勾选框必须收起、标签必须回到左列（MultiDataTrigger），否则整行没有名字或被 chip 盖住。
7. **事件编辑器是独立 UserControl**：属性面板的隐式 `ToolTip` 样式管不到它，必须在 `ScadaEventEditor.xaml` 自带一份深色样式，否则事件描述仍是系统黄底。
8. **FlowCanvasChecks 构建锁**：运行中的 `VisionMaster.exe` 锁 `Modules\hdevenginedotnet.dll` / `Microsoft.CodeAnalysis*.dll`，插件 `copy` 报 MSB3073；用 `-p:BuildProjectReferences=false` 走现有插件产物可先验证当前代码（4258/0），最终 gate 仍应在关闭应用后重跑。
9. **`$null` 文件（C-06）**：cmd 包装的 `powershell -Command` 里 `2>$null` 会被 cmd 抢先解析成重定向，在仓库根建 0 字节 `$null`；已删并更新台账 C-06。
