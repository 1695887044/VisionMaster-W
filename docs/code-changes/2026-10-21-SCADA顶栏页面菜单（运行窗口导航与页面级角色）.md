# SCADA 顶栏页面菜单（运行窗口导航与页面级角色）

> 日期：2026-10-21 ｜ 范围：P0-3（SCADA 推荐控件第二批） ｜ 状态：已实现，专项断言通过，待真机确认

## 1. 背景

P0-1 已把页栈、`GoBack()`、`CanGoBack` 通知与 `NavigateBack` 动作接通；但运行窗口顶栏只有一行页名，没有页面菜单与返回入口。本项在 `ScadaRuntimeWindow` chrome 上补：

- 顶栏页面下拉（自动列出可导航页，当前页打勾）；
- 「← 返回」按钮（绑 `CanGoBack`，走 `GoBack()`）；
- 页面级 `ScadaPage.RequiredRole`：`Navigate` / `GoBack` / 页面菜单共用 `ScadaRuntime.CanAccess`，无权限页不进菜单、也不能作为回退目标；
- 启动页被角色挡住时，`Start()` 落到第一张可进入的可导航页。

不新增 TypeKey、不改画布；页面菜单是运行窗口 chrome。

## 3. 关键决策

### 3.1 页面菜单是运行窗口 chrome，不是画布图元

- 全局导航一处维护，不受画布缩放/裁剪/图层影响；不写 `.vms`、不进 web 快照。
- 页面清单每次打开菜单时从 `Document.Pages` 重建：运行中删页/改名/角色变化都会在下次打开时反映。
- 基座页由 `IsNavigable` 排除；空清单显示禁用项「（没有可切换的画面）」。

### 3.2 页面级角色放领域层

`ScadaRuntime.CanAccess(page)` 是唯一判定入口：

- `Navigate(Guid…)`：找到页后先 `CanAccess`，拒绝时 `reason` 直接上屏/写日志；
- `Navigate(ScadaPage?)`：`IsNavigable` 后、幂等判断前判角色；
- `GoBack`：回退目标被角色挡住时 `continue` 继续往下找，不把用户送回进不去的页；
- `Start`：启动页被挡住时按 `Document.Pages` 顺序找第一张 `IsNavigable && CanAccess` 的页；一张都没有则 `Start` 返回 false；
- 页面菜单：`IsNavigable && CanAccess` 过滤。

这样页面菜单、动作表「切换画面」、`NavigateBack`、返回按钮不会各写一套角色判断。

### 3.3 当前页可点但幂等

当前页在菜单里打勾；点击它仍走 `Navigate`，而 `Navigate` 对当前页直接返回 true（不压栈、不发 Loaded/Unloaded）。设计稿原写“不可点”，实现选择“可点但幂等”——省掉“置灰后勾选看不清”的问题，行为上也不会重复加载。

### 3.4 菜单生命周期

`ContextMenu` 在独立 Popup 视觉树里，不随窗口关闭自动消失；它的 `Click` 处理器指向窗口实例。若不收掉，菜单会反向钉住已关闭的窗口/会话/Document。处理：

- 窗口持有 `_pageMenu`；
- 每次打开先关旧菜单；
- `OnWindowClosed` 里 `IsOpen=false` 并清字段；
- 菜单 `Closed` 时清字段。

### 3.5 深色菜单模板与下划线

- 窗口级隐式 `MenuItem` 样式会整条顶掉应用级模板，悬停项落回浅底浅字；改为**显式 key** 的 `PageMenuItemStyle`，只作用于页面菜单，并给完整深色模板（勾选 ✓、`IsHighlighted` 深底、禁用 0.55）。
- 页名用 `TextBlock` 作为 `Header`，模板 `RecognizesAccessKey=False`：`01_总览` 不再显示成 `01总览`。
- 页名 `MaxWidth=220` + `CharacterEllipsis` + ToolTip，避免超长页名挤掉报警/停止区。

## 5. 边界与未做

1. **手动排序/改显示名后置**：本批只做自动列表（`Document.Pages` 顺序）；页面菜单不写 `.vms`。
2. **弹窗页排除后置**：`ScadaPage.IsPopup` 尚未实现（P1）；P1 落地时必须同步 `IsNavigable` 或菜单过滤，否则弹窗页会出现在菜单里。
3. **Web 镜像**：web 没有页面菜单（镜像模式不允许浏览器切页）；页面级角色未进 web 快照——web 只跟随桌面当前页，`Navigate` 动作在 web 侧仍被 mirror-mode 剔除，不存在 web 越权切页。
4. **WPF 视觉证据待补**：本项只有断言级证据与设计 HTML，没有真机截图；菜单悬停/勾选/禁用态的最终观感需真机确认。
5. **Release 未重建**：本项只验证 Debug；打包前需 Debug/Release 都重建（R55 同族）。
6. **全量断言未绿**：两个并发/监控段本机偶发崩溃，未修；不影响 P0-3 的专项结论。
