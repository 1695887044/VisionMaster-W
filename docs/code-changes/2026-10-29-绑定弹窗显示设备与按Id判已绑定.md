## 3. 关键取舍：设备必须放在变量名**之前**

显示串格式定为 `{节点名}.{设备}.{变量名}[{下标}]`，而不是 `{节点名}.{变量名} · {设备}`。原因是变量改名级联 `RebuildVariableDisplayAddress`（`Core/IReadOnlyWorkspaceContext.cs:386-408`）按**最后一个点**切前缀、只替换名字那一段：

- 设备在前：`全局变量 (Global).B_PLC.A` → 前缀 `全局变量 (Global).B_PLC.` → 改名后 `…B_PLC.A_NEW`，设备段保留；
- 设备在后：`全局变量 (Global).A · B_PLC` → 最后一个点是 `(Global).` 那个 → 改名后变成 `全局变量 (Global).A_NEW`，**设备段直接丢失**。

探针 C21.5 专门钉这条（走真注册表改名 + 真级联，断言 `after == "全局变量 (Global).B_PLC.A_NEW"`）。

## 6. 踩过的坑

1. **格式选错会让改名静默丢设备**：`RebuildVariableDisplayAddress` 的"最后一个点"规则是既有契约（`ScadaChecks` 有一组断言钉它），改格式前必须先验算这条路径。
2. **`IsBound` 不能只改成 Id 比较**：旧方案的连线没有 `TargetVariableId`，纯 Id 比较会让老数据"一个都不亮"。必须"两边都有 Id 才按 Id，否则退回名字串"。
3. **`CloneForCandidate` 漏拷贝 `Device`**：候选列表是克隆后展示的，漏一个字段就等于"显示串里没设备"，而 `BuildVariableDisplayAddress` 拿到的 `port.Device` 是空。
4. **反射断言的签名守门**：`IsBound` 是 `internal static`，探针只能反射；先断言 5 个参数，签名一变立即判红（C21.6）。
