## 五、踩过的坑

- **"没挂 Style"是最容易被忽略的一类丑**：XAML 里只写了 `FontFamily`，看起来像"自定义过"，实际全部落回应用级默认模板。判据是"这个 ContextMenu 有没有 `Style="{StaticResource ...}"`"，不是"有没有写属性"。
- **四态并排用 flex-wrap 会折成 3+1 孤行**：320×4 + 间距 > 1180 容器宽，必须显式 2×2 grid。
- **语气色选择器写成 `.menu .item.tone-*`，放大样张里的 `.item.tone-*` 就不生效**：设计稿里同一组件在两处出现时，选择器要按"组件"而不是"容器"限定。
- **10px 灰字用 `ScadaFaintTextBrush`（#A8ABB2）在白底上只有约 2.3:1**：分组标题必须用 `ScadaSecondaryTextBrush`（#66708A），否则渲染出来"像没写"。
- **本地 `file:` 页面不能直接交给浏览器工具打开**：`goto()` 只接受 http/https，必须临时起一个静态服务器；用完记得杀掉（本轮 8899）。
