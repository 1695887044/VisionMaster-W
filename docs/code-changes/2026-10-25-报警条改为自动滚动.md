# 报警条改为自动滚动

日期：2026-10-25　状态：已实现；`ScadaChecks` **3063 通过 / 0 失败**

## 用户反馈

> 报警条应该做成滚动条那种吧，现在的报警条效果不理想。

## 改法（为什么是"纵向自动滚动"而不是"横向跑马灯"）

报警条现有的卡片形态（44px 一行、严重度胶囊 + 时间 + 状态）是**有信息量的**：
跑马灯只能塞一句话，会丢掉时间和状态。所以保留卡片，把"停在第一屏等人手动拖"改成
**按固定节奏逐行下移、到底回顶**：

- 触摸屏上拖一条 140px 高的条子本来就难受（尤其戴手套），自动滚动才符合"扫一眼"的用法；
- 严重度颜色、行内状态全部保留；
- 条数不足一屏时**不滚**（否则"滚了个寂寞"，还让人以为漏了报警）。

## 实现

1. **新增两个属性**（`Hmi.AlarmBanner`，分组「状态」）：
   - `AutoScroll`（Bool，默认 `True`）；
   - `SecondsPerRow`（Number，默认 `2.5`，0.5~30）。
2. **纯计算** `Scada.Controls/Elements/AlarmBannerScroll.cs`：
   `RowIndex(累计秒, 每行秒, 可滚位置数)`、`ScrollPositions(行数, 可见行数)`、`Offset(...)`。
   按**累计时长取模**，与闪烁相位同一个理由——漏拍/卡顿不会越走越偏；
   `secondsPerRow ≤ 0` 回落默认值，绝不除零。
3. **控件** `AlarmBannerElement`：
   - `OnBeat` 里**先**推进滚动、再判断是否闪烁（原来 `!_isFlashing` 直接 return，
     导致"一条不闪的报警条永远停在第一屏"——这正是"效果不理想"的直接原因）；
   - `ApplyAutoScroll` 用 `ScrollViewer.ViewportHeight / 47px` 算可见行数，只在偏移变化 > 0.5px 时滚。
4. **断言** `[AB-S1]~[AB-S3]`：按累计时长推进（0s→第1行、2.6s→第2行、10.1s 回顶）、
   不足一屏不滚、偏移 = 行号 × 47px、非法秒数回落默认值。

## 顺带同步的两条既有断言

- 描述符快照（`Hmi.AlarmBanner`）补 `AutoScroll` / `SecondsPerRow` 两项；
- 属性键计数 20 → 22（6 几何 + 16 自有），标题同步。

## 未做

- **横向跑马灯**形态（单行连续左移）没有做：它会丢掉时间/状态两列，且与本条"三重编码"的结论冲突。
  如果现场要的是"一条接一条滚过"，那是另一种图元（或 `ScrollMode` 的第三个取值），需单独定。
- 自动滚动期间**用户手动拖动**会被下一拍拽回：目前没有"用户接管后暂停 N 秒"的机制。
  评审 B2 里"新报警插入是否打断阅读"也还没定——两条一起在下一批处理。

## 追加：改为横向跑马灯（同日，按用户裁定）

用户口径：**从右往左滚、不带确认、只要触发条件为 ON 就在队列里**，且纵向卡片太占空间。

- 新增 `ScrollMode`（`Ticker` 默认 / `List`）与 `ScrollSpeed`（默认 60 px/s）；
- `Ticker`：单行 34px，所有活动报警拼一行（**不筛确认状态**），按严重度上色，条间用「·」；
- 位移 = 视口宽 − (累计秒 × 速度) mod (文本宽 + 视口宽)，按累计时长取模不累加；
- `List` 保留纵向逐行自动滚动（老工程不变样）；
- 断言 `[AB-T1]`（右缘出发、走完一圈回起点）、`[AB-T2]`（空文本不滚、拼接跳过空项）。

`ScadaChecks` **3065 通过 / 0 失败**；设计稿已更新（`docs/UI设计基线/scada-third-round-review/review.html` 的「改为横向跑马灯」一节）。
## 追加：悬浮暂停（2026-10-26）

用户要求：跑马灯悬浮要停止滚动，让人看清文字。

- `ApplyTicker` 每拍检查 `IsMouseOver`：悬浮时记录暂停起点并直接 return（位移不推进）；
- 移开后把暂停时长累加进 `_tickerPausedSeconds`，有效时长 = 累计 − 暂停（`AlarmBannerScroll.EffectiveSeconds`）；
  **不清零重来**——清零会让文字瞬间跳回起点，正在读的人会跟丢；
- 内容重建（`RebuildTicker`）时暂停累计归零，新内容从右缘重新进入；
- 断言 `[AB-T3]`：有效时长扣减、负数/NaN 按 0、6 秒位移 = −40px（320 − 6×60）。
