## 改动点

1. **表格控件**：`ListView + GridView` → `DataGrid`。原因：GridView 没有星号列宽，旧版 50+150+220+330=750 > 视口 722，默认尺寸必出横向滚动条。DataGrid 路径列 `Width="1.6*"` + `MinWidth="220"`，列宽 **40 / 1.2\* / 1.0\* / 1.6\* / 72**（MinWidth 160/100/220），行高 52、表头 40；关闭排序、列重排、列宽拖拽、横向滚动。
1b. **宿主窗口尺寸**：视图不写死 `Width/Height`；首次 `Loaded` 通过 `Window.GetWindow(this)` 把 Prism `DialogWindow` 钉到 **960×640**（最小 900×560），之后内容随窗口伸缩。用户截图里整屏大窗口、名称列被挤成一条，根因就是这里没有默认尺寸。
2. **卡片头**：32px 图标块 + 「方案清单」+ 计数徽标 + 默认摘要 chip + 副标题；默认摘要由 `Solutions` 与 `StartupSolutionPath` 派生（`StartupSummaryConverter`）。
3. **默认列**：`Path == StartupSolutionPath`（忽略大小写）时显示「默认」chip；卡片头显示「默认：<Name>」；底栏显示完整路径。纯显示派生，不改 VM、不新增持久化字段。
4. **空态**：`Solutions.Count == 0` 时覆盖行区域、保留表头；给「添加当前方案 / 浏览添加…」两个现有入口。
5. **未选中态**：命令 `CanExecute` 自动禁用打开/设默认/移除/上移/下移；右栏提示切「选中一行后可打开 / 设为默认 / 排序 / 移除」。
6. **注释编辑**：`DialogCellInputQuiet` + 右侧铅笔图标；`PreviewKeyDown` 拦 Enter，避免冒泡到 `IsDefault` 的确认按钮；仍 `UpdateSourceTrigger=PropertyChanged` 回写 `Comment`。
7. **右栏动作分组**：打开方案（主色）→ 清单（设为默认 / 添加当前 / 浏览添加）→ 排序（上移 / 下移）→ 危险操作（从清单移除，危险色）；确认=主色、取消=次要色。
8. **全令牌化**：`DialogBackgroundBrush` / `DialogSurfaceBrush` / `DialogRowAlternateBrush` / `DialogBorderBrush` / `DialogText*` / `DialogPrimaryButton` / `DialogDangerButton` / `DialogSecondaryButton` / `DialogGhostButton` / `DialogDataGrid*` / `DialogCellInputQuiet` / `DialogEmptyState*` / `DialogFocusVisual` / `DialogToolTipStyle`；视图 `hex=0`，无本地 keyed Style。
9. **视图级转换器**（`SolutionListView.xaml.cs`）：`PathEqualsToVisibilityConverter`、`StartupSummaryConverter`、`NullToVisibilityConverter`；无独立 VM。
10. **断言与收编**：`UIThemeSmokeTest --solution-list`（29 条）/ `--solution-list-render`（5 张）；`CollectedDialogViews` 加入 `SolutionListView.xaml`；`hardcoded-colors.baseline.txt` 删除 `SolutionListView.xaml|16`。
11. **默认 chip 样式**：卡片头从通用 `DialogChipAccent`（9px 胶囊、无边框）改为 BasedOn `DialogChip` + `DialogAccentSoftBrush` + `DialogAccentBorderBrush`（1px、6px）；行内 chip 改 6px；空态 off chip 用 neutral 底 + 1px 边框 + 6px。

## 与设计基线的差异

1. **行内默认 chip 文案「默认」**：列宽 72 − 单元格左内边距 12 = 60；「默认启动」四字 + 星形约 67px 会溢出。卡片头与底栏仍写全「默认启动」，行内 ToolTip 写「默认启动方案」。
2. **右栏按钮文字居中**：Fluent 按钮模板的 `ContentPresenter` 固定 `HorizontalAlignment=Center`，设计稿为左对齐；未改共享模板（R141）。
3. **视图不写死尺寸**：Prism `DialogWindow` 按内容自适应，默认落在 900×560；960×640 是渲染/推荐尺寸，WPF 证据按 960 出图。
4. **空态主按钮**：`DialogPrimaryButton` 实心主色（设计稿是 soft 主色）；未新增 soft 按钮变体（R141）。
5. **保存失败 toast**：由宿主 `Notifier` 提供，不在视图内渲染；`--solution-list-render` 没有 save-error 图，VM 侧由 `ScadaChecks.SolutionListAuditChecks` 覆盖。
6. **列头「序号」**：共享列头样式左右各 12 内边距，40px 列会被挤成 16px（实测「序号」被裁）；本视图把列头 `Padding` 覆盖为 `12,0,0,0`，不改共享键。
7. **宿主窗口尺寸**：视图不写死；首次 `Loaded` 把宿主窗口钉到 960×640（最小 900×560），之后内容随窗口伸缩。用户截图里整屏大窗口的根因是 Prism `DialogWindow` 没有默认尺寸。
8. **名称/注释/路径比例列**：设计稿 40/152/176/*/72；真实长方案名「解决方案-20260829224154」在 152 下会被截断，WPF 改为 `1.2* / 1.0* / 1.6*`（960 约 199/162/265，900 路径 220）。
