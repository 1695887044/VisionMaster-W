# 主界面视图整改剩余收口（命令面板 / 状态栏 / 控制台）

- 日期：2026-10-20
- 范围：`VisionMaster/Shell.xaml`、`VisionMaster/Shell.xaml.cs`、`VisionMaster/ShellViewModel.cs`、`VisionMaster/Services/LayoutHelper.cs`、`VisionMaster/Views/RunCockpitView.xaml`、`UI/Controls/Themes/Colors.xaml`、`UIThemeSmokeTest/Program.cs`
- 设计依据：`docs/UI设计基线/app-shell/design.html`、`docs/UI设计基线/app-shell/README.md`
- 目标：在**不改变 AvalonDock 面板归属**的前提下，补齐主界面 V2 里可直接落地的交互与视觉项；停靠结构类改动单列“未完成项”。

## 1. 改动清单

### 1.1 命令面板（Ctrl+K）

- `ShellViewModel` 新增 `CommandPaletteItem`、`CommandPaletteItems`、`CommandPaletteQuery`、`SelectedCommandPaletteItem`、`IsCommandPaletteOpen` 与三条命令（打开/关闭/执行）。
- 面板项按四类生成：工作模式、中央文档/左右面板、全局命令、当前方案流程；每次打开时重建，避免流程改名/删除后留下过期引用。
- `Shell.xaml` 增加遮罩 + 640 宽面板 + 搜索框 + 结果列表；`Shell.xaml.cs` 处理 `Ctrl+K`、↑↓、Enter、Esc、双击执行与打开后的焦点。
- 面板只做“导航/命令入口”，不复制任何业务逻辑；执行项最终仍调用现有 `SetShellMode`、`LayoutHelper.ShowPanel`、`SystemCommand`、`Workspace.SwitchFlow`。

### 1.2 状态栏生产 KPI 占位

- `ShellViewModel` 新增 `CycleTimeText / OkCountText / NgCountText / AlarmCountText`，当前统一返回 `—`，明确表示“待接入运行统计”，不用 `0` 冒充真实计数。
- `Shell.xaml` 状态栏在运行状态后增加 `节拍 / OK / NG / 告警` 四组；组态模式仍沿用原“组态信息”分支，不显示流程 KPI。

### 1.3 底部控制台 32 / 240 两档

- `LayoutHelper.ToggleConsole()`：只改底部日志 pane 的 `DockHeight`（32 ↔ 240），不改可见性与标签选择；与组态模式的 `CollapseLogPane`（1px + 保存前高度记忆）分开。
- `ShellViewModel.ToggleConsoleCommand` 同时供状态栏按钮与命令面板使用；状态栏右侧新增控制台图标按钮。

### 1.4 术语与死菜单

- 菜单/右键菜单统一：`程序` → `流程导航`、`流程设计器` → `流程画布`、`日志信息` → `控制台`、`属性` → `检查器`、`模块参数` → `步骤参数`。
- `激活 / 建议及反馈 / 关于` 标记“（未实现）”并禁用，避免点击无反应。

### 1.5 颜色令牌与运行驾驶舱

- `Shell.xaml` 的硬编码十六进制色值全部收口到现有 `Dialog*/Scada*` 语义令牌；新增 `DialogScrimBrush`（命令面板遮罩）。
- `RunCockpitView` 图像区内层由白底改为 `RunCockpitBackgroundBrush`，去掉 8px 内边距与 `ImageView` 外边距，运行态图像区不再出现白框。
