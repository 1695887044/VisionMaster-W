### 2. 核心实现

- `DeformableMatchingPlugin`：
  - `[StepConfig]`：`TemplateJson`、`TemplateAssetId`、`TemplateFilePath`、`MinScore`、`MaxMatches`、`MaxOverlap`、`Greediness`、`DisplayViewIndex`。
  - 实现 `IAssetIdConfig`：`AssetKind = "template"`，`AssetId` 映射 `TemplateAssetId`。
  - 模板来源优先级：方案资产 > 本地 JSON > 内嵌 `TemplateJson`；外部来源失败不回退。
  - 资产解析：`IExecutionContext.Assets.TryResolve` 取 `AbsolutePath/ContentHash/Version`；
    缓存键 `AssetId|ContentHash|Version|算法`。
  - 本地文件：绝对路径或宿主程序目录相对路径；缓存键 `路径|大小|mtime|算法`。
  - 外部条目校验：`Model` 非空、`LearnedAlgorithm == Entry.Algorithm`；失败中文点名原因。
  - 外部模式 `OnConfirm` 只写元数据（`Model` 置空），模型留在资产/文件里。
  - 端口：两个可选输入 + 11 个输出（含基类 Success/ErrorMessage）。
  - 学习：参考图 → ROI（矩形/圆/椭圆）→ 可选掩膜差集 → 灰度 → `create_local_deformable_model` / `create_planar_uncalib_deformable_model` → 原点（相对域重心）→ `write_deformable_model` → base64。
  - 查找：局部 `find_local_deformable_model`；平面 `find_planar_uncalib_deformable_model` + `ProjectiveTransPixel(hom,0,0)` 反推 Row/Column。
  - 模型缓存：`RuntimeModelId + RuntimeModelSource`，平面缓存 `RuntimeModelContours`（level 1）。
  - 过期指纹：`Algorithm|Shape|Rect|Mask.Length|NumLevels|UsePolarity|ScaleRMin|ScaleCMin`。
  - 失败语义：无图/无模型/算法不符/加载失败/无命中/外部来源失败/异常 → 中文 `Fail`。
  - `MeasureImage`：原图 + 绿色形变轮廓；无命中输出原图。
  - `PublishPreview` 按 `DisplayViewIndex` 发布。
- `DeformableTemplateEntry`：INPC + JSON 落盘；`[JsonIgnore]` 运行期句柄。
- `DeformableMatchingView`：两栏、算法卡片、模板来源/本地文件/导出、ROI 数值、掩膜、查找参数、输出、固定学习栏、结果表、状态栏；`ImageReadOnly` 常驻；按钮走 `ICommand`。

## 五、踩过的坑

1. **`deformation_smoothness` 必须是整数**：`new HTuple(11.0, 0, 1)` 会报 HALCON #9465
   `Invalid 'deformation_smoothness'`；改成 `new HTuple((int)Math.Round(smoothness), 0, 1)` 后通过。
2. **`set_deformable_model_origin` 是相对域重心的偏移**，不是绝对坐标；写成绝对坐标会让
   Row/Column 与 HomMat2D 整体偏掉。M0 探针已实测。
3. **`get_deformable_model_contours` 的 level 是 1 基**：0 非法（#1302），固定用 1。
4. **`ImageRectified` 是每命中一张的 image array**：端口必须 `HObject`，不能 `HImage`。
5. **命中顺序不保证分数降序**：标量端口必须自己取最高分；本次对拍用 -30/60 与参考实现同参数后
   Score 逐值一致（0/0 参考实现会得到不同分数，已修正）。
6. **`PreviewImage` 是只读属性**：`ImageReadOnly.HImage` 绑定必须显式 `Mode=OneWay`，
   否则 UI 冒烟报“无法对只读属性进行 TwoWay 绑定”。
7. **UI 冒烟的 Button.Command 契约**：视图自己的按钮至少有一个 `Command` 绑定；
   本次把载入/掩膜/清除/学习/清除模板改成 `UiCommand`，Fit 按钮保留 Click。
8. **`UiCommand` 是各插件本地类**，不在 `Core.Halcon.Controls`；本插件自带一份极简实现。
9. **`Plugin.CodeReader` 的 DLL 比源码旧**（`audit_artifacts` 判红）：重建该工程后恢复 OK；
   这是并发编辑/增量构建的典型静默坑（红线③）。
10. **完整 FlowCanvasChecks 超过前台单次 600s 观察窗口**：本次先用 `--deformable` 专项模式快速迭代，
    再放后台跑全量（最终 3951/0）。全量 gate 也要留足时间，`run_gates.ps1` 可传 `-StepTimeoutSec`。
11. **资产页引用识别不能靠子串**：`SolutionProjectAssetCatalog` 原来用
    `step.Plugin.Contains("MatchingPlugin")`；`DeformableMatchingPlugin` 恰好包含这个子串，
    会“碰巧”显示引用。已改成显式识别 `DeformableMatchingPlugin + TemplateAssetId`。
12. **外部来源 `OnConfirm` 必须去掉模型**：否则选了资产还会把整份 base64 再写回 `.vms`，
    资产化的体积收益直接归零；已改成外部模式只写元数据。
13. **本地文件相对路径不是方案目录**：插件拿不到方案根路径，按宿主程序目录解析；
    需要可移植就用方案资产，样例流程保持内嵌/资产。
14. **`IAssetIdConfig` 只有一个 AssetId**：不能同时暴露“模板资产 + 模型资产”两个下拉；
    模板必须是一整包，别拆成两份真源。
