## 三、未做 / 偏差

- **点击胶囊是钉回 300 列，不是 300 覆盖浮层**。AvalonDock 的 auto-hide 页签是库内部控件：实测 `LayoutAnchorable.TabItem=null`，DockingManager 视觉树里只有左栏的 `LayoutAnchorableTabItem`，拿不到 auto-hide 的 tab 实例换模板；第一版用 Shell 覆盖层胶囊，放弃库的 auto-hide 浮层。
- 没有滑出动画；没有 `Esc` / 点外部收回（点击即钉回）。
- 切模式按模式默认恢复（`respectUserHidden=false`），胶囊不跨模式保留；Q10 未实现。
- 胶囊计数徽标未做；胶囊标题用 `RotateTransform 90`（横排旋转），不是 CSS 的 upright 竖排。
- auto-hide 的 6px 竖条被 24px 轨道覆盖，但库的 auto-hide 状态仍在；胶囊点击用 `ShowPanel` 钉回。

### 3.1 已修：检查器页签被拖成中央文档（2026-10-26 用户现场）

- **现象**：工具箱页签被双击/拖到中央文档区，变成"视觉图像 / 流程画布 / 工具箱"的文档标签，右侧空。
- **原因**：`LayoutAnchorable.CanDockAsTabbedDocument` 默认 `true`，右侧检查器页签没有拦；不是胶囊钉回逻辑——冒烟里 `ShowPanel("Panel_ToolView")` 实测回右侧 `LayoutAnchorablePane`。
- **修法**：左侧流程导航 + 右侧 4 个面板加 `CanDockAsTabbedDocument="False"`；加载时 `EnsureInspectorPanelsAreAnchorables` 把已经落成 `LayoutDocument` 的检查器面板迁回右侧空 pane；冒烟新增"点胶囊钉回：工具箱回右侧 LayoutAnchorablePane（不是中央文档）"。
- **注意**：已经保存成文档的旧 `Layout.xml` 不需要升版本，加载时自动迁回；用户重启即可。

## 五、踩过的坑

- **auto-hide 页签不是普通页签**：`LayoutAnchorable.TabItem` 在隐藏后为 null；`DockingManager` 视觉树里找不到它的 `LayoutAnchorableTabItem`；`IsAutoHidden` 是只读属性，`IsVisible=false` 才是可靠判据。改主题 type style 会误伤正常页签，局部行为也拿不到实例——所以第一版改用 Shell 覆盖层。
- **模式收敛会把工具箱 Show 回来**：`ApplyScadaPanelMode(false)` 原来无条件 `ShowPanel(OperatorToolboxPanel)`；启动/布局加载必须传 `respectUserHidden: true`，否则用户的收起在重启后失效。
- **显式切模式 vs 启动**：`SetShellMode` 用 `respectUserHidden=false`（模式默认恢复）；`ApplyPanelMode` 用 true（尊重用户）。两条路径不能共用一个默认值。
- **ShellCopy 不含胶囊轨道**：轨道是停靠区覆盖层，不在 docking 子树里；冒烟测不到它的视觉，只能测 ShellCopy 的结构与布局模型。真机截图是必需的。
- **`AutoHideWidth` 是浮层宽度，不是胶囊宽度**：胶囊 20×64~100 由 Shell 覆盖层模板控制；库的 auto-hide 竖条宽度不受它影响。
- **Computer Use 的 `click(element)` 对 WPF Button 只聚焦**：真机实测 AXPress 后按钮变 focused，但 `Click`/命令没执行、日志无 `[胶囊]`；`performSecondaryAction` 与 Space 也不触发。判断点击生效要看业务日志/面板状态，不看 focus。
- **坐标点击落到画布**：胶囊在截图右边缘，点击 (1268,92) 却选中了左侧 Diag 流程；说明命中测试/覆盖层是首要问题，不是命令绑定。
- **启动恢复/项目资产管理窗口会遮挡主界面并导致 pid 变化**：真机测试前先处理这两个窗口；不要用 Alt+F4 关项目资产管理（会退出应用）。
- **`CanDockAsTabbedDocument` 默认 true**：右侧检查器页签能被双击/拖成中央文档；这和胶囊钉回是两条路（`ShowPanel` 实测回右侧 `LayoutAnchorablePane`）。新布局必须显式 false，旧现场靠 `EnsureInspectorPanelsAreAnchorables` 在加载时迁回。
