# HALCON 标定数值对拍（九点 / 透视 / 内参）

> 日期：2026-10-26。目的：用 HALCON 自带标定算子/例子独立复核「标定」插件的数值结果，
> 回答"两边算出来是不是一样"。**不改产品代码**，只跑临时对拍探针。

## 一、当前状态

- **九点/仿射**：插件 `CalibrationMath.TrySolveAffine` 与 HALCON `vector_to_hom_mat2d`
  在精确数据与带确定性噪声的数据上，系数与映射点都一致到 **1e-15 量级**。
- **透视**：插件 `TrySolveProjective` 与 HALCON `vector_to_proj_hom_mat2d('normalized_dlt')`
  按 h33 归一后逐元一致到 **1e-12 量级**（精确 6.2e-13，带噪 4.0e-12）。
- **内参**：插件 `IntrinsicsCalibration.TrySelfVerify` 走 HALCON 的
  `sim_caltab → find_calib_object → calibrate_cameras` 完整链，12/12 张找到板：
  焦距误差 **0.0018%**、主点偏差 **0.0001px**、kappa 误差 **0.002%**、重投影 RMS **0.0039px**。
- 结论：**数值一致，没有发现系统性偏差**。

## 五、踩过的坑

- **契约 6 元与 HALCON 6 元不是同一排布**：HALCON `vector_to_hom_mat2d` 是
  `[h11 h12 h13 h21 h22 h23]`，契约是 `[a11 a12 a21 a22 a31 a32]`（平移项提前到索引 2）。
  不重排直接逐元比会得出"矩阵不一致"的假结论。
- **透视要先按 h33 归一**再比：HALCON 返回的 9 元可能整体差一个尺度，逐元直接比没有意义。
- **精确数据只能证明公式一致，不能证明最小二乘口径一致**：所以额外加了确定性噪声，
  带噪下两边仍然一致到 1e-15（仿射）/4e-12（透视），才说明最小二乘解也同口径。
- **临时探针必须删**（R134）：本记录保留输出原文，探针目录用完即删。
