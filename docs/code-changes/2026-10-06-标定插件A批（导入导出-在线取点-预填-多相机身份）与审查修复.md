## 一、背景

主文档 4.5 的保留待办里，有四项都属"现场真用得上、且互相关联"的一批：多设备共享同一份标定（导入/导出）、不落盘直接对着实时图取点、把上游定位结果一键填进表、多相机换相机时身份自证。本轮一次做完，并把「界面人工走查」转成自动化冒烟。

## 二、改动清单

### 2.1 标定文件（新增 `Models\CalibrationFile.cs`）

`CalibrationExportFile`：版本化 JSON（`Version` / 模式 / 网格 / 表格四值（可空）/ A、B（可空）/ 已知长度 / `CameraSerial` / 阈值 / 当量护栏 / 时间戳 / 图尺寸 / `SourceTag` / 质量快照）。**不含**锁定开关、预览图、画布状态（那些是"本机状态"，跟人走不跟文件走）。快照只是导出时刻的窗口，导入端不依赖（导入后自行重算）。

### 2.2 标定插件（`CalibrationPlugin.cs`）

- **新增端口 5 入**：`SourceImage`(HImage?，实时图在线取点)、`SourceSerial`(string，上游相机序列号)、`SourcePointRow/Col`(double?，上游定位点预填)；原有 `SourceImagePath` 保留。
- **实时图在线取点**：`OnlineImage` **借入引用（绝不 Dispose）** 优先接管画布；断开时回落文件预览；同一引用不重复处理（试运行每轮桥接同一对象）；`RefreshCanvasImageState` 按"当前底图"统一重推尺寸——**尺寸只增不清**（图片不在场 ≠ 标定快照作废）。
- **按行预填**：`PrefillRowFromSource` 把上游定位点填进该行；上游无值 → **明确拒绝**并说明（不动数据）。
- **相机身份校验**：上游与本步骤序列号都非空且不一致（大小写不敏感）→ `BlockingError`，文案含两台相机与下一步；日志行补打「本步骤/上游」序列号（事后可查）。
- **导入/导出**：`BuildCalibrationExportJson`（**先算后建**，时间戳以最终结果为准）/ `ImportCalibrationJson`（全量覆盖；**拒绝先于改动**；导入后 `_lastInputSignature=null` 让文件时间戳成为权威，导入动作不推进它）；界面 `ExportCalibration… / ImportCalibration…`（SaveFileDialog/OpenFileDialog）。
- **`Dispose()` 收口**：摘逐行 `PropertyChanged`、`_pointRows.CollectionChanged`、`SourceImagePath.ValueChanged`、`SourceImage.ValueChanged`；`OnlineImage` 只断引用。
- `TryParseRows` 提升为 `public static`（供断言；Tab 空单元格 = 未填、行首空列保留、全空行跳过、4/5 列）。

### 2.3 视图（`CalibrationView.xaml`）

HImage 绑定改 `CanvasImage`（实时图优先）；表格新增「预填」按钮列；卡片③新增「导出标定…/导入标定…」；提示文案补实时图与预填。

### 2.4 图像采集（`ImageAcquisitionPlugin.cs`）

新增输出 `SourceSerial`：开轮先清空；仅相机模式成功时写入配置的序列号；取消/失败/异常路径保持空（无失败轮残留）。

### 2.5 坐标变换（`PoseTransformPlugin.cs`）

新增输入 `SourceSerial` + **失配第四类**：标定记录的序列号与上游图像序列号都不为空且不符 → 明确失败（文案含两台相机）。旧标定文件没记序列号 → 放行（不误拦）。

## 三、审查（reviewer，结论 fail）与修复

后台 reviewer 独立审 A 批，判 fail——主流程自洽，但「非法拒绝面」有一处异常绕过 + 两处会静默关掉下游护栏：

| # | 问题（现象） | 修法 | 断言 |
|---|---|---|---|
| 1（严重） | `{"Points":[null]}` 过校验后 `p.Name` 解引用 → **NRE 抛穿**（UI 未处理异常），而不是承诺的中文原因 | 拒绝面新增"标定表含空行"检查（**改动数据之前**） | 72(d) |
| 2 | 文件尺寸为 0 时导入把本机尺寸清 0 → 下游「换分辨率自证」fail-open 且不自愈 | 尺寸 ≤0 时**按当前底图回填 → 否则保留本机原值**，永不清 0 | 72(e) |
| 3 | `ResidualThresholdPx=NaN` / 护栏 NaN→ 判据恒 false **静默放行一切** | 导入时校验有限性与非负，非法即拒绝 | 72(d) |
| 4 | `SourceTag` 导出携带、导入丢弃（跨设备核对无据） | 新增 `_importedSourceTag`：本机无图路径时继承文件标签（进入产物与签名） | 72(f) |
