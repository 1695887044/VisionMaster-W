# 开发记录：C#脚本插件（Plugin.CSharpScript）—— Roslyn 脚本 + 自定义函数门面

- 日期：2026-09-16
- 类型：新功能（新插件）
- 触发场景：用户希望再引入一个插件——"C#脚本 + 自定义函数（获取模块参数、修改全局变量、日志输出等）"，并确认要完整 C# 语法（类、方法、引用包）后全权授权开发。

---

## 一、需求与决策

### 需求

1. 新增"逻辑控制"类插件，步骤正文用**完整 C# 语法**编写：可定义 class、方法、泛型、LINQ、`using`，能引用平台内置程序集。
2. 脚本能调用一组"自定义函数"：取上游模块参数（输入端口）、写输出端口、读写运行期变量、日志输出、显示图像、主动失败。
3. 与框架既有范式（图像脚本插件、变量插件正样本）对齐：动态端口、配置持久化、Success 契约、编译校验前置。

### 关键决策（及理由）

| 决策 | 理由 |
|------|------|
| 用 **Roslyn Scripting**（`Microsoft.CodeAnalysis.CSharp.Scripting` 4.12.0）做脚本宿主 | 官方 C# 解释执行方案；脚本体=顶层语句，天然支持类/方法/using；NuGet 离线缓存已验证可用 |
| 脚本以**顶层语句**编写，class/方法可定义在正文中，"干活"语句必须在顶层 | CSharpScript 会忽略手写 Main，只执行顶层（探针实测确认） |
| 自定义函数走 **globals 门面** `ScriptContext`（脚本里以顶层名 `Context` 访问） | `globalsType` 注入，门面不持 UI、全部动作经宿主注入的委托回调，跨线程安全 |
| 失败契约：**抛异常=失败；`Context.Fail()`=显式失败；返回值不作状态** | 与框架"业务失败不抛异常但 Success 必须显式写"的契约对齐（延时插件假失败教训） |
| "改全局变量"的正门 = **输出端口绑定到全局变量**；运行期临时变量走 `Context.SetVar/GetVar`（`IExecutionContext.LocalVariables`） | 与 VariableDefinition/VariableAssignment 正样本一致，引擎在连线时自动落回 `Workspace.GlobalVariables`，插件不直写全局 |
| 脚本正文按 **SHA256 指纹缓存**已编译委托 | 循环运行零重复编译；内容一改即失配重编 |
| 编辑器用 **AvalonEdit + C# 高亮**，输入/输出变量两张表 + "显示到窗口N"下拉 | 与 ImageScriptView 同源范式；图形输出按路推预览 |
| 动态输入端口在 **ApplyConfigValues**（LinkPorts 之前）重建 | 否则方案加载后按名连线失败（框架既有约定） |

### 踩坑记录（均有教学价值）

1. **命名空间遮蔽**：工程命名空间 `Plugin.CSharpScript` 末段 `CSharpScript` 遮蔽了 Roslyn 的 `Microsoft.CodeAnalysis.CSharp.Scripting.CSharpScript`（CS0234）。解法：`global::` 全限定。
2. **CompilationErrorException 真身**在 `Microsoft.CodeAnalysis.Scripting`（不是 `.CSharp.Scripting`），凭记忆会写错 using；其 `Diagnostics` 是 `ImmutableArray<Diagnostic>`（结构体，不能用 `?.`，用 `IsDefault/Length` 判空）。
3. **dotnet CLI 下类库默认不把 PackageReference 的 dll 落盘**到自身 bin（只记 deps.json），导致 PostBuild 从 `$(TargetDir)` 拷 Roslyn dll 失败。解法：csproj 加 `<CopyLocalLockFileAssemblies>true</CopyLocalLockFileAssemblies>`。

## 四、已知边界

| 项 | 说明 |
|----|------|
| 脚本=顶层语句 | 正文里 class/方法定义合法，但执行入口必须是顶层语句；写 `static void Main()` 会被忽略（模板注释已提示） |
| 同步阻塞执行 | `RunAlgorithm` 是同步契约，内部 `GetAwaiter().GetResult()` 阻塞；引擎线程本就是后台线程，无 UI 死锁风险；脚本内起长任务需自行 await/超时 |
| 引用集=运行期已加载 | 脚本能 `using` 的包 = 宿主 bin/Modules 里已有的 dll（含 HalconDotNet、Newtonsoft、HslCommunication 等）；**不能**在脚本里引 NuGet 新包；TPA 缺失个别私有 dll 时靠已加载程序集兜底，未加载者不可见 |
| 编译缓存上限 64 | 超量清空重来（防方案极多时字典无界增长）；缓存键=正文 SHA256，改一个字符即重编 |
| 全局变量写入路径 | 只能通过"输出端口绑定全局变量"间接写；`SetVar` 写的是步骤作用域 LocalVariables，方案级变量互不影响 |
| ShowImage 线程 | 发布预览经 `PublishPreview` 的既有调度封装，脚本线程直接调用安全；勿在脚本里触碰任何 WPF 对象 |
| 脚本内 `return` 值 | 仅作可选输出记录，不参与成功/失败判定（契约见上） |
| 宿主 bin 的 Roslyn | 下次全量构建主程序时经项目引用链传递到宿主输出目录；当前以 `Modules` 拷贝 + LoadFrom 连续性为准（hdevenginedotnet 先例） |
