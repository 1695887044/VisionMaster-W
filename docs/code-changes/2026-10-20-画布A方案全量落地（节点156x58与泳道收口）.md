# 画布 A 方案全量落地（节点 156×58 / 容器 46 / 泳道 28 / 小地图 180×118）

- 日期：2026-10-20
- 范围：`VisionMaster/Views/FlowCanvasView.xaml`、`VisionMaster/ViewModels/CanvasNodeViewModel.cs`、`VisionMaster/ViewModels/FlowCanvasViewModel.cs`、`Core/Models/FlowLayoutStore.cs`、`UI/Controls/Themes/Colors.xaml`、`FlowCanvasChecks`（测试）

- 前提：项目未发布，用户明确不考虑旧布局迁移

## 1. 已落地

### 节点

- 尺寸 **156×58**（`FlowLayoutStore.NodeWidth/Height` 唯一来源，`FlowCanvasViewModel` 只做别名）。
- 图标块 28×28/圆角 8/图标 14；标题 11.5、副标题 9；卡片圆角 10、内边距 10/8。
- `node-op` 操作徽标：`ComparisonPlugin.Type` → `EQ/NEQ/GT/LT/GTE/LTE`；`LogicOperationPlugin.Operation` → `AND/OR/NOT/XOR/NAND/NOR`；普通节点不占位。
- 副标题：比较/逻辑插件拼 A/B/Tolerance 或上游端口，否则回退插件名；小容差用 `0.######`，`0.0001` 不再被吞。
- 右上 7×7 状态点（运行脉冲）、右下耗时、左上 16×14 深色序号；失败底色 `#FFF7F7`；选中 2px 运行色；禁用整节点 45% 透明。

### 容器

- 组头 **46px**、类型色条 4×26、类型徽标高 20、标题 12.5、条件胶囊高 20、`N 分支 · M 算子`、7×7 状态点、序号 24×18。
- 失败/条件缺失红框红头红点；运行/成功只改状态点；禁用整节点 45% 透明。
- 条件列改为 `*` + `MaxWidth=190` + `MinWidth=0`，组头 `ClipToBounds=True`，长条件不再把 meta/状态点/折叠钮挤出。

### 泳道

- 泳道头 **28px**、分支徽标/名称/计数；If/Case/While/For/Parallel 类型分色。
- **Else / Case 默认分支中性灰**（`FlowCanvasLaneNeutral*`）。
- 父容器失败/缺条件时整列红染（`FlowCanvasContainerFailedBackgroundBrush` / `FlowCanvasFailedBorderBrush`）。
- 运行分支蓝边蓝头带；While/For 底部说明条；并行分组底部“汇合 · N 分支”条。
- 禁用态整节点透明；`IsNeutralLane` / `IsLaneParentFaulted` 都有 PropertyChanged 通知。

### 小地图

- 180×118、工具条开关、默认关闭、关闭时 Collapsed；打开后保留点击/拖动平移。
- 视图态仅会话内有效，不落盘。

### 布局与测试

- `FlowLayoutStore`：`NodeWidth=156`、`NodeHeight=58`、`FrameHeaderHeight=46`、`LaneHeaderHeight=28`、`CollapsedFrameHeight=50`、`MinLaneWidth=240`、`LaneNoteExtraHeight=34`、`ParallelJoinExtraHeight=34`。
- `FlowCanvasChecks` 新增 `FLC-1..36`：操作徽标、节点实量 156×58、小地图 180×118/默认关闭、泳道中性/失败矩阵、容器组头 46/泳道头 28、禁用透明度、长条件不溢出。

## 3. 已知偏差

1. **Case 仍为列布局**：设计稿是三条横向分支行；当前沿用 `FlowLayoutStore`/`FlowCanvasViewModel` 的通用“分支=列”几何。`flow-logic/README.md` 已知偏差 #8 允许按现有 Canvas 流式布局扩展；若后续要严格行布局，需要为 `CaseStep` 单独实现行堆叠几何。
2. **未做分支内 150×46 compact 节点**：全画布统一 156×58。
3. **小地图视图态不落盘**；断点圆点仍常驻（设计稿无断点入口）；折叠钮为浮层保留（设计稿无折叠控件）。
