## 踩过的坑

- **agent 给的路径可能错**：`RecipeManagerView.xaml` 被报在 `Plugins\Plugin.Recipe\`，实际在 `VisionMaster\Views\DialogViews\`。按 agent 路径 grep 会空手而归，结论必须以主会话复核为准。
- **"条数"不能只数顶层 Check**：方法里有分支/循环，agent 数 37/26 条、主会话数 44/34 处调用，口径不同。结论只需"远多于条文数字"，不要在报告里钉死一个数。
- **`audit_docs.ps1` 末尾 `exit 0`**：看 run_gates 全绿会误以为 docs 结构已被判红，实际它从不判红。
- **`findstr /s` 对不存在的文件静默**：加 `2>nul` 后连"找不到文件"都吞掉，容易把"路径写错"当成"零命中"。先 `dir /s /b` 确认文件存在再 grep。
- **中文路径不要走 `-Command` 字面量**（R2）：用码点拼 `docs\架构文档` 再 `Test-Path`，否则控制台代码页会把路径弄坏。
