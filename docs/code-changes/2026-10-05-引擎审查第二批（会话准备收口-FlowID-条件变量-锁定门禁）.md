## 一、会话准备收口（`FlowSessionFactory`，P1-10）

原先"查会话 → 判新鲜度 → 编译 → 注册"四步在 **9 个调用点各写一遍**，已经产生真实漂移（加密门禁漏两处、
"没跑上"读成"跑起来"两处）。现在收口成 `FlowSessionFactory.TryEnsureSession(runtime, compiler, flow, out session, out error, log)`：

- **使用单点的路径**：HTTP 收图、子程序调用（`FlowInvoker`）、定时/变量自动触发（`FlowAutoRunner`）、程序栏单流程运行；
- **HTTP 里删掉了第二份实现**（`TryBuildSession` / `IsOutdated`），彻底消除"同语义两套口径"的种子；
- 其余仍自行编译的入口（界面"编译全部"、程序栏"编译本流程"等）补上 `CompiledFlowId = flow.FlowID`，
  使**所有**会话都带流程身份；
- 失败口径仍在调用方（HTTP → 409/404、子程序 → 文本、自动触发 → 日志、界面 → 提示），单点只负责"准备"。

**回归中抓到并修正的一处自身失误**：收口时把 HTTP 的"会话在跑 → 409"快速预检一并删了，
`[S11] 流程运行中 → 409` 当轮变红（返回 200）——已补回预检（真正的互斥在引擎会话锁，预检负责尽早、明确地回错）。

## 二、新鲜度判据 = 流程身份 + 版本（P1-2 的一半）

`FlowSession.CompiledFlowId`（流程 `FlowID`）+ `FlowSessionFactory.IsStale`：
`Version` 更高 → 过期（图纸改过）；**FlowID 不同 → 过期（换成了另一份方案里的同名流程）**；
`CompiledFlowId` 为空串（老调用方/旧会话）→ 退化为只比版本（兼容）。
配套：`ShellViewModel` 在**切换/打开方案后** `_runtimeManager.ClearAll()`，不再让上一份方案的会话按名串车
（此前 `UnregisterSession` 全仓无生产调用点）。

## 三、条件变量未绑定 → 编译期硬错误（P1-4）

`FlowCompiler.CompileLocalVarParams` 增加反向检查：`LocalVariables` 里每一项都必须在步骤连线里出现
（键 = 变量 Id 字符串；旧数据按变量名做键也认），否则报
`[条件变量未绑定] 变量 'X' 没有绑定数据源（请在条件编辑器里绑定上游端口，或删除该行）`。
此前未绑定的变量在求值时静默取类型默认值（double=0 → 条件恒假走 Else、While 立即退出），而步骤仍标成功。

## 四、数组下标写进 `TargetPortName`（P1-6）

`VariableBindingViewModel.DoFinalBind`：`targetPort = index >= 0 ? $"{port.Name}[{index}]" : port.Name`。
协议规定 `TargetPortName` 可带 `[索引]`，编译器只从那里解析并生成 `ArrayIndexProxyPort`；
此前下标只进显示串 → 绑定"数组取元素"要么编译报类型不匹配、要么（目标为 object 时）把整个数组静默传下去。

## 五、锁定语义统一 + 界面诚实化（P1-3 的最小修法）

- **引擎层统一门禁**：`FlowEngineService` 在两条执行入口（单次 / 连续）都先判"流程是否被锁定
  （`StepsEncrypted`）"——此前只有定时/变量/子程序/单流程四条链拦，HTTP 与界面"运行全部"漏判；
  现在**任何触发源（含将来新增的）**都受同一道闸，拒绝时记 Warn、单次执行如实返回 false；
- **界面口径改真话**：流程管理里"加密/解密"改为**「锁定/解锁」**，提示写明
  "锁定后禁止运行；**不改变文件内容，不提供机密性保护**"；状态列显示"🔒 已锁定（禁止运行）"；
- 真正的落盘加密（`Steps → JSON → Encrypt` + 密钥管理）另立一期——本批不做假承诺。
