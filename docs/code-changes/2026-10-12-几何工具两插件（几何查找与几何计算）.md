## 二、目标与背景

补齐"几何基元"缺口：平台原先只**出**几何（卡尺 `FittedGeometry`/胶路 `ErrorSegments` 等 HXLD），**无任何插件能消费**（全仓零 `InputPort<HXLD>`）。本轮让几何基元成为可复用、可组合的一等数据：**查找出基元 → 计算算关系**。

## 四、实现相对方案的刻意偏离（以此为准）

1. **参数走端口**，不走 `[StepConfig]`：两插件无自定义视图，宿主 `AutoPortConfigView` 只渲染输入端口，`[StepConfig]` 在界面上无入口。
2. **几何查找是单算子**（`Kind` 枚举分派），非"链 + 注册表 + 三栏视图"；链式与视图列为二期。
3. **找边/拟合自包含**（`edges_sub_pix` → 最长轮廓 → `fit_*_contour_xld`），**未**抽取卡尺服务、**未**改卡尺（卡尺回归断言 G12 不适用）。
4. **夹角口径为无向 [0,90]**（`min(|Δ|,180−|Δ|)`），不与卡尺（依赖点分布取向的射线夹角）逐值一致。
5. 契约命名空间 `Core.Interfaces`（非 `.Geometry`）；有 `public` 无参构造供 JSON 反序列化（属性 init-only，仍不可变）。
6. `GeometryRelation` 的属性 `ConstructKind` 改名 `ConstructMode`（避免与枚举类型同名，字段初值解析不到类型）。

## 五、未决问题 / 二期

1. **HALCON 找边/拟合（G1/G2）**：`GeometryFinder` 的算子层未纳入离线断言（依赖真 HALCON），待探针/现场验证。
2. **链式架构 + 自定义视图**（PreProcessing 式：算子注册表 + 链 + 三栏视图 + 逐步预览）列为二期。
3. **卡尺"阵列卡尺"找边路径**（更抗噪的定向扫描）列为二期可选；若要，则按原方案决策 4 抽取共享服务并补卡尺回归。
4. **`PoseTransform` 增几何口**（基元随位姿变换到机械系）列为二期。
5. `GeometryFinder` 仅取"最长轮廓"参与拟合；多轮廓聚合（concatenate 后拟合）未做。
