## 五、踩过的坑

1. **`ImageAcquisition` 不解析裸相对路径**：真机实测只写 `FilePath=Image\smd_on_chip_01.png`
   报「路径不存在」。`AcquireSingleFile` 只做 `File.Exists(path)`，按进程 cwd 解析；
   `ProjectAssetPathResolver` 只有在 `ImageAssetId` 非空时才走资产目录
   （`SolutionProjectAssetResolver` 按「方案根 + RelativePath」解析）。
   正解：相对 `FilePath` + `ImageAssetId` + 根级 `ImageAssets`，不要写盘符绝对路径。
   注意：`SolutionService.LoadAsync` 不会回填 `SolutionFilePath`，宿主加载后要
   `solution.SolutionFilePath = 打开路径`，否则资产解析报「方案尚未保存」。
2. **不能只改 `.vms` 路径**：断言里 `File.Exists(imagePath)` 按测试进程 cwd 解析，
   相对路径会落到仓库根。断言要按 `.vms` 所在目录拼绝对路径；资产解析断言要先回填
   `SolutionFilePath`。
3. **图片必须平铺**：`SolutionAssetService.TryResolve` 只接受 `Image\<文件名>`；
   带子目录的引用在构建方案时不会被复制。
4. **文件夹名 / 文件名 / `SolutionName` 必须三者同名**：`SolutionPaths.IsFolderLayout`
   按这个判据识别；否则打开后点保存会走「另存为」。
5. **旧散装文件不要留两份**：已备份到 `%TEMP%\视觉样例对拍.vms.flat.bak` 后删除。
6. **`结果显示` 的动态口 `r1/r2` 必须在 `Items` 里先定义**：`ResultDisplayPlugin`
   按 `Items` 重建 `InputPort<object>`，`LinkedSources` 的键就是 `rN`；
   `SrcImage` 是固定口，接算法标注图。
