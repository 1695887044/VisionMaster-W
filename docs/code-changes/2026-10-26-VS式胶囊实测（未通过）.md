### 2.3 点击胶囊的三次尝试（全部未钉回）

1. **UIA `click(element 49)`**：AX 树里 `button 工具箱` 变为 `focused`，但工具箱仍隐藏、胶囊仍在；日志无 `[胶囊]`。
2. **`performSecondaryAction(49, "AXPress")`**：结果同上；反而把活动文档切到了「视觉图像」。
3. **坐标点击 (1268, 92)**（胶囊在 1280×860 截图里的位置）：点击落到了**流程画布**，左侧流程切到 `Diag`、画布显示 Diag 的 22 个节点；胶囊未响应。
4. **聚焦后按 Space**：仍无 `[胶囊]` 日志、无钉回。

结论：`OnInspectorCapsuleClick` 没有被触发；`ShowInspectorCapsule` 里的两条 `[胶囊]` Warn 一条都没出现。

## 三、未做 / 失败原因假设

1. **胶囊轨道不可点中**：坐标点击落在流程画布上，说明右边缘的 WPF 覆盖层没有拿到这次点击。可能原因：
   - `Panel.ZIndex=5` 对 AvalonDock 的文档内容不生效（文档控件在模板/宿主层，或 HALCON `HwndHost` 的空域问题）；
   - 胶囊轨道的 `Border`/`ItemsControl` 命中测试被上层文档覆盖；
   - 坐标换算/窗口缩放导致落点偏到画布。
2. **Button 的 Click 没有执行**：UIA 只把按钮聚焦；`Space` 不触发 Click；日志无 `[胶囊]`。可能是 DataTemplate 里的 `Click` 处理器没有接到（虽然构建 0 错误），或 WPF Button 在 `ItemsControl` 里的 AutomationPeer 只做 Focus。
3. **应用重启**：启动恢复/项目资产管理窗口 + 外部看门狗；本次无法稳定跑完"点击→图钉→双击守卫→重启"的完整链路。
