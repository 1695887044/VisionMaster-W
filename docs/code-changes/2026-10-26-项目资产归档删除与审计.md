# 项目资产：归档 / 删除 / 逐字段差异 / 页内审计流水

## 当前状态

资产页补齐了三项运维能力，都走 `ProjectAssetService` 同一道权限闸门：

- **归档 / 恢复**：切生命周期状态，不删文件、不动版本号；
- **删除**：从方案移除记录 + 清默认指针与生命周期，**磁盘文件保留**，二次确认；
- **逐字段差异**：版本页选中记录，与上一条记录比较，逐字段列出 before/after；
- **页内审计流水**：新增「审计」页签，直接读 `Audit\Audit-*.csv` 显示该资产的操作记录。

## 已做

1. **生命周期模型**
   - `AssetLifecycleState`（AssetId / Kind / State / 时间 / 操作者 / 备注）挂 `SolutionModel.AssetLifecycle`。
   - **五类资产共用一张表**，不往 `CalibrationAsset` / `RecipeDefinition` 加字段——那两处是契约类型，加字段会让"状态"出现两份真相。
   - 目录读取时本表优先：`ApplyLifecycle` 覆盖资产自身 `Status`，没有记录 = 有效。
2. **归档 / 恢复**
   - `TrySetArchived`：归档前检查冻结（冻结时拒绝），写状态 + 版本记录 + 审计。
   - 不递增版本号（归档不是内容变化）。
3. **删除**
   - `TryDelete`：按类型从对应集合移除；同时清 `AssetDefaults` 与 `AssetLifecycle`。
   - **不删磁盘文件**：返回被保留的相对路径，界面提示"文件保留："。
   - 历史记录保留（谁在何时删了哪份资产是审计事实）。
   - 界面二次确认（`MessageBox`），确认后才执行。
4. **逐字段差异**
   - `ProjectAssetService.DiffSnapshots(before, after)`：把快照 JSON 摊平成 `a.b[0].c → 值`，逐键比对。
   - 缺一边标 `<新增>` / `<移除>`，不当成空串（否则"字段被删"看起来像"改成空"）。
   - 数组按下标展开（`Matrix[0]`、`Matrix[1]`…）。
   - 非法 JSON 整段当一条 `<raw>`，不抛。
   - 版本页改成 `ListBox` 才能选中记录；选中后与"上一条更早的记录"比较，面板显示比较对象与变化字段数。
5. **页内审计流水**
   - 新增第五个页签「审计」，`刷新审计` 按钮读 `ScadaAuditReader`。
   - **按对象名匹配**（审计行只记 subject，没有资产 Id），界面明确写出匹配口径与目录。
   - 每行显示时间、动作、结果、操作者、说明；被拒绝的记录也在列表里。
   - 审计目录可注入（`ProjectAssetsViewModel(auditDirectory:)`），宿主用默认程序目录，探针指到临时目录才能验证。
6. **布局**
   - 归档/删除并入右下角操作卡第三行（原来放左下角会遮住列表页脚）。
   - 详情页签底部留 104px，避免操作卡盖住内容。
   - 版本列表 `MaxHeight=240` 自己滚动，保证差异面板始终可见。
7. **断言**
   - `ProjectAssetsUiProbe` 新增三组：
     - 归档/删除 18 条：未登录被拒、冻结时被拒、归档不改版本号、目录读取显示已归档、恢复回有效、删除清默认指针与生命周期、磁盘文件仍存在；
     - 逐字段差异 8 条：`MmPerPixel 0.05 → 0.2`、`Matrix[0]` 下标展开、未变字段标未变化、新增标 `<新增>`、删除标 `<移除>`、空快照与非法快照不崩；
     - 审计 4 条：读到记录、能按对象名查到、归档动作与结果可见、带操作者。
   - 版本页截图验证：差异面板可见（"与 v1（解冻）比较：1 个字段变化"）。
   - 审计页截图验证：6 条记录（含 2 条被拒绝）。

## 未做 / 已知边界

- **审计按名字匹配**：同名不同类的资产可能串记录；要精确匹配需要给审计行加资产 Id 列（会动 CSV 表头，影响既有读端）。
- **删除不删文件**：物理删除需要独立动作（还要处理"文件被其它方案引用"），本轮不做。
- **归档资产仍可被插件按 Id 解析**：归档只影响界面展示与写操作，运行期解析没有拦。真要拦需在 `SolutionProjectAssetResolver` 加状态检查。
- 文件资产仍没有二进制版本快照，回滚只对标定开放。
- `BeadInspect` 配方资产化仍未做。
