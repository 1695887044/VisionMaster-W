## 一、做了什么（一句话）

新增"宿主数据库服务 + 插件三步骤 + 硬件管理数据库页"：配置集中在宿主，插件只选
`ProfileId + StatementId + 参数`，`.vms` 不含 SQL/连接串；v1 只支持 SQLite。

```text
Plugin.Database（Query / Execute / WriteRow）
   │ 只引用 Core.Interfaces
   ▼
IDatabaseAccess（Core.Interfaces.Database，默认 NullDatabaseAccess）
   │ 宿主实现
   ▼
Services\Core.Database（DatabaseService / DatabaseStore / SqliteExecutor / StatementValidator）
   │
   ▼
SQLite 文件（databases.json 存 profile + 命名语句）
```

## 四、关键口径（实现时定死的）

| # | 口径 | 理由 |
| --- | --- | --- |
| 1 | 契约一律 **Guid 寻址**（ProfileId / StatementId） | 显示名可改，改名不断链 |
| 2 | `.vms` 额外存**参数模式快照**（名字/类型/必填/默认值） | 编译期只调 `ApplyConfigValues`（`FlowCompiler.cs:883`），没有宿主可查语句定义；不存快照建不出端口 |
| 3 | v1 **不做 DPAPI** | SQLite 无密码；Provider 扩展时再补 |
| 4 | Query 输出增加 `Truncated(bool)` | 截断必须可观测 |
| 5 | 宿主页与插件窗口共用 `TryTestStatement` | 测试语义只有一份 |
| 6 | `MaxAffectedRows` 超限**事务内回滚** | 宁可不写，不误删 |
| 7 | `FailFast` = `Fail()` + 抛 + `RethrowOnException => FailFast` | 基类默认吞异常；只抛不停线 |
| 8 | 参数端口在 `ApplyConfigValues` 重建并回灌常量 | 运行实例不走 `Initialize` |
| 9 | 只读 profile 双保险：连接串 `Mode=ReadOnly` + 语句 Kind 白名单 | 不只靠 SQL 前缀判断 |
| 10 | 删除前深遍历方案引用；有引用拒绝删除 | 避免下次编译流程直接失败 |

## 六、过程中发现并修掉的两个问题

### 1. 插件缓存会被"加载失败"投毒（已修）

并行构建期间 `Modules\Plugin.Database.dll` 被另一进程占用/半写，全量扫描抛异常；
原实现仍然把该 DLL 写进缓存（只是没有插件条目）。下一次启动命中缓存、跳过反射与实例化，
**插件永久消失**，日志里只剩一条当时才可见的"加载插件失败"。

修法：`PluginService` 记录 `loadFailed`；有失败时 `PluginCache.Invalidate(pluginsDir)`
（删清单）且不写缓存，并留一行 Warn。下次启动重新全量扫描。
现场处理：删 `Modules\PluginCache\manifest.json` 即可恢复。

### 2. `TextBox.Text` 绑只读属性在布局期抛异常（已修）

`DatabasePageView` 的 `PreviewText` 是只读属性，`TextBox.Text` 默认 TwoWay →
`InvalidOperationException: 无法对只读属性进行 TwoWay 绑定`，且只在 `UpdateLayout` 时才炸。
修法：`Mode=OneWay`（R174 同族：任何 `BindsTwoWayByDefault` 的 DP 绑只读属性都要显式 Mode）。

## 七、与设计基线的偏差（已评估，可接受）

| 项 | 设计基线 | 实现 | 原因 |
| --- | --- | --- | --- |
| 结果预览 | `DataGrid` 动态列 | 等宽文本（制表符分隔，前 100 行） | 动态列需运行期生成列，v1 收益低、风险高；数据仍完整可读 |
| 页面视觉 | 1100×820 双栏 + 卡片 | 左列表 260 + 右滚动区（连接卡/语句卡），全部走 `Dialog*` 令牌 | 结构与信息层级一致；尺寸随硬件管理外壳自适应 |
| 语句测试参数 | 可编辑测试值 | 用参数表「默认值」当测试值 | 避免在测试区再引入一套参数编辑器；必填无默认值会明确提示 |
| Provider | 预留 SQL Server/MySQL | v1 只 SQLite，下拉未做 | 用户已拍板 SQLite 优先 |
