## 5. 踩过的坑

| 现象 | 原因 | 规避 |
|---|---|---|
| `type` 读中文 `.md` 全是乱码 | cmd 按 936 代码页解码 UTF-8 | 用 Read 工具或 `[IO.File]::ReadAllText(..., UTF8)`；不要用 `type` 看 UTF-8 文档 |
| 以为 `.zcode/` 已被整体退役 | 2026-10-24 退役的是 `.zcode/plans/`、workflow drafts 等 ZCode 桌面状态；`.zcode` 目录本身仍在 `root-layout.json` 白名单里，且治理结论把角色定义归客户端 | 只重建 `.zcode/agents/`，不恢复已退役的计划/草稿目录 |
| 角色文件差点写进 `docs/` | `docs/AI协作/README.md` 明确"角色定义归客户端，不进仓库文档" | 角色放 `.zcode/agents/`，仓库只留契约 |
| runner 无法执行拖拽/长按 | computer-use 仅主会话可用 | 契约与角色文件都写 `BLOCKED_NEEDS_MAIN`，不假装成功 |
| AGENTS.md 与脚本的宿主数量不一致 | R182 写"六个"，`run_gates.ps1` 实际 9 个 | 执行侧以脚本 `$hosts` 为准；本次只记录不改规则 |
