## 三、复刻时的四个 WPF 坑（都实测踩过）

1. **`Style=` 与 `<Xxx.Style>` 不能并存**：写了 `Style="{StaticResource X}"` 又想加触发器，XAML 直接报
   `MC3024 已设置属性…只能设置一次`。改法：只留 `<Xxx.Style><Style BasedOn=…>`。
   本轮踩了 4 处（chip、搜索框、生效中徽章、目标列）。
2. **`WindowStartupLocation` 不是依赖属性**（V5.1 已记）：不能进 `Style Setter`，否则解析期抛
   `ArgumentNullException(property)`，表现是"点入口没反应"。
3. **无 `Application` 的断言宿主里控件拿不到隐式样式**：必须从 `Generic.xaml` 现取 `Style` 赋给控件，
   否则量到的是"没套模板的空白控件"（与 `TankKpiChecks` 同一手法）。
4. **离屏出图必须显式设 `DataContext`**：探针第一版忘了设，六张图的 PNG 字节完全相同、
   所有 `Visibility` 绑定停在默认值——**图看起来"设计没生效"，实际是探针没接 VM**。
   现在探针每张图都打 `[state]` 与 `[pixels]`（64×64 采样 MD5）两行指纹，六张必须各不相同。

## 五、边界

1. **多选删除是逐条调服务**：每删一条都会递增内容版本，失败的那条留在表里并报原因（不做事务合并——服务层没有批量删除接口）。
2. **新建仍是"就地展开卡片"**，不是基线设想的独立弹层（基线 §9 明确允许这个过渡）。
3. **「仅显示差异」与参数搜索是纯视图过滤**，不改模型、不写盘。
4. **权限条只在"未登录"时出现**；"回滚锁定"那一态（基线 §7.1 最后一行）标为 v1.1。
5. **未做深色模式**：App 当前无运行时主题切换（R140 边界）。

已按 R166 删除，根目录回到 8 个文件。**这条要记住**：`-Command` 里的 `>` 后面写变量名会真的建文件。
