| 高级参数 | `UseFixedThreshold` / `FixedThreshold` / `ClosingRadius` / `ErosionRadius` / `DilationRadius` / `MinArea` / `MaxArea` / `ModelPath` / `ColumnFirst` | `[StepConfig]`，分割/形态学/模型/排序 | 只改外观；全部保留在折叠区 |

## 5. 改动点

1. **根布局**：删除固定 `Width=1000 Height=620`，改为 `MinWidth=560 MinHeight=280`；两栏 `Grid`：左栏 `1* MinWidth=280 MaxWidth=356`，右栏 `1.45* MinWidth=200`。
2. **左栏配置轨**：`ScrollViewer` + 五块内容（图像输入 / 识别区 / 常用参数 / 高级参数 / 试算），统一卡片（白底、浅描边、10px 圆角、12px 内边距）、标签 12px、输入框 36px、帮助 11.5px。
3. **图像输入**：`LinkableValueEditor` 设 `Label=""`，外置「输入图像」标签；`Port`/`StepData` 原绑定，链接/解除链接仍走控件自带按钮。
4. **识别区**：`RoiSummary` 放进等宽信息块；「清空识别区」用 `DialogSecondaryButton`；右上 chip 用 `CanvasRois.Count` 触发器显示「已框选/未框选」。
5. **常用参数**：`TextIsDark` 用 `DialogCheckBox`；四个字符尺寸用 2×2 `TextBox`（`DialogInput` 派生，高 36），全部保留原绑定。
6. **高级参数**：`Expander` 默认折叠；固定阈值、闭/腐/膨半径、面积、模型路径、列优先全部保留原绑定与 ToolTip；复选框文案从「按直方图自动找分界」缩短为「自动阈值」，完整说明留在 ToolTip，避免 280px 窄栏裁切。
7. **试算**：`DialogPrimaryButton` + `ResultSummary` 等宽结果块（`ScrollViewer MaxHeight=110`）；`Hint` 同时出现在试算卡与状态行。
8. **右栏画布工作区**：画布头（OCR 图标 + 「识别区画布」+ `ROI · 可编辑` + `ImageEdit`）、无图提示条、`ImageEdit` 常驻画布、状态行（中性点 + `Hint` + 识别区状态）。
9. **无图态**：不折叠 `ImageEdit`；无图提示放在画布**上方**的提示条（HALCON `HwndHost` 有 airspace，覆盖层会被 HWND 盖住）。`DisplayImage` 为 null 时显示，非 null 时折叠提示条。
10. **按钮命令化**：`ClearRoiCommand` / `TryRecognizeCommand` 定义在 `OcrView` code-behind，绑定用 `ElementName=OcrRoot`；只调用插件既有公开方法，满足批量冒烟的 `Button.Command` 契约。
11. **OcrPlugin 两处非逻辑修正**：
    - 无图试算文案从「先点『载入』把示意图读进来再试算」改为「先在『图像输入』绑定上游图像（或点『执行』试运行把图带进来）再试算」——原界面没有「载入」按钮；
    - `InputPort<HImage>` 的 `null` 默认值改为 `default!`，消除既有 `CS8625` 警告，运行期值仍为 null。
12. **颜色**：视图只引用公共令牌（`Dialog*` / `PluginPreviewCanvasBrush` / `ScadaSecondaryTextBrush`）；`hex=0`。未新增/修改任何公共字典键。

## 6. 与 ImageAcquisition V2 的差异

| 维度 | ImageAcquisition V2 | OCR v1 |
| --- | --- | --- |
| 信息架构 | 四种采集模式 2×2 卡片 + 模式专属面板 + 输出区 | 单图像输入 + 识别区 + 常用/高级参数 + 试算；无模式切换、无输出区 |
| HALCON 控件 | `ImageReadOnly`，用 `ContentControl` + `DataTemplate` **有图才创建** | `ImageEdit`（ROI 编辑），**常驻**；不做 ContentControl/折叠 |
| 空态 | 覆盖在预览画布中央 | 画布上方提示条（`HwndHost` airspace），画布保持常驻 |
| LinkableValueEditor | 4 个（FilePath/FolderPath/FileIndex/FrameTimeout） | 1 个（`Image`），无 `BrowseCommand` |
| 相机/网络/显示窗口 | 有 | 不适用 |
| 状态 | `StatusMessage` + `StatusLevel` 三档 | `Hint` 单行状态；插件没有 `StatusLevel`，不伪造 |
| 命令 | 插件暴露 `Browse*`/`Refresh`/`Prev`/`Next`/`PushLocalImage` | 插件暴露 `ClearRoi()` / `TryPreviewRecognize()` 方法；视图用两个 `ICommand` 转发 |
| 极性/枚举控件 | 4 个 `RadioButton` + `EnumConverter` 写 `Mode` | 1 个 `CheckBox` 写 `TextIsDark`（bool） |
| 渲染证据 | 5 张（四模式 + 错误） | 1 张初始态（批量冒烟）；无 `--ocr-render` 模式，且本轮禁止改 `UIThemeSmokeTest` |

## 8. 遗留问题

1. **真机回环未做**：需在 VisionMaster 中打开 OCR 配置 → 绑定上游图/点执行 → 右键新建矩形 → 拖拽句柄 → 试算 → 清空 → 确认 → 重开，验证 ROI 持久化与 `ResultSummary`。
2. **设计基线待用户确认**：`docs/UI设计基线/ocr/README.md` v1 与 `design.html` 已产出，尚未走用户确认。
3. **FlowCanvasChecks 未跑**：本任务只要求插件构建 + `--plugin-views`；该改动未触及共享契约，但按 SOP §5.8 仍建议 reviewer/主会话补跑 gate。
4. **无 `--ocr-render` 模式**：本轮禁止修改 `UIThemeSmokeTest`，只能提供批量冒烟的初始态 PNG；设计稿的五态交互在 `design.html` 里，WPF 五态截图需后续补。
5. **`StatusLevel` 不适用**：`OcrPlugin` 没有 `StatusMessage`/`StatusLevel`；本版没有新增状态枚举。若后续要三档状态，需插件 VM 新增属性，属于功能改动。
6. **无图时 `ImageEdit` 仍是黑色 HALCON 窗口**：提示条在画布上方，未做覆盖层；这是 `HwndHost` airspace 的已知边界，不是遗漏。
7. **高级参数文案缩短**：`UseFixedThreshold` 的界面文案从「按直方图自动找分界」缩短为「自动阈值」，完整说明在 ToolTip；如果现场更习惯原文，可回退并接受窄档裁切。
8. **`OcrPlugin` 文案/空值标注**：两处非逻辑修改已记录；reviewer 需确认没有把「文案调整」误判为功能变更。
