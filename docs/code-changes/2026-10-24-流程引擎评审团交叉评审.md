## 三、调度与触发链（scheduler-juror）

- **D1（high）** 子程序调用递归**无上限且跨线程**：`FlowInvoker` 层层嵌套 `Task.Run`，深递归既爆栈也爆线程池，且没有深度计数。
- **D3（high）** 变量触发无重入闸：变量被反复写入时同一流程可有多个会话并排启动，靠全局锁「挡住」而不是靠语义拒绝。
- **C1（high）** HTTP / SCADA 入口的锁定校验是 TOCTOU（`HttpImageServer.cs:321-329`、`ScadaFlowRunner.cs:162`）：校验与实际启动之间会话状态可被改动。
- **E1（high）** 插件缓存指纹缺目录维度：只比 DLL 大小 + mtime，未登记 `Plugin*.dll` 的检测依赖扫描顺序，改名/搬迁可能命中旧缓存。
- **A1（medium）** `Engine/FlowTickSource.cs:212-216` 周期按「完成时刻 + 间隔」计算，没有绝对时间轴，每轮漂移（sleep 抖动 + 执行耗时）逐轮累加。修法：`_nextDue += interval` 而不是 `_nextDue = now + interval`。
- 自动运行 `FlowAutoRunner.cs:36-38`/`:52-58` 的软跳过与其类注释「都不抢占」不符，消费方只拿到合并文案。
