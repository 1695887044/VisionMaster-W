## 1. 当前状态

三处用户可见的小毛病已修：

1. **自动模式「当前生效」标签不再写死**：命中结果输出步骤 → 主色标签「结果输出步骤」；
   没命中 → 琥珀标签「回退解析」，与下一行"未找到"不再自相矛盾。
2. **只读态只出现一行提示**：`ValidationText` 在只读时返回空串，只留 `ReadOnlyText` 一行；
   面板内的"请选择…"也不再在只读下亮起。
3. **变量候选可搜索**：变量面板加搜索框（名字 / 类型 / 来源任一命中），
   候选列表改绑过滤后的集合；已选变量永远保留，清空搜索恢复全量。

### 两条实现纪律（写在代码注释里）

- **不直接给 ComboBox 换 ItemsSource**：换源会清掉 `SelectedItem` 并经 TwoWay 推回 null；
  过滤走独立集合，重填后把已选项顶回去（与 R35 记录的"重填候选前先记住值"同一手法）。
- **已选变量永远保留在过滤结果里**：否则用户一边打字一边把已配好的选择弄丢。
