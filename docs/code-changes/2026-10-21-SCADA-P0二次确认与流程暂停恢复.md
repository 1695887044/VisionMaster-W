## 2. 关键语义与决策

### 2.1 确认闸门

- 挂在**事件钩子**上，不是单条动作上：确认一次，整串动作按原顺序执行；取消则一条都不执行。
- 未接线 / 无 WPF 上下文 / 确认出口抛异常：一律按取消处理（失败安全），记 Warn + 审计 `Skipped`；异常不冒到 UI 线程。
- 危险动作判据单源：`ScadaActionTypeExtensions.IsDangerous()`。当前集合 = 启动流程 / 停止流程 / 执行一次 / 轴停止 / 轴失能 / 轴定位 / 轴相对定位 / 轴回零 / 点动开始。
- 标题与主按钮文案同义：
  - 含停止流程 →「确认停止流程？」+「确认停止」；
  - 含轴停止/轴失能 →「确认停止设备？」+「确认停止」；
  - 含启动流程/执行一次 →「确认启动流程？」+「确认启动」；
  - 其它危险 →「确认危险操作？」+「确认执行」。
- `MessageDialog` 危险场景默认焦点在「取消」，Enter/Esc/Y 都是取消；底栏写明 Enter 取消 / Esc 取消 / 需点击或 Tab 到主按钮。

### 2.2 暂停/恢复

- 暂停只在**节点边界**生效：`FlowSession.DebugGateBeforeNode` 对 `IsContinuousRun=true` 不再要求 `DebugEnabled`，每个节点执行前检查 `PauseLock`。未暂停时只多读几个标志，不改变执行顺序。
- 恢复从当前节点继续，不是下一轮从第 1 步重来。
- 单次执行（`IsContinuousRun=false`）不支持暂停，返回「单次执行不支持暂停」。
- `ScadaFlowRunner.Pause/Resume` **校验会话状态真的迁移**（Running→Paused / Paused→Running）；引擎静默收手时返回 false + 原因，绝不把“引擎什么也没做”报成“已暂停/已恢复”。
- 幂等口径：已暂停再暂停 =「本就已暂停」；未暂停再恢复 =「本就未暂停」；两者都不重复调用引擎。

### 2.3 自动页状态

自动页仍是用户组态模板，P0 不新增流程状态源。推荐配置：

1. 暂停钩子：`PauseFlow` + `WriteVariable(Paused=1)`（写变量勾选「仅在上一条成功时执行」）。
2. 恢复钩子：`ResumeFlow` + `WriteVariable(Paused=0)`（同样勾选）。
3. 页面用 `Paused` 变量 + 可见性/外观动画显示“已暂停”。

条件动作保证：`PauseFlow` 被跳过/失败时，写变量不执行，页面不会出现假“已暂停”。

## 6. 未决 / 风险

- 自动页是**模板**：WPF 不提供固定自动页；真机需用户按现场变量命名落地 `Paused`。
- 暂停/恢复只在连续运行可用；单次执行明确拒绝（P0 范围）。
- 轴控台既有 `Confirm(title, message)` 调用现在走 Warning 语气 + 默认焦点取消；480/560 宽度的长文案仍建议真机复核。
- 确认弹窗不承诺副标题/结构化详情/富文本，只使用 `MessageDialog` 现有槽位。
- 本批未改插件源码，`Modules\` 无需重建；`Core` 引擎变更已通过 `FlowCanvasChecks` 回归。
