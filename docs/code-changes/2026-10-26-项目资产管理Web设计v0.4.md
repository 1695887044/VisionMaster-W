## 踩过的坑

- **不能拿空 `ModelPath` 假装已配置**：当前 5 个模型槽位都是空路径，演示必须标“未绑定”，否则会把设计稿变成假能力。
- **模板不等于模板匹配**：`BeadA` 是胶路 RecipeLibraryJson，`Board01` 是几何查找 ROI，`OCR_Lot` 是 OCR 参数，三者不能套同一字段模板。
- **图像资产必须有哈希和尺寸**：只写文件名无法做版本和追溯；本次从磁盘取 10 个真实文件的大小、分辨率和 SHA-256 前缀。
- **列表/详情/健康度要同源**：切换页签后三处计数必须同步，否则一眼露馅。
- **标定 6 个是 UI 样例**：当前方案实际只有 `LineCalib` 1 个，文档必须说清楚。
- **断点被主题覆盖**：浅色主题的 `.workspace { 240/1fr/440 }` 写在 `@media` 之后，导致 1440 仍用桌面列宽、列表被挤窄；断点必须放在主题之后，且 1440 采用紧凑列宽保留全部列。
