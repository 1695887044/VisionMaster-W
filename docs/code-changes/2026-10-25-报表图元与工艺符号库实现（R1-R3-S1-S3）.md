## 五、踩过的坑

| 坑 | 现象 | 处置 |
| --- | --- | --- |
| 只读 DP 用公开属性 SetValue | `InvalidOperationException：“HasRows”属性已注册为只读；必须具有授权密钥` | 一律用 `XxxPropertyKey`；`HasRows/PageText/FooterText/TitleMeta` 四处都踩过一遍 |
| 属性袋键 ≠ CLR 属性名 | 测试里 `SetProperty("ColumnsJson", …)` 静默无效，图元报"还没有配置列" | 落盘键是 `ReportColumns`（`ScadaReportCodec.Key`）；断言按**键**设置 |
| 自定义数值格式不抛异常 | `10.256.ToString("{{bad}}")` 返回字面量 `{{bad}}`，不抛 `FormatException` | 用非法**标准**格式 `"Q"` 才能测到回落分支 |
| 描述符 `Min` 会夹住测试值 | `PageSize=2` 被夹到 20，5 行只有 1 页，分页断言假红 | 断言改用 45 行 + 每页 20 行 |
| 工具箱搜索词冲突 | `Hmi.Symbol` 的说明里含"风机"，"搜索命中说明文字"从 1 命中变 2 | 搜索词换成"软管"（与之前"罐体"同一类维护动作） |
| `GeometryGroup.Children` 套了一层 | 细部被包在内层 group 里，断言数出 1 条 | `BuildDetail` 摊平进外层 group（返回 `GeometryGroup`） |
| 元素属性名与类型名同名 | `public partial string? SymbolKind` 遮蔽 `enum SymbolKind`，`SymbolKind.Tower` 编译不过 | CLR 属性改名 `Symbol`，落盘键仍是 `SymbolKind` |
| 并发会话改同一仓库 | `FlowCanvasSurface.cs`/`RecipeManagerView.xaml` 半改状态导致 `dotnet build` 报 CS0103/MC3072；运行中的 `VisionMaster.exe` 锁 `VM.Scada.Controls.dll` | 不碰别人的文件；等 mtime 稳定后重试；期间用 `-p:OutputPath=artifacts\tmp\rrun\` 编到临时目录跑断言，收尾再回真实输出跑 gate |
