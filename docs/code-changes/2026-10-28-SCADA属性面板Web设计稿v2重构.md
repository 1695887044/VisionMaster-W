## 踩过的坑

1. **flex 列容器里的卡片会被压缩**：`.scroll{display:flex;flex-direction:column}` 定高时，子项默认 `flex-shrink:1`，内容多的卡被压扁、`overflow:hidden` 把行截掉（表现为「基本卡只剩名称标签」）。修法 `.scroll>*{flex:none}`，让溢出交给滚动而不是压缩子项。
2. **`?shot` 模式的 `main{margin-top:26px}`**：v1 踩过（H 系列之外的页面级坑），v2 重写时直接带上 `body.shot main{margin:0}`；漏掉会让 860 高的编辑器整体下移、底部页签出不了图。
3. **绝对定位弹出层被卡片的 `overflow:hidden` 裁切**：标本页里取色板演示要给该卡单独 `overflow:visible`。
4. **无头 Edge 批量截图竞态（H-02 的正解）**：`& msedge ...` 返回的是启动器进程，循环里连续启动会复用浏览器进程导致 `--window-size` 失效（全部 756×488）。改用 `[System.Diagnostics.Process]::Start + WaitForExit(25000)`（超时杀）逐张等待后，8/8 尺寸全部正确——已补进台账 H-02 的解法。
5. **零命中卡的静态示例**：设计稿里手写「搜索命中」静态卡时，不要画 0 命中的组卡（真实搜索中零命中卡隐藏），否则与计数规则自相矛盾。
