## 一、背景

上级评估列出的问题（P0/P1/P2）在本轮一次性清零。四类共同主题：

1. **"0 当哨兵"的静默语义错误**——旧实现拿 `0` 表示"没填"，于是"机械坐标恰为 0"的合法标定点会被误判半填（报错）或静默剔除（标定悄悄算歪）；表格残差列同族：机械系偏差（mm）被直接写进"残差px"列。
2. **配置态反馈不完整**——闸门未过时旧实现清空质量数字，现场调点没有"差多少"的收敛反馈；标定时间戳每轮重算被刷成"刚刚"，下游"标定多久没更新"失去意义；A/B 未取点时拿默认 (0,0) 悄悄算。
3. **现场易用 / 易误改的缺口**——方案承诺的"逐行图上取点"（§五②）与"标定线占视野百分比"（§五①）未落地；没有防现场误改的锁定开关。
4. **跨语言消费安全**——径向带"无点带 = NaN"会被 JSON 序列化成非标准 `"NaN"` 字符串，且没有计数无法区分"残差真的是 0"与"这个带没点"。

## 二、改动清单

### 2.1 数据模型：null = 未填，0 是合法坐标（`Models\CalibPointRow.cs`）

- 四坐标 `double` → **`double?`**：`null` = 未填；**0 是合法坐标**（机械回零位、工件原点、图像边缘都可能取到 0）；
- `IsEmpty / IsFilled / IsPartial` 全部改按 null 判定（0 参与 `IsFilled`）；
- 新增 `NormalizeLegacyAllZero()`：**旧方案迁移**——"四值全 0"的行 → null。旧实现本来就把这种行当空行（不参与求解），故迁移**不丢任何真实标定点**；已是 null 的行是空操作（幂等）；
- 注意："半填且含 0"的旧行（如机械 X=0、图像 Row=0）迁移后会被当成有效点——这类点在旧版是报错行，新版若位置不对会被残差闸门拦下（不会静默放行）。

### 2.2 执行核心：闸门未过不再清空质量数字（`CalibrationPlugin.cs`）

- 新增内部类 **`CalibrationAttempt`**（`Transform` / `BlockingError` / `GateError` 三分；`Succeeded` = 两者皆空）：把"数学解出"与"质量闸门通过"分开表达；
- `TryComputeCalibration` → **`ComputeCalibration()`**（唯一一份计算，配置态与运行期共用）；
- 残差超阈值 / 当量越界时：`attempt.Transform` 仍保留 → 配置态质量区**红字照常显示残差数字**（"看得到差多少"是调点的前提）；运行期照旧失败且不发布端口。

### 2.3 像素当量：A/B 可空 + 明确失败 + 跨度提示

- `ScaleARow / ScaleACol / ScaleBRow / ScaleBCol` 改 **`double?`**；新增 `TryPixelScaleFromConfig`：任一为 null → **明确失败**（"A / B 两点尚未取全"，给下一步），不再拿默认 (0,0) 悄悄算；
- 新增跨度提示 `ScaleSpanText` / `ScaleSpanLevel`：A–B 距离占**视野对角线百分比**，< 33% 橙字"偏短"（方案 §五① 的承诺落地）；
- A/B setter 钩子 `SyncScaleMarker`：表格改值 → 画布 A/B 标记跟随（与"拖标记→回写表格"构成双向同步）。

### 2.4 配置态回写：表格残差列按像素口径（`ApplyRowResiduals`）

- 回写值 = 反算偏差（机械系 mm）**÷ 当量 → 像素**，与 `TrySolveAffine` 内部残差、残差闸门（1px）同口径（0.5mm、当量 0.02 → ≈22px，而不是 0.5）；
- 配置态每次计算都回写（表格残差列不再"要跑一次流程才填"）；
- 病根与上一轮 P0（mm→px）同族：表格列头写"残差px"，写进去的却是 mm。

### 2.5 收集点：null 语义 + NaN/Inf 按行名指名（`CollectPoints`）

- 半填行文案更新为："标定表第「{行名}」行只填了一部分：机械X / 机械Y / 图像Row / 图像Col 必须四值齐全（**整行不填 = 空行，不参与计算；0 是合法坐标值，不会被判成没填**）"；
- NaN/Inf 在插件侧**先按行名指名**（"标定表第「P2」行含非法数值（NaN/Inf）——请检查该行的填写"）；数学层兜底文案改为"参与求解的第 N 组点…"（"第几个有效点"与表格行号对不上，两边都报便于定位）。

### 2.6 标定时间戳：签名不变不推进（`CalibrationStampUtc` + `BuildInputSignature`）

- 新增 `[StepConfig] CalibrationStampUtc`（标定配置最后改动时间，UTC）；`BuildInputSignature()` 拼装模式/网格/表格四值/A、B/相机/来源标签/图尺寸（用 `double?` 原始值拼串，**null 与 0 拼出不同的串**）；
- 三条路径都照顾到：**首轮只记签名**（载入的标定时间是权威，仅空值时补 UtcNow；流程编译出的运行实例只走 `ApplyConfigValues`、不经配置界面 `Initialize`，不区分的话每次运行首轮都会刷成"刚刚"）；**签名变化 → 推进**；**签名不变 → 不动**（运行期每轮重算不刷"刚刚"）。

### 2.7 锁定防误改（`IsCalibrationLocked` + `IsEditable`）

- 新增 `[StepConfig] IsCalibrationLocked`（默认 false）+ 只读 `IsEditable`；
- 守卫覆盖：**粘贴 / 重建网格 / 清空表格 / 取点（ArmPick）/ 拖标记（弹回表格记录位置，"数据是权威"）**；**模式切换与网格下拉**经 XAML `IsEnabled={Binding IsEditable}` 在 UI 禁用；
- **只锁输入不锁输出**：锁定期间照常重算与输出，下游不受影响。

### 2.8 图上取点通道（一次性点击回填）

- 插件侧：`PickRowPointCommand`（逐行，参数=行）/ `PickScalePointCommand`（A/B）/ `CancelPickCommand`（再点一次或 Esc 取消）；`IsPickingPoint`（待命态，绑定画布 `IsPickMode`）、`ApplyPickedPoint(row, col)`（画布点击回填，public）；
- 视图：表格新增"取点"列（逐行按钮）、A/B「取A点/取B点」按钮、取点待命**橙色横幅**（`{ui:BooleanToVisibilityConverter}`）、`CalibrationView.xaml.cs` 把 `ImageEdit.ImagePicked` 转交插件、Esc 取消、`Unloaded` 取消待命；
- 双向同步：表格改值 → `SyncMarkerFromRow` / `SyncScaleMarker` 更新画布标记（值没变不写原生句柄）。

### 2.9 粘贴解析 / 清空 / 标记半径 / 预览清尺寸

- `PasteRows` / `TryParseRows`：**Tab 分隔保留空单元格**——空格子 = 未填（null）；**行首空列也保留 = 未填**（剥掉会把后面的列顶到前面，整行错位）；行尾空列裁掉；全空行跳过；4 列/5 列（带序号）兼容；0 是合法值；
- `ClearRows` 置 null（保留行数与行名，不再用 0 占位）；
- `MarkerRadiusFor`：标记半径随图幅 `clamp(min(宽,高)/60, 8, 48)`（大图不至于看不见、小图不成一坨）；只影响"看得见"，不参与计算；
- `EnsurePreviewLoaded` 空路径分支：清空路径时**同步清掉 `SourceImageWidth/Height`**（标定图元信息随之作废，下游失配自证不拿旧尺寸当依据）。

### 2.10 算法层（`CalibrationMath.cs`）

- `TrySolveAffine` 新增 `out int[]? bandCounts`；**无点的带残差记 0（原 NaN）**，"这个带没有点"由计数表达；
- `DiagnoseRadialBands(bands, bandCounts = null, minEdgeResidualPx = 0.5)`：给了计数时，**中心带与边缘带必须都有点才判形态**（3 点标定常见"只有中心带有 1 个点"，没有计数会被误读成"中心残差 0 → 畸变"）；提示门限参数化；
- 插件侧传 `max(0.5px, 残差阈值 × 0.5)`（现场显式放宽阈值时，0.5px 的"边缘偏大"不再提示）；
- NaN 文案改"参与求解的第 N 组点…"（行名由插件侧给，见 2.5）。

### 2.11 跨插件契约（`Shard\Core.Interfaces\Calibration\CalibrationTransform.cs`）

- 新增 **`int[] ResidualBandCounts = new int[3]`**（加法字段，JSON 往返安全）；
- `ResidualByRadiusBands` 语义：**无点带 = 0（原 NaN）**——NaN 会被序列化成非标准 `"NaN"` 字符串，跨语言消费有风险；消费方**先看计数再看均值**，计数为 0 的带均值无意义。

### 2.12 共享画布基类（`Services\Core.Halcon\Base\HalconBase.cs`）

- 新增 **opt-in 取点通道**：DP `IsPickMode`（**默认 false**）+ `ImagePickEventArgs` + `ImagePicked` 事件；仅 `IsPickMode = true` 时左键单击触发（订阅方异常吞掉，不打断 HALCON 鼠标管线）；
- 涂擦（`HSmart_MouseDownForSmear`）与 ROI 选中（`HSmart_MouseDownForRoi`）在取点模式**早退**——取点优先，不抢编辑对象；
- **其它插件零行为变化**（不绑定的控件行为与旧版完全一致）。

### 2.13 配置视图（`CalibrationView.xaml` / `.xaml.cs`）

- 模式单选、网格下拉、重建网格、粘贴/清空/取点/标记按钮全部 `IsEnabled={Binding IsEditable}`；
- 取点横幅；画布 `IsPickMode` / `ImagePicked`；Esc 取消取点；
- ③ 卡片：**锁定 CheckBox**「锁定标定（防误改）」+ 当量护栏 **min/max 输入框**；
- 像素当量区：A/B 取点按钮、A/B Row/Col 输入（`TargetNullValue=''`，空 = 未填）、跨度提示行；
- 表格：新增"取点"列；表尾提示更新为"整行留空 = 空行（不参与计算）；**0 是合法坐标值**（回零位取点不会被当成没填）；半填行运行时报错并指到行…"。
