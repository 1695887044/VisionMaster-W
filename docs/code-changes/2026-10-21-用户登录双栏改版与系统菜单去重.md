# 用户登录双栏改版 + 系统菜单去重

- 日期：2026-10-21
- 范围：`ScadaLoginView` / `ScadaLoginViewModel`、`Shell.xaml`、`UIThemeSmokeTest\ShellCopy.xaml`
- 起因：用户反馈「只看到登录设计稿，没看到 UI」；同时系统菜单里仍能看到相机设置 / 运动板卡 / 通讯设置，与「统一收进硬件管理」矛盾。

## 1. 登录窗按设计稿落地

原实现是 440px 宽、`登录 / 修改密码` 两个并列页签的小弹窗；批次 B 只改了令牌与关闭键，视觉没有落地设计稿。本次重做为 820×560 双栏：

- **左栏（品牌 / 上下文）**：VisionMaster 标识、当前方案名、当前身份、可用权限、空闲策略、会话说明与版本号。方案名来自 `IWorkspaceManager.CurrentSolution`（VM 新增 `SolutionName`）。
- **右栏（账号区）**：顶部 `ACCOUNT / LOCAL SESSION` + 关闭；正文按状态切换：
  - 未登录：登录标题/说明、出厂密码提示条、账号/密码输入、失败原因、主登录按钮、忘记密码与操作员权限说明。
  - 已登录：当前身份、权限说明、空闲策略、修改密码/退出登录。
  - 修改密码：用户名/当前密码/新密码/确认新密码、结果提示、返回登录（VM 新增 `BackToLoginCommand`）。
- 无边框窗口顶部补 `ui:WindowDragBehavior.IsWindowDraggable`，保留拖动能力（守门断言要求每个自绘标题栏可拖动）。
- 窗口设 `AllowsTransparency=True` + 透明背景：卡片外 14px 是阴影区，不再是白底窗口边（用户截图里的“白框”）。
- 用户名/密码一改动就清掉上一次的登录失败提示，避免“密码框已有内容、下面还挂着‘请输入密码’”。
- 未引入无数据支撑的「记住账号 / 忘记密码跳转」：界面上只给「请联系管理员在用户管理中重置」的说明。

## 2. 系统菜单去重

- `Shell.xaml` 的「系统」菜单删除 `相机设置`、`运动板卡`、`通讯设置` 三项；统一保留 `硬件管理`。
- 顶栏原「通讯设置」快捷按钮改为 `HardwareSettings`，图标/提示改为「硬件管理」。
- **命令面板（Ctrl+K）** 同步删除「相机设置 / 运动板卡 / 通讯设置」，改为「硬件管理」——否则菜单没了，搜索仍能打开旧入口。
- `SystemAction.CameraSettings` / `MotionBoard` / `CommSettings` 枚举值与 `OnSystemAction` 分支**保留**：旧布局、脚本、快捷键仍可触发，只是不再出现在菜单/命令面板 UI；它们继续深链到硬件管理对应页。
- `UIThemeSmokeTest\ShellCopy.xaml` 同步删除三项、同步顶栏按钮（R44）。

## 3. 守门

- `UIThemeSmokeTest` 新增：
  - 「用户登录视图能实例化并完成布局（双栏 / 资源键 / XAML 解析）」——820×560 真实 Measure/Arrange。
  - 「系统菜单不再重复暴露相机/运动/通讯入口（统一走硬件管理）」——Shell.xaml 的 SystemAction 集合里不允许再出现这三项。
  - 原「两个全局命令（全局变量/通讯设置）在停靠区之前」改为「全局变量/硬件管理」。
- `FlowCanvasChecks` 新增 **HW21**：`BuildCommandPalette` 不许再出现相机/运动/通讯三项，必须保留硬件管理。
- `FlowCanvasChecks` 的窗框检查要求 `ScadaLoginView` 自绘标题栏带 `WindowDragBehavior`，已满足。

## 4. 验证

- `dotnet build VisionMaster.sln`：**0 错误**。
- `UIThemeSmokeTest`：登录视图 820×560 实例化通过；系统菜单去重通过；ShellCopy 集合一致。整体退出码仍为失败，但唯一红项是**并发改动**的 `VisionMaster\Views\ScadaRuntimeWindow.xaml` 硬编码颜色 14→19（与本改动无关，未触碰该文件）。
- `FlowCanvasChecks`：**3168 通过 / 0 失败**（含 HW21）。
- 真机：系统菜单打开用户登录，双栏布局、当前方案/身份/权限/空闲策略、出厂密码提示、登录表单均正常显示；窗口外白框已消失（透明窗口 + 卡片阴影），账号输入框聚焦、密码框可输入。

## 5. 已知边界

- 登录状态仍只在本机会话；没有新增持久化（记住账号、上次登录时间等）。
- 系统菜单去重只改 UI；旧入口枚举/处理分支保留，旧布局或脚本仍能打开对应页（会落到硬件管理）。
