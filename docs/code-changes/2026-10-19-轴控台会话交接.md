## 1. 用户裁定（已定，不要重新论证）

| 决策点 | 结论 |
| --- | --- |
| 控件形态 | **轴选择器 + 单轴视图**，不做多轴同屏 |
| 监控与运动 | **必须同一个控件**（避免"看 X、动 Y"的错靶） |
| 点位表 | 合并进轴控台；旧 `Hmi.AxisPointTable` 只做兼容别名 |
| 运行期改配置 | **有足够权限就可以改**（示教/改速度）；权限走 `RequiredRole` |
| 参数设置弹窗、点位改名 | **不做**（属于配置项，继续在「运动卡设置」里改） |
| 外部改点位 | **要自动刷新**（已实现：节拍 + 指纹短路） |
| 视觉 | 参考 `web-70060145-source` 的暗色控制台 |

## 5. 给下一个会话的硬纪律

- 改任何具体文件前先 `Read`（磁盘为准，别信本摘要里的行号）。
- 轴相关：
  - 轴身份一律 `AxisId`，名字只做展示/旧数据兜底；
  - 有 Id 就只认 Id，不按名兜底（防"删旧建新同名"错靶）；
  - 切轴先停旧轴点动（`e.OldValue`）；
  - 点动停止只在卡收下后才清租约；
  - 离线不编 0（`IsValid=false` + "—"）。
- 运动口径（2026-10-19 晚定稿）：
  - **停止/失能是安全动作**：`Alarm` / `SafeStopped` 都放行（`MotionCommandGate.CheckSafetyAction`）；
  - **使能只认 Online**：报警态先清报警（`CheckEnable(device, true)`）；
  - **清报警按 `PhysicalAxis` 单轴下发**：`>=0` 只清那一根，`<0` 才是卡级清全部；
  - **回 Online 由轮询确认**（所有轴无致命信号），不在命令完成回调里直接置；
  - **清报警成功要摘该轴的报警去重记录**，否则"清完立刻又报同一原因"会被静默吞掉。
- 控件：
  - `ControlTemplate` 里的 `DataTrigger` 本环境不触发；显隐用控件算好的 `Visibility` DP。
  - `DataTemplate` 里没有 `TemplatedParent`；颜色/可见性/可编辑性用 `RelativeSource AncestorType=图元类型`。
  - 分册里的 `StaticResource` 只能看本分册（R30/R31），不许跨册。
  - 不要在 `Control` 子类上声明名为 `IsEnabled` 的 DP（用 `AxisEnabled`）。
  - **轴选择器绑 `SelectedItem`（`SelectedAxisItem` DP），不要绑 `SelectedValue`**：
    `ItemsSource` 后到会把选中置空，屏幕上是空框（AX14 守门）。
  - **点位区高度 = `PointsRows * 22`**：表头在 `ScrollViewer` 外面，不要把 18px 表头算进
    `PointsHeight`，否则"6 行"实际会显示 8 行。
  - **点位表列头必须与数据行同列宽**（`* / 58 / 46 / Auto`）：改列宽要同步改 `PointsHeader`，
    否则列头与数字错位。
  - **示教/定位默认二次确认**（`ConfirmCommands`，操作组，默认 True）；执行顺序固定为
    **权限 → 确认 → 出口**：`CheckCanRun` 先判权限，没权限的人根本不会弹确认框。
    宿主必须接 `IScadaConfirmationService`（`ScadaRuntimeHost` 已接）；没接时拒绝执行，
    不许静默跳过确认。
- 同一控件类多预设：用 `ScadaPropertyCatalog.WithDefaults`，不要复制控件类。
- 配置型数据展示：每拍重读 + 指纹短路（R138）；没变化不重建行。
- 改过任何 `Help\**\*.md` 或 `.xaml` 资源后按仓库规则重建（R42/R62）。
