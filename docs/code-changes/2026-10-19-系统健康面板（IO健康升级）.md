# 系统健康面板（IO 健康升级）· 阶段 1-3 落地

- 日期：2026-10-19
- 前置：`docs/code-changes/2026-10-19-系统健康面板阶段0（门禁可信化与三处前置修复）.md`
- 设计基线：Web 原型 `system-health-v1`（用户已确认）

## 1. 交付形态

一个弹窗「系统健康」，5 个一级页签：

| 页签 | 内容 |
|---|---|
| 概览 | 4 张域摘要卡 + 异常优先表（默认只列 Error/Warn）+ 搜索 + 正向空态 |
| 通讯 | 状态/连接/协议/端点(含 L 标记)/角色/轮询/失败原因 |
| 相机 | 状态/相机/序列号/驱动/说明/帧率/收·待·溢·丢/最近收帧 |
| 运动 | 状态/卡/驱动/地址/轴/回零/最近故障(历史)/计数 |
| IO | 复用原 IO 健康面板（4 个子页签：设备/总线/点位/写入审计） |

窗口 1180×700，`MinWidth=1176`（四张表列宽合计 ≤1100 + 边距 + 滚动条）。

## 2. 数据层（`VisionMaster/Services/Health/`）

| 文件 | 职责 |
|---|---|
| `HealthTypes.cs` | `HealthLevel`（Idle<Ok<Warn<Error，聚合取 max）、`HealthIssue`、`HealthDomainSummary`、`HealthLevels` |
| `CameraHealthMonitor.cs` | 相机只读采集 + 判级 |
| `MotionHealthMonitor.cs` | 运动卡只读采集 + 判级 |
| `CommunicationHealthMonitor.cs` | 通讯连接只读采集 + 端点归一化/关联 |

三条关键口径：

1. **相机只有"本采样周期收到帧"才判 Ok**。契约没有 `LastFrameTime`，`Streaming` 状态不证明出图
   （基类在调驱动之前就置 Streaming）。无新帧只判 Warn，文案固定写"可能未触发或已停拍；不代表掉线"。
   设备重建/计数倒退按"重置"处理，不产出负帧率。
2. **运动判级不看 `LastFault`**。它在 `MotionDeviceBase` 里全仓无清空点，且"命令被拒绝"也会写它；
   拿它判级会让修好的卡永久红灯。`LastFault` 只作"最近故障（历史）"列。`IsHomed` 是卡级，
   文案写"已回零（卡级）"。
3. **通讯读 Worker 真值**（`GetConnectionState`/`GetConnectionError`），不读 `config.State`
   ——后者经 `SafeDispatch`，无 `Application` 的宿主会永久停在 Disconnected。

## 3. 视图模型层

| 文件 | 职责 |
|---|---|
| `HealthPanelViewModelBase.cs` | `IHealthPanel` 契约 + 基类（异常隔离、等级聚合、`SyncRows` 原位对齐） |
| `HealthPanelViewModels.cs` | 通讯/相机/运动三个面板 VM |
| `SystemHealthViewModel.cs` | 壳：5 页签、唯一 1s `DispatcherTimer`、概览聚合、IO 适配器 |
| `IoHealthViewModel.cs` | 保留原实现，只加 `public Refresh()` 供壳调用（不启动自身定时器） |

**定时器只有一个，在壳里**。子面板只提供 `Refresh/ForceRefresh/CollectIssues`。
概览页刷新全部四域；停在某个域页签时只刷新该域（IO 点位多时避免每秒物化几千行）。

**异常隔离**：基类把单个面板的异常变成该面板的一条 Error 问题行，其余面板照常刷新；
壳在 `RefreshAll`/`Tick` 再兜一层。一个坏相机不会冻住整页诊断。

## 4. 视图层

- 新增 `SystemHealthView.xaml`（5 页签 + 4 张表 + 概览卡）。
- `IoHealthView` → `IoHealthPanelView`：删掉 `AutoWireViewModel`、`Dialog.WindowStyle`、
  自绘标题栏、`CloseCommand` 绑定；改为 UserControl，DataContext 由壳给（`{Binding Io}`）。
  **删 `AutoWireViewModel` 是硬要求**：保留它 Prism 会另建一份 VM 覆盖壳的，表现是"表格永远空且不报错"。
- 每个 ListView 挂 `GridListViewStyle` + 自带行模板（`GridViewRowPresenter`）+ 就地合并 `GridView.xaml`（R19-R22）。

## 7. 与原型的两处偏差（需要下一批收口）

1. **IO 页签内部仍是 4 个 TabItem**，不是原型里的 chips。功能等价，但多一行页签头，
   与"5 个一级页签 + 域内 chips"的设计不完全一致。
2. **概览表少了"持续 / 最近成功"两列**（原型有）。这两项需要每个域额外记录"首次进入异常的时间"，
   属于下一批的数据增强。
