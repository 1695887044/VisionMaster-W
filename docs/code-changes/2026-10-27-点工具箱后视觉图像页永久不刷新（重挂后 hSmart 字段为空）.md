# 点工具箱后视觉图像页永久不刷新（重挂后 `hSmart` 字段为空）修复（2026-10-27 批 3）

> 现场：两个流程在跑 → 点了一下工具箱 → 图片不再刷新；再跑第三个流程 → 图像窗口一片空白。
> 查下来是**两条互不相干的原因**：A 是显示层回归（本篇修的），B 是画布布局与插件窗口号不匹配（口径问题）。

## 一、当前状态

### 原因 A（已修）：`Unloaded` 把 `hSmart/hWindow` 置空，`Loaded` 里还在读字段 → NRE

`HalconBase.OnControlUnloaded` 今天为修"幽灵格子拿失效窗口调 RenderAll、把进程级 `flush_graphic`
设成 false"而新增了字段置空（`HalconBase.cs:83-84`）；但 `OnApplyTemplate` 里挂的
`hSmart.Loaded` 回调读的是**字段** `hSmart`。点工具箱胶囊（自动隐藏面板）→ `LayoutHelper.ShowPanel`
→ AvalonDock 重挂文档区 → 画布 **Unloaded → Loaded** → 回调跑起来时字段已是 null。

日志两次同栈（15:29:23 / 15:30:43，都在点胶囊后 60~170ms）：

```
15:30:43.126 [胶囊] Click 到达 … 工具箱 Panel_ToolView
15:30:43.130 [ShowPanel] Panel_ToolView 自动隐藏收回后 auto=False parent=LayoutAnchorablePane
15:30:43.190 [ERR ] [全局异常] UI 线程未处理异常（已拦截，界面继续运行）：
System.NullReferenceException
   at Core.Halcon.Controls.HalconBase.<OnApplyTemplate>b__62_0(...) in HalconBase.cs:line 437
   at System.Windows.BroadcastEventHelper.BroadcastLoadedEvent(Object root)
```

链路后果两条，叠加起来就是"整页永久不刷新"：

1. 抛异常的那个控件 `hWindow` 没被恢复 → 之后每次 `RenderAll()` 都卡在 `if (hWindow == null) return;`；
2. 异常从 `BroadcastLoadedEvent` 抛出去 → **这次 Loaded 广播剩下的元素全被跳过** → 同一页其它
   画布（每个 `ImageDisplay`、对比大图）的 `Loaded` 回调也没跑 → 它们的 `hWindow` 同样停在 null。
   再切标签也会在同一行再抛一次，所以**不自愈，只能重启**。

**已修**：回调改用事件源重新取实例，并把字段补回去；ROI 补挂前判 `hWindow != null`。
顺带发现一条**新的硬事实**：重挂之后 `HSmartWindowControlWPF` 会给出**新的 `HWindow` 实例**
（旧句柄只是残留缓冲）——所以"字段必须重新取"不只是防 NRE，也是防往死窗口里画。

### 原因 B（未改代码，口径问题）：流程投窗口 3/4，画布是单画面只认窗口 1

- 方案里 `"ImageViewMode": 0`（`eViewMode.One` = 单画面）；退出时的自动草稿同样为 0。
- 同一份草稿里 `DisplayViewIndex` 出现 **1 / 3 / 3 / 3 / 4 / 4**（磁盘 `.vms` 全是 1，说明本会话里改过）。
- 日志：`[图像集] 已收录 … → 窗口 3` / `→ 窗口 1` / `→ 窗口 4`。
- `ImageView` 单画面只摆 1 格（`ViewIndexFilter = 1`），`ImageGallery.Recompute` 里
  `all.Where(f => f.ViewIndex == ViewIndexFilter)` → 窗口 3/4 的帧**收进来了但没有任何一格接收**。

## 五、踩过的坑

1. **"置空字段"和"读字段"必须成对改**：`OnControlUnloaded` 置空 `hSmart/hWindow` 是必要的（防幽灵格子），
   但 `Loaded` 回调、`RenderAll`、ROI 补挂都必须能在"重新 Loaded"时恢复——否则一次布局重挂就永久死。
2. **重挂后 `HWindow` 是新的实例**：拿重挂前缓存的 `hw` 去 `DumpWindowImage` 读到的仍是旧缓冲，
   断言会得到"图还在"的假象（本轮 ⑥ 就这样假红过一次）。**一律从 `hSmart.HalconWindow` 现取**。
3. **`Loaded` 广播里的异常会波及其它控件**：一个控件在 `Loaded` 里抛，`BroadcastLoadedEvent` 后面的
   元素全部收不到 `Loaded`——所以"某个控件崩了"在 UI 上的表现可能是"一整页都不刷新"。
4. **断言宿主在插件目录被重写时会静默死掉**（无 stderr、无 WER 事件、日志截断）：跑宿门前先确认
   `Modules` 最新 mtime 稳定 ≥ 45s，且没有并行 `dotnet` 构建。
