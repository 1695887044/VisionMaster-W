# 2026-10-08 Core.Halcon 第二批（缩放保持 / 直方图上提 / 标定残差箭头 / 伪彩 LUT）

## 一、背景

三方评审（ui + vision + 主会话仲裁）产出的分批清单中的**第二批**四项。第一批见《2026-10-08-Core.Halcon第一批菜单重构》。本批三条来自评审仲裁（直方图"上提"而非新写、缩放保持采用"进程内 LRU"形态而非 VM 持久化）、一条来自 vision 评审遗漏（伪彩 LUT 是"一行原生调用 + 一个菜单项"的最便宜档）。

## 二、改动清单

### 1. 缩放状态保持（HalconBase.cs）

- **动机**：控件 Unloaded 即销毁 HALCON 窗口——配置窗口关了再开 / 图集帧切换都从"铺满"起步，用户每轮调参都要重新缩放定位。
- **形态**（仲裁）：进程内静态 LRU 表（容量 4），键 = `图像宽<<32|高`，值 = 不可变 `record ViewPart(r1,c1,r2,c2)`。不做磁盘持久化（重启重适应一次可接受）、不推给插件 VM（19 个插件没人该为此写代码）。
- **防 P0-1 同类坑**：值是不可变四元组而非可变共享对象；键按图像尺寸天然隔离不同实例。
- **链路**：`OnControlUnloaded` 里 `SaveViewPartForResume()`（GetPart 存入 LRU）；`HImageChangedCallBack` 换尺寸图时先 `TryRestoreViewPart(newImg)`，命中则恢复 part，失败/无记录 → 铺满兜底（旧行为）。恢复与铺满同一条时序纪律（先按旧 part 画 → 恢复 → 重绘，避开"SetPart 被内部状态顶掉"的坑）。
- **实测修正**：`HImage.GetImageSize()` 的返回 HTuple 索引器没有 `.I` 扩展（那是旧版 `HObjectExtension` 的 0 参重载口径）——统一改 `GetImageSize(out w, out h)`。

### 2. 直方图上提（Plugin.BlobDetect → Core.Halcon）

- `GrayHistogram.cs` → `Core.Halcon\Models\GrayHistogram.cs`（数据侧：8/16 位分档口径、"实际灰度范围用 min_max_gray 度量"的原有经验全保留）。
- `HistogramPlot.cs` → `Core.Halcon\Controls\HistogramPlot.cs`（绘制侧：矢量 OnRender、可拖阈值线双向回写、Plugin* 主题令牌 + 内置回退）。
- **多通道增量**：`GrayHistogram.TryComputeChannels(HObject, out GrayHistogram?[], out error)`——1 通道等价单份（ChannelName=Gray）、3 通道拆 R/G/B 三份（宿主用并排控件各画一条，每线可独立拖阈值）、其它通道数明确拒绝不静默。通道副本 AccessChannel 创建、finally 统一 Dispose。
- 消费方迁移：`BlobDetectView.xaml` 的 `local:HistogramPlot` → `h:HistogramPlot`（h: 映射本就指向 Core.Halcon.Controls）；`BlobDetectPlugin.cs` 加 `using Core.Halcon.Models`。**旧两文件删除**——全仓一个直方图实现。
- **实测坑**：`Core.Halcon.Color`（取色内核目录的命名空间）与 `System.Windows.Media.Color` 撞名——HistogramPlot 里的 `Color.FromArgb/FromRgb` 全部 fully qualify。

### 3. 标定残差箭头（CalibrationPlugin.cs + CalibrationView.xaml）

- **动机**（vision 评审）：残差此前只有质量区 RMS/最大值文本，"哪个点拖后腿、往哪个方向偏"全靠猜。
- **实现**：`RebuildResidualAnnotations()`——每点"图像点 → 变换 → 机械 → 理想机械 → 反变换回图像 = 理想点"连线（`MeasureType.Line`，长度 = 残差 × 50，亚像素残差不放大不可见）+ 点标注（`MeasureType.Point`，行名；超 `ResidualThresholdPx` 阈值者红色并带残差值文本）。网格模式用全局仿射基线（与 `ApplyRowResidualsFromMatrix` 同口径——箭头展示的就是该口径度量的畸变）。
- 挂接：`ResidualAnnotations` 属性（INPC）绑定 `ImageEdit.Annotations`（基类随帧覆盖渲染，零新增绘制机制）；配置态调点（`RunAlgorithm` 前的质量预览）与正式求解后都刷新。未求解 = null（不画）。
- 依赖的既有 API：`CalibrationMath.TryMapXYToPixel`（`CalibrationMath.cs:571`，仿射反变换；透视模式箭头不画——透视走逐点局部当量，箭头口径待真机验证后再定，本轮只覆盖仿射/网格）。

### 4. 伪彩 LUT 开关（HalconBase.cs）

- 「视图」子菜单新增「伪彩映射（温度色板）」：`_useColorLut` 状态 + `RenderAll` 每帧 `hWindow.SetLut(_useColorLut ? "temperature" : "default")`（状态纪律与十字线一致——不是设一次就完，换图/缩放后的全量重绘都带上）；勾选态随 `ContextMenu.Opened` 同步。
- 用途：real/16 位差分图（BeadInspect 差分基准、PreProcessing 滤波结果）在线性灰度映射下低对比区域一片黑/白，温度色板一眼可辨。
