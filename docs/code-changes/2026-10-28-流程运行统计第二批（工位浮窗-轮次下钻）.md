## 1. 当前状态

底栏从"只有聚合数"升级为**可切范围 + 可下钻**：

- 底栏新增**范围胶囊**：默认「全部在跑 · N 条」；点工位浮窗里的某条流程 → 底栏跟该流程；点范围胶囊 → 回到全部。
- 点「N 条在跑」打开**工位浮窗**：每流程一行（流程/工位、状态、节拍、OK、NG、未判定、判定源、最近一轮）；Home / End / 子程序 / 调试行置灰且不可选。
- 浮窗底部「查看最近一轮」打开**轮次详情**：FlowName、轮次号、开始/结束、节拍、判定源、失败步骤、步骤数、原因；NG 记录会显示"判定表 Failed 仍按 IsOk 计 NG"。
- 轮次记录进**每流程台账**（默认保留最近 50 轮，旧→新），按 FlowId 隔离；换方案/删除流程清空。

**仍然没有 L2 引擎契约**：`FlowRoundRecord` / 台账在宿主侧，引擎只发每轮事件；`FlowSession.LastRound`、`FlowRoundCompleted`、`IFlowVerdictResolver`、`FlowInvoker` 语义修正留到下一批。

### 关键口径（与第一批一致）

- 节拍：选中流程显示该流程上一轮；「全部」取在跑流程**瓶颈**。
- OK/NG：选中流程显示该流程；「全部」取**主流程线级汇总**，不跨站求和。
- 未判定：选中流程显示该流程；「全部」为生产流程合计。
- 浮窗行：`IsIncluded=false`（Home/End/子程序/调试）置灰、不可选；选中行高亮。
- 下钻：只读最近一轮；没有轮次时按钮不打开（不伪造空记录）。

## 5. 踩过的坑

1. **UI 冒烟被外部改动的硬编码色拦红**：`Scada.Controls/Themes/DataGridElement.xaml` 与 `ReportElement.xaml`
   在 14:16/14:17 被另一会话改动，各写了 1 处 `#FFFFFFFF`；`UIThemeSmokeTest` 判"新文件硬编码色"。
   已用 `HmiPrimaryTextBrush`（白，与 `HmiPrimaryBrush` 配对）替换，行为不变，闸门恢复绿。
2. **`StaysOpen=False` 的"再点关不掉"**：Popup 开着时点按钮，Popup 先因失焦关闭、Click 又打开；
   沿用 `PerfButton` 的 `PreviewMouseLeftButtonDown` 先吃一下，Click 只负责打开。
3. **浮窗行不能每 200ms 整表重建**：会丢滚动/焦点；按 FlowId 增量更新 `FlowStatsRow`，只在流程集合变化时增删。
4. **`Popup` 里的行命令要跨 DataTemplate 找 VM**：用
   `Command="{Binding DataContext.SelectFlowCommand, RelativeSource={RelativeSource AncestorType=ItemsControl}}"`，
   行自身 DataContext 是 `FlowStatsRow`。
5. **调试轮不落台账**：`FlowRunCompleted` 时 `DebugEnabled` 仍为 true，先判再记；否则调试轮会进"最近一轮"。
6. **轮次号按流程自增**：`FlowStat.RoundIndex` 在非调试轮完成时 `++`；换方案清零。
