# 图像窗口不跟随最新帧（诊断与修复，2026-10-26）

## 一、当前状态

- **插件侧没有问题**：`二维码读取_QR` 的三步都执行成功，`显示检测结果` 确实把二维码结果
  发布到了视图 1（探针实测：`view=1 title='结果显示' size=640x480 info=码个数: 1 ; 码内容: 12345678901234567890`）。
- **根因在宿主图像窗口 `ImageGallery` 的“选中哪一帧”策略**：
  `Services\Core.Halcon\Controls\ImageGallery.cs:597-620` 的 `Recompute()`：
  - 可见帧先按**流程名**（Ordinal）再按 `Sequence` 排序（`:597-599`）；
  - 选中项优先保留上一帧：`if (previous != null && visible.Contains(previous)) → 保持`（`:608-609`）；
  - “自动选最新”取 `visible[visible.Count - 1]`（`:611`、`:617-619`），即**流程名排序最后的那条流程的帧**，
    不是发布序号最新的一帧。
- 本机 `KeepInjectedHistory=false`（每格只留最新一张、无缩略图条、锁定按钮置灰），
  用户没有手工选帧入口，但代码仍保留旧选中帧。于是二维码流程的新帧**进了集合却永远选不中**，
  窗口一直画 NCC 那一帧。
- 用户看到的“二维码底图 + NCC 文字”不是混合态：那一帧整体就是 NCC 帧
  （`smd_on_chip_01.png` 640x512，左上角烧着 `分数 0.7824 / 行 307.9517 / 列 308.3951 / 角度 0`），
  该图本身就是暗底 + 方块阵列，视觉上像二维码。`PART_Big` 只画 `SelectedFrame`，
  `HalconBase.RenderAll` 每帧 `ClearWindow()` 后重画，不存在旧标注残留。

### 1.1 修复已实施（2026-10-26）

- **`ImageGallery.Recompute()`**（`Services\Core.Halcon\Controls\ImageGallery.cs:601-626`）：

  - `SupportsFrameHistory == false`（每格一张、无缩略图条）时强制选 `newest`；
  - 有历史时才保留旧选中项；选中项被淘汰时回落到 `newest`。

  - 收容开关按帧类型取：注入帧看 `KeepInjectedHistory`，兜底采集帧看 `KeepFrameHistory`；
  - 修掉“只打开 `KeepFrameHistory` 时注入帧重复”的隐患。

## 四、修复内容（已实施）

已按下面方案修改 `Services\Core.Halcon\Controls\ImageGallery.cs` 的 `Recompute()`（`:591-626`）：

1. 展示顺序仍按流程名分组，不动；
2. **“最新”按 `Sequence` 取**：`var newest = visible.OrderBy(f => f.Sequence).LastOrDefault();`
3. **`SupportsFrameHistory == false`（每格只留一张、无缩略图条）时强制跟随最新帧**：
   这种模式用户没有选中旧帧的入口，保留旧选中项没有语义；
4. `SupportsFrameHistory == true` 时保留旧选中项（有缩略图条，用户可能正在看旧帧）；
5. 选中项被淘汰时回落到 `newest`，不要回落到“流程名最大”的帧。

```csharp
var newest = visible.Count == 0 ? null : visible.OrderBy(f => f.Sequence).Last();

if (!FilteredFrames.SequenceEqual(visible))
{
    var previous = SelectedFrame;
    FilteredFrames.Clear();
    foreach (var f in visible) FilteredFrames.Add(f);

    if (!SupportsFrameHistory)
        SetCurrentValue(SelectedFrameProperty, newest);
    else if (previous != null && visible.Contains(previous))
        SetCurrentValue(SelectedFrameProperty, previous);
    else if (AutoSelectNewest)
        SetCurrentValue(SelectedFrameProperty, newest);
    else if (visible.Count == 0)
        SetCurrentValue(SelectedFrameProperty, null);
}
else if (SelectedFrame != null && !visible.Contains(SelectedFrame))
{
    SetCurrentValue(SelectedFrameProperty, AutoSelectNewest ? newest : null);
}
```

**临时规避（不改代码）**：系统参数设置 → 画布 → 每轮开始选「清空整张画布」
（`RunStartMode=ClearAll`）。探针已验证该模式下 QR 帧能被正确选中；代价是每跑一条流程
就清掉其它流程的图。

**验证**（已执行）：

   - 只开 `KeepFrameHistory` → 注入帧仍只留 1 张。
3. 变异反证：把 `InsertOrReplace` 退回旧逻辑，第 4 条 FAIL（帧数=2）；还原后 PASS（帧数=1）。
