# 恢复默认布局修复（出厂快照重捕获 + 确认 + 失败反馈）

日期：2026-10-19
范围：
- `VisionMaster/Services/LayoutHelper.cs`（`Load(bool refreshDefaultSnapshot)`、`CaptureDefaultLayoutSnapshot`）
- `VisionMaster/Commands/ResetLayoutCommand.cs`（确认框 + 失败反馈）
- `VisionMaster/Commands/LoadLayoutCommand.cs`（加载布局不刷新出厂快照）
- `UIThemeSmokeTest/Program.cs`（新增断言 ⑩）

## 起因

检查「工具(T) → 恢复默认布局」时发现两个问题：

1. **出厂快照是错的**：`bin\Debug\DefaultLayout.xml`（2026-10-18 捕获）里流程栏列宽是
   **`DockWidth="25"`**、程序/流程栏两个 pane 都没有 `DockHeight`。点"恢复默认布局"
   等于把左栏恢复成一条 25px 的缝（随后被 R143 的列宽兜底拉回 340，但快照本身仍然错）。
2. **失败时静默无反应**：`ResetLayoutCommand` 只在 `LayoutHelper.Reset()` 返回 true 时弹提示；
   快照缺失/过期时 `Reset()` 返回 false（只删文件），用户点了菜单什么都没发生。

## 根因

`CaptureDefaultLayoutSnapshot()` 原来的策略是"只捕获一次"（文件存在就 return）。
快照在 2026-10-18 某次启动时捕获，当时左栏宽度是 25px（早期布局未测量/被拖窄的状态），
此后 `Shell.xaml` 再怎么改都不会更新它——"恢复默认布局"的数据源永远是那份旧快照。

## 修法

### 1. 每次启动重捕获出厂快照

`Load(bool refreshDefaultSnapshot = true)`：
- **启动路径**（`Shell.OnContentRendered` → `LayoutHelper.Load()`）传 true；
  此刻 `LoadFromString` 还没执行，内存里必然是 Shell.xaml 的默认布局，重捕获不会覆盖用户布局。
- **「加载布局」命令**传 false：那时内存里是用户当前布局，若刷新快照就会把用户布局
  当成"出厂默认"写进 `DefaultLayout.xml`。

`CaptureDefaultLayoutSnapshot` 改为每次覆盖写入，并在序列化前 `FindManager()?.UpdateLayout()`，
让宽高取实测值而不是未测量时的占位值。

**内存副本**：捕获成功后同时存一份 `_defaultLayoutXml`；`Reset()` 优先用它。
这样即使 `DefaultLayout.xml` 被删/被占用/是旧版本，点"恢复默认布局"也能立即恢复，
不必等重启（文件只作持久化备份）。

### 2. 恢复默认布局：先确认、失败也说话

`ResetLayoutCommand`：
- 先弹 `OKCancel` 确认框（会丢弃面板位置/大小/显隐，属于破坏性操作）；
- 成功 → "已恢复默认布局。"；
- 失败（快照不可用，`Reset()` 已删掉快照与用户布局）→
  "已清除自定义布局。出厂默认快照不可用，重启后将按软件默认布局显示。"，不再静默。

### 3. 守门人

`UIThemeSmokeTest.RunPanelModeChecks` 新增第 ⑩ 条：
把 ShellCopy 的 DockingManager 序列化（等价于启动时写进 `DefaultLayout.xml` 的内容），
断言其中必须出现 `DockWidth="340"` 与 `DockHeight="180"`。
变异反证：把 ShellCopy 的流程栏列改成 230、或去掉程序栏 `DockHeight="180"` → 这条红。

## 验证

- `dotnet build VisionMaster` → **0 错误**。
- `UIThemeSmokeTest`：
  - `[PASS] 出厂快照尺寸基线：流程栏列宽 340、程序栏高 180`
  - `[PASS] 流程栏列宽兜底：230 → 340、最小宽度 320`
  - 其余仅既有 vendored GridView 红灯。

## 没有改的部分（记录）

- **窗口大小/位置**不随"恢复默认布局"重置：该命令只恢复 AvalonDock 停靠树，
  窗口尺寸由系统/用户控制（与菜单语义一致）。
- **方案（.vms）内嵌布局**不受影响：确认框里已写明；切换方案时仍会按方案布局恢复。
- **`SaveLayoutCommand`（保存布局）没有成功提示**：属另一条命令，本次不动。
