# 系统变量重构：设备级复合变量（MotionAxis / CommDevice / CameraDevice）

日期：2026-10-23
状态：实现完成，断言通过（ScadaChecks 2515/0）

## 1. 目标

重构前：每根轴产 12 条**互不相干**的平级变量（`System.Motion.X.Position`、`...Velocity` …），
注册表里没有"X 这根轴"这个实体；通讯设备只有用户级网络变量，相机完全没有系统变量。

重构后：**一台设备 = 一个复合变量 + 若干字段**，字段集由宿主归一、对所有厂家/协议一致
（对齐 EtherCAT 的 REF 402 Axis 思路：不管伺服是谁家的，状态都从同一套对象读）。

## 2. 新结构

```
System.Motion.X                 : MotionAxis     ← 整根轴（只读快照）
  Position / Velocity / Moving / InPosition / Enabled / Alarm / AlarmMessage /
  PositiveLimit / NegativeLimit / Origin / EmergencyStop / StatusText        （12 字段）

System.Comm.PLC_Modbus          : CommDevice     ← 整台通讯设备
  Connected / State / StateText / LastError / Protocol / Enabled / ReadCycleMs （7 字段）

System.Camera.Cam1              : CameraDevice   ← 整台相机
  Online / State / StateText / StateDetail / ReceivedFrameCount /
  DroppedFrameCount / OverflowCount / PendingFrameCount                      （8 字段）
```

三个快照类型定义在 `Core/Models/Variable/SystemDeviceSnapshots.cs`：
字段由宿主归一（运动侧 `MotionStatePublisher` 把各驱动 `AxisStatus` 归一成 `ScadaAxisSample`；
通讯侧读 `ICommunicationManager` 的连接状态；相机侧读 `ICameraDevice`），
**驱动插件不允许自定义字段**——这就是"统一结构"的落点。

## 3. 命名与身份（兼容红线）

| 对象 | 名字 | Id |
| --- | --- | --- |
| 运动父变量 | `System.Motion.{轴名}` | `SHA1("motion-dev\|{轴Id:N}")` |
| 运动字段 | `System.Motion.{轴名}.{字段}` | `SHA1("motion-var\|{轴Id:N}\|{字段}")` **与重构前逐字节一致** |
| 通讯父变量 | `System.Comm.{连接名}` | `SHA1("comm-dev\|{连接名}")` |
| 通讯字段 | `System.Comm.{连接名}.{字段}` | `SHA1("comm-var\|{连接名}\|{字段}")` |
| 相机父变量 | `System.Camera.{显示名}` | `SHA1("camera-dev\|{相机Id:N}")` |
| 相机字段 | `System.Camera.{显示名}.{字段}` | `SHA1("camera-var\|{相机Id:N}\|{字段}")` |

- **老方案零迁移**：运动字段的名字与 Id 一个字节都没变，按 Id/名字绑好的连线、画面、监视项
  重启后照常命中。父变量是纯新增。守门断言直接抄了一份重构前的哈希推导做外部锚点
  （`AxisPanelChecks.LegacyMotionLeafId`），不从产品代码调同一个函数（否则改了也一起变，等于自证）。
- 通讯配置里没有 Guid，**连接名就是唯一稳定键**：改名等于换一台设备（旧 Id 失效、新 Id 生成），
  与"删掉再新建"同语义。
- 相机按内部 Id 寻址（改名不断链）；两台相机显示名相同时，第二台自动追加 `_序列号`，
  仍冲突则用 `#序号`，保证名字索引不打架。

## 5. 三条关键取舍

1. **模型级复合，不是界面分组**：父变量本身是可解析的 `IVariable`（有确定性 Id、有 `Value` 快照），
   将来表格式图元可以整块绑"一根轴"；界面只是把它展开成子行。
2. **只读**：三个快照类型都不实现 `IWritableVariable`。运动命令仍只走动作表 / `MotionCommandGate`，
   不给系统变量开第二条写路径（CiA 402 的 ControlWord 在本工程对应的是动作表，不是变量写）。
3. **字段集由宿主定义**：驱动插件只提供 `AxisStatus` / `ICameraDevice` 这些原始状态，
   映射到统一字段是宿主的事；新增厂家不需要动系统变量层。

## 6. 兼容与已知风险

- **UI 计数口径变了**：「系统变量」左栏与明细头数的是**根行**（一台设备算 1），
  不再是字段数。与网络数组一致（数组算 1 个变量，元素行不计数）。
- **父行默认折叠**；展开状态按 `VariableId` 记忆，重建树不丢。
- **SCADA 选择器 / 插件候选 / 监视栏「Global.All」/ 变量事件里看不到父行**
  （结构体不能绑标量、不能配"值为真"）；字段行照常可选。
- **通讯/相机目录各自 500ms 一拍**；值变化只走模型 INPC，拓扑变化才通知宿主刷新。
- **连接名含点**：`System.Comm.A.Connected` 这类路径与"设备 A.Connected 的父变量"在字符串上会撞名
  （运动轴名同样保留点，属既有约定）。宿主按名字去重，先注册者优先；真要支持需给名字段加转义规则。

### 6.1 独立审查后的修正（同批）

| # | 问题 | 修法 |
| --- | --- | --- |
| 1 | 字段行的"复制完整变量名"被操作列的 `IsRootNode` 可见性挡住（命令支持子行但入口不可见） | `VariableNode.ShowRowActions`（根行或字段行）；名称列工具提示改绑 `DisplayFullName` |
| 2 | `MotionAxis` 含 `TimestampUtc`，父变量每 100ms 发一次 `ValueChanged`（差分推送失效） | 自定义 `Equals`/`GetHashCode` **排除时间戳**；断言"连发两拍同值只通知一次" |
| 3 | 宿主 `_current` 交换与写集合不在同一临界区，两次并发刷新可留下**永久幽灵变量** | 合并 → 交换 → 写集合整段放进 `_applyGate`（锁序 `_applyGate → _gate`，无反向路径） |
| 4 | 托管模式下运动目录在发布器线程**无锁枚举**共享集合（可抛"集合已修改"）；点号撞名时按数量比会每拍全量重建 | 托管模式（`_host != null`）跳过"集合被外部动过"的计数检查，只在非托管（测试/简化容器）保留自愈 |
| 5 | 通讯目录 `Publish` 用原始设备表（自定义状态源名字带空白时字段永远不刷新） | 归一化一次，`Rebuild` 与 `Publish` 共用同一份 |
| 6 | 父快照的 `State` 与字段语义不一致（父传中文、字段传枚举名） | 父/字段统一：`State` = 枚举成员名，`StateText` = 中文 |
| 7 | 离线/不可用时父快照的身份字段不刷新（离线期间改名，`Value` 停在旧名） | `with` 里一并写 `AxisName/CardName`、`Name/SerialNo` |
| 8 | 复用父实例时 `Fields` 列表被冻结 | `SystemVariableModel.UpdateFields`，复用分支同步刷新 |
| 9 | 搜索 "Position" 搜不到（只匹配根行名称/描述） | 根行匹配时并查子行名称/完整名/描述 |
| 10 | 监视栏「Global.All」与 SCADA 变量事件可选中复合父行 | 两处按 `ISystemVariableContainer` 排除 |

## 7. 验证

- `ScadaChecks`：**2515 通过 / 0 失败**（新增 36 条）。
  - 结构：1 父 + 12 字段、顺序"父 → 字段"、`MotionAxis` 类型、`ISystemVariableContainer` 12 字段；
  - 兼容：叶子 Id 与重构前逐字节一致；轴改名后父/字段新名可查、旧名查不到、Id 不变；
  - 短路：拓扑没变时 `Snapshot()` 引用不变；集合里挂着 `Owner="Comm"` 的外来变量时仍短路；
  - 值：父变量快照与字段同一拍；离线保留上次位置、`Error` 写明原因（不编 0）；
  - 差分推送：父变量连发两拍同值只通知一次（`MotionAxis` 相等判断排除时间戳）；
  - 通讯：2 设备 = 2 父 + 14 字段；设备移除后整组消失；实例复用；字段值来自链路状态；
  - 相机：1 台 = 1 父 + 8 字段；在线/采流/收帧计数；设备不可用时状态改"不可用"、计数保留上一拍；
  - 重名相机自动加序列号；**三源合并**（运动 13 + 通讯 8 + 相机 9 = 30 条）进同一个集合；
  - 变量管理：根行只含父变量与独立叶子；字段行短名显示、完整名可复制、只读、`OriginalModel` 指向字段。
