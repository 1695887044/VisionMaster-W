## 4. 与设计稿的已知偏差

| # | 偏差 | 原因 |
| --- | --- | --- |
| 1 | 驾驶舱图像区**没有**空态覆盖层 | `ImageView` 是共享视图（`Panel_ImageView` 也在用），它的内容由 code-behind 动态填充；本页不知道"有没有图"，硬加覆盖层会与主图像面板的状态打架 |
| 2 | 驾驶舱**没有** OK/NG 结果章、帧信息、告警条 | 都需要当前不存在的数据源（帧元数据 / 流程结果汇总 / 最新报警订阅） |
| 3 | 流程胶囊的"禁用"没有独立标签 | 22px 单行里放不下；用删除线 + 灰点表达，完整说明进提示条与 ToolTip |
| 4 | 日志"面板保留最近 N 条"改为不显示具体数 | 两个上限并存（`AppConfigModel.LogPanelMaxRows` 与 `LogView` 的 `MaxItems=2000`），写死任一个都会撒谎；底栏改为只给"完整历史"路径 |
