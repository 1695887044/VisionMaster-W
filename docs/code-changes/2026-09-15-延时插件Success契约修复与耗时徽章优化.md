# 开发记录：延时插件 Success 契约修复 + 耗时徽章"<1 ms"显示

- 日期：2026-09-15
- 类型：Bug 修复 + 体验优化
- 触发场景：循环运行时观察到 ①"图像脚本_0"卡片没有耗时徽章；②日志每轮出现"步骤[MainTask.延时_0]执行失败:"（消息为空）

---

## 一、问题定位与决策

### 问题 1：图像脚本"没有运行时间"（非 Bug，显示门槛）

耗时记账链：步骤完成时 `elapsed = (long)(DateTime.Now - LastRunStartTime).TotalMilliseconds`（`Core\Models\Compileds\CompiledNode.cs` L74，**整数截断**）；徽章显示条件 `LastRunTimeMs > 0`（`ProcessView.xaml` L246）。
脚本热身后每轮 <1ms → 截断为 0 → 徽章整体隐藏，造成"没运行"错觉。单步首跑有热身开销显示过 1 ms，循环中恒为 0。

**决策**：不改记账精度，徽章在"成功且耗时=0"时显示 `<1 ms`。

### 问题 2：延时节点每轮"真失败"（Bug，契约违约）

框架契约：`VisionPluginBase.Execute` 返回 `Success.Value is true`（`Shard\Core.Interfaces\VisionPluginBase.cs` L93-96）；`Success` 端口无初始值 → bool 默认 false。
`DelayPlugin.RunAlgorithm` 完成后只写自家 `State.Value = true`（面向用户连线的输出端口），**从不写 `Success.Value`** → 引擎每轮判 Failed 并落"执行失败:"日志（`ErrorMessage` 未写过，故消息为空）。流程未中断仅因框架"业务失败不抛异常"语义。

**决策**：补齐契约——正常完成置 `Success=true`；急停中断/异常置 `false`；入口处先清零防上轮残留。

## 二、修改文件清单

### 1. Plugins\Plugin.Utility\DelayPlugin.cs（RunAlgorithm）
- 入口：`Success.Value = false;`（与 State 同步清零）
- 急停中断分支：`Success.Value = false;` 后 return
- 正常完成：`State.Value = true;` 后新增 `Success.Value = true;`（含契约注释）
- catch 分支：`Success.Value = false;`

### 2. VisionMaster\Views\ProcessView.xaml（ActionStep 模板 Triggers）
- 在 `LastRunTimeMs > 0` 徽章触发器之后新增 `MultiDataTrigger`：
  条件 `State == Success && LastRunTimeMs == 0` → `TimeText = "<1 ms"`、徽章可见。
- 置于 `IsRunningFocus` 触发器之前，运行中绿色实时计数行为不受影响。
