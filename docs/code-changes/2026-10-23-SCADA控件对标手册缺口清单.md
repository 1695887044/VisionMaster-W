## 四、控件之外的两块缺口

### 7.5.1 动画：10 项，已做 4 项

| 已做 | 未做 |
| --- | --- |
| 外观变化、水平移动、垂直移动、可见性 | **启用对象**、对角线移动、直接移动、自定义移动、动态移动、**比例移动（缩放）** |

`ScadaAnimationType` 只有 4 个枚举值（`ScadaAnimation.cs:71` 明写「本版只支持四种」）。其中「启用对象」成本最低、价值最高（联锁/权限/无数据时把控件置灰），其余五项是几何变换，需要新字段 + `TransformGroup` + 复位。

### 7.5.2 事件：19 类，已实现 10 类

| 已实现 | 未实现 |
| --- | --- |
| 加载 / 清除（画面）、按下 / 释放、输入完成时、更改数值、值为真 / 值为假、上限 / 下限 | 报警激活 / 取消激活 / **确认**、对象更改、开关打开 / 关闭、按钮激活 / 取消激活（启用/禁用）、**定时器超时** |

「单击」目前用「按下 + 释放」近似，没有独立的点击语义。

### 动作表：20 类，缺常用三族

| 缺口 | 影响 |
| --- | --- |
| 增量 / 减量（`IncreaseValue`/`DecreaseValue`） | 微调按钮只能写定值，做不了「+1」「-0.1」 |
| 位操作（置位 / 复位 / 取反） | 布尔量只能写 0/1，取反要两条动作 |
| 配方下载 / 上传、语言切换、声音、打印、数据记录启停 | 对应能力本身也缺（见上表） |

## 五、建议优先级（按本项目：视觉机 + 运控 + Web 运行态）

### P0：不补就上不了现场画面

1. **页面背景图（`ScadaPage.BackgroundImage`）+ 内容图片（`Hmi.Picture`）** — 现场绝大多数本地图片是整页背景（工艺图、设备布置、厂区平面），应做成页面属性：铺满、压底、不参与框选/命中，基座背景可被继承；`Hmi.Picture` 只负责 logo、产品图、操作指引这类可移动内容图。成本 S/M：页面属性面板 + 图片选择器 + 复制进方案 `Image\` + 相对路径 + 缺失回退背景色。
2. **线 / 折线 / 箭头（`Hmi.Line`）** — 工艺图连线、分区框、标注。成本 S/M：几何绘制 + 命中测试 + 端点手柄。
3. **增量 / 减量动作** — 微调按钮（速度、补偿、偏移）是现场高频操作。成本 S：动作类型 + 分发器 + 属性面板一行。

### P1：客户验收会问

4. **历史数据（`IScadaHistorySource` + DataGrid `Source=History`）** — 视觉机的核心价值是追溯；现在只有报警历史，没有过程数据。成本 L：存储契约 + 查询分页/取消 + 三态 + Web 标注非目标。基线 v2 已把它从 P2 升到 P1，但契约一直没定。
5. **二维码 / 条形码图元** — SN、批次、追溯码上屏。成本 S/M（引 ZXing 类库 + 渲染 + Web 端用同一编码结果）。
6. **启用对象动画** — 联锁未满足、无权限、无数据时置灰，比「点了报错」诚实。成本 S：枚举 + 一个动画求值分支 + 复位。
7. **对象更改 / 开关打开关闭事件** — 操作记录与联锁都靠它；现在只能靠变量值变化间接推。成本 S/M。
8. **配方（换型参数集）** — 成本 L，且要先定「配方 vs 整方案切换」的产品口径；建议先做方案级，别急着做图元。
9. **多曲线趋势（`Hmi.MultiTrend`）** — PV/SP/OP 对比；现在只能并排放多个 ChartTrend。成本 L（VM.Charts 多系列 + 图例 + 独立量程）。
10. **声音报警** — 报警引擎有事件，没有任何发声出口。成本 S（宿主级，不必做成图元）。
11. **运行计时 / 计数器** — OEE 与节拍的基础数据。成本 S/M。

### P2 / P3：能用现有控件拼，或场景很窄

- P2：圆形进度条、旋钮、跑马灯、XY 曲线、柱状/饼图、堆栈灯、报警记录图元（宿主抽屉已覆盖）、图形开关/图形 IO 域、时间日期输入、页内变量监视。
- P3：GIF / 增强图片、多边形 / 贝塞尔 / 动态画线、报表 / PDF / 浏览器 / 数据库视图、图库、定制控件机制、软件容器。
- 不适用：物联网卡、网络信号栏、WiFi 系列（嵌入式 HMI 专用）。

### 横切项（不是控件，但决定上限）

- **多语言 / 国际化**（手册 19.3）：现在所有文案写死在图元属性里，导出设备要重做一套画面。若近期有出口需求，应升到 P1，并和「状态列表」一起做。
- **状态列表（手册第 8 章：文本列表 / 图形列表）**：现在 `ComboBox.Options`、状态色都是每图元一份；同一套状态在十个图元上要配十份。共享列表是配方、多语言、图形开关的共同前置。

## 七、新增一个 TypeKey 的真实成本

不是「写一个控件类」一件事。按仓库现有约束，一个 TypeKey 要同时落地：

1. `Elements\` 控件类 + `Themes\` 样式 + `Generic.xaml` 合并 + `BuiltInElements.cs` 描述符（三处缺一，工具箱为空）；
2. `[ScadaProperty]` 走源生成器（或手写 DP），属性面板分组必须先在 `ScadaPropertyGroups` 登记；
3. Web 运行态渲染器 + `caps` 声明（否则落 `Hmi.Unsupported`）；
4. `ScadaChecks` 断言段 + 渲染证据；
5. 设计基线（R111 六项）+ 截图验收（R122/R132）。

所以「能不能用现有控件加属性解决」永远先问一遍（基线 v2 的三问）。

## 八、结论

- 手册 68 项里，**17 项直接对应、14 项可近似、37 项无对应**；但 37 项里有 4 项是嵌入式平台专用、约 12 项属于「能用现有控件拼」。
- 真正影响现场交付的缺口只有 **3 个 P0**：页面背景/内容图片、线/折线、增量减量动作。
- 决定「像不像商业 HMI」的是 **历史数据 + 配方 + 多语言** 三件横切能力，不是图元数量。
- 动画缺 6/10、事件缺 9/19，其中只有「启用对象」与「对象更改/报警确认事件」值得优先补。
