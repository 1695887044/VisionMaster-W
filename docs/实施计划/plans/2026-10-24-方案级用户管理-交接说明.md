### 2.3 写作期间踩过并已修的坑（给下一位写计划的人）

1. **heredoc 追加长文本会炸**：`cat >> file <<'EOF'` 在本机 Git Bash 下报 `unexpected EOF`。改成「Write 到临时文件 → `cat tmp >> plan`」。
2. **C# 字符串里嵌 ASCII 双引号**：在 markdown 里一眼看不出，编译才发现。计划里所有 `Check(...)` 的 detail 一律用字符串拼接，不用 `$"…\"…\""`。
3. **`IScopedProvider CreateScope()` 不存在**：Prism 9.0.537 的 `IContainerProvider` 只有 `object Resolve(Type)`。假容器不要实现不存在的方法。
4. **`ScadaWebSettings` 在 `VisionMaster.Models`**，不在 `VisionMaster.Lifetime`；`MemberInfo` 要 `using System.Reflection`。
5. **`Get-Counts` 取「最后一次匹配」**：`ScadaWebChecks` 会先打印 `M2ActionFilterChecks` / `M2CommandChecks` 的分段 `RESULT`，最后才是全进程累计。顺序错了会把分段数字当总数。
