## 与其他目录的关系

本目录只放**计划**。同一个主题的审核清单、评审报告、交接报告分布在别的目录，
容易只读到一半——跨目录的主题请走它自己的总索引，例如：

- 方案级用户管理改造 → [`docs/方案设计/方案级用户管理-总索引.md`](../../方案设计/方案级用户管理-总索引.md)
