# 文字图标库使用（SCADA / VM）

## 一、它是什么

VM 已有的 **Font Awesome 6 Pro Solid** 字体（`UI\Controls\Asserts\FontFamilys\Font Awesome 6 Pro-Solid-900.otf`）
以**链接编译**方式内置进 `VM.Scada.Controls`，并提供一层“名字 → 字形”的映射，界面可以直接用文字写图标。

- 资源键：`ScadaIconFont`（FontFamily）、`ScadaIconText`（图标文字样式）
- 挂载点：
  - `Scada.Controls\Themes\Generic.xaml`（控件库自带，纯宿主/断言环境可用）
  - `VisionMaster\App.xaml`（应用级，任何视图可用）
- 名字表：`Scada.Controls\ScadaIconGlyphs.cs`
- 附加属性：`Scada.Controls\ScadaIconHelper.cs`

> 为什么在 SCADA 控件库里再放一份：本库刻意不引用 UI 工程，而 `StaticResource` 在无 `Application`
> 的断言宿主里不会跨程序集去找 UI 的 `FA.Solid`。链接编译后 `ScadaIconFont` 是本册自带资源，
> 断言宿主也能解析；字体文件不复制，只链接。

## 二、三种写法

### 1. 按名字（推荐，最像“文字”）

```xml
xmlns:scada="clr-namespace:VisionMaster.Scada.Controls;assembly=VM.Scada.Controls"

<TextBlock scada:ScadaIconHelper.Glyph="Gear" FontSize="14" />
```

`ScadaIconHelper` 会同时设置 `Text`（字形）与 `FontFamily`（`ScadaIconFont`），
字体解析顺序：元素自身资源 → `Application` 资源 → 本程序集内置 pack URI。

### 2. 字体 + 静态字形常量

```xml
<TextBlock
    FontFamily="{StaticResource ScadaIconFont}"
    Text="{x:Static scada:ScadaIconGlyphs.Gear}" />
```

适合要在模板/样式的 `Setter` 里写死图标、或需要在代码里比较字形的场合。

### 3. 原始码点

```xml
<TextBlock FontFamily="{StaticResource ScadaIconFont}" Text="&#xF013;" />
```

`ScadaIconGlyphs.TryResolve` 也认 `f013` / `\uf013` / `&#xf013;` / `0xf013` 四种写法；
解析不出来返回空串（不把 “Gear” 五个字母显示出来）。

## 四、新增一个图标

1. 在 Font Awesome 6 Pro Solid 的 cheatsheet 里查码点；
2. 在 `ScadaIconGlyphs` 里加一个 `public const string Name = "\uFXXX";`；
3. 在 `ByName` 字典里加 `["Name"] = Name`（需要别名就再加一行）；
4. **已有常量的值不许改**（界面与文档已经按它写）；
5. 跑 `ScadaChecks` 的 `[BD]` 段确认字体真的带这个字形。

## 五、守门与注意事项

- 断言 `[BD1]~[BD4]`：名字解析、四种码点写法、未知名字返回空、字体真的带 `U+F013` 字形。
- 只内置了 **Solid** 一档；Light/Regular/Thin 仍在 UI 程序集（`FA.Light/FA.Regular/FA.Thin`）。
  需要其它字重时按同样的“链接 Resource + FontFamily 键”方式加，不要跨程序集引用 UI 的键。
- 图标按钮若写了 `Width`/`Height`，必须挂 `Style` 或显式 `Padding`（AGENTS.md R68），
  否则会吃 Fluent 的默认内边距，字形被裁。
- 图标字形的颜色走 `Foreground`（状态色由使用处给），不要在图标库里写死颜色。
- 图标是私有区字符，复制粘贴到日志/CSV 里会变成不可见字符；日志文案里请用名字，不要用字形。
