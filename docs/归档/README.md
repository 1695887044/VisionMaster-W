## 维护约定

1. **新内容不要直接写进本目录**。现行文档应进对应专题目录；改动记录应进 `code-changes/`。
2. 本目录文件**加过 📦 归档横幅**，请勿移除或继续修改（工作性方案 `整理方案.md` 除外）。
3. 若某归档件的内容后来被某专题目录的主文档吸收，可将其移入该专题目录并改为"已并入主文档"横幅。
