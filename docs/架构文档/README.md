## 两份的关系

内容同源、编号一致，MD 是长文与台账，HTML 是版面与连线。以 **MD 为准**：
HTML 里画不下的取证过程、复核命令、口径修正表都写在 MD 里。改结论时先改 MD，再决定要不要同步图。

## 边界（务必读）

- **HTML 是沟通媒介，不是交付物**（`AGENTS.md` R126）：不进构建、不部署、不作为第二个客户端维护。
  实测过：没有任何 `.csproj` / `.props` / `.targets` 以 glob 方式读 `docs\`，放这里不会被构建捡走。
- **图里的数字有保质期**。行号锚点、断言条数、结构计数是 2026-10-23 13:30–13:34 那一轮闸口的快照；
  哪些条目会先腐、用什么命令重测，写在主文档 §0「失效条件」与 §9「复核命令」。**引用前先重跑，不要照抄。**
- **影响面为 grep/read 结论，不是索引结论**（R28：本会话无 CodeGraph 工具）。
- 本目录**不是** `docs/归档/`：这里是现行文档，会随架构变动而升版；旧版本如果被推翻，按 R7 搬去归档并留指针。

## 加文件的规矩

1. 动结构前先读 `docs/归档/README.md` 与本 README（R7）。
2. 新图必须与主文档同一证据口径：每格带 `文件:行号`，数字来自实测命令，不引用记忆。
3. 发现与 `AGENTS.md` 口径冲突（例：主文档 §11 列的 5 条陈旧数字），**不直接改 AGENTS.md**，
   先在「口径修正」表里登记，由用户裁决。
