## 五、踩过的坑

1. **设计稿里的“状态：…”是标注不是控件**：它只为 UM5 逐名字对照；WPF 复刻时删除，状态由 VM 标志驱动。
2. **design.html 不能出现 hex**：颜色全部走 `--dialog-*` 变量与 `rgb()`；README 的 rgb 值只作对照，不抄进 XAML。
3. **Web 不可用时不能还显示“共 3 个在线会话”**：截图前已把计数改「—」、meta 改「Web 客户端未安装或未启用」、踢人按钮灰掉。
4. **FactoryFallback 必须体现“最后一个管理员不可删除”**：否则设计稿会诱导实施方把 SL9 保护漏掉。
5. **`audit_docs` 仍是 report-only**：`exit=0` 不证明结构正确，判据是 `TOP/NOREADME/ORPHAN/LINK` 四个计数。
6. **截图用 Edge headless**：`file:///D:/C%23/...` 的 `#` 必须写成 `%23`；中文目录写 `%E8%AE%BE%E8%AE%A1%E5%9F%BA%E7%BA%BF`，否则 Edge 把 `#` 当 fragment。
