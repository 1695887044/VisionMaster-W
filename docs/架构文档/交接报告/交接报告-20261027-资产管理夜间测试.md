|---|---|---|
| `Scada.Controls` 报 RG1000 `themes/ackbuttonelement.baml` 重复键 | WPF 标记编译缓存陈旧（增量构建） | `dotnet build Scada.Controls\VM.Scada.Controls.csproj -m:1 -nodeReuse:false -t:Rebuild` |

| `AppActivate`/`SendKeys` 不生效 | 返回空/焦点不在目标窗口 | 用 UIA `ExpandCollapse`/`Invoke` 走菜单（`uia-menu.ps1`） |

| CameraSim 首次构建 MSB3021/3027 | 另一会话 `FlowCanvasChecks (34388)` 锁 `Modules\Plugin.Camera.Sim.dll` | 等其退出再复跑；不杀 |
| MotionSim 端口冲突 | 10/25 旧 `LineSim` PID 14588 占 19510 | `netstat` + 启动时间判断归属；不杀别人的 |
| 保存自动转另存为 | 夹具目录名 ≠ 方案名（K-04） | 夹具必须放 `<父目录>\<方案名>\<方案名>.vms`；规范目录下保存直接写回（已验证） |
