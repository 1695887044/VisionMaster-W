### 1.1 ⚠️ `packages\` 目录不在 Git 里，但三个工程硬依赖它

`.gitignore:200` 有 `**/[Pp]ackages/*`，而这三个工程用 **HintPath 直引**（不是 PackageReference）：

```
DLL\HslCommunication\HslCommunication.csproj:40   ..\..\packages\Newtonsoft.Json.13.0.4\lib\net45\Newtonsoft.Json.dll
tools\DeviceSimulator\DeviceSimulator.csproj:18   ..\..\packages\Newtonsoft.Json.13.0.4\lib\net45\Newtonsoft.Json.dll
tools\VirtualLineConsole\VirtualLineConsole.csproj:17   同上
```

**新机器拉下来后必须先补这个包**，否则这三个工程编译失败（AGENTS R169 明确写了"`packages\` 不许删"，就是为这件事）：

```powershell
# 方式一：直接拷（最快，从旧机器或任何 nuget 缓存取）
#   源：C:\Users\<user>\.nuget\packages\newtonsoft.json\13.0.4\lib\net45\Newtonsoft.Json.dll
#   目标：D:\C#\VM\packages\Newtonsoft.Json.13.0.4\lib\net45\Newtonsoft.Json.dll
# 方式二：nuget install
nuget install Newtonsoft.Json -Version 13.0.4 -OutputDirectory packages
```

> `DLL\`（648 文件）已入库，**不需要**额外处理；`Modules\`（49 个 DLL）是构建产物，**不在 Git**，首次构建自动生成。

### 1.2 ⚠️ 加密软件会让 `dotnet build` 随机失败（本机踩过，新机器若没装可跳过）

本机装了**亿赛通 Cobra DocGuard**（进程 `EstEncrpyDlp.exe`），它按**进程**决定是否加密落盘：

- `csc.exe` 在白名单，**`VBCSCompiler`（`dotnet build` 的共享编译服务）不在**
- 后果：`obj\*.AssemblyInfo.cs` 被写成密文（首字节 `62 14 23 65` + `E-SafeNet LOCK`），`csc` 读回报
  `CSC : error CS2015: "...AssemblyInfo.cs"是二进制文件而非文本文件`，**随机出现在几个工程**

**如果新机器也装了**，`dotnet build` 一律加 `-p:UseSharedCompilation=false`（已实测有效）。

### 4.1 三条红线（AGENTS §3，违反即回滚）

1. **插件工程必须放 `Plugins\` 下** —— `Directory.Build.targets` 按目录投递到 `Modules\`，放别处加载不到
2. **契约程序集（`Core.Interfaces` 等）不许拷进 `Modules\`** —— 两份静态状态，图投进去取不出来
3. **改了插件源码必须重建该插件工程** —— `Modules\` 不由宿主带出，只重建宿主仍是旧 DLL

### 8.1 已定口径（改代码时不要推翻）

- **`ColumnSource.Variable` / `FieldSource.Variable` 成员保留但标 `[Obsolete]`**，数值不变（`Port=0/Variable=1/BuiltIn=2`）——旧 `.vms` 靠数值反序列化，删成员会让"取变量值"静默变成"记时间戳"
