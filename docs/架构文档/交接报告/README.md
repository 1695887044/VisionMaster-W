# docs/架构文档/交接报告

按日期命名的交接报告存档。每篇覆盖一次跨会话工作收尾时的状态快照。

## 为什么单独一个目录

`AGENTS.md` R177 要求"每轮结束必须留落盘物"。这些报告就是那条纪律的产物，数量会持续增长，因此不与架构正文混放——`docs/架构文档/` 根下只留**长期有效的架构叙述**。
