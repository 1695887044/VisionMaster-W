## 踩过的坑

- **v1 域选错**：设计稿用运行态深色令牌、实现用弹窗浅色令牌，两边都"自洽"，但对不上。教训：出稿前先确认目标视图实际 merge 的是哪一族令牌（本视图 `ScadaScheduleManagerView.xaml:16` 就地 merge `Colors.xaml`）。
- **内联样式会压过状态规则**：`.block-time` 上写 `style="display:flex"` 后，`body[data-state="event"] .block-time{display:none}` 完全失效，且渲染出来只是"多了一块"，不看截图发现不了。
- **状态规则要按"隐藏谁"写**：`display:none` 打在容器上会把容器里"该显示的空态"一起隐藏（`.act-rows` → `.act-table`）。
- **Edge headless 截图**：`--headless=new --screenshot` 配合 `file:///D:/C%23/...`（路径里的 `#` 必须转义成 `%23`）；输出落 `artifacts/render/<yyyyMMdd>/`，再拷进 `docs/UI设计基线/<页面>/evidence/`。
- 截图窗口高度要按内容留足：正文 540~620 + 标题 52 + 页脚 56 + 上下 24，1030×760 刚好；窗口偏矮会把"添加动作"切掉，看起来像设计缺陷。
