### 实现期发现并修掉的 5 个问题

1. **宿主卡片 `MaxWidth=700`**：980 宽视图被压到 652，动作表「操作」列裁成一条缝——这是走查第 6 条「无内容窄条」的真正根因，不在视图里。放宽到 1040（只是上限，窄弹窗不受影响）。
2. **`ValidateAndShow()` 没有任何调用方**：EasyDialog 的「确定」直接设 Primary 关窗，校验是死代码。新增 `IDialogValidator`，宿主在设结果前调用，返回 false 就留在弹窗。
3. **内嵌单位后缀把内容区挤到 12px**：`Padding="8,0,46,0"` 下 R184 实测 `viewport=12 < extent=32.3`，「08:00」只显示「08」。改成「输入框 + 独立后缀列」后 `viewport=65.7`（[SV2b] 钉住）。
4. **折叠的事件块仍会触发 `SelectionChanged`**：条件下拉在布局期完成一次绑定，`OnConditionChanged` 里的 `ClearErrors()` 把刚校验出来的红框在弹窗显示前全抹掉（R35：不能从"值变了"倒推用户改过）。改为只刷新上下限显隐；[SV20] 钉住"渲染后错误仍在"。
5. **`"8:0"` 被读成 00:08**：`TimeSpan.TryParse("8:0")` = 8 分钟。先卡格式再解析，`[SC1]` 覆盖。

## 踩过的坑

- **XML 注释里不能出现 `--`**：`<!--  ----------  左列  ----------  -->` 直接 `MC3000`，整份 XAML 编译失败。改 `====`。
- **WPF 增量构建会留下坏 obj**：先出现 `RG1000 An item with the same key has already been added (app.baml)`，再重建成"能编译但 BAML 资源缺失"（宿主报 `找不到资源 views/scadaruntimewindow.xaml`）。清 `VisionMaster\obj` 与 `Core.Halcon\obj` 后 `--no-incremental` 重建才干净（R42 的"看产物不看退出码"）。
- **两个 ScadaChecks 实例会互相锁死**：并发跑时后一个的构建被前一个锁住 exe（MSB3027），已运行的实例还会在 `[SX]` 段挂住（AppSettings/日志文件竞争），日志停在半截、退出码 1。判据：先 `taskkill` 清干净再跑。
- **`run_gates` 的构建步骤偶发 exit=1 而日志 0 错误**：本次 UIThemeSmokeTest 首次整轮被判 `BUILD FAILED`，单步复跑 `exit=0`、整轮复跑 14/14。遇到时先看 build 日志内容，再单步复跑，别直接改代码。
- **离屏渲染要泵 Dispatcher**：`Window.Show()` 后必须 `Dispatcher.PushFrame` 到 `ApplicationIdle`，否则 `ActualWidth` 还是 0、截图为空（R53）。
- **Read 工具会占住 PNG 句柄**：边看图边跑渲染会撞 `The process cannot access the file`，把 [SV19] 判红。渲染前别开证据图。
