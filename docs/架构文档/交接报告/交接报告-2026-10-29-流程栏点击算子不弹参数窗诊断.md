# 流程栏双击算子不弹参数窗（命令靶脱钩）修复

- 日期：2026-10-29
- 现象（用户反馈）：**有时候**在流程栏双击算子不弹参数窗，但双击画布节点一直正常。
- 涉及：
  - `UI\Controls\Behaviors\TreeViewBehavior.cs`（双击写回靶 + null 推送清高亮）
  - `VisionMaster\ViewModels\ProcessViewModel.cs`（`ModuleParameters` 接住返回值）
  - `FlowCanvasChecks\ProcessTreeInteractionChecks.cs`（新增 V11 四条）

---

## 1. 当前状态

**已修复，断言宿主全绿；全量闸门 `run_gates.ps1` 本轮未跑（原因见 §4）。**

两条入口最终都调 `StepParameterDialog.Open`，但**目标对象来源不同**：

| 入口 | 触发手势 | 目标对象 | 取不到时 |
| --- | --- | --- | --- |
| 流程栏（`ProcessView`） | 双击（单击只选中） | `ProcessViewModel.SelectStep`（可变状态） | 改前**静默** |
| 画布（`FlowCanvasView`） | 双击 | `CanvasNodeViewModel.Model`（被点的节点） | 状态栏提示 |

所以只要"当前选中项"和树上高亮行脱钩，流程栏就点不动，而画布照旧正常 —— 与用户观察完全一致。

## 2. 根因（两条脱钩通道，都在 TreeViewBehavior）

1. **`null` 推送被丢弃**：`OnBindableSelectedItemChanged` 原来 `if (e.NewValue == null) return;`，
   而 `TreeView.SelectedItem` 是只读的 —— VM 把选中项清空后树上的高亮**留在旧行不动**。
2. **双击按"当前选中项"取参**：`TreeView_MouseDoubleClick` 只做 `item.IsSelected = true`，
   而"已选中"的行再置一次是幂等的（WPF 不再发 `SelectedItemChanged`），写回链一次都不跑。
   于是双击拿到 `SelectStep == null` → `Open(null)` → `return false` → **无窗、无提示、无日志**
   （`ProcessViewModel.cs` 旧写法丢弃了返回值）。

能触发通道 ① 的确定路径：`Core\IReadOnlyWorkspaceContext.cs` 的 `SwitchFlow(flow)` **无条件**
调 `SwitchStep(null)`；传入的就是当前流程时流程树不重建（高亮保留），但 `CurrentStep` 被清空。

## 3. 修法（三处，均为最小改动）

1. `TreeView_MouseDoubleClick`：`item.IsSelected = true` 之后补一步 ——
   若 `BindableSelectedItem != item.DataContext`，直接把被点的数据项写进绑定，
   保证"**命令靶 = 用户看到的那一行**"（与画布 `node.Model` 同口径）。
   顺带把 `e.OriginalSource` 改成 `(e.OriginalSource ?? e.Source)`：`MouseDoubleClick` 是 Direct 路由，
   合成事件只能投给树、`Source` 声明被点处（与 `ProcessView.IsBranchCardUnderMouse` 同一手法，回放才测得动）。
2. `OnBindableSelectedItemChanged`：`null` 不再直接 return，改为排队
   `ClearSelectionFromViewModel(tree)`（逐容器 `IsSelected = false`；排队期间 DP 已不是 null 就放弃）。
3. `ProcessViewModel.ModuleParameters`：接住返回值，靶不是步骤时给一条提示
   （插件视图创建失败那条路已由 `StepParameterDialog` 自己报过，这里只兜"没有可打开的靶"）。

## 6. 踩过的坑

- **单击流程栏算子本来就不弹窗**（`ProcessView.xaml:314` 只有 `DoubleClickCommand`）。
  先分清单击/双击，否则会去改一个本来就没有的行为。
- **`TreeView.SelectedItem` 只读**：清高亮只能逐容器 `IsSelected = false`，写 `SelectedItem = null` 编译不过。
- **`Control.MouseDoubleClickEvent` 是 Direct 路由**：`RaiseEvent` 只能投给挂处理器的树，`Source` 声明被点处；
  生产处理器若只读 `e.OriginalSource`，回放永远命中不了（本轮顺带补了 `?? e.Source` 兜底）。
- **"高亮着 ≠ 命令靶指着它"**：这是本仓第三次同类事故（前两次见
  `docs\code-changes\2026-10-16-流程栏删除没反应（删后命令靶被清空抹掉）.md`）。判据永远看命令靶字段，不看界面高亮。
- **并发会话**：本仓当前有第二个会话在改 SCADA/通讯。构建报 `CS0103` 或 `MSB3073 copy ... 代码为 1`
  时先看目标文件 `LastWriteTime`，别当自己的改动炸了（本轮两种都遇到过一次）。
