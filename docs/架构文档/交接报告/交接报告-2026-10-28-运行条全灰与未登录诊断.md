# 运行条全灰与「未登录」诊断（2026-10-28）

## 1. 当前状态

用户报「主界面显示未运行、运行条按钮不能点」。**诊断结论：不是程序故障，是会话已因空闲超时自动登出（未登录），
运行类命令被权限闸门整批拒绝**，七个按钮同时被 WPF 置灰。

机制（代码位置）：

1. `VisionMaster\ShellViewModel.cs:1761 CanExecuteExecution` 第一句就是
   `_permissionGate.Can(ScadaPermissionGate.PermissionFor(action), out _)`，不通过直接 `return false`。
2. `VisionMaster\Services\ScadaAccessPolicy.cs:170 Can`：未登录时 `_permissions` 为空数组，
   只有 `Always` 这个 Key 放行 → `Compile` / `ControlRun` / `Stop` / `EditStructure` 全拒。
3. `VisionMaster\Services\ScadaPermissionGate.cs:56-65`：编译=Compile、运行/暂停/继续=ControlRun、
   停止=Stop、单步=EditStructure。所以**七个按钮同时灰**是这条路径的指纹
   （若只是状态不对，未启动时「编译/运行」本应是亮的）。
4. 空闲登出：`AppConfig.json` 的 `IdleTimeoutMinutes = 10`，
   `ScadaAccessPolicy.OnIdleTick`（15 秒一拍）到点 `Logout()` 并弹一次
   「已因 N 分钟无操作自动退出登录」。
5. `SolutionSessionCoordinator.TryAutoLoginDebugAdmin`（`SolutionSessionCoordinator.cs:231`）
   **每进程只尝试一次**（`_debugAutoLoginAttempted`）——登出后不会自动登回，必须手动登录。

## 5. 踩过的坑

1. **别把「未启动」当故障**：运行条状态文字只反映 `RunState`，与「按钮能不能点」是两条判据；
   全灰时先看登录态与权限，再看 `RunState`。
2. **禁用按钮的 ToolTip 默认不弹**（`ToolTipService.ShowOnDisabled` 默认 false），
   「为什么不能点」在界面上没有任何说明，只能靠 audit CSV + operations.db 取证。
3. **audit CSV 是 UTF-8**，`type` 在 936 控制台下全是乱码；用 `rg` 或 python 按 UTF-8 读。
4. **operations.db 的 `ts_utc` 是 UTC**，与 audit CSV 的本地时间差 8 小时，对齐时别当成两次事件。
5. **判 exe 是否陈旧只看 mtime**：界面文案是旧构建的，不能拿它证明「代码没改」。
6. 同一天还有一次同型事件（12:59:44 登录 → 13:10:29 登出，10 分 45 秒），
   说明空闲登出在本机是**反复发生**的，不是偶发。
