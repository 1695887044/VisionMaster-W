## 5. 同步方案设计（待实现）

### 5.1 单一事实源

`AGENTS.md` 是唯一事实源。任何其他位置出现的规则，要么是从它派生的，要么是**明确标注的本地补充**。

### 5.2 单向镜像：`tools/sync_constraints.ps1`

把 `AGENTS.md` 中"**必须无条件遵守的硬约束**"抽取成一小段，写入 `~/.zcode/AGENTS.md` 的标记块之间。

```
<!-- DSH-SYNC:BEGIN （由 tools/sync_constraints.ps1 生成，不要手改） -->
... 生成内容 ...
<!-- DSH-SYNC:END -->
```

规则：

- **只替换标记块内部**，标记块外的内容（AgentHub 记忆中枢那段）原样保留。
- 幂等：连续跑两次，第二次不产生 diff。
- 检据一致：脚本读 `AGENTS.md` 的 `## 3. 三条红线`、`## 39.` 的 R179/R182/R183/R66、`## 1.` 的 R1–R6，不手抄正文。
- 失败不破坏：先写临时文件，成功后 `File.Move(overwrite: true)`（AGENTS.md R180 要求同时 catch `IOException` + `UnauthorizedAccessException`）。

### 5.3 镜像内容（第一批只放 7 条）

| 条目 | 为什么必须让 ZCode 知道 |
|---|---|
| 三条红线（插件工程位置 / 契约程序集不许拷进 `Modules\` / 改插件必须重建） | 违反即回滚，且症状静默 |
| R179 `dotnet build` 必须 `-m:1 -nodeReuse:false` | 本机不加会静默失败、报"0 个错误"但退出码 1 |
| R182 收尾验证唯一入口 `tools\run_gates.ps1` | 不跑这个入口就等于没验证 |
| R183 "没跑"和"跑绿了"必须能分开 | 子进程零输出必须判红 |
| R1–R5 编码与写文件（`.ps1` 纯 ASCII、不用 `Get-Content`/`Set-Content` 往返） | 会静默损坏无 BOM UTF-8 中文 |
| 文档落点：`docs/code-changes/` 或 `docs/交接报告-*.md`（R177） | 否则这轮结论等于没发生 |
| 根目录白名单 `tools\root-layout.json`（R166） | 根目录乱掉的直接原因 |

### 5.4 边界（不做的）

- **不**把 R1–R184 全量镜像过去。5.3 万字符塞进 ZCode 全局文件，两边都会失智。
- **不**做双向同步。ZCode 侧修的东西不许回写 `AGENTS.md`。
- **不**动 `.zcode/skills/` 下那两个保留的 SKILL.md——它们的正文是 DSH 之外的独立知识，只由 `AGENTS.md` 指路。

## 7. 踩过的坑

1. **PS 5.1 按 936 代码页读无 BOM UTF-8 的 `.ps1`** → 中文字面量变乱码，报 `MissingEqualsInHashLiteral`。修法：脚本文件纯 ASCII，中文放单独 UTF-8 JSON，用 `Get-Content -Encoding UTF8` 读。
2. **`git rm --cached` 后 `git mv` 报 `not under version control`**，导致 13 个 agent 文件从索引消失。修法：`git reset HEAD -- .zcode/` 恢复；教训是 `git mv` 失败先清目标、别先动索引。
3. **`Find`/全仓 `find -newermt` 极慢**，一度挂住 120 秒。改用定向 `ls` / `git status`。
4. **审计脚本第一次跑出 `ORPHAN=386`**，其中 `docs/code-changes` 一个目录就 392 篇日志。判定：把日志式记录算孤儿会让指标永远不可行动，且埋掉真信号 → 引入 `orphanPolicy.journalDirs` 豁免。
5. **控制台 936 代码页解码 UTF-8 输出** → 报告里所有中文路径变 `?`。修法：脚本开头 `[Console]::OutputEncoding = New-Object System.Text.UTF8Encoding($false)`。
