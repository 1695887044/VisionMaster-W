# 交接报告-2026-10-25-标注图 SCADA 显示链路核查

## 1. 当前状态

用户报「流程跑出来的 Halcon 带标注缺陷 / 文字的效果图，在 SCADA 显示不出来」。
核查结论：**现象真实存在，但不是单一 bug，分三类根因**：

1. **确定的能力缺口**：标注只走「覆盖层」的插件（颜色检查 / 颜色区域 / 几何查找 / 几何计算 / C# 脚本 ShowImage），以及图像脚本的「脚本自绘效果图」——这些标注从未进入 HImage 像素，SCADA 没有覆盖层通道，必然看不到。
2. **链路本身是通的**：已把标注烧进像素的插件（BlobDetect.DefectImage、CaliperMeasure.MeasureImage、Matching.MeasureImage、ResultDisplay.AnnotatedImage、ImageDiff.OverlayImage、BeadInspect.AnnotatedImage），只要按「标注输出 → 图像赋值 → 全局 HImage 变量 → ImageView.Source」接线，可以显示。
3. **历史所有权 bug 已修**：图像变量曾存上游端口引用，上游下一轮释放后转位图返回 null（Web `/img` 404「该图元当前没有图像」）；2026-10-24 已改为写入即拷贝 + 延迟一代释放。

本次为**代码走读 + 现有闸门日志核对**，未新构建、未改源码、未复现用户的具体方案。

## 5. 踩过的坑

- **主界面能看见 ≠ 图里有标注**：主界面是「HImage + 覆盖层」两路合成；SCADA 只拿 HImage 像素。
- **`ToBitmapSource` 静默失败**：只支持 1/3 通道，其它返回 null，调用点全 catch，现场只表现为「无图像」。
- **图像变量不落盘**：重启后为空（设计内），不能拿重启后的画面当缺陷。
- **编辑态不跑流程**：组态设计态 `ImageView` 永远显示「无图像」占位，不能作为判据。
- **别把所有权 bug 与标注丢失混为一谈**：前者是整张图周期性消失，后者是图在、标注不在。
