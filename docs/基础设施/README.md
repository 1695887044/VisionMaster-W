# 基础设施（共享技术底座）

本目录收录**全平台复用**的共享基础设施文档，属于**现行有效参考**（非归档）。所有插件都依赖这里的弹窗引擎与 UI 组件库，写插件文档时涉及弹窗 / 编辑器 / 样式规范，应链接到此目录，避免重复描述。

---

## 主文档（现行有效）

| 文件 | 作用 | 被谁依赖 |
|---|---|---|
| `EasyDialog弹窗引擎使用文档.md` | 弹窗引擎（EasyDialog）的 API、调用范式、自绘标题栏、尺寸/样式约定 | 所有带交互弹窗的插件（变量绑定、条件编辑器、C#/图像脚本编辑器等） |
| `UI组件库-Fluent设计系统与迁移.md` | UI 组件库的 Fluent 设计体系、控件清单、向统一组件库的迁移规范 | 全部插件配置界面（View） |

> 这两份文档已从 `docs/归档/` **提升**出来（去掉了 📦 归档横幅），因为经核实它们是唯一的使用文档、仍是现行参考。

## 索引 / 引用约定

- 插件主文档若讲到"弹窗""编辑器""UI 样式"，用相对链接指向本目录，例如：
  `../../基础设施/EasyDialog弹窗引擎使用文档.md`
- 如需引用具体整改背景，链接到 `整改记录/` 下对应文件。
- 本目录文档是**规范源**，各插件只需"引用 + 说明本插件如何遵循"，不要另起一套描述。
