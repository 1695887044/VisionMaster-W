## ⚠️ 最需要记住的五条

> 1. **残差超阈值是失败，不是警告**——先查点、再查单位、最后才动阈值（调大 = 显式放行错标定）。
> 2. **PixelScale 的产出没有机械坐标系**——需要机械坐标的场景必须用**九点标定**（或透视 / 网格），拿当量标定去换算会被下游明确拒绝。
> 3. **点数只是采样密度**：12 点仍是仿射，治不了畸变；畸变按"残差形态 → 升级路线"处置（主文档 1.2 / 2.6）——② 网格标定已可用，③ 内参仍是正解（设计已定、待实现）。
> 4. **0 是合法坐标，未填 = 留空**——整行不填才算空行；半填行会在运行时报错并指到行（别用 0 表示"没填"，旧方案"四值全 0"行载入时自动还原为空行）。
> 5. **网格标定的质量数字不是节点拟合残差**：节点处精确通过（残差恒 0），界面显示的是**全局仿射基线**残差（判读畸变大小用）；网格外一律失败、不外推。

## 维护约定

1. **只改主文档**。行为、失败文案、参数默认值以 `标定插件.md` 为准；方案说明书只作设计依据，不再随实现更新。
2. **改行为/修 bug 必须同时补回归断言**（`FlowCanvasChecks\CalibrationChecks.cs`），并在主文档第 4 章记录「现象 → 原因 → 修法 → 证据」。
3. **属性和端口名 = 持久化键 = 接线契约**：改名等于静默丢配置 / 断下游接线——改名前先想清楚，改完同步本文端口表与断言。
4. **修 `[StepConfig]` 属性遵守 R18 三选一写法**（自动属性 / partial + 钩子 / 保持手写），状态类钩子别写进 setter。
5. **契约（`CalibrationTransform`）变更要三处同步**：契约类注释、本文附录 B、以及「坐标变换」插件的消费断言。
6. **九点只覆盖标定平面**：工件有高度差/相机倾斜/镜头畸变都会表现为残差——升级路线见主文档 1.2，未做项列主文档 4.5。
