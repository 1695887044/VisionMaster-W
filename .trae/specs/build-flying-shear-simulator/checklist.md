## 电子凸轮技术点（核心验收）
- [x] 主从轴：虚拟主轴编码器驱动 3 个从轴，主轴速度/行程随设定运行（Modbus 冒烟：计米器 61→5342mm）（技术点 1、11）
- [x] 电子齿轮：工位3 齿轮比 2:1 时耦合中速度=2×材料速度（SimTest：600mm/s@材料300）；在线改比生效（技术点 2）
- [x] 电子凸轮：追剪臂、刀辊按凸轮表插值运动（技术点 3）
- [x] 啮合/脱离 Ramp：追剪切入/切出同步区加速度受限平滑无跳变（技术点 4）
- [x] 同步窗口：窗口内剪臂速度=材料速度；窗口起点/长度可写生效（技术点 5）
- [x] 定长计米器：恒速 500mm/s + 切长 2000mm 时循环触发间隔行程=2000mm，计数每循环 +1（技术点 6）
- [x] 飞剪三区段：切长 200/周长 400 → 加速区；切长 600 → 减速区；等长 → 等速区（技术点 7）
- [x] 相位偏移：飞剪刀刃相位 0.01° 精度、工位3 冲压相位可写生效（技术点 8）
- [x] 相位在线追赶：运行中改偏移 50mm，从轴斜坡追赶（最大单步增量 14mm）无位置跳变（技术点 9）
- [x] 凸轮表在线切换：写 40/41 表号 + 42 切换命令生效，曲线图随表号更新（代码路径 + 编译验证；3D 视觉效果待目视确认）（技术点 10）
