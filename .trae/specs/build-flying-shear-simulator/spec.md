# 电子凸轮多工位仿真产线 (Electronic Cam Multi-Station Simulator) Spec

## Why
学习电子凸轮技术（追剪、飞剪、相位偏移、多轴耦合）时，缺少一个低风险、可视化的验证环境。需要一个仿真平台：通过 Modbus TCP 与 PLC（先用模拟器代替）双向通信，用 3D 场景实时展示**三工位、多耦合**的复杂产线运行，覆盖电子凸轮的全部核心技术点。

## What Changes
- 新建独立解决方案 `E:\VM\FlyingShearSimulator`（不修改 VisionMaster 现有代码）
- 技术选型（3D 由 AI 决策，依据用户"性能高、无现成模型"的要求）：
  - **HelixToolkit.SharpDX.Wpf**（DirectX 11 渲染，性能高，支持 Instancing）
  - 无外部模型：**程序化几何建模**（MeshBuilder 搭建导轨、材料、剪臂、刀辊、冲压头）
- 通信：**NModbus** 库
  - 内置 **Modbus TCP 从站模拟器**（虚拟 PLC，监听 127.0.0.1:502），内部运行多轴虚拟运动学引擎
  - 平台同时作为 **Modbus TCP 主站客户端**，50ms 轮询驱动 3D 与仪表，参数/命令写回 PLC（双向）
- 架构：MVVM（CommunityToolkit.Mvvm），通信线程与 UI/3D 渲染线程分离；Core 类库纯逻辑可单元测试

## Impact
- Affected specs: 无（全新项目）
- Affected code: 全部为新文件，位于 `E:\VM\FlyingShearSimulator`
  - `FlyingShear.Core`（类库）：寄存器映射、虚拟轴引擎、凸轮表、三工位工艺逻辑
  - `FlyingShear.Simulator`（类库）：Modbus TCP 从站服务
  - `FlyingShear.App`（WPF net48）：主程序（MVVM + 3D + 凸轮曲线图 + 通信主站）

## 目标平台与技术基线
- 目标框架：.NET Framework 4.8（与用户现有开发环境一致）
- NuGet 依赖：`HelixToolkit.SharpDX.Wpf` (2.26.x)、`NModbus` (3.x)、`CommunityToolkit.Mvvm` (8.x)

## 工艺场景设计（三工位产线）

材料沿 X 轴从左向右连续运动（虚拟送料辊 = 主轴编码器），依次经过三个工位：

### 工位1：追剪（直线伺服剪臂）
- 剪臂自由停在原位 → 计米器累积材料行程达切长 → **啮合（Ramp 加速）** → 进入**同步窗口**（速度=材料速度）→ 到达剪切点剪切（计数+1）→ **脱离（Ramp 减速）** → 返回原位
- 同步窗口起点/长度可写；切长可写
- 教学点：2、3、4、5、6

### 工位2：旋转飞剪（刀辊）
- 刀辊 360° 旋转，凸轮表把"主轴行程"映射为"刀辊角度"，分三个区段：
  - **短切**（切长 < 刀辊周长）：加速区——刀辊在非剪切弧段加速追赶材料
  - **等长切**（= 周长）：全周等速，1:1 同步
  - **长切**（> 周长）：减速区——刀辊在非剪切弧段降速等待
- 刀刃咬合相位偏移可在线调整（0.01° 精度）
- 教学点：3、7、8、9

### 工位3：相位偏移冲压工位
- 冲压头通过**电子齿轮**直连主轴（齿轮比在线可改，默认 1:1）
- 材料上每隔固定间距印一个色标；冲压头按设定**相位偏移**对准色标下压
- 运行中修改相位偏移 → 从轴**斜坡追赶**到新相位（不跳变），3D 可见冲压头平滑滑移对准过程
- 教学点：2、8、9、11

## ADDED Requirements

### Requirement: 虚拟多轴运动学引擎（Core）
系统 SHALL 提供纯逻辑的多轴虚拟运动学引擎，20ms 步进运行，不依赖 UI 与通信库：
- `VirtualAxis`：位置/速度/加速度状态
- `MasterAxis`：按设定速度运行（可选缓慢扰动模拟速度波动），累计行程 = 计米器
- `CamTable`：凸轮点表（主轴位置→从轴位置），线性插值；支持多张表按编号选择
- 耦合模式：自由 / 电子齿轮（比例）/ 电子凸轮（查表）
- 耦合状态机：啮合中（Ramp 平滑过渡）→ 耦合中 → 脱离中（Ramp）→ 自由；相位修改后斜坡追赶
- 相位偏移：从轴目标 = 齿轮比/凸轮输出 + 相位偏移

#### Scenario: 齿轮耦合正确性
- **WHEN** 工位3 齿轮比 = 2:1，主轴前进 100mm
- **THEN** 工位3 轴位置前进 200mm

#### Scenario: 相位在线追赶
- **WHEN** 运行中把工位3 相位偏移从 0 改为 50mm
- **THEN** 工位3 轴在数秒内平滑追赶 50mm，无位置跳变，状态经历"相位追赶中→耦合中"

#### Scenario: 模拟器启动
- **WHEN** 点击"启动模拟器"
- **THEN** 监听 127.0.0.1:502，全部寄存器持续刷新，主轴按设定速度累积行程

#### Scenario: 飞剪长短切自动识别
- **WHEN** 切长设定为 200mm、刀辊周长 400mm
- **THEN** 飞剪状态出现"加速区(短切)"；切长改为 600mm 后出现"减速区(长切)"

### Requirement: Modbus TCP 主站通信服务
系统 SHALL 作为客户端以 50ms 周期轮询寄存器 0~44，解析为强类型状态对象；参数/命令写入用 FC06/FC16，处理 UInt32/Int32 高低字序（高字在前）。运行在后台 Task，断线自动重连（指数退避 1s→10s 上限），异常不阻塞渲染。

#### Scenario: 轮询与断线重连
- **WHEN** 模拟器停止后重启
- **THEN** 客户端数秒内自动重连恢复刷新，3D 保持上一状态不崩溃

### Requirement: 3D 场景（程序化建模）
系统 SHALL 用 MeshBuilder 程序化构建三工位产线，无外部模型：
- **全线**：底座 + 导轨贯穿，材料长条（贴图/UV 滚动表现速度），材料上按冲压间距绘制色标
- **工位1**：直线剪臂（立柱+横梁+刀头组合体），X 向追剪运动 + 剪切时 Y 向下压回弹
- **工位2**：旋转刀辊（圆柱+刀刃凸起），绕自身轴旋转，角度/角速度由寄存器 21/22 驱动，剪切瞬间视觉闪光
- **工位3**：冲压头，Y 向下压动画，相位追赶时可见沿 X 平滑滑移
- **相机**：整线全景/工位聚焦预设切换，鼠标旋转缩放
- 数据驱动：轮询 → Transform3D 更新，渲染帧率与轮询频率解耦

#### Scenario: 完整追剪循环可视化
- **WHEN** 线体启动，追剪切长 300mm
- **THEN** 剪臂从原位 Ramp 加速→与材料同速（同步窗口色块内）→下压剪切→减速返回，循环往复，计数递增

#### Scenario: 相位对准可视化
- **WHEN** 修改工位3 相位偏移
- **THEN** 冲压头沿材料方向平滑滑移，最终对准材料色标后冲压

### Requirement: 凸轮曲线 2D 图表
系统 SHALL 提供 2D 凸轮曲线图（自制 Polyline 或轻量图表库）：横轴主轴归一化位置、纵轴从轴归一化位置，绘制当前凸轮表曲线，并用高亮点标记实时工作点（寄存器 43/44）；切换凸轮表时曲线平滑更新。

#### Scenario: 工作点沿曲线运动
- **WHEN** 线体运行
- **THEN** 高亮工作点沿凸轮曲线连续移动，可直观看到加速区/等速区/减速区

### Requirement: 操作界面（MVVM）
系统 SHALL 提供以下 UI 区块，全 MVVM 绑定，无 code-behind 业务逻辑：
- **连接面板**：IP/端口、连接/断开、状态指示灯
- **模拟器面板**：启动/停止虚拟 PLC、主轴速度设定、线体启动/停止/复位
- **工位面板 ×3**：各工位参数（切长/窗口/相位/齿轮比/冲压间距）写入、状态中文+颜色、计数
- **凸轮表面板**：表号选择、在线切换按钮、凸轮曲线图
- **3D 视图区**：主界面中央
- **故障显示**：全局故障字红色告警

#### Scenario: 一键运行
- **WHEN** 启动 App → 启动模拟器 → 连接 → 线体启动
- **THEN** 三工位同时按各自逻辑运行，3D 与仪表实时刷新，无需额外配置

### Requirement: 模块化与可测试性
- `FlyingShear.Core` 不引用 UI/通信库，运动学与工艺逻辑可单元测试
- `FlyingShear.Simulator` 独立可拆出为独立进程模拟真实 PLC
- 寄存器地址集中于 `RegisterMap` 常量类，禁止魔法数字

#### Scenario: 运动学单元验证
- **WHEN** 恒速 500mm/s、切长 300mm 逻辑推演
- **THEN** 追剪循环触发间隔行程 = 300mm，计数每循环 +1；齿轮比 2:1 时位移关系正确
