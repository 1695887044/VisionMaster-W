# 综合检测线演示方案（综合检测线.vms）

> 方案文件：`解决方案\综合检测线.vms`（8 条流程 / 99 个步骤 / 33 类算子插件）
> 目标：用仓库现有算子把「PLC 触发 → 板卡视觉检测 → 判定 → 分拣 → 计数 → 上报/记账 → 多工位演示」串成一条可运行的完整线体。

## 2. 流程总览

| 流程 | 角色 | 调用方式 | 步骤数 | 作用 |
| --- | --- | --- | --- | --- |
| Home | 回原/回零 | 手动 | 11 | 轴使能 → 回零 → 读轴状态 → 待机位 → IO/PLC 就绪 |
| Main | 主任务 | HTTP 外部触发（位 64） | 42 | 读 PLC 触发 → 2 轮板卡检测 → 计数 → 并行上报/记账 → 报表 → 综合工位 |

| 卡尺测量 | 普通 | 子程序（位 32） | 15 | 宽度/两点距/点到线距/圆直径/角度 五种测量 |

| End | 收尾 | 手动 | 6 | 停轴 → IO 复位 → 清 S7 心跳 → 清就绪 → 延时 |

## 3. Main 主流程（计划表）

```
读PLC触发 (Modbus HoldingRegisters[0])
└─ 触发判断 (If: Trigger >= 1)
   ├─ If
   │  ├─ 循环检测 (For: 2 次, Index → 图像采集.FileIndex)
   │  │  ├─ 采集板卡图          (图像采集：Folder=D:\C#\VM\Image\board)
   │  │  ├─ 图像预处理          (高斯5 + 灰度闭运算5×5 + 锐化7×7/1.2)
   │  │  ├─ ROI圆区域 / ROI小圆区 (ROI 插件，矩形 ROI)
   │  │  ├─ 找圆 / 找小圆        (几何查找：Circle, Tukey)
   │  │  ├─ 两圆心距            (几何计算：CircleRelation, mm/px=0.05)
   │  │  ├─ 跟随ROI             (坐标变换：FollowRoi, 基准=ROI, 位姿=找圆)
   │  │  ├─ 表面缺陷检测        (Blob：暗目标, MinArea=10, MaxSingle=1000)
   │  │  ├─ 采集批号图          (OCR 测试图 lot_number_01.png)
   │  │  ├─ OCR识别             (工业 0-9A-Z 分类器, ROI=11240B)
   │  │  ├─ 缺陷数比较 / OCR文本比较 → 综合判定 (And)
   │  │  ├─ 写当前结果/OCR文本/缺陷数 (运行期变量)
   │  │  ├─ 结果显示            (缺陷数 / OCR / 判定 / 两圆心距)
   │  │  ├─ 写PLC结果           (Modbus HoldingRegisters[2])
   │  │  ├─ 分拣判断 (If: Ok)
   │  │  │  ├─ If  → X到取料位(100) → 等待到位 → X回检测位(0) → 等待到位
   │  │  │  └─ Else→ NG停止(减速) + NG报警灯(IO1)
   │  │  ├─ 读PLC确认           (HoldingRegisters[1])
   │  │  └─ 等待PLC确认 (Wait: Ack == 1, 5s, 超时继续)
   │  ├─ 结果计数 (Case: CurrentResult)
   │  │  ├─ True  → OKCount+1 → 写 OKCount
   │  │  └─ False → NGCount+1 → 写 NGCount
   │  ├─ 并行收尾 (Parallel, 真并发, JoinTimeout=15s)
   │  │  ├─ 上报MES (ResultUpload, Async, 失败不阻断)
   │  │  └─ CSV记录 (DataRecord, D:\Records\{StepName}\{yyyy-MM}\)
   │  ├─ 导出Excel报表 (Manual 触发)
   │  └─ 调用综合工位 (RunFlow)
   └─ Else → 空闲延时 200ms
```

### 3.1 判定口径

| 项 | 口径 |
| --- | --- |
| 缺陷数 | `DefectCount <= 10`（板卡样例实测 7~8 个） |
| OCR | `Count > 0`（实测 `11240B`，6 字符，置信 0.95） |
| 综合 | 缺陷 OK **且** OCR 有文本 |
| 分拣 | 综合为真 → X 轴取料位/回位；为假 → 减速停 + NG 报警灯 |

> 阈值是演示起点，换产品/换相机后按现场样本重标；`Blob.MaxSingleArea/MaxTotalArea/MaxDefectCount` 都在步骤配置里。

## 6. 运行前准备

1. **打开方案**：主程序 → 文件 → 打开 → `解决方案\综合检测线.vms`。
2. **让 Main 走检测分支**：把 `PLC_Modbus` 的保持寄存器 0（`PLC_Trigger`）写成 `1`；若为 0 会走 Else 只延时 200ms。
3. **确认回零**：先手动运行 `Home`，确认 ZMotion 虚拟卡 X/Y 轴使能、回零、到位。
4. **确认通讯**：连接管理器里三条连接应为在线；`PLC_Ack`（寄存器 1）在 5 秒内写成 1，否则「等待PLC确认」会超时（按设计继续执行并留日志）。
5. **MES 地址**：`上报MES` 步骤的 URL 是占位 `http://127.0.0.1:19001/api/inspect`，请改成实际接口；`AsyncMode=true`、`BlockOnFailure=false`，没有服务也不会阻断生产。
6. **Excel**：`导出Excel报表` 是 `Manual`，需要时在配置面板点「立即导出」；CSV 已由 `CSV记录` 每轮写入 `D:\Records\{流程.步骤}\{yyyy-MM}\{yyyy-MM-dd}.csv`。
7. **图片路径**：方案里全部是绝对路径 `D:\C#\VM\Image\...`；换机器时改各「图像采集」步骤的路径。

## 8. 已知边界

| 项 | 说明 |
| --- | --- |
| 循环次数 | 设为 **2 次**（board-01/02，同一板型）。`board-05` 起是旋转/不同板型，直接改成 5 次会让 ROI 失配，需按新图重画 ROI。 |
| 模板匹配 / YOLO / 深度学习分类 | 本方案未启用：仓库内没有可用的形状模板 / ONNX 模型。需要时先在对应插件里学习模板或放模型文件。 |
| 标定 | 未启用：没有现场标定板/九点数据；`Blob/Pose/Caliper` 的 mm/px 目前用手填 `0.05`（板卡）与 `1.0`（卡尺合成图）。 |
| Home/End 的真机动作 | 需要 ZMotion 虚拟卡与 S7 服务在线；离线打开方案不影响，运行时这两条流程的通讯/运动步骤会明确报错。 |
| 上报/报表 | 上报 URL 是占位；Excel 为手动导出。两者都不阻断主流程。 |
